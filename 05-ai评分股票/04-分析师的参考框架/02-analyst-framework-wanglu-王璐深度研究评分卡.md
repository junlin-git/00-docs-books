# 王璐式深度研究实战评分卡（优化版 V2）

本评分卡以申万宏源王璐分析师“**深研为锚、多维平衡、动态迭代、亲力闭环**”十六字方法论为内核，将顶尖卖方研究理念转化为可量化、可执行的自查清单。适用于卖方分析师、买方研究员及独立研究者进行深度研究能力的自我诊断。

---

## 一、核心价值观（底层行为准则）

- **亲手算账，拒绝二手**：任何核心假设必须亲手计算、亲手搭建模型，严禁直接粘贴第三方一致预期。
- **多目标博弈，拒绝线性**：公用事业（及周期/价值股）始终受**能源安全**、**低碳转型**、**社会承受力**三重约束，单因素推演必犯大错。
- **日拱一卒，活体迭代**：预测是动态修正的框架，而非报告发布即完结的静态作业。每月依据经营数据与政策信号校准。
- **开放证伪，诚实地犯错**：主动寻求团队“拍砖”，将误差归因为迭代养料。拒绝死不认错、拒绝模糊归因。

| :--- | :--- | :--- | :--- | :--- | :--- |
| **亲手搭建盈利模型** | 30% | 三张报表勾稽关系亲手编制；每个收入/成本分项均有底层行业数据（月度电价、煤耗、利用小时等）支撑；模型底稿路径清晰、数据源可追溯。 | 在第三方模型基础上做调整修改，能解释主要变量逻辑。 | | 直接复制万得/同花顺一致预期且无独立调整 → **此项记0分**。模型底稿缺失 → 一票否决。 |
| **高频数据跟踪密度** | 20% | 坚持每日整理核心指标（电价/煤价/来水/利用小时/负荷率）；**月度经营数据发布后48小时内**完成模型更新。 | 季度或半年度更新一次，依赖季报公开数据。 | | 超过1个月未跟踪核心指标 → 扣15分。未在48小时内响应月报 → 扣10分。 |
| **产业链调研频次** | 20% | **近3个月内**有实地或深度线上调研（含公司、供应商、大客户、竞对、政策制定侧）；调研纪要量化反哺模型假设。 | 近半年参加过业绩说明会或策略会，无独立草根调研。 | | 仅依赖年报和卖方路演 → 此项≤50分。 |
| **深度报告产出质量** | 15% | **每年≥2篇**深度首次覆盖/行业深度；报告含独立见解（非数据堆砌），附核心假设敏感性分析表与可验证的底层数据附录。 | 有定期跟踪点评，深度报告多为公开数据汇总。 | | 报告被发现重大数据错误或逻辑硬伤 → 一票否决。 |
| **公告/政策覆盖效率** | 15% | **每日**阅读全部相关行业公告、政府文件及监管动态；重大政策发布后**当日**完成解读并启动盈利影响测算。 | 选择性阅读重点公告，偶有遗漏。 | | 遗漏行业重大新政（如容量电价、碳配额规则）超过3天 → 此项不及格。 |

| 行为维度 | A级分析师日常标准 | 自检对照 |
| :--- | :--- | :--- |
| **每日必修课** | 早上8:15前到岗听晨会；每晚刷一遍所有覆盖公司公告；每周整理一次行业高频数据库。 | 能否连续一周做到？ |
| **模型习惯** | 每次季报发布后，48小时内完成模型修正并输出季度盈利前瞻；每年至少重构一次底层模型框架。 | 上季度是否按时完成？ |

| :--- | :--- | :--- | :--- | :--- | :--- |
| **政策三角平衡量化** | 30% | 预测中同时量化 **安全保供**（煤电兜底/备用率）、**低碳成本**（绿电消纳/碳价/绿证）、**经济承受力**（居民/工业电价弹性）三大约束，并能预判政策优先级切换时点。 | 聚焦煤电博弈，对其他政策提及但不量化。 | | 单边押注电价上涨而忽略保供压制 → 扣20分。 |
| **公司治理与执行力** | 20% | 对管理层战略（资本开支方向、分红承诺、新业务布局）有独立画像；能识别国企考核（市值管理、ROE）对经营行为的实质影响。 | 认可公司公开战略表述，未区分不同管理层风格差异。 | | 未识别出管理层频繁变更或利益输送倾向 → 此项≤50分。 |
| **跨行业交叉验证** | 20% | 主动融入**宏观、策略、周期、环保组**观点；将公用事业置于**利率-股息率比价**、**大宗商品轮动**、**资产配置切换**等跨资产框架中检验。 | 仅在本行业内纵向对比。 | | 从不参与跨组交流或仅引用宏观二手结论 → 此项≤60分。 |
| **情景分析与压力测试** | 15% | 报告中明确给出**乐观/中性/悲观**三种情景假设；对核心变量（煤价±10%、电价±5%、利用小时±3%）有敏感性测试表格。 | 仅给中性预测，偶提其他可能性但无量级。 | | 无情景分析且为绝对单值预测 → 此项≤50分。 |
| **估值方法适配性** | 15% | 依据公司生命周期与商业模式，灵活运用**PB-ROE、DDM、DCF、EV/EBITDA、分部估值**等交叉验证；不机械套用单一PE。 | 对稳定类用DDM、火电用PB，但无交叉验证。 | | 无论什么公司只用PE且无解释 → 此项≤40分。 |

## 五、动态校准与迭代闭环评分（过程管控，满分100）

| 校准维度 | 权重 | 优秀（90-100）标准 | 及格（60-79）标准 | 自评 | 扣分/否决项 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **月度经营数据校准** | 25% | **每月15日前**完成上月核心运营数据（发电量、利用小时、煤耗、电价）跟踪；偏离度超2%即启动假设复核并修正模型。 | 季报后统一调整，月频数据仅参考不校正。 | | 连续两季实际偏离>5%且未回溯说明 → 此项≤50分。 |
| **政策响应时效** | 25% | 重大政策（容量电价、碳配额、现货市场规则）发布后**3个工作日内**出具影响点评并**同步修正**年度盈利预测数字。 | 一周内解读但不立即修订盈利数字。 | | 政策实施一个月后模型仍未调整 → 此项≤30分。 |
| **误差归因书面回溯** | 30% | **每季度季报后**书面输出“预测 vs 实际”误差归因报告，拆解至具体假设分项（如煤价、利用小时、电价），将经验固化为模型校验参数。 | 内心有数但无正式记录；误差归因笼统为“市场突发”。 | | 从不做误差回溯 → 此项≤30分，**且总评级强制降一级**。 |
| **团队拍砖与协作** | 20% | **月度**将个人关键假设提交团队内部或导师进行“拍砖”挑战，记录批判意见及模型修正过程，形成书面修改纪要。 | 偶尔口头讨论，无书面修改记录。 | | 一味坚持己见拒绝接受质疑 → 此项≤40分。 |

## 六、一票否决陷阱（严禁出现）

- ❌ **刻舟求剑**：连续6个月未根据实际经营数据或政策变化修正核心假设，仍沿用初始报告预测。
- ❌ **二手数据依赖**：关键盈利假设（如燃煤成本、利用小时数）直接引用其他卖方或行业平均数据，无独立计算底稿。
- ❌ **单维度推演**：仅从供需缺口看多/看空，完全无视安全保供、低碳考核或社会承受力的反向约束。
- ❌ **隐瞒负面信息**：发布预测时对已覆盖公司，故意隐瞒调研中获得的负面信号、管理层限制或潜在利益关联。
- ❌ **逻辑不可证伪**：预测模型过于宏大抽象（如“受益于双碳长期趋势”），无法拆解为具体可跟踪的关键中间变量（KPI）。

## 七、行业配置思维验证（新增维度）

> 王璐不仅是优秀的行业分析师，更具备宏观配置视角。以下维度用于检验研究是否具有“自上而下”的配置价值。

| 配置维度 | 优秀标准 | 自评 |
| :--- | :--- | :--- |
| **利率敏感性分析** | 能定量测算无风险利率±50bp对覆盖公司DCF估值的影响幅度，并在利率拐点出现时主动调整目标价。 | |
| **跨资产比价框架** | 定期（至少每季度）将覆盖板块的**股息率、PE、PB**与**10年期国债收益率、理财收益率、REITs收益率**进行系统性比价，并给出相对吸引力排序。 | |
| **资金面洞察** | 能识别公募/保险/外资对公用事业板块的持仓变化趋势，判断增量资金的性质（追求股息 vs 追求弹性）与持续性。 | |
| **行业配置建议** | 在年度/半年度策略中给出明确的行业配置权重建议（如“超配水电、标配火电、低配光伏运营”），并有量化逻辑支撑。 | |

## 八、实战对标范例（验证标准）

| 应用场景 | 实战动作与检验标准 | 合格标志 |
| :--- | :--- | :--- |
| **火电公司年度盈利预测** | 1. **亲手搭建**：根据各省月度市场化电价、长协煤比例及履约率、现货煤价指数、利用小时，**逐月汇总**推演全年净利润。<br>2. **交叉验证**：与宏观组煤价判断、策略组红利资产资金流向对表。<br>3. **压力测试**：煤价±5%、电价±2%对净利润的敏感性表。<br>4. **误差回溯**：季报后对比“预测vs实际”，修正后续季度假设。 | 全年实际净利润落在预测值**±5%**区间内；且**季度节奏（Q1-Q4）**与实际吻合。 |
| **绿电运营商估值定价** | 1. **多元估值**：PB-ROE（对标央企考核）、DCF（折现率随无风险利率动态调整）、EV/EBITDA（对比可比港股）。<br>2. **政策量化**：将绿证交易收入、补贴回款进度、现货市场折价分别独立建模。<br>3. **收益率拐点判断**：结合行业装机节奏与消纳压力，判断绿电IRR是否已触底。 | 研报发布后6个月内，股价偏离目标价**＜10%**。 |
| **水电公司分红预测** | 1. **底层数据**：亲自跟踪流域来水预测、梯级调度策略及外送电价。<br>2. **资本开支拆解**：逐一拆分在建工程转固节奏及折旧影响。<br>3. **股东回报测算**：结合国资委市值管理指引，推算极限分红比例与股息率。<br>4. **利率联动**：测算10年期国债收益率下行50bp对DCF估值的增厚幅度。 | 预测股息率与实际公告股息率偏差**＜0.3个百分点**。 |
| **行业配置观点输出** | 1. **跨资产比价**：将水电股息率与国债收益率、理财收益率进行历史分位数对比。<br>2. **资金面判断**：测算公募/保险当前配置比例及理论增配空间。<br>3. **明确建议**：输出“超配/标配/低配”的明确行业配置结论。 | 行业配置建议在**6个月内**被市场验证有效（相对收益为正）。 |

## 九、综合评级与使用建议

| 总分（加权后） | 评级 | 预测可信度 | 使用建议 |
| :--- | :--- | :--- | :--- |
| **≥85** | **A级（深度研究）** | 高，具备持续高精准度输出能力 | 可将其核心假设作为仓位配置依据，重点关注其情景分析中的悲观底线。 |
| **70-84** | **B级（合格跟踪）** | 中，常规季度预测可靠，但年度拐点判断需审慎 | 可作为行业数据来源与逻辑参考，重大拐点决策需二次独立验证。 |
| **<70** | **C级（浅层研究）** | 低，预测多为线性外推或滞后修正 | 仅作信息浏览，不适用于投资决策参考。 |

> **使用说明**：本评分卡的目标不是刻板打分，而是对标顶尖分析师（王璐）研究习惯的**自查清单**。真正的预测思维，最终落脚于**日复一日的积累**与**诚实的误差反思**。建议每季度对照评分卡进行一次全面自评，并将结果记入研究日志，形成“自评-迭代-进步”的正向循环。
