# 东方财富股票软件指标完整版详解（含手算公式与实战案例）

> 东方财富软件指标可归纳为四大类：**基本面与行情数据类**、**趋势类**、**震荡超买超卖类**、**量价资金面类**。以下以东方财富（300059）2026-06-16的真实收盘数据（18.89元）为基准，逐条拆解公式、计算过程、看盘要点与实战逻辑。

## 一、基本面与行情数据指标（F10 → 操盘必读）

### 1. 最新价（现价）
*   **是什么**：最近一笔成交的价格，是整个F10页面所有市值/估值的“发动机”，只要它变，总市值、PB、换手对应的金额全跟着变。
*   **例子**：最新价 = 18.89 元，昨收 = 18.89 元，今开 = 18.70 元，最高 = 19.46 元，最低 = 18.69 元。
*   **读盘**：最高 19.46 - 最低 18.69 = 振幅 0.77元，振幅% = 0.77/昨收 ≈ 4.08%。

### 2. 涨跌额 & 涨跌幅
*   **公式**：涨跌额 = 最新价 - 昨收；涨跌幅 = 涨跌额 / 昨收 × 100%
*   **例子**：若盘中最新=19.12，昨收=18.89，则涨跌额 = +0.23 元，涨跌幅 = +1.22%。

### 3. 成交量（VOL）
*   **是什么**：单位时间内成交的股数/手数。软件默认显示万手，1手=100股。
*   **例子**：成交量 = 458.08 万手 = 4.58 亿股。
*   **验算换手率**：流通股本 ≈ 133.53 亿股，换手率% = 4.58亿 / 133.53亿 × 100% ≈ 3.43% ✅

### 4. 成交额
*   **是什么**：当日成交的总金额（成交量 × 均价）。
*   **例子**：成交额 = 87.49 亿元。验算：4.58亿股 × 均价(约19.1元) ≈ 87.5亿 ✅
*   **意义**：比成交量更“真实”。同样是100万手，股价10块和100块的成交额差10倍，市场含义完全不同。

### 5. 换手率（Turnover Rate）
*   **公式**：换手率% = 当日成交量(股) / 流通A股 × 100%
*   **区间对照表**：
    | 换手区间 | 含义 | 东方财富3.43%属于 |
    | :--- | :--- | :--- |
    | < 1% | 极度冷清 | |
    | 1%~3% | 正常震荡 | |
    | 3%~5% | 开始活跃 | ←边缘/这里 |
    | 7%~10%+ | 短线激烈博弈 | |

### 6. 总股本 & 流通股本
*   **是什么**：总股本是公司发行的全部股票数量；流通股本是在二级市场可交易的股票；差额为限售股。
*   **例子**：总股本 = 158.22 亿股，流通股本 = 133.53 亿股，限售股 ≈ 24.69 亿股（含股权激励未解锁等）。

### 7. 总市值 & 流通市值
*   **公式**：总市值 = 最新价 × 总股本；流通市值 = 最新价 × 流通股本
*   **例子**：总市值 = 18.89 × 158.22亿 ≈ 2988.7 亿；流通市值 = 18.89 × 133.53亿 ≈ 2522 亿。

### 8. PE 市盈率（三种口径拆解）
*   **8a. PE(静) 静态市盈率**
    *   公式：总市值 / 上年度（2025）归母净利润
    *   例子：3000亿 / 120.85亿 ≈ 24.8 倍。白话：按去年赚的钱不变，约 24~25年回本。
*   **8b. PE(TTM) 滚动市盈率（最常用）**
    *   公式：总市值 / 最近4个季度归母净利润之和
    *   例子：页面显示 PE(TTM) ≈ 23.08 倍。标尺作用：投资者愿意为每一块钱年度利润支付 23 块钱。
*   **8c. PE(动) 动态市盈率**
    *   公式：总市值 / 预估全年净利润（如季报×4）
    *   例子：2026Q1净利 37.38 亿 × 4 = 149.52 亿，PE(动) ≈ 3000 / 149.52 ≈ 20.1 倍。

### 9. 每股净资产（BVPS）& PB 市净率
*   **公式**：每股净资产 = 归母净资产 / 总股本；PB = 股价 / 每股净资产
*   **例子**：归母净资产 918.75 亿 / 总股本 158.22 亿 ≈ 5.81 元/股。PB = 18.89 / 5.81 ≈ 3.25×。
*   **区间对照表**：
    | PB读数 | 含义 |
    | :--- | :--- |
    | < 1× | 破净（市场觉得净资产有水分，银行/钢铁常见） |
    | 1~2× | 重资产制造业正常 |
    | 2.5~4× | 轻资产/牌照/品牌溢价（东方财富在此区间） |
    | > 5× | 高增长预期或泡沫区 |

### 10. ROE 净资产收益率
*   **公式**：ROE(%) = 归母净利润 / 平均归母净资产 × 100%
*   **例子**：2025年报加权ROE = 14.03%。股东每投100块钱本金，一年赚约14块钱。
*   **杜邦拆解（东方财富商业逻辑）**：ROE = 净利率(75%) × 资产周转率(4.1%) × 权益乘数(4.3)。净利率极高是因为轻资产平台；周转率低是因为客户保证金计入总资产导致基数大。

### 11. 毛利率
*   **公式**：毛利率% = (营业收入 - 营业成本) / 营业收入 × 100%
*   **例子**：2025年报毛利率 = 70.30%。每赚100块营收，扣掉直接成本剩70.3块。
*   **行业逻辑**：营业成本主要是服务器折旧+带宽+人员薪酬，边际新增用户成本极低，导致天然高毛利。

### 12. 净利率
*   **公式**：净利率% = 归母净利润 / 营业收入 × 100%
*   **例子**：120.85 / 160.68 × 100% = 75.2%。
*   **行业逻辑**：券商净利率高不等于暴利，因为表内有大量客户保证金和交易性金融资产，表观净利率会被投资收益放大。

### 13. 资产负债率
*   **公式**：资产负债率% = 总负债 / 总资产 × 100%
*   **例子**：总资产 3929.34 亿，净资产 918.75 亿，负债率 ≈ 76.6%。
*   **行业逻辑**：76%看着吓人，但券商负债大头是客户交易结算资金（欠客户的，非坏账风险）、卖出回购等。东方财富作为互联网券商，杠杆反而比传统券商更干净。

### 14. 营收同比 & 净利润同比
*   **公式**：同比% = (本期 - 去年同期) / |去年同期| × 100%
*   **例子**：营收同比 +38.46%，净利润同比 +25.75%。利润增速略低于营收增速说明成本随业务扩张增长，但双位数+高净利率说明不是苦哈哈生意。

### 15. 扣非净利润
*   **是什么**：扣除与主业无关的偶然性损益后的净利润。
*   **例子**：扣非 116.54 亿，归母净利 120.85 亿。差额 4.31 亿来自非经常性损益。净利≈扣非，说明利润真实来自主业。

## 二、技术面 - 趋势类指标

### 1. MA 移动平均线
*   **公式**：MA(N) = (C₁ + C₂ + ... + Cₙ) / N
*   **手算示例**：假设近5天收盘价为 17.80, 18.10, 18.50, 18.30, 18.89。MA5 = (17.80+18.10+18.50+18.30+18.89)/5 = 18.318。
*   **买卖信号**：多头排列（短在上长在下，全向上）看涨；金叉（短上穿长）买入，死叉卖出。
*   **读盘**：东方财富当前价18.89 > MA5(18.23)，踩在MA20(18.89)上，但在MA60(19.57)下，属“震荡修复”形态。

### 2. MACD 指数平滑异同平均线
*   **公式**：DIF = EMA(12) - EMA(26)；DEA = EMA(DIF, 9)；柱 = (DIF - DEA) × 2
*   **权重理解**：EMA(12)的α = 2/13 ≈ 0.1538，对新价权重15.4%，比SMA的8.3%更敏感。
*   **真实值**：DIF = -0.442，DEA = -0.481，柱 = +0.077。
*   **读盘**：DIF/DEA在零轴下方=大趋势偏空；但柱翻红=DIF上靠DEA，动能修复中。零轴下金叉仅为弱势反弹买点。

### 3. BOLL 布林带
*   **公式**：中轨 MB = MA(20)；上轨 UB = MB + 2×σ；下轨 LB = MB - 2×σ
*   **手算示例**：均值18.318，方差0.135，σ ≈ 0.367。上轨 = 18.318 + 2×0.367 = 19.052。
*   **真实值**：UB=21.177，MB=19.222，LB=17.266。
*   **读盘**：当前价18.89在中轨略下方（偏弱震荡），距上轨还有2.29空间。UB-LB收窄是变盘前兆。

### 4. BBI 多空指标
*   **公式**：BBI = (MA3 + MA6 + MA12 + MA24) / 4
*   **买卖信号**：收盘价上穿BBI买入，下破卖出。

### 5. EXPMA 指数平滑均线
*   **公式**：新EXPMA = 昨日EXPMA + α × (今日收盘 - 昨日EXPMA)
*   **手算示例**：昨日18.10，今日收18.89，N=12，α=0.1538。新EXPMA = 18.10 + 0.1538×0.79 = 18.22。
*   **本质**：MA每天权重一样，EXPMA更看重“刚才发生的价格”，少滞后半拍。东方财富当前EXPMA(12)=18.557。

### 6. DMI 趋向指标
*   **公式**：+DM = 今日最高-昨日最高(若正)；TR = 真实波幅。ADX = EMA(DX, 14)。
*   **读盘**：ADX < 20 是震荡市，趋势指标容易打脸；ADX > 25 才是真正的方向性行情。东方财富近期ADX偏低，适合BOLL下轨买上轨减。

### 7. SAR 抛物线停损
*   **逻辑**：多头中，圆点在K线下方（动态止损线）；若某日最低价 ≤ SAR，则翻空，圆点跳到K线上方。
*   **例子**：假设SAR在18.20，若明日最低打到18.15，系统翻空提示先出来。

### 8. DMA 平均线差
*   **逻辑**：用两条不同周期均线之差判断中长期资金趋势。DDD上穿AMA买入，双线同步向上主升延续。

## 三、技术面 - 震荡超买超卖类指标

### 1. KDJ 随机指标
*   **公式**：RSV = (C - L9) / (H9 - L9) × 100；K = 2/3×K(prev) + 1/3×RSV；J = 3K - 2D
*   **真实值**：K=53.03，D=31.83，J=95.44。
*   **读盘**：K、D在20下超卖，80上超买。当前J≈95逼近100超买警戒线，不理想追涨点，等回踩20~30区。

### 2. RSI 相对强弱指标
*   **公式**：U = 上涨日涨幅均值；D = 下跌日跌幅均值；RSI = 100 - 100/(1+U/D)
*   **手算示例**：6天内涨跌幅为 +0.30, -0.20, +0.40, -0.15, +0.54。U=0.207，D=0.058，RS=3.57，RSI = 100 - 21.9 = 78.1。
*   **读盘**：真实RSI(6)=65，偏强但未到75~80危险区。

### 3. WR 威廉指标
*   **公式**：W%R(N) = (Hₙ - C) / (Hₙ - Lₙ) × (-100)
*   **手算示例**：H14=19.80，L14=17.50，C=18.89。W%R = 0.91 / 2.30 × (-100) = -39.6。
*   **读盘**：-20以上偏超买，-80以下偏超卖。当前-39.6为中位偏上。

### 4. CCI 顺势指标
*   **公式**：典型价 TP = (H + L + C) / 3；CCI = (TP - MA(TP)) / (0.015 × MD)
*   **手算示例**：H=19.46, L=18.69, C=18.89。TP = 19.013。若MA(TP)=18.80, MD=0.25，CCI ≈ +56.8。
*   **读盘**：+100以上强势区，-100以下超卖区。当前+57中性。

### 5. BIAS 乖离率
*   **公式**：BIAS(N) = (C - MA(N)) / MA(N) × 100%
*   **手算示例**：C=18.89，MA5=18.23。BIAS(5) = 0.66 / 18.23 × 100% = 3.62%。
*   **读盘**：+5%~+8%以上短线偏离易回踩；当前+3.6%为轻微正乖离，温和偏强。

### 6. ROC 变动率指标
*   **逻辑**：当日收盘与N日前收盘的差值比。上穿0轴买入，下穿卖出。

### 7. PSY 心理线
*   **逻辑**：N日内上涨天数占比。>75超买，<25超卖。

## 四、技术面 - 量价资金面类指标

### 1. VOL 成交量 + 均量线
*   **手算示例**：前4日量280, 310, 265, 340，今日458。MAVOL5 = 330.6万手。放量倍数 = 458 / 330.6 ≈ 1.39倍（温和放量）。
*   **价量组合**：阳线+VOL>MAVOL=真涨；大阴线+爆量=出货；连跌后VOL缩到极致=抛压枯竭。

### 2. OBV 能量潮
*   **公式**：涨日OBV+=VOL；跌日OBV-=VOL。
*   **手算推演**：
    *   第2天涨，VOL=350 → OBV = 1000 + 350 = 1350
    *   第3天跌，VOL=280 → OBV = 1350 - 280 = 1070
*   **读盘**：股价盘整但OBV悄悄走高，“价未动量先动”，有人在吸筹。

### 3. VR 成交量变异率
*   **逻辑**：上涨日量总与下跌日量总比值。<40超买，>350超卖。

### 4. CR 带状能量线
*   **逻辑**：以中间价计算能量。低位上穿其均线买入。

### 5. 资金流向（主力/超大单/大单/中单/小单）
*   **是什么**：超大单(>100万)、大单(20-100万)等主动买卖差额。主力=超大单+大单。
*   **读盘**：主力净流入为正且占比高=机构增配；主力流出散户流入=警惕派发。

### 6. CYQ 筹码分布
*   **是什么**：将流通盘按买入成本挂到价位上。蓝色套牢盘，红色获利盘。
*   **读盘**：低位单峰密集后放量突破买入；高位密集且筹码上移卖出。

### 7. CBW 成本带宽
*   **逻辑**：筹码最上沿与最下沿距离比。CBW降至5以下，无震荡空间，近期可能突破。
