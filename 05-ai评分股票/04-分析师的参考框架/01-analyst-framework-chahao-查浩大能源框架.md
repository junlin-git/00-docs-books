# 查浩式“大能源”选股实战框架（优化版）

本框架以华源证券查浩团队“**级差地租+低协方差重估+杠铃策略**”方法论为内核，将抽象投资哲学转化为可量化、可执行的实战筛选标准。适用于在大能源（水、火、核、绿、电力市场化服务）赛道中寻找长期Alpha。

---

## 一、核心投资哲学（底层行为准则）

- **EVA（经济增加值）优先**：项目IRR必须显著高于WACC，创造正向EVA。这是企业价值增厚的唯一来源，拒绝“伪增长”。
- **低协方差重估**：优选与宏观经济弱相关的资产（水电、核电），利用CAPM模型中β极低的特性，在利率下行周期获取系统性估值弹性。
- **级差地租防御**：在同质化商品（电）中，只筛选“最低成本供给”（前20%分位）。这是穿越周期、获取长期护城河的唯一路径。
- **供需平衡定方向**：不博弈短期电价，通过“电力电量平衡表”和“煤电利用小时数倒算”锚定3-5年供需格局拐点。
- **杠铃策略（守正出奇）** ：核心仓位重仓低协方差（水核），卫星仓位配置高弹性（算电协同、绿电反转、电力交易新业态），靠现金流与分红实现复利。

---

## 二、定量筛选标准（硬性指标门槛）

| 指标 | 要求 | 备注与逻辑 |
| :--- | :--- | :--- |
| **项目IRR（内部收益率）** | ≥ 8% | 重资产底线。IRR仅与项目现金流有关，决定分子端价值。 |
| **IRR与WACC差值** | IRR - WACC > 2% | 必须创造正向EVA。若低于折现率，即为毁灭股东价值。 |
| **股息率（TTM）** | 水核≥4%；稳健火电≥4%；高成长绿电≥3%（需IRR补偿） | 分红是低协方差资产复利的核心抓手。 |
| **市盈率（PE-TTM）** | 火电/绿电≤15倍；水核等久期长资产可放宽至≤20倍 | 低协方差资产享受估值溢价。 |
| **市净率（PB）** | 火电/绿电破净（<1）优先；水核高ROE支撑下≤2.5倍可接受 | 破净火电具备极高安全边际。 |
| **ROE（净资产收益率）** | 近三年平均≥8%；水核需≥10% | 反映底层资产盈利质量。 |
| **经营现金流/净利润** | ≥ 1.2倍 | 重资产折旧高，现金流必须远大于账面利润（真金白银）。 |
| **资产负债率** | < 70%（重资产可适度放宽） | 需关注久期与当前利率环境的匹配度。 |
| **资本开支拐点** | 趋于平稳或明确下降 | 资本开支缩减时，往往是FCF跃升与股息率爆发的起点。 |

## 三、定性筛选标准（查浩“级差地租+DCF”框架）

### 3.1 自上而下基础定性
- **区域供需格局**：优选处于“紧平衡至短缺”区域（华东、华南）的发电企业。
- **股东背景**：大型央企/国企优先，融资成本低，匹配国家能源安全战略。
- **资产久期匹配**：利率下行周期，久期越长的资产（水核）分母端估值弹性越大。
- **业务定位清晰**：煤电须有“调节性电源”转型逻辑；绿电须有资源禀赋；新业态须有技术壁垒。

### 3.2 查浩八项核心定性原则（精选“低成本+低协方差”）

| 序号 | 核心原则 | 具体要求与量化标准 |
| :--- | :--- | :--- |
| 1 | **供需平衡表测算** | 能通过“电量平衡表”独立倒算煤电利用小时。理解利用小时下降是结构性转型，并非“过剩”。 |
| 2 | **级差地租优势** | 度电成本位于同电源类型**前20%**（如优质大水电、低造价陆风、坑口低煤价火电）。 |
| 3 | **低协方差属性** | 业绩（电量/电价/现金流）不随宏观经济周期大幅波动，享受CAPM低风险溢价。 |
| 4 | **极简DCF检验** | 核心资产寿命期内，净现金流现值总和 > 初始投资（NPV>0），且EVA持续为正。 |
| 5 | **先发优势与资源壁垒** | 优质资源“先占先得”（如早期核准水电站址、一类风资源区），后发者无法复制或成本极高。 |
| 6 | **出力曲线匹配度** | 出力曲线与用电负荷匹配度高的电源优先：**风电优于光伏**；有调节能力的水电优于径流式。 |
| 7 | **转型锚点（火电）** | 若为火电标的，必须量化**容量电价+辅助服务收入**占利润比重。此为判断“调节性价值”转型成败的唯一锚点。 |
| 8 | **分红与FCF拐点** | 进入成熟期，资本开支缩减，FCF充沛，且有明确提升分红比例的意愿与能力。 |

## 四、一票否决（禁止买入）

- ❌ IRR低于WACC，长期EVA为负，毁灭股东价值者。
- ❌ 协方差极高、业绩随宏观经济剧烈波动，却被市场错视为“公用事业”的伪防御股。
- ❌ 处于长期电力过剩（备用率>15%）区域，且无特高压外送消纳逻辑的火电。
- ❌ 度电成本处于行业后30%，仅靠补贴或高电价存活的“高成本供给”绿电。
- ❌ 资本开支无休止扩张，FCF常年为负，无法兑现分红承诺的能源股。
- ❌ 盲目跨界新能源，缺乏资源禀赋与管理半径，导致主业被拖累的标的。
- ❌ 久期极短（如临近退役机组）却被市场按“长久期水核”给与高估值的陷阱股。

## 五、当前市场环境下的特殊考量（2025-2026周期）

基于当前“十五五”规划前期、利率长周期下行、电力市场化深化的背景，需额外聚焦以下五大边际变化：

1.  **煤电定位重塑（转型锚点）**
    煤电利用小时下降是必然趋势。火电价值从“电量主体”转向“调节主体”。**容量电价+辅助服务收入占比**是衡量其转型成败的核心指标（低于20%利润占比的标的需谨慎）。

2.  **无风险利率下行（低协方差重估）**
    长端利率持续下行周期中，以**“四水两核”（长江电力、华能水电、国投电力、川投能源、中国核电、中国广核）**为代表的低协方差、长久期资产，其折现率下降对估值的正贡献远大于盈利波动，DCF重估空间巨大。

3.  **绿电收益率触底与分化（级差地租验证）**
    风电与光伏收益率显著分化。现货市场中，光伏出力集中导致折价严重。需重点关注**风电（级差地租优质）**资源的重估机会，特别是当“绿电运营收益率全面触底”时，风电价值重估或将悄然展开。

4.  **算电协同爆发（出奇弹性）**
    AI算力爆发带来用电增量与高质量用能需求。重点关注**东部沿海（电力紧缺区域）**的“源网荷储算”一体化运营商，或具备向算力中心输出稳定绿色电力的区域能源龙头。

5.  **电力市场化新业态——卖铲人战略**
    电力现货市场全面铺开后，电力交易复杂度指数级上升。**电力交易策略、负荷聚合、虚拟电厂等“卖铲人”型服务商**将迎来行业性机遇。此为杠铃策略中“出奇”端的重要新补充。

## 七、附：框架动态校验原则

- **季度校验**：每季度对照实际“电力电量平衡表”与模型推演，修正对利用小时及电价趋势的判断。
- **政策响应**：容量电价标准、绿证交易规则、现货市场结算细则发布后，3个工作日内完成对持仓标的影响测算。
- **利率跟踪**：密切跟踪10年期国债收益率走势，动态调整DCF折现率假设，尤其是对“四水两核”的目标估值进行重估。
