# 《怎样选择成长股》15原则深度分析 —— SOP + 评分模板

## 一、标准操作流程（SOP）

### 1. 数据准备（必须获取的最新数据）

在开始分析前，请确保收集以下**最新**数据（建议以最近一期年报/季报及近3年历史数据为准）：

| 数据类型 | 具体内容 | 推荐来源 |
|---------|---------|---------|
| **财务数据** | 近3-5年营收、净利润、毛利率、净利率、ROE、研发费用、销售费用、经营性现金流 | 同花顺、东方财富、公司年报 |
| **估值数据** | 当前PE、PB、市值、历史估值分位 | 同花顺、Wind |
| **行业数据** | 行业总规模、增速、竞争格局、公司市占率 | 行业白皮书、券商研报、行业协会 |
| **公司公告** | 年报、季报、重大合同、再融资、股权激励、监管问询函及回复 | 巨潮资讯、上交所/深交所官网 |
| **管理层信息** | 高管简历、持股变动、媒体报道、公开演讲 | 公司官网、雪球、百度资讯 |
| **第三方评价** | ESG评级、信息披露评级、审计意见 | MSCI、上交所评级、审计报告 |
| **渠道/客户信息** | 经销商数量、终端覆盖、大客户反馈（若有） | 公司公告、行业调研、招聘网站（员工评价） |

### 2. 分析流程（逐步执行）

1. **快速初筛（10分钟）** ：财务数据是否符合基本要求（营收/净利正增长、ROE>10%、毛利率>行业平均）？若不符合，可直接给出低分，但仍需完成后续分析以确认原因。

2. **逐条评估（每项5-15分钟）** ：按照模板中的15个原则，逐一收集证据，给出得分和理由。注意：每个原则必须基于**最新数据**和**可验证事实**，避免主观臆断。

3. **交叉验证（30分钟以上）** ：利用“闲聊法”思路，寻找多方信息源印证或反驳。例如：查看竞争对手年报对比、搜索员工评价、关注监管问询等。

4. **综合评分与风险分析（15分钟）** ：汇总得分，识别得分最低的项（风险点），撰写总体判断。

5. **定期复评（至少每季度一次）** ：公司基本面可能变化，需持续跟踪关键指标（如营收增速、利润率、管理层变动等）。

### 3. 评分标准（每个原则满分见权重表）

- 得分 ≥ 该原则满分×90% → 优秀（⭐等效为5星）
- 得分 ≥ 满分×70% → 良好（⭐等效为4星）
- 得分 ≥ 满分×50% → 及格（⭐等效为3星）
- 得分 ≥ 满分×30% → 较差（⭐等效为2星）
- 得分 < 满分×30% → 很差（⭐等效为1星）
