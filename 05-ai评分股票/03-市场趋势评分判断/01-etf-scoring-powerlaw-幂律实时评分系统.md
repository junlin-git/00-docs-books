> **核心升级说明**：本版本基于 V3.1 框架，将“成交额集中度”、“品类虹吸”、“热度排名”等核心维度的**离散阶梯打分**全部替换为**连续幂律函数（Power-law Distribution）**。数学上消除了“69.9%占比给15分，70.1%占比给25分”的阈值跳跃，实现了盘中实时评分的平滑与公平，更贴合头部流动性“赢家通吃”的幂律分布本质。
> 
> **适用对象**：A股行业主题ETF + 港股行业主题ETF（分类归属规则及港股映射见附录，与V3.1完全一致）。

## 二、四维度评分细则（满分 100分 = 连续幂律基础分 + 动态调节项）

### 维度一：资金极端集中度（满分 40分）—— **完全幂律连续化**
本维度彻底废弃阶梯分段，改用连续幂律函数（指数α根据头部虹吸强度设定为 **0.35 ~ 0.6**）。

#### ① 全市场流动性幂律分（满分 25分）
- **公式**：`流动性幂律分 = 25 × ( 该ETF成交额 / 全市场第1名成交额 ) ^ 0.35`
- **额外精英奖励（触发即加）**：若该ETF为全市场成交额 **第1名**（即比值 = 100%），直接 **+3分**（流动性之王）。
- **即时映射效果**（参考）：
  - 占比 70% → `25 × 0.7^0.35 ≈ 22.1` 分（原阶梯为25分，平滑过渡）
  - 占比 40% → `25 × 0.4^0.35 ≈ 18.0` 分（原阶梯为15分，更细腻）
  - 占比 15% → `25 × 0.15^0.35 ≈ 11.8` 分（原阶梯为8分）
  - 占比 5% → `25 × 0.05^0.35 ≈ 7.4` 分（原阶梯为3分，给予长尾流动性底部溢价）

#### ② 行业品类虹吸幂律分（满分 15分）
- **公式**：`品类虹吸分 = 15 × ( 该ETF成交额 / 该二级行业品类总成交额 ) ^ 0.5`
  - （A股支分母只加A股同类，港股支分母只加港股同类，绝对不跨支相加）
- **即时映射效果**（参考）：
  - 品类占比 40%（龙头）→ `15 × 0.4^0.5 ≈ 9.5` 分
  - 品类占比 15% → `15 × 0.15^0.5 ≈ 5.8` 分
  - 品类占比 8% → `15 × 0.08^0.5 ≈ 4.2` 分

**维度一得分 = ①得分 + ②得分**（无离散断崖，盘中随成交额变化连续波动）。

### 维度二：趋势与爆发力（满分 26分）—— **连续动量 + 均线偏离**
保留原V3.1的涨跌幅/量比矩阵（因其代表瞬时人类情绪爆发，非存量分布），但将“20日均线位置”改造为 **连续偏离调节因子**，彻底替代布尔判定。

#### ③ 中期趋势背景——RS相对强度（满分 14分）
- **保留原V3.1的20日超额收益排名阶梯**（此指标为日频滞后指标，不适用于实时变动，仅用于盘后校准）。
- **盘中实时替代方案（用于实时分支）**：使用 `现价 / 20日均线` 的 **连续偏离度**（港股用人民币净值K线）：
  - `趋势锚定分 = 14 × ( 现价 / MA20 )`，但限制上下限（0.8 ~ 1.2），即**理论上满分14分，平价为10分**。
  - 若价格高于MA20达5%（即比值1.05），得 `14 × 1.05 = 14.7 → 封顶14分`。
  - 若价格低于MA20达5%（比值0.95），得 `14 × 0.95 = 13.3`，若低于10%（比值0.9），得 `12.6`。

#### ④ 量价爆发力（满分 12分）—— **保留矩阵，但嵌入均线连续调节**
- **基础分规则**（沿用V3.1矩阵，因其捕捉瞬时量价配合）：

| 今日涨跌幅 | 量比区间 | 基础得分 | 20日均线连续调节（乘数） |
| :--- | :--- | :--- | :--- |
| 涨幅 ≥ 5% | ≥ 1.5 | 12 | 若收盘价 > MA20，乘数 1.0；若 < MA20，乘数 0.7 |
| 涨幅 ≥ 5% | 0.8 – 1.5 | 10 | 若收盘价 > MA20，乘数 0.9；若 < MA20，乘数 0.5 |
| 涨幅 ≥ 5% | < 0.8 | 4 | 无论均线位置，直接乘数 0.4（流动性枯竭预警） |
| 涨幅 2% – 4.99% | ≥ 1.5 | 8 | 连续调节同上（>MA20为1.0，<MA20为0.8） |
| 涨幅 0.5% – 1.99% | ≥ 1.2 | 6 | 连续调节同上 |
| 涨幅 0 – 0.49% | 任意 | 0 | 0 |
| 下跌 -3% ~ 0% | < 0.8（缩量跌） | 4 | 若价格 > MA20，乘数 1.2（健康回踩加分）；若 < MA20，乘数 0.8 |
| 下跌 -3% ~ 0% | 0.8 – 1.5（平量跌） | 0 | 0 |
| 下跌 -3% ~ 0% | > 1.5（放量跌） | 基础 -2 | 若价格 > MA20，乘数 0.5；若 < MA20，直接归零（即扣至0） |
| 大跌 < -3% | 任意 | 基础 -5 | 若价格 > MA20，乘数 0.6；若 < MA20，扣至-8封顶 |

**维度二实时得分 = ③盘中替代分（趋势锚定） + ④连续调节后的爆发分**。

### 维度三：人气与持续性（满分 9分）—— **幂律排名 + 连续霸榜**
#### ⑤ 全市场热度排名幂律分（满分 5分）
- **公式**：`热度幂律分 = 5 × ( 1 / 全市场热度排名 ) ^ 0.25`
  - （若该ETF未进入热榜前100，默认排名赋值为101，得分约为 `5 × (1/101)^0.25 ≈ 1.6`，体现长尾基数热度）
- **映射效果**：第1名得5分；第3名得 `5×0.333^0.25 ≈ 3.8`；第10名得 `5×0.1^0.25 ≈ 2.8`；第20名得 `5×0.05^0.25 ≈ 2.1`。

#### ⑥ 连续霸榜TOP20天数奖励（满分 4分）—— **线性不连续，但逻辑清晰**
- 连续出现在“全市场成交额TOP20”的天数（A股+港股通合并排名）：
  - ≥ 5个交易日 → **+4**
  - 3 – 4个交易日 → **+2**
  - 1 – 2个交易日 → **0**

**维度三得分 = ⑤得分 + ⑥得分**。

### 维度四：风险排雷（满分 15分）—— **保留原V3.1逻辑，增加连续扣分机制**
完全保留V3.1的PE分位数、规模骤降规则，仅新增 **“PE分位数偏离连续扣分”**：

- **PE > 90%**：若③不在前50（高动量豁免），扣 **3分**；若③在前50，不扣。
- **PE < 10%**：**+2分**（价值动量双因子）。
- **近1月规模下降 > 20%**：一票否决，总分归零。
- **近1月规模下降 15% – 20%**：若份额连续净增长天数为0 → 维度四 **直接记0分**；若份额有增长 → 不扣分，但取消所有份额类加分。
- **基础安全分**：未触发上述任何条件时，维度四默认获得 **15分 - 隐含波动率惩罚（隐含波动率 = 近5日ATR/收盘价，每高出行业均值1%，扣0.5分，上限扣5分）**。

**维度四得分 = 15 - 各项扣分 + 加分（上限17分，下限0分，遇规模骤降直接归零）**。

## 三、微操奖惩因子（连续化改造 + 保留原精华）
（直接在总分上叠加，封顶 ±20分；熔断系数在最终总分上单独施加）

| 情境 | 调整分 | 判定条件 / 连续化改进 |
| :--- | :--- | :--- |
| **创历史新高** | **+3** | 今日最高价 ≥ 上市以来最高价（港股用人民币净值最高价） |
| **份额连续净增长** | **+3** | 连续3个交易日份额增加（若触发维度四规模惩罚，本项自动失效） |
| **折价率 > 1%** | **+1** | 流动性尚可品种的安全边际信号 |
| **溢价率 > 3%** | **-5** | A股阈值；港股因汇率波动大，若溢价>5%则-5，3%-5%之间-2（连续线性过渡） |
| **近5日日均成交额环比增长 > 50%** | **+2** | `(近5日均值 / 前5日均值) > 1.5` |
| **行业主线加成** | **+3** | 该二级行业品类成交额占全市场总成交额比例，较前5日均值提升 > 30% 且 品类总成交额≥20亿（港股支品类≥10亿） |
| **系统性风险熔断（乘数）** | **×0.8** | A股看中证全指跌幅>1.5%且上涨家数<30%；港股看恒生指数跌幅>1.5%且上涨家数<30%（各自基准独立判定） |

**奖惩总分 = 上述各项代数和，上限 +20，下限 -20**。

## 四、最终总分计算公式（幂律连续版）
### 盘中实时简化版（用于快速筛选，每5分钟刷新）
`实时总分 = [ 维度一(流动性幂律+虹吸幂律) + 维度二实时(均线锚定+量价爆发) + 维度三(热度幂律+霸榜) ] × 熔断系数`  
> 此版本满分约 **75分**，不含滞后指标（20日超额收益、PE分位数、规模变动），适合盘中快速排序。

### 盘后深度校准版（用于次日仓位分配，每日收盘后计算）
`深度总分 = [ 维度一(40) + 维度二(26) + 维度三(9) + 维度四(15) + 奖惩总分(±20) ] × 熔断系数`  
> 此版本满分 **115分（理论极值）**，完全保留V3.1的风险排雷与趋势背景，用于确定次日操作等级。
