# 幂律分布实时筛选与评分系统：V3.1 微操量化实操版（终极拆解）

> 本版将V3.0所有定性描述（如“前10%”、“高位滞涨”）拆解为**全市场绝对数值阈值**与**边界处理逻辑**，补全淘汰机制与微操奖惩，支持Excel公式一键拉分，实现“30秒速排20只龙头”。

---

## 🚨 一、前置硬性门槛（一票否决，先过此关）

**但凡触发以下任意一条，直接移出自选，总分归零，不参与后续评分：**

1. 非ST、非停牌（问财已过滤）。
2. 最新一期归母净利润 ≤ 0（亏损）。
3. 近半年存在“减持进行中”或“减持计划届满”公告。
4. **（新增量化）** 今日成交量 < 20亿 **或** 换手率 < 5%（若刚好等于5.00%，算通过）。

## 📊 二、V3.1 四维度评分细则（傻瓜式查表算分）

### 第一维度：资金极端集中度（满分 40分 → 拆解为 25+15）

#### ① 全市场成交额排名分（25分）
> **数据口径**：全A股（含北交所）今日成交额降序排列。

| 绝对排名区间 | 基础分 | 额外精英奖励（≤3只时触发） |
| :--- | :---: | :--- |
| **第 1 名**（市场总龙头） | 25 | **额外 +3**（体现“吸血之王”） |
| **第 2 - 3 名** | 25 | 无 |
| **第 4 - 5 名** | 15 | 无 |
| **第 6 - 10 名** | 8 | 无 |
| **第 11 - 20 名** | 3 | 无 |
| **第 21 名及以后** | **0（直接出局）** | — |

#### ② 概念/行业虹吸效应分（15分）
> **数据口径**：在同花顺问财输入“XX概念今日成交额”，查看该概念在全市场所有概念中的排名。

| 条件（满足其一即可，取高分值） | 得分 |
| :--- | :---: |
| **所属概念板块成交额排名 全市场第 1** | **15**（绝对主线） |
| 所属概念板块成交额排名 第 2 - 3 | 12（强力虹吸） |
| 所属概念板块成交额排名 第 4 - 5 **或** 该概念占全市场总成交额 ≥ 8% | 8 |
| 所属概念板块排名 第 6 - 10 **或** 占比 5% - 8% | 5 |
| 所属概念板块排名 第 11 及以后 **且** 占比 < 5% | **3**（跟风杂毛，给安慰分） |

### 第二维度：趋势与爆发力（满分 30分 → 拆解为 15+15，含倒扣）

#### ③ 中期趋势背景（15分）
> **数据口径**：`近20日涨幅` 在全A股（约5000只）中的绝对排名。

| 全市场绝对排名区间 | 基础分 | **高位滞涨陷阱判定**（若触发，直接降至3分） |
| :--- | :---: | :--- |
| **排名前 200 名**（即前4%） | **15** | 触发条件：今日涨幅 < 1.5% **且** 量比 > 2.0 → 改判 **3分** |
| **排名 201 - 800 名**（前4%-16%） | **10** | 触发条件：今日涨幅 < 1.0% **且** 量比 > 1.8 → 改判 **3分** |
| **排名 801 - 1500 名**（前16%-30%） | **6** | 同上（滞涨即降至3分） |
| **排名 1500 名以外** | **3** | 趋势走弱，无滞涨判定（本来就弱） |

#### ④ 量价爆发力（15分）
> **核心原则**：跌可以，但缩量跌是健康；放量跌是原罪。

| 今日涨跌幅 | 量比区间 | 得分 | 逻辑解释 |
| :--- | :--- | :---: | :--- |
| **涨停（≥9.9%）** | ≥ 1.5 | **15** | 极致一致，封板坚决 |
| **涨停（≥9.9%）** | ＜ 1.5 | **12** | 缩量一字/秒板，惜售，次高分 |
| **涨幅 5% - 9.9%** | ≥ 1.5 | **10** | 大阳放量，强势攻击 |
| **涨幅 2% - 4.99%** | ≥ 1.2 | **7** | 温和放量上涨 |
| **涨幅 0 - 1.99%** | 任意 | **3** | 横盘/微涨，无爆发力 |
| **下跌（-5% - 0%）** | **＜ 0.8**（缩量跌） | **5** | 健康回踩，给正分 |
| **下跌（-5% - 0%）** | **0.8 - 1.5**（平量跌） | **0** | 无抵抗，不给分 |
| **下跌（-5% - 0%）** | **＞ 1.5**（放量跌） | **-10（倒扣）** | 资金出逃，次日大概率低开，**必须紧急回避** |
| **大跌（＜ -5%）** | **任意** | **-10（倒扣）** | 破位大阴线，无需看量，直接扣 |

| 连续霸榜天数（交易日） | 得分 |
| :--- | :---: |

## ✳️ 三、V3.1 新增“微操奖惩因子”（± 3分调节项，用于打破同分僵局）

在四维度总分出来后，根据盘口细节进行微调，让头部更清晰：

| 情境 | 调整分 | 判定标准 |
| :--- | :---: | :--- |
| **创历史新高** | **+3** | 今日最高价 = 上市以来最高价（无套牢盘，空间打开） |
| **炸板未回封** | **-5** | 今日盘中曾涨停，但收盘价 < 涨停价（严重弱化信号） |
| **尾盘偷袭（14:45后拉板）** | **-2** | 封板时间在收盘前15分钟内（心虚表现） |
| **早盘10:00前封死涨停** | **+2** | 强势表态，日内定军心 |
| **龙虎榜机构净买入 > 1亿** | **+3** | 机构认可锁仓，加分项（问财可查） |

## 📐 四、终极算分公式（Excel/VBA 逻辑伪代码）

你可以直接在Excel中设定列（A=成交额排名，B=概念排名，C=20日涨幅排名，D=今日涨幅，E=量比，F=热度排名，G=连续霸榜天数），套用以下逻辑：

```excel
=IF(OR(成交额<20亿, 换手<5%, 净利润<=0, 有减持), 0, 
   (IF(A<=3,25,IF(A<=5,15,IF(A<=10,8,IF(A<=20,3,0)))) + 
    IF(概念排名<=1,15,IF(概念排名<=3,12,IF(概念排名<=5,8,IF(概念排名<=10,5,3)))) + 
    IF(C<=200,15,IF(C<=800,10,IF(C<=1500,6,3))) - [滞涨扣分判断] + 
    IF(AND(D>=0.099,E>=1.5),15,IF(AND(D>=0.099,E<1.5),12,IF(AND(D>=0.05,E>=1.5),10,IF(AND(D>=0.02,E>=1.2),7,IF(AND(D<0,D>=-0.05,E<0.8),5,IF(AND(D<0,D>=-0.05,E>1.5),-10,IF(D<-0.05,-10,3))))))) + 
    IF(F<=3,10,IF(F<=10,5,IF(F<=20,2,0))) + 
    IF(G>=5,5,IF(G>=3,3,0)) + 15 + 
    微操奖惩分
   )
```
