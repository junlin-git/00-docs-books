# A股申万一级行业M10多学科思维模型评分标准（v1.1）

**版本**：v1.1 — 行业筛选校准版（基于2025年年报及2026年上半年最新进展）  
**定位**：作为行业层面的认知质量过滤器，独立于个股M10，用于辅助行业配置优先级判定与仓位上限的行业约束  
**使用方法**：将任意申万一级行业代入本评分标准，按十大维度逐一评分（0–10分，精度0.5分），累加得M10总分（满分100分）。评分依据应基于公开的行业数据、政策动态及产业逻辑。

---

## 一、M10行业模块概述

M10将全部128个多学科思维模型映射至十大投资决策维度，每个维度从行业层面评估认知质量。行业M10得分独立于个股M1–M9体系，仅作为行业配置的思维审计工具，用于：

- 识别行业层面的认知偏差（如叙事泡沫、幸存者偏差）
- 辅助行业仓位上限的设定（高认知质量行业可配更高权重）
- 作为行业轮动决策的过滤器（规避低认知质量行业）

**评分总则**：
- 每个维度基础分6分为“行业逻辑自洽，无明显瑕疵”
- 9分以上需“行业具备显著的阿尔法特征或进化优势”
- 4分以下表示“行业存在系统性认知陷阱或价值毁灭风险”

## 二、十大维度 — 完整思维模型映射与评分逻辑（行业版）

以下每个维度均列出全部映射模型，并给出在**行业分析**中的具体应用场景和评分要点。

---

### 维度一：逻辑与元认知（00-逻辑与元认知）

| 映射模型 | 在行业分析中的具体应用 |
|---------|------------------------|
| 01-第一性原理 | 该行业解决的根本社会/经济需求是什么？是否具备不可替代性？（如医药=治病，食品=消费） |
| 02-奥卡姆剃刀 | 行业的商业模式是否简洁？能否用一句话说清行业盈利本质？ |
| 03-汉隆剃刀 | 对行业政策变动，优先归因于宏观情境而非恶意打压 |
| 04-证伪主义 | 行业的繁荣叙事是否具备可证伪性？若核心假设被打破（如补贴取消），行业逻辑是否崩塌？ |
| 05-二阶思考 | 市场共识之外，行业的二阶效应是什么？（如新能源过剩→储能需求爆发） |

**评分要点（0–10）**：
- 行业是否直击刚性需求或长期趋势？
- 商业模式是否简单易懂？
- 行业叙事是否存在重大逻辑漏洞？
- **0分**：行业靠补贴或政策套利生存，无内生价值；**10分**：行业与人类长期需求深度绑定，逻辑自洽且不可替代。

### 维度二：数学与概率（01-数学与概率）

| 映射模型 | 在行业分析中的具体应用 |
|---------|------------------------|
| 01-复利 | 行业是否具备长期复利增长特征（消费、医药）还是强周期波动（有色、航运）？ |
| 02-指数增长 | 行业是否处于渗透率快速提升的指数增长早期（如AI、新能源车）？ |
| 03-幂律分布 | 行业是否呈现赢家通吃（龙头占大部分利润）还是百花齐放（如餐饮）？ |
| 04-概率论 | 行业景气度向上的先验概率如何？ |
| 05-贝叶斯更新 | 市场是否随宏观数据、政策信号动态修正行业预期？ |
| 06-期望值 | 行业整体投资期望值是否为显著为正？ |
| 07-回归均值 | 行业超高增速终将回归均值，当前处于均值回归的哪个阶段？ |
| 08-大数定律 | 行业样本量是否足够支撑统计结论？ |
| 09-随机游走 | 行业股价是否受短期噪音过度驱动？ |
| 10-蒙特卡洛思维 | 是否对行业进行多情景压力测试？ |
| 11-非线性 | 行业是否存在政策或技术拐点带来的非线性变化？ |
| 12-帕累托分布 | 行业利润是否集中于头部企业？ |
| 13-边际分析 | 行业扩产的边际收益是否递减？ |
| 14-遍历性 | 行业是否受到地缘政治等打破长期稳定性的因素干扰？ |
| 15-辛普森悖论 | 行业细分领域数据是否与整体结论相反？ |

**评分要点**：
- 行业整体期望值是否明确为正？
- 市场是否以贝叶斯方式合理更新预期？
- 是否存在非遍历性黑天鹅（如政策彻底颠覆行业）？
- **0分**：负期望值且不可持续；**10分**：高确定性正期望值，且市场持续上修。

### 维度三：物理与工程（02-物理与工程）

| 映射模型 | 在行业分析中的具体应用 |
|---------|------------------------|
| 01-惯性 | 行业是否存在技术或资本路径依赖？ |
| 02-杠杆效应 | 行业是否具有高经营杠杆（固定成本占比高，如半导体、面板）？ |
| 03-临界点 | 行业是否处于盈亏平衡或渗透率拐点的临界点？ |
| 04-热力学与熵增 | 行业是否因无序竞争导致内耗加剧（如光伏产能过剩）？ |
| 05-阻力与摩擦 | 行业供应链、物流、监管摩擦成本是否可控？ |
| 06-冗余与安全边际 | 行业是否有足够多的参与者或技术路线对冲风险？ |
| 07-反馈控制 | 行业是否有自调节机制（如价格信号引导供给）？ |
| 08-系统稳定性 | 行业供应链和产能体系是否具备抗冲击能力？ |
| 09-瓶颈理论 | 行业当前最大瓶颈是什么（资源、技术、人才、政策）？ |
| 10-最小作用路径 | 行业是否选择了阻力最小的商业化路径？ |
| 11-墨菲定律与防错设计 | 行业是否对最坏情况（如贸易禁运）有预案？ |

**评分要点**：
- 行业组织是否有序，熵增可控？
- 是否存在明显的产能或技术瓶颈？
- 供应链是否具备鲁棒性？
- **0分**：行业处于无序内耗状态；**10分**：行业具备高效的工程化体系和抗风险冗余。

### 维度四：复杂系统与系统论（03-复杂系统与系统论）

| 映射模型 | 在行业分析中的具体应用 |
|---------|------------------------|
| 01-涌现 | 行业内部各环节是否产生协同效应（如半导体设计+制造+封测协同）？ |
| 02-自组织 | 行业是否具备自我调节和优化能力？ |
| 03-路径依赖 | 行业是否因历史选择被锁定在某种技术或模式上？ |
| 04-相变 | 行业是否处于系统性变革的临界点（如燃油车→电动车）？ |
| 05-混沌与蝴蝶效应 | 一个政策或技术突破是否可能引发行业巨变？ |
| 06-网络效应 | 行业是否具备用户或客户端的网络效应（如互联网平台）？ |
| 07-耗散结构 | 行业是否通过开放合作引入外部资源对抗熵增？ |
| 08-分形与自相似 | 行业不同子领域的竞争格局是否呈现相似规律？ |
| 09-自组织临界性 | 行业是否处于微小扰动可能触发大规模崩溃的临界状态（如银行系统）？ |
| 10-标度律 | 行业规模与效率之间是否存在正标度关系？ |
| 11-吸引子 | 行业的长期发展方向是否收敛于某个清晰目标？ |
| 12-小世界网络 | 行业内企业、上下游、政策制定者是否形成紧密的信息网络？ |
| 13-系统思维 | 行业是否从整体链条角度优化，而非局部最优？ |

**评分要点**：
- 行业是否具备涌现式协同效应？
- 是否建立了开放系统（国际合作、技术引进）？
- 是否存在有害路径依赖导致转型困难？
- **0分**：行业封闭僵化，孤立运行；**10分**：高度协同、开放、自适应进化的生态系统。

### 维度五：进化与生物学（04-进化与生物学）

| 映射模型 | 在行业分析中的具体应用 |
|---------|------------------------|
| 01-自然选择 | 行业竞争中被选择的核心优势是什么（成本、技术、品牌）？ |
| 02-红皇后效应 | 行业是否处于“跑得慢即淘汰”的持续竞赛中？ |
| 03-生态位 | 行业在整个经济系统中占据何种独特生态位？ |
| 04-协同进化 | 行业与上下游、政策、技术是否形成协同进化？ |
| 05-进化稳定策略 | 行业的竞争策略是否具备长期稳定性？ |
| 06-遗传漂变 | 行业是否因偶然事件（如政策突变）发生非适应性漂变？ |
| 07-共生与寄生 | 行业是否过度依赖某一外部因素（如补贴、进口技术）？ |
| 08-突变与选择 | 行业内是否有足够多的创新“突变”供市场选择？ |
| 09-间断均衡 | 行业是否处于长期稳定被革命性技术打破的间断均衡中？ |
| 10-群体选择与个体选择 | 行业集体利益与企业个体利益是否一致？ |
| 11-进化心理学 | 行业决策者是否存在过度自信或短视偏差？ |

**评分要点**：
- 行业是否处于进化优势地位？
- 是否具备持续创新能力（突变）？
- 生态位是否稳固，能否抵御外部冲击？
- **0分**：行业生态位被侵蚀，进化停滞；**10分**：主动引领行业间断均衡。

### 维度六：经济学（05-经济学）

| 映射模型 | 在行业分析中的具体应用 |
|---------|------------------------|
| 01-供需关系 | 行业供需格局是紧平衡、过剩还是短缺？ |
| 02-机会成本 | 资本配置在该行业的机会成本如何（与其他行业相比）？ |
| 03-比较优势 | 该行业在国内/全球的比较优势是什么？ |
| 04-边际效用 | 行业扩产或新增产品线的边际收益是否递减？ |
| 05-激励机制 | 行业政策、补贴机制是否合理？是否扭曲市场？ |
| 06-外部性 | 行业活动是否产生正向或负向外部性（如环保）？ |
| 07-交易成本 | 行业内部及跨行业的交易成本是否可控？ |
| 08-信息不对称 | 行业是否存在严重的信息不对称（如军工、医药）？ |
| 09-公地悲剧 | 热门赛道是否因过度投资导致资源浪费？ |
| 10-创造性破坏 | 行业是否正在颠覆旧模式，还是被颠覆？ |
| 11-套利 | 跨市场或跨周期的估值套利空间是否存在？ |
| 12-市场均衡 | 当前估值是否偏离长期均衡？ |
| 13-沉没成本 | 行业参与者是否理性退出落后产能？ |
| 14-规模经济与范围经济 | 行业是否具备规模或范围经济效应？ |
| 15-网络经济 | 行业是否具备网络经济特征（如平台型）？ |
| 16-租值耗散 | 竞争是否导致行业利润被侵蚀殆尽？ |

**评分要点**：
- 行业供需格局是否健康？
- 是否存在创造性破坏带来的投资机会？
- 是否具备规模经济或网络效应护城河？
- **0分**：行业陷入恶性竞争，租值耗散严重；**10分**：行业具备显著结构性套利空间。

### 维度七：博弈论（06-博弈论）

| 映射模型 | 在行业分析中的具体应用 |
|---------|------------------------|
| 01-囚徒困境 | 行业内企业是否陷入价格战或过度扩产的囚徒困境？ |
| 02-纳什均衡 | 行业内竞争格局是否处于某种稳定均衡？ |
| 03-重复博弈 | 行业内企业间是否长期博弈，形成信誉与合作？ |
| 04-零和博弈 | 行业增长是否主要来自存量争夺（零和）还是增量扩张（正和）？ |
| 05-协调博弈 | 行业标准、政策制定是否形成协调均衡？ |
| 06-信号博弈 | 企业行为（如扩产公告）是否传递有效信号？ |
| 07-承诺策略 | 行业内头部企业是否做出可信的长期承诺（如产能规划）？ |
| 08-可信威慑 | 行业是否存在防止新进入者的壁垒（专利、资质）？ |

**评分要点**：
- 行业是否陷入囚徒困境（如光伏、养猪）？
- 头部企业是否拥有可信威慑和主动博弈地位？
- 行业竞争是正和还是零和？
- **0分**：行业深陷囚徒困境，利润不断被侵蚀；**10分**：行业博弈格局稳固，龙头企业拥有定价权。

### 维度八：心理学与认知科学（07-心理学与认知科学）

| 映射模型 | 在行业分析中的具体应用 |
|---------|------------------------|
| 01-确认偏误 | 市场是否只关注行业利好而忽视利空？ |
| 02-损失厌恶 | 市场是否对行业负面事件过度反应？ |
| 03-锚定效应 | 市场是否锚定行业历史估值而忽视基本面变化？ |
| 04-从众效应 | 机构是否因抱团而忽视行业特有风险？ |
| 05-可得性偏差 | 是否因近期某细分领域成功而高估整个行业胜率？ |
| 06-过度自信 | 行业内管理层是否对前景过度自信？ |
| 07-框架效应 | 行业数据被呈现为“增长”还是“风险”框架？ |
| 08-激励驱动偏差 | 政策制定是否受短期政绩激励扭曲？ |
| 09-叙事偏误 | 市场是否构建了过于简化的行业故事（如“黄金十年”）？ |
| 10-现状偏差 | 行业是否安于现状错失转型？ |
| 11-基本归因错误 | 行业增长被过度归因于管理能力而非行业Beta？ |
| 12-幸存者偏差 | 是否只看到行业成功者而忽视大量失败者？ |
| 13-邓巴数 | 行业参与者过多导致认知带宽摊薄？ |

**评分要点**：
- 市场对行业的定价是否理性？是否存在普遍认知偏误？
- 行业叙事是否过度简化或夸大？
- **0分**：市场严重认知偏误，行业估值泡沫明显；**10分**：市场理性定价，信息充分对称。

### 维度九：决策理论（08-决策理论）

| 映射模型 | 在行业分析中的具体应用 |
|---------|------------------------|
| 01-期望效用理论 | 行业投资的期望效用是否匹配风险偏好？ |
| 02-风险收益权衡 | 行业当前的风险收益比是否具备吸引力？ |
| 03-决策树 | 行业关键变量（政策、技术、周期）是否经过系统性多路径分析？ |
| 04-反事实思考 | 是否思考“如果产业政策转向”等反事实情境？ |
| 05-不确定性管理 | 行业对监管、技术、竞争等不确定性是否有效管理？ |
| 06-黑天鹅 | 行业是否存在未被定价的极端尾部风险？ |
| 07-反脆弱性 | 行业能否从波动和危机中获益（如危机后格局优化）？ |

**评分要点**：
- 行业是否具备反脆弱性（能因波动受益）？
- 尾部黑天鹅风险是否可识别且可控？
- 行业决策是否基于多情景分析而非线性外推？
- **0分**：行业极度脆弱，黑天鹅事件可致崩溃；**10分**：行业具备反脆弱结构，尾部风险有对冲。

### 维度十：信息与计算（09）+ 社会与组织（10）

| 映射模型 | 在行业分析中的具体应用 |
|---------|------------------------|
| 09-01-信息论 | 行业信息披露是否高效？噪声比例如何？ |
| 09-02-信噪比 | 行业数据中信号与噪声的比值是否足够高？ |
| 09-03-压缩 | 能否用极简框架理解行业的投资核心逻辑？ |
| 09-04-复杂度 | 行业产业链、政策、技术复杂到什么程度？ |
| 09-05-算法效率 | 行业内企业的运营是否具备算法化高效率？ |
| 09-06-纠错码与容错 | 行业是否有快速纠错机制（如产能出清）？ |
| 09-07-分布式系统 | 行业供应链是否具备分布式鲁棒性？ |
| 10-01-权力结构 | 行业监管权力是否集中或分散？决策效率如何？ |
| 10-02-组织激励 | 行业政策是否激励企业做出最优决策？ |
| 10-03-官僚结构 | 行业管理是否存在官僚层级侵蚀效率？ |
| 10-04-群体动力学 | 行业内是否存在群体迷思或非理性繁荣？ |
| 10-05-文化演化 | 行业文化是否向更开放、更创新方向演化？ |

**评分要点**：
- 行业是否简单易懂（复杂度低）？
- 行业数据信噪比是否足够高？
- 行业组织结构和政策激励是否支持高效发展？
- **0分**：信息混沌、组织僵化；**10分**：高透明度、低复杂度、激励相容。

## 三、行业M10评级门槛与仓位影响

| M10得分区间 | 定性含义 | 对行业仓位的影响 |
|------------|---------|----------------|
| ≥85分 | 顶级认知质量，行业逻辑完美 | 可超配（+5%以上），核心配置 |
| 75–84分 | 优秀认知质量，逻辑自洽 | 正常配置（基准权重） |
| 60–74分 | 一般认知质量，存在明显逻辑瑕疵 | 低配（基准权重减半） |
| <60分 | 认知质量堪忧，行业陷阱较多 | 规避，仅保留极小观察仓位 |

## 四、示例应用：申万一级行业“电子”完整M10评分

以下以A股**电子行业（申万一级）** 为例，应用上述标准进行全维度评分。

**行业背景**（2025年数据）：
- 2025年涨幅47.88%，融资净买入1646亿元居各行业之首

- 半导体国产替代+AI算力需求为双主线
- 2025年中国12吋晶圆自产率已达50%，大陆厂商全球产能占比从2020年3%跃升至2025年28%

## 五、M10行业评分标准作业程序（SOP）——强制执行版（v1.1补充）

**制定目的**：杜绝AI执行者在分析过程中的“偷懒、遗漏、概括性敷衍”行为，确保每一次行业扫描均为**全量、透明、可追溯**的认知审计。

### 5.1 执行铁律（三大刚性原则）

1. **全量覆盖原则**：执行者**必须一次性**对A股**全部31个申万一级行业**进行独立评分。严禁以“篇幅有限”、“代表性不足”、“行业冷门”等理由省略任何一个行业。遗漏即视为本次分析任务失败。

2. **透明溯源原则**：每个行业的最终得分必须附带**十大维度的简略得分数组**（格式如：[X, X, X, ...]），且评分依据必须明确锚定“**2025年年报及2026年上半年公开数据、政策文件及产业动态**”，严禁使用模糊的“感觉”或“长期印象”代替实证。

3. **强制筛选与优先级排序原则**：完成全量评分后，必须依据总分进行**降序排列**，并严格按照评级门槛（≥85、75–84、60–74、<60）**自动机械切割**，输出明确的“可配置池”与“规避池”。

### 5.2 输出格式规范（唯一指定结构）

当执行者依据本标准进行行业扫描时，最终输出报告必须严格遵循以下三段式结构，不得擅自变更顺序或合并输出：

| 输出模块 | 强制内容要求 |
| :--- | :--- |
| **模块一：全行业总览排行榜** | 以表格形式一次性列出全部31个申万一级行业的**M10总分及十大维度得分数组**（例如：电子 \| 79.5 \| [8.5,8.0,8.0,8.5,8.5,8.0,7.5,7.5,7.5,8.0]）。此表格用于横向对比，杜绝暗箱操作。 |
| **模块二：高分筛选池（配置级）** | **自动提取**总分 **≥75分** 的所有行业。在此模块中，**必须**为每一个高分行业提供**不少于200字的详细评分依据**（参照原文档“电子行业”示例的详细程度），详细拆解其在该维度评分背后的核心产业逻辑。 |
| **模块三：低分警示池（规避/观察级）** | **自动提取**总分 **<60分** 的所有行业。简要列出导致其低分的关键“认知陷阱”或“价值毁灭逻辑”（如囚徒困境、租值耗散、政策证伪等）。若不存在低分行业，则须注明“当前无行业落入极端陷阱区间”。 |

### 5.3 评分过程中的防偏纠偏机制（AI行为准则）

- **禁止“近因效应”绑架**：不得因某行业近期（2026年Q2）大涨或大跌而擅自调整权重。评分必须基于**行业生态结构**，而非短期股价波动。
- **强制贝叶斯更新**：若行业当前市场共识（卖方研报主流叙事）与行业基本面数据（如库存周期、渗透率）出现背离，必须在**数学与概率（维度二）** 和**心理学（维度八）** 中**明确扣分**，指出市场的非理性定价。
- **尾部风险硬约束**：对于任何涉及**地缘政治断供（如半导体设备）、政策强监管（如教培/医药集采）、技术颠覆性替代（如燃油车）** 的行业，若未在**维度九（决策理论）** 中给出明确的黑天鹅应对预案或反脆弱性分析，则该维度得分不得高于 **5.0分**。

### 5.4 启动执行指令

当用户发出指令：“**请严格按照A股申万一级行业M10评分标准SOP，执行全行业扫描并筛选出高分行业**”时，AI执行者**必须无条件启动**上述5.1至5.2条款规定的全流程，不得以“上下文长度不足”为由压缩评分数量。若因模型上下文限制无法一次性输出全部详细依据，应优先完整输出**模块一（全量数据表格）** 和**模块二（高分解读）**，并在回答末尾明确声明未展开的低分行业名单，而非直接忽略。

## 六、总结

本评分标准提供了对任意申万一级行业进行多学科思维审计的完整框架。使用者可按十大维度逐一打分，并依据总分确定行业配置优先级。关键在于**实事求是**地依据公开数据和逻辑推导，避免主观臆断。

十个维度等权重（各10分），总分100分。每个维度内所有模型综合考量后给出一个整体评分，精度0.5分。
