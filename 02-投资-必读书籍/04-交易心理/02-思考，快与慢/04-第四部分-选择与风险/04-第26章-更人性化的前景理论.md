# 第26章 更人性化的前景理论

## 1. 核心图解：前景理论的价值函数
### 1.1 S型曲线
- 前景理论用一条“S型曲线”来直观描绘人类对收益和损失的心理价值评估。
- **横轴**：客观的收益（右侧为正）和损失（左侧为负）。
- **纵轴**：主观的心理价值（满足感或痛苦感）。
### 1.2 参考点的决定性作用
- 曲线的原点（拐点）就是“参考点”（通常是现状或期望值）。
- 所有的评估都是相对参考点而言的，而非基于最终总财富。
### 1.3 两种不对称的敏感度
- **收益区域（右上角，凹形）**：代表面对收益时，边际效用递减。人们在此区域通常是风险规避的（想落袋为安）。
- **损失区域（左下角，凸形）**：代表面对损失时，边际痛苦也递减。人们在此区域通常是风险寻求的（想赌一把翻本）。
- **损失曲线更陡峭**：在相同的金额下，左侧（损失）曲线的倾斜度远大于右侧（收益）曲线，直观体现了“损失厌恶”。

## 2. 确定性效应
### 2.1 现象描述
- 人们对“确定性”赋予了过高的心理权重。
- 从99%到100%的心理跨度，远远大于从1%到2%，或者从10%到11%的跨度。
### 2.2 收益领域的确定性效应
- **表现**：当面对确定能赢的钱和有微小风险赢更多钱时，人们为了获得“确定性”而放弃更高期望值的赌博。
- **例子**：
  - 选项A：100%概率得到900美元。
  - 选项B：90%概率得到1000美元。
  - **结果**：绝大多数人选A，即使B的期望值也是900美元，人们依然讨厌那10%什么都得不到的风险。
### 2.3 损失领域的确定性效应
- **表现**：当面对确定会输的钱和有微小风险输更多钱时，人们为了“避免确定的损失”而宁愿去赌一把。
- **例子**：
  - 选项A：100%概率损失900美元。
  - 选项B：90%概率损失1000美元，10%概率不损失。
  - **结果**：绝大多数人选B，为了逃避那10%的“完全免单”希望，他们宁愿承担多损失100美元的风险。

## 3. 概率的心理学：极小概率与极大概率
系统1无法准确处理概率，尤其是极端概率，这导致了系统性的决策偏差。

### 3.1 极小概率的过度加权
- **现象**：对于极小概率（如0.001%）的事件，系统1无法真正理解它有多小，往往会将其心理权重放大到远超其实际概率的程度。
- **结果**：人们对极小概率的收益或损失产生强烈的反应。
### 3.2 极大概率的加权不足
- **现象**：对于极大概率（如99%）的事件，系统1觉得它“不是100%”，因此在心理上将其权重打折，觉得它“不够可靠”。
- **结果**：这其实也是确定性效应的延伸，即99%和100%之间存在巨大的心理鸿沟。

## 4. 风险态度的四重模式
结合“收益/损失”与“高概率/极低概率”，前景理论总结出了人类风险决策的四重模式，这是本章的核心精髓：

### 4.1 高概率的收益 -> 风险规避
- **场景**：有90%的机会赢钱。
- **行为**：为了落袋为安，接受一个比期望值略低的确定性收益。
- **例子**：法庭上，有强有力证据的原告通常愿意接受较低的庭外和解金额，而不愿冒那10%败诉的风险。
### 4.2 低概率的收益 -> 风险寻求
- **场景**：有极小机会赢大钱。
- **行为**：为了那万一的梦想，放弃确定性的小利，去买彩票。
- **例子**：买彩票。彩票的期望收益通常是负的，但极小概率暴富的诱惑让人趋之若鹜。
### 4.3 高概率的损失 -> 风险寻求
- **场景**：有90%的机会亏钱。
- **行为**：为了避免确定的损失，宁愿孤注一掷去赌那10%的翻盘机会。
- **例子**：沉没成本效应。亏损的企业或投资者，为了不让账面亏损变成实际亏损，继续往无底洞里砸钱。
### 4.4 低概率的损失 -> 风险规避
- **场景**：有极小机会遭遇灾难性损失。
- **行为**：为了消除这种极小概率的恐惧，宁愿支付一笔确定性的小额费用。
- **例子**：买保险。人们愿意支付高于期望损失金额的保费，只为买个安心。

## 5. 现实应用与解释力
### 5.1 彩票与保险的悖论
- 传统经济学难以解释：为什么同一个人既买彩票（追求极小概率收益），又买保险（规避极小概率损失）？这两者在数学上是矛盾的。
- 前景理论的解释：极小概率被过度加权。买彩票是放大了“中奖的微光”，买保险是放大了“灾难的恐惧”。两者都符合四重模式。
### 5.2 法律诉讼与和解
- 原告如果胜诉概率很高（高概率收益），通常倾向于风险规避，愿意和解。
- 被告如果败诉概率很高（高概率损失），通常倾向于风险寻求，拒绝和解，坚持打官司。这解释了为什么很多理亏的被告依然死扛到底。

## 6. 本章核心启示
- **确定性是人类心理的引力场**：“100%”这个数字在心理上具有致命的吸引力（收益时）和排斥力（损失时），它让我们做出大量违背数学期望的非理性选择。
- **极端概率的幻觉**：我们总是被极小概率的奇迹（彩票）或灾难（空难）牵着鼻子走，而对日常的高概率事件缺乏敏感度。
- **四重模式是预测人类行为的利器**：只要知道一个人处于收益还是损失状态，以及事件发生的概率高低，就能准确预测他将扮演胆小鬼还是赌徒。前景理论比传统经济学更深刻地揭示了真实的人性。
