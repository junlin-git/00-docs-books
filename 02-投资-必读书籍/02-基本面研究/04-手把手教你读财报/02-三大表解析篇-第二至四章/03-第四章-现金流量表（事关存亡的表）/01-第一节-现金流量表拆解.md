## 第一节 现金流量表拆解

### 一、为什么说现金流量表“事关存亡”？

#### 1.1 一个你可能忽略的真相

假设你开了一家小餐馆，生意火爆——每天客人排队，月流水20万。但仔细一算：一半客人是熟人赊账，月底才结；供应商的货款你得每周现金结算；三个员工的工资每月5号必须发；房东每月1号准时收租。

月底你翻开账本：**利润表上赚了5万，但银行账户里的钱却不够发下个月工资。**

你猜，这家餐馆还能撑多久？

**利润是“算出来”的，现金是“活下来”的。** 这就是为什么现金流量表被称为“事关存亡的表”。

#### 1.2 利润表 vs 现金流量表：本质区别

| | 利润表 | 现金流量表 |
|---|---|---|
| **计量方式** | 权责发生制（按权利和义务确认） | 收付实现制（按实际现金进出确认） |
| **核心问题** | “赚了多少钱？” | “收了多少现金？花了多少现金？” |
| **可操纵性** | 较高（折旧、坏账计提、收入确认时点等均可调节） | 极低（每一笔都是银行账户的真实流水） |
| **反映的内容** | 一段时期的经营成果 | 一段时期的现金“来龙去脉” |

一家公司可以账面上利润丰厚，但银行账户空空如也。**一场债务危机，往往始于“利润为正、现金流为负”的错配；一次突然暴雷，常藏在“账上利润丰厚、银行账户空空”的假相之下**。

> 💡 **一句话记住：利润决定企业能走多远，现金流决定它今天能不能开门**。


### 二、现金流量表长什么样？

现金流量表把企业的现金进出分成**三大类活动**：
```
┌─────────────────────────────────────────────────────┐
│ 现金流量表 │
├─────────────────────────────────────────────────────┤
│ 一、经营活动产生的现金流量 │
│ ├── 销售商品、提供劳务收到的现金 + │
│ ├── 收到的税费返还 + │
│ ├── 购买商品、接受劳务支付的现金 - │
│ ├── 支付给职工以及为职工支付的现金 - │
│ ├── 支付的各项税费 - │
│ └── 经营活动产生的现金流量净额 = │
├─────────────────────────────────────────────────────┤
│ 二、投资活动产生的现金流量 │
│ ├── 收回投资收到的现金 + │
│ ├── 取得投资收益收到的现金 + │
│ ├── 购建固定资产等支付的现金 - │
│ ├── 投资支付的现金 - │
│ └── 投资活动产生的现金流量净额 = │
├─────────────────────────────────────────────────────┤
│ 三、筹资活动产生的现金流量 │
│ ├── 吸收投资收到的现金 + │
│ ├── 取得借款收到的现金 + │
│ ├── 偿还债务支付的现金 - │
│ ├── 分配股利、利润或偿付利息支付 - │
│ └── 筹资活动产生的现金流量净额 = │
├─────────────────────────────────────────────────────┤
│ 四、汇率变动对现金的影响 ± │
│ 五、现金及现金等价物净增加额 = │
│ 六、期末现金及现金等价物余额 │
└─────────────────────────────────────────────────────┘
 ```

**三大活动，对应企业的三种“身份”：**

| 活动类型 | 通俗理解 | 好比 |
|---|---|---|
| **经营活动** | 企业靠主业“造血” | 打工人的工资收入与日常开销 |
| **投资活动** | 企业拿钱“生钱” | 买房、买理财、投资副业 |
| **筹资活动** | 企业向外部“借钱或找钱” | 向银行借房贷、找朋友入股 |


### 三、逐项拆解：三大活动怎么看？

#### 3.1 经营活动现金流：企业的“造血能力”

这是**最重要**的一部分——它回答的是：**企业靠主营业务能不能自己养活自己？**

**关键科目解读：**

**（1）销售商品、提供劳务收到的现金**

这是企业经营活动最大的现金来源。**理想情况下，这个数字应该大于利润表上的营业收入。** 为什么？因为营业收入里可能包含赊销（没收到钱就确认了收入），而“销售商品收到的现金”是实打实进账的钱。

**（2）购买商品、接受劳务支付的现金**

这是最大的现金支出。跟“销售商品收到的现金”搭配看，就能知道企业的**收付款节奏**。

**（3）支付给职工以及为职工支付的现金**

工资、奖金、社保公积金——这是**刚性支出**。员工不会因为公司“账面盈利”就同意晚发工资。

**（4）支付的各项税费**

税是**必须交的现金**，一分不能少。

**（5）经营活动产生的现金流量净额**

这是**最终答案**——正数说明主业在赚钱，负数说明主业在烧钱。

**⚠️ 重点观察指标：**

- **经营现金流净额为正** → 主业能自己造血 ✅
- **经营现金流净额为负** → 主业入不敷出，需要“输血” ❌
- **经营现金流净额长期高于净利润** → 盈利质量高，赚的是真钱 👍
- **经营现金流净额长期低于净利润** → 利润可能是“纸面富贵”，要警惕 👀

#### 3.2 投资活动现金流：企业的“花钱能力”

这部分回答的是：**企业把钱花到哪里去了？是在扩张还是在收缩？**

**关键科目解读：**

**（1）购建固定资产、无形资产和其他长期资产支付的现金**

这是企业的**资本性支出**——建厂房、买设备、购专利。**这个数字大，通常意味着企业在扩张。** 但如果持续大额支出而经营现金流跟不上，就要警惕资金链风险。

**（2）投资支付的现金**

买股票、买理财、参股其他公司——这是“金融投资”类支出。

**（3）收回投资收到的现金 / 取得投资收益收到的现金**

卖出投资品或收到分红——这是投资活动的现金流入。

**投资活动现金流净额通常为负数**（因为企业在花钱投资）。如果长期为正，说明企业在**变卖资产**，可能是在收缩或遇到困难。

#### 3.3 筹资活动现金流：企业的“找钱能力”

这部分回答的是：**企业从外部拿了多少钱？又还了多少钱？**

**关键科目解读：**

**（1）吸收投资收到的现金**

发行股票募资——这是**股权融资**。

**（2）取得借款收到的现金**

从银行借钱——这是**债务融资**。

**（3）偿还债务支付的现金 / 分配股利、利润或偿付利息支付的现金**

还本金、分红、付利息——这是**资金的流出**。

**筹资活动现金流净额为正** → 企业在“找钱”（融资）；**为负** → 企业在“还钱”（还债或分红）。


### 四、生活案例：用“打工人”的视角理解三大活动

假设你是一个打工人，我们来做一个“个人现金流量表”：

| 活动类型 | 你的个人版 | 企业版对应 |
|---|---|---|
| **经营活动** | 工资收入 - 房租 - 吃饭 - 交通 - 日常开销 | 卖货收钱 - 进货 - 发工资 - 交税 |
| **投资活动** | 买基金/股票 - 卖基金/股票 - 收分红 | 建厂房 - 卖设备 - 收投资收益 |
| **筹资活动** | 向银行借房贷 - 还房贷 - 付利息 | 发股票 - 借银行钱 - 还债 - 分红 |

**你的“经营活动现金流净额”** = 工资 - 所有生活必需开销。如果是正数，你每月能存下钱；如果是负数，你每月在透支——这就是“月光族”的财务危机根源。

**一家企业如果经营现金流持续为负**，就等于一个“月月透支”的打工人。短期可以靠借债（筹资活动）或卖资产（投资活动）撑过去，但**长期来看，没有造血能力的企业终将倒下**。


### 五、2026年A股真实案例：读懂现金流量表的价值

#### 案例一：贵州茅台——现金“王者”

2026年一季度，贵州茅台营收539.09亿元，净利润272.43亿元——但这些数字可能还不够震撼。真正震撼的是：

> **经营活动产生的现金流量净额：269.10亿元，同比增长205.48%**

这意味着什么？茅台一季度**每赚100元利润，就收回了近99元现金**（净现比98.78%）。换句话说，茅台赚的每一分钱，都是实打实进了银行账户的真金白银。

这就是**“现金奶牛”** 的典型特征——不仅利润高，而且利润的质量极高。

#### 案例二：敷尔佳——经营现金流由负转正的关键信号

2026年一季度，敷尔佳营收同比增长82.12%，扣非利润同比增长100.13%。但比这两个数字更值得关注的，是另一行被很多人忽略的数据：

> **经营活动产生的现金流量净额：从去年同期的-6616.48万元，回升到1.25亿元，同比增长288.48%**

为什么这个数字更“硬”？因为**利润表上的数字有会计处理空间**——收入确认时点、坏账计提比例、存货跌价处理……都可以在合规范围内调节。但**现金流量表不一样**——每一笔都是银行账户上能查到的真实流水，造假成本极高，会计处理空间极小。

对于敷尔佳这类消费公司来说，经营现金流转正意味着：**渠道端发生了系统性改善**——经销商打款节奏加快、终端动销好转、应收账款管理优化。

#### 案例三：盘龙药业——“增现不增利”的另类信号

2026年一季度，盘龙药业营收同比下降11.06%，净利润同比下降30.36%。按常理，这应该是个坏消息。

但蹊跷的是：**经营活动现金流净额9300.58万元，同比增长258.20%**。

这就是典型的 **“增现不增利”** ——利润在跌，但收回的现金在大幅增长。拆开看原因：

- 销售端：收到的现金只下降了5.38%（比营收降幅小）
- 支出端：采购付款下降了34.12%，其他经营支出下降了51.88%
- 预收端：合同负债从420.91万增至806.87万，增长91.70%

这说明公司在**主动收缩、控制支出、加速回款**——虽然利润不好看，但现金流在改善，**活下来的能力在增强**。

#### 案例四：如鲲新材——利润与现金严重背离的危险信号

如鲲新材2023-2025年营收从6.47亿增至9.10亿，归母净利润从7700万增至1.09亿。

但翻开现金流量表：

| 年份 | 经营现金流净额 |
|---|---|
| 2023年 | 1.34亿元 |
| 2024年 | **-222.57万元**（骤转负） |
| 2025年 | 仅1850.72万元 |

**净利润从7700万涨到1.09亿，经营现金流却从1.34亿跌到1850万**——这就是**净利润与现金流严重背离**。

问题出在哪？公司的**应收票据、应收账款、应收款项融资**占流动资产的比例从60.56%一路飙到69.88%——赚的钱都变成了“欠条”，没收到真钱。

> ⚠️ **如果一家公司利润在增长，但经营现金流持续恶化，大概率是——赚的都是“账面上的钱”，不是“口袋里的钱”。**

#### 案例五：沈鼓集团——IPO前的现金流警报

2026年一季度，沈鼓集团营收21.04亿元，归母净利润翻倍增长。但：

> **经营性现金流净额为-10亿元**，2025年同期仅为-5264.93万元。

更严重的是，公司逾期应收账款高达27.08亿元，占应收账款余额的61.41%，但期后回款比例仅14.43%。

**利润翻倍，现金流却暴跌至-10亿**——这种“纸面富贵”撑不了多久。

#### 案例六：五洲特纸——现金流量表与资产负债表的“差异”从哪来？

五洲特纸在回答投资者提问时解释：经营性现金流量表变化，主要系公司**采用应收票据背书方式结算采购货款**的规模大幅增加所致。

通俗地说：公司收到客户的商业票据后，没有去银行兑成现金，而是**直接背书转让给供应商用来支付货款**。这在会计上属于**非现金结算**——它减少了报表上的往来账款余额，但**没有产生实际的现金流入和流出**。

**这就是为什么现金流量表和资产负债表有时候“对不上账”——不是因为做错了，而是因为有些交易本身就不涉及现金**。

> 💡 **延伸阅读：** 根据《企业会计准则解释第19号》，自2026年1月1日起，上市公司对金融资产合同现金流量特征评估及指定为以公允价值计量且其变动计入其他综合收益的权益工具披露进行了会计政策调整。虽然这不会对现金流量产生重大影响，但说明会计准则在不断细化，投资者需要关注这些变化对财务报表解读的影响。


### 六、2026年A股整体趋势：现金流在“全面修复”

如果把视角从单个公司拉高到整个A股市场，你会发现一个趋势：

> **2025年年报与2026年一季报显示，A股上市公司经营现金流出现了全局性、趋势性改善，边际修复力度为近三年最强**。

具体来看：

- **科技制造领跑**：电子、半导体、计算机、通信等板块经营现金流改善最为突出
- **周期与资源品跟进**：有色、化工、建材、钢铁等，价格因素对现金流形成支撑
- **覆盖面广**：不仅是头部公司，全市场尤其是非金融企业的经营现金流增速大幅提升

**营业现金比率已连续多个季度走升**，说明企业的“造血能力”正在全面修复。

而那些**现金流强劲的公司**——格力电器、中国海油、上汽集团、中远海控、潍柴动力等——正在成为A股的“现金牛”组合。中国海油2019年至2024年企业自由现金流均在500亿元以上，长期居于上市公司前列。

> 💡 **一个朴素的真理：在资本市场，利润可以靠会计调节美化，营收可以靠赊销虚增膨胀，但经营性现金流——那笔从客户口袋实实在在流进公司账户的钱——无法作假，也无法透支**。


### 七、现金流量表分析框架（傻瓜版）

当你拿到一家公司的现金流量表，按以下顺序“三连问”：

#### 第一问：经营活动现金流是正还是负？

| 结果 | 含义 | 怎么办 |
|---|---|---|
| **正数** | 主业能自己造血 | ✅ 好信号，继续看“够不够多” |
| **负数** | 主业在烧钱 | ❌ 危险信号，看还能烧多久 |

#### 第二问：经营现金流跟净利润比，谁大？

| 结果 | 含义 |
|---|---|
| **经营现金流 > 净利润** | 赚的是真钱，盈利质量高 👍 |
| **经营现金流 ≈ 净利润** | 正常，赚的钱基本都收回来了 |
| **经营现金流 < 净利润** | 利润可能是“纸面富贵”，要警惕 👀 |
| **经营现金流为负、净利润为正** | ⚠️ **严重背离！** 赶紧跑 |

#### 第三问：钱从哪来？花到哪去？

- **如果经营现金流为正** → 企业自己能造血 ✅
- **如果经营现金流为负，但筹资现金流为正** → 企业在借钱续命，能撑多久是个问题
- **如果经营现金流为负，但投资现金流为正** → 企业在变卖家产维持，不可持续
