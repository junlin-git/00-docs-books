# 第二节 创造利润的过程

> 本章目标：让你像算自家小账本一样，看懂上市公司利润表上“收入是如何一步步变成利润的”


## 一、利润表是什么？——用生活场景来理解

### 1.1 一个类比：利润表就是公司的“工资条”

想象你每个月拿到工资条：

| 你的工资条 | 上市公司的利润表 |
|-----------|----------------|
| 应发工资 | **营业收入**——公司卖东西收到的钱 |
| 扣五险一金 | **营业成本**——生产东西花的钱 |
| 扣个税 | **税金及附加**——交给国家的税 |
| 扣房租、交通费 | **期间费用**——销售、管理、财务费用 |
| 实发到手工资 | **净利润**——公司真正赚到的钱 |

**关键认知：** 利润表回答的是**“公司赚钱了吗？赚了多少？怎么赚的？”** 这三个问题。它记录的是**一段时间内**（比如一个季度或一年）的“流水账”，而不是某个时间点的“家底清单”（那是资产负债表的活）。

### 1.2 利润表的核心公式

> **收入 - 费用 = 利润**

就这么简单。但“收入”怎么变成“利润”，中间要经历**五次“过筛子”** ——每过一次筛子，就扣掉一部分钱，最后剩下的才是真正赚到手的钱。

### 1.3 利润的五个层次：从“毛收入”到“到手利润”
```
┌─────────────────────────────────────────────────────────────────┐
│ 利润的五个层次 │
├─────────────────────────────────────────────────────────────────┤
│ │
│ 第1层 营业收入 ← 公司卖东西收到的总钱款 │
│ ↓ 减去 营业成本 │
│ 第2层 毛利润 ← 卖东西的“差价” │
│ ↓ 减去 税金及附加 + 期间费用 │
│ 第3层 营业利润 ← 主业经营赚的钱 │
│ ↓ 加上/减去 营业外收支 + 投资收益等 │
│ 第4层 利润总额 ← 税前总利润 │
│ ↓ 减去 所得税 │
│ 第5层 净利润 ← 真正赚到手的钱 ⭐ │
│ │
└─────────────────────────────────────────────────────────────────┘
```

> 💡 **傻瓜式理解：** 就像你卖包子——卖了1000块钱（营业收入），面粉肉馅花了400块（营业成本），毛利润600块。交摊位费、雇小工、还贷款利息一共花了200块（期间费用），营业利润400块。隔壁老王找你借了50块没还（营业外支出），利润总额350块。交税50块，**最后到手300块（净利润）** 。


## 二、逐层拆解：利润是怎么“筛”出来的？

### 🔴 第1层：营业收入 → 毛利润

**公式：** `毛利润 = 营业收入 - 营业成本`

**营业收入是什么？**

公司**卖产品/提供服务**收到的钱。注意：这是**扣掉折扣、退货之后**的净收入。

**营业成本是什么？**

生产产品**直接花的钱**——原材料、人工工资、生产设备折旧等。

> 💡 **核心概念：毛利率**
>
> **毛利率 = 毛利润 ÷ 营业收入 × 100%**
>
> 毛利率是衡量公司**产品竞争力**的最重要指标之一。毛利率越高，说明产品越赚钱、品牌越强势。

**真实案例①：贵州茅台——毛利率之王**

2026年一季度，贵州茅台营业收入**539.09亿元**，营业成本约**55亿元**（推算）。

> 毛利润 ≈ 539 - 55 = **484亿元**
>
> **毛利率 ≈ 484 ÷ 539 ≈ 89.8%**

> 💡 **解读：** 茅台卖100块钱的酒，成本只有10块钱左右，**毛利高达90块钱**。这就是“品牌溢价”的极致体现——你喝的不是酒，是品牌。一季度毛利率同比小幅下降2.1个百分点，主要受系列酒占比提升和成本上涨影响。

**真实案例②：宁德时代——制造业的标杆**

2026年一季度，宁德时代营业收入**1291.31亿元**，毛利率**24.82%** 。

> 毛利润 ≈ 1291 × 24.82% ≈ **320亿元**

> 💡 **解读：** 宁德时代卖100块钱的电池，成本约75块钱，毛利25块钱。在制造业中，这个毛利率已经**非常优秀**了——说明宁德时代在锂电池行业有很强的定价权和成本控制能力。一季度毛利率同比上升0.41个百分点，但环比下降3.40个百分点，主要受碳酸锂等原材料涨价影响。

**真实案例③：格力电器——家电龙头**

2026年一季度，格力电器营业收入**429.66亿元**，营业成本约**311.87亿元**。

> 毛利润 ≈ 429.66 - 311.87 = **117.79亿元**
>
> **毛利率 ≈ 117.79 ÷ 429.66 ≈ 27.4%**

> 💡 **解读：** 格力卖100块钱的空调，成本约73块钱，毛利27块钱。在家电行业属于中上水平，但远低于茅台——这就是**白酒和制造业**的行业差异。


### 🟠 第2层：毛利润 → 营业利润

**公式：** `营业利润 = 毛利润 - 税金及附加 - 销售费用 - 管理费用 - 研发费用 - 财务费用 + 其他收益`

通俗说就是：**毛利扣掉“交给国家的税”和“公司运营花的钱”** 。

**四大费用是什么？**

| 费用类型 | 通俗理解 | 包含什么 |
|---------|---------|---------|
| **销售费用** | 卖东西花的钱 | 广告费、销售人员工资、运输费 |
| **管理费用** | 管公司花的钱 | 管理人员工资、办公费、差旅费 |
| **研发费用** | 搞研发花的钱 | 技术人员工资、实验材料费 |
| **财务费用** | 借钱花的钱 | 银行贷款利息（减掉存款利息） |

> 💡 **核心概念：期间费用率**
>
> **期间费用率 = (销售+管理+研发+财务费用) ÷ 营业收入 × 100%**
>
> 期间费用率越低，说明公司**管理效率越高**、**花钱越省**。

**真实案例①：贵州茅台——费用控制之王**

2026年一季度，贵州茅台的各项费用：

| 费用项目 | 金额（亿元） | 占营收比例 |
|---------|-----------|----------|
| 销售费用 | 16.06 | 2.98% |
| 管理费用 | 18.54 | 3.44% |
| 研发费用 | 0.59 | 0.11% |
| 财务费用 | 约-1.2 | -0.22% |
| **合计** | **约34亿** | **约6.3%** |

> 💡 **解读：** 茅台539亿的营收，只花了34亿的费用——**费用率仅6.3%** 。这意味着茅台每卖100块钱的酒，只需要花6块3毛钱的“运营成本”。其中财务费用还是**负数**（-0.22%），说明茅台**存钱的利息收入 > 借钱的利息支出**——钱多到不需要借钱！

**真实案例②：宁德时代——高速成长中的费用**

2026年一季度，宁德时代期间费用**93.80亿元**，期间费用率**7.26%** 。

> 💡 **解读：** 宁德时代1291亿的营收，费用约94亿，费用率7.26%。虽然绝对值很大（94亿！），但相对于1291亿的营收，比例控制得相当好。一季度期间费用率同比上升0.18个百分点，主要受汇兑损失影响——估计汇兑损失约18亿元。

**真实案例③：比亚迪——费用吞噬利润**

2026年一季度，比亚迪营业收入**1502亿元**，同比下降11.82%；归母净利润**40.85亿元**，同比暴跌55.38%。

费用方面：

| 费用项目 | 占营收比例 |
|---------|----------|
| 销售费用率 | 3.88% |
| 管理费用率 | 2.38% |
| 研发费用率 | 7.55% |
| 财务费用率 | 1.40% |
| **期间费用率合计** | **15.21%** |

关键问题出在**财务费用**——一季度财务费用**21亿元**，而去年同期是**-19.08亿元**（汇兑收益），一进一出差了**40亿元**！

> 💡 **解读：** 比亚迪的“利润暴跌”主要是**汇率波动**导致的——不是公司主业出了问题，而是海外收入多了，汇率一波动就产生了大量汇兑损失。这就是**全球化企业的“双刃剑”** ：赚外汇的时候爽，汇率一跌就疼。


### 🟡 第3层：营业利润 → 利润总额

**公式：** `利润总额 = 营业利润 + 营业外收入 - 营业外支出`

**营业外收支是什么？**

和公司**主业无关**的意外收入或支出——比如卖旧设备的钱、被罚款的钱、政府给的补贴等。

**真实案例：茅台2026年一季度**

茅台2026年一季度利润总额**375.43亿元**，营业利润约**375.37亿元**，营业外收支净额仅约**0.06亿元**。

> 💡 **解读：** 茅台的利润**几乎全部来自主业**——营业外收支占比微乎其微。这是一个**非常干净**的利润表，说明公司专注卖酒，不靠“歪门邪道”赚钱。


### 🟢 第4层：利润总额 → 净利润

**公式：** `净利润 = 利润总额 - 所得税费用`

公司赚了钱要交企业所得税（通常税率25%，但高新技术企业有优惠）。

**真实案例①：茅台2026年一季度**

| 项目 | 金额（亿元） |
|------|----------|
| 利润总额 | 375.43 |
| 所得税费用 | 约93 |
| **净利润** | **约282** |

> 💡 **解读：** 茅台赚了375亿，交税约93亿（税率约25%），净赚282亿。但这282亿是“净利润”（包含少数股东的部分），**真正属于茅台股东的**是“归母净利润”272.43亿元。

**真实案例②：宁德时代2026年一季度**

| 项目 | 金额（亿元） |
|------|----------|
| 营业收入 | 1291.31 |
| 毛利率 | 24.82% |
| 净利润（估算） | 约227亿 |
| **归母净利润** | **207.38亿** |

> 💡 **解读：** 宁德时代一季度**每天净赚约2.3亿元**。这就是新能源龙头的赚钱能力。


### 🔵 第5层：净利润 → 归母净利润

**两个关键概念：**

| 概念 | 含义 |
|------|------|
| **净利润** | 整个集团（上市公司+所有子公司）赚的钱 |
| **归母净利润** | 净利润中**真正属于上市公司股东**的钱 |

**为什么会有差异？**

因为上市公司不一定100%持有所有子公司——子公司里还有“少数股东”的份额。

**真实案例：宁德时代2026年一季度**

| 项目 | 金额（亿元） |
|------|----------|
| 净利润（估算） | 约227 |
| 少数股东损益 | 约20 |
| **归母净利润** | **207.38** |

> 💡 **解读：** 宁德时代整个集团赚了约227亿，其中约20亿被“少数股东”分走了，真正属于宁德时代股东的只有207.38亿。
>
> **核心口诀：看利润一定要看“归母净利润”** ——这才是**真正属于你的那一份**。


## 三、2026年一季度A股全景——谁在赚钱？谁在亏钱？

### 3.1 整体情况：七成公司赚钱

2026年一季度，5503家A股公司合计营收**17.44万亿元**，同比增长4.66%；归母净利润**1.59万亿元**，同比增长6.54%。

- **4040家**公司盈利，占比**73.42%**
- **2846家**净利润同比增长，占比**51.72%**

> 💡 **解读：** 10家公司里，超过7家赚钱，超过5家比去年赚得更多。A股整体盈利在**温和复苏**。

### 3.2 最赚钱的公司：银行称霸

2026年一季度归母净利润排名：

| 排名 | 公司 | 归母净利润（亿元） |
|------|------|----------------|
| 1 | 工商银行 | **869.41** |
| 2 | 建设银行 | 862.91 |
| 3 | 农业银行 | 751.85 |
| 4 | 中国银行 | ~600 |
| 5 | 中国石油 | 483.32 |

> 💡 **解读：** 工商银行一季度赚**869亿**——**每天赚近10个亿**！这就是“宇宙第一大行”的赚钱能力。银行、石油这些“巨无霸”赚的是**规模的钱**——体量巨大，利润自然惊人。

### 3.3 增长最快的赛道：科技领跑

2026年一季度各板块净利润增速：

| 板块 | 净利润增速 |
|------|----------|
| 科创板 | **+209.03%** |
| 计算机行业 | **+100.56%** |
| 有色金属 | **+90.61%** |
| 创业板 | **+21.75%** |
| 深市主板 | **+13.05%** |

> 💡 **解读：** 科创板净利润增速**209%** ——连续两个季度高增长。科技、AI、半导体是当前A股**最赚钱的方向**。

79家公司一季度净利润增幅超**10倍**。其中存储芯片三巨头——江波龙（38.62亿）、德明利（33.46亿）、佰维存储（28.99亿）——一季度合计净利润超100亿元。

> 💡 **解读：** 存储芯片行业正处于**超级景气周期**。AI算力需求爆发，带动存储芯片量价齐升——这就是“赛道”的力量。

### 3.4 谁在亏钱？——万科的困境

2026年一季度，万科归母净利润**亏损59.52亿元**。

| 项目 | 数据 |
|------|------|
| 营业收入 | 289.28亿元（同比-23.86%） |
| 归母净利润 | **-59.52亿元** |
| 综合毛利率 | 9.1%（同比+3.0pct） |
| 加权平均ROE | **-5.23%** |

> 💡 **解读：** 万科的毛利率从去年的0.5%回升到了9.1%，看起来在好转，但为什么还亏59亿？
>
> 原因有三：
> 1. **收入大幅下滑**：营收从380亿降到289亿，少了91亿
> 2. **费用率上升**：期间费用率同比增长1.2个百分点至13.3%
> 3. **投资收益亏损**：投资净收益亏损12.1亿
>
> 万科的问题不是“卖一套亏一套”，而是**卖得太少**——收入规模大幅萎缩，但固定费用（管理人员工资、利息等）还在，导致**规模不经济**。这是房地产行业“磨底”阶段的典型特征。


## 四、利润表分析框架——“傻瓜四步法”

### 第一步：看“归母净利润”（1分钟）

**最重要的一步！** 打开利润表，直接找到 **“归属于上市公司股东的净利润”** ——这是**真正属于你的钱**。

| 情况 | 判断 |
|------|------|
| 归母净利润 > 0，且同比增长 | ✅ 公司在**赚钱**，而且越赚越多 |
| 归母净利润 > 0，但同比下降 | ⚠️ 公司在**赚钱**，但赚钱能力在**变弱** |
| 归母净利润 < 0 | ❌ 公司在**亏钱**，要找出原因 |

**2026年一季度真实数据：**
- 贵州茅台归母净利润**272.43亿**，同比增长1.47%——赚钱且增长 ✅
- 宁德时代归母净利润**207.38亿**，同比增长48.52%——赚钱且高速增长 ✅✅
- 比亚迪归母净利润**40.85亿**，同比下降55.38%——赚钱但大幅下滑 ⚠️
- 万科归母净利润**-59.52亿**——亏钱 ❌

### 第二步：看“毛利率”（3分钟）

毛利率告诉你**产品赚不赚钱**。

| 毛利率 | 判断 |
|--------|------|
| > 40% | 产品**非常赚钱**，有品牌溢价或技术壁垒 |
| 20% - 40% | 产品**正常赚钱**，有竞争力 |
| < 20% | 产品**不太赚钱**，靠走量或效率 |
| 同比上升 | 产品**变强了**（涨价或成本下降） ✅ |
| 同比下降 | 产品**变弱了**（降价或成本上升） ⚠️ |

**2026年一季度真实数据：**
- 贵州茅台毛利率**89.8%** ——产品极度赚钱 ✅
- 宁德时代毛利率**24.82%** ——制造业中优秀水平 ✅
- 比亚迪毛利率**18.81%** ——略低于行业平均 ⚠️
- 格力电器毛利率**约27.4%** ——家电行业中上水平 ✅

### 第三步：看“期间费用率”（3分钟）

费用率告诉你**公司花钱省不省**。

| 费用率 | 判断 |
|--------|------|
| 低且稳定 | 公司**管理高效** ✅ |
| 突然上升 | 公司在**烧钱**扩张，或者**管理失控** ⚠️ |
| 财务费用为正且很大 | 公司**借钱太多**，利息负担重 ❌ |

**2026年一季度真实数据：**
- 贵州茅台期间费用率**6.3%** ——极低，管理高效 ✅
- 宁德时代期间费用率**7.26%** ——较低，控制良好 ✅
- 比亚迪期间费用率**15.21%** ——偏高，财务费用拖累 ⚠️

### 第四步：看“非经常性损益”（3分钟）

**非经常性损益**就是**“不常有”的收益或损失**——卖资产、政府补贴、罚款等。

**为什么重要？**

因为非经常性损益会**扭曲**真实的盈利能力。

| 情况 | 判断 |
|------|------|
| 归母净利润 > 扣非净利润 | 公司靠**非经常性收益**撑门面 ⚠️ |
| 归母净利润 ≈ 扣非净利润 | 公司**主业**在赚钱 ✅ |
| 归母净利润 < 扣非净利润 | 公司有**非经常性损失**（一次性的） |

**真实案例：宁德时代2026年一季度**

| 项目 | 金额（亿元） |
|------|----------|
| 归母净利润 | 207.38 |
| 扣非净利润 | 180.93 |
| 差额 | **26.45亿** |

> 💡 **解读：** 宁德时代归母净利润比扣非净利润多了26.45亿——这26.45亿就是“非经常性损益”（主要是投资收益和政府补助等）。这说明宁德时代的**主业利润**是180.93亿，另外26.45亿是“额外奖励”。**看主业赚钱能力，要看扣非净利润。**

## 六、给“傻瓜”的终极建议

> **记住五句话：**
>
> 1. **利润是“算”出来的，不是“数”出来的。** ——每一步都要“过筛子”，扣掉各种成本费用。
>
> 2. **看利润一定要看“归母净利润”。** ——这才是真正属于上市公司股东的钱。
>
> 3. **毛利率看竞争力，费用率看管理效率。** ——两个指标结合起来，才能判断公司“赚钱的能力”和“管钱的能力”。
>
> 4. **归母净利润和扣非净利润对比看。** ——差距大说明公司在靠“意外之财”撑门面，要警惕。
>
> 5. **不怕利润下滑，怕不知道为什么下滑。** ——比亚迪利润暴跌是因为汇兑损失（一次性），万科利润亏损是因为收入崩塌（结构性的）——前者可能反弹，后者更难逆转。

**现在，你已经掌握了利润表创造利润的全部过程。打开任意一家上市公司的利润表，从“营业收入”开始，一步一步往下算，看看这家公司的钱是怎么“筛”出来的吧！**
