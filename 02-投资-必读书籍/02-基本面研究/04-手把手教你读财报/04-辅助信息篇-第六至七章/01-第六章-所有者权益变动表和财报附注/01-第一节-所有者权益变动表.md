# 第六章 所有者权益变动表和财报附注

## 第一节 所有者权益变动表

### 一、为什么说所有者权益变动表是“家底的日记”？

#### 1.1 一个你可能忽略的真相

假设你开了一家小店。年初你盘了一下账：

- 你投了50万（本金）
- 店里攒了20万利润没分红（积累）
- 合计家底 **70万**

一年下来，你忙前忙后，年底再一算：

- 本金还是50万
- 但积累的利润变成了30万
- 合计家底 **80万**

**家底从70万变成了80万，这10万是怎么来的？** 是你辛辛苦苦经营赚来的？还是你额外又投了钱？还是你买的隔壁商铺涨价了？

**资产负债表告诉你“家底有多少”，所有者权益变动表告诉你“家底为什么变了”。**

> 💡 **一句话记住：资产负债表是“家底清单”，所有者权益变动表是“家底变动日记”。**

#### 1.2 所有者权益变动表是什么？

所有者权益变动表，是指**反映构成所有者权益各组成部分当期增减变动情况的报表**。它是对资产负债表的补充，也是对企业所有者权益（股东权益）增减变动根源的进一步说明。

在2007年以前，所有者权益变动情况只是资产负债表的附表。**2007年新会计准则颁布后，所有者权益变动表正式升级为第四张核心财务报表**，与资产负债表、利润表、现金流量表平起平坐。

**它是四张报表中最年轻、也最容易被忽视的一张——但恰恰是它，揭示了企业“家底”变化的全部秘密。**


### 二、所有者权益由哪些部分组成？

在读懂变动表之前，先搞清楚“所有者权益”本身长什么样：
```
┌─────────────────────────────────────────────────────────┐
│ 所有者权益（股东权益） │
├─────────────────────────────────────────────────────────┤
│ │
│ ┌─────────────────────────────────────────────────┐ │
│ │ 一、实收资本（或股本） │ │
│ │ ——股东投入的“本钱” │ │
│ └─────────────────────────────────────────────────┘ │
│ │
│ ┌─────────────────────────────────────────────────┐ │
│ │ 二、其他权益工具 │ │
│ │ ——优先股、永续债等特殊融资工具 │ │
│ └─────────────────────────────────────────────────┘ │
│ │
│ ┌─────────────────────────────────────────────────┐ │
│ │ 三、资本公积 │ │
│ │ ——资本溢价、股本溢价等“额外本钱” │ │
│ └─────────────────────────────────────────────────┘ │
│ │
│ ┌─────────────────────────────────────────────────┐ │
│ │ 四、减：库存股 │ │
│ │ ——公司回购但尚未注销的自家股票 │ │
│ └─────────────────────────────────────────────────┘ │
│ │
│ ┌─────────────────────────────────────────────────┐ │
│ │ 五、其他综合收益 │ │
│ │ ——直接计入权益的利得和损失（不经过利润表） │ │
│ └─────────────────────────────────────────────────┘ │
│ │
│ ┌─────────────────────────────────────────────────┐ │
│ │ 六、专项储备 │ │
│ │ ——安全生产费等法定储备 │ │
│ └─────────────────────────────────────────────────┘ │
│ │
│ ┌─────────────────────────────────────────────────┐ │
│ │ 七、盈余公积 │ │
│ │ ——法定公积金、任意公积金（强制“储蓄”） │ │
│ └─────────────────────────────────────────────────┘ │
│ │
│ ┌─────────────────────────────────────────────────┐ │
│ │ 八、未分配利润 │ │
│ │ ——历年攒下来没分掉的利润 │ │
│ └─────────────────────────────────────────────────┘ │
│ │
│ 所有者权益合计 = 以上各项之和 │
│ │
└─────────────────────────────────────────────────────────┘
```

**用“打工人”的视角理解：**

| 所有者权益项目 | 打工人版本 | 说明 |
|---|---|---|
| **实收资本/股本** | 你买房时自己掏的首付 | 股东投入的原始本钱 |
| **资本公积** | 父母额外给你的装修款 | 股东多投的钱（超出股本部分） |
| **盈余公积** | 你强制存进定期存款的钱 | 法律规定不能随便分的利润 |
| **未分配利润** | 你银行卡里可随时花的存款 | 赚了没分的利润 |
| **库存股** | 你把自己的车买回来停在车库 | 公司回购的自家股票（用减号） |
| **其他综合收益** | 你买的基金涨价了但没卖 | 资产涨价了但还没变现 |


### 三、所有者权益变动表长什么样？

所有者权益变动表采用**纵横交叉的矩阵式结构**：

**纵向——按时间顺序：**

上年年末余额 → 本年年初余额 → 本年增减变动 → 本年年末余额
text


**横向——按权益项目分类：**

| | 股本 | 资本公积 | 减：库存股 | 其他综合收益 | 盈余公积 | 未分配利润 | 合计 |
|---|---|---|---|---|---|---|---|
| **上年年末余额** | | | | | | | |
| **本年年初余额** | | | | | | | |
| **本年增减变动** | | | | | | | |
| **本年年末余额** | | | | | | | |

**为什么是这种结构？** 因为它要回答四个问题：

1. **从哪来？** ——上年末有多少？
2. **变没变？** ——年初有没有调整（会计政策变更、差错更正）？
3. **怎么变的？** ——这一年发生了什么导致权益变化？
4. **到哪去？** ——年末最终剩多少？


### 四、逐项拆解：所有者权益是怎么“动”起来的？

所有者权益变动表需要单独列示的信息包括：**综合收益总额、会计政策变更和差错更正的累积影响、所有者投入和向所有者分配利润、提取的盈余公积，以及各项目的期初和期末余额及其调节情况**。

下面用**2026年A股的真实案例**，逐一说明每个项目是怎么变动的。

#### 4.1 股本（实收资本）——公司发行了多少“份额”

**股本的变动，通常来自：**

- **增发股票**（融资扩股）→ 股本增加
- **资本公积转增股本**（“拆股”）→ 股本增加（但总权益不变）
- **回购注销**（减资）→ 股本减少

**🔍 2026年真实案例：海程邦达资本公积转增股本**

2026年6月，海程邦达（603836）实施了资本公积转增股本方案：以总股本205,235,237股为基数，**向全体股东每股转增0.4股**，合计转增80,974,095股。转增完成后，公司总股本从2.05亿股增至2.86亿股，注册资本相应增加。

**⚠️ 特别注意：** 资本公积转增股本，**总的所有者权益不变**——只是把“资本公积”这个口袋里的钱，挪到了“股本”这个口袋里。就像你把左口袋的100块钱掏出来放到右口袋——钱还是你的钱，只是放的位置变了。

**🔍 2026年真实案例：联合精密“10转4”**

联合精密（001268）2025年度权益分派方案为：**以资本公积每10股转增4股**，合计转增42,769,333股，转增后总股本从1.08亿股增至1.51亿股。

**🔍 2026年真实案例：汇宇制药大比例转增**

汇宇制药（688553）2025年度权益分派方案实施完毕后，**总股本从4.24亿股增加至6.26亿股**，增幅达47.7%。

#### 4.2 资本公积——“溢价”和“馈赠”的蓄水池

**资本公积的变动，通常来自：**

- **股票发行溢价**（IPO或增发时，发行价高于面值的部分）→ 增加
- **资本公积转增股本**→ 减少
- **接受捐赠、资产重估增值**等→ 增加

**通俗理解：** 假如你开公司，注册资本100万（股本），但有投资人想入股，愿意出200万买20%的股份——多出来的100万就是“资本公积”。它不是利润，是股东多掏的钱。

#### 4.3 库存股——公司买回来的“自家股票”

**库存股的变动，通常来自：**

- **公司回购股票**（但尚未注销）→ 库存股增加（用减号表示）
- **库存股注销**→ 库存股减少
- **库存股用于股权激励**→ 库存股减少

**⚠️ 库存股是“减项”！** 在所有者权益中，库存股用负数表示——因为公司花钱买回自己的股票，相当于把一部分权益“拿回来”了。

**🔍 2026年真实案例：豪威集团回购A股**

2026年7月1日，豪威集团（00501.HK）于上海证券交易所**回购A股195.62万股**，每股回购价94.72元至98.99元，总支付金额约**1.92亿元**。所回购股份将持有作为**库存股份**，不予注销。

**🔍 2026年真实案例：美的集团回购**

美的集团（00300.HK）于2026年7月1日**购回A股股份1,993,939股**。

**🔍 2026年真实案例：神马股份注销库存股**

神马股份（600810.SH）于2026年6月30日公告，**拟注销回购专用账户中未用于股权激励的295.413万股股份**，占总股本0.27%，相应减少注册资本。

**🔍 2026年真实案例：山鹰国际“双重降股本”**

山鹰国际通过集中竞价交易已累计回购股份2.72亿股，其中1.70亿股已用于可转债转股，剩余约**1.02亿股由“激励用途”改为“注销减资”** ——注销后公司总股本从63.07亿股降至62.05亿股。

**库存股变动的意义：**

| 行为 | 对股东的影响 |
|---|---|
| **回购但不注销（库存股）** | 每股收益可能提升（总股本不变，但库存股不参与分红和表决） |
| **回购并注销** | 总股本减少，**每股收益和每股净资产提升**——对股东是利好 |
| **库存股用于股权激励** | 相当于“低价发股票给员工”——可能稀释原有股东权益 |

#### 4.4 其他综合收益——不经过利润表的“隐藏收益”

**这是所有者权益变动表中最容易被忽略、但也最重要的项目之一。**

**什么是“其他综合收益”？**

有些资产涨价了或跌价了，但**还没卖掉**——会计上不让你计入利润表（因为利润表只记录“已实现”的损益），但你又不能假装没发生——于是就放在“其他综合收益”里，直接计入所有者权益。

**🔍 2026年真实案例：贝达药业——其他权益工具投资的公允价值变动**

贝达药业（300558）在接受投资者调研时明确表示：**公司将禾元生物投资指定为其他权益工具投资，其公允价值变动计入其他综合收益，属于所有者权益变动，不纳入利润表核算，对公司2025年归母净利润、扣非净利润均无影响**。

**这句话翻译成大白话：**

- 贝达药业投了一家叫“禾元生物”的公司
- 这家公司的估值涨了（或跌了）
- 但贝达药业**还没卖掉**这笔投资
- 所以**涨价的钱不能算进利润**（因为没变现）
- 但**涨价的事实不能不记录**——于是放在“其他综合收益”里
- **利润表上看不到这笔收益，但所有者权益里已经体现出来了**

**这就是为什么：两家公司利润一样，但一家所有者权益增长更快——可能是因为它有“隐藏的收益”藏在其他综合收益里。**

**🔍 2026年真实案例：翔鹭钨业财报“摆乌龙”**

2026年5月，翔鹭钨业（002842）发布更正公告：经自查发现，**公司报表科目分类有误**，需要调整其他权益工具投资、未分配利润、其他应收款及其他综合收益。

**这个“乌龙”说明了什么？** 说明其他综合收益的分类和计量，**连上市公司自己都可能搞错**——普通投资者更要注意看清。

**🔍 2026年真实案例：同仁堂更正一季报**

同仁堂（600085）于2026年4月30日披露一季报后，发现**合并利润表中“外币财务报表折算差额”科目填列数据遗漏负号**，紧急发布更正公告。

**其他综合收益主要包括：**

| 类型 | 通俗解释 |
|---|---|
| **外币报表折算差额** | 有海外子公司，汇率变了，折算回来有差异 |
| **其他权益工具投资公允价值变动** | 持有未上市的股权，估值变了 |
| **金融资产重分类计入** | 金融资产分类变了，产生的差异 |

**⚠️ 关键提醒：** 其他综合收益**不进入利润表**，但它**直接改变所有者权益**。一个公司如果其他综合收益持续大额增长，可能隐藏着巨大的“潜在收益”；反之，如果持续大额减少，可能隐藏着“潜在亏损”。

#### 4.5 盈余公积——强制“储蓄”

**盈余公积的变动，通常来自：**

- **从净利润中提取**（法定10%）→ 增加
- **用盈余公积弥补亏损**→ 减少
- **用盈余公积转增股本**→ 减少

**通俗理解：** 公司赚了钱，不能全分了——法律规定必须至少留10%作为“储备金”，这就是法定盈余公积。相当于你每个月工资发下来，强制存10%到定期账户，不能随便花。

#### 4.6 未分配利润——攒下来的“家底”

**未分配利润的变动，通常来自：**

- **净利润**→ 增加
- **分红**（分配现金股利）→ 减少
- **提取盈余公积**→ 减少（转移到盈余公积）
- **会计差错更正**→ 可能增加或减少

**通俗理解：** 公司历年赚的利润，**扣掉分红、扣掉提取的盈余公积**之后，剩下的就是“未分配利润”——这是公司真正的“积蓄”。

**🔍 2026年真实案例：恒尚节能收购标的——所有者权益5个月飙升290%**

恒尚节能（603137）拟收购金胜电子100%股权。金胜电子的财务数据显示：

| 时间 | 所有者权益 |
|---|---|
| 2024年末 | 2,539.64万元 |
| 2025年末 | 6,626.88万元 |
| **2026年5月末** | **2.58亿元** |

**短短5个月，所有者权益飙升290%**。

原因是什么？恒尚节能的解释是：**2026年金胜电子因持续经营积累及完成1.2亿元股权融资**，所有者权益规模增长。

**拆解一下：**

- **持续经营积累**→ 赚了钱，**未分配利润**增加
- **完成1.2亿元股权融资**→ 新股东投钱，**股本和资本公积**增加

**这就是所有者权益变动表的魅力——它把“家底增加了2.3亿”这个结果，拆解成了“赚了多少”和“融了多少”两个清清楚楚的原因。**


### 五、所有者权益变动表的“四大变动类型”

把所有变动归纳起来，其实就是四种情况：
```
┌─────────────────────────────────────────────────────────────┐
│ 所有者权益变动的四大类型 │
├─────────────────────────────────────────────────────────────┤
│ │
│ 类型一：所有者投入和减少资本 │
│ ├── 股东投入新资金 → 股本/资本公积增加 │
│ ├── 股份回购 → 库存股增加（减项） │
│ └── 股份支付计入 → 资本公积增加 │
│ │
│ 类型二：利润分配 │
│ ├── 提取盈余公积 → 盈余公积增加，未分配利润减少 │
│ └── 对股东的分配（分红）→ 未分配利润减少 │
│ │
│ 类型三：综合收益总额 │
│ ├── 净利润 → 未分配利润增加 │
│ └── 其他综合收益 → 其他综合收益项目变动 │
│ │
│ 类型四：所有者权益内部结转 │
│ ├── 资本公积转增股本 → 资本公积减少，股本增加 │
│ ├── 盈余公积转增股本 → 盈余公积减少，股本增加 │
│ └── 盈余公积弥补亏损 → 盈余公积减少，未分配利润增加 │
│ │
└─────────────────────────────────────────────────────────────┘
```


**关键理解：** 类型一和类型二是“**外部**”变动（钱进来了或钱出去了），类型三是“**经营**”变动（赚了或亏了），类型四是“**内部**”变动（左口袋到右口袋，**总权益不变**）。


### 六、生活案例：用“打工人”的视角理解所有者权益变动表

假设你是一个打工人，我们用你的“个人所有者权益变动表”来理解：

| 项目 | 你的情况 | 企业对应 |
|---|---|---|
| **期初所有者权益** | 年初存款50万 | 年初股东权益 |
| **所有者投入** | 父母给了你10万 | 股东增资 |
| **综合收益** | 工资收入20万 - 开销15万 = 赚了5万 | 净利润 |
| **利润分配** | 花了2万买了个包（相当于“分红”） | 现金分红 |
| **其他综合收益** | 你买的基金涨了3万（没卖） | 公允价值变动 |
| **内部结转** | 你把5万活期转成定期 | 资本公积转增股本（总权益不变） |
| **期末所有者权益** | 50+10+5-2+3=66万 | 期末股东权益 |

**所有者权益变动表就是把你这66万是怎么从50万变出来的，一笔一笔记清楚。**


### 七、2026年A股特殊案例：天价离婚与权益变动

2026年7月1日，安正时尚（603839.SH）发布公告：**公司原第二大股东陈克川因婚姻解除，将所持全部公司股份（41,406,300股，占总股本10.70%）无偿过户至前妻郑秀萍名下**。按照当日股价测算，分割股份市值**超2.46亿元**。

过户完成后，陈克川持股降至0，郑秀萍成为公司主要股东。

**这件事跟所有者权益变动表有什么关系？**

- 公司的**总股本没有变**（股份还是那些股份）
- 公司的**总所有者权益没有变**（只是股东名字变了）
- 但**股东层面的权益结构**发生了重大变化——这是“所有者权益变动表”之外的故事

**⚠️ 重要提醒：** 所有者权益变动表记录的是**公司层面**权益的变化（股本、资本公积、未分配利润等），而不是**股东个人**持股的变化。股东之间的股份转让，**不会体现在所有者权益变动表上**——因为公司的总权益没变。

但如果股东转让导致**控制权变更**，会在**财报附注**中披露。


### 八、所有者权益变动表分析框架（傻瓜版）

当你拿到一家公司的所有者权益变动表，按以下顺序“三连问”：

#### 第一问：所有者权益总额是增加还是减少？

| 结果 | 含义 |
|---|---|
| **增加** | 公司在“积累财富” ✅ |
| **减少** | 公司在“消耗家底” ❌ |

#### 第二问：增加/减少的来源是什么？

| 来源 | 含义 | 质量 |
|---|---|---|
| **净利润贡献** | 靠经营赚来的 | 👍 **高质量**（可持续） |
| **股东增资** | 靠股东投来的 | 👀 中性（不可持续，但说明股东有信心） |
| **其他综合收益** | 靠资产涨价 | 👀 要看是什么资产（可能是不可持续的） |
| **分红/回购** | 钱分出去了 | 如果是减少，要看是不是分得太多 |

#### 第三问：内部结构是否健康？

| 健康信号 | 危险信号 |
|---|---|
| 未分配利润持续增长 | 未分配利润为负（累计亏损） |
| 资本公积合理（有溢价融资能力） | 资本公积过度依赖非经常性项目 |
| 盈余公积按规定提取 | 长期不提取盈余公积（逃避法定义务） |
| 其他综合收益透明可理解 | 其他综合收益占比过大且说不清楚 |


### 九、核心要点速记
```
┌────────────────────────────────────────────────────────────┐
│ 所有者权益变动表“三字经” │
├────────────────────────────────────────────────────────────┤
│ │
│ 家底多少看负债表 —— 所有者权益总额 │
│ 家底咋变看变动表 —— 变动原因全知道 │
│ │
│ 股本代表“本钱” —— 股东投入的基础 │
│ 公积代表“溢价” —— 额外投入的蓄水池 │
│ 库存股是“减项” —— 回购的自家股票 │
│ 其他综合收益 —— 不进利润表的“隐藏账” │
│ 盈余公积是“储蓄” —— 强制留下的储备金 │
│ 未分配利润是“积蓄” —— 历年攒下的真家底 │
│ │
│ 外部变动看投入分红 —— 钱进来或钱出去 │
│ 经营变动看综合收益 —— 赚了还是亏了 │
│ 内部变动看结转 —— 左口袋到右口袋（总权益不变） │
│ │
│ ⚠️ 记住：股东之间转让股份，公司总权益不变 │
│ ⚠️ 记住：其他综合收益不经过利润表，但改变所有者权益 │
│ │
└────────────────────────────────────────────────────────────┘
```

**读懂所有者权益变动表，就是看懂一家公司“家底”变化的全部真相——哪些是经营赚来的，哪些是股东投来的，哪些是资产涨价带来的，哪些是分给股东了的。每一分钱的来龙去脉，都清清楚楚。**

**在资本市场，利润可以被调节，现金流可以被粉饰，但所有者权益的变动逻辑——只要你读懂了——是骗不了人的。**
