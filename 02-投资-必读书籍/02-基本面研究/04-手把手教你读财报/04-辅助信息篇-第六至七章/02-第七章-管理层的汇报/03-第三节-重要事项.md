# 第七章 管理层的汇报

## 第三节 重要事项

### 一、为什么“重要事项”是财报里最不能跳过的一章？

#### 1.1 一个你可能忽略的真相

假设你准备借钱给一个朋友开公司。朋友给你看了一份漂亮的财务报告——利润在增长、资产在增加、现金流也不错。

但就在这时，你偶然发现：

- 他正在跟供应商打一场**上亿元的官司**，如果输了可能要赔掉大半家产
- 他给别人的借款**做了担保**，如果对方还不上，他要**替人还债**
- 他公司的**大股东正在悄悄减持股票**
- 他因为**偷税漏税正在被税务局调查**

你还会借钱给他吗？

**这就是“重要事项”的价值——它告诉你财报数字背后那些“不能不知道的事”。**

> 💡 **一句话记住：资产负债表告诉你“家里有什么”，利润表告诉你“赚了多少”，现金流量表告诉你“钱去哪了”——而“重要事项”告诉你“家里出了什么大事”。**

#### 1.2 什么是“重要事项”？

“重要事项”是上市公司年度报告中的**第十三节**（不同交易所格式略有差异），专门披露**那些对投资者决策有重大影响、但又不属于三张主表范围的事项**。

**为什么它很重要？**

根据统计，2025年度，中国证监会及派出机构共对上市公司作出近500次行政处罚，其中**信息披露违规占比将近50%**，是上市公司违法违规的“重灾区”。而“重要事项”的披露不完整、不及时、不准确，正是信息披露违规的主要表现之一。

**换句话说：很多公司暴雷，早就在“重要事项”里埋下了伏笔——只是你没看。**


### 二、“重要事项”包含哪些内容？

根据证监会《公开发行证券的公司信息披露内容与格式准则第2号——年度报告的内容与格式》，“重要事项”通常包括以下**十大类**：
```
┌─────────────────────────────────────────────────────────────┐
│ 重要事项（十大类别） │
├─────────────────────────────────────────────────────────────┤
│ │
│ 类别一：重大诉讼、仲裁 │
│ ——公司正在打的官司，输了可能赔多少钱 │
│ │
│ 类别二：破产重整相关事项 │
│ ——公司是否正在或曾经进入破产程序 │
│ │
│ 类别三：资产交易事项 │
│ ——重大资产收购、出售、置换 │
│ │
│ 类别四：关联交易 │
│ ——跟“自己人”做的生意，价格是否公允 │
│ │
│ 类别五：对外担保 │
│ ——公司替别人做了多少担保，风险有多大 │
│ │
│ 类别六：资金占用 │
│ ——大股东或关联方是否“借用”了公司的钱 │
│ │
│ 类别七：股份回购与股东减持 │
│ ——公司自己买股票，还是大股东在卖股票 │
│ │
│ 类别八：股权激励 │
│ ——给员工发股票，会稀释多少现有股东的权益 │
│ │
│ 类别九：重大合同 │
│ ——签了大单还是丢了重要客户 │
│ │
│ 类别十：其他重大事项 │
│ ——会计政策变更、补税、受到处罚、董责险购买等 │
│ │
└─────────────────────────────────────────────────────────────┘
```


### 三、逐类拆解：每一类“重要事项”怎么看？

#### 3.1 重大诉讼、仲裁——公司的“官司清单”

**披露什么？** 公司及子公司**涉案金额超过一定比例**（通常为净资产的10%）的重大诉讼、仲裁案件。

**怎么看？**

| 看什么 | 怎么看 |
|---|---|
| **涉案金额** | 占净资产比例越大，风险越高 |
| **案件性质** | 是合同纠纷、专利侵权还是担保追偿？ |
| **进展阶段** | 一审？二审？还是已判决？ |
| **预计影响** | 公司自己估计会赔多少？ |

**🔍 2026年真实案例：丰沃股份——5600万专利诉讼“杀死”IPO**

2026年，丰沃股份在冲刺IPO的关键阶段，**陷入与国际涡轮增压器巨头盖瑞特的专利诉讼**，盖瑞特合计索赔5600万元。专利诉讼成为上交所两轮问询的**重点关注问题**之一，最终因公司及其保荐人撤回发行上市申请，**上交所终止了其发行上市审核**。

**启示：** 一场官司，可以毁掉一家公司几年的上市努力。如果你在打新之前没看“重要事项”里的诉讼披露，可能根本不知道这家公司正在“刀尖上跳舞”。

**🔍 2026年真实案例：龙泉股份——累计诉讼涉案1.76亿元**

龙泉股份（002671）2026年2月公告：公司及控股子公司**在过去十二个月内累计诉讼、仲裁涉案金额达17,632.53万元，占最近一期经审计净资产的10.58%**。相关案件尚处于未开庭或未结案状态。

**启示：** 累计诉讼金额超过净资产10%，这是一个**明确的红色预警信号**——公司面临的潜在赔付风险已经不容忽视。

**🔍 2026年真实案例：利元亨——1.29亿合同纠纷**

利元亨（688499）与微宏动力系统（湖州）有限公司的合同纠纷升级：微宏动力已向法院起诉，**要求解除采购合同、返还已支付货款6051.55万元、赔偿预期可得利益损失6687.76万元，合计索赔约1.29亿元**。

**启示：** 1.29亿的索赔金额，对很多公司来说可能就是**一年的净利润**。一场官司输了，可能就白干一年。

#### 3.2 关联交易——跟“自己人”做的生意

**披露什么？** 公司与**关联方**（控股股东、实际控制人、董事、监事、高管及其控制的公司等）之间的交易。

**为什么关联交易需要特别关注？**

因为**关联交易最容易出现利益输送**——大股东可能通过关联交易把公司的钱“倒”到自己口袋里。

**🔍 2026年真实案例：倍轻松——关联交易“瞒而不报”，被罚1010万**

2026年6月12日，倍轻松（688793）收到深圳证监局下发的《行政处罚事先告知书》。

证监局查明：2024年期间，倍轻松第一大股东、实际控制人马学军**通过安排孙公司转出资金、组织员工申请备付金借款、向供应商提前支付采购款等方式，非经营性占用公司资金**，构成关联交易。

截至2024年12月31日，**资金占用发生额8593.29万元，占公司最近一期经审计净资产的21.22%** 。

更严重的是——**倍轻松既没有进行临时公告，2024年年报也遗漏了3193.29万元的发生额和2533.29万元的余额** 。

最终，公司及相关责任人被罚款**合计1010万元**。

**⚠️ 核心教训：** 关联交易金额超过净资产20%却不披露——这不仅是违规，更是**严重的管理层诚信问题**。这样的公司，你敢投资吗？

**🔍 2026年真实案例：海南高速——关联交易调整，新增3.61亿元**

2026年7月，海南高速（000886）发布日常关联交易公告：因公司重大资产购买导致关联人范围变化，**拟对2026年度日常关联交易预计作出调整，调整后全年日常关联交易金额合计约16.38亿元，较调整前的12.77亿元增加3.61亿元，增幅约28.3%** 。

**启示：** 关联交易不是“有”就不好，但要关注**金额是否过大、价格是否公允、程序是否合规**。

#### 3.3 对外担保——公司替别人“背的债”

**披露什么？** 公司为**非关联方或子公司**提供的担保。

**为什么担保很危险？**

因为**担保是“或有负债”** ——平时看不见，一旦被担保方还不上钱，担保方就要**替别人还债**。

**🔍 2026年真实案例：倍轻松——三次巨额担保，均未披露**

倍轻松案中，实际控制人马学军**三次指使公司向关联公司转账用于开立定期存单，并以相关存单为第三方公司提供质押担保**，担保金额分别为3024.75万元、3010.50万元、3022.50万元，**均占上市公司最近一期经审计净资产的7%以上**。

三次担保，**没有一次及时披露**。

**🔍 2026年真实案例：王府井——为合营公司提供1.1亿担保**

2026年7月，王府井（600859）公告：拟为合营公司佛山王府井紫薇港商业管理有限责任公司**按50%股权比例提供连带责任担保，担保额不超过1.1亿元**。

截至2026年6月30日，**公司对外担保总额11.27亿元，占净资产5.82%**。

**启示：** 王府井的担保占净资产不到6%，属于**可控范围**。但如果一家公司的对外担保总额**超过净资产的30%甚至50%** ，就要高度警惕了。

#### 3.4 重大合同——公司的“大单”和“大坑”

**披露什么？** 对公司经营有重大影响的**重大合同**（采购合同、销售合同、工程合同等）。

**🔍 2026年真实案例：行云科技——子公司签下55亿算力合同**

2026年7月1日，行云科技（300209）公告：控股子公司海南行云智算科技有限公司与VC客户签署《计算平台服务协议》及补充协议，**达成五年期算力租赁合作，合同含税总金额达55.08亿元**。

**启示：** 55亿的合同，对一个公司来说可能是**营收的几倍甚至几十倍**。但要注意：合同金额≠实际收入——要看合同执行进度、付款条件、违约风险。

**🔍 2026年真实案例：中国中车——516亿重大合同**

2026年6月30日，中国中车（601766）公告：公司及下属企业于近期（主要为2026年4-6月）**签订了若干项重大合同，合计金额约516.4亿元，约占公司2025年营业收入的18.9%**。

**启示：** 央企的“重大合同”动辄几百亿，说明其业务体量巨大。但也要关注——这些合同是否已经执行？回款情况如何？

#### 3.5 会计政策变更——游戏规则变了

**披露什么？** 公司**改变会计处理方法**（如折旧方法、收入确认方式等）。

**为什么会计政策变更很重要？**

因为**变更会计政策可以“美化”利润**——同样的业务，用不同的会计方法，利润可能差出几个亿。

**🔍 2026年真实案例：长高电气——会计核算方法变更，增厚利润2.6亿**

2026年6月，长高电气公告：**对参股公司会计核算方法变更**，从“长期股权投资”改为“交易性金融资产”。

这次变更导致：合并资产负债表中**长期股权投资减少4514.59万元，交易性金融资产增加3.06亿元**，**增加公司2026年半年度合并报表利润总额约2.6亿元**。

**⚠️ 核心教训：** **一个会计方法的变更，就能凭空“变出”2.6亿利润**——这不是公司赚了更多钱，只是**算账的方式变了**。遇到这种情况，一定要问：**这个变更合理吗？还是为了“美化”报表？**

#### 3.6 补税——利润的“隐形杀手”

**披露什么？** 公司因税务问题需要**补缴税款及滞纳金**。

**🔍 2026年真实案例：25家公司密集补税，总额超35亿**

2026年6月，A股市场掀起一轮**上市公司密集补税潮**。6月以来已有23家A股公司披露补税公告，**25家公司累计补缴税款及滞纳金超35亿元**。

其中：

| 公司 | 补税金额 | 占净利润比例 |
|---|---|---|
| **北大荒** | **14.1亿元** | 超过2025年全年净利润（11.66亿） |
| **华菱钢铁** | 6.96亿元 | — |
| **百济神州** | 4.46亿元 | — |

**北大荒**因下属16家农业分公司从非职工家庭农场取得的土地承包费收入，不应享受企业所得税优惠政策，**需补缴2021年至2025年期间企业所得税10.24亿元、滞纳金3.86亿元，合计14.1亿元**。

**消息披露后，北大荒连吃两个跌停**。

**启示：** 补税公告是**利润的“隐形杀手”** ——14.1亿的补税，直接超过了公司一年的净利润。如果你只看利润表上的“净利润11.66亿”，却忽略了“重要事项”里的补税公告，就会**严重高估公司的真实盈利能力**。

#### 3.7 股份回购与股东减持——“内部人”在做什么？

**披露什么？** 公司回购股票、大股东减持或增持股票。

**为什么重要？**

- **大股东减持** → 可能是“内部人觉得股价贵了”
- **大股东增持** → 可能是“内部人觉得股价便宜了”
- **公司回购** → 可能是“公司觉得股价被低估了”

**🔍 2026年真实案例：美的集团回购**

美的集团（00300.HK）于2026年7月1日**购回A股股份1,993,939股**。

**🔍 2026年真实案例：豪威集团回购A股**

2026年7月1日，豪威集团于上海证券交易所**回购A股195.62万股**，每股回购价94.72元至98.99元，总支付金额约**1.92亿元**。

**启示：** 回购不一定代表股价被低估——也可能是为了**稳定股价**或**用于股权激励**。要看回购的**目的**和**后续处理方式**（注销还是用于激励）。

#### 3.8 股权激励——给员工发“金手铐”

**披露什么？** 公司向员工授予股票期权或限制性股票的计划。

**为什么要关注股权激励？**

因为**股权激励会稀释现有股东的权益**——公司增发股票给员工，总股本变大了，你手里的股票占比就变小了。

**🔍 2026年真实案例：欣旺达——2026年股权激励计划**

2026年5月，欣旺达（300207）召开董事会薪酬与考核委员会会议，**审议通过了《2026年限制性股票与股票期权激励计划（草案）》及其摘要**。

**🔍 2026年真实案例：浙江福莱新材料——股票期权激励**

浙江福莱新材料2026年股票期权激励计划：**拟授予激励对象股票期权255.50万份，约占公司股本总额的0.85%**。

**启示：** 0.85%的稀释比例不算大，但如果一家公司**频繁推出股权激励计划**，累计稀释比例可能达到**5%甚至10%以上**——这就意味着你的权益在不断被摊薄。

#### 3.9 监管问询与处罚——监管层的“红牌警告”

**披露什么？** 公司收到交易所问询函、证监会立案调查或行政处罚。

**🔍 2026年真实案例：先导基电——股价异动+关联收购，遭上交所问询**

2026年7月1日，先导基电（600641）公告收到上交所问询函：**公司股票最近三个交易日收盘价涨幅偏离值累计超过20%** ，同时公司披露拟通过增资方式取得实控人持有的广东先导微电子科技有限公司50%以上控股权，**构成关联交易**。

上交所要求公司说明：**标的公司估值合理性、交易支付安排及对公司现金流影响、信息披露及内幕信息管理等问题**。

**启示：** 监管问询函是**监管层的“红牌警告”** ——说明监管层认为公司某些做法**有问题、需要解释**。收到问询函的公司，往往存在**信息披露不充分、交易定价不合理、内部管理不规范**等问题。

**🔍 2026年真实案例：近20家公司因信披违规被警示或立案**

2026年以来，已有**电科数字、杭萧钢构、亚辉龙、天普股份等近20家上市公司**及其高管或股东因信息披露“抢报、迟报、漏报”等违规行为，收到沪深交易所监管警示或被证监会立案调查。

其中，**天普股份**因涉嫌炒作人工智能热点概念，被监管问询并遭立案。此前，天普股份在2025年**股价大涨16倍**，位列2025年十大牛股第二位。

**启示：** “蹭热点”炒作股价——然后被监管层盯上、立案调查。**股价暴涨的背后，可能是信息披露的严重问题。**

#### 3.10 董责险——上市公司的新“标配”

**披露什么？** 公司为董事、监事、高级管理人员购买责任保险。

**🔍 2026年真实案例：年内超380家上市公司披露购买董责险**

董责险正逐渐成为A股上市公司的“标配”。截至2026年6月30日，**年内已有至少389家A股上市公司发布购买、拟购买董责险的公告**。

2025年全年，**共有643家A股上市公司发布公告披露购买董责险计划，同比增长19%** 。截至2025年底，**A股累计1753家上市公司公告披露购买董责险计划，渗透率达32%** 。

**为什么董责险突然火了？**

主要受两个因素推动：
1. **新公司法的施行**大幅提高了董监高的履职责任风险
2. **“长牙带刺”的严监管背景下**，证券虚假陈述诉讼日益增多

此外，《上市公司董事会秘书监管规则》自2026年5月24日起施行，**进一步压实了董秘作为“关键少数”的个人责任**。

**启示：** 董责险购买公告本身不是坏事——说明公司重视风险管理。但**大量公司集中购买董责险**，背后反映的是**监管趋严、董监高履职风险上升**的大趋势。


### 四、“重要事项”分析框架（傻瓜版）

当你打开一份年报的“重要事项”章节，按以下顺序“四连问”：

#### 第一问：公司在打什么官司？（诉讼风险）

| 情况 | 风险等级 |
|---|---|
| 无重大诉讼 | 🟢 低风险 |
| 有诉讼，涉案金额 < 净资产5% | 🟡 中等风险 |
| 有诉讼，涉案金额 > 净资产10% | 🔴 **高风险** |
| 有诉讼且涉及核心业务/专利 | 🔴 **极高风险** |

#### 第二问：公司跟“自己人”做了多少生意？（关联交易）

| 情况 | 风险等级 |
|---|---|
| 关联交易占比 < 5% | 🟢 低风险 |
| 关联交易占比 5%-20% | 🟡 中等风险（需关注定价公允性） |
| 关联交易占比 > 20% | 🔴 **高风险（可能存在利益输送）** |
| 关联交易未披露或披露不完整 | 🔴 **极高风险（严重违规）** |

#### 第三问：公司替别人背了多少债？（对外担保）

| 情况 | 风险等级 |
|---|---|
| 担保总额 < 净资产10% | 🟢 低风险 |
| 担保总额 10%-30% | 🟡 中等风险 |
| 担保总额 > 净资产30% | 🔴 **高风险** |
| 担保对象是关联方或经营困难企业 | 🔴 **极高风险** |

#### 第四问：公司最近被监管层“盯上”了吗？

| 情况 | 含义 |
|---|---|
| 收到问询函 | 监管层认为有事项需要解释 ⚠️ |
| 被监管警示 | 已经违规，但情节较轻 ⚠️⚠️ |
| 被立案调查 | 涉嫌严重违规 🔴🔴🔴 |
| 收到行政处罚 | 违规事实已认定，面临罚款 🔴🔴🔴 |


### 五、核心要点速记
```
┌─────────────────────────────────────────────────────────────┐
│ 重要事项“五字诀” │
├─────────────────────────────────────────────────────────────┤
│ │
│ 诉 —— 官司缠身要警惕，涉案金额看比例 │
│ 关 —— 关联交易防输送，披露完整才放心 │
│ 担 —— 对外担保是地雷，超过三成要回避 │
│ 税 —— 补税公告是杀手，利润可能被吞噬 │
│ 罚 —— 监管问询是红牌，立案调查赶紧跑 │
│ │
│ ⚠️ 记住：利润可以“算”出来，但官司、担保、补税—— │
│ 这些是真金白银的风险，骗不了人 │
│ │
│ ⚠️ 记住：一家公司财报再漂亮，如果“重要事项”里 │
│ 藏着未披露的诉讼、违规的关联交易、巨额的担保—— │
│ 那就是一颗随时可能爆炸的“定时炸弹” │
│ │
└─────────────────────────────────────────────────────────────┘
```


**读懂“重要事项”，就是看懂一家公司“不能说的秘密”——那些不在三张主表里、却可能随时引爆的风险。在投资的世界里，知道“哪里有坑”，比知道“哪里有钱”更重要。**
