# 25-相对估值vs绝对估值（第27-30章 & 第15-21章）-中国适用性判断

> **适用性判断**：⚠️ **两者均适用，但均需改造**
> **核心提醒**：绝对估值告诉你“公司值多少钱”，相对估值告诉你“市场愿意为同类公司付多少钱”。两者结合使用是估值的最佳实践——单独使用任何一种都有重大缺陷。在中国市场，绝对估值受制于预测不确定性，相对估值受制于可比标的稀缺和A股整体估值泡沫化，但两者的**交叉验证**可以提供最有价值的投资决策参考。


## 第一部分：总 · 核心框架与结论

### 📌 开篇 · 一句话定调

**绝对估值是“称重机”——它告诉你公司本身值多少钱；相对估值是“投票机”——它告诉你市场愿意为同类公司付多少钱。聪明的投资者同时使用两者，当两者指向同一方向时，就是最佳击球区。**

格雷厄姆原话：“证券市场的估价过程经常是不合常理甚至是谬误的，而这一过程是心理作用的结果，是在参与买卖的投资者头脑中发生的。”

关键洞察：格雷厄姆在《证券分析》中既使用了绝对估值的思维（DCF哲学基础、资产覆盖分析），也大量使用了相对估值的思维（PE、PB比较、同行业对比分析）。他从未将两者对立，而是将它们视为**互补的工具**。在A股这个高波动、估值分化极端的市场，单独使用任何一种估值方法都有重大缺陷，但两者的交叉验证可以提供最有价值的决策参考。

### 🎯 中国实践的总结论

| 序号 | 核心结论 |
|:---:|:---|
| 1 | **绝对估值在A股高度受限**——预测期短、折现率波动大、终值占比过高，计算结果“差之毫厘，谬以千里”；但在稳定型行业（银行、公用事业）仍有效 |
| 2 | **相对估值在A股需要“锚点改造”** ——A股整体估值偏高、可比标的稀缺，直接套用美股标准或行业均值可能导致系统性误判；需结合港股/全球同类公司定价调整 |

| 4 | **A股的极端分化使相对估值更需谨慎**——同一行业，龙头与跟风者估值可能差3-5倍，简单用“行业平均PE”来判断个别公司是否低估，可能是致命错误 |


## 第二部分：分 · 绝对估值 vs 相对估值

### 第一章：绝对估值（Absolute Valuation）——DCF及其思想根源

#### 1.1 绝对估值的定义与核心逻辑

> **绝对估值 = 基于公司自身基本面计算的内在价值，独立于市场定价。**

核心逻辑：公司价值由其**未来创造的现金流**决定，与市场情绪、同类公司定价无关。如果算出的内在价值是100元，市场价格60元，就是被低估；市场价格150元，就是被高估。

**格雷厄姆与绝对估值的思想渊源**：

| 格雷厄姆的思想 | 与绝对估值的关系 |
|:---|:---|
| “企业价值取决于其偿付能力” | 偿付能力=未来产生现金流的能力 → DCF的哲学基础 |
| “用多年平均盈利剔除周期波动” | 用正常化盈利作为DCF的起点 |
| “安全边际=价格低于价值” | DCF算出的价值是安全边际的锚点 |
| “资产覆盖是最后的兜底” | 当DCF不可靠时，用清算价值作为底 |

#### 1.2 绝对估值的主要方法

| 方法 | 适用场景 | 在A股的适用性 |
|:---|:---|:---|
| **DCF（自由现金流折现）** | 现金流稳定、可预测的公司 | ⚠️ 有限适用（预测不确定、终值占比过高） |
| **DDM（股息折现模型）** | 稳定分红的公司 | ✅ 适用于银行、公用事业等高股息公司 |
| **资产重估（NAV/SOTP）** | 资产型公司、控股型公司 | ✅ 适用于资源股、地产股、国企改革标的 |
| **清算价值（NCAV）** | 极端低估的“烟蒂” | ⚠️ A股机会稀少，偶现于极端熊市 |

#### 1.3 绝对估值在A股的“三大挑战”

| 挑战 | 具体表现 | 影响 |
|:---|:---|:---|
| **预测不确定性** | 分析师只敢预测3-5年，终值常超70% | 估值结果高度依赖不可验证的假设 |
| **折现率波动大** | 无风险利率从3.5%→1.7%，ERP波动剧烈 | 折现率微小变化导致估值结果大幅波动 |
| **永续假设不成立** | A股公司寿命短、政策风险高 | “永续增长”假设脱离现实 |


### 第二章：相对估值（Relative Valuation）——市场定价的参照系

#### 2.1 相对估值的定义与核心逻辑

> **相对估值 = 基于可比公司或市场平均定价，判断当前价格在参照系中的位置。**

核心逻辑：在“市场有效”的假设下，同类公司的定价反映了市场对该类资产的共识。如果目标公司比同类公司更便宜，就是相对低估；比同类公司更贵，就是相对高估。

**格雷厄姆与相对估值的思想渊源**：

| 格雷厄姆的思想 | 与相对估值的关系 |
|:---|:---|:---|
| 第28-30章：PE使用标准 | PE是相对估值最核心的工具 |
| 第49章：同领域公司比较分析 | 直接奠定了相对估值的行业对比方法论 |
| 第28章：“PE作为筛选工具” | 相对估值是发现机会的起点 |

#### 2.2 相对估值的主要方法

| 方法 | 计算公式 | A股适用性 | 中国化改造要点 |
|:---|:---|:---|:---|
| **PE（市盈率）** | 价格 ÷ 每股盈利 | ✅ 适用（需结合盈利质量） | 用5年平均盈利、扣非净利润计算 |
| **PB（市净率）** | 价格 ÷ 每股净资产 | ✅ 适用（需结合ROE） | 用调整后有形净资产、PB-ROE框架 |
| **PS（市销率）** | 价格 ÷ 每股营收 | ⚠️ 适用于尚未盈利的成长股 | 需结合毛利率和增长预期 |
| **PEG（市盈率相对盈利增长比率）** | PE ÷ 增长率 | ✅ 适用于成长股 | 增长率需保守估计 |
| **EV/EBITDA** | 企业价值 ÷ EBITDA | ✅ 适用于资本密集型行业 | 排除折旧/摊销/资本结构差异 |
| **行业对比** | 与同行业均值/中位数对比 | ✅ 格雷厄姆第49章的核心理念 | 需区分“龙头溢价”与“泡沫” |

#### 2.3 相对估值在A股的“五大挑战”

| 挑战 | 具体表现 | 影响 |
|:---|:---|:---|
| **A股整体估值偏高** | A股整体PE高于全球主要市场 | 用A股自身历史做锚点，可能系统性高估 |
| **可比标的稀缺** | 很多A股公司在全球没有真正的可比公司 | 无法用“全球对标”来验证估值 |
| **行业内部估值分化极端** | 同一行业龙头PE 30倍，跟风者PE 50倍 | “行业平均”失去参照意义 |
| **政策溢价/折价无法量化** | 政策支持行业享有政策溢价 | 相对估值无法区分政策溢价和泡沫 |
| **情绪化定价严重** | 市场狂热时所有PE都被推高 | 相对估值变成情绪放大器而非价值工具 |


### 第三章：格雷厄姆的“三维交叉验证”方法论

#### 3.1 格雷厄姆的底层逻辑

格雷厄姆从未将绝对估值和相对估值对立。他的方法论是：**同时从资产、盈利、股息三个维度出发，交叉验证后得出一个“价值区间”，然后用市场价格与这个区间的差距来判断安全边际。**

| 维度 | 绝对估值对应 | 相对估值对应 | 格雷厄姆的具体工具 |
|:---|:---|:---|:---|
| **资产维度** | 清算价值、NCAV、资产重估 | PB对比、行业PB对比 | 第42-45章：资产负债表分析 |
| **盈利维度** | DCF哲学、正常化盈利 | PE对比、行业PE对比、成长股公式 | 第27-30章：PE使用标准 |
| **股息维度** | DDM | 股息率对比、行业股息率对比 | 第38章：V=M(D+1/3E) |

#### 3.2 “三维交叉验证”的决策逻辑
```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 格雷厄姆“三维交叉验证”决策矩阵 │
├─────────────────────────────────────────────────────────────────────────────┤
│ │
│ 资产维度估值 ────┐ │
│ │ │
│ 盈利维度估值 ────┼───→ 价值区间（交叉验证后）───→ 市场价格 ───→ 安全边际 │
│ │ │
│ 股息维度估值 ────┘ │
│ │
│ ┌───────────────────────────────────────────────────────────────────────┐ │
│ │ 💡 三个维度指向同一方向 = 高置信度决策 │ │
│ │ 💡 三个维度指向不同方向 = 需要更高的安全边际来补偿不确定性 │ │
│ └───────────────────────────────────────────────────────────────────────┘ │
│ │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 第四章：A股实战中的估值方法选择矩阵

#### 4.1 按公司类型选择估值方法

| 公司类型 | 首选估值方法 | 辅助验证方法 | A股典型 |
|:---|:---|:---|:---|
| **稳定型（类债券）** | DDM + 股息率 | PB-ROE | 长江电力、国有大行 |
| **消费龙头型** | DCF（保守） | PE历史分位数 + 行业对比 | 贵州茅台、伊利股份 |
| **周期型** | 资产重估（NAV）+ 正常化PE | 行业PB对比 | 煤炭、化工、航运 |
| **成长/科技型** | PEG + PS | 退出倍数（EV/EBITDA） | 新能源、AI、半导体 |
| **资产型/控股型** | SOTP（分类加总估值法）+ 资产重估 | PB对比 | 资源股、国企改革标的 |
| **困境/烟蒂型** | 清算价值（NCAV） | PB对比 | 极端熊市中的“破净”股 |

#### 4.2 按市场环境选择估值方法

| 市场环境 | 估值方法选择 | 理由 |
|:---|:---|:---|
| **恐慌/熊市底部** | 绝对估值优先（资产兜底） | 市场定价已经不可信，需回归基本面 |
| **狂热/牛市顶部** | 相对估值+历史分位数 | 绝对估值已被乐观假设扭曲，需看市场相对位置 |
| **正常市况** | 绝对估值+相对估值交叉验证 | 两种方法都相对可靠，交叉验证提高置信度 |
| **极端分化市** | 相对估值（同行对比）+ 龙头溢价分析 | 需区分“合理的龙头溢价”与“泡沫” |

#### 4.3 A股实战估值流程：四步交叉验证法
```
📊 第一步：定性判断（能力圈）
├── 理解商业模式、行业格局、竞争壁垒
├── 判断公司的生命周期阶段（成长期/成熟期/衰退期）
└── 判断公司是否在自己的能力圈内

📊 第二步：绝对估值（内在价值锚）
├── 选择适合的绝对估值方法（DCF/DDM/资产重估/SOTP）
├── 用保守假设计算内在价值区间
└── 计算当前价格与内在价值区间的差距

📊 第三步：相对估值（市场定价锚）
├── 选择适合的相对估值方法（PE/PB/PEG/EV/EBITDA）
├── 与历史分位数对比
├── 与同行业A股公司对比
└── 与港股/全球同类公司对比（可选）

📊 第四步：交叉验证与决策
├── 绝对估值和相对估值是否指向同一方向？
│ ├── 是 → 高置信度决策，安全边际可以适当放宽
│ └── 否 → 低置信度决策，需要更大的安全边际
├── 三个维度（资产+盈利+股息）是否都支持？
└── 最终决策：价格是否提供了足够的安全边际？
```


### 第五章：中国案例库——两种估值方法的实战应用

#### 🇨🇳 案例一：A股银行股（2023-2026年）——绝对估值与相对估值的双重验证

**背景**：2023-2026年，A股银行板块普遍“破净”，PE仅4-5倍，股息率超5%。

| 估值方法 | 评估结果 | 分析 |
|:---|:---|:---|
| **绝对估值（DDM）** | ✅ 被低估 | 股息率5.16% vs 无风险利率1.71%，息差超3个百分点 |
| **绝对估值（资产重估）** | ✅ 显著被低估 | PB 0.4-0.6倍，资产质量被过度悲观定价 |
| **相对估值（历史分位数）** | ✅ 被低估 | PB处于历史10%分位以下 |
| **相对估值（全球对比）** | ✅ 被低估 | 全球银行平均PB约0.8-1.0倍，A股银行更低 |
| **三维交叉验证结论** | ✅✅✅ 三个维度同时指向低估 | **高置信度机会** |

**结果**：2024年以来银行股集体估值修复，部分银行涨幅超50%。

#### 🇨🇳 案例二：某新能源龙头（2021年）——绝对估值与相对估值的分歧

**背景**：2021年，某新能源龙头PE高达80-100倍，市场情绪极度乐观。

| 估值方法 | 评估结果 | 分析 |
|:---|:---|:---|
| **绝对估值（DCF）** | ❌ 显著高估 | 即使最乐观假设（30%增长持续10年），DCF估值也远低于市价 |
| **相对估值（历史分位数）** | ❌ 历史最高 | PE处于历史100%分位 |
| **相对估值（全球对比）** | ❌ 显著高于全球同行 | 全球同行PE约30-40倍 |
| **三维交叉验证结论** | ❌❌❌ 三个维度同时指向高估 | **高置信度的泡沫信号** |

**结果**：随后2-3年该股票跌幅超50%，估值回归均值。

#### 🇨🇳 案例三：某周期龙头（行业高点）——相对估值的陷阱

**背景**：某周期龙头在行业景气高点PE仅5-6倍，PB约2倍，看似“极度低估”。

| 估值方法 | 评估结果 | 分析 |
|:---|:---|:---|
| **绝对估值（正常化PE）** | ⚠️ 合理或偏高 | 用10年平均盈利计算，PE约12-15倍 |
| **相对估值（PE历史分位数）** | ✅ 看似低估 | PE处于历史10%分位以下，但盈利处于周期顶部 |
| **相对估值（PB对比）** | ⚠️ 需谨慎 | PB 2倍，高于周期底部时的0.5倍 |
| **三维交叉验证结论** | ⚠️⚠️⚠️ 相对估值“看起来低”，但绝对估值“并不低” | **低置信度机会，需要更高安全边际** |

**结果**：随后行业进入下行周期，盈利断崖式下滑，PE从5倍变成20倍，股价下跌超60%。

> **💡 核心认知**：这个案例完美展示了绝对估值和相对估值结合使用的价值——如果只看相对估值（PE低），你会掉入价值陷阱；如果使用绝对估值（正常化盈利），你会看到真正的估值水平。


## 第三部分：总 · 知行合一与落地工具箱

### 📋 实战“估值方法选择体检卡”

| 检查项 | ✅ 最佳实践 | ⚠️ 需谨慎 | ❌ 需避免 |
|:---|:---|:---|:---|
| **是否同时使用了绝对估值和相对估值？** | 两者都用了，交叉验证 | 只用了其中一种 | 没有估值，凭感觉 |
| **绝对估值的假设是否保守？** | 保守假设，多情景分析 | 中性假设 | 过于乐观假设 |
| **相对估值的锚点是否合理？** | 全球对标+行业对比+历史分位数 | 只用行业对比或历史分位数 | 只用A股自身历史（系统性高估） |
| **是否识别了相对估值中的“系统性误差”？** | 考虑了A股整体估值偏高的因素 | 有意识但未调整 | 完全忽略 |
| **是否考虑了公司生命周期阶段？** | 根据生命周期选择估值方法 | 有意识但执行不严格 | 用同一方法套所有公司 |

### 🔄 季度“估值方法有效性跟踪卡”

| 检查维度 | 🟢 有效 | 🔴 失效 |
|:---|:---|:---|
| **绝对估值 vs 实际价格** | 价格在内在价值区间内波动 | 价格持续偏离内在价值区间（情绪极端） |
| **相对估值 vs 历史分位数** | 在合理区间内波动 | 持续在极端分位数 |
| **三维交叉验证** | 三个维度指向一致 | 三个维度指向不一致 |
| **需要调整估值方法？** | 公司特征未变，继续使用 | 公司特征变化（如从成长进入成熟期） |

### 🎯 终极一句话心法

> **绝对估值是“锚”，告诉你公司本身值多少钱；相对估值是“参照系”，告诉你市场在同类资产上怎么定价。单独使用任何一种都不可靠，交叉验证才是关键——当两者指向同一方向时，是高质量决策信号；当两者指向不同方向时，需要更高的安全边际来补偿不确定性。在A股这个估值分化极端的市场，没有一种估值方法可以单打独斗。**

### 🏁 结语

格雷厄姆在《证券分析》中从未将绝对估值和相对估值对立。他在第15-21章（债券估值）中强调基于偿付能力的绝对价值判断；在第27-30章（PE使用）中又大量使用相对估值的思维；在第49章（同领域公司比较分析）中更是直接奠定了相对估值中“行业对比”的方法论基础。

对于A股投资者，两种估值方法的组合使用尤为关键：

**第一**，绝对估值在A股高度受限——预测期短、折现率波动大、终值占比过高——但在稳定型行业（银行、公用事业）依然有效。它提供了一个**独立于市场情绪的“锚”** ，让你在恐慌时不至于过度悲观，在狂热时不至于过度乐观。

**第二**，相对估值在A股需要“锚点改造”——直接用A股自身历史分位数可能系统性高估，因为A股整体估值长期高于全球市场。需要结合港股/全球同类公司定价来调整判断。在A股估值极端分化的环境下，**行业内部的可比分析比跨行业的简单PE比较更有价值**。

**第三**，格雷厄姆的“三维交叉验证”方法论——从资产、盈利、股息三个维度同时评估——是A股最实用的估值实践。当三个维度指向同一方向时，决策置信度大幅提升；当三个维度指向不同方向时，需要更高的安全边际来补偿不确定性。

> **在A股，没有一种估值方法可以单打独斗。绝对估值提供“锚”，相对估值提供“参照系”，交叉验证提供“置信度”——三者结合，才是A股估值的最佳实践。**
