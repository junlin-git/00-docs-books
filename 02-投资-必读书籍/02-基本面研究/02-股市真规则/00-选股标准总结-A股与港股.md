## 一、通用选股框架总览

《股市真规则》的核心逻辑：**先找好生意，再找好价格，最后控制风险**。

```
优质商业模式（护城河）
       ↓
健康财务数据（真实盈利）
       ↓
合理估值（MOS安全边际）
       ↓
行业顺风 + 催化剂存在
       ↓
风险量化 + 仓位匹配
       ↓
买入并持续追踪
```

**五大核心支柱：**

| 支柱 | 核心问题 | 权重 |
|------|---------|------|
| 商业模式 | 这家公司凭什么赚钱，护城河有多宽？ | ★★★★★ |
| 财务质量 | 数字是否真实，现金流是否健康？ | ★★★★★ |
| 成长空间 | 未来3~5年增长从哪里来？ | ★★★★ |
| 估值安全 | 现在的价格是否给了足够折扣？ | ★★★★ |
| 风险边界 | 最坏情况是什么，能否承受？ | ★★★★ |

## 二、A股选股标准（完整版）

### 2.1 商业模式与护城河（第一关）

**必须满足以下至少2项护城河来源：**

| 护城河类型 | 判断标准 | 举例行业 |
|-----------|---------|---------|
| 无形资产（品牌/专利） | 品牌溢价率 > 15%，或核心专利覆盖主营业务 | 白酒、医药、消费 |
| 网络效应 | 用户越多价值越大，切换成本极高 | 互联网平台、支付 |
| 成本优势 | 同品质下成本比竞争对手低 > 10% | 化工、制造业龙头 |
| 客户转换成本 | 客户更换供应商的隐性成本极高 | ToB软件、工业气体 |
| 规模效应 | 收入规模越大，边际成本越低 | 零售、物流 |
| 高效流程 | 独特流程难以复制，形成运营壁垒 | 专业服务、精密制造 |

**护城河宽度评级（必须达到"宽护城河"或"窄护城河+高成长"）：**

- 🟢 **宽护城河**：竞争优势可维持10年以上，ROIC持续 > 15%
- 🟡 **窄护城河**：竞争优势可维持5~10年，ROIC持续 > 10%
- 🔴 **无护城河**：直接淘汰，不考虑

**A股特殊注意事项：**
- 白酒、中药等传统品牌行业，品牌护城河在A股具有极强定价权，重点关注
- 国有企业护城河评估需额外考虑政策保护因素（如牌照垄断）
- 避免"伪护城河"：纯靠补贴维持的规模、靠关系维持的渠道

### 2.2 财务质量（第二关）

#### 2.2.1 盈利质量三核心

**① 利润含金量检验（必须全部通过）：**

```
经营现金流 / 净利润 ≥ 1.0（最低0.8）
```
- 低于0.8：利润可能虚假，立即警惕
- 低于0.5：基本可认定利润质量极差，一票否决

**② 应收账款健康度：**

```
应收账款增速 ≤ 营收增速（正常情况）
应收账款周转天数 ≤ 行业平均水平
```
- A股重点警惕：应收账款占营收比例 > 30% 且持续增长 → 高风险信号

**③ 收入真实性验证：**

```
营收增速与行业增速的偏差 < ±30%（超过需特别解释）
毛利率是否与同行一致（±5%内为正常）
```

#### 2.2.2 核心财务指标门槛（A股）

| 指标 | 最低标准 | 优质标准 | 备注 |
|------|---------|---------|------|
| ROE（净资产收益率） | ≥ 12% | ≥ 20% | 连续3年达标 |
| ROIC（投入资本回报率） | ≥ 10% | ≥ 15% | 高于资金成本(WACC) |
| 毛利率 | ≥ 30% | ≥ 50% | 制造业≥20%可接受 |
| 净利率 | ≥ 8% | ≥ 15% | 不同行业差异大 |
| 资产负债率 | ≤ 60% | ≤ 40% | 金融行业除外 |
| 流动比率 | ≥ 1.5 | ≥ 2.0 | |
| 速动比率 | ≥ 1.0 | ≥ 1.5 | |
| 自由现金流 | 连续3年为正 | 持续增长 | FCF = 经营CF - 资本支出 |
| 负债/EBITDA | ≤ 3倍 | ≤ 2倍 | 重资产行业可放宽至4倍 |

#### 2.2.3 杜邦分析三要素

```
ROE = 净利率 × 资产周转率 × 权益乘数
```

**A股优质企业特征（来源于盈利能力，而非财务杠杆）：**
- 净利率驱动型：消费、医药、科技（最优）
- 周转率驱动型：零售、制造（次优）
- 杠杆驱动型：警惕，负债扩张型ROE不可持续

#### 2.2.4 财务造假红旗信号（A股专项）

以下任意一项出现 → **直接否决**：

- [ ] 应收账款/营收比率持续上升超3年
- [ ] 审计师出具非标意见
- [ ] 经营现金流长期为负但利润为正
- [ ] 关联交易占营收 > 20%
- [ ] 实控人频繁质押股份（质押比例 > 50%）
- [ ] 频繁更换审计师或财务总监
- [ ] 商誉占总资产 > 30%（高并购风险）
- [ ] 存货大幅异常增长（与营收不匹配）
- [ ] 货币资金充裕但大量借债（资金被占用信号）

### 2.3 成长性分析（第三关）

#### 2.3.1 成长股三要素

**① 市场空间（TAM - 总可寻址市场）：**

```
目标市场规模 ≥ 公司当前营收的 10倍（理想）
公司市占率 < 30%（仍有提升空间）
```

**② 可持续成长驱动因素（至少满足1项）：**

| 驱动类型 | 判断方式 |
|---------|---------|
| 量的扩张 | 产能扩张、门店扩张、新客户增长 |
| 价的提升 | 产品升级、提价能力、结构改善 |
| 新市场渗透 | 地理扩张、品类扩展 |
| 行业整合 | 龙头市占率提升（竞争格局改善） |

**③ 成长质量检验：**

```
有机成长（内生增长）> 并购成长（外延增长）→ 优质
净利润增速 ≥ 营收增速（利润率改善中）→ 优质
研发投入占比持续提升（科技型企业）→ 加分
```

#### 2.3.2 A股成长股分类标准

| 类型 | 营收增速 | 净利润增速 | 适合策略 |
|------|---------|---------|---------|
| 超高速成长 | > 40% | > 40% | 高估值可接受，重点跟踪 |
| 高速成长 | 20%~40% | 20%~40% | PEG ≤ 1.5合理 |
| 稳健成长 | 10%~20% | 10%~20% | PE ≤ 25倍合理 |
| 低速成长 | < 10% | < 10% | 需高股息补偿，否则不考虑 |

**PEG判断标准：**
```
PEG = PE / 净利润增速（%）
PEG ≤ 1.0 → 低估，可买入
PEG 1.0~1.5 → 合理，可持有
PEG > 2.0 → 高估，谨慎
```

### 2.4 估值分析（第四关）

#### 2.4.1 多方法估值体系

**A股优先使用的估值方法：**

| 方法 | 适用场景 | 关键参数 |
|------|---------|---------|
| DCF（现金流折现） | 现金流稳定的成熟企业 | 折现率10%~12%，终值增长率3% |
| PE估值法 | 消费、医药、科技 | 对比历史PE + 行业PE |
| PB估值法 | 银行、地产、重资产 | PB<1可关注 |
| EV/EBITDA | 制造业、重资产行业 | 同行业横向对比 |
| PS估值法 | 高成长但亏损企业 | 谨慎使用 |
| 股息贴现模型 | 高股息稳定型企业 | 股息增长率 + 折现率 |

#### 2.4.2 安全边际要求（A股）

```
买入价格 ≤ 内在价值 × 70%（折价30%以上）
理想情况：折价40%~50%
```

**A股行业参考估值区间（历史合理PE中枢）：**

| 行业 | 合理PE区间 | 高估警戒线 | 低估买入线 |
|------|-----------|-----------|-----------|
| 白酒龙头 | 25~40倍 | > 50倍 | < 20倍 |
| 消费品 | 20~35倍 | > 45倍 | < 15倍 |
| 医药生物 | 25~45倍 | > 60倍 | < 20倍 |
| 科技/半导体 | 30~60倍 | > 80倍 | < 25倍 |
| 银行 | 5~10倍 | > 12倍 | < 6倍 |
| 地产 | 6~12倍 | > 15倍 | < 5倍 |
| 制造业 | 15~25倍 | > 35倍 | < 10倍 |
| 公用事业 | 12~18倍 | > 22倍 | < 10倍 |

#### 2.4.3 估值陷阱识别（A股）

- **周期股**：不能用低PE买入，应在高PE（行业低谷）时买入
- **概念股**：无收入支撑的高PS股，远离
- **壳资源**：A股特有，小市值壳价值随注册制推进持续下降
- **高商誉**：并购溢价过高，商誉减值风险巨大

### 2.5 行业分析（第五关）

#### 2.5.1 行业选择五力分析

**Porter五力 → 选择竞争力弱的行业中的强者：**

| 力量 | 理想状态（利于龙头） |
|------|-------------------|
| 新进入者威胁 | 极低（高壁垒行业） |
| 替代品威胁 | 极低（无替代品） |
| 供应商议价权 | 极低（原材料分散） |
| 客户议价权 | 极低（品牌忠诚度高） |
| 行业内竞争 | 低（寡头格局） |

#### 2.5.2 A股行业景气度判断

**顺势而为原则：**

```
优先选择：景气度上行 + 政策支持 + 行业集中度提升的行业
回避：产能过剩 + 价格战激烈 + 强监管打压的行业
```

**A股政策敏感行业特别注意：**
- 教育、游戏、互联网平台：监管变化风险极高，需持续跟踪政策
- 新能源、半导体：政策红利明显，但补贴退潮风险需评估
- 地产：政策调控直接影响基本面，需单独评估政策周期

#### 2.5.3 行业生命周期定位

| 阶段 | 特征 | 投资策略 |
|------|------|---------|
| 导入期 | 高增长、不盈利 | 极度谨慎，小仓位试探 |
| 成长期 | 高增长、开始盈利 | 重点布局，可接受高估值 |
| 成熟期 | 稳增长、高盈利 | 精选龙头，关注股息 |
| 衰退期 | 负增长或零增长 | 回避，除非困境反转逻辑 |

### 2.6 市场情绪与择时（第六关）

#### 2.6.1 A股市场情绪指标

**宏观情绪温度计：**

| 指标 | 过热信号（卖出参考） | 过冷信号（买入参考） |
|------|-------------------|-------------------|
| 沪深两市日成交额 | > 1.5万亿 | < 5000亿 |
| 股票型基金发行规模 | 单只 > 200亿 | 市场乏人问津 |
| 市场新增开户数 | 周度 > 100万 | 极低位 |
| 全市场PE百分位 | > 80% | < 20% |
| 融资余额/流通市值 | > 3.5% | < 2% |

**A股特有情绪信号：**
- 亲朋好友纷纷讨论股票 → 市场接近顶部
- 散户亏损严重、媒体悲观 → 市场接近底部
- 涨停板数量持续 > 200 → 过热
- 跌停板数量持续 > 100 → 恐慌底部区域

#### 2.6.2 择时辅助指标

**不做精准择时，但用以下指标辅助判断大方向：**

```
宏观择时：
- 利率周期（降息周期对股市有利）
- 信贷周期（社融增速回升 → 经济复苏信号）
- 盈利周期（企业盈利增速拐点）
- 估值周期（全市场PE/PB历史分位）
```

## 三、港股选股标准（完整版）

### 3.1 港股市场特殊性认知（前提）

**港股与A股核心差异，影响选股逻辑：**

| 维度 | A股特征 | 港股特征 | 影响 |
|------|---------|---------|------|
| 投资者结构 | 散户为主（~70%） | 机构为主（~70%） | 港股更理性，波动更大 |
| 流动性 | 整体充裕 | 分化严重（中小盘流动性差） | 港股小盘溢价反为折价 |
| 估值体系 | 情绪驱动强 | 与国际接轨，更看盈利 | 港股估值普遍低于A股 |
| 退市制度 | 极难退市 | 退市较多 | 港股小市值垃圾股风险更高 |
| 做空机制 | 受限 | 发达 | 港股真实反映负面信息更快 |
| 汇率风险 | 无 | 港币/人民币汇率 | 需考虑汇率对冲 |
| 信息透明度 | 较低（中文为主） | 较高（中英双语） | 港股信息获取需更强能力 |

---

### 3.2 商业模式与护城河（港股版）

**港股护城河评估重点与A股差异：**

1. **机构投资者视角**：港股机构主导，护城河需经受更严格的国际机构审视
2. **国际竞争维度**：港股企业往往面临国际竞争者，护城河需更宽
3. **中概股回归港股**：重点评估在内地的竞争壁垒是否依然有效

**港股特有的护城河来源：**

| 护城河类型 | 港股典型案例 | 判断标准 |
|-----------|-----------|---------|
| 内地市场准入 | 内地业务强势的港股 | 市场准入壁垒是否可持续 |
| 跨境资本通道 | 金融、保险类港股 | 政策许可的独特优势 |
| 国际品牌背书 | 在港上市的全球品牌 | 品牌国际认可度 |
| 离岸人民币业务 | 香港特色金融 | 政策支持的稀缺资源 |

---

### 3.3 财务质量（港股版）

#### 3.3.1 港股财务指标门槛

| 指标 | 最低标准 | 优质标准 | 备注 |
|------|---------|---------|------|
| ROE | ≥ 10% | ≥ 15% | 港股整体ROE低于A股 |
| ROIC | ≥ 8% | ≥ 12% | 超过WACC即可 |
| 毛利率 | ≥ 25% | ≥ 40% | 行业差异大 |
| 净利率 | ≥ 6% | ≥ 12% | |
| 资产负债率 | ≤ 65% | ≤ 45% | |
| 股息率 | ≥ 3% | ≥ 5% | 港股高股息是重要回报来源 |
| 自由现金流 | 连续3年为正 | 持续增长 | |
| 派息比率 | ≥ 30% | ≥ 50% | 港股重视股东回报 |

**港股财务特殊关注点：**

```
① IFRS准则 vs 中国会计准则差异：
   - 港股采用IFRS，部分科目与A股不同
   - 重点关注：收入确认方式、租赁负债（IFRS16影响）

② 外币收入风险：
   - 主要收入/成本是否与港币/美元匹配
   - 汇率敞口对利润的影响程度

③ 港股H股/红筹股分红：
   - 分红需缴纳预扣税（境外投资者）
   - 实际到手股息率需扣除税费
```

#### 3.3.2 港股财务造假红旗（特别关注）

港股做空机构（浑水、GMT等）常用的发现造假指标：

- [ ] 现金余额与利息收入不匹配（高现金但利息收入极低）
- [ ] 税率异常低（盈利企业税率 < 5%，需解释）
- [ ] 资本支出与折旧严重不匹配
- [ ] 审计师为小型本地事务所（非四大或知名所）
- [ ] 关联方交易复杂、不透明
- [ ] 公司披露信息与行业数据差异过大
- [ ] 高层频繁离职（尤其CFO）
- [ ] 实控人减持、大规模配股（在低价时）

### 3.4 成长性分析（港股版）

#### 3.4.1 港股成长股分类

**港股成长股特殊分类（结合港股市场特性）：**

| 类型 | 代表 | 核心判断逻辑 |
|------|------|-----------|
| 中概回归成长股 | 互联网平台 | 内地业务护城河 + 股东回报政策 |
| 内地消费出海股 | 消费品牌 | 海外市场渗透率 + 品牌溢价 |
| 大湾区受益股 | 地产/金融 | 政策红利 + 跨境流动受益 |
| 高股息成长股 | 公用事业/电信 | 股息稳定 + 低估值 |
| 港股独有稀缺股 | 仅在港上市 | 稀缺性溢价 + 基本面 |

#### 3.4.2 港股成长股门槛

```
营收增速 ≥ 15%（可接受，港股成长股估值给的比A股低）
净利润增速 ≥ 10%
PEG ≤ 1.2（港股估值比A股保守）
股息率 ≥ 2%（即使成长股也应有基础分红意识）
```

### 3.5 估值分析（港股版）

#### 3.5.1 港股估值折价认知

**港股系统性折价原因：**
1. 流动性折价（部分港股交投稀少）
2. 结构性折价（机构主导，不炒概念）
3. 地缘政治风险折价
4. 汇率风险折价

**合理的折价范围（相对A股AH溢价参考）：**
```
AH溢价率 = (A股价格 - H股价格) / H股价格 × 100%
历史均值约 30%~40%
AH溢价率 > 50% → H股明显低估，可关注
AH溢价率 < 10% → H股估值已与A股接近，折价优势消失
```

#### 3.5.2 港股行业参考估值（合理PE区间）

| 行业 | 合理PE区间 | 高估警戒线 | 低估买入线 |
|------|-----------|-----------|-----------|
| 互联网平台 | 15~30倍 | > 40倍 | < 12倍 |
| 内地消费 | 15~28倍 | > 40倍 | < 12倍 |
| 医药/医疗 | 18~35倍 | > 50倍 | < 15倍 |
| 银行（国有） | 4~7倍 | > 10倍 | < 4倍 |
| 保险 | 8~15倍 | > 20倍 | < 6倍 |
| 地产 | 4~10倍 | > 15倍 | < 4倍 |
| 公用事业 | 10~16倍 | > 20倍 | < 8倍 |
| 电信运营商 | 8~14倍 | > 18倍 | < 7倍 |
| 能源 | 6~12倍 | > 18倍 | < 5倍 |

#### 3.5.3 港股安全边际要求

```
买入价格 ≤ 内在价值 × 65%（折价35%以上，比A股要求更高）
原因：港股流动性风险、做空风险均更大
```

**港股估值特别关注：**
- 股息率法更重要：稳定高股息港股，用股息贴现模型（DDM）
- 资产重估法：部分港股持有大量内地资产，需重估净资产
- 分拆重估法：港股集团股常有拆分机会，关注分拆价值释放

### 3.6 港股流动性与风险（特别章节）

#### 3.6.1 流动性筛选标准（港股必须通过）

```
日均成交额 ≥ 500万港元（最低门槛）
理想：日均成交额 ≥ 3000万港元
自由流通股比例 ≥ 25%
```

**港股流动性陷阱警示：**
- 大股东持股 > 70%：实际流通盘极小，操控风险高
- 频繁配股：摊薄现有股东权益，需高度警惕
- 股价长期横盘不动：流动性差的信号

#### 3.6.2 港股特有风险清单

| 风险类型 | 具体表现 | 应对措施 |
|---------|---------|---------|
| 做空风险 | 做空机构发布报告 | 建立反脆弱仓位，不用杠杆 |
| 流动性风险 | 买卖价差大，难以出手 | 严格遵守流动性门槛 |
| 退市风险 | 长期停牌、仙股 | 回避市值 < 20亿港元的小盘股 |
| 配股摊薄 | 低价大规模配股 | 关注公司融资历史 |
| 汇率风险 | 港元贬值（极小概率） | 长期持有自然对冲 |
| 地缘政治 | 中美关系影响港股情绪 | 分散配置、控制仓位 |

## 五、一票否决条件（红线清单）

### A股一票否决（任意一项即淘汰）

- ❌ 经营现金流/净利润 < 0.5（连续2年）
- ❌ 应收账款占营收比例 > 40%（非行业特殊情况）
- ❌ 实控人股权质押比例 > 70%
- ❌ 商誉占总资产 > 35%
- ❌ 审计师出具非标意见
- ❌ 资产负债率 > 80%（非金融行业）
- ❌ 近3年有重大违规、被立案调查
- ❌ 无护城河、无定价权、行业完全竞争
- ❌ 关联交易混乱、实控人资金占用
- ❌ PE > 行业历史估值90%分位（极度高估）

### 港股一票否决（任意一项即淘汰）

- ❌ 日均成交额 < 500万港元（流动性不足）
- ❌ 市值 < 20亿港元（退市风险、操控风险）
- ❌ 大股东持股 > 80%（流通盘过小）
- ❌ 3年内有配股 > 20%（摊薄过度）
- ❌ 审计师为小型本地事务所（非知名审计机构）
- ❌ 被做空机构发布重大做空报告且公司无有效回应
- ❌ 现金余额与利息收入严重不匹配
- ❌ 经营现金流/净利润 < 0.5（连续2年）
- ❌ 无股息或股息率 < 1%（成熟型企业）
- ❌ 股价长期停牌（超过30个交易日）

## 六、买入 / 卖出 / 持有决策树

### 买入决策（必须全部满足）

```
Step 1: 护城河 ≥ 窄护城河？        → 否 → 直接淘汰
Step 2: 财务红线全部通过？          → 否 → 直接淘汰
Step 3: 成长性满足对应分类标准？    → 否 → 转为观察池
Step 4: 当前估值 ≤ 内在价值×70%？  → 否 → 等待价格下跌
Step 5: 行业处于景气上行阶段？      → 否 → 可小仓位布局
Step 6: 仓位是否符合组合规则？      → 否 → 调整组合后再买
                                    → 全部是 → 可以买入
```

### 卖出决策（满足任意一项）

```
① 基本面恶化：护城河消失、财务数据持续恶化
② 估值过高：股价超出内在价值50%以上
③ 发现更好机会：机会成本更优的标的出现
④ 仓位过重：单只股票超过组合上限
⑤ 初始买入逻辑已被证伪
⑥ 持有期超过3年但基本面无改善（止损离场）
```

### 持有标准

```
① 护城河依然存在或在增强
② 财务数据健康，无恶化信号
③ 估值在合理区间（未极度高估）
④ 成长逻辑未被破坏
→ 持有，不因短期波动卖出
```

## 七、仓位与组合管理规则

### 7.1 单只股票仓位上限

| 级别 | 条件 | 最大仓位 |
|------|------|---------|
| 核心仓位 | 宽护城河 + 高确定性 + 低估值 | 不超过25% |
| 标准仓位 | 窄护城河 + 中确定性 + 合理估值 | 不超过15% |
| 卫星仓位 | 高成长但不确定性高 | 不超过8% |
| 试探仓位 | 初步看好，尚需验证 | 不超过3% |

### 7.2 组合多样化要求

```
行业分散：单一行业不超过35%
市场分散：A股/港股可各自独立组合，或混合组合
市值分散：大盘 ≥ 50%，中盘 ≤ 35%，小盘 ≤ 15%
持仓数量：精选10~20只（不宜过多分散，也不宜过度集中）
```

### 7.3 加仓与减仓规则

**加仓条件：**
```
① 股价下跌10%~20%，基本面未变 → 可加仓至上限
② 业绩超预期，估值仍合理 → 可加仓
③ 护城河有新的加强信号 → 可加仓
```

**减仓条件：**
```
① 单只股票涨幅超过组合平均20个百分点 → 部分减仓
② 估值接近历史高位 → 减半仓位
③ 基本面出现黄旗（非红线）→ 减至1/3仓位观察
```

### 7.4 现金管理

```
正常市场：现金比例 5%~15%
市场高估（全市场PE > 80%分位）：现金提升至 25%~35%
市场极度低估（全市场PE < 20%分位）：现金降至 5%以下，满仓布局
```

## 八、常见投资误区警示

### 8.1 认知误区

| 误区 | 正确认知 |
|------|---------|
| 股价低就是便宜 | 便宜要看估值，不是绝对价格 |
| 名气大的公司就是好公司 | 好公司≠好股票，关键在买入价格 |
| 分散越多越安全 | 过度分散导致业绩平庸，精选 > 广撒网 |
| 短期亏损就是错了 | 正确判断+短期下跌是加仓机会 |
| 跟着大V买就安全 | 别人的持仓成本、退出时点你不知道 |
| 历史业绩好就未来好 | 过去的成功不代表护城河仍然存在 |

### 8.2 行为误区

| 误区 | 纠正措施 |
|------|---------|
| 买入后不再跟踪 | 每季度复核一次财务和基本面 |
| 亏损不止损 | 初始买入逻辑证伪，必须离场 |
| 追涨杀跌 | 制定买入/卖出规则，机械执行 |
| 过度自信（近期赚钱后） | 每笔交易独立评估，不依赖运气 |
| 忽视流动性 | 港股必须先过流动性门槛 |
| 听消息买股票 | 所有决策基于可验证的公开数据 |

### 8.3 A股特有误区

- **炒小炒新炒差**：注册制下壳资源价值持续消亡
- **政策博弈代替基本面分析**：政策是催化剂，不是投资逻辑本身
- **过度相信庄家存在**：现代市场监管下，长期庄股极难维持
- **年报前后博弈**：利用信息不对称已违规，回避

### 8.4 港股特有误区

- **高股息陷阱**：股息高但现金流不支持，分红难以持续
- **折价即低估**：港股折价可能是流动性折价，不一定是投资机会
- **AH溢价套利**：A/H两地套利通道不完全打通，套利需考虑锁定期
- **做空免疫**：认为自己持有的港股不会被做空 → 任何港股都可能被做空
