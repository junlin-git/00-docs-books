### 第六步：正确理解股利（第七章）

**费雪版**：
- 分红不重要，资本配置效率才重要
- 高分红可能是增长枯竭的信号
- 股利政策的稳定性有价值

**🩸 A股血泪检查清单**：

| 你的“分红观” | 费雪会怎么说？ |
| :--- | :--- |
| “分红多的公司才是好公司” | **“工商银行分红多，但你赚到钱了吗？”** |
| “不分红就是铁公鸡” | **“早期的宁德时代不分红，它的股东少赚了吗？”** |
| “高股息就是高回报” | **“总回报 = 股息 + 资本增值，你只看了一半。”** |

**A股分红判断框架**：

| 公司类型 | 分红特征 | 你的正确态度 |
| :--- | :--- | :--- |
| 工商银行（成熟期） | 高分红 | 合理，因为找不到更好的增长机会 |
| 宁德时代（成长期） | 中高分红（50%） | 费雪会问：这钱留在公司再投资，回报率不是更高吗？ |
| 某“伪成长股”（报表亏损但强行分红） | 借钱分红 | 危险信号——这是“伪分红” |

> **A股铁律：在A股，分红是一面“照妖镜”。**  
> **它照出的不是公司好不好，而是你对管理层的信任有多少。**  
> **如果你不确定管理层能把留存利润用好——你宁愿公司把钱分了。**  
> **但如果你确认管理层能创造高回报——那分红多少根本不重要。**
