## ——费雪的“实战操作手册”，在A股为何对散户近乎“神话”，以及怎么强行抢救

>
> **⚠️ A股现实警告**：

>
> **第十章的方法论本身完美无缺，但执行门槛之高，对A股散户来说近乎“神话”。**  
>
> **本章的任务不是让你照搬费雪的操作，而是告诉你：**  
> **在A股，哪些可以照搬、哪些需要“代餐”、哪些只能放弃。**  
> **然后给你一套“丐版”但可执行的筛选流程。**

## 二、分：费雪筛选流程的三个阶段——以及A股怎么“代餐”

### 🎯 阶段一：海量初筛——从数千只股票中锁定目标

#### 📖 费雪的原话

> “有几十个行业的数千只股票，理论上都可能值得深入研究。但没有人有足够的时间去调查超过极小比例的公司。你如何选择那**一只或几只**值得投入时间的股票？”

费雪回顾了自己的投资生涯，发现了一个**反直觉的事实**：

> **他最终买入的股票中，约80%的创意来自“可信赖的投资圈子”——一小部分投资能力出众、业绩优秀的专业人士。**

只有约20%是他自己通过直接调研发现的。

费雪会向这些可信赖的朋友问两个核心问题：
1. **这家公司总体上有没有高速增长的潜力？**
2. **后来的竞争者进入这个行业有多容易？它们会不会抢夺市场份额或侵蚀利润率？**

> **🩸 A股现实（血淋淋版）** ：

**A股散户的“信息孤岛”困境**

费雪有一个“可信赖的投资圈”——里面有投资能力出众、业绩优秀的专业人士。  
A股散户呢？你的“投资圈”里有什么？

| 费雪的“投资圈” | A股散户的“投资圈” |
| :--- | :--- |
| 投资能力出众、业绩优秀的专业人士 | 同事老王、同学小李、微信群里的“老师” |
| 能提供深度分析和独立思考 | 能提供“内幕消息”和“代码” |
| 推荐股票后能解释为什么 | 推荐股票后只会说“干就完了” |

**费雪如果看到A股散户的“信息源”，他会说：**

> “你的‘朋友’推荐一只股票，你连他过去三年的投资业绩都不知道，你就敢买？  
> 你连他的判断力水平都不了解，你就把真金白银押在他的推荐上？  
> **这不是投资，这是盲从。** ”

**A股“代餐式”信息源建设**：

既然你没有“可信赖的投资圈”，你就得用公开信息来替代：

| 费雪的方法 | A股的本土化实践 |
| :--- | :--- |
| 可信赖的投资圈朋友 | **跟踪有长期业绩记录的基金经理的持仓变化**——他们就是你“可信赖的朋友” |
| 投资专家的推荐 | **关注深度研究型券商分析师的深度报告**（而非流水线研报） |
| 与同行的交流 | **在专业投资社区（如雪球）中识别并关注值得信赖的资深投资者** |
| 直接向专家提问 | **阅读并分析上市公司的投资者关系活动记录** |

> **A股铁律：你没有“投资圈”，但你有“公开数据库”。**  
> **基金经理的季报、交易所的问询函、上市公司的年报——这些都是免费的、公开的、可以被你“借用”的信息源。**  
> **区别只在于：你愿不愿意花时间去看。**


### 🎯 阶段二：信息收集与初步筛选——用“排除法”缩小范围

#### 📖 费雪的原话

费雪在获得初步的股票创意后，进入**信息收集和筛选阶段**。核心方法是**“排除法”**——

- 先研究**哪些公司应该被排除在外**
- 那些**不符合十五个原则基本要求**的公司，被迅速淘汰
- 那些**信息太少、无法判断**的公司，也被暂时搁置

他浏览公开文件、积极寻求“闲聊”，不断了解目标公司接近十五个原则的程度。在这个过程中，费雪会**舍弃一家又一家**潜在投资目标。

**只有在少数例子中，费雪才能得到足够多的、能证明这是一家好公司的资料。**

> **🩸 A股现实（血淋淋版）** ：

**A股是“排除法”最适用的市场**

费雪的“排除法”在A股尤其有效——因为A股有太多“一眼就能排除”的公司：

| 排除标准 | 操作方法 | 排除比例 |
| :--- | :--- | :--- |
| **ST/*ST** | 直接排除 | 约5% |
| **有监管处罚记录** | 证监会/交易所处罚公告查询 | 约10% |
| **大股东高比例质押** | 查询质押公告 | 约15% |
| **审计非标意见** | 年报审计意见查询 | 约3% |
| **ROE持续<10%** | 财报数据筛选 | 约40% |
| **经营性现金流持续为负** | 财报数据筛选 | 约25% |

**叠加这些排除条件，可以轻松排除掉A股70%以上的公司。**  
剩下的30%，才值得你花时间做进一步研究。

**但A股最危险的地方在于——**

> **“排除法”排除的是“明显不合格”的公司，但筛剩下的公司未必是“合格”的。**  
> 有些公司财务报表完美、没有任何“危险信号”，但仍然是垃圾——  
> 因为它的“好”是“做”出来的，不是“干”出来的。

**费雪会怎么说？**

> “排除法只是让你**不看垃圾**，不是让你**找到黄金**。  
> 排除掉70%之后，剩下的30%里，还有95%不值得投资。  
> **真正的筛选才刚刚开始。** ”

**A股实践指南——排除清单**：

在开始深度研究之前，先把以下公司排除掉：
- ❌ ST和*ST公司
- ❌ 过去三年被监管处罚过的公司
- ❌ 大股东质押率超过60%的公司
- ❌ 审计意见非“标准无保留”的公司
- ❌ ROE连续三年低于10%的公司（传统行业可放宽至8%）
- ❌ 经营性现金流/净利润 < 0.6 的公司（连续三年）
- ❌ 上市不足3年的公司（除非你有特别的理由）

> **这些条件排除之后，A股5000多家公司，能剩下来值得深度研究的，大概不到300家。**  
> **然后从这300家里，再用十五个原则去筛选——最终目标可能只有20-30家。**


### 🎯 阶段三：最终决策——“拜访管理层”的A股替代方案

#### 📖 费雪的原话

通过前两个阶段的筛选后，剩下的候选公司已经**极少**。这时费雪才会走**最后一步**——**拜访公司管理层**。

他带着**具体的问题和疑虑**去拜访，而不是空着手去“听故事”。如果原先的良好预期得到证实、管理层的回答足以消除先前的疑虑，费雪就会**认定这家公司可以投资**。

> **🩸 A股现实（血淋淋版）** ：

**对A股99%的散户来说，“拜访管理层”这四个字，就是神话。**

| 费雪能做到的 | A股散户的现实 |
| :--- | :--- |
| 直接约见CEO、CFO | 连证券事务代表都见不到 |
| 带着具体问题去验证判断 | 只能通过公开渠道提问，还不一定有回复 |
| 感受管理层素质和诚信 | 只能通过年报和公告“感受” |

**但费雪拜访管理层的核心目的，在A股是可以“代餐”的：**

**费雪拜访管理层的目的：**
1. 验证之前的判断
2. 消除先前的疑虑
3. 感受管理层的素质和诚信

**A股“代餐方案”：**

| 费雪的目的 | A股的本土化替代方案 |
| :--- | :--- |
| 验证判断 | **深度阅读3-5年的年报和季报，验证业务逻辑是否兑现** |
| 消除疑虑 | **跟踪公司的投资者问答记录，看管理层如何回应尖锐问题** |
| 感受管理层素质和诚信 | **对比公司在顺境和逆境时的沟通态度——诚信的管理层在困难时也会坦诚面对股东** |

> **A股铁律：公开信息已经足够你判断一家公司好不好——关键是你要愿意花时间去看。**  
> **你不需要见到CEO才能判断这家公司值不值得投资。**  
> **年报、公告、问询函、调研记录——这些就是你的“虚拟管理层拜访”。**


## 三、费雪对“时间投入”的看法——A股版

### 📖 费雪的原话

> “在这些事情上应该投入多少时间，当然是每个投资者必须根据自己的**可用资金、兴趣和能力**来决定的。”

费雪承认，**小型兼职投资者可能觉得这样的投入不值得**。如果有捷径当然好，但费雪**怀疑是否存在这样的捷径**。

> **费雪的潜台词**：投资是一件**需要付出代价**的事。如果你没有时间、没有精力、没有兴趣做深度研究，就不要指望能获得超额回报。

> **🩸 A股现实（血淋淋版）** ：

**A股散户的时间投入现状：**

| 时间投入 | 占比 | 做什么 |
| :--- | :--- | :--- |
| 每天<30分钟 | 约60% | 看盘、看涨跌、看弹窗新闻 |
| 每天30分钟-1小时 | 约25% | 看盘、看K线、刷股吧 |
| 每天1-2小时 | 约10% | 看盘、看研报摘要、听“老师”直播 |
| 每天>2小时 | 约5% | 读公告、看财报、做研究 |

**费雪会怎么说？**

> “你们每天花1小时看K线图，却不愿意花1小时读年报？  
> 你们花30分钟刷股吧看别人怎么说，却不愿意花30分钟看公司公告？  
> **你们在做‘投资’吗？你们是在做‘看电视’——被动接收，不做思考。** ”

**A股实践指南：**

| 你的可用时间 | 你应该怎么做 | 你不该怎么做 |
| :--- | :--- | :--- |
| 每天<30分钟 | **买指数基金**，别买个股 | 别妄想通过选股获得超额收益 |
| 每天30分钟-1小时 | **买优质基金**，或长期持有1-2只你深度研究的公司 | 别频繁交易，别追热点 |
| 每天1-2小时 | **可以尝试深度研究**，聚焦1-2个行业 | 别研究超过5家公司 |
| 每天>2小时 | **可以构建自己的研究体系** | 别把时间浪费在看盘上 |


## 四、总：第十章A股终极实践框架

### ✅ 第一，第十章回答的核心问题：“我该怎么开始？”

前九章回答了“买什么、什么时候买、什么时候卖、不要做什么”。第十章回答了 **“从哪里开始”** 。

```
费雪的完整筛选流程可以概括为：

第一步：建立可信赖的信息源网络 → 获得初步的股票创意
↓
第二步：快速排除明显不合格的公司 → 缩小研究范围
↓
第三步：阅读公开文件 + 积极“闲聊” → 用排除法淘汰大部分候选
↓
第四步：只有极少数公司进入最终候选 → 拜访管理层验证判断
↓
第五步：确认良好预期、消除所有疑虑 → 做出投资决策

```


**A股版筛选流程：**

```
第一步：建立“代餐式”信息源 → 跟踪优秀基金经理持仓 + 深度研报
↓
第二步：用“排除清单”快速淘汰 → 排除ST、质押高、现金流差、上市不足3年
↓
第三步：深度阅读公开信息 → 3-5年年报、公告、问询函、调研记录
↓
第四步：用十五个原则做深度评估 → 只有极少数能通过
↓
第五步：确认公司优秀 + 价格合理 + 时机合适 → 做出投资决策

```

### ✅ 第二，费雪给A股投资者的终极心法

| 费雪的教诲 | A股实践版 |
| :--- | :--- |
| 80%的创意来自可信赖的圈子 | **找到比你更专业的人（基金经理/资深投资者），认真听取他们的分析，但用你自己的判断去验证** |
| 用排除法快速淘汰大部分候选 | **建立你的“A股排除清单”，先排除明显不合格的公司，再研究剩下的** |
| 只有极少数公司值得深度研究 | **把80%的研究时间花在20%的候选公司上——不要平均用力** |
| 拜访管理层是最后一步 | **在A股，用深度阅读年报和公告替代“拜访管理层”——公开信息已经足够** |
| 投入多少就得到多少 | **如果你不愿意花时间读年报、做研究，就不要指望赚超额收益——买指数基金才是你的归宿** |
