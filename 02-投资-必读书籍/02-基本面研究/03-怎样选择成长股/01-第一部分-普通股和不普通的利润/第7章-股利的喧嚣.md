# 📖 《怎样选择成长股》第七章「股利的喧嚣」A股血泪重译
## ——费雪的“分红无用论”，在A股为何被政策强行扭转，以及你该怎么看

> **本章核心命题（费雪原话）**  
> 市场对股利的狂热追捧，到底是对是错？  
> 费雪的回答堪称全书最反常识的一句：  
> **“是否发放股利、发放多少，并不重要。优良的成长公司应减少发放股利，而将其用作增长之需。”**  
>
> 他甚至借用了莎士比亚《麦克白》的名句来形容市场对分红的争论——  
> **“充满了声音和愤怒，却毫无意义”（full of sound and fury, signifying nothing）。**  
>
> **⚠️ A股现实警告**：  
> 费雪如果活在今天的A股，他可能会被气死——  
>
> - 他刚说完“分红不重要”，A股正在经历**史上最大规模的分红浪潮**：2025年全年现金分红**2.55万亿元**，再创历史新高  
> - 他刚说完“优秀成长公司应少分红”，**宁德时代**宣布全年合计派现**361亿元**，占净利润的**50%**  
> - 他刚说完“股利政策的稳定性有价值”，监管层正在用行政手段**强制**上市公司一年多次分红  
>
> **费雪的“分红无用论”和A股的“分红狂热”，撞了个满怀。**  
> 谁对谁错？——都对，也都不对。  
>
> **本章的任务不是让你背费雪的结论，而是告诉你：**  
> **在美国成立的分红逻辑，在中国为什么完全反转？在A股，分红到底重不重要？什么时候该看重分红，什么时候该无视分红？**


## 一、总：费雪在说什么？——分红不重要，资本配置效率才重要

费雪在第七章的核心逻辑极其清晰，只有三步：

**第一步：利润只有两个去处**

> 一笔利润，要么分给股东（分红），要么留在公司再投资（留存利润）。

**第二步：哪个更好，取决于再投资回报率**

> 如果公司能把留存利润以**高于市场平均水平**的回报率进行再投资，那么不分红对股东更有利。  
> 如果公司找不到好的投资机会，那么分红对股东更有利。

**第三步：优秀成长公司应该少分红**

> 真正高增长的成长型公司，总是将大部分盈利投入到新的业务扩张中去。若大比例分红，则多数是因为公司的业务扩张有难度。

费雪用了一个极其精妙的比喻：

> **“如果优秀的管理层增加股利，因此牺牲了利用增加的收益进行再投资的机会，就像农场主把最好的牲畜赶到市场上卖掉，而不是把它们养到能卖出最好的价格为止。”**

> **🩸 A股现实（血淋淋版）** ：  
> 费雪这套逻辑，放在今天的A股，你拿去跟散户说，他们可能会骂你——  
> “不分红？那买股票干什么？存银行不香吗？”  
>
> **问题出在哪？**  
> 费雪的“分红不重要”有一个**隐藏前提**：  
> **“公司能把留存利润以高于市场平均水平的回报率进行再投资。”**  
>
> 这个前提在费雪时代的美国成立——因为按照十五个原则选出来的公司，管理层确实有能力高效配置资本。  
> **但这个前提在A股——成立的概率低得多。**  
>
> **A股大量公司，留存利润的再投资回报率连银行理财都跑不赢，甚至还亏钱。**  
> 在这种环境下，投资者当然宁愿公司把钱分了——至少落袋为安。  
>
> **费雪的结论没错，但A股的前提错了。**  
> **不是“分红不重要”，而是“在A股，不分红的钱，大概率会被管理层糟蹋掉”。**


## 二、分：A股分红的三重现实——费雪理论的“反向验证”

### 📊 现实一：A股正在经历“政策驱动的分红狂热”

费雪写《怎样选择成长股》时，美国公司的分红政策是**管理层自主决策**的结果。  
而在A股，分红是一场**自上而下的政策运动**。

**政策时间线**：

- **2024年4月**：国务院印发新“国九条”，全面强化上市公司现金分红监管——对多年未分红或分红比例偏低的公司，**限制大股东减持、实施风险警示**
- **2025年**：一年多次分红成为新风尚，实施一年多次分红的公司达**1052家**
- **2026年政府工作报告**：提出持续深化资本市场改革，大力推动中长期资金入市，加强分红回购

**A股分红数据（2025年）** ：

| 指标 | 数据 | 来源 |
| :--- | :--- | :--- |
| **现金分红总额** | **2.55万亿元** | 较5年前增长85.9% |
| **分红公司数量** | **3711家** | 占全部盈利公司的近九成 |
| **现金分红比例** | **44.87%** | 历史最高水平 |
| **平均股利支付率** | **37.7%** |  |
| **超百亿分红公司** | **35家** |  |
| **一年多次分红公司** | **1052家** |  |

> **🩸 A股现实（血淋淋版）** ：  
> 费雪说“分红是公司经营的自然结果”。  
> A股的分红是**政策强制的结果**。  
>
> **这不是“公司主动选择少分红来再投资”，而是“公司被政策逼着多分红”。**  
> 费雪的逻辑在这里被**完全颠倒**了。

**费雪会怎么看A股的分红狂热？**

费雪不会反对分红本身——他反对的是**为了分红而牺牲增长**。  
但如果一家公司**本来就没有增长可牺牲**（比如传统银行、成熟国企），那么多分红就是对股东最负责的做法。

**关键问题不是“分不分红”，而是“不分红的钱去了哪里”。**


### 📊 现实二：A股的“分红王”们——费雪理论的最佳验证

费雪在第七章中说了一句被很多人忽略的话：

> **“在价格表现糟糕的股票中，支付高股利的股票远远多于支付低股利的股票。”**

这句话在A股得到了**淋漓尽致的验证**。

**A股“分红王”——工商银行**：

- 2025年全年总派息额**1105.93亿元**，连续第19年稳居A股分红榜首
- 42家A股上市银行2025年度分红超**6456亿元**，连续三年创新高
- 六大行全年分红合计**4274亿元**

**但银行的股价表现呢？**

- 工商银行过去十年股价涨幅**远低于**同期消费、科技类成长股
- 高股息率吸引了大批“吃股息”的投资者，但资本增值极其有限
- 经典A股现象：**“赚了股息，亏了本金”**

**费雪会怎么说？**

> “工商银行身处成熟行业、增长空间有限，将大部分利润分红给股东是合理的。  
> **但如果你指望靠工商银行发财——你搞错了投资逻辑。**  
> 它是一只债券替代品，不是一只成长股。”

**费雪真正想说的是：**

> **高股息不是“好公司”的证明，而是“高增长机会枯竭”的信号。**  
> 在A股，银行、煤炭、电力这些高股息板块——**它们的股息率越高，越说明它们找不到更好的钱生钱的办法。**


### 📊 现实三：A股的“成长股分红”——费雪最想骂人的部分

费雪最核心的结论是：**优秀成长公司应该少分红，把利润留在公司再投资。**

但在A股，**成长股正在大规模分红**——

**宁德时代（2025年）** ：

- 拟向全体股东每10股派发现金分红**69.57元**（含税）
- 全年合计派现**361.01亿元**，占2025年归母净利润的**50%**
- 连续三年分红比例均占归母净利润的**50%**，三年累计分红超**835亿元**

**贵州茅台（2025年）** ：

- 每股派发现金红利**28.02元**（含税）
- 全年累计派发现金红利达**350.33亿元**
- 上市以来累计现金分红总额超过**4000亿元**

> **🩸 A股现实（血淋淋版）** ：  
> 费雪如果看到宁德时代50%的分红率，他会问一个问题：  
> **“这些钱如果留在公司再投资，回报率是否更高？”**
>
> 宁德时代的ROE长期在**20%以上**——这意味着，每留存1块钱利润，公司能创造2毛钱以上的年回报。  
> 如果把这1块钱分给股东，股东拿去存银行只有2%的利息——**年回报2分钱。**
>
> **从纯粹的财务角度看，宁德时代不分红对股东更有利。**  
> 那它为什么还要分50%？
>
> **答案：不是财务逻辑，是政治逻辑。**  
> - 政策要求分红  
> - 市场期待分红  
> - 机构投资者需要分红  
>
> **费雪的“资本配置效率”逻辑，在A股被“政策合规”逻辑压倒了。**

**但事情没那么简单——A股有一个费雪没遇到过的特殊情况。**


## 三、A股的特殊性：为什么“不分红”在A股是危险的？

费雪的“不分红”逻辑建立在两个前提上：

| 前提 | 费雪时代的美国 | A股现实 |
| :--- | :--- | :--- |
| **管理层诚信** | 大部分公司管理层值得信任 | **财务造假、利益输送屡禁不止** |
| **资本配置能力** | 优秀公司能把钱用好 | **大量公司拿着留存利润乱投资、乱并购** |

**A股血泪教训：不分红的钱，可能被管理层糟蹋掉。**

| 留存利润的去向 | A股现实 | 对股东的影响 |
| :--- | :--- | :--- |
| **盲目跨界并购** | 2015-2016年并购潮，60%+业绩承诺未达标 | 商誉暴雷、股价崩盘 |
| **大股东占用** | 关联交易、资金挪用 | 钱被“借”走了，再也回不来 |
| **低效产能扩张** | 行业下行期还在扩产 | 产能过剩、利润下滑 |
| **账面现金堆积** | 躺在账上吃低息存款 | 资金闲置、ROE下降 |

> **A股铁律：**  
> **如果你不能确认管理层能把留存利润用好——你宁愿公司把钱分了。**
>
> **费雪的逻辑没有错，但A股的“管理层质量”达不到费雪的标准。**  
> 在A股，**“分红”是投资者保护自己的最后一道防线。**


## 四、费雪没遇到过的A股新物种——“伪分红”

费雪在第七章讨论了“高股利”和“低股利”的优劣。  
但他没遇到过一种A股独有的现象——**“伪分红”**。

### 🚨 类型一：借钱分红

**特征**：公司净利润不高、现金流紧张，但为了满足政策要求或“做市值”，借钱也要分红。

**A股案例**：某些上市公司账面货币资金有限，却宣布高额分红——钱从哪来？银行贷款、发债、甚至挪用经营资金。

**费雪会怎么说？**

> “分红应该是**利润的真实分配**，不是**负债的转移**。  
> 借钱分红——是把股东的短期利益建立在公司的长期风险之上。”

**判断标准**：看**分红金额 vs 经营活动现金流**。如果分红金额远超经营现金流——**危险信号**。

### 🚨 类型二：大股东“定制分红”

**特征**：大股东持股比例高，通过高分红将公司利润“合法”转移给自己，同时摊薄小股东的相对收益。

**A股现实**：
- 大股东持股60%，公司分红100亿 → 大股东拿走60亿
- 小股东持股1%，拿走1亿
- 表面上“雨露均沾”，实际上**大股东在用公司的利润给自己发钱**

**费雪会怎么说？**

> “如果一家公司在**有更好再投资机会**的情况下仍然高比例分红——  
> 你要问：**这是为了股东利益，还是为了大股东利益？** ”

**判断标准**：看**大股东持股比例 + 公司ROE**。
- 大股东持股高 + ROE高 + 高分红 = **警惕利益输送**
- 大股东持股低 + ROE低 + 高分红 = **合理的股东回报**

### 🚨 类型三：分红“做市值”

**特征**：公司宣布高分红方案，股价短期上涨，大股东趁机减持。

**A股经典套路**：
1. 公司宣布“每10股派XX元”——股价大涨
2. 大股东在股价高位减持——套现走人
3. 分红实施后股价“除息”下跌——小股东被套

**费雪会怎么说？**

> “**分红应该是回报，不是套路。**  
> 如果一家公司用分红来掩盖减持——你看到的是分红，实际上是在被收割。”


## 五、总：第七章的A股终极实践框架

### ✅ 第一，费雪的结论没错，但A股的前提错了

| 维度 | 费雪的逻辑 | A股的现实 |
| :--- | :--- | :--- |
| **核心结论** | 优秀成长公司应少分红 | **部分成立**——如果管理层能把钱用好 |
| **隐藏前提** | 管理层诚信、资本配置能力强 | **不成立**——A股大量公司做不到 |
| **政策环境** | 公司自主决策 | **政策强制分红**——逻辑被颠倒 |
| **投资者心态** | 关注长期资本增值 | **普遍“落袋为安”** ——信任缺失 |

> **在A股实践费雪的分红理论，不是照搬“不分红更好”，而是问自己一个问题：**  
> **“这家公司不分红的钱，我能放心让它留在公司里吗？”**

### ✅ 第二，A股“分红判断”三问框架

在评估一家公司的分红政策时，问自己三个问题：

| 问题 | 通过标准 | 危险信号 |
| :--- | :--- | :--- |
| **公司还有增长空间吗？** | 行业渗透率还在提升、新产品管线丰富 | 行业见顶、产品被替代 |
| **留存利润的回报率高吗？** | ROE持续>15%，ROIC高于行业平均 | ROE逐年下滑、资金闲置 |
| **管理层值得信任吗？** | 诚信记录良好、资本配置历史成功 | 有处罚记录、历史并购频繁失败 |

**根据答案决定态度**：

| 三个问题的答案 | 对分红的正确态度 | A股实操 |
| :--- | :--- | :--- |
| **全是“是”** | 可以接受低分红/不分红 | 如早期的宁德时代、比亚迪——钱留在公司比分了更值钱 |
| **有“否”** | 希望公司多分红 | 如大部分传统制造业——不分红可能被乱花掉 |
| **全是“否”** | **不要买这家公司** | 不管分不分红，公司本身就不值得投资 |

### ✅ 第三，费雪给A股投资者的“分红观”修正

| 常见误区 | 费雪的正确认知 | A股修正版 |
| :--- | :--- | :--- |
| “分红多的公司才是好公司” | 分红多少取决于增长机会 | **在A股，分红多可能意味着增长枯竭，但也可能是“被迫分红”** |
| “不分红的公司是铁公鸡” | 如果留存利润能创造更高回报，不分红更负责 | **在A股，不分红可能是“真成长”，也可能是“管理层想乱花”** |
| “高股息就是高回报” | 高股息可能意味着增长枯竭 | **在A股，高股息策略2025年跑输大盘**——中证红利下跌3.1%，Wind全A上涨5.8% |
| “分红率越高越好” | 应与再投资回报率匹配 | **在A股，要警惕“借钱分红”和“大股东定制分红”** |

### ✅ 第四，费雪的终极智慧：分红是“结果”而非“原因”

费雪在第七章的真正贡献，不是告诉你“该不该买高股息股票”，而是教你一种思维方式：

> **不要从“这家公司分多少钱”出发去选股，而要从“这家公司能把钱用得多好”出发去选股。**

如果一家公司能把每一分留存利润都变成未来更高的利润，那么它不分红就是对股东最大的负责。  
如果一家公司找不到好的投资机会，那么它把利润分给股东就是最合理的做法。

**但在A股，你还需要加上一句：**

> **如果你不确定这家公司能把钱用得多好——你宁愿它把钱分了。**


> **✨ 费雪式灵魂提问（A股版）** ：
> 当你选择一只股票时，你问自己的是 **“这家公司每年分多少钱”** ，还是 **“这家公司能把留存的钱变成多少未来的利润”** ？
>
> 前者让你成为**“股利收集者”** ——盯着眼前的现金，却可能错过未来的增长，也可能踩中“伪分红”的雷。  
> 后者让你成为**“价值发现者”** ——关注资本的效率，与企业共同成长。
>
> **但A股版追加拷问**：
> 如果你选择“不分红更好”的逻辑——  
> **你确认这家公司的管理层，值得你把钱留在公司里吗？**
>
> 如果你不确定——**那就别骂公司不分红，是你自己选错了公司。**  
> 如果你确定——**那分红多少根本不重要，重要的是公司还在不在创造价值。**
>
> **第七章的全部智慧 + A股的全部血泪，就是逼你承认：**  
> **在A股，“分红”是一面照妖镜——它照出的不是公司好不好，而是你对管理层的信任有多少。**
