# 📖 《怎样选择成长股》第十章「如何找到成长型股票」深度总结
## ——费雪的实战操作指南及其在A股的本土化实践框架

> **本章核心命题**：前九章搭建了完整的理论框架——十五个原则、买入卖出时机、股利哲学、“十不”纪律。但读者最大的疑问始终是：**“道理我都懂，可我到底该怎么开始？”** 第十章就是费雪给出的**实战操作指南**——作为一个普通投资者，面对几十个行业、数千只股票，你**从哪里开始、怎么做、怎么一步步筛选**，最终找到真正值得投资的成长型股票。


## 一、总：从“理论框架”到“实战操作”的最后一步

费雪在1958年出版《怎样选择成长股》后，收到了来自世界各地读者的来信。读者们最关心的问题是：**“我理解十五个原则了，也知道不要做什么了，可我怎么在成千上万只股票中找到符合这些原则的那一只？”**

第十章正是回应这个问题的。费雪开篇就强调了一个残酷的现实：

> **寻找成长型股票是一个繁琐的过程，必须投入时间、精力，以及技巧和警觉性**。

没有捷径，没有“一键筛选”的公式。但费雪根据自己的实践经验，总结出了一套**可操作的两阶段筛选流程**。

> **本章核心命题**：找到成长型股票不是靠运气，而是靠一套**系统化的筛选流程**——从“海量初筛”到“深度研究”到“最终决策”，每一步都有明确的方法和判断标准。


## 二、分：费雪寻找成长型股票的完整流程

### 🎯 阶段一：海量初筛——如何从数千只股票中锁定目标？

费雪坦承，这是整个过程中**最困难的一步**：

> “有几十个行业的数千只股票，理论上都可能值得深入研究。但没有人有足够的时间去调查超过极小比例的公司。你如何选择那**一只或几只**值得投入时间的股票？”

费雪对自己投资生涯的筛选过程进行回顾后，发现了一个**反直觉的事实**：

#### 🔑 核心发现：80%的创意来自“可信赖的圈子”

费雪惊讶地发现，他最终买入的股票中：

| 来源 | 占比 | 说明 |
| :--- | :--- | :--- |
| **自己通过直接调研发现** | 约20% | 与科学家、管理层直接交流得到的创意 |
| **来自可信赖的投资圈子的推荐** | 约80% | 一小部分能力出众的投资专家 |

费雪指出，这个“可信赖的圈子”由一小部分**投资能力出众、业绩记录优秀**的专业人士组成。他们可能推荐一只费雪本人并不完全认同的股票，但**因为费雪了解他们的判断力和过往记录**，他会认真听取他们提供的细节。

> **费雪的关键提问**：费雪会向这些可信赖的朋友问两个核心问题：
> 1. **这家公司总体上有没有高速增长的潜力？**
> 2. **后来的竞争者进入这个行业有多容易？它们会不会抢夺市场份额或侵蚀利润率？**

**费雪的这个发现，本质上回答了A股投资者最焦虑的问题：“我没法像机构那样调研，我怎么找到好股票？”——答案是：建立一个可信赖的信息源网络，而不是闭门造车。**


### 🎯 阶段二：信息收集与初步筛选——用“排除法”缩小范围

在获得初步的股票创意后，费雪进入**信息收集和筛选阶段**。这个阶段的核心方法是**“排除法”** ——不是急着证明“这家公司好”，而是先找出“这家公司哪里不好”。

#### 📋 第一步：快速排除明显不合格的公司

费雪会先研究：

- **哪些公司应该被排除在外**
- 那些**不符合十五个原则基本要求**的公司，被迅速淘汰
- 那些**信息太少、无法判断**的公司，也被暂时搁置

#### 📋 第二步：阅读公开文件

费雪会浏览证券管理委员会（相当于A股的证监会）公开的**说明书中的要点**。

在A股实践中，这对应的是：

- **巨潮资讯网的招股说明书**（尤其是“风险因素”和“财务附注”部分）
- **年度报告**（不是看管理层致辞，而是看财务数据附注）
- **临时公告**（尤其是重大资产重组、关联交易等）

#### 📋 第三步：积极运用“闲聊法”

费雪会**积极寻求“闲聊”** ，不断了解目标公司接近十五个原则的程度。

在这个过程中，费雪会**舍弃一家又一家**潜在投资目标：

| 淘汰原因 | 费雪的做法 |
| :--- | :--- |
| **信息显示公司平庸** | 直接淘汰 |
| **无法获取足够信息** | 暂时搁置 |
| **信息矛盾或可疑** | 继续深挖或放弃 |

**只有在少数例子中，费雪才能得到足够多的、能证明这是一家好公司的资料**。


### 🎯 阶段三：最终决策——拜访管理层

通过前两个阶段的筛选后，剩下的候选公司已经**极少**。这时费雪才会走**最后一步**——**拜访公司管理层**。

#### 📋 拜访前的准备

费雪在拜访前，已经通过前面的研究对这家公司有了**50%左右的基本判断**。他带着**具体的问题和疑虑**去拜访，而不是空着手去“听故事”。

#### 📋 拜访中的判断

- 如果**原先的良好预期得到证实**
- 如果**管理层的回答足以消除先前的疑虑**
- 那么费雪就会**认定这家公司可以投资**

#### 📋 拜访后的结果

费雪坦言：**只有极少数公司能通过全部筛选**。大多数候选公司在研究过程中被淘汰——不是因为它们“不好”，而是因为**信息不足、或者信息显示它们不够优秀**。


### ⏳ 费雪对“时间投入”的务实看法

费雪在第十章中给出了一个**务实的提醒**：

> “在这些事情上应该投入多少时间，当然是每个投资者必须根据自己的**可用资金、兴趣和能力**来决定的。”

费雪承认，**小型兼职投资者可能觉得这样的投入不值得**。如果有捷径当然好，但费雪**怀疑是否存在这样的捷径**。

> **费雪的潜台词**：投资是一件**需要付出代价**的事。如果你没有时间、没有精力、没有兴趣做深度研究，就不要指望能获得超额回报。要么投入足够的时间和精力，要么接受平庸的回报——**没有第三种选择**。


## 三、A股映射：费雪筛选流程的本土化实践

### 🔍 映射一：A股投资者的“可信赖圈子”在哪里？

费雪80%的股票创意来自“可信赖的投资圈子”——这是A股投资者面临的最大挑战，也是最大的机会。

**A股的现实困境**：

- 大多数散户没有“投资圈”——没有几个能力出众、业绩优秀的投资朋友可以交流
- 券商的公开研报**信息价值有限**
- 社交媒体上的荐股信息**鱼龙混杂**

**A股的本土化出路**：

| 费雪的方法 | A股的本土化实践 |
| :--- | :--- |
| 可信赖的投资圈朋友 | **跟踪有长期业绩记录的基金经理的持仓变化** |
| 投资专家的推荐 | **关注深度研究型券商分析师的深度报告**（而非流水线研报） |
| 与同行的交流 | **在专业投资社区（如雪球）中识别并关注值得信赖的资深投资者** |
| 直接向专家提问 | **阅读并分析上市公司的投资者关系活动记录** |

**费雪的核心逻辑在A股依然成立**：**你不需要自己发现所有好股票。找到比你更聪明、更专业的人，认真听取他们的分析，然后用自己的判断去验证。**


### 🔍 映射二：A股投资者的“信息筛选”怎么做？

费雪的“排除法”在A股尤其适用——**在信息过载的时代，知道“不看什么”比知道“看什么”更重要**。

**A股的信息筛选清单**：

| 费雪的做法 | A股的本土化实践 |
| :--- | :--- |
| 快速排除明显不合格的公司 | **排除ST股、有监管处罚记录的公司、大股东高比例质押的公司** |
| 浏览公开说明书要点 | **认真阅读招股说明书的“风险因素”和“关联交易”章节** |
| 通过“闲聊”了解公司 | **参加线上业绩说明会、阅读机构调研记录** |
| 舍弃信息不足的公司 | **对信息不透明的公司保持距离——宁可错过，不可踩雷** |

> **费雪给A股投资者的核心提醒**：**不要试图研究所有公司。用排除法快速淘汰大部分，只对极少数公司做深度研究。**


### 🔍 映射三：A股投资者的“最终决策”怎么做？

费雪的“拜访管理层”这一步，对绝大多数A股散户来说**不现实**。但费雪的精神实质可以**本土化**：

**费雪拜访管理层的目的是什么？**

1. **验证之前的判断**
2. **消除先前的疑虑**
3. **感受管理层的素质和诚信**

**A股投资者如何实现同样的目的？**

| 费雪的目的 | A股的本土化替代方案 |
| :--- | :--- |
| 验证判断 | **深度阅读3-5年的年报和季报，验证业务逻辑是否兑现** |
| 消除疑虑 | **跟踪公司的投资者问答记录，看管理层如何回应尖锐问题** |
| 感受管理层素质和诚信 | **对比公司在顺境和逆境时的沟通态度——诚信的管理层在困难时也会坦诚面对股东** |

> **费雪给A股投资者的核心提醒**：**你不需要见到CEO才能判断一家公司好不好。公开信息中已经包含了足够多的线索——关键是你要愿意花时间去看。**


### ⏳ 映射四：A股投资者的“时间投入”悖论

费雪说：“小型兼职投资者可能觉得这样的投入不值得。”

**A股的现实**：

- 绝大多数散户每天花在股票上的时间**少于1小时**
- 大多数人看的是**股价涨跌、K线图、股吧帖子**——而不是年报和公告
- 然后他们抱怨**“A股赚不到钱”**

**费雪会怎么说？**

> **“你投入多少，就得到多少。如果你不愿投入时间和精力做深度研究，就不要指望获得超额回报。”**

在A股，信息的获取门槛**其实很低**——巨潮资讯网对所有投资者免费开放，年报和公告对所有投资者一视同仁。**差距不在于“能不能获得信息”，而在于“愿不愿意花时间去看”** 。


## 四、总：第十章的核心框架与A股实践总结

### ✅ 第一，费雪第十章回答的核心问题：“我该怎么开始？”

前九章回答了“买什么、什么时候买、什么时候卖、不要做什么”。第十章回答了**“从哪里开始”** 。

费雪的完整筛选流程可以概括为：
```
第一步：建立可信赖的信息源网络 → 获得初步的股票创意
↓
第二步：快速排除明显不合格的公司 → 缩小研究范围
↓
第三步：阅读公开文件 + 积极“闲聊” → 用排除法淘汰大部分候选
↓
第四步：只有极少数公司进入最终候选 → 拜访管理层验证判断
↓
第五步：确认良好预期、消除所有疑虑 → 做出投资决策

```

### ✅ 第二，第十章与前面章节的关系

| 前面的章节 | 第十章的作用 |
| :--- | :--- |
| 第二章“闲聊法” | 第十章告诉你**什么时候、怎么用**“闲聊” |
| 第三章“十五个原则” | 第十章告诉你**用十五个原则去筛什么** |
| 第八章、第九章“十不”原则 | 第十章告诉你**筛选过程中要避开什么** |

**第十章是将前面所有章节整合起来的“操作手册”** 。

### ✅ 第三，费雪给A股投资者的终极心法

| 费雪的教诲 | A股实践版 |
| :--- | :--- |
| 80%的创意来自可信赖的圈子 | **找到比你更专业的人，认真听取他们的分析** |
| 用排除法快速淘汰大部分候选 | **不要试图研究所有公司——先排除明显不合格的** |
| 只有极少数公司值得深度研究 | **把80%的研究时间花在20%的候选公司上** |
| 拜访管理层是最后一步 | **在A股，用深度阅读年报和公告替代“拜访管理层”** |
| 投入多少就得到多少 | **如果你不愿意花时间读年报，就不要指望赚超额收益** |

> 回顾你过去的投资，你是**怎么找到你买的那只股票的**？
>
> 是**听朋友推荐**？**看股吧帖子**？**追热门概念**？**看K线图选出来的**？
>
> 还是**经过了一套系统化的筛选流程**——从数千只股票中一步步缩小范围，最终锁定那少数几只真正值得研究的公司？
>
> 第十章的全部智慧，就是逼你承认：**大多数人亏损，不是因为“没有好公司”，而是因为“没有好方法”** ——他们用买彩票的方式在做投资，却期待获得种地的收成。
