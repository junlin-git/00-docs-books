# 《金融炼金术》第11章读书笔记：控制对照阶段：1986年1月～1986年7月

## ——当市场陷入“区间震荡”，考验的是框架的韧性


## 总论：验证理论最难的不是“判断对了”，而是“判断错了还能修正”

第十章中，索罗斯在广场协议后大获全胜，量子基金1985年全年收益约**121.2%**。按照常理，下一步应该是“乘胜追击”。但索罗斯选择了一个更艰难的方向——**进入“控制对照阶段”**。

这听起来像科学实验术语，放在投资中是什么意思？在1986年1月至7月这七个月中，市场不再像1985年下半年那样出现单边大趋势，美元没有继续暴跌，而是在一个区间内反复拉锯。**反身性理论面临的真正考验不是“能不能抓住趋势”，而是“在没有明显趋势时，框架是否还能提供有效指导”**。

此阶段的关键特征是：**索罗斯没有等待下一次广场协议式的“核爆时刻”——他主动将实验推向更复杂的市场环境，用股票、债券、外汇、商品的多资产组合来检验反身性理论的普适性。实验结果并不完美——他一度在原油多头中巨亏，对美元走势的判断也出现摇摆，但整个框架在“被修正”的过程中，反而变得更加坚固。**

对于2026年的A股投资者而言，这一章的启示价值，甚至超过了“广场协议”的胜利时刻。因为真正考验一个投资者的，从来不是牛市中的判断力，而是震荡市中坚守纪律与修正框架的能力。


## 一、实验的新阶段：从“单边验证”到“控制对照”

### 1.1 为什么需要“控制对照阶段”？

1985年12月，索罗斯在日记中信心满满地宣告：**“实时实验阶段可以结束了，他已经看穿了一切”**。如果故事到此结束，反身性理论仍然只是一个“成功预测了一次广场协议”的框架。

真正的科学实验需要**对照**——即在不同条件下测试同一套框架的有效性。

在1986年1月的日记中，索罗斯写道：

> **“在经过几个月的实时实验之后，他得出结论：这是进入‘控制对照’阶段的恰当时机。即按照理论对环境变化的解读来调整持仓。”**

换句话说：**市场不会永远给你单边趋势。理论是否能指导你在震荡、反复、噪音横行的市场中不犯大错，才是真正的检验标准。**

### 1.2 索罗斯的新判断：验证新局面的到来

第一阶段结束时，索罗斯判断：大循环已经终结，取而代之的是“五个低”的新局面——**弱势美元 + 低调经济 + 低财政赤字 + 低贸易赤字 + 低利率**。第二阶段的任务，是验证这一新局面是否真正到来，并据此调整仓位。

他预期的剧情是：**美国经济走弱，迫使美联储降息，带动美元进一步贬值，同时美股和债券走牛，全球经济温和复苏。**

这一判断整体正确，但市场在1986年上半年并没有按照“广场协议后”的直线路径运行。


## 二、仓位结构：多市场、跨资产的复杂组合

### 2.1 从“外汇大赌注”到“多资产布局”

索罗斯在第二阶段的仓位明显比第一阶段更加复杂和分散：

| 资产类别 | 方向 | 仓位规模 | 核心逻辑 |
|---------|------|---------|----------|
| **标准普尔500期货** | 做多 | 约3亿美元 | 押注美国经济软着陆，利率下行利好股市 |
| **美国长期国债** | 做多 | 约4.5亿美元 | 押注经济疲软→降息→债券上涨 |
| **日元/德国马克** | 做多 | 约5亿美元 | 押注美元继续贬值 |
| **原油期货** | 做多 | 约1.5亿美元 | 押注油价见底反弹 |
| **日本政府债券（JGB）** | 做多 | 约2.5亿美元 | 押注日本利率下行，债券牛市延续 |
| **欧洲股票** | 做多 | 规模较小 | 押注全球资本从美国流向非美市场 |

这套组合的核心逻辑是：**美元走弱 + 利率下行 + 经济软着陆 → 利好美股、美债、非美货币、原油。**

### 2.2 仓位背后的“反身性逻辑”

索罗斯将这套组合称为“控制对照阶段”，并非随意布阵。他面临的两个核心反身性问题分别是：

**问题一（美国本土）：美联储减息与股市的关系**
传统认知是“降息刺激股市”，但反身性有可能逆转这一逻辑：降息幅度不够或滞后 → 经济疲软侵蚀企业利润 → 股市下跌；降息太猛 → 市场将之解读为“美联储恐慌” → 进一步动摇信心。**减息对股市的影响，取决于市场如何解读美联储的行为。**

**问题二（全球传导）：美元贬值对美国股市的关系**
强势美元贬值，改善了美国跨国公司的出口竞争力，资金回流本土，对美股利好。但如果贬值过快，资本加速外逃，美股反而可能下跌。**汇率与股市之间同样是反身性关系，不存在单向的线性影响。**


## 三、市场验证与中途修正

### 3.1 1986年1月至3月：利好的经济信号频发

- 美国经济数据有所企稳，原油价格从低点反弹
- 日本和德国经济保持扩张趋势，全球风险偏好回升
- 索罗斯的多资产组合整体表现良好：美股上涨、日债上涨、日元和马克震荡上行

### 3.2 1986年4月：震荡中的反思

4月的日记中，索罗斯开始出现疑虑：

- **美元没有继续大幅贬值，而是在区间内反复拉锯**
- 美国经济数据并不像预期中那么疲软，美联储降息的紧迫性下降
- 原油价格反弹后陷入震荡，索罗斯的原油多头仓位面临压力

他在日记中写道：

> **“也许是我对新局面到来的判断过于乐观了。”**

索罗斯的态度开始变得“矛盾”——这恰恰是理论框架在发挥作用：**框架告诉他“新局面的逻辑没有破”，但市场告诉他“短期节奏与预期不符”。**

### 3.3 1986年6月至7月：原油多头遭遇“滑铁卢”

1986年上半年，国际原油价格出现了剧烈波动：

- OPEC内部减产协议破裂，沙特大幅增产，油价从约28美元/桶急速下跌
- 索罗斯的原油多头仓位在短短数周内遭受重创

他在6月底的日记中写道：

> **“原油多头是我在控制对照阶段中最大的错误。”**

这并非判断失误——索罗斯押注的是“油价见底反弹”这一逻辑，在当时的产业基本面支撑下有其合理性。但**反身性理论并未让他避开这次亏损**，因为油价的暴跌本质上是OPEC内部政治博弈的结果，是一种外生冲击。


## 四、1986年7月：关键的“自我修正”

### 4.1 重新审视判断框架

面对原油巨亏和美元走势的持续摇摆，索罗斯在1986年7月进行了一次至关重要的复盘。他在日记中写道：

> **“从现在开始，必须根据判断来修正我的实验方法。”**

他没有僵化地“坚持逻辑、死扛到底”，也没有因亏损而全盘否定自己的框架。他的修正方向是：**从依赖单一框架（大循环）过渡到多个框架的组合（信贷周期 + 大循环）。**

### 4.2 方法论升级：引入“信贷与管制周期”

索罗斯在第七章中已经详细阐述了“信贷与管制周期”的理论。到了1986年7月，他决定将这一框架整合进实时实验中：

| 原框架 | 新框架（整合后） |
|--------|----------------|
| 以“大循环”为核心的宏观分析 | **大循环 + 信贷周期** 双轨并行 |
| 主要关注汇率、利率、商品价格 | **同时关注信贷扩张与收缩对资产价格的传导** |
| 偏向于“单边判断”（美元贬值or升值） | **偏向于“条件判断”（如果A则B，如果C则D）** |

**信贷周期框架告诉他：**

- 1986年上半年，全球信贷扩张仍在延续（日本、欧洲银行体系仍在向美国输出资本）
- 这意味着美元即使有贬值压力，短期内也难以形成单边暴跌
- 震荡可能是常态，而非意外

### 4.3 修正后的仓位调整

基于上述修正，索罗斯在7月底进行了一系列调整：

| 操作 | 逻辑 |
|------|------|
| 削减原油多头仓位 | 承认错误，止损离场 |
| 维持美股多头 | 判断美国经济仍在软着陆轨道上 |
| 维持日债多头 | 判断日本利率仍有下行空间 |
| 外汇头寸部分减仓 | 承认“美元短期内难以单边暴跌”的判断 |


## 五、本章对中国投资者的启示

### 5.1 震荡市是框架的“压力测试”

索罗斯在1986年上半年的最大考验不是“亏了钱”，而是“市场没有按照预期走”。他没有因为一次判断正确就“封神”，也没有因为一次判断错误就“崩盘”——他在震荡中修正了自己的框架，这才是这个阶段对投资者最有价值的案例。

在2026年的A股，这种能力尤其重要：

- **当市场在3000点反复拉锯时，考验的不是你“看对了什么”，而是“当看错时，你的框架能不能快速修正”**
- **不要用“牛市状态”来配置震荡市——用框架来应对，而不是用情绪来应对**

### 5.2 承认局部错误，但不否定整体框架

索罗斯在原油上“认栽”了，但他没有因此推翻“大循环终结”的整体判断：

- **他只是修正了“过程”的判断——美元不会直线下跌，而会反复拉锯**
- **但他没有修正“方向”的判断——大循环已经终结，新局面的逻辑仍然成立**

在A股投资中，这对应着一种重要的思维：

> **“我可能判断错了短期节奏，但如果长期逻辑没有破，核心仓位不应该被短期波动‘洗出去’。”**

### 5.3 引入“信贷周期”作为核心分析工具

索罗斯在1986年7月的最大方法论突破，是将信贷周期与大循环框架结合起来。这一突破的意义在于：**“汇率 + 利率”分析框架不够用，必须要加上“信贷”维度。**

对于2026年的A股投资者：

- 2025年，大型银行新增贷款占比从2018年的34.8%升至56.6%
- 信贷正在“财政化”——政府债券净融资占比持续上升，人民币贷款占比首破50%
- **理解信贷周期的结构性变化，比预测短期涨跌重要得多**

### 5.4 实验的意义不在于“对错”，而在于“迭代”

索罗斯在第二阶段结束时，账面上的表现远不如第一阶段耀眼。但他完成了远比“再赚100%”更重要的事：

> **他将反身性理论从“预测工具”升级为“修正工具”——当市场走势与理论预期不符时，框架告诉你“如何修正”，而不是“如何死扛”。**

在投资中，**“被修正的框架”远比“永远正确的判断”更有价值**。


## 总结：震荡是试金石，修正才是真功夫

1986年上半年，索罗斯面对一个没有单边趋势的市场、一个令他巨亏的仓位、一个需要修正的判断框架。他没有否认问题，也没有坐等奇迹，而是主动进入“控制对照模式”：

| 阶段 | 面对的问题 | 索罗斯的应对 |
|------|-----------|-------------|
| **1-3月** | 市场验证了部分判断（美股涨、日债涨） | 维持原仓位，观察数据 |
| **4月** | 美元不再单边下跌，陷入区间震荡 | 开始反思，承认“过于乐观” |
| **6-7月** | 原油多头遭遇重创 | 承认错误，砍仓止损 |
| **7月底** | 理论框架遭遇挑战 | 升级方法论：引入信贷周期，形成“双框架” |

最终，量子基金在1986年上半年并未实现“暴利”，但索罗斯在个人成长层面完成了更为深刻的一跃：**从“用理论预测市场”升级为“用理论修正自身”。**

对于2026年的中国投资者，最值得记住的一句话是：

> **“判断错误是必然的，真正重要的是你有没有一个框架来告诉你——错了之后该怎么办。”**

在震荡市中，没有完美的预判，只有不断迭代的体系。**系统，是投资者在市场无常中最可靠的朋友。**
