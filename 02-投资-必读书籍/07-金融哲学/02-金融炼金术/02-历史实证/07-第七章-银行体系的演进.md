# 《金融炼金术》第7章读书笔记：银行体系的演进

## ——大而不倒不是保护，而是慢性自杀的许可证


## 总论：银行体系不是在“修复”，而是在“进化”——朝着更危险的方向

索罗斯在第六章剖析了里根大循环——一个用全球资本支撑美国繁荣的反身性幻象。但大循环的受益者不只是美国政府，还有**美国的银行体系**。到了第七章，索罗斯将镜头对准了银行体系本身：**1982年国际债务危机之后，银行体系没有崩溃，不是因为它们变强了，而是因为它们学会了一种更危险的生存方式——用幻象替代现实，用拖延替代解决，用更大的风险掩盖旧的风险。**

索罗斯在第七章揭示了一个令人不安的真相：

> **银行体系在危机之后经历的，不是“修复”，而是“演进”——朝着更集中、更脆弱、更依赖幻觉的方向演进。**

1982年的危机暴露了银行体系的致命弱点——过度暴露于主权债务。但危机之后的“解决方案”——集团体制、监管妥协、借新还旧——并没有解决这个问题，而是**让银行体系进化出了一种新的生存形态：大而不倒、共谋幻象、风险转嫁**。

索罗斯写道：

> **“贷款的集团体制所赖以运行的基本原则是自愿合作，唯一可行的办法就是保持一种幻象，似乎未清偿贷款并未对银行造成损害。”**

幻象不是偶然的副产品——**它是银行体系得以继续运转的唯一燃料。**

对于2026年的中国而言，银行体系的演进不是1980年代的遥远故事——它正在中国以更快的速度、更大的规模上演。**大型银行主导、中小银行边缘化、净息差持续收窄、资产质量分化**——这些现象背后，正是索罗斯所描述的“银行体系演进”的中国版本。


## 一、1982年危机后的银行体系：从“竞争”到“共谋”

### 1.1 危机暴露了什么？

1982年，墨西哥等国违约，国际银行体系面临崩溃。索罗斯在第五章和第六章已经揭示了危机的规模：**所涉及的款项大大超出了银行的自有资本**。

危机暴露了银行体系的两个致命弱点：

| 弱点 | 具体表现 |
|------|---------|
| **过度集中** | 少数几家“金融中心银行”持有绝大部分发展中国家债务 |
| **过度杠杆** | 银行贷款远远超出自有资本，一旦违约即资不抵债 |

如果按常理——借债人还不起钱，债主就该记坏账——那么这些银行应该破产。但1982年的情况特殊：**那些欠债的是主权国家，债主是全球顶级的商业银行**。如果银行停止放贷，国家破产，银行跟着完蛋，整个金融体系崩溃。

### 1.2 美欧的分岔：两种演进路径

索罗斯在第七章揭示了一个关键差异：**美联储和欧洲各国央行采取了完全不同的应对策略**。

| 维度 | 美联储（美国） | 欧洲央行 |
|------|--------------|---------|
| **策略** | 保守、妥协、拖延 | 果断、强硬、刮骨疗毒 |
| **操作** | 允许银行把纸面利息算作收益 | 鼓励银行认栽、建立储备、冲销坏账 |
| **结果** | 银行账面繁荣，实际烂账 | 短期痛苦，长期健康 |
| **代价** | 问题非但没有暴露，反而更形严重 | 银行体系更早出清 |

美联储为什么选择保守路线？因为**美国银行体系参与得太深，无法轻易脱身**；而欧洲银行在前期参与程度较低，因此方便掉头。

里根总统希望以市场的方式解决问题——比如银行间的并购，稳健的吃下出险的，金融体系的风险在金融体系内部解决。为了确保这一思路得以贯彻，**许多清规戒律一下子被扫除了**。

索罗斯的结论是：**美联储在支持金融中心银行方面“走得太远了”** 。

### 1.3 “共谋的幻象”如何运作？

索罗斯揭示了“共谋幻象”的具体操作：

**第一步：借新还旧**
银行继续给还不起钱的国家发放新贷款，这笔钱转手就变成了利息流回银行。账面上，利息收到了，贷款是“正常”的。

**第二步：不提储备**
如果承认贷款有风险，就得提坏账准备金，利润就会变负。所以大家心照不宣地假装一切安好。

**第三步：增加分红**
美国的大银行明明肚子里全是烂账，脸面上却红光满面，甚至在1983年还增加了股息分红！

索罗斯一针见血地指出：

> **“问题非但没有暴露，反而更形严重了。”**

这让我想起一句话：**“当你欠银行100块，是你烦恼；当你欠银行100亿，是银行烦恼。”** 1982年的银行，正是利用这种“大到不能死”的捆绑，硬生生把危机拖成了慢性病。

### 1.4 反身性的“二阶效应”：饮鸩止渴

索罗斯进一步揭示了银行体系演进的可怕逻辑：

> **因为没有立即的生存压力，美国银行并没有收敛，反而为了掩盖旧伤，不得不去寻找新的、收益更高的（通常风险也更大的）业务来填坑。**

这是一个典型的饮鸩止渴的故事：

1. 1982年危机 → 银行暴露于主权债务风险
2. 监管“保护”→ 银行没有出清
3. 为了掩盖烂账 → 银行必须寻找高收益业务
4. 高收益业务 = 高风险业务（杠杆收购、垃圾债）
5. 新的风险累积 → 为下一场危机埋下伏笔

**维持幻象的行为本身，就在制造下一场危机。** 这正是反身性的“二阶效应”——你为解决问题而采取的行动，恰恰在创造新的、更大的问题。


## 二、中国银行体系的演进：2026年的现场演绎

### 2.1 集中化：中国版的“金融中心银行”

索罗斯笔下的1980年代美国银行体系，核心特征是**少数几家“金融中心银行”持有绝大部分风险敞口**。

2026年的中国，呈现出一个**更集中、更制度化的版本**——**以国有大型银行为核心的银行体系**。

**总资产规模**：

截至2026年一季度末，中国银行业机构总资产为**494.72万亿元**，同比增长8.0%。金融业机构总资产为556.34万亿元，同比增长8.8%。

**六大行的统治地位**：

截至2025年末，六大行资产合计突破**220万亿元**，达220.48万亿元，同比增长10.42%。工商银行以**53.48万亿元**的资产规模稳居首位。

**信贷市场份额的“马太效应”** ：

2025年，大型银行新增人民币贷款**10.66万亿元**，占各类型银行新增信贷的**56.6%**，创历史新高。

拉长时间看：

| 年份 | 大行新增信贷占比 |
|------|----------------|
| 2018年 | 34.8% |
| 2023年 | 首度超过50% |
| 2025年 | **56.6%** |

**行业集中度进一步向头部集中**：2025年末国有大行资产占比较2021年末提升4.0个百分点至**43.3%**。

索罗斯如果在世，会说：**这不是市场竞争的结果，而是一种结构性的“演进”——信贷资源越来越集中于少数几家“系统重要性”银行。这正是1980年代美国“金融中心银行”模式的中国版本。**

### 2.2 净息差的“慢性病”：利润空间被两头挤压

索罗斯在第七章揭示：**维持幻象的代价，是银行不得不寻找更高风险的业务来填补利润缺口。**

2026年的中国银行业，正在经历类似的困境。

**净息差持续下行**：

2026年一季度，商业银行净息差降至**1.40%**，较2025年四季度的1.42%收窄2个基点。

分银行类型看：

| 银行类型 | 净息差（2026Q1） |
|---------|-----------------|
| 大型商业银行 | **1.29%** |
| 股份制商业银行 | **1.54%** |
| 城市商业银行 | **1.38%** |
| 农村商业银行 | **1.58%** |
| 民营银行 | **3.62%** |

**大型银行的净息差仅1.29%**——这是历史低位。而民营银行虽然高达3.62%，但季度环比降幅达21BP，成为收窄最剧烈的板块。

**利润下滑**：

一季度商业银行累计实现净利润**6323亿元**，同比下降**3.73%**。

**“量增价减”** 的格局仍未根本改观。银行的资产规模在增长，但赚钱的效率在下降——**这正是索罗斯所说的“慢性病”** 。

### 2.3 资产质量的分化：大行稳、中小行忧

索罗斯在第七章揭示：**“共谋的幻象”让银行账面繁荣，但实际烂账在暗处滋长。**

2026年的中国，资产质量呈现出明显的**结构性分化**：

| 指标 | 数据 |
|------|------|
| 不良贷款余额 | **3.7万亿元**（一季度末） |
| 不良贷款率 | **1.51%**（较去年末上升0.01个百分点） |
| 关注类贷款占比 | **2.17%** |

**大型银行资产质量保持稳健，中小银行不良率较上年末有所上行，农商行资产质量压力相对明显**。

**不良率与关注率之和保持平稳**——表面数字看起来“稳”，但**结构性的分化正在加剧**。大行稳如泰山，中小行暗流涌动。

这正是索罗斯所描述的模式：**大银行“大到不能倒”，享受保护；小银行在暗处承受压力。**

### 2.4 大行下沉：中国版的“金融中心银行扩张”

索罗斯在第七章描述了美国“金融中心银行”如何在危机后进一步扩张——通过并购、通过监管放松、通过规模效应。

2026年的中国，大型银行正在以另一种方式扩张：**业务下沉**。

- 大型商业银行的普惠小微贷款占比从2020年末的**31.65%** 一路上涨至2025年末的**45.55%** ，6年间提升了近14个百分点
- 自2022年以来，大型银行在短期贷款市场份额持续攀升，至2026年2月已达**41.9%**
- 某股份行地市分行普惠金融部负责人直言：“大行下沉到地方后，靠着数字化优势和低利率贷款，我们15%-20%的存量普惠小微客户出现了流失。”

**“马太效应”的自我强化**：

> **“在‘僧多粥少’的信贷市场中，大行凭借政策、资金、技术、风险抵御能力的综合优势，通过低价贷款实现了市场份额的逆势扩张。”** 

这正是索罗斯所说的**反身性演进**——大行越强，越能获得政策支持；越有政策支持，越能抢占市场份额；市场份额越大，越“大而不能倒”。

### 2.5 “大而不能倒”的中国版本

索罗斯在第七章揭示的核心逻辑是：**“大而不能倒”不是一种保护，而是一种绑架。**

当一家银行“大到不能倒”时：

1. **监管者不敢让它倒** → 必须持续提供支持
2. **银行知道自己不会倒** → 道德风险上升，风险控制松懈
3. **风险在暗处累积** → 直到有一天，“不能倒”变成“救不动”

2026年的中国，这一逻辑同样在运行。

2023年10月召开的中央金融工作会议明确提出：**“支持国有大型金融机构做优做强，当好服务实体经济的主力军和维护金融稳定的压舱石。”** 

2025年，中央财政发行**5000亿元特别国债**向中国银行等大型银行注资。2026年，又有3000亿元特别国债用于注资银行。

**注资→更强→更大→更不能倒→更多注资**——这是一个完整的反身性循环。


## 三、反身性理论给中国投资者的启示

### 3.1 银行体系的“演进”不是“修复”

索罗斯最深刻的启示是：**银行体系在危机之后经历的，不是变得更健康，而是进化出了一种更危险的生存方式。**

对于中国投资者，这意味着：

- **不要将大行市场份额的提升视为“行业健康”的信号**——它可能是“集中化演进”的结果，而非“体系变强”的证据
- **低不良率不等于低风险**——在“共谋的幻象”下，真实的资产质量可能被掩盖
- **净息差持续下行是慢性病**——当银行赚钱越来越难时，它们可能被迫寻找更高风险的业务

### 3.2 识别“共谋的幻象”

索罗斯指出，集团体制的运转依赖于一个前提：**保持一种幻象，似乎未清偿贷款并未对银行造成损害**。

在中国，需要警惕的“幻象”包括：

| 幻象类型 | 表现 | 潜在风险 |
|---------|------|---------|
| **不良率幻象** | 不良率1.51%看似稳定 | 展期、重组、借新还旧掩盖了真实质量 |
| **利润幻象** | 大行利润依然增长 | 净息差1.29%下，利润靠“以量补价”维持 |
| **资产质量幻象** | 大行稳、中小行分化 | 中小行的压力可能通过传染效应影响大行 |

### 3.3 理解“二阶效应”

索罗斯在第七章揭示的最危险机制是：**维持幻象的行为本身，就在制造下一场危机。**

在中国，这一“二阶效应”正在显现：

- 银行为了维持利润增速，**不得不加大高风险领域的信贷投放**
- 为了“以量补价”，**贷款规模必须持续扩张**
- 但贷款规模的扩张，**又在进一步压低净息差**

**你越努力解决问题，问题就变得越大。** 这正是反身性最危险的地方。

### 3.4 “大而不能倒”的双刃剑

“大而不能倒”在短期内保护了金融体系的稳定，但长期来看：

- **它创造了道德风险**——大行知道“国家不会让我倒”，风险控制的激励被削弱
- **它扭曲了市场竞争**——大行享受低成本资金和政策支持，中小行被挤出市场
- **它集中了系统性风险**——当风险最终暴露时，它将是“系统性”的，而非“个体”的

对于投资者，这意味着：
- **不要因为“大而不能倒”就盲目买入大行股票**——估值可能已经反映了“保护溢价”，而真实的盈利能力在下降
- **关注中小行的“边缘化”进程**——当风险最终暴露时，最先受伤的可能是中小行的股东和债权人


## 总结：银行体系的演进，本质是反身性的自我实现

索罗斯在第七章最终传递的核心思想是：

> **银行体系在危机之后的“演进”，不是变得更健康、更稳健，而是进化出了一种更隐蔽、更危险的生存形态——集中化、共谋化、幻象化。大而不倒不是保护，而是慢性自杀的许可证。**

从1980年代的美国“金融中心银行”，到2026年的中国国有大行主导格局——反身性的逻辑从未改变：

| 维度 | 美国1980年代 | 中国2026 |
|------|------------|---------|
| **核心特征** | 金融中心银行主导 | 国有大行主导 |
| **集中度** | 少数银行持有绝大部分风险敞口 | 大行新增信贷占比56.6% |
| **监管态度** | 美联储“走得太远” | “支持国有大型金融机构做优做强” |
| **表面数据** | 账面繁荣、增加分红 | 不良率1.51%、大行稳健 |
| **真实风险** | 烂账暗藏、风险转移 | 净息差1.29%、中小行承压 |
| **二阶效应** | 转向杠杆收购和高风险借贷 | 大行下沉、中小行被挤出 |

索罗斯在1985年写下的这段话，至今仍是理解所有银行体系“演进”的最佳注脚：

> **“贷款的集团体制所赖以运行的基本原则是自愿合作，唯一可行的办法就是保持一种幻象，似乎未清偿贷款并未对银行造成损害。”**

在银行体系的世界里，**幻象从来不是例外——它是体系得以运转的常态。问题不在于幻象是否存在，而在于你能否在幻象破裂之前，看清它的真实面目。**

对于2026年的中国投资者，这意味着：

> **不要问“中国的银行体系稳不稳”——要问“当前的银行体系正在演进到什么方向？这种演进的代价是什么？当‘共谋的幻象’最终破裂时，谁会是第一个看清真相的人？”**

**在反身性的世界里，银行体系的每一次“演进”，都在为下一场危机铺路。**
