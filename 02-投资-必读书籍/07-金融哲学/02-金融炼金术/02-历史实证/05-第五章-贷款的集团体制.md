# 《金融炼金术》第5章读书笔记：贷款的集团体制

## ——当银行从“竞争”转向“共谋”，幻象就成了唯一的现实


## 总论：危机之后，银行不是变得更健康，而是学会了“假装健康”

索罗斯在第四章剖析了国际债务危机的反身性本质。到了第五章，他将镜头转向危机之后——**当债务危机爆发、银行体系濒临崩溃时，一个前所未有的“贷款集团体制”应运而生**。

这个体制不是精心设计的，而是“临时的、未经规划的”。它没有正式宣布过，从一开始就是过渡性的。然而正是这个临时的、非正式的安排，**将1980年代的国际金融体系从崩溃边缘拉了回来——代价是将一场急性危机，转化为一场漫长的慢性病**。

索罗斯在第五章揭示了一个令人不安的真相：

> **“贷款的集团体制所赖以运行的基本原则是自愿合作，唯一可行的办法就是保持一种幻象，似乎未清偿贷款并未对银行造成损害。”**

**幻象不是偶然的副产品——它是这个体制得以运转的核心燃料。**

对于2026年的中国而言，“贷款的集团体制”不是1980年代的遗物，而是正在中国银行业以另一种形态重演的现实——**大行主导、政府信用兜底、借新还旧、维持幻象**。理解这一章，就是理解中国金融体系“稳”字背后的真实成本。


## 一、从“竞争”到“合作”：贷款体制的反身性逆转

### 1.1 旧体制（竞争型）：正向反身性

1982年债务危机之前，国际贷款体制是**竞争型**的：

> **银行为了追逐利润而自愿提供贷款，并且相互之间竞争激烈。**

在这种体制下，反身性体现为**正向循环**：

> **银行贷款意愿强 → 债务国获得更多资金 → 偿债能力“因贷款而改善”→ 更多银行愿意贷款 → 债务进一步累积**

索罗斯的洞见是：**银行的贷款行为本身，创造了债务国“信用良好”的假象**。每家银行都认为自己只是在“响应基本面”，却没有意识到——**正是集体的贷款行为，在创造和维持那个所谓的“基本面”。**

### 1.2 新体制（合作型）：反向反身性

1982年墨西哥等国违约后，旧体制崩塌。取而代之的是一个**合作型**的新体制：

> **银行被迫进行贷款，以求保存它们已经投入的资产，而为了达到这一目标，就必须同其他银行密切合作。**

新体制中的反身性是**反向的**：

> **银行无力也不愿贷款 → 债务国偿债能力下降 → 银行更不愿贷款 → 债务国更无力偿还**

**这不是一个均衡，而是两个下行螺旋的相互碰撞。** 如果没有外力干预，“这一体制必然就此寿终正寝”。

### 1.3 从“追逐利润”到“保存资产”：银行行为的质变

旧体制与新体制的核心区别，不在于“贷款多少”，而在于**贷款的动机**：

| 维度 | 旧体制（竞争型） | 新体制（合作型） |
|------|----------------|----------------|
| **动机** | 追逐利润 | 保存已有资产 |
| **驱动力** | 自愿 | 被迫 |
| **银行间关系** | 竞争 | 合作 |
| **反身性方向** | 正向（自我强化繁荣） | 反向（自我强化萧条） |
| **核心逻辑** | 贷得越多赚得越多 | 不贷就会全盘皆输 |

索罗斯的核心判断是：**新体制“基于保存债务完整性的原则”** ——不是为了帮助债务国发展，而是为了**让银行的资产负债表看起来依然健康**。


## 二、贷款集团体制的运作机制：“共谋的幻象”

### 2.1 挽救一揽子计划：谁在参与？

索罗斯描述了1982年危机后形成的“挽救一揽子计划”：

| 参与方 | 角色 |
|--------|------|
| **国际货币基金组织（IMF）** | 组织谈判、监督协议执行 |
| **国际清算银行（BIS）** | 提供协调与清算 |
| **各国政府与中央银行** | 提供政治背书与最后贷款人职能 |
| **商业银行** | 提供新增贷款 |

以墨西哥为例，牵涉到的商业银行多达**500家**。将这些参与者冠以“**集团**”的称号是合适的——**它既不是市场，也不是政府，而是一种介于两者之间的、非正式的卡特尔**。

### 2.2 “借新还旧”：幻象的制造工艺

集团体制的核心操作是**借新还旧**：

1. **银行继续给还不起钱的国家发放新贷款**
2. **这笔钱转手就变成了利息，流回银行**
3. **账面上，利息收到了，贷款是“正常”的**
4. **坏账准备金？不提。承认风险？不认。**

索罗斯一针见血地指出：

> **“债务国必须做出让步才有可能偿还债务，而每一次的让步都加重了未来的偿债负担。”**

每一次“救助”都在增加债务国的总债务，而不是减少它。**集团体制不是在解决问题，而是在延缓问题——并让问题变得更大。**

### 2.3 美联储的角色：走得“太远”的监管者

索罗斯批评美联储在支持金融中心银行方面“走得太远了”：

- **美国监管层允许银行把那些重组过的、仅仅停留在纸面上的利息算作本期收益**
- **美国的大银行明明肚子里全是烂账，脸面上却红光满面，甚至在1983年还增加了股息分红**

结果是什么？

> **“问题非但没有暴露，反而更形严重了。”**

推迟痛苦、掩盖问题——这正是集团体制的本质。索罗斯指出，相比之下欧洲央行更倾向于让银行“赶紧认栽，建立储备，冲销坏账”。但美国选择了另一条路：**用幻象维持稳定，用时间换取空间——代价是让问题在暗处滋长**。

### 2.4 反身性的“二阶效应”

索罗斯进一步指出，集团体制还有一个更隐蔽的反身性效应：

- 银行为了掩盖旧伤，**不得不去寻找新的、收益更高的（通常风险也更大的）业务来填坑**
- 这直接导致了美国银行业随后在**杠杆收购和高风险借贷**上的疯狂

**维持幻象的行为本身，就在制造下一场危机。** 这正是反身性的“二阶效应”——你为解决问题而采取的行动，恰恰在创造新的、更大的问题。


## 三、中国的“贷款集团体制”：2026年的现场演绎

### 3.1 大行主导：中国版的“银行集团”

1980年代的国际贷款集团体制，以“多家银行合作”为特征。而2026年的中国，呈现出一个**更集中、更制度化的版本**——**以国有大型银行为核心的信贷集团**。

**关键数据**：

- 2025年，**大型银行新增人民币贷款10.66万亿元**，占各类型银行新增信贷的**56.6%**，创历史新高
- 2018年，这一占比仅为**34.8%** ——六年间上升了近22个百分点
- 截至2026年2月，大型银行在短期贷款市场份额已达**41.9%**
- 四大行对贷款增量的贡献已从2018年的不到30%升至2025年的**51.2%**

**这不是市场竞争的结果，而是一种结构性的“集团化”——信贷资源越来越集中于少数几家“系统重要性”银行。**

### 3.2 财政化：信贷扩张的新模式

索罗斯笔下的集团体制，核心特征是“借新还旧”——银行发放新贷款以维持旧贷款的账面健康。

2026年的中国，这一模式以**“财政化”** 的形式呈现：

- 2025年前三季度，**政府债券净融资高达11.46万亿元**，同比多增4.28万亿元
- 社融统计口径内的各项贷款在社融增量中的占比首次跌破50%，降至**48.3%**
- 2026年银行资产扩张“**财政化**”有望加速推进

**谁在借钱？政府。谁在承接？银行。** 银行购买政府债券，政府用这笔钱进行基建投资、置换地方债务——**这本质上是一种“借新还旧”的变体**，只不过债务主体从拉美国家换成了中国各级政府。

### 3.3 监管的“积极而富于想象力的干预”

索罗斯在第五章开篇就指出：

> **“如果不是管理当局进行了积极而富于想象力的干预，国际债务危机势必令银行体系陷入崩溃。”**

2026年的中国，监管的“积极干预”同样无处不在：

- **宏观审慎和金融稳定管理工具箱**不断完善
- **MPA考核**引导信贷投向“五篇大文章”（科技金融、绿色金融、普惠金融、养老金融、数字金融）
- **结构性货币政策工具**余额已达**4.3万亿元**
- **并购贷款新规**落地，支持战略性新兴领域
- **六大行密集披露2026年信贷路线图**，集团贷款增速与上年保持平稳

这些干预与索罗斯笔下1980年代的国际贷款集团体制，有着惊人的相似逻辑：**当市场机制失效时，监管与银行形成“合作型”关系，共同维持系统的表面稳定。**

### 3.4 幻象的代价：净息差与资产质量

索罗斯警告：集团体制的代价是“问题非但没有暴露，反而更形严重了”。

2026年的中国银行业，正在为此付出代价：

- **净息差已降至历史低位**
- 按揭与信用卡风险上升
- 贷款需求疲软，银行将资金投向国债
- 2026年银行面临**规模较大的三年期及五年期等长期存款到期重定价**

**维持幻象的成本，正在以净息差收窄、资产质量承压的方式，被整个银行体系所消化。** 索罗斯在1985年写下的警告，在2026年的中国依然振聋发聩。

### 3.5 化债：中国版的“保存债务完整性”

索罗斯指出，贷款集团体制“基于保存债务完整性的原则”。

2024年11月推出的**10万亿元化债“组合拳”** ，本质上也是同一逻辑：

- **用国家信用置换地方信用**
- **用低息债务置换高息债务**
- **用时间换取空间**

2025年，用于置换存量隐性债务的**2万亿元**地方政府债券全部发行完毕。2026年是一揽子化债方案的**收官攻坚年**，中央首次将地方政府融资平台经营性债务风险纳入重点化解范围。

**化债不是在消灭债务，而是在重组债务——让债务从“违约”变成“展期”，从“高危”变成“可控”。** 这正是索罗斯所说的“保存债务完整性”的中国版本。


## 四、反身性理论给中国投资者的启示

### 4.1 识别“集团体制”的幻象

索罗斯最深刻的启示是：**当银行和监管者“合作”维持幻象时，市场信号是失真的。**

在中国，这意味着：

- **不良率数据可能被低估**——展期、重组、借新还旧掩盖了真实的资产质量
- **利润数据可能被高估**——当银行通过“以量补价”维持利润时，真实的盈利能力在下降
- **“稳”的表象下，可能隐藏着“危”的累积**

**不要被表面的“稳”所迷惑——集团体制的本质，就是用幻象替代现实。**

### 4.2 理解“大而不倒”的反身性

索罗斯笔下的贷款集团体制，核心驱动力是“**大而不能倒**”。

在中国，这一逻辑同样成立——**大型银行、地方政府融资平台、系统重要性金融机构，都处于“不能倒”的保护伞之下**。

但反身性告诉我们：**“不能倒”的保护本身，就在创造更大的风险**。因为：

- 被保护者会有**道德风险**——既然不会倒，就不需要严格控制风险
- 保护者会被**绑架**——越是不敢让它们倒，它们就越“大”
- 风险会在暗处**累积**——直到有一天，“不能倒”变成“救不动”

### 4.3 关注“二阶效应”

索罗斯指出，集团体制的一个隐蔽后果是：**银行为了掩盖旧伤，不得不去寻找新的、风险更高的业务**。

在中国，这一“二阶效应”正在显现：

- 银行为了维持利润增速，**不得不加大高风险领域的信贷投放**
- 为了“以量补价”，**贷款规模必须持续扩张**
- 但贷款规模的扩张，**又在进一步压低净息差**

**这是一个自我强化的困境——你越努力解决问题，问题就变得越大。**

### 4.4 “集团体制”终将被替代

索罗斯明确指出：

> **“贷款集团体制的确立没有经过认真的规划，甚至没有正式宣布过，它从一开始就是过渡性的，并且注定将被某种另外的形式所替代。”**

对于中国投资者，这意味着：

- 当前的“大行主导+政府信用兜底”模式**不是永久的**
- 制度变革（如直接融资占比上升、金融开放）**正在逐步改变这一格局**
- **当“替代”发生时，估值体系将发生系统性重估**

2025年，人民币贷款占比首次跌破50%，直接融资占比升至47.4%——**替代已经开始，只是大多数人还没有意识到。**


## 总结：幻象不是例外，而是体制的常态

索罗斯在第五章最终传递的核心思想是：

> **贷款的集团体制不是一个“错误”，而是一个“必然”——当旧体制崩溃时，参与者为了生存，不得不临时构建一个合作型的、基于幻象的新体制。这个体制维持了系统的表面稳定，却让问题在暗处滋长。幻象不是例外——它就是体制的常态。**

从1982年的拉美债务危机，到2026年的中国信贷体系，反身性的逻辑从未改变：

- **繁荣时，贷款创造信用**——银行争相放贷，债务国的偿债能力“因贷款而改善”
- **危机时，信用停止创造危机**——银行停止放贷，债务国的偿债能力“因贷款停止而恶化”
- **危机后，集团维持幻象**——银行合作放贷、借新还旧、保存债务完整性

**每一次循环都在重复同一个模式——只是换了一批参与者、换了一套术语、换了一副面孔。**

对于2026年的中国投资者，这意味着：

> **不要问“中国的银行体系稳不稳”——要问“当前的集团体制正在维持什么样的幻象？这个幻象还能维持多久？当幻象破裂时，谁会是第一个看清真相的人？”**

索罗斯在1985年写下的这段话，至今仍是投资者最好的提醒：

> **“贷款的集团体制所赖以运行的基本原则是自愿合作，唯一可行的办法就是保持一种幻象，似乎未清偿贷款并未对银行造成损害。”**

**在金融的世界里，幻象从来不是例外——它是体制得以运转的常态。问题不在于幻象是否存在，而在于你能否在幻象破裂之前，看清它的真实面目。**
