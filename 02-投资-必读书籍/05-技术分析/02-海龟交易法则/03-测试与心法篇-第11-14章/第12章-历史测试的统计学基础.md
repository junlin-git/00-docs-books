> 原著：柯蒂斯·费思（Curtis Faith）｜Way of the Turtle
> 
> **章首定调**：历史模拟结果最多只是对未来趋势的**粗略感觉**。但即便是粗略的认识，也给优秀交易者足够大的优势。问题在于——大多数人用**拙劣的方法**做历史测试，得到一个漂亮的数字后就信心满满，殊不知那个数字的预测价值可能**为零甚至为负**。本章讲的，就是如何让这"粗略估计"尽可能靠谱。

## 一、为什么历史测试既必要又危险：章首的"谦虚立场"

费思开篇就设定了正确的预期——

### 1.1 "用拙劣的方法做交易，就像站在暴风骤雨中的一叶小舟上学杂耍"

历史测试之所以被滥用，是因为：

- 软件让回测变得**太容易**——点几下就出一张漂亮的 equity curve
- 但大多数人**不知道统计学前提**，把"拟合过去的巧合"当成"预测未来的能力"
- 第十一章已经拆完了**骗子陷阱**（交易者效应、随机效应、过拟合、最优化矛盾），本章转向建设性：**如果你一定要做历史测试，怎么让它尽量不骗你？**

### 1.2 统计学的基本承诺（也是全部合法性的来源）

> 核心逻辑：**通过样本特征推断总体特征。**
> - 如果你有**足够大且有代表性**的样本 → 你可以近似推断总体 → 历史测试有意义
> - 如果样本**太小或不具代表性** → 测试数字好看也毫无预测价值

民意调查就是同一个逻辑：从州里随机抽500人→推断全州选民倾向。**但**如果在民主党大会上抽500人→"全美都爱民主党"——样本规模够大（500），但**不具代表性**，结论一文不值。

交易者最常犯的正是这个错误：只测最近3年数据（刚好牛市/刚好震荡）→ 等于在"民主党大会"取样。

## 二、测试样本的有效性：两个支柱

> *"样本分析在统计学上的有效性受两大因素影响：**样本规模**和**样本对总体的代表性**。"*

### 2.1 支柱Ⅰ：样本规模——不只是"交易次数"

| 常见误解 | 正确理解 |
|---------|---------|
| "我测了2000根K线/1200笔交易，样本超大！" | 样本规模不只看总数，**还要看你正在测试的"法则/信号"在样本中实际生效了几次** |
| 认为有个"神奇数字"一到就灵 | 没有魔法数字，但有经验底线（见下） |

**经验基准**（费思给出）：

| 交易次数 | 说服力 |
|---------|-------|
| **< 20次** | 严重偏差，任何结论都不可信 |
| **> 100次** | 开始有预测价值 |
| **数百次** | 对大多数系统测试来说够用了 |
| **越大越好** | 样本越大→推理越准确→误差幅度越小 |

⚠️ 关键洞见：

> 一条法则在整个测试期内**只生效了4次**，那你根本无从判断它是不是真有用——你看到的效果**很可能只是随机性**在扮好看。

### 2.2 支柱Ⅱ：样本对总体的代表性——更隐蔽、更致命

代表性问题回答的是：**你的样本，真的是"未来市场"的微缩模型吗？**

#### 市场至少有4种状态（第二章框架的呼应）

| 市场状态 | 特征 | 哪种策略吃香 |
|---------|------|------------|
| 稳定—平静 | 窄幅横盘 | 反趋势/做市 |
| 稳定—波动 | 宽幅横盘 | 反趋势吃香，趋势策略挨揍 |
| 有趋势—平静 | 流畅单向走 | 趋势跟踪天堂 |
| 有趋势—波动 | 剧烈但方向性 | 趋势跟踪能赚但回撤深 |

如果你只测了 **2017~2020（震荡）→ 反趋势系统爆表**，或只测了 **2020~2021（单边牛）→ 趋势系统无敌**，都等于**取样偏差**。

#### 最常见的一种代表性崩溃：近期偏好驱动的短视测试

> 交易者只看最近发生的事 → 用最近3~5年数据测试 → 误以为"这就是市场的本来面目" → 实则是**用局部代替整体**，等同于在民主党大会抽样本。

费思的吐槽很尖锐：

> *"年轻是好事，但不要太愚蠢——一定要学历史。年轻人往往看不到历史的价值，就因为历史发生在他们出生之前。"*

#### 两个放大器：小样本问题如何被人为放大

| 放大器 | 为什么更糟 |
|--------|-----------|
| **① 单一市场最优化** | 把系统单独在某一个品种上优化 → 该品种的样本交易次数更少 → 统计说服力急剧下降 → 过拟合风险暴增 |
| **② 过于复杂的系统** | 法则太多 → 每条法则生效频率更低 → "某条法则到底有没有用"更难判断 → 你更容易把随机巧合解读为规律 |

> **费思的建议**：❌ 不建议针对单个市场做最优化；✅ 更喜欢**简单、具备统计学意义的理念**（参数越少，自由度越低，越难过拟合）。

## 三、衡量指标的稳健性：为什么你的"漂亮夏普比"可能是海市蜃楼

> *"如果对数据稍作改动并不会显著影响一个统计指标，我们就说这个指标是**稳健的（robust）**。"*

这是全章的方法论枢纽。

### 3.1 传统三大指标为什么不稳健

| 指标 | 全称 | 为什么不稳健 |
|------|------|------------|
| **CAGR** | 平均复合增长率（Compound Annual Growth Rate） | 对测试起止日极度敏感——起止日掐掉/加上一段，CAGR跳来跳去，因为它是"起→止"的端点函数 |
| **MAR比率** | MAR = CAGR / 最大回撤 | MAR的分子和最大回撤都对起止日敏感 → 双重敏感 |
| **夏普比率（传统）** | 月度平均回报 / 月度回报标准差 | 分子用"平均回报"而非回归线 → 仍受极端月份/起止日框选影响 |

费思给了一个实证级别的演示（以海龟式系统为例）：

- 三重移动均线系统：起止日微调（1月初→2月初，6月底→4月底，只差3个月）→ **CAGR 43.2%→46.2%，MAR 1.39→1.61，夏普 1.25→1.37**
- ATR通道突破系统：同样微调 → **CAGR 51.7%→54.9%，MAR 1.31→1.49**

→ 仅仅**3个月的数据出入**，指标就跳了 **10%~20%**。短于10年的测试尤其夸张。

**这意味着什么？**

如果你的"最优参数"是靠这种敏感指标选出来的 → 你选的可能不是真正的优势，而是**对那段特定时间框架的过拟合**。

### 3.2 解法一：回归年度回报率 —— RAR

#### 什么是RAR？

不用"起点→终点的复合增长"，而是对**净值曲线做线性回归**，回归线的斜率所代表的年化回报率就叫 **RAR（Regressed Annual Return）**。

| 对比 | CAGR | RAR |
|------|------|-----|
| 本质 | 只关心首尾两个端点 | 用**整条曲线上所有点**拟合成一条直线 |
| 对起止日掐头去尾的反应 | 剧烈跳变 | 变化极小（因为去掉几个月只是少了几个散点，不改变整条回归线太多） |
| 直觉 | 像"期末考成绩" | 像"学期平均成绩趋势线" |

> RAR的核心优势：**它不是端点函数，所以不容易被"恰好起止日包含/不包含某次大衰落"绑架。**

### 3.3 解法二：稳健风险回报比率 —— R³（R立方）

#### 为什么最大回撤（Max Drawdown）不够？

传统最大回撤只看**最深的那一次坑**，但它忽略了一件至关重要的事——

> 亏30%花了**2个月**爬回来 vs 亏30%花了**2年**爬回来 → 用户体验和风险压力**天差地别**，但传统MDD把它们记为同一个数。

#### R³的构造

R³（R立方）= RAR / 长度调整平均最大衰落

**（1）分子 = RAR**（已解决"端点敏感"问题）

**（2）分母 = 长度调整平均最大衰落**，有两层考量：

| 要素 | 计算 | 解决什么问题 |
|------|------|------------|
| **平均最大衰落** | 取**前5次最大衰落**的幅度，求平均 | 不只看"最惨的一次"（避免被单次极值绑架），用多峰平均更稳 |
| **长度调整** | (这5次衰落的平均持续天数 / 365) × 平均最大衰落 | 把"持续时间"折算进来——恢复越慢，惩罚越大 |

举例（费思书内示意）：

> RAR = 50%，平均最大衰落 = 25%，5次平均衰落天数 = 365天（整整一年）
> → 长度调整 = 25% × (365/365) = 25%
> → **R³ = 50% / 25% = 2**

#### R³ vs MAR

| | MAR | R³ |
|--|-----|-----|
| 分子 | CAGR（端点敏感） | RAR（回归线，稳健） |
| 分母 | 单次最大回撤（幅度-only） | 平均Top5回撤 + 时长折算（幅度+时间） |
| 对起止日变化 | 敏感 | **远更不敏感** |

### 3.4 解法三：稳健夏普比率

传统夏普： 月度平均回报 / 月度回报标准差

稳健夏普： **RAR / 年度化的月度回报标准差**

→ 把分子从"平均回报"（可被极端月份扭曲）换成RAR → 指标整体对时间框选的敏感度大幅下降。

### 3.5 稳健指标的三重价值（为什么要折腾这些？）

| 价值 | 说明 |
|------|------|
| ① 不那么容易被运气摆布 | 随机巧合造不出稳定的回归线 |
| ② 帮你发现过拟合 | 不稳健指标会让过拟合的系统看起来"超神"；稳健指标会冷冷地把它打回原形 |
| ③ 让相对比较更有意义 | 两个系统PK时，用R³比用MAR更不容易被"恰好哪个时间段包含大衰落"干扰 |

## 四、样本代表性的实操法则：你的数据"够不够好"？

### 4.1 两个操控杆

| 操控杆 | 怎么做 | 为什么 |
|--------|--------|--------|
| **市场数量** | 测**越多不同的市场**越好（不同板块/不同资产类/正负相关混合） | 单一市场只能暴露一种生态；多市场→各种状态更容易被囊括 |
| **测试时间跨度** | **把所有能拿到的数据都测一遍**，尽量覆盖多个年代 | 时间越长 → 越可能碰到牛市/熊市/危机/平静/暴涨暴跌 → 样本更接近"全状态集合" |

费思的态度几乎是偏执的：

> *"把你能得到的数据都测试一遍。买数据花不了多少钱，但如果没有经过多个市场多个年头的充分测试就盲目相信一个系统——风险太大了。"*

### 4.2 反例：泡沫期陷阱

互联网泡沫年代，人人都是"短线天才"，因为那段特殊时期几乎所有东西都只涨不跌。**如果测试样本只采自那段时间** → 你的样本=民主党大会样本 → 结论在未来崩盘后**完全作废**。

**市场有周期性，也经常回归到过去出现过的状态**——你的测试只有"见过"那些状态，才算合格。

## 五、从虚拟测试到实战：三个"压力测试"方法

这是全章最实用的部分——回答了那个扎心问题：

> *"就算我用了稳健指标+大样本+多市场，我怎么知道我不是刚好走运？"*

### 5.1 方法①：参数调整检验（Parameter Perturbation）

#### 怎么做

- 把你系统的最优参数 **粗调 20%～25%**（不是精细微调±5%）
- 看系统表现会不会**断崖式崩塌**

#### 怎么解读

| 结果 | 含义 |
|------|------|
| 参数一换，收益几乎不变 | ✅ 系统是**稳健的**——优势来自理念而非数字巧合 |
| 参数一换，收益暴跌/变负 | 🚩 你的"最优解"很可能是**对这段历史数据过拟合的产物**——不是真优势 |

> 逻辑：如果只有那个精确到小数点的参数值才行，其他地方都不行→说明你拟合的是**那段特定数据的噪声**，不是可重复的市场规律。

### 5.2 方法②：滚动最优化窗口（Walk-Forward / Rolling Window）

这是费思花相当篇幅描述的**最贴近实战的验证框架**。

#### 怎么做（步骤）

Step 1：回到8~10年前的某一天D
Step 2：只用 D 及之前的所有数据做最优化（假装你活在那天，没有未来数据）
Step 3：用优化出的参数，去跑 D 之后【接下来两年】的 out-of-sample 测试
→ 记录这两年的实际表现
Step 4：窗口顺延两年 → 重复 Step 2~3
直到推进到现在
Step 5：汇总所有 out-of-sample 段的表现

#### 为什么要这么做

| 问题 | 普通回测 | 滚动窗口 |
|------|---------|---------|
| 用了未来信息？ | 容易不知不觉用到 | ❌ 严格隔离——优化段和检验段绝不重叠 |
| 过拟合隐藏其中？ | 隐藏很深 | 一到OOS段就现形 |
| "最优参数"的稳定性 | 看起来稳 | 你发现**每一轮的'最优参数'都不一样**，OOS表现比in-sample差一大截（费思提到差约30%） |

> **启示**：即便是最好的系统，in-sample 和 out-of-sample 之间也存在落差——这就是**最优化矛盾的现实版本**。你做滚动窗口不是为了"证明系统完美"，而是为了**摸清楚它在不同时期的真实韧性区间**。

### 5.3 方法③：蒙特卡洛检验（Monte Carlo Simulation）

费思介绍了两种在交易净值曲线上的蒙特卡洛思路：

#### A. 交易调整（Trade Permutation / Resampling Trades）

- 把历史模拟产生的交易序列拿出来
- **随机打乱交易顺序**，或随机偏移起始日
- 用调整后的交易序列重新拼出净值曲线
- 重复上千次 → 得到**别样净值曲线的分布**

> 逻辑：实际交易中，同样一批赢家和亏家的出现**顺序**是不可控的——蒙特卡洛帮你问："如果倒霉的-1R连亏来得比历史更早更密，你的资金和心态扛得住吗？"

#### B. 净值曲线调整（Equity Curve Resampling）

- 把净值曲线切成若干段
- 随机选取不同段重新拼接组合
- 生成大量**替代净值曲线**
- 观察RAR、R³等指标在这些替代曲线上的分布范围

#### 蒙特卡洛告诉你什么

| 它能做 | 它不能做 |
|--------|---------|
| 让你看到"同等统计特征下的其他可能苦命版本" | 不能创造历史中没有的极端事件（黑天鹅仍在外面） |
| 帮你在心理上和资金规划上预留更保守的安全边际 | 不能把坏系统变好 |
| 检测系统对"坏运气排列"的脆弱性 | 不能消除最优化矛盾的根本不确定性 |

## 六、全章结论：历史测试的正确姿态

> *"历史测试充其量只是对未来趋势的粗略估计。稳健指标对未来表现的预测价值要高于较敏感的指标，但仍然谈不上精确。"*

费思给了两条硬边界：

1. **如果有人号称你的回报'一定能达到'某个精确到小数点后的数字——这人要么在撒谎，要么根本是外行；如果他正向你推销什么，我强烈怀疑是前者。**
2. 但——有粗略估计 **远好于** 没有估计。关键是让这个"粗略"尽可能**诚实**：用稳健指标 + 大代表性样本 + 压力验证去框住误差幅度。

## 七、章内核心概念速查表

| 概念 | 符号/缩写 | 一句话 |
|------|----------|--------|
| 样本规模 | — | 交易次数够不够（>100起步，数百较稳） |
| 样本代表性 | — | 样本有没有覆盖多种市场状态，还是只采了"民主党大会" |
| CAGR | Compound Annual Growth Rate | 首尾端点函数→对起止日敏感→**不稳健** |
| MAR比率 | CAGR / MaxDD | 分子+分母都敏感→**不稳健** |
| 夏普比率（传统） | 月均回报 / 月标准差 | 分子靠均值→**不够稳健** |
| **RAR** | Regressed Annual Return | 净值曲线线性回归斜率→**稳健** |
| **平均最大衰落** | Top5 MDD 幅度均值 | 用多峰平均取代单次极值 |
| **长度调整** | (AvgDays/365) × AvgMaxDD | 把"恢复时长"折算进风险 |
| **R³ / R立方** | RAR / 长度调整平均最大衰落 | 稳健的 回报/风险 综合尺 |
| **稳健夏普** | RAR / 年化月标准差 | 稳健版的夏普 |
| 参数调整检验 | Perturbation ±20%~25% | 粗调看塌不塌→测过拟合 |
| 滚动最优化窗口 | Walk-Forward | in-sample优化 / OOS检验 / 顺延循环 |
| 蒙特卡洛 | MC resampling | 打乱顺序/重组曲线→测运气敏感度 |

## 八、给你的实操清单（读完马上能用）

### 🔍 审计你上一次回测报告的"三问"

□ Q1【代表性】我的测试数据覆盖了哪些市场状态？有没有只测了牛市/只测了最近3年？
→ 补救：拉更长年份 + 加负相关品种（债券/黄金/外汇）一起测
□ Q2【指标】我用来判断"这个系统最好"的排名尺子是 CAGR/MAR/夏普（传统），还是 RAR/R³？
→ 补救：至少把 RAR 和 R³ 加进报告；对任何"最优参数"用 ±20% 粗调炸一遍
□ Q3【验证】我有没有 out-of-sample 检验？还是全程 in-sample 漂亮曲线？
→ 补救：做一次滚动窗口（哪怕只分两段：前半优化→后半测，后半优化→再后半测）

### 📐 最简 R³ 速算模板（你可以直接抄进Excel）

    对净值序列做线性回归 → 斜率年化 = RAR（%）
    找出历史 Top5 最大回撤（幅度 %）→ A = AVERAGE(Top5_MDD%)
    对应 Top5 回撤的持续天数 → B_avg_days = AVERAGE(Top5_Days)
    长度调整平均最大衰落 = A × (B_avg_days / 365)
    R³ = RAR / [A × (B_avg_days / 365)]
