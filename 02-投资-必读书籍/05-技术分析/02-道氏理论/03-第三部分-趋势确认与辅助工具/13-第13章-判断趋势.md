## 一、趋势识别的根本方法：峰谷分析（Peak-and-Trough Analysis）

### 1.1 核心定义：什么是"上升趋势"，什么是"下降趋势"

道氏理论不依赖均线、不依赖指标，而是回到**价格本身的几何结构**——看每一波上涨能否越过前高，每一次回撤能否守住前低。

| 趋势方向 | 价格行为的精确定义 |
|----------|-------------------|
| **上升趋势（牛市主要运动进行中）** | 连续的价格回升 **超过前期的高点**（higher highs），且随后的下跌 **能在前期低点上方结束**（higher lows）。即：**一系列不断抬高的波峰 + 不断抬高的波谷** |
| **下降趋势（熊市主要运动进行中）** | 价格的回升 **没能超越前期的高点**（lower highs），且随后的下跌 **跌破前期的低点**（lower lows）。即：**一系列不断降低的波峰 + 不断降低的波谷** |
| **趋势未定 / 过渡状态** | 既不形成清晰的更高-更高，也不形成清晰的更低-更低——此时**不急于定性**，等待确认 |

用汉密尔顿的话说（雷亚引述）：

> *"对于没有得到另一个价格指数确认的走势，查尔斯·道通常认为这种走势无足轻重。并且自从他去世以后，市场经验已经多次证明了这种读取平均价格指数的智慧。"*

---

### 1.2 牛市信号与熊市信号的判别句式（本章最核心的两句话）

#### 🐂 牛市信号（趋势向上确立 / 恢复）

> **连续的价格回升超过前期的高点，伴随接下来的下跌能在前期低点上结束——这就是牛市的信号。**

翻译成操作语言：

低点A → 高点B（突破前高B₀）
↘ 回调至低点C
条件：C ≥ 前期低点A₀（不破前低）且 B > B₀（已过前高）
⇒ 上升趋势有效延续 / 重启

#### 🐻 熊市信号（趋势向下确立 / 转变）

> **如果价格的回升没能超越前期的高点，并且随后下跌的低点比先前的低点更低——那么这就是熊市的信号。**

翻译成操作语言：

高点A → 低点B（跌破前低B₀）
↗ 反弹至高点C
条件：C ≤ 前期高点A₀（不过前高）且 B < B₀（已破前低）
⇒ 下降趋势有效延续 / 主导

⚠️ **这里的深层含义**：道氏理论并不在每一天都宣布"牛市开始了"或"熊市开始了"。它只在**高低点结构发生质变**时才做判断——而且这种判断是**回溯确认**而非前瞻性赌注。

## 二、3% 门槛：什么是"值得认真对待的"反弹或回调

### 2.1 为什么要设门槛

如果只是盘中瞬间刺穿前高就叫作"突破"，市场会被无数微小的日间波动淹没，产生大量假信号。因此雷亚明确给出一个操作性定义：

> **为了便于讨论，价格的恢复或下跌被定义为：一个或多个交易日导致任意一种平均价格指数超过 3% 的净逆转。**

| 术语 | 含义 |
|------|------|
| **回升 / 反弹**（Rally / Recovery） | 在下跌段落中，价格向反方向运动——但**必须使平均指数净回升 ≥ 3%**，才被视为一个"有意义"的回升 |
| **下跌 / 回调**（Decline / Reaction） | 在上升段落中，价格向反方向运动——但**必须使平均指数净回落 ≥ 3%**，才被视为一个"有意义"的次级回调 |
| **日间波动（不予理会的部分）** | 不足 3% 的逆势抖动——归入"市场噪音"，不构成趋势判定的依据 |

> 这 3% 不是神圣常数，而是一种**过滤噪声的实用阈值**。其核心精神是：**只有足够力度的运动才值得纳入峰谷分析框架；其余都是涟漪。**

### 2.2 3% 与"次级运动"的关系

- 次级反应运动（Secondary Reaction）通常历时 **10天～3个月**，回撤幅度约主要运动的 **1/3 ～ 2/3**
- 但仅凭幅度和时间还不够——你还需要看到它在峰谷结构上**与主要趋势发生关系**（突破前高或跌破前低）
- 第13章强调：**3%规则是用来识别"这到底是不是一个次级运动"的第一步筛选**，然后再用峰谷分析看它是否威胁主要趋势

## 三、铁律：两个平均价格指数必须互相确认

### 3.1 为什么是"两个"而不是"一个"

道的原始设计里，两大平均指数是：
| 指数 | 代表的经济含义 |
|------|----------------|
| **道琼斯工业平均指数（DJIA）** | 制造、生产、消费端的利润与预期 |
| **道琼斯运输业平均指数（DJTA）** | 物流、货运、铁路——**生产出来必须运出去卖出去才有意义** |

逻辑链条：
> 工业企业利润上升 → 产量增加 → 货运量增加 → 运输企业收入上升  
> 两者**必须同步验证**，才能确认一轮真实的、由经济基本面支撑的主要趋势。

### 3.2 确认规则（第13章重申的版本）

| 情形 | 单指数行为 | 另一指数行为 | 道氏结论 |
|------|-----------|-------------|---------|
| **有效牛市确认** | 工业指数收盘突破前期重要高点 | 运输指数 **也在合理时间内**（不必同一天，但通常不远）突破自身对应高点 | ✅ 牛市信号 **有效** |
| **有效熊市确认** | 工业指数收盘跌破前期重要低点 | 运输指数也跌破自身对应低点 | ✅ 熊市信号 **有效** |
| **背离（Divergence）** | 工业创新高，运输 **未**创新高 | — | ⛔ **不确认**——道认为这种走势"无足轻重"，至少不足以宣告主要趋势改变 |
| **单指数假突破** | 一个指数越过前高，另一个止步不前 | — | 视为**警告信号**，而非行动信号 |

> 汉密尔顿/雷亚反复强调：**"两个指数相互确认，未必要求发生在同一天"**——允许一个指数先到、另一个稍后追上，但不能差得太远、也不能最终不追上。

### 3.3 本章引出的一个关键推论

> **一个次级下跌趋势或许最终来看它属于主要运动——但只有当两个平均价格指数的新低都低于前期回调的低点时，这种可能性才会确立。**

换言之：
- 单指数破前低 ≠ 趋势反转
- **双指数共振破前低** = 才有资格讨论主要趋势的转变

## 四、趋势的存续假设：在没有确凿反转信号前，假定趋势继续

这可能是全章**最反直觉也最重要**的哲学原则——

### 4.1 "趋势存在直到被证明结束"

| 默认假设 | 含义 |
|----------|------|
| **上升趋势有效** | 直到你看到：**跌破前低 + 反弹不过前高**（双条件同现） |
| **下降趋势有效** | 直到你看到：**越过前高 + 回调不破前低**（双条件同现） |

雷亚/汉密尔顿的立场是：
- 市场充满**次级折返的假动作**（牛市里的急跌吓人、熊市里的急弹诱多）
- 过早"判定趋势反转"是散户亏损的核心原因之一
- 因此道氏方法的保守性体现为：**宁可晚一点确认反转，也不要早一点误判**

> 正如查尔斯·道的原意：*给趋势"疑罪从无"——没有确凿的反转证据，趋势就还在。*

## 五、本章工具箱总结：从价格到判定的完整流程

① 看收盘价（道氏只看收盘/接近收盘价位，不盯日内高低）
│
② 过滤：逆势运动是否 ≥ 3%？（否 → 归入噪音，忽略）
│
③ 是 → 标记为一个"有意义的"峰或谷
│
④ 排列峰谷序列：
┌─ 更高的高点 + 更高的低点？ → 上升趋势（牛市结构）
├─ 更低的高点 + 更低的低点？ → 下降趋势（熊市结构）
└─ 混乱 / 横盘？ → 无定论，等待
│
⑤ 交叉验证：工业指数 AND 运输指数的峰谷结构是否一致？
├─ 一致 → 趋势判定有效
└─ 背离 → 信号无效 / 高度警惕 / 等待进一步展开
│
⑥ 结论：主要趋势 = 牛 / 熊 / 尚未可知
次级运动 = 正常的折返 / 潜在的反转（需继续观察）

## 八、对读者的实务提醒（从本章延伸出的使用纪律）

1. **只用收盘价**（或接近收盘的最终报价），不用日内最高/最低做判定——日内极值容易被操纵或情绪夸张
2. **3% 过滤 ≠ 万能**——在大波动时代（如高通胀年代）3%可能显得太小，在极低波动时代可能显得太大；精神是"过滤噪音"，数值可按市场状态微调
3. **确认可以延迟但不可以省**：工业指数先破，运输指数后破——允许时间差，但**最终必须都到**
4. **道氏趋势判定天生滞后**——它不抓尖顶尖底，它抓的是"趋势已经变了"的**高概率确认点**。代价是牺牲一部分利润空间，换取的是不被假动作清洗出局
5. **第13章的判定是"关于主要运动的"，不是交易系统**——它告诉你大方向，不等于告诉你每次回调该不该加仓（那是第14章线态盘整 + 风险管理的事）
