## 〇、【核心引擎】政策雷达 & 趋势判定引擎（每季度校准）

### §0.1 十五五“产业确定性图谱”

国家“十五五”规划纲要明确了“**发展壮大新兴产业**”与“**前瞻布局未来产业**”的双层架构。

#### 一、战略性新兴产业（八大方向）

国家“十五五”规划纲要“点名”了**新一代信息技术、新能源、新材料、智能网联新能源汽车、机器人、生物医药、高端装备、航空航天**等八大产业方向。这八大方向是**进攻仓的核心选股池**。

与此同时，国家发改委在2026年全国两会期间进一步明确了**六大新兴支柱产业**作为重点打造方向：**集成电路、航空航天、生物医药、低空经济、新型储能、智能机器人**。初步测算，2025年相关产值已接近**6万亿元**，预计到2030年有望再翻一番甚至更多，扩大到**十万亿元以上**。

|------|------|---------------|-------------|
| **战略性新兴产业（核心配置区）** | 新一代信息技术 | 发展壮大新兴产业 | 进攻仓首选，聚焦有订单验证的细分龙头 |

| | 智能机器人 | 重点打造 | 进攻仓次线，看核心零部件真实出货量 |

#### 二、未来产业（六大方向）

国家“十五五”规划纲要提出前瞻布局**量子科技、生物制造、氢能和核聚变能、脑机接口、具身智能、第六代移动通信**等六大未来产业。

**仓位规则**：仅≤10%观察仓，不追高，等待商业化里程碑（技术突破、示范工程落地、首份订单）。

**结论**：进攻仓须优先从国家五年规划级资源倾斜的**八大战略性新兴产业**和**六大新兴支柱产业**中筛选，避免被“运动式整顿”误伤，获取最高的政策确定性溢价。


### §0.2 新“国九条”配套落地状态（重塑压舱石逻辑与市场生态）

2024年4月，国务院发布新版“国九条”，明确要求完善减持规则体系。核心政策信号如下：

| 政策信号 | 现状与进展 | 对投资框架的影响 |
|----------|-----------|-----------------|
| **分红约束→减持阀门** | 最近三年累计现金分红总额低于年均净利润**30%**，且分红金额低于**5000万元**的，控股股东、实控人不得减持 | 高股息从“风格炒作”转为“硬制度约束”，倒逼企业分红 |
| **分红常态化** | 对多年未分红或分红比例偏低的公司，限制大股东减持、实施风险警示 | 高股息策略的制度底座已建成，底仓安全性大幅提升 |
| **中长期资金入市** | 推动一年多次分红、预分红、春节前分红 | 压舱石估值底更“厚”，长线资金沉淀减少非理性波动 |
| **退市+质量门** | 加大退市监管力度，进一步严格强制退市标准 | 财务排雷权重上升，垃圾股彻底失去“壳价值”兜底 |


### §0.3 2026“监管-市场结构”新变量（影响择时与流动性）

**程序化交易与公平化改革**：证监会主席吴清2026年6月6日明确表示，将“持续完善程序化交易监管的机制安排，更突出**公平和规范**”，加强针对性监管，“切实防范滥用技术优势，坚决打击操纵市场、扰乱市场秩序等违法违规行为”。高频量化“速度特权”被拆除，市场微观结构变“慢”变“真”。短线暴涨暴跌减少，人为制造的表面流动性被挤掉。

**资管监管收紧（1+N+X体系）** ：证监会正研究制定贯彻落实指导意见的三年行动方案，并会同相关单位建立完善准入、持续监管、风险化解、服务发展等“1+N+X”制度体系。题材爆拉—量化助涨—散户追高的正反馈环被削弱。逆向买入法更容易在“真恐慌”时买到好价格，而非在量化踩踏中接飞刀。

**推论动作**：当监管连续点名某类交易行为或题材时，不等财务指标恶化，先减至警戒仓（索罗斯式“反身性+外生冲击”合并处理）。


### §0.4 出海的“地缘趋势实况”（已发生的事实过滤）

| 事实 | 对出海仓的含义 |
|------|---------------|
| 美对东南亚光伏双反最高税率3521%+出口退税取消 | 光伏组件纯贸易出海通道封死，降级为观察仓；若配置仅限有非美落地产能的头部 |
| 美对多国光伏反补贴裁定（80-143%区间） | “第三国转口”空间收缩，出海仓必须验“原产地多元化+当地雇佣+纳税”三件套 |
| 储能系统美综合税率约40.9%，认证门槛隐形增高 | 储能出海需具备完整认证包+本地服务+ESG合规包；**东盟、中东、拉美市场积极布局** |

## 二、压舱石：高股息央国企（45–55%）

**逻辑**：不分红→大股东不能卖已成法律约束（三年累计分红＜年均净利润30%且金额＜5000万，控股股东不得减持）。高股息从“风格”升格为“制度性现金流资产”。

### ✅ 硬指标筛选

| 指标 | 门槛 |
|------|------|
| 股息率(TTM) | ≥ **3.5%**（大行类可≥3.0%）|
| 分红覆盖倍数 | OCF / 现金分红 ＞ 1.5×（3年平均）|
| 分红连续性 | 连续 ≥5年现金分红 |
| PB分位（10年）| ≤ 50%分位 |
| ROE(3年平均) | ≥ 10% |
| OCF/净利润(3年平均) | ≥ 0.7 |

### 🔄 联动动作
- 每季度财报后复核分红兑现率，未兑现降级处理
- 破净且不分红的标的，减持虽锁死，但不盲抄底，需等PB企稳+OCF修复双重确认


## 三、进攻仓：硬科技（25–35%）

**逻辑**：用十五五产业图谱做方向过滤器，拒绝纯概念炒作。

### 1. 方向过滤矩阵

**🟢 绿灯（战略性新兴产业优先）** ：
- 新一代信息技术（集成电路设备/材料/EDA，有国产替代订单）
- 新能源（非光伏组件，有技术代差）
- 新材料（有国产替代验证）
- 智能网联新能源汽车（核心零部件，有供货证明）
- 机器人（传感器/减速器，有供货证明）
- 生物医药（有BD能力验证）
- 高端装备（工业母机/航空发动机，有订单）
- 航空航天（有营收拐点）

**🟡 黄灯（未来产业，仅观察仓）** ：
- 量子科技/生物制造/氢能/脑机接口/具身智能/6G——有背书但商业化未到

**🔴 红灯（概念区，一票否决）** ：
- AI相关但无合同/出货/可追溯收入
- 芯片概念但无大客户认证
- 任何“十五五”产业图谱之外的纯题材炒作

### 2. 硬指标

| 指标 | 门槛 |
|------|------|
| 营收环比 | 近两季均＞0 |
| 毛利率趋势 | 近3季不连续下滑 |
| OCF/净利润(TTM) | ＞ 0.6 |
| 概念纯度 | 必须有合同/中标/出货数据，或相关营收占比≥10% |
| 研发强度 | 行业前1/3分位 |

### 3. 趋势过滤器（监管交叉）
- 监管点名查异常交易集中在该细分 → 暂停新建仓，先减到警戒线
- 行业被列入产能过剩调控 → 降级为观察，只配非单一依赖的设备龙头


## 四、战略仓：出海全球化（20–30%）

**逻辑**：赚取全球利润，规避国内内卷，但必须过地缘壁垒矩阵。

### 1. 地缘过滤矩阵判定

| 赛道 | 判定 | 依据 |
|------|------|------|
| 电力设备/特高压EPC | ✅ **优选** | 中东/拉美需求旺，壁垒低 |
| 汽车零部件（OEM） | ✅ **优选** | 核心看原产地证书+本地化用工 |
| 储能系统 | ✅ **可配（分市场）** | 美国谨慎（综合税率约40.9%+认证门槛），东盟/中东/拉美积极布局 |
| 光伏组件（纯贸易） | ❌ **不配** | 关税壁垒极高（最高3521%），纯贸易通道封死 |

### 2. 硬指标

| 指标 | 门槛 |
|------|------|
| 海外营收占比 | ＞ 25%（优质＞35%）|
| 海外毛利率 | ≥ 国内毛利率×0.9 |
| 海外产能实锤 | 已运营或资本开支已投入（非PPT）|
| 地缘分散度（CR3）| ＜ 65%（光伏链要求＜50%）|
| 合规文件包 | 目标市场认证齐全 + 供应链溯源文件完整 |


## 五、通用财务排雷清单（一票否决）

| 🚩 | 触发条件 |
|----|----------|
| **存贷双高** | 高账面现金 + 高有息负债 + 异常利息 |
| **商誉炸弹** | 商誉/归母净资产 ＞ 30%（科技＞25%）|
| **现金流断裂先兆** | OCF连续2年为负且净利为正 |
| **质押失控** | 大股东质押 ＞ 60% |
| **审计异象** | 频繁换所/保留意见/无法表示意见 |
| **关联方黑洞** | 其他应收款/预付异常膨胀 |


## 六、择时、建仓与拥挤度（引入监管脉冲）

### 1. 逆向买入法
**三重确认**：情绪冰点 + 基本面未碎 + 现金流验证 → 金字塔分批建仓 → 绝对止损底 -25%

### 2. 拥挤度监控升级

| 指标类型 | 具体指标 | 警戒线 | 强减仓线 |
|----------|---------|--------|----------|
| **传统指标** | 行业成交额占比 | ＞25% | ＞35% |
| | 换手率分位 | ＞90% | ＞95% |
| **新增分化度** | 成分股涨跌幅标准差急剧收窄（烂股也涨停）| — | 泡沫指纹，立即启动退出序列 |
| **新增监管脉冲** | 监管点名/查处集中在该板块 | 首次减30%并暂停新建 | 查处升级再减 |

### 3. 流动性隐形约束
微观结构变慢后，个股表面流动性下降，门槛需卡严：**20日日均成交额 ≥ 计划持仓 × 20倍**


## 七、卖出纪律（机械化触发）

| 触发条件 | 信号说明 |
|----------|---------|
| **① 极度高估** | 压舱石PE近5年≥95%分位+股息率<2.5%；科技PEG>2.5且营收拐头向下 |
| **② 逻辑证伪** | 护城河破坏/核心牌照丢/行业被定向出清 |
| **③ 现金流预警** | OCF连续2季为负 + 应收/存货异常堆积 |
| **④ 更优标的** | 同确定性下估值低20%+ → 置换换仓 |
| **⑤ 监管/地缘外生** | 监管查处升级或地缘壁垒突变击中核心市场，不等财报先减仓保流动性 |
| **⑥ 拥挤度爆表** | 成交额占比>35% / 换手>95%分位 / 分化度消失 |
