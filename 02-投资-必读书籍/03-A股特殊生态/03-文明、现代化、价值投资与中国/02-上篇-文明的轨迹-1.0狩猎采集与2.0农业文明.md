# 上篇·文明的轨迹：1.0狩猎采集文明与2.0农业文明

## 一、总览：文明的三段式划分

李录根据人类生产方式的不同，将截至目前的人类文明史划分为三个阶段：1.0采集狩猎文明、2.0农业畜牧业文明、3.0科技文明。

| 文明阶段 | 时间跨度 | 核心生产方式 | 决定性因素 |
|:---|:---|:---|:---|
| 1.0 狩猎采集文明 | 约7万年前 — 公元前9600年 | 狩猎、采集 | 气候 |
| 2.0 农业畜牧业文明 | 约公元前9600年 — 1776年 | 种植、畜牧 | 土地 |
| 3.0 科技文明 | 1776年至今 | 现代科技+市场经济 | 市场规模 |

三个文明阶段的划分依据，参考了斯坦福大学历史学家伊恩·莫里斯（Ian Morris）创建的 **"社会发展指数"** 。这一指数以定量方式记录人类长期文明历史的轨迹，清晰地呈现出人类文明进化轨迹的不断上升趋势。

在展开具体论述之前，有必要先厘清李录对两个核心概念的界定：

- **文化**：指生活在不同地区的人们，在漫长的时间里形成的独特的生活方式、生活习惯及信仰。文化用来区分不同地区、不同人群之间的区别。
- **文明**：指人类利用自身与环境中的资源，在生存发展中所创造出来的全部成果，意在计量人类与最接近的动物祖先之间拉开的距离。文明用于描述人类发展的共性。

## 二、1.0 狩猎采集文明

### 2.1 定义与时间跨度

1.0文明是人类文明发展的第一阶段，即采集狩猎文明。人类最开始的生存活动主要就是采集和狩猎，这个时期的文明程度相对较低。从公元前约60000年开始，一直到公元前约12000年前后，人类经历了漫长的狩猎采集时代。

### 2.2 文明飞跃的契机：米兰科维奇循环

在1.0文明的大部分时间里，人类采集、使用能量的方式似乎一直没有太大变化。但这是一种误解——人类的1.0文明，其实在7万年前发生了一次巨大的飞跃。

这次飞跃的契机是气候变化。李录引入了 **"米兰科维奇循环"** 理论来解释这一变化。该理论由塞尔维亚数学家米卢廷·米兰科维奇提出，核心观点是：

地球围绕太阳公转的轨道并非正圆形（受其他星球引力影响呈椭圆形），加上地球自转的倾斜和自转轴的进动，三个因素共同导致地球气候形成了三大循环周期：

- 每26000年的周期（地轴进动引起）
- 每41000年的周期（地轴倾斜引起）
- 每96000年的周期（地球离心轨道引起）

三大循环造成了地球接受太阳光热数量的不同，形成了气候的冰期和间冰期。冰川纪在历史上出现过四十到五十次，最严重的两次发生在19万年前和9万年前。

**9万年前的恶劣气候**将人类的生活环境极度压缩，仅能在非洲靠近赤道的很有限区域内得以生存。根据基因学家和考古学家的考证，当时人类的总数量一度下降到仅2万人左右。这是人类历史上最黑暗的时代。

否极泰来。到了7万年前，米兰科维奇循环朝相反方向变化。随着全球气候逐渐转暖，非洲的东部和南部变得更加温暖湿润，给人类提供了更好的自然条件来狩猎和采集，人口也开始随着食物的增加迅速增长。

### 2.3 走出非洲：人类的全球远征

伴随着气候变暖和人口增长，人类开始探索更大的生存空间。从公元前6万年开始，人类开启了一场历时数万年的地球长征：

> 非洲索马里 → 阿拉伯半岛 → 欧亚大陆 → 北非进入欧洲 → 欧亚大陆进入东亚 → 亚洲南部进入澳洲 → 欧亚大陆穿过阿拉斯加进入北美 → 北美进入南美

这次远征的壮丽之处在于：人类跨过大冰川、越过海洋，在对未来和目的地一无所知的情况下，一代一代以顽强的决心、以平均每年一英里的速度，最终遍布了整个地球。李录感慨道："这次人类祖先的远征，今天想起来还会令人震撼，激动人心。"

### 2.4 1.0文明的历史意义

这次走出非洲的飞跃，对人类文明具有深远意义：

- **人口增长**：人类从约2万人迅速增长；
- **降低灭绝风险**：濒于灭种的可能性大大降低；
- **基因多样性**：基因的多样性和适应性大大增加；
- **全球布局**：人类遍及全球所有地方，开始在全球寻找最适合发展的生存条件；
- **奠定基础**：当生存条件在地球某些地区首先出现时，人类利用机会的能力已彻底形成，为下一次飞跃奠定了坚实基础。

李录特别强调，这次飞跃从一开始就显示出人类这种动物独特的进取心和智力。虽然大自然给各种生物创造的条件是一致的，但并非所有物种都像人类这样有强烈的进取心，克服重重困难走遍全球。


## 三、2.0 农业畜牧业文明

### 3.1 农业文明的诞生

大约在公元前9600年，农业开始在西南亚的侧翼丘陵区（即今天的中东地区）出现。在中国，农业出现于公元前7500年左右的黄河长江流域。

农业文明诞生的关键自然条件是 **"幸运纬度带"** ——即欧亚大陆北纬20度到北纬35度、美洲大陆北纬15度到南纬20度之间的地区。在这个纬度带上，出现了各种野生谷物，穗粒很大，采集时花费1卡的能量可以在食用时得到50倍的回报。

从公元前10000年左右开始，人口开始长期上升，人类对土地的开垦利用不断扩张，土地的单位产出也因为农业技术的不断改进而提高。公元前5000年左右，集中的水利灌溉技术最先出现在中东的美索不达米亚平原。此后，轮种、选种、育种、休耕、农具改革、牲畜使用、铁制农具、水车、风车等农业工具和技术相继出现。

农业的出现带来了深刻的社会变革：

- **社会组织升级**：为了更好地利用新技术，人类开始提高组织能力，建立了城市、国家乃至庞大的帝国；
- **人口流动与贸易**：城邦和国家间出现了人口流动、掠夺和战争，同时也促进了贸易和社会分工；
- **技术传播**：大的帝国得以建立稳定统一的市场，先进技术得以在大范围内更快传播。

### 3.2 农业文明的地域差异

农业文明从这一阶段开始产生了显著的地域差别，主要有两个原因：

**第一，自然资源的禀赋不同。** 西南亚侧翼丘陵区拥有比其他地方更多种类的适合种植的粮食，且有更多种动物容易被驯服。亚洲次之，而欧洲、非洲和美洲则缺乏合适的种类。

**第二，地理位置不同。** 非洲、美洲、澳洲相对孤立，而欧亚大陆是连成板块的，易于文明和经验的传播。今天世界上最发达的文明，都从两个最幸运的中心发展而来：一个是西南亚和中东地区，一个是中国的黄河长江流域。

到了公元前1500年左右，基本上整个亚洲、中东、非洲北部地中海、欧洲都已经进入2.0文明阶段；而美洲和澳大利亚因为自然资源不足和地理上的隔绝，基本上还处在1.0文明阶段。

### 3.3 农业文明的"天花板"

农业文明虽然带来了人口的持续增长和社会的发展，但其发展潜力存在天然天花板。

**根本原因在于能量来源的上限：**

- 农作物产生于光合作用，光合作用能够产生的能量上限受制于土地面积和土地的单位产出；
- 牲畜也要消耗植物，动物产出的热量和消耗的植物能量比例约为10:1；
- 在这两者都有上限的情况下，自然资源也就有了上限。

与此同时，人类在这个时期还不能够控制人口——人使用新能量的一个重要方式就是生育更多的子嗣。有限的资源和近乎无限的人口增长，决定了人口增长最终只能通过非自然灾难来消化和制约。

这便是著名的 **"马尔萨斯陷阱"** ：土地多的时候人口增多，人口多到一定程度土地无法再支撑，社会发展掉入陷阱，最后以各种"天灾人祸"的方式急剧减少人口。

### 3.4 农业文明面临的五大灾难

纵观整个2.0文明的历史，尤其是近代几千年，"做饼与分饼"的矛盾不仅一直存在，而且有愈演愈烈之势。人类在农业文明时代面临的灾难主要由五个原因导致：

| 灾难类型 | 具体表现 |
|:---|:---|
| 饥荒 | 土地收成受制于天气，气候变化直接影响农作物产出 |
| 战争 | 游牧民族与农业人口对土地的争夺，以及农业人口之间的流动 |
| 瘟疫 | 人畜接触和人口流动导致细菌、病毒的传播 |
| 气候变化 | 长期气候变化导致土地收成系统性减缓，引发大规模人口迁徙 |
| 政权失败 | 政权组织能力的崩溃导致社会秩序瓦解 |

游牧民族因为蓄养的动物需要消耗大量植物，更受制于天气变化，加之本身流动性强，所以更倾向于掠夺和战争。游牧民族的掠夺战争不仅让东西方暂停冲击更高级的文明，还带来了毁灭性倒退。

### 3.5 农业文明的"三次冲顶"

尽管农业文明面临诸多挑战，但在几千年里至少出现了三次冲顶的尝试。这三次冲顶标志着旧的生产方式已达顶峰：

| 冲顶 | 时间 | 代表性文明 | 特征 |
|:---|:---|:---|:---|
| 第一次 | 公元前1000年—公元前200年 | 罗马帝国 | 环地中海地区的统一，达到西方农业文明的顶峰 |
| 第二次 | 公元500年—公元1000年 | 中华文明（唐宋） | 东亚农业文明的巅峰 |
| 第三次 | 17—18世纪 | 东西方同时冲顶 | 东西方都再次冲向农业文明的顶峰 |

每一次冲顶之后都陷入停滞或衰退，新的生产方式的出现才会带来世界格局的根本变化。

### 3.6 农业文明中的制度创新

在应对挑战的过程中，农业文明阶段在制度上不断进行创新。其中最重要的制度创新之一是科举制的诞生。李录对科举制称赞有加，认为这种制度是东方在500—1700年领先西方的主要因素之一。

科举制实现了选拔优秀文人的要求，同时又通过科举内容达到道德上的忠诚。在思想层面，公元前5世纪左右，东西方同时出现了伟大的思想家——西方的苏格拉底、中国的孔子等，思考的是人、社会、国家层面的根本问题。


## 四、总结：从1.0到2.0的关键跃迁

1.0狩猎采集文明与2.0农业文明的核心差异可以概括为：

| 维度 | 1.0 狩猎采集文明 | 2.0 农业畜牧业文明 |
|:---|:---|:---|
| 核心驱动力 | 气候变化（米兰科维奇循环） | 土地与农业技术 |
| 生产方式 | 狩猎、采集 | 种植、畜牧 |
| 社会组织 | 小团队、部落 | 城市、国家、帝国 |
| 人口规模 | 约2万人（最低点时） | 持续增长，周期性崩溃 |
| 发展模式 | 迁徙、扩张 | 定居、循环（上升—冲顶—衰落） |
| 根本瓶颈 | 气候与食物供给 | 土地与人口（马尔萨斯陷阱） |
| 决定性因素 | 气候 | 土地 |

1.0文明的核心特征是 **"迁徙"** ——人类随着气候变化走出非洲，以顽强的进取心遍布全球。2.0文明的核心特征则是 **"定居"** ——人类在幸运纬度带上驯化动植物，建立城市与国家，但也因此被锁在"上升—冲顶—衰落"的循环之中。

直到1776年——亚当·斯密发表《国富论》、美国发布《独立宣言》、瓦特发明蒸汽机——这三件看似毫不相干的事情在同一年发生，才标志着人类文明终于跃升至3.0科技文明阶段。从此，人类第一次有可能摆脱马尔萨斯陷阱，进入持续、复利式、无限的经济增长。
