# 14 这次不同了（A股实战加强版）

> **核心主旨**：“这次不同了”是投资史上最危险的四个字。每当市场出现极端泡沫或狂热时，人们总喜欢用这句话来为违背常识的高估值找借口。认清人性中盲目自信与贪婪的弱点，敬畏历史规律，是投资者避免在泡沫中毁灭的关键。


## 一、“这次不同了”与全书的关系：收官之章

“这次不同了”是全书的 **“收官之章”** ——前面各章讲的教训，最终都指向同一个警示：

| 章节 | 内容 | 与“这次不同了”的关联 |
| :--- | :--- | :--- |
| 第6章 经验像旧衣服 | 旧经验可能失效 | “这次不同了”是说“旧经验不适用了” |
| 第7章 价值陷阱 | 用过去判断价值 | “这次不同了”是说“过去的估值标准不适用了” |
| 第12章 后视镜 | 线性外推的危险 | “这次不同了”是说“历史的规律不适用了” |
| 第13章 傻瓜定价 | 极端情绪定价 | “这次不同了”是说“傻瓜这次不会亏” |

**本章的价值在于**：用一句话总结了前面所有的教训——

> **当市场开始说“这次不同了”的时候，恰恰说明一切都没有变。**


## 二、核心名言与理论溯源

### 约翰·邓普顿的名言：

> **“投资中最危险的四个字就是‘这次不同了’。”**

每当这四个字在市场中广为流传时，往往意味着巨大的泡沫已经形成，崩盘随时可能发生。

**核心逻辑**：历史虽然不会简单重复，但**总是压着相同的韵脚**。人性的贪婪与恐惧、商业竞争的本质、均值回归的万有引力——这几百年来从未改变。


## 三、为什么人们总爱说“这次不同了”？（心理与诱因）

### 诱因一：新技术的出现

**表现**：每当出现颠覆性的新技术（铁路、汽车、互联网、区块链、AI），人们就认为传统的估值体系失效了。

**心理**：对新事物的盲目崇拜，认为新技术能带来无限的增长空间，从而忽略了商业的本质——**任何企业最终都必须创造现金流**。

### 诱因二：宏观环境的短暂突变

**表现**：流动性极度泛滥（如大放水时期）或政策强刺激时，资产价格飙升。

**心理**：认为“钱多了，估值中枢就该永久性上移”，忽略了宽松只是阶段性的。

### 诱因三：贪婪与错失恐惧（FOMO）

**表现**：看到身边人都在泡沫中赚大钱，自己不想踏空，于是抛弃了原有的纪律。

**心理**：为了说服自己高位接盘是合理的，必须在逻辑上给自己洗脑——编造“新时代”的故事。

### A股特色：“这次是慢牛”——最特殊的“这次不同了”叙事 ⚠️

在A股，“这次不同了”最常见的表述是 **“这次是慢牛”** 。

每一轮牛市，投资者都会说：
- “这次是机构主导的牛市，不会像以前那样散户踩踏”
- “这次有国家队托底，不会大跌”
- “这次是价值投资的牛市，估值合理”

然后每一次，“慢牛”都会变成“疯牛”，然后变成“股灾”。

> **结论**：在A股，当大多数人开始相信“这次是慢牛”的时候，往往意味着牛市已经进入了下半场。“慢牛”本身就是一个危险的“这次不同了”信号。


## 四、历史教训：“这次不同了”的经典案例

### 案例一：1999年互联网泡沫

**口号**：“新经济时代来了，传统的市盈率估值不再适用，眼球经济才是王道。”

**结果**：纳斯达克市盈率炒到上百倍，随后泡沫破裂，指数腰斩，无数没有盈利的“.com”公司破产。

**教训**：“这次不同了”最终变成了 **“其实没什么不同”** 。

### 案例二：2007年A股6124点

**口号**：“黄金十年，人口红利，大国崛起，A股将迎来超长牛市，市盈率可以一直维持在高位。”

**结果**：全球金融危机爆发叠加国内宏观调控，A股从6124点一路暴跌至1664点。

**教训**：**树不可能长到天上去。**

### 案例三：2008年次贷危机前夕

**口号**：“金融衍生品已经将风险分散到了全球，房地产永远不会下跌，这次金融危机不会再发生了。”

**结果**：次贷违约引发多米诺骨牌效应，雷曼兄弟倒闭，全球经济陷入大衰退。

### A股更多的“这次不同了”案例：

| 时间 | 口号 | 结果 |
| :--- | :--- | :--- |
| **2015年创业板牛市** | “互联网+改造一切”“新经济不适用传统估值” | 创业板从4000点跌至1200点 |
| **2020-2021年核心资产** | “外资流入改变了定价体系”“核心资产永远涨” | 茅指数从高点下跌超40% |
| **2021年新能源** | “碳中和是百年大计”“100倍PE也不贵” | 新能源板块大幅调整 |


## 五、不变的规律：为什么“其实每次都一样”？

尽管技术在变、工具在变、宏观背景在变，但投资中有些底层规律是永恒不变的。

### 不变一：人性的贪婪与恐惧

无论什么时代，投资者追涨杀跌的本能没有变。市场情绪永远在极度乐观和极度悲观之间摆动——**钟摆现象不会消失**。

### 不变二：商业的本质（创造现金流）

任何商业模式，无论故事多动听，最终都必须能够创造真实的自由现金流。不能持续赚钱的企业，其内在价值终将归零。

> 这是第1章“以实业的眼光做投资”的底层逻辑。

### 不变三：供需关系与均值回归

价格围绕价值波动。当价格远超价值时，必然有巨大的做空力量（如大股东减持、再融资、产能过剩）将其拉回地面。**万有引力始终存在**。

### 不变四：护城河决定超额利润的持续性

没有深厚护城河的行业，任何高利润都会吸引无数资本涌入，最终将超额利润打回社会平均利润率。只有拥有护城河的企业才能长期维持超额利润。

> 这是第5章“数月亮”的底层逻辑。


## 六、如何区分“真正的结构性变化”与“这次不同了的泡沫叙事”？

### 实操框架：四问判断法

当有人说“这次不同了”的时候，用四个问题来判断：
```
□ 问题1：这个变化，改变的是“商业模式”还是“人性规律”？
→ 如果改变的是商业模式（如电商改变零售）→ 可能是结构性变化
→ 如果试图改变人性规律（如“这次没有周期”）→ 是“这次不同了”的叙事

□ 问题2：这个变化，能否用“估值”来衡量？
→ 如果可以用估值衡量（PE/PB/现金流）→ 可以理性分析
→ 如果拒绝用估值衡量（“这次不看估值”）→ 是“这次不同了”的叙事

□ 问题3：支持这个变化的钱，是“长期资金”还是“杠杆资金”？
→ 如果是长期资金（保险、养老金）→ 可能支撑结构性变化
→ 如果是杠杆资金、散户资金→ 是“这次不同了”的叙事

□ 问题4：三年后，这个行业的“月亮”还是现在这些公司吗？
→ 如果是 → 可能是结构性变化（格局稳定）
→ 如果可能换一批公司 → 是“这次不同了”的叙事
```

> **如果四个问题中有三个指向“这次不同了”，那么它就是“这次不同了”。**


## 七、投资者的应对策略

### 策略一：保持对常识的敬畏

常识比复杂的高深理论更管用。如果一个投资逻辑需要用极其复杂的模型或前所未有的新理论来证明其合理性，那它大概率是个泡沫。

**常识**：买入价格低于重置成本、有稳定现金流的公司，是永远不变的真理。

### 策略二：宁可错过，不要做错

当市场高喊“这次不同了”时，往往处于泡沫中后期。此时虽然可能还有最后一段最疯狂的上涨，但**风险收益比极度不对称**（下行空间80%，上行空间20%）。

理性的投资者应该选择离场，忍受踏空的痛苦，**保住本金**。

### 策略三：坚守估值纪律

估值是最好的防守。不论概念多么性感，一旦透支了未来3-5年的业绩预期，就应该坚决减仓或回避。

**不为“梦想”支付高昂的溢价。**

### 策略四：当大家都在说“这次不同了”，先问自己三个问题
```
□ 这个“新叙事”，是“市场先生”在说话，还是“基本面”在说话？
□ 支持这个“新叙事”的资金，是长期资金还是短期博弈资金？
□ 如果三年后回头看，这个“新叙事”还会有多少人相信？
```


## 八、本章核心总结

**一句话记住本章**：

> **“这次不同了”是市场在极度狂热时为非理性繁荣寻找的遮羞布。每一次泡沫的破灭，都是对这四个字的无情嘲讽。**

**三个核心判断：**

1. **历史会重演，但不会简单重复**——每次的“新叙事”都不同，但人性规律、均值回归从未改变
2. **区分结构性变化与泡沫叙事**——用“四问判断法”做区分，不要一棍子打死所有新事物
3. **当大家都说“这次不同了”，恰恰说明一切都没变**——这是邓普顿给投资者最大的启示

**A股投资者最该记住的一句话：**

> **在A股，“这次不同了”最常出现在牛市的最后阶段。当你在朋友圈看到越来越多的人说“这次是慢牛”“这次不会大跌”的时候，记得提醒自己：树不会长到天上去，泡沫终将破裂，而买单的永远是最后一个相信“这次不同了”的人。**
