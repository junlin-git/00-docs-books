# 12 后视镜（A股实战加强版）

> **核心主旨**：在投资中，过度依赖过去的数据、走势和经验来做未来的决策，就像开着车只盯着后视镜一样危险。投资是面向未来的概率游戏，历史可以为鉴，但不能作为线性外推的依据。


## 一、“后视镜”与全书的关系：一条贯穿始终的红线

“后视镜”并非孤立的问题——它贯穿了全书的多个章节：

| 章节 | 内容 | 与“后视镜”的关系 |
| :--- | :--- | :--- |
| 第6章 经验像旧衣服 | 旧经验可能过时 | “后视镜”的一种表现——盯着过去的经验 |
| 第7章 价值陷阱 | 用过去的利润判断价值 | 盯着“后视镜”里的财务数据 |
| 第8章 真假风险 | 暴露的风险已被计价 | 盯着“后视镜”里的利空/利好 |
| 第10章 四种周期 | 周期的传导顺序 | 盯着“后视镜”里的宏观经验 |
| 第11章 人性的弱点 | 可得性启发 | 解释了为什么我们天然倾向于看“后视镜” |

**本章的价值在于**：把前面各章的“经验可能失效”现象，用一个统一的隐喻总结出来——

> **不要用昨天的旧地图，去寻找明天的新大陆。**


## 二、核心隐喻：什么是投资中的“后视镜”？

**隐喻定义**：驾驶员看着后视镜倒车是安全的，但如果看着后视镜往前开，必然车毁人亡。投资者用过去发生的股价走势、财务数据来预测未来，就是“看着后视镜开车”。

**本质特征**：**线性外推**——假设“过去发生的，未来也会继续发生”。

**市场表现**：大众总是习惯于从过去的行情中寻找未来的规律，但市场的每一次大级别转折，往往都打破了历史的惯性。


## 三、“后视镜”效应的三大典型表现

### 3.1 看过去的股价走势（技术分析与趋势外推）

**表现**：认为“过去一年涨得好的股票，未来也会涨”；或者“过去跌成这样的股票，总会反弹”。

**误区**：把阶段性的资金博弈结果，当成了企业的长期成长规律。涨得越多，估值越高，风险其实越大——但因为看着后视镜里“涨势喜人”，反而觉得越安全。

**例子**：在牛市顶峰（如2015年或2021年初），投资者看着某些赛道股过去两年的翻倍走势，画出趋势线认为“还会大涨”，结果买在最高点，被深套数年。

### 3.2 看过去的财务数据（成长陷阱与周期陷阱）

**表现一（伪成长）** ：看到一家公司过去三年利润年均增长50%，就假设未来三年也能增长50%，并据此给出高估值。

**误区**：忽略了基数效应、行业渗透率到顶以及均值回归的引力。**没有一种高增长是永续的。**

**表现二（伪价值）** ：看到一家周期股在过去几年每年赚上百亿，PE只有4倍，就认为极度低估。

**误区**：这是把**周期的顶点当成了常态**。过去的暴利会吸引大量产能，未来利润可能雪崩。

### 3.3 看过去的宏观环境（刻舟求剑式配置）

**表现**：根据过去十年的宏观经验（如“每次降准A股都会涨”“只要刺激地产经济就复苏”）来指导当前的操作。

**误区**：宏观经济结构、产业政策、人口周期都在发生结构性变化。过去的因果逻辑可能在新时代已经失效。

**例子**：过去二十年，买房/买地产股是稳赚不赔的。如果投资者盯着这个“后视镜”，在房地产大周期拐点到来时依然加杠杆抄底，将面临毁灭性打击。


## 四、A股特色：最典型的“后视镜”——用历史PE百分位找底 ⚠️

A股投资者最喜欢看的一个指标是“历史PE百分位”——“这只股票的PE已经低于历史上90%的时间，肯定到底了。”

**但这个逻辑有一个致命漏洞**：如果公司的基本面发生了**结构性恶化**（比如行业需求萎缩、政策导致商业模式改变），历史估值区间就完全失去了参考意义。

**案例**：某地产公司在“房住不炒”政策长期化后，基本面发生了根本性变化。但投资者看着它“PE已经跌到历史最低”，认为“很便宜”而买入——结果继续下跌，因为“历史最低PE”建立在一个已经不复存在的盈利基础上。

> **判断标准**：当你想用“历史PE百分位”来判断底部时，先问自己一句——**“这个公司，还是以前那个公司吗？”**


## 五、为什么投资者难以摆脱后视镜？

### 5.1 心理机制：可得性启发

近期发生的、印象深刻的、刚刚经历过的历史，在大脑中权重最大，最容易提取。人类天生倾向于用近期的经验来预判未来。

**A股表现**：
- 2015年牛市记忆 → 2020年还在等“5000点再来一次”
- 2020年核心资产记忆 → 2021年还在追“好公司永远涨”
- 2021年新能源记忆 → 2022年还在相信“100倍PE不贵”

### 5.2 现实原因：研究过去比预测未来容易得多

- 券商研报喜欢用过去三年的CAGR（复合增长率）来倒推未来
- 投资者喜欢用历史PE百分位来找底——因为这些都是现成的、确定的数字
- 面对未知的未来，人们本能地想抓住历史的确定性来壮胆


## 六、历史的真正作用：如何正确使用“后视镜”？

> 邱国鹭的观点：虽然不能看着后视镜往前开，但后视镜依然有它的价值。关键在于你要从历史中学什么。

### 6.1 学规律，不学表象

- 历史不会简单重复，但**总是压着相同的韵脚**
- 要通过历史学习：
  - 人性规律（贪婪与恐惧的钟摆）
  - 商业本质（竞争格局如何演变）
  - 泡沫破裂的共性特征

### 6.2 找参照，不找答案

- 历史估值百分位可以作为**参考**，但不是绝对的买入理由
- 如果基本面发生不可逆恶化，历史大底依然可以被跌破

### 6.3 如何区分“有用的历史”和“有害的后视镜”？

| | 有用的历史（学规律） | 有害的后视镜（学表象） |
| :--- | :--- | :--- |
| **关注点** | 人性规律、商业本质、泡沫共性 | 具体股价走势、特定指标、某次经验 |
| **问的问题** | “泡沫破裂前一般有什么特征？”“护城河是如何被颠覆的？” | “上次牛市涨了多少？”“某只股票上次跌到这就反弹了” |
| **结论性质** | 原则性、可迁移 | 具体化、不可复制 |
| **A股案例** | 学习“高估值+高杠杆+高换手”是泡沫的三要素 | 认为“5000点还会再来的”，因为2015年到过 |


## 七、破局之道：从“向后看”转向“向前看”

建立前瞻性的投资框架，将注意力从过去的K线转移到未来的生息能力上。

### 7.1 估值锚点：看未来的现金流，不看过去的K线

- 真正的安全边际，不在于它从最高点跌了多少（跌了80%不代表便宜）
- 而在于**它未来的自由现金流折现值是否远高于当前市值**

**操作原则**：忘掉你的买入成本，忘掉它的历史最高价。只问一个问题：**“以今天的价格买入，未来三年我能获得怎样的年化回报？”**

### 7.2 基本面分析：看未来的竞争格局，不看过去的财务报表

- 过去的利润只代表过去
- 重点研究：未来三年行业的供需关系、渗透率阶段、公司的护城河是在加深还是变浅

**警惕“好公司”陷阱**：过去的好公司，如果技术路线被颠覆或护城河被攻破，未来的财报会急转直下。

### 7.3 仓位管理：应对重于预测

- 既然未来不可精准预测，就不能用后视镜里的“确定性”去满仓单押
- 保持投资组合的多样性和弹性，当未来的走势与后视镜里的经验相悖时，有足够的容错空间去修正


## 八、延伸思考：后视镜是“成长陷阱”的源头

（本章“投资随想录”内容）

投资者最常犯的错误有两个：一是**买的太贵**，二是**买的便宜却买错了**。

第二种错误——**买错**——往往是因为**看着后视镜**。

过去几年这家公司业绩很好，过去十年它一直是行业龙头，所以你觉得现在的低PE是“便宜”。但你忽略了——**过去的好不代表未来的好**。当行业发生结构性变化时，过去的“好”可能恰恰是未来的“负担”。

> **启示**：便宜不是买入的理由，**便宜 + 未来能持续赚钱**才是。不要用后视镜里的“过去好”来论证“未来好”。


## 九、本章核心总结

**一句话记住本章**：

> **后视镜里没有未来，只有残影。投资是面向未来的概率游戏——用昨天的旧地图，找不到明天的新大陆。**

**三个核心判断：**

1. **后视镜是线性外推的根源**——看着过去的走势、财务、宏观来预测未来，是投资中最常见的错误
2. **历史有用，但要学规律而非学表象**——学人性、学商业本质、学泡沫共性，而不是学具体走势
3. **向前看是唯一的破局之道**——估值看未来现金流，基本面看未来格局，仓位要应对重于预测

**A股投资者最该记住的一句话：**

> **在A股这个变化最快的市场里，“过去一直如此”是最危险的理由。当你说出“这次不一样”的时候要警惕，但当你说出“每次都一样”的时候——更要警惕。因为每一次，细节都不一样。**
