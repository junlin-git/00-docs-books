# 06 经验就像旧衣服（A股实战加强版）

> **核心理念**：经验就像旧衣服，曾经合身且为你遮风挡雨，但随着时间、市场环境的变化，旧衣服会变得不合身甚至束缚行动。投资者需要懂得适时“脱下”旧经验，换上新衣。


## 一、核心隐喻：经验的价值与局限

### 1.1 为什么是“旧衣服”？

投资中的任何感悟和总结都有各种局限性——**于己合身的，于人往往并不合适**。每一段投资经验都是在特定的市场环境、特定的周期位置、特定的个人认知下形成的。当这些条件改变时，经验就可能从“铠甲”变成“束缚”。

**衣服的作用**：为你遮风挡雨、提供保护——对应经验的价值：建立框架、识别风险、提供指引。

**衣服的局限**：身材变了、季节变了，旧衣服就不再合身——对应经验的局限：路径依赖、时代变迁、逻辑失效。

### 1.2 经验的正面价值

- **建立初步的投资框架**：让新手有一个可以起步的参照系
- **识别常见的骗局和泡沫**：历史虽不会简单重复，但往往押着相似的韵脚
- **在相似的市场周期中提供决策指引**：周期的“韵脚”可以帮助判断位置

### 1.3 经验的致命局限

- **路径依赖**：成功经验容易让人盲目自信，认为“这次也会和上次一样”
- **时代背景变迁**：宏观经济、行业格局、参与者结构的改变，会使过去的估值体系和投资逻辑失效
- **幸存者偏差**：过去的成功可能只是运气好（碰上了牛市或某个风口），不要把运气当成能力


## 二、经验失效的三大陷阱

### 陷阱一：“这次没什么不同”（拒绝变化的保守主义）

**表现**：过度依赖历史经验，对正在发生的新变化视而不见，认为历史的重演是必然的。

**危险**：错失结构性创新带来的大级别投资机会，甚至在产业被颠覆时仍然死守烂公司。

**经典案例**：互联网刚兴起时，传统零售业者认为“零售本质没变，互联网只是噱头”，结果被电商大幅颠覆。如果投资者死守“传统零售经验”，就会错失互联网巨头的高速成长期。

**A股案例**：2013-2015年，部分传统价值投资者认为“互联网泡沫和2000年一样”，对移动互联网的结构性变化视而不见，错过了创业板的大牛市。

### 陷阱二：“这次不同了”（拥抱变化的狂热主义）

**表现**：抛弃所有历史规律，盲目相信当前的新概念、新故事能打破经济常识和估值引力。

**危险**：陷入疯狂泡沫，在估值极高时接盘，导致本金永久性损失。

**经典案例**：1999年互联网泡沫顶峰时，人们相信“新经济改变了盈利规律，不需要看市盈率”；2007年A股6000点时，人们相信“黄金十年，市盈率可以永远在高位”。结果泡沫破裂，一地鸡毛。

**A股案例**：2015年5000点时，人们相信“新经济不需要看估值”；2021年新能源狂热时，人们相信“100倍PE也不贵”——最终都被均值回归击碎。

### 陷阱三：锚定效应与线性外推

**表现**：把过去的股价高点或低点作为“锚”，或者把过去几年的高增长线性外推到未来。

**危险**：在周期顶峰买入所谓的“成长股”，在周期底部卖出真正的优质资产。

**经典案例**：某周期股在景气度最高时利润大增，PE看起来很低（如5倍），投资者用过去的经验认为它低估了；但实际上周期即将反转，利润暴跌后PE会变成50倍甚至亏损。

**A股案例**：将2015年的5178点或2007年的6124点作为“锚”，认为“不到那个位置就不是牛市”——这种锚定思维让无数投资者在结构性行情中踏空。


## 三、核心方法论：区分“周期性”与“结构性”

面对市场变化，第一步不是“行动”，而是**判断**——当前的变化属于周期性变化还是结构性变化？

### 3.1 周期性变化：经验依然有效，“穿旧衣”

| | 内容 |
| :--- | :--- |
| **特征** | 供需关系围绕均衡点波动，均值回归终将发生；行业底层逻辑未变 |
| **应对策略** | 运用过往的周期经验，在别人恐慌时贪婪，在别人狂热时谨慎 |
| **A股案例** | 猪肉价格的周期性波动、航运业的景气周期、货币政策松紧驱动的估值周期 |

### 3.2 结构性变化：经验已经失效，“换新衣”

| | 内容 |
| :--- | :--- |
| **特征** | 行业底层的商业模式、技术路线、竞争格局发生了不可逆的根本改变 |
| **应对策略** | 果断抛弃旧估值体系，深入研究新逻辑，承认无知并重新学习 |
| **A股案例** | 智能手机替代功能机、新能源汽车替代燃油车、注册制改革改变A股生态 |

### 3.3 如何区分？三问判断法（实操工具）

□ **问题1：这个变化是否改变了行业的底层商业模式？**

  → 如果商业模式没变 → 可能是**周期性变化**
  → 如果商业模式变了 → 可能是**结构性变化**

□ **问题2：这个行业的“均值回归”规律是否仍然适用？**

  → 如果均值回归仍然适用 → **周期性变化**
  → 如果均值回归可能失效 → **结构性变化**

□ **问题3：三年后，这个行业的前几名还是现在的这些公司吗？**

  → 如果还是 → **周期性变化**
  → 如果可能换人 → **结构性变化**

### 3.4 A股特色：周期性变化往往与政策周期深度绑定 ⚠️

在成熟市场，周期性变化的驱动力主要是市场供需。但在A股，很多周期性变化的驱动力是**政策周期**：

- 供给侧改革驱动的周期品行情（2016年后的钢铁煤炭）
- 货币政策松紧驱动的估值周期（降息→估值扩张，加息→估值收缩）
- 监管政策变化驱动的行业周期（并购重组松紧、IPO节奏变化）

> **A股经验主义陷阱的一个特殊来源**：很多投资者的“经验”来自于对过去政策周期的记忆——比如“每次降准都会涨”“每次政治局会议前都会维稳”。但当政策框架发生结构性变化时（如从“房住不炒”到“提振资本市场”），这些经验就可能失效。


## 四、投资中“不变”的东西——三根定海神针

尽管市场表象千变万化，但投资的核心本质是不变的。这些才是真正值得依赖的“经验”。

### 定海神针一：商业的本质——现金流

任何不能持续创造自由现金流的商业模式，无论故事多动听，最终都是毁灭价值的。

- **问自己**：这家公司赚的钱，是“真金白银”还是“账面数字”？
- **验证指标**：经营活动现金流净额 / 净利润是否持续 > 0.8？

### 定海神针二：人性的本质——贪婪与恐惧的钟摆

市场情绪永远在极度乐观和极度悲观之间摆动——这保证了逆向投资的有效性。

- **问自己**：现在市场情绪在钟摆的哪一端？
- **验证指标**：爆款基金频发 vs 基金发行遇冷；人人谈股 vs 无人问津

### 定海神针三：价值的本质——价格终将回归价值

无论什么时代，买得便宜都是降低风险、提高收益的根本途径。

- **问自己**：现在的价格，提供了足够的安全边际吗？
- **验证指标**：PE/PB历史分位数、股债性价比（1/PE vs 国债收益率）


## 五、投资者的应对策略与心态建设

### 5.1 保持空杯心态

承认自己的经验可能过时，对新事物保持好奇心。**不要轻易用“我看不懂所以它是骗局”来排斥新事物**——你看不懂，可能只是因为你的经验已经“旧”了。

### 5.2 建立“应对”而非“预测”的体系

既然经验无法百分百预测未来，投资组合就必须具备容错性：
- 买入时留有足够的安全边际——即使判断错误，也不至于伤筋动骨
- 适度分散——不要把所有筹码压在“这次一定对”上

### 5.3 适时止损与认错

当发现市场的走势与自己的“经验”相悖，且逻辑上确实发生了结构性变化时，必须果断认错，不要为了面子死扛。

> **A股大实话**：在A股，最大的成本不是交易成本，而是“我上次就是这样赚钱的”这个执念。

### 5.4 延伸思考：扑克与投资的共通之处 ⚠️

本章“投资随想录”中有一个重要的延伸：**扑克与投资的共同难点**。

扑克中，**未出的牌能否构成张，事前是可以估算概率的，然而懂得估算的人少之又少**。人性的弱点在于，对未出的牌往往抱有过于美好的想象，驱使人们去赌未来的小概率事件。

**投资的启示同样如此**：

> 能预见未来成长的人少之又少，而为成长过分买单的却大有人在。

不要把过去的“好运气”当成可重复的“能力”。每一手牌都是新的概率问题，每一次投资都是新的估值问题。


## 六、本章核心总结

**一句话记住本章**：

> **经验是你在市场中生存的工具，而不是信仰的教条。**

**三个核心判断框架：**

1. **面对变化，先问“周期性还是结构性”** ——用“三问判断法”做区分
2. **锚定三根定海神针** ——现金流、人性钟摆、价值回归
3. **保持空杯，适时换衣** ——衣服旧了可以扔，但身体（核心原则）是根本

**A股投资者最该记住的一句话：**

> **在A股这个变化最快的市场里，最大的风险不是“看错”，而是“用旧经验看新市场”。每一轮牛市都有新的逻辑，每一轮熊市都有新的教训——保持学习，才是唯一不过时的经验。**
