# 05 宁数月亮，不数星星（A股实战加强版）

> **核心理念**：行业竞争格局比行业增速更重要。一个增速平庸但格局清晰的行业，远好于一个高增速但格局混乱的行业。投资应追求确定性——宁数月亮，不数星星。


## 一、核心隐喻：数星星 vs 数月亮

### 1.1 什么是“数星星”？

指投资于竞争激烈、行业分散、群雄逐鹿的行业。

- **特征**：市场参与者众多，尚未形成明确的龙头，大家都在打价格战抢份额
- **难点**：不确定性极高，很难预测谁能最终胜出，投资就像赌博，胜率低
- **典型**：早期的团购（千团大战）、共享单车（彩虹大战）、当下的某些新兴赛道

### 1.2 什么是“数月亮”？

指投资于竞争格局清晰、行业集中度高、寡头垄断或寡头格局已经形成的行业。

- **特征**：行业胜负已分，龙头地位稳固（月亮），小企业（星星）难以撼动其地位
- **优势**：确定性高，不需要去猜谁能赢，因为赢家已经浮现
- **典型**：白电（美的+格力+海尔）、高端白酒（茅台+五粮液）

### 1.3 为什么“数月亮”更好？

**原书最精辟的总结**：

> 数月亮的行业一般门槛高，参与竞争的企业少，所以竞争有序，坐地收钱，旱涝保收；数星星的行业门槛低，谁都能进来，竞争激烈，经济好时担心成本上升，经济差时担心需求下降，好日子总是不长久。前者是**赚钱不辛苦**，后者是**辛苦不赚钱**。

**三个核心优势**：

| 优势 | 解释 |
| :--- | :--- |
| **定价权** | 格局清晰的行业中，龙头拥有定价权，不会轻易陷入恶性价格战 |
| **规模效应** | 龙头企业拥有成本、渠道和品牌优势，形成坚固护城河 |
| **降低研究难度** | 预测行业增速很难，但判断行业格局是否稳定相对容易 |


## 二、月亮的形成：门槛是核心

### 2.1 核心：有门槛

数星星的行业门槛低，谁都能进来；数月亮的行业门槛高，把竞争对手堵在门口。

**选行业的第一问**：这个行业的门槛是什么？如果说不清楚，说明没有门槛，直接跳过。

### 2.2 门槛的四种具体形式

| 门槛类型 | 解释 | A股案例 |
| :--- | :--- | :--- |
| **规模效应** | 产量越大，单位成本越低，小企业无法生存 | 空调（格力、美的）、水泥（海螺） |
| **品牌壁垒** | 消费者认品牌胜过价格，形成差异化 | 高端白酒（茅台、五粮液）、调味品（海天） |
| **网络效应** | 用户越多，平台价值越大，赢者通吃 | 社交（微信）、电商（淘宝/京东） |
| **高转换成本** | 客户更换供应商成本极高，不敢轻易换 | 企业级软件（用友）、医疗器械 |

### 2.3 一个更精妙的视角：学会“定义天空”

> **原书核心观点**：“数月亮的关键是学会如何定义天空，如何定义子行业。”

同一个行业，从不同角度划分，可能看到的是完全不同的格局：

- **白酒**：群星闪耀（几百个品牌）→ **高端白酒**：月朗星稀（茅台+五粮液）
- **家电**：竞争激烈 → **白色家电**：三足鼎立（美的+格力+海尔）
- **互联网**：百花齐放 → **社交**：一家独大（微信）

> **实操要点**：不要只盯着大行业看，要学会在细分领域中找“月亮”。大行业可能是“星星”，但细分领域可能是“月亮”。


## 三、竞争格局的四层分类与投资策略

> **原书框架**：最好的格局是“月朗星稀”，其次是一超多强，再次是两分天下或三足鼎立，最差的是百花齐放、百舸争流。

### 3.1 月朗星稀（一家独大）

| | 内容 |
| :--- | :--- |
| **特征** | 一家独大，占据绝大部分市场份额，其他企业只能捡漏 |
| **策略** | 首选买入绝对的龙头。只要估值不离谱，这就是最好的长期持有标的 |
| **A股案例** | 高端白酒（茅台）、社交（腾讯） |

### 3.2 一超多强（老大优势明显）

| | 内容 |
| :--- | :--- |
| **特征** | 老大优势明显，市场份额远超老二、老三 |
| **策略** | 买入龙头，享受规模优势和品牌溢价 |
| **A股案例** | 工程机械（三一重工）、客车（宇通） |

### 3.3 两分天下 / 三足鼎立（寡头格局）

| | 内容 |
| :--- | :--- |
| **特征** | 两三家大企业占据主要市场，形成默契，不打恶性价格战 |
| **策略** | 买入其中基本面最扎实、成本控制最好的龙头之一 |
| **A股案例** | 白电（美的+格力+海尔）、乳制品（伊利+蒙牛） |

### 3.4 百花齐放（高度分散）

| | 内容 |
| :--- | :--- |
| **特征** | 门槛低，参与者众多，无龙头，同质化严重，价格战惨烈 |
| **策略** | **坚决回避**。除非看到行业正在发生大规模并购或洗牌 |
| **A股案例** | 早期的团购、共享单车、低端服装制造 |

> **邱国鹭原话**：“最差的竞争格局就是'百花齐放'、'百舸争流'的高度竞争行业。这种充分竞争的行业一般是吃力不讨好的行业，长期投资者不妨等待他们通过竞争分出胜负之后再投资。”


## 四、经典A股案例

### 4.1 白色家电（空调）——从星星到月亮的蜕变

- **演变过程**：2000年代初，空调行业有几百个品牌（满天星），价格战惨烈，谁都不赚钱。经过惨烈的行业洗牌后，大量小品牌倒闭。
- **现状**：形成了美的、格力、海尔“白电三巨头”格局。格局稳定后，龙头拥有了定价权，利润大幅增长。
- **投资结果**：06年起格力美的实现百倍市值扩张，核心驱动正是格局的确立。

### 4.2 白色家电 vs 黑色家电（电视）——同行业，天壤之别

| | 白电（冰洗空） | 黑电（电视） |
| :--- | :--- | :--- |
| **技术迭代** | 慢，核心在于成本控制和渠道规模 | 极快（CRT→液晶→OLED→MiniLED） |
| **竞争格局** | 三足鼎立，格局清晰 | 分散，每次技术换代都是一次洗牌 |
| **投资结果** | 白电出长牛股 | 黑电很难出长牛股 |

> **原书分析**：白电虽然还在混战，但已只剩下几家；而黑电从CRT到等离子到液晶屏到LED到3D电视，每一次改变都是革命性的，企业跟不跟都很痛苦。

### 4.3 工程机械——周期股的格局重塑

- **演变过程**：经过上一轮行业低谷（2011-2015年）的出清，小企业退出市场，龙头集中度大幅提升。
- **现状**：三一重工、徐工等龙头占据主导地位。
- **投资结果**：格局改善后，即使周期向下，龙头的盈利韧性和抗风险能力也远超过去。

### 4.4 “胜而后求战”的哲学

> **原书引用《孙子兵法》** ：“胜而后求战，而不是战而后求胜。”

邱国鹭的投资哲学是：**等行业分出胜负之后再投资**。很多人担心会太迟，但回头看，十年前早就是龙头的公司，十年后还是行业龙头，十年来涨幅惊人。

**一个生动的比喻**：

> “判断一个人是否成才，你是愿意在三岁的时候去判断还是等到30岁呢？我们是二级市场投资者，30岁看老就可以了。”


## 五、识别“伪月亮”——三种风险

### 5.1 跨界降维打击

行业内部看似格局已定，但被外部新技术或新模式颠覆。

- **案例**：诺基亚曾经是手机行业的月亮，被苹果智能手机降维打击
- **应对**：关注底层需求是否改变，而不是仅仅看市场份额

### 5.2 政策反垄断风险

当一个“月亮”过于庞大，可能面临反垄断政策的限制。

- **案例**：互联网平台的反垄断监管
- **应对**：评估政策的持久性和实质影响，区分“规范行业”还是“摧毁行业”

### 5.3 A股特色：政策扶持下的“伪月亮” ⚠️

在A股，有些行业的“月亮”不是市场竞争出来的，而是政策补贴催生出来的。一旦政策退坡，这些“月亮”就会现出原形。

- **典型案例**：新能源汽车行业早期，大量企业依靠补贴生存，看似形成了若干“龙头”，但补贴退坡后大批淘汰
- **判断标准**：这家公司的竞争优势，是“市场给的”还是“政策给的”？政策退坡后，它还能活得好吗？

> **原书提醒**：国家给的寡头垄断（如公用事业）往往伴随着价格管制，长期投资回报一般不会太高。只有市场竞争、行业洗牌后产生的寡头垄断才有定价权。


## 六、“数月亮”实操检查清单

**买入前必须回答的五个问题：**
```
□ 问题1：这个行业的竞争格局属于哪一类？
→ 月朗星稀 / 一超多强 / 两分天下 / 三足鼎立 / 百花齐放？
→ 如果是“百花齐放”，直接跳过，不参与。

□ 问题2：这个行业的“月亮”是怎么形成的？
→ 是市场竞争洗牌出来的，还是政策给的？
→ 只有市场给的才有定价权。

□ 问题3：这个行业的门槛是什么？
→ 规模效应？品牌？网络效应？转换成本？
→ 如果说不清楚门槛是什么，说明没有门槛，不投。

□ 问题4：这个“月亮”有没有被颠覆的风险？
→ 有没有跨界降维打击的可能？
→ 政策会不会反垄断或改变行业规则？
→ 竞争优势是“政策给的”还是“市场给的”？

□ 问题5：这个“月亮”现在贵不贵？
→ PE/PB在什么历史分位数？
→ 再好的月亮，买贵了也会亏钱。“月亮”+“好价格”=好投资；“月亮”+“贵价格”=可能亏钱。
```

## 七、本章核心总结

**一句话记住本章**：

> **行业格局决定结局。** 

**四条操作纪律：**

1. **先选行业格局，再选公司。** 放弃高增长但群雄逐鹿的行业，拥抱低增长但壁垒森严的寡头行业。
2. **学会“定义天空”。** 在大行业中找细分领域的“月亮”——白酒是星星，但高端白酒是月亮。
3. **警惕“伪月亮”。** 跨界颠覆、政策反垄断、政策扶持下的伪寡头——三种风险都要防。
4. **月亮虽好，别买太贵。** 再好的公司，在估值极度透支时买入，也可能多年不赚钱。

**A股投资者最该记住的一句话：**

> **在A股，不要做第一个吃螃蟹的人。等胜负已分、事情清晰了再投资，反正A股波动性很大，常常出现很好的买入时机。**
