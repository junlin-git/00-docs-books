# 《穷查理宝典》第三章：芒格主义——查理的即席谈话
## 第八节：对华尔街的批评 —— 详细总结

---

## 一、本节总览：芒格为什么要批评华尔街？

这一节收录的是芒格在 **2001–2006 年间**伯克希尔·哈撒韦和西科金融（Wesco）年度股东大会上的即席发言，核心矛头指向一个事实——**华尔街已经从"服务客户的金融业"蜕变为"不惜一切售卖产品的销售机器"**，而会计制度、激励机制和法律边界的集体沦陷，使这套系统变得危险。

> 芒格的批评不是情绪化的反资本宣言，而是一个**老派 banker's banker** 对本行业基本职业道德崩塌的诊断书。他批评的靶心是：**当"合法"取代了"正确"，当"能卖出去"取代了"对客户有益"，整个金融体系就从文明的基础设施变成了文明的诅咒。**

---

## 二、核心主题一：华尔街的道德缺失

### 2.1 开篇定调——毫不留情的诚实判断

> **"华尔街的平均道德水准永远至多只能说是中等……"**

这句话本身就是芒格风格的典型——不用修辞包装、不做政治正确缓冲。他紧接着补了一刀：

> *"这并不意味着华尔街没有一些正直的聪明人——其实是有的，像今天在座的各位——但我认识的每个人都不得不和他自己的公司对抗（为了做正确的事情）。"*

**思维框架层面**，这里揭示了一个关键区分：

| 层级 | 芒格的判断 |
|------|-----------|
| **个人层面** | 华尔街不乏聪明、正直之人 |
| **机构/系统层面** | 机构的激励结构把好人逼成"不得不对抗公司才能做对事" |
| **文化层面** | "平均道德水准=中等"且**还在下滑**——这才是系统性风险 |

芒格点出的核心矛盾是：**不是华尔街没有好人，而是好人在制度里被惩罚，坏人被奖励。**

---

### 2.2 道德风气的"滑坡论证"——今昔对比

芒格给出了一个具体的历史锚点：

> **"许多年前，我们花600万美元收购多元零售公司（Diversified Retailing），银行对我们进行了严格而聪明的审查。那些银行家关心他们的客户，想要保护他们的客户。"**

然后他按下快进键：

> **"现在的风气是——只要能赚钱，什么都可以卖。你能把东西卖掉，你就道德高尚。但这个标准可不够。"**

| 维度 | 过去的投行文化 | 芒格眼中的现状 |
|------|--------------|---------------|
| 银行角色 | **把关人 / 受托人**——审查客户、保护客户 | **推销员**——把东西卖出去就算成功 |
| 道德标尺 | 客户长期利益 | 交易量 × 手续费率 = 收入 |
| 评判标准 | "这件事对客户合适吗？" | "这东西合规吗？能卖掉吗？" |

> 💡 **芒格的核心洞察**：当一个行业的道德下限由"法律红线"定义而非由"受托人义务"定义，它就不可能自我纠偏——因为**合法≠正确**，而华尔街恰恰把"没被抓＝可以干"当成了道德哲学。

---

### 2.3 个案研究 A：「所罗门」与罗伯特·麦克斯韦尔——追逐恶棍的投行

这是全节最辛辣的叙述之一。

- **罗伯特·麦克斯韦尔**（Robert Maxwell），绰号**"跳来跳去的捷克人"**，是个众所周知的争议人物。
- 所罗门兄弟（Salomon Brothers）——芒格亲任其审计委员会委员 **五年**——居然**求爷爷告奶奶地想要得到麦克斯韦尔的投资业务**。

> "他既然有这个花名，投资银行就不应该去抢着做他的生意。"

芒格的逻辑链条极为干净：

1. 投行不是普通商店——它管理的是别人的信任和资本；
2. 如果你为了一笔手续费，**把不三不四的人引入系统**，你就污染了整个系统；
3. 如果有个投行家多开几张交易单给麦克斯韦尔，他的收入就会显著增长——**个人的金钱激励直接对抗机构的名誉风险**；
4. 麦克斯韦尔最终丑行败露、**跳海自杀**那天，所罗门还在往他账户里汇款……

> 芒格的结语带着典型的苦涩幽默：*"这是个小小的奇迹——我们不配要回这笔钱。"*

**深层诊断**：

| 病根 | 表现 |
|------|------|
| **委托-代理冲突** | 交易员/ banker 赚的是手续费和奖金，风险由股东和未来买单 |
| **名声的"公地悲剧"** | 每个部门都消耗所罗门的信誉，没人真正看护它 |
| **"合法化堕落"** | 没违法 ≠ 没作恶；竞争压力让"不做这单"的人被淘汰 |

---

### 2.4 个案研究 B：诺曼底美国（Normandy America）——IPO 欺诈与投行的"发现即放行"

芒格讲了另一个案例：诺曼底美国准备公开募股，但**招股材料几乎全部是伪造的**。所罗门的人发现了，在交易尚未完成时**果断取消了IPO**。

这个故事的反面教训才是重点：

- 投行**有能力**发现欺诈；
- 多数情况下，它们选择**不看**、或看了也推进——因为**承销费太香了**；
- 所罗门这次"做了正确的事"，恰恰反衬出行业常态是**睁一只眼闭一只眼**。

---

### 2.5 芒格对华尔街道德问题的"一句话总结"

> **"在你应该做的事情，和就算你做了也不会受到法律制裁的事情之间，应该有一条巨大的鸿沟。我想你应该远离那条线。"**

这句话是整个华尔街批评章节的**道义基石**。它直接否定了华尔街的法律主义道德观（"只要不违法就行"），代之以真正的**职业伦理**（fiduciary standard / 受托人标准）。

## 三、核心主题二：对会计制度的批评——"创造性会计"之咒

芒格把华尔街的道德问题和会计制度的溃烂视为**同一个病灶的两面**。银行卖毒药，会计师给它贴"符合GAAP"的标签。

### 3.1 会计报表应该是什么？

芒格引用 C.F. 布劳厄（C.F. Braun）的信条：

> **"报表不应以报表编制者的利益为中心。报表唯一的使命是服务使用者。它们是衡量业绩的尺子——它们本身必须成为高质量的尺子，才配得上使用者。"**

这意味着：
- 会计不是"合规表演"，而是**信托责任**；
- 一旦你把尺子弄弯，后面所有的决策——股价、薪酬、并购——全是基于谎言的连锁反应。

---

### 3.2 激进会计法（Aggressive Accounting）= 文明级诅咒

芒格直言不讳：

- **安然（Enron）** 是企业文化长期出毛病的**最典型标本**——不是孤立事件，而是会计软化 + 投行纵容 + 高管贪婪的**Lollapalooza效应**（多种偏误同向叠加）；
- **"创造性会计"（伪造账目）绝对是对文明的诅咒**；
- **在民主国家里，往往需要丑闻才能撬动改革**——这是制度设计的悲哀。

关键机制链条：

宽松的会计标准
→ 利润可以"被创造"出来
→ 高管/交易员的奖金立即兑现
→ 没人愿意戳破泡沫（因为自己分到了钱）
→ 直到爆雷 → 社会承担代价

> 芒格的观察极为冷峻：**"你一旦开始做坏事，第二次就容易多了，到最后你就会成为道德败坏的人。"** 这不是说教，这是对行为心理学的精确描述——习惯uation + 一致性原理 + 社会认同把普通人一步步锁进犯罪。

---

### 3.3 EBITDA 与"狗屁利润"

芒格留下了全书最粗粝也最难忘的一句吐槽：

> **"我认为，你每次看到 EBITDA（未计利息、税项、折旧及摊销前的利润）这个词汇，你都应该用'狗屁利润'（bullshit earnings）来代替它。"**

为什么？因为 EBITDA 剥离了资本开支和折旧——恰恰是**重资产/资本密集生意的真实成本藏身之处**。用它来衡量企业绩效，等于**把维持生意运转的必需开销定义为"不关我事"**，方便管理层把账面利润做得漂漂亮亮、把真实现金流掏空。

---

### 3.4 安达信（Arthur Andersen）的倒塌

安达信曾是五大会计师事务所之一，因安然丑闻被定罪（后被最高法院部分推翻，但品牌已死）。

芒格的态度复杂而犀利：
- 他对安达信**无辜员工**表示同情——*"没有失败的资本主义，就像没有地狱的宗教"*（又一记芒格式冷笑话）；
- 但同时对合伙制的脆弱本质敲警钟：**合伙制企业在选客户时必须额外谨慎**，因为你的名字就是你的产品。

隐含的更大指控是：会计师事务所把自己从"独立审计把关人"变成了"收费咨询服务提供者"，审计意见开始**被客户需求绑架**。

## 四、核心主题三：对金融机构和衍生品的警告

> 这部分内容在书中常与"对华尔街的批评"并列作为姊妹节。芒格对衍生品的抨击，是他**最早预警 2008 年金融危机**的核心论述之一。

### 4.1 衍生品的会计法——"像阴沟，说它像阴沟是对阴沟的侮辱"

芒格原话的力度需要完整保留：

> **"我非常讨厌将 GAAP（公认会计准则）应用于衍生品和掉期协议。摩根大通为了虚报的前端收入将自己彻底出卖给了这种会计准则。"**

运作机制解剖：

| 步骤 | 发生了什么 | 芒格的判断 |
|------|-----------|-----------|
| ① 签衍生品合约 | 未来几十年的现金流承诺 | 真实盈亏根本无法可靠计量 |
| ② "按市值计价"（Mark-to-Market）/ 按模型定价 | 用一个理论模型算出"当前价值" | **与其叫 mark-to-model，不如叫 mark-to-myth（按臆想定价）** |
| ③ 账面利润立刻入账 | 当期收益暴增 → 奖金池暴涨 | "产生了大量由会计人员**捏造出来的利润**，不是真实的收益" |
| ④ 想动用那笔钱时 | **它就消失不见了——它从来就不曾存在过** | "你所能做的就是想好当账本上那些衍生品破灭时该怎么办" |

芒格的结论：

> **"它是这么恶心。它像阴沟那么臭——如果我猜得没错，那些公司将会付出沉重的代价。"**

---

### 4.2 衍生品 = 披着合法外衣的国家级赌博

芒格后来的表述更加直白（跨年度的语录汇总）：

> - *"华尔街上的衍生品交易实质上是披着合法外衣的赌博，这是国家的不幸。"*
> - *"我们的文明需要股指期权交易，就像它需要更多的艾滋病一样。结果不是零和交易，而是**负的**。"*
> - *"同一笔衍生品交易，一家公司的估值是一个数字，另一家公司的估值是另一个数字。"*

三层指控：

1. **经济功能层面**：大部分衍生品不为实体经济融资，只是**金融机构间互相下注**；
2. **会计层面**：无法可靠估值 → 为操纵利润开了后门；
3. **系统性风险层面**：规模巨大、对手方交织、不透明——**一个节点爆雷 = 连锁传染**。

---

### 4.3 伯克希尔的实践验证：甩掉衍生品账本

芒格透露：
- 伯克希尔收购通用再保险（General Re）后，继承了衍生品账簿；
- 他们**试图卖掉这块业务 → 失败 → 只能亲自清算**；
- 清算时**不得不大幅削减价格**——证明账面上标的价格是幻觉；
- 芒格断言：**美国的主要银行也无法以账本上的价格清算其衍生品持仓**；
- **"我认为我们是美国唯一甩掉衍生品账本的大型公司。"**

预测（2001–2003 年语境）：

> *"在未来五到十年里，如果美国没有遇到（和衍生品相关的）大问题，我将会非常吃惊。"*

——事后看，2008 年正好落在那个窗口里。

## 五、深层框架：芒格诊断华尔街的"病因树"

把以上散落的火力组织成一棵因果树，就能看清芒格的思维模型：
```
┌─────────────────────────────────────────────────┐
│ ROOT：错位的激励机制 │
│ banker 的收入 = 交易量×费率（不管长期后果） │
│ 会计师的激励 = 留住大客户（不是保护公众） │
│ 高管薪酬 = 当期EPS/Bonus（不是长期内在价值） │
├─────────────────────────────────────────────────┤
│ TRUNK：道德基准的下移（The Serpico Effect）│
│ "大家都这么做" → 合理化 → 底线不断下沉 │
│ "合法"取代"正确" → 职业伦理空心化 │
├─────────────────────────────────────────────────┤
│ BRANCH ① 投行变成推销机器 │
│ └─ 所罗门抢麦克斯韦尔的生意 │
│ └─ 承销IPO时对欺诈睁一只眼 │
├─────────────────────────────────────────────────┤
│ BRANCH ② 会计变成化妆师 │
│ └─ 激进会计 / EBITDA美化 / mark-to-myth │
│ └─ 安然式骗局的制度化温床 │
├─────────────────────────────────────────────────┤
│ BRANCH ③ 衍生品 = 假利润 + 真杠杆 + 暗传染 │
│ └─ 账面财富幻觉 → 奖金兑现 → 爆雷时社会化损失 │
├─────────────────────────────────────────────────┤
│ LEAF：系统性金融危机（2008验证了他的预言） │
└─────────────────────────────────────────────────┘
```

## 六、芒格的正面主张——"我们凭什么不与华尔街同流？"

批评之外，芒格给出了伯克希尔之所以能避开这些陷阱的操作原则，它们同样是该节不可分割的一部分：

| 原则 | 原文精神 | 实践含义 |
|------|---------|---------|
| **远离那条线** | 在"应做的事"和"合法但不该做的事"之间留巨大缓冲 | 不碰看不懂的东西；不靠会计魔术美化 |
| **说真话，你就不必记住你的谎言** | 引路易斯·文森狄规则 | 坦诚披露 > 华尔街式"管理预期" |
| **保守会计是竞争优势** | "我们利用会计来帮我们做商业决策，不是用会计来骗人" | 账面价值低于内在价值 = 安全边际之源 |
| **不做蠢事 > 做聪明事** | "我们赚钱靠记住浅显的，而不是掌握深奥的" | 复杂衍生品之所以危险，恰恰因为"深奥"被用来掩盖风险 |
| **老派文化 = 护城河** | 像富兰克林/卡内基的文化——不请顾问、不追华尔街认可 | 股东把毕生积蓄托付给你 → 就得像个受托人的样子 |

---

## 七、一句话读完这节的灵魂

> **芒格对华尔街的批评，本质上不是反商业，而是反伪商业——他捍卫的是金融应当服务的东西：诚实的资本配置。当华尔街把"能合法卖掉"当成道德满分，它就从文明的管道工变成了文明的漏水龙头。**
