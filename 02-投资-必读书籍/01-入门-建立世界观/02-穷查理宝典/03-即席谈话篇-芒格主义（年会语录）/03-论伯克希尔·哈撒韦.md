# 论伯克希尔·哈撒韦 ——《穷查理宝典》第三章·芒格主义：查理的即席谈话

> **性质**：这是全书从"芒格的智慧格言"下沉到**一台真实运转的巨型机器的解剖台**——芒格以即席谈话的方式，把伯克希尔从一个"传奇投资故事"拆回它的**工程零件**：资金引擎（浮存金）、组织结构（去中心化）、收购哲学（不买则已买则不爱）、文化（富兰克林式保守主义）、以及对自身局限的诚实预估（规模诅咒）。
>
> **贯穿全节的一条暗线**：伯克希尔的成功 ≠ 巴菲特+芒格个人天才不可复制，而是他们把天才**固化成了制度**（"伯克希尔系统"），所以即便将来没有同等天才，也不会"go to hell in a bucket"。

---

## 0. 总纲：伯克希尔的"发动机原理"——一句话说清它为什么存在

> **"我们就像（伯林教授的）刺猬，只知道一个大道理：如果你能够用3%的利率吸取浮存金，然后将其投资给某家能够带来13%的收益的企业，那么这就是一桩很好的生意。"**

这句话是全节的解锁密钥。整本书后面几千字，都是对这个等式的展开：

┌──────────────────────────────────────────────────────────┐
│ 伯克希尔的"单引擎双螺旋"结构 │
│ │
│ Engine（资金端） │
│ 保险公司收取保费 → 理赔前形成"浮存金" │
│ （别人的钱，成本≈3%或更低，甚至承保利润=-负成本） │
│ ↓ 投资 │
│ Propeller（资产端） │
│ 把浮存金投去ROI≈13%+的好企业 / 好证券 │
│ spread ≈ 10% × 时间 × 复利 = 伯克希尔 │
│ │
│ 约束条件（让它不爆炸）：不杠杆 / 不冒险赔付能力 / │
│ 保守主义文化 / 去中心化防止总部腐败 │
└──────────────────────────────────────────────────────────┘

芒格紧接着补刀：

> "伯克希尔收购的企业能够给我们带来的税前回报率是13%，也许还要更多一点。由于资本成本利率只有3%——这些资本金是别人的钱，以浮存金的形式得到的——这就是非常棒的生意。所以伯克希尔的股东完全不必感到绝望。就复合回报率而言，伯克希尔是没以前那么好，但它仍然是一家极好的企业。"

注意措辞的芒格式诚实：
- "没以前那么好"＝先给你打预防针（后面专节展开）
- "仍然是极好的企业"＝回归基本面：这架机器的**结构优势**没变

## 1. 伯克希尔以前的回报：好到几近荒谬

> "伯克希尔以往的业绩好到几近荒谬。如果伯克希尔愿意举债经营，比如说吧，就算负债率只有鲁珀特·默多克（新闻集团）的一半，它的规模也应该是现在的5倍。"

### 这段的真实含义（两层）

| 层 | 解码 |
|---|------|
| **自夸？** | 不——是在陈述一个可验证的历史事实：长期复合回报确实 absurd |
| **"如果举债…规模是现在5倍"** | 这是芒格式的对比武器：别人用杠杆吹气球 → 短期大，但尾部一炸归零；伯克希尔**主动选择不举债** → 规模受约束，但活下来了，而且活成了最大的 |

> 潜台词：**你可以选"看起来更大更快"的路，也可以选"永远不爆"的路。伯克希尔选了后者，结果后者反而赢了——但不是因为它保守，是因为它同时找到了浮存金这个"免费杠杆"。**

## 2. 伯克希尔的未来展望：芒格最诚实的一段宏观自省

> **"一个人可以做的最聪明的事之一是调低投资预期，尤其是调低对伯克希尔的收益的预期。那是成熟而负责任的表现。"**

然后他给出**两个不容乐观的原因**：

### 原因一：规模太大 → 只能去竞争更激烈的池子

| 过去 | 现在/未来 |
|------|----------|
| 小资金 → 可以去tiny-cap捡烟蒂、找无人竞争的小宝石 | 巨资 → 被迫进入大盘股/成熟行业的池子 → 那里**全是聪明人**（他点名爱丽丝·施罗德这类保险分析专家） |
| 可买的标的多且便宜 | 可吞并的好公司相对少，估值被充分竞争压缩 |

### 原因二：大气候变了

> "从当前的大气候来看，在未来15到20年里，普通的股票市场不会像我们在过去15到20年中体验到的那么景气。请参看沃伦发表在《财富》杂志上的文章——'巴菲特先生论股票市场'（1999年11月）——我完全赞同。"

（注：1999年底正是科网泡沫顶峰前夜，巴菲特的《Fortune》文章警告估值过高——芒格在此背书。）

### 结论

> "在未来20年里，伯克希尔·哈撒韦的市值将会增加，但可以肯定的是，**每年的增长率将会比以前低得多**。但这并不是悲剧。我们很满意。"
>
> "伯克希尔和西科的现金每年都在增加，我们的结构使我们拥有很大的回旋余地。虽然我们规模太大，不可能去购买小公司的股票，但我们在收购整体出售给我们的公司时占有优势。"
>
> "**惟一的区别是我们会告诉你们。未来将会比过去差很多。（所有大型成功企业的情况都是这样的。）**"

#### 框架要点

- **"调低预期"不是悲观，是风险管理的基础动作**——不骗股东、不骗自己、不因落差而慌
- **"所有大型成功企业都这样"**＝均值回归的客观陈述，不是伯克希尔特有的衰老
- **"现金每年增加 + 回旋余地"**＝安全边际在组织层面：宁可闲置现金，不瞎投

## 3. 伯克希尔·哈撒韦的文化：富兰克林式老派保守主义

> "我们的文化是非常老派的，像本杰明·富兰克林或安德鲁·卡内基的文化。你能想像卡内基聘请公司顾问吗？！让人吃惊的是，这种方法现在仍然非常有效。"

### 文化的具体表现——芒格列出的那些"古怪"但致命有效的东西

| 文化特征 | 对应现代企业的反面 | 伯克希尔的做法 |
|----------|-------------------|---------------|
| **无总部官僚** | 庞大的HR/战略/PR/IR部门 | 奥马哈总部≈20多人（一间小套间） |
| **保守主义 = 抗灾能力** | 激进扩张、杠杆美化 | "我们比绝大多数地方更能抵御灾难" |
| **对股东的受托人意识** | 把股东当提款机/期权行权池 | "对我们许多股东而言，我们的股票是他们拥有的一切，我们非常清楚这一点" |
| **不搞华尔街表演** | CEO职责="让股价上涨" | "现在很多人似乎认为企业CEO的责任就是让股票价格上涨。这种观点导致了各种各样的愚蠢行为。我们会实话实说，值多少就说多少。" |
| **不回到GO** | 反复危机→救助→稀释→更多风险 | "我可不想回到GO（起点）。我是从GO走过来的。"（意指早年艰难岁月） |

> "我很高兴我有90%的净资产是在伯克希尔的股票里。"——这句话是文化的最硬背书：**skin in the game**，不是说说。

## 4. 股票价格政策：不讨好华尔街

> "我们希望伯克希尔和西科的股票价格和我们认为它们的**固有价值**相差不要太远。如果股价升得太高，我们就会**呼吁它降下来**。并非所有的美国企业都这么做，但这是我们的做事方式。"
>
> "我可不想回到GO。我是从GO走过来的。我们的许多股东把大部分净资产都投在伯克希尔了，他们也不希望回到GO。"

| 反常识点 | 芒格逻辑 |
|----------|---------|
| 股价太高 ≠ 好事 | 严重高估会吸引投机客、扭曲股东结构、让买入成本变贵、增加未来崩盘伤害忠实股东 |
| "呼吁它降下来" | 用语言管理预期——不回购吹泡泡，不编故事，坦诚"未来比过去差"来冷却非理性溢价 |
| 和主流CEO观对立 | 主流：股价=KPI；芒格：股价=代表真实价值的通信信号，掺假=对股东不忠 |

## 5. 伯克希尔股东：不诱惑人来、只善待已在的

> "我们喜欢现在的股东，不想诱惑谁来成为我们的股东。"
>
> "考虑到这个企业的复杂性，我认为就向股东披露他们需要的信息而言，我们的年报比我知道的任何一家公司都要好。我们是凭着良心这么做的。"

- **"不想诱惑谁"**＝反营销式股东招募。伯克希尔的股东筛选机制是：**只有理解了"长期、无季度承诺、不炒、不吹"的人才会舒服留下来**——自动过滤短线资金
- 年报透明度＝文化的技术实现：不靠PR稿，靠信息密度

## 6. 收购策略："三分之二的收购是失败的"——所以我们的做法是反直觉的

> ### 🔑 全节最著名的论断之一：
>
> **"三分之二的收购是失败的。而我们的收购很成功，那是因为我们从来不试图为收购而收购——我们等着那些不用多想也知道会成功的机会。"**

### 拆解芒格的收购哲学

| 主流PE/并购逻辑 | 伯克希尔逻辑 |
|-----------------|-------------|
| 坐在办公室等投行带deal上门 | "我们不跟上门推销的人打交道。如果你只是坐着等交易上门，那你坐的位子会非常危险" |
| 设KPI："今年必须部署X亿" | "20年来，我们每年购买的企业只有一家或者两家。可以说，我们不停在找。" |
| 为交易而交易（fee-driven） | 只买"不用多想也知道会成功"＝能力圈内 + 好价格 + 好CEO留任 |
| 主动推销式搜寻 ≠ 守株待兔 | **主动但不急**：不停找、看、接触、建立声誉，但绝不因为"有钱要花掉"而扣扳机 |

> "长久以来，许多私募股权投资公司一直与我们展开竞争，但不管怎么样，我们还是设法收购了一些企业。"

芒格这里承认竞争存在——但伯克希尔的"用户友好"+"现金在手+不增发股票+保密+不捣鬼"的组合，在长期反而win。

## 7. 被兼并公司的管理人员：激情 > 天分

> "我们收购一家又一家的企业，是因为我们**敬佩**它们的创办人和这些创办人在生活中取得的成就。在绝大多数情况下，他们会留下来，而且**从来不曾让我们失望**。"

### 激情与天分，哪个更重要？

> **"我认为激情比头脑的能力更加重要。我认为我们的管理人员来参加会议，并不是为了学习管理技巧——他们精通所有跟他们的企业相关的技巧——而是因为这是个有趣的地方，而且每年都变得更加有趣，他们愿意成为它的一部分。"**

| 点 | 含义 |
|---|------|
| 敬佩创办人/成就 | 收购标准第一条：**人**，不是EBITDA曲线 |
| 留任 + 从不失望 | 说明筛选极严——买得少、买得对、不折腾人 |
| 激情 > 头脑能力 | 芒格见过太多聪明但无心之人搞砸；热爱事业的"次优聪明"人反而长期可靠 |
| 来开会不是学管理 | 这等于说：伯克希尔总部**不扮演老师的角色**——子公司CEO不需要被教育 |

## 8. 管理附属企业：权力分散到"几乎全面退位"的程度

> **"基本上，我们会选择那些我们非常钦佩的人来管理我们的附属公司。一般来说，我们跟他们很容易相处，因为我们喜爱并敬佩他们。"**
>
> **"他们总是能够积极进取，及时更正以往的错误。如果让伯克希尔管理的附属公司的那些CEO来发言，可能对现在的股东会有帮助，但我们向他们承诺过，他们可以把100%的时间花在他们的企业上。"**
>
> **"我们对他们管理他们的企业不设置任何障碍。"**
>
> **"许多人对我说他们很高兴，因为不用把25%的时间浪费在各种他们不喜欢的活动上。"**

### 去中心化的操典

| 原则 | 内容 |
|------|------|
| **选对人** | 不是培养人——"我们并不创造这些美德，我们选择那些已经拥有这些美德的公司。我们只是不把它搞坏" |
| **彻底放权** | 子公司CEO像100% owner一样决策：定价、招聘、资本开支——总部不批 |
| **不设统一制度** | 无统一HR政策、无统一预算周期、无全系统KPI体系——各子公司自带有用制度 |
| **几乎不卖子公司** | "作为重要事项之一，几乎从不出售子公司"——这让CEO敢做长期投资而不怕短期被砍 |
| **不调岗** | "几乎从来不将一家子公司CEO调到另一家不相关子公司"——隔行如隔山，原地深耕最值 |
| **不强制退休年龄** | 不以年龄为借口赶人——只要脑子清楚、热爱事业、表现好，就留下 |

> **"我们把权力分散到几乎全面退位的程度。"**——这是全书对伯克希尔组织结构的终极一句定性。

## 9. "合力"：不说这个词，但充满合力

> **"我们不说'合力'这个词，因为人们总是宣称兼并之后会产生合力作用。是的，合力确实存在，但有太多关于合力的不实承诺了。伯克希尔充满了合力——我们并不回避合力，只是回避那些对合力的宣称。"**

| 芒格在打什么 | 解码 |
|-------------|------|
| 投行PPT里的"synergy" | 通常是裁人+粉饰的遮羞布 |
| 伯克希尔的真实合力 | 保险浮存金→资本分配网络 + 母公司AAA级信用→子公司融资成本低 + 永久持有→CEO敢做长期R&D/品牌 |
| 区别 | 伯克希尔的合力是**结构性的、无声的**，不是"合并部门节省10% overhead"那种账面戏法 |

## 10. 人事决定：解雇少得惊人

> "过去几十年来，我们解雇职员的次数少得令人吃惊——远远少于其他企业。这并不是因为我们太心软或者太愚蠢，这是因为我们更加聪明和更加幸运。"
>
> "很多人会回过头来看，并说他们最大的错误是没有及早地解聘某个人（我们从来不这么说）。我们的纪录惊人的好。"

框架：
- **选得极严** → 解雇就少（预防 > 治疗）
- **放权到底** → CEO自驱，总部不需要"监督式fire"
- "更聪明更幸运"＝承认系统之功：好筛选机制 + 好结构，让你不必频繁行使最痛苦的管理权力

## 11. 伯克希尔的保险业务：浮存金的来源与"信任"壁垒

> "表面上看，再保险是一种过度竞争的生意，但其实不是这样的。保险合同的签署和赔付之间有很大的时间差，所以投保人必须评估保险公司未来的支付意愿和支付能力。"
>
> "在这方面，我们信誉良好，拥有一定的优势，不过这种优势本来应该更大的。"
>
> "我认为我们在再保险行业拥有某些优势，是因为**人们信任我们的支付意愿和支付能力**，所以再保险并不是价格低就能卖得好的无特性商品。"
>
> "别人都不这么做，但在我看来，这（别总是想着要取悦华尔街）明显是惟一可行的道路。"

### 保险浮存金逻辑链（芒格式的紧凑版）

承保纪律（宁可少写也不烂账）
→ 长期兑现赔付 → 信誉 → A+评级
→ 投保人/大客户愿意把钱放你这里
→ 浮存金成本低甚至负成本（承保利润）
→ 投资 spread = 真实引擎

> "用很低的成本让浮存金以可观的速度增长几乎是不可能的任务——但不管怎么样，我们想要做到这一点。我曾经为我们的浮存金的增长和成本感到惊讶。我们得到了几十亿美元的浮存金，而所支付的利率比国债的利息还要低，这真是太好了。"

## 12. 回购与股票分割：反华尔街的两个硬姿态

### 回购

> "在过去，当伯克希尔的股价变得便宜时，我们会去买比它更便宜的股票。（相比回购股票）我总是更喜欢这么做。拥有一家声名狼藉的公司，得通过收购某些股东的股份来让其他股东赚钱，这可不好玩。"

- 芒格的优先级：**外部收购好企业 > 回购自家股**
- 回购只在"自家极度便宜且没更好外部用途"才考虑——且不是为了吹股价

### 分割股票（反对）

> "有人认为可交易的普通股票的流动性对资本主义贡献极大，我觉得这种观念**大多是胡说八道**。流动性给我们带来了这些疯狂的泡沫，所以它的问题和好处一样多。"
>
> （巴菲特插话："伯克希尔股票平均每天成交额5000万美元，如果想卖根本不会遇到问题。"）

- 高股价 = **天然股东筛选器**：把短期交易者/小额投机客挡在外面
- 不拆股 = 不迎合"让更多人买得起"的民粹式诉求——保护股东质量

## 13. 终极追问：为什么没有更多公司效仿伯克希尔？

> **"这是一个好问题。我们的方法让我们取得了成功。看看我们、我们的管理人员和股东有多么开心就知道啦。大多数人应该效仿我们。"**

> "我们的投资方法并不难学，但表面上看起来很难，因为它跟一般的方法不同——**它不是常见的方法**。我们的管理费用很低，没有季度目标和预算，也没有一套标准的人事体系，我们的投资集中度比一般企业高得多。就这么简单而且合情合理。"

| 为什么别人不抄 | 芒格的诊断 |
|---------------|-----------|
| 华尔街不奖励它 | 没有季度 EPS 故事可卖 |
| 需要真信任文化 | 大多数CEO-董事会关系是对抗式的，不是合伙式的 |
| 需要delayed gratification | 三年无"可见成绩"＝CEO可能被炒 |
| 需要大股东控制权 | 没有控股地位，这套系统会被董事会/维权股东拆掉 |
| **所以不是"不知道"，是"做不到"** | 结构条件（控股+信誉+长期资本+文化）不可轻易复制 |

## 15. 可迁移的行动原则（无论你是否管企业，都能用）

1. **找到你的"浮存金"等价物**：每个人的"别人的钱"可能是时间、信誉、平台资源——低成本+可投资=杠杆；但必须用**纪律**换低成本，否则杠杆杀你。
2. **去中心化不是"不管"，是"选对人→彻底放权→不折腾"**——最难的部分是克制总部自己扩张的冲动。
3. **收购/重大决策：记住2/3失败律**——设KPI"今年必须买X"是把枪口对准自己；正确姿势是主动搜寻+无限耐心+零妥协。
4. **别把股价当成绩单**——股价是你的通信信道，掺假=长期毁掉最忠实的受众。
5. **调低预期是战略动作，不是丧气话**——清醒的股东base比膨胀的投机base稳固十个量级。
6. **"我们只是不把它搞坏"**——这也许是管理学最伟大的低调宣言：很多组织死于"改进"和"优化"，而非死于不进取。

## 16. 一句话封底

> "论伯克希尔·哈撒韦"不是炫耀一台印钞机的战绩，而是芒格把印钞机拆开让你看齿轮：一只刺猬知道一个大道理（浮存金spread）、一个老派文化（富兰克林式保守+诚实）、一套反本能纪律（不举债/不回购吹泡/不拆分/不迎合/不解雇/不卖子公司/不选错人）——所有这些加在一起，才让"好到几近荒谬"不是运气，而是**可重复的工程设计**。
