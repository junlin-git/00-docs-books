# 第三章「芒格主义：查理的即席谈话」——**对企业管理层的批评**（详细结构化总结）

> **它在书里的位置**：第三章收录的 2001–2006 伯克希尔/西科年会即席答问中，编者把芒格炮轰**上市公司管理层行为与公司治理体系**的段落归到同名小块（有的版本还衔接"对股票期权的批评""对会计/华尔街/律所的批评"等同板块）。  
> **一句话定调**：这不是"管理技巧"章节，而是一次**治理 autopsy（尸检）**——芒格把企业丑闻与平庸追溯到同一条根：**激励错了 + 底线滑了 + 董事会睡着 + 会计规则帮忙化妆**，然后他用富兰克林式直话告诉你：合法≠可以。

---

## 0. 总靶心：芒格在打什么？（先装好瞄准镜）

芒格的批评链可以压成一条因果管：

薪酬/股价激励错配
→ 管理层把"报表数字"当KPI（而非把"企业真实经济结果"当KPI）
→ 用会计自由度"管理EPS"（重组费/一次性/特别费/提前确认/递延费用…）
→ 董事会被流程裹挟成橡皮图章（compensation consultant 产业喂养循环）
→ 会计师事务所/投行生态帮忙"合法化"
→ 系统不靠个别妖怪也能烂（安然/世通是夸张版；更常见的"壳牌级难逮"问题是温水煮青蛙版）

他的解决方案从来不是"更细的法条"，而是：**更硬的品格底线 + 更透明的账 + 所有权感更强的董事会 + 不把股价当成绩单**——也就是伯克希尔自己那套"老派保守主义"。

## 1) 篡改盈利数字与做假账：当"应该"被"大家都这样"覆盖

### 1.1 书中关键意象（原文精神）

- **钱压在财报数据上太重** → 篡改动机极强，"很多人都这么做"并不奇怪。  
- 于是出现 **"谢皮科效应"（Serpico Effect）**：大环境里每个人都觉得"我的做法没啥错，因为其他人也那么干"——**正常化偏差**（normalization of deviance）。  
- 机制会滑向**连锁信/庞氏式骗局**：合法活动（风投/增长叙事）与不体面甚至可耻的活动混在一起，看起来"体面"。  
- 芒格的金句定位：  
  > **"如果你把葡萄干和大便搅在一起，你得到的仍然是大便。"**  
  意思是：用"合法复杂金融/会计技术"包装造假，本质不变——**会计学拦不住道德崩了的人**。

### 1.2 芒格怎么区分"妖怪"与"更难逮的类型"

- 伯尼·埃伯斯（世通）、肯·拉伊（安然）这类 → **近乎变态狂的漫画小丑**，粗暴到容易逮。  
- 但**更难逮的**是更"体面"的组织里，费用归类、一次性项目、表外风险 slowly drift，没有单一妖怪脸——这种更让芒格警觉，因为它说明**系统结构在纵容模糊**。

### 1.3 对你的可迁移原则（审计思维）

| 红旗 | 你在看公司/看自己组织时该问的 |
|---|---|
| "特别费/重组费/一次性"年年出现 | 为什么不算进常规成本结构？谁在用它平滑EPS？ |
| 收入确认节奏很"巧" | 是不是把明年后年的往前拉？渠道库存/应收账款是否同步异常？ |
| 激进解释总有"大所意见"背书 | 大所≠安全；问"如果换个保守CFO这分录还敢做吗？" |
| 公开叙事=一切完美 | 连环增长+零意外≈更该紧张，不是更该信 |

## 2) 美国企业对"特别费"的痴迷：用会计名目管理市场预期

### 2.1 芒格的反问（极锋利）

> **"你说这笔费用每年总是会出现，它还有什么特别的呢？"**

含义：如果一项支出反复发生、可预期，那就应当**进常规OPEX框架**，被管理层解释清楚、被投资者当作常态成本评估。  
把它叫"特别/一次性/非经常性"＝**语言化妆术**——目的是让你别把它视为"这家公司日常烧钱结构的一部分"。

### 2.2 机制后果（这才是芒格生气的地方）

- 管理层用"调整后EPS/Non-GAAP"把"特别费"摘出去 → 市场也乐意配合（因为涨更舒服）  
- 结果：  
  - **股东被训练只看"调整后"**，真实成本结构能见度下降  
  - **管理层自评KPI也漂移**：不是"我把单位经济做好了"，而是"我把adj数字做出来了"  
- 这跟造假不是同一罪名，但**走在同一条滑坡上**——差别只是坡度。

### 2.3 芒格的逆向（你该怎么要求账本）

- 任何"非经常性"必须**真·非经常性**（并购一次性、灾害一次性、法律和解一次性）  
- 年年出现＝**永久成本**，写进你的DCF/利润率基准里，不当橡皮  
- 芒格对EBITDA的著名态度也落这儿（相邻段）：**看到EBITDA当核心指标时要警惕**——它刚好把"折旧/摊销/资本维持开销"这坨最硬的现实藏起来，适合"把旧设备锈在院子里还装盈利"的故事。

## 3) 对股票期权（作为管理层薪酬）的批评：不是"反激励"，是反"造假式成本隐藏"

> 注：在即席谈话的编排里，"对股票期权的批评"常与"对企业管理层的批评"紧邻/同簇，因为期权是**薪酬—报表—治理三角的中心**。

### 3.1 核心指控（书中三层）

#### A. 期权往往不激励该激励的人，却稀释该珍惜的人（股东）

- 给六十几岁亲手创办公司的CEO**大量期权**来"刺激忠诚"＝精神错乱：Mayo Clinic医生、Cravath律师六十多岁会因为期权更拼命吗？不会。  
- 结果：期权体系可能让**什么事都没做的人暴富**，而真正该拿很多的人（长期建设者/关键骨干）反而没拿到对称回报。

#### B. 会计准则纵容"期权无成本论"＝文明的错误工程

- 芒格暴怒点：  
  **期权明明会稀释股权、明明有经济成本，却长期被允许不计入成本** → 等于给管理层送"看不见的工资"，同时让报表EPS更好看。  
- 他骂到参议员层面：那些投票支持"不计入成本"的人**知道是错的还做**→"愚蠢而可耻"。  
- 原话风味：*"我宁愿在妓院弹钢琴谋生，也不愿靠这种期权会计来赚钱。"*

#### C. 估值/模型滥用：布莱克–舒尔斯的边界被故意无视

- BS模型对**短期、市场可交易**期权相对有效（≈"一无所知系统"，只靠价格/波动率输入）。  
- 但公司发的**长期员工期权**根本不满足那些假设；用BS去装"精确估值"＝**用精密仪器给泥巴称重**。  
- 芒格举例：好市多不同行权价期权，BS给出"60的执行价期权价值更高"那种荒谬结论 → 说明模型被当神学，不当事实工具。

### 3.2 伯克希尔的反事实

- **除非收购标的原来就有期权计划**，否则伯克希尔不用。  
- 薪酬偏好：**直接持股/现金奖金/长期股东利益绑定**，不靠"不计入成本的期权烟雾"。

### 3.3 可迁移原则（给公司/投资者）

| 你该要求的透明度 | 为什么 |
|---|---|
| 期权费用化（计入GAAP成本） | 不然你永远不知道真实薪酬吃多少EPS |
| 完全稀释股数情景 | 看最坏稀释，不只看"基本EPS" |
| 期权与业绩挂钩的real clawback | 不劳而获的 upside 必须能被追回 |
| 不与股价脱钩＝噪音激励 | 真正该激励的是长期经济价值，不是Beta |

## 4) 公司治理：董事会橡皮图章与"补偿顾问产业"（芒格暗线很硬）

虽然他不一定用小标题写"董事会改革方案"，但话锋扫到：

- **董事会常见失效模式**：不是天天吵架，而是**不反对任何事，直到公开羞辱逼他们动**（芒格版本≈"不反对短于斧头谋杀"的讽刺）。  
- 补偿委员会请外部顾问 → 顾问拿基准数据 → 基准被高薪CEO市场拱高 → 顾问说"要 competitive" → 董事会点头 → 循环通胀。  
- 所谓"热心改革者"有时也乱咬（例如他呛过对沃伦在可口可乐董事席位那种外行攻击），意思是：  
  **真治理改革=把激励/透明/诚实修对；不是摆姿态、搞政治。**

---

## 5) 衍生金融工具/复杂金融工程：芒格对"报表复杂度=风险隐藏"的延伸火力

同板块/紧邻段落里，芒格把"管理层+会计+风控叙事"延伸到更复杂的机构：

- 衍生品＝**不负责任的系统**：太复杂 → 没人真懂账目 → 会计规则妥协 → 捏造利润感 → 抵押条款（margin/credit downgrade triggers）制造**自放大崩塌**。  
- 他的最冷一句：测管理层道德/智力，问*"你真懂你衍生品账吗？"*  
  答"懂"＝**要么疯了要么说谎**（因为系统层面就不可能"真懂"到市场压力测试级）。  
- 通用再保险衍生品清算的亲身教训：账面价格≠可变现价格；**想卖时钱不在**。

> 把这层放回"对企业管理层的批评"就是：  
> **管理层用"太复杂"当护身符，用会计当画笔，把风险藏在 footnote 里——这不是高级金融，是工程安全裕度被卖掉换当期数字。**

## A. 芒格式的"公司治理三问"（比章程好用）

1. **钱的轨迹透明吗？** 期权成本/特别费/一次性/表外/衍生抵押条款——你能用三句话说清"股东的真实经济稀释去哪了"吗？  
2. **CEO的KPI绑定什么？** 长期每股内在价值/现金流，还是 adj-EPS/股价短期？  
3. **董事会敢说不吗？** 不是对战略说不，是对"薪酬/会计弹性/风险结构"说不——在不丢脸时也敢叫停。

## B. 投资者快速避雷针（对应本节精神）

- 年年"特别费"＝常态成本伪装 → 下调 margin 质量  
- 期权大量发行 + 不费用化 → 报表EPS虚高，真实成本延后爆  
- 复杂衍生品/复杂表外 + 管理层大谈"风险管理先进" → 更该紧张  
- 增长漂亮 + 应收/存货/资本支出异常 → 先假设"做账"再看  
- 谢皮科效应环境（同业都这么干）→ 你最需要的不是信，是**疑**

## C. 企业经营者自查（不想变成芒格嘲讽对象）

- 把"特别费"当管理工具→立刻改名、重分类、讲人话  
- 期权当免费薪酬→至少费用化、完全稀释情景公开、clawback写死  
- 别让补偿顾问竞赛把你变成"市场基准的奴隶"  
- 一句话：**让账本经得起"葡萄干大便"测试——别让报表成为你的公关部。**

---

> **封底一句**：  
> 芒格对管理层的批评，骨子里不是"更严监管"的呼吁，而是**富兰克林式个人/机构品格宣言**——你要么把账当契约，要么把账当画笔；前者能活几十年，后者可能在你最需要时（融资/下行/信任危机）突然发现"钱不在"。
