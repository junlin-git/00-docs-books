## 0. 这一讲的"总攻方向"——一句话说清芒格在干什么

> **芒格走上台，面对一群全美最体面的慈善基金会CFO，开口做的事是：把"慈善基金投资业"这台看似专业、体面、流程完善的高成本机器拆开，指出里面大部分齿轮的存在不是为了投资回报，而是为了养活一个"捞灰金"的中介生态——然后给出一条极简出路。**

这不是一篇"教你优化配置"的演讲，是一份**行业起诉书**，用礼貌但毫不留情的芒格式幽默写的。

---

## 1. 现状诊断：大型慈善基金"常规做法"长什么样

### 1.1 标准配方（几乎所有人都这么做）

| 步骤 | 具体操作 | 表面理由 |
|------|---------|---------|
| **① 不借债** | 基金会依法/传统上不用杠杆 | "保守"（芒格不反对这条） |
| **② 投可流通美国证券为主** | 主要是股票，少量债券 | 流动性好、可计量、符合 fiduciary 规范 |
| **③ 聘请众多投资顾问/多家顾问公司** | 层层外包：基金会 → 主顾问 → 各子类顾问 | "多元化专长""最佳大脑都用上" |
| **④ 追分散化** | 撒到几百只证券、多种资产类别、越来越多"另类" | "降波动 = 降风险" |

### 1.2 芒格揭示的"暗线食物链"

那条看似专业的顾问链，实际上是**一条反向抽水管**：

基金会（最终出资人/受益人）
↓ 管理费 / 顾问费
主顾问公司
↓ 又把选择甩给第三级
投行证券分析专家 + 基金经理
↓ 收入来源双通道：
(1) 证券买家产生的手续费 + 交易价差

    基金经理收取的回扣（"软钱"）
    (2) 某些公司为答谢投行推荐其证券而缴的服务费

> **芒格的定性**：这不是"投资流程"，这是**捞灰金（skimming）的结构化系统**——每个人都从基金会的资产池里舀一勺，合法、合规、尽调文件齐全，但**期望值对基金会是负的**。

## 2. 三大病因：为什么"专业模式"跑不赢大盘

芒格把基金会平庸回报的根源归结为三类互锁的病，不是"运气不好"：

### 病因一：摩擦成本吃掉一切（The Skim / 捞灰金效应）

**公式（芒格给出精神，非死板数字）**：

实际资产增长率 ≈
股票指数化可得的年均实际回报
− 投资产生的成本率（管理费+顾问费+交易费+软钱暗费）
− 捐赠支出率

- 很多大型基金每年总成本（explicit + implicit）轻松超过 **1%~2%**
- 在7%–10%的名义回报环境里，**1.5%的隐性税≈吃掉15%–20%的长期复利**
- 而且越"专业""多元""多层顾问"，成本越高——**流程与回报成反比**

> 芒格补刀：有些基金会追随耶鲁模式搞"基金中的基金"，走向了**伯尼·康菲尔德式**的结构。康菲尔德是谁？——1960年代臭名昭著的"基金中的基金"推销贩子，用层层收费把投资者榨干后入狱。芒格说：**"很少有人能预料到，在康菲尔德锒铛入狱之后很久，一些主流大学仍然用康菲尔德式的方法管理慈善基金会。"**

这就是全书最刺的一句：**你把慈善的钱交给了"合法版的康菲尔德机器"。**

---

### 病因二：过度自信（Overconfidence）/ "专业态度的讽刺"

> **"90%的司机认为自己的驾驶技术在平均水平以上"——瑞典的严密调查。那些投资顾问们的乐观自信，会让这些瑞典司机相形见绌。**

芒格的论点：

| 现象 | 机制 |
|------|------|
| 顾问/投资委员会觉得"我们能打败大盘" | 自我归因偏差 + 社会认同（"别人也请顾问，所以这就对"） |
| "极其仔细的过程"反而有害 | **极其仔细的过程 → 大量细节信息 → 产生"我懂很多"的错觉 → 过度自信 → 敢上难度高的航程** |
| 长期资本管理公司（LTCM）1998年刚爆 | LTCM以为自己有超人方法和模型 → 选了困难航程（高杠杆+脆弱假设）→ 崩了 |
| 数学装饰 ≠ 智慧 | 复杂模型给你"科学感"，但不消除"你不知道你不知道" |

> **"过度自信"是芒格式反向思考的经典靶点：你不需要更聪明，你需要少信自己的聪明。**

---

### 病因三：盲目分散化（Diversification as Dogma）

正统教条：**分散 = 安全** → 于是基金持有一大篮子股票，其中大部分它谈不上真正理解。

芒格的反论：

| 正统说法 | 芒格反驳 |
|----------|---------|
| 分散降低风险 | **分散降的是波动率，但不降"平庸"——你买一堆半懂不懂的东西，等于买了一篮子平均，然后被成本再砍一刀** |
| 集中=危险 | 如果你**理性**地判断出几个低成本、长期优质的选择，集中反而**降**真正风险（永久损失的概率），因为你的判断质量↑、交易成本↓ |
| 基金会"必须"分散 | 如果创始人的原始股票（比如创始家族的企业）从来没卖，回报往往吊打后来的"专业化分散" |

> **核心洞见**：许多基金会用"分散"来掩盖一个事实——**它们不知道该把信心放在哪里，所以用统计学代替判断力。** 而芒格始终认为：在投资里，**好的判断比好的统计分布值钱得多。**

## 3. 三种"现代选择"——芒格开出的药方

芒格说，基金会想改善业绩，至少有三种路径可选（注意措辞：他**推荐第2种为核心**，第1种为底线，第3种是"可以但有严格限"）：

---

### 选择一：【底线方案】解雇顾问 → 指数化

> 对那些每年管理成本超过总资产 **1%** 的基金来说，这是最清醒的一步。

- 砍掉昂贵的投顾链
- 转为低成本指数化（S&P 500或全市场）
- 把成本压下去
- 承认：**"打败大盘"的企图本身，就是成本之源**

芒格的潜台词：连这第一步都做不到的基金会，就不该自称在管钱——它是在管一场慈善性质的**成本秀**。

---

### 选择二：（芒格推荐的）效仿伯克希尔——集中、低换手、极低成本的"拥有者"模式

这是全讲的**心脏处方**：

| 要素 | 内容 |
|------|------|
| **持股哲学** | 长期持有**少数几家**你真正理解、备受敬仰的国内（美国）优秀企业 |
| **交易频率** | 不过多交易——目标是"买了就别老折腾" |
| **成本目标** | 把年均管理成本压到资产总额的 **0.1%** 量级（不是1%+） |
| **外部建议** | 可以采纳外部信息，但**决策权在自己**，不外包给收费中介 |
| **不杠杆** | 零负债（基金会本来就传统上不借，芒格强调保持） |
| **不碰复杂衍生品** | 远离他说的"奇异交易策略" |

对应逻辑链：

降成本(0.1%) → 减少交易 → 少决策 → 只投真懂的少数好企业
→ 让企业本身的ROIC和时间替你滚
→ 复合回报 > 指数 + 还不被中介抽成

> "如果有基金会把大量资本集中投给它仰慕甚至**热爱**的企业，不失为一种好投资方式。"——这句话把"冷冰冰的配置"变成"所有者自豪感"，但前提始终是**判断质量**，不是情怀。

---

### 选择三：【有限额度】另类投资——但严守"非杠杆 + 有限责任"

芒格承认基金会可以拿出**一部分**资金做：
- 初创高科技公司的**非杠杆式**股权投资（天使/VC式）
- 杠杆收购的**有限责任**参与（注意：是别人用杠杆，你以LP身份参与，自己不加杠杆）
- 各种相对价值/套利类策略

但他立刻划红线：

| 红线 | 理由 |
|------|------|
| **绝对不杠杆（基金会自身不加杠杆）** | 流通股 + 杠杆 = 大环境一差 → 灾难性追加保证金式死亡（LTCM活教材） |
| **竞争过度激烈** | 越来越多聪明钱挤进"套利缝隙"，alpha被费用+竞争吃掉 |
| 芒格（家族）基金会**不采取**第三种 | 他自己以身作则：不碰复杂衍生品、不做奇异策略 |

## 4. "捞灰金"概念的正式出场——芒格对金融中介生态的终极命名

> 这是全讲的理论高点：**Skim（撇脂/抽成）** 披着**合规专业主义**的外衣。

| 层 | 表现 |
|----|------|
| **软钱（soft dollars）** | 基金/顾问通过路由交易给特定券商换取"研究服务"——本质是客户付的隐性佣金 |
| **基金中的基金（FoF）** | 你付一层费用给FoF经理，FoF再投别的基金，那些基金再收自己的费用——**三层抽成，零额外alpha保证** |
| **"极其仔细的尽职调查"产业** | 流程越长、报告越厚、顾问越多 → 越像"科学化的捞灰金"，越难有人站出来说停 |
| **薪酬顾问/对标游戏** | 董事薪酬委员会用顾问数据把CEO和自己薪酬都推高——利益共同体，谁砍谁？ |

芒格不骂"贪婪"（那是废话），他骂的是：**整个行业把财富转移（从受益人/捐赠使命→中介链）包装成" fiduciary best practice "。** 这才是"捞灰金"——不是偷，是**合法的结构性撇取**。

## 5. 其他关键子题

### 5.1 海外投资

- 芒格称伯克希尔**几乎不直接进行海外投资**
- 理由：**许多国家股东权益保障不足**——这是投资的硬约束，不应低估
- 同时嘲讽：现在很多基金会海外敞口很大，但未必真理解当地的法治/产权现实

### 5.2 为什么基金会不改（人性 + 制度惯性）

芒格点到两个深层阻力：

| 阻力 | 解码 |
|------|------|
| **"太简单，显得你们没价值"** | 降成本+集中持股+自己做判断 → 裁掉一半顾问/委员会 → **CFO/顾问的存在感危机** |
| **社会认同/别人都这么做** | 生物偏好固定活动模式以省精力；偏离"行业标准 portfolio"→ 万一输，你没法躲进"大家都一样"的安全毯 |
| **过度自信 + 流程迷信** | "我们请了最好的顾问、做了最仔细的分析"——这句越经常被说，越危险 |

> 所以他演讲的听众虽然是CFO，但他真正在敲的是**董事会/捐赠人/创始家族**：你们的"专业团队"可能是世界上最体面的价值毁灭机器。

## 6. 演讲收束：终极建议（四句硬话）

浓缩芒格给出的终点规则（不同版本措辞略异，精神一致）：

① 极致降成本：把投资成本压到 ≤ 0.1% / 年（砍顾问、砍交易、砍FoF）
② 只投极少数能彻底看懂的顶级企业：合理价买入 → 长期持有（近乎永持）
③ 绝对不杠杆 / 绝对不碰看不懂的复杂衍生品 / 坚守能力圈
④ 自建决策能力：用自己的头脑 + 自己的委员会，
不把命运交给和你利益不完全一致的中介链

> 最后一句的芒格式结语精神：  
> **"你们不愿意这么做，不是因为它不对——而是因为它太简单了，显得你们这些专业管理人没有存在必要。但投资的真相就是：越简单越有效。"**

## 8. 可迁移的行动清单（不只给基金会——给任何管钱的人）

1. **算真实成本**：管理费 + 交易费 + 隐性软钱 + 税费 + FoF夹层费 = ？如果 >1%，你的基准线已经输了——先砍成本再谈 alpha
2. **数你"真懂"的持仓有几只**：>15只且你讲不清每只的护城河 → 你持的是"分散化借口"，不是投资组合
3. **画中介链**：基金会/你 → 谁拿钱？几层？每层加了什么判断力，还是只加了报告和会议？——链越长，越可疑
4. **问"杠杆问题"**：谁在用什么在赌？你自己的净杠杆 >0 吗？流通股+杠杆=爆仓结构，跟"专业"无关
5. **反向测试**：如果你明天被剥夺"顾问团队/精美报告"，只剩自己读财报做决定——你的持仓会变吗？如果会，说明你依赖的是**他人权威**而非**自己判断**。

## 9. 一句话封底

> **"一流慈善基金的投资实践"本质上是一篇用礼貌话写的炸弹——它把"现代基金会投资业"还原成一个捞灰金的食物链，然后用四个字推翻整个学科：成本、集中、持有、别杠杆。芒格的愤怒不在语气里（他很温和），在命题里：你们拿公益的钱养了一套合法的中介抽水机，而解药简单到让所有获利者恨它——因为那解药让他们失业。**
