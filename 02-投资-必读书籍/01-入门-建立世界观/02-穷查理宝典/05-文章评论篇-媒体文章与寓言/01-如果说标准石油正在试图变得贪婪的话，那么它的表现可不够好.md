# 第五章-如果说标准石油正在试图变得贪婪的话，那么它的表现可不够好——向那些优秀的工程师致敬
> **《穷查理宝典》第五章·文章、报道与评论——第一篇**
> **署名**：查理·芒格（Charlie T. Munger）
> **发表**：《洛杉矶时报》（Los Angeles Times），**1978年10月1日**
> **背景**：1970年代石油危机后期，加州标准石油（Standard Oil of California，今雪佛龙前身）与"大石油"被公众和政界猛烈抨击为**贪婪的垄断奸商**，芒格以股东+消费者+律师曾任对手+公民的复合身份撰文反驳。

---

## 0. 这篇文章到底在做什么——一句话定位

> 这不是一篇"石油行业分析报告"，而是一篇**关于标签暴力、数据诚实与制度判断的范文**：芒格用一本年报+一把计算器，把"垄断=必然贪婪"的流行叙事拆成碎片，然后告诉你——**真正的危险企业不是利润数字不好看的那家，而是"运转糟糕"却被允许继续糟下去的那家。**

---

## 1. 开篇：芒格的入场凭证（为什么他有权说话）

### 个人 stake（不是空谈）

> **"许多年前，我母亲送给我妻子300美元当作新婚礼物。我妻子用这笔钱投资了标准石油的股票。所以我经常阅读标准石油的年报——不过我的阅读从来没有促使我买进更多标准石油的股票。"**

| 身份 | 芒格在这件事里的角色 |
|------|---------------------|
| **股东**（妻子名义持有）→ 长期读年报 | 他不是旁观者，是被绑定的利益相关方 |
| **消费者**（加州居住30年，去其加油站） | 产品体验可验证 |
| **前代理律师**（年轻时代表利益方与标石打过交道） | 见过其内部运作，知道它"傲慢/官僚"的另一面 |
| **公民**（工程师文化、危险资产应由谁管？） | 宏观判断的落脚点 |

**关键句**："我的保留态度是有原因的"——他先交代自己**不追加投资**（即他不认为它是"暴利机器"），再把这作为 credibility 的底座：**我不是在为持仓辩护，我是在为事实辩护。**

## 2. 核心命题：如果它想贪婪，它表现得糟透了（数据拆弹）

### 2.1 总回报视角：股东的实际购买力在缩水

| 指标 | 1965 → 1978 |
|------|------------|
| 平均**股价**涨幅 | **+22%** |
| 同期**消费者价格指数（CPI）**涨幅 | **≈ +102%** |
| 股息（红利） | $1.03/股 → $2.55/股（递增） |
| 红利年增速 vs 通胀 | 红利增速仅**略高于**CPI约1个百分点 |
| 红利增速 vs **同期平均工资增速** | **远低于**工资增速 |
| 税后实际回报（含资本价值+红利，扣40%税） | **按1965年购买力算，年均损失＞2%** |

> **芒格的结论**：一个1965年底买入并持有到1978年的股东——**名义上看赚了，通胀+所得税一扣，购买力实实在在缩水**。  
> 如果这就是"贪婪的垄断企业榨取暴利"——它的表现确实**很糟糕**。

💡 **芒格式提醒（多数人忽略的）**：  
大众骂"油价涨=石油公司赚翻"；芒格让你看的是**股东端实际回报**——油价上涨的收益很多被**通胀成本（勘探/钻井/炼化/设备全部变贵）+ 税收 + 海外资产被迫贱卖**吃掉，终端股东并没有躺赢。

---

### 2.2 资产回报率的"内外撕裂"——真正理解利润结构

#### 1968–1972（欧佩克尚未暴涨前）

| 板块 | 数据 | 芒格解读 |
|------|------|---------|
| 美国国内业务净资产年均回报率 | **极低**（到1973年也才**6%**） | 低于正常行业标准——谈不上"超额垄断利润" |
| 海外资产（东半球/沙特等）回报率 | **＞30%**（1973年：$5.29亿盈利 / $16亿投资） | 极高，但这是**风险勘探**的结果，不是"在国内压榨消费者" |
| **全球合并净资产年均回报率** | **≈ 10%** | "对于一家健康的公司而言，偏低的数字" |

#### 1972年后（欧佩克提价＞400%，局势剧变）

| 变化 | 效果 |
|------|------|
| 欧佩克大幅提价 → 美国本土油田利润**被动上升**（油价贵了，国内产油也受益） | 标石的**美国**净资产回报率 → 1977年达**10%**（从6%上来） |
| 但：标石**被迫将海外资产大部分以低价卖给当地政府**（资源国有化/征收浪潮） | 海外盈利**大幅下降**（虽ROE仍19%） |
| **全球加权平均ROE** | **14%**（1977）——比1968-72的10%只多了**4个百分点** |

> **芒格的致命反问**：
> "作为消费者，我应该为标准石油的利润比过去**多了一点**而生气吗？或者我应该为其美国净资产回报率从前只有**6%**现在升到**10%**而生气吗？**我想是不应该的。**"
>
> "标准石油公司在美国的盈利是**低于正常标准**的，但这种情况被它生产和销售大量便宜的阿拉伯石油赚取的高额利润所**掩盖**，所以它经常被指责为牟取暴利的奸商。"

🎯 这句话是整篇文的**轴**——他拆穿了大众的因果幻觉：
- 高**合并**利润 ≠ 在美国本土压榨消费者
- 海外高回报来自**早年冒险勘探发现低成本油藏**，而后又被政治力量夺走
- 公众骂的是"国内加油站价格"，但真正的利润引擎在别处、且正在消亡

## 3. 品格证据：为什么芒格"信任它"胜过其他大企业

### 3.1 消费者侧（可验证的接触面）

| 观察 | 时长 |
|------|------|
| 产品从未给他制造过麻烦 | 30年在加州 |
| 全资加油站服务：**迅捷、公平** | 反复亲自体验 |
| **从未听说标准石油有什么大丑闻** | 30年——对一家这种规模的企业，这本身是非凡的"无事故记录" |

### 3.2 组织与文化侧

| 维度 | 芒格评价 |
|------|---------|
| **高层出身** | 高层管理人多是**工程师出身**——"该公司在工程方面的成就出色"，而油井/炼油厂/输油管/储油罐是"必需但复杂而危险的资产"→ 他**希望交给这样的人控制** |
| **用人政策** | 任人唯才、按能力提拔、**极少随意解雇**；即便解雇也给经济补偿 |
| **治理结构（委托书线索）** | 妻子定期收到**股东委托书**（proxy statement）——管理人员征求股东投票的书面文件→ 表明董事对**股东/员工/消费者**都负责任 |
| **高管薪酬** | 薪水和补贴比同等规模企业**相当低**→ 不是"肥猫"画像 |
| 年轻时当律师跟它打交道的印象 | "很傲慢，有点官僚主义——可能为了内部控制和避免丑闻，它**不得不**这样，但**作风很正派，方方面面都很理性**" |

> 这一串不是"好人奖状"，是**风险评估**：  
> 当你需要把危险工业资产交给某公司托管时，"傲慢但正派+工程纪律+无丑闻"远比"讨喜但财务花哨"值钱。

## 4. 政策主张：芒格的"反直觉"结论——应该让油价更高，让标石赚更多

### 4.1 逻辑链（一步步推）

石油行业 = 资本密集型 + 国内资源渐枯竭
→ 未来需要更大规模 R&D + 勘探开发投资
→ 如果不让价格稍微提高 → 再投资资金不足
→ 长期供应能力↓ → 消费者最终承受更大损失

> **"我个人提倡把油价提得更高，让标准石油公司赚更多的钱，因为我相信这将会拉高再投资的资金，从而让消费者受益。当消费者的活力需要供应商的活力来支持时，适当地提高价格当然是对消费者有利的。"**

### 4.2 为什么消费者"无需担心股东中饱私囊"

- 他妻子的投资史已证明：股东实际购买力在降
- 治理结构（低高管薪、委托书问责、工程师文化）表明**不是榨取型组织**
- 所以"涨价→钱去哪"的恐惧，在标石这个case里不成立

### 4.3 反对"因规模大而拆分"

> 芒格暗示：治理的核心应是整治那些**明显腐败**的机构，而不是把管理规范、理性运营、无丑闻的巨型企业按"大=坏"公式拆碎——拆分可能破坏规模效率、提高成本、削弱长期再投资能力。

---

## 5. 收束金句（全篇的封底逻辑）

> **"运转良好的东西，如果得到鼓励和支持，通常能够表现得更好；与之相反，运转糟糕的东西往往是无法被改正的，或者能够被改正，但其难度比你们可能想到的要难十倍。"**

这是芒格的核心制度哲学一句话版：
- **识别哪个阵营**企业/机构在哪个阵营
- 对运转良好的：别用标签谋杀它
- 对运转糟糕的：别幻想廉价改革——难度×10

## 7. 可迁移的思维清单（你从这篇能拿走什么——无论是否碰石油）

1. **别用标签替你思考**："垄断""大公司""石油"都是情绪词，不是分析。芒格的做法永远是——**打开年报，看ROE、看分部、看现金流、看通胀调整后股东实际所得**。
2. **合并数字会骗你**：标石全球利润"看起来大"，但一拆成"美国国内 vs 海外"，真相完全不同。**凡有跨国/多业务的企业，都该要求分部ROE，不能吞枣看净利。**
3. **通胀是利润的静默税**：股价+22%听起来涨了，CPI+102%告诉你"涨了个寂寞"——这是芒格教你永远把名义→实际（购买力）换算的习惯。
4. **品格是可操作的风险变量**：30年无丑闻 + 工程师内控文化 + 低高管薪 + 负责任委托书 ≠ 保证，但它是**系统性降低"管理人把你卖了你还数钱"概率**的硬证据。
5. **"运转良好的"经济学**：提高价格≠贪婪，如果该价格信号驱动的是再投资×长期供给安全×更低崩溃风险——芒格把"道德"翻译成"系统稳定性"来判断。

## 8. 一句话封底

> 这篇东西表面在替一家石油公司出头，骨子里在做三件事：**①教你把愤怒从标签移回数据；②教你用分部视角拆开合并幻象；③教你区分"看起来坏（大/油价涨）"和"实际上是坏（腐败/榨取/不可持续）"**——而这三点，在任何行业、任何时代，都是理性公民的生存技能。
