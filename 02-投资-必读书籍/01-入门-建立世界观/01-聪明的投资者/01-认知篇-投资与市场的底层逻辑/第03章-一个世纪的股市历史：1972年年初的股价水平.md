## 一、开篇：两次对话，一个追问（总起·时代的镜像）

### 场景一：1972年初，纽约

一位华尔街资深投资顾问坐在办公室里，盯着道琼斯指数首次突破1000点的报价屏幕。他翻开格雷厄姆刚刚修订的《聪明的投资者》第四版，喃喃自语：

> “道指已经接近1000点了，市盈率快18倍了。格老说债券利率7%，股票盈利收益率才5.5%，债券比股票更有吸引力。但我周围的每一个人都在买股票——他们说‘股票永远是最好的投资’。我该听谁的？”

### 场景二：2026年初，上海

一位A股投资者在复盘自己的账户。2024年“924行情”之后，他的沪深300ETF已经从底部反弹了30%。他打开手机，看到了最新的数据：沪深300 PE约13~14倍，股息率近3%，10年期国债收益率仅1.7%。他想起了一位老股民的话：

> “A股PE低于10倍就是送钱，高于20倍就是送命。现在13倍，不高不低，我该怎么办？”

💡 **本章终极追问**：相隔54年、相隔太平洋的两国投资者，面对的是同一个困惑——“现在的股价水平究竟是过高、过低，还是大致合理？”

格雷厄姆在1972年给出的回答，同样适用于2026年的A股：

> **“不依赖预测，而是基于历史数据所揭示的规律和估值中枢，对当前市场水平做出理性判断。”**


## 二、为什么要学习百年前的股市历史？（第一层·方法论的意义）

### 2.1 格雷厄姆的深刻洞见：历史不是包袱，是坐标系

格雷厄姆在开篇就点明了研究历史的根本目的：

> “投资者应当具备一些股票市场的历史知识，特别是有关其价格的重大波动，以及股价整体水平与股票利润和股息的各种关系的知识。在此基础上，就能够对不同时期股价水平的吸引力和危险性得出某种有价值的判断。”

他的意图非常明确：
- ❌ **不是**为了让投资者去预测“下个月道指是涨是跌”
- ❌ **不是**为了找出一个“稳赚不赔的公式”
- ✅ **而是**为了建立一个衡量市场贵贱的坐标参照系

打个比方：如果你不知道北京冬天的平均气温是-5℃到5℃，当某天气温降到-10℃时，你就不会知道该穿羽绒服。同样，如果你不知道A股的PE中枢是12~14倍，当PE跌到10倍时，你就不会知道这是“打折促销”而非“世界末日”。

## 三、百年美股的历史规律（1871-1971）—— 格雷厄姆的数据基石（第二层·历史实证）

### 3.1 研究方法的严谨性：一个世纪的数据库

格雷厄姆团队并非依赖零散的市场回忆，而是系统性地构建了一个跨越整整100年的数据库。他们追踪的核心指标包括：

| 追踪指标 | 含义 | 为什么重要 |
| :--- | :--- | :--- |
| 年末股价指数 | 反映长期价格趋势 | 衡量市场长期走向 |
| 年度每股利润（EPS） | 企业真实的赚钱能力 | 判断基本面的好坏 |
| 年度每股股息 | 股东实际获得的现金回报 | 防御型投资者的“定心丸” |
| 市盈率（PE） | 价格与利润的比值 | **衡量贵贱的核心标尺** |
| 股息率 | 股息与价格的比值 | 衡量现金回报率 |
| 每股账面价值 | 净资产的积累 | 衡量清算价值底线 |

这100年包含了9个完整的十年周期，其中：
- 只有**2个十年**出现了利润和平均价格的同时下降
- 1900年之后，**没有任何一个十年**的平均股息出现下降

🧠 **这一发现的深远意义**：即使经历了1929年大崩盘、两次世界大战和大萧条，美国企业整体的利润和股息支付能力在长期中依然保持了向上的韧性。**股市长期是向上的，但过程极不平坦。**

### 3.2 第一个视角：股价走势——上涨但极不平坦

**总体涨幅**：
从1871年到1971年，股价指数从约4点上涨至约100点，100年上涨约**25倍**，年化复合增长率约**3.2%~3.5%**。这恰好与同期美国名义GDP的长期增速大致吻合，印证了“股市长期是称重机”的论断。

**过程的极度曲折性（这是重点）** ：

格雷厄姆特别强调，这种上涨绝不是一条平滑的45度斜线。市场经历了多轮 **“暴涨—崩溃—长期横盘”** 的残酷交替：

| 周期阶段 | 时间跨度 | 市场表现 | 投资者的真实体验 |
| :--- | :--- | :--- | :--- |
| 漫长横盘 | 1900–1921年 | 长达21年，股价几乎没有净涨幅 | 整整一代人失去对股票的信心，认为“股票是赌博” |
| 咆哮牛市 | 1921–1929年 | 股价飙升约4倍，全民炒股 | 狂热、杠杆、认为“新时代”永远持续 |
| 大崩盘与恢复 | 1929–1949年 | 暴跌89%，直到1949年才彻底突破1929年高点 | **整整等了20年！** 绝望、怀疑、远离股市 |
| 战后长牛 | 1949–1968年 | 股价上涨约5倍 | 重新燃起信心，但1968年后再度陷入震荡 |

🧠 **格雷厄姆的深刻观察**：

> “1924年至1949年，股票指数年均上涨率仅为1.5%。这25年间，公众对股票毫无兴趣。”

这一数据揭示了一个**反直觉的真相**：
- 当市场最令人**兴奋**的时候（牛市顶峰），往往是**风险最大**的时候
- 当市场最令人**绝望**的时候（长期横盘或暴跌），反而**孕育着最大的机会**

📌 **A股映射**：这与A股“牛短熊长”的特征惊人地一致。2007年6124点最兴奋的时候，恰恰是最危险的时候；2014年2000点以下最绝望的时候，恰恰是最具投资价值的时候。

### 3.3 第二个视角：利润与股息——增长但剧烈波动

**每股利润的长期增长**：
标普500指数成分股的每股利润，从1871年的约0.4美元增长至1971年的约6美元，100年增长15倍，年化增长率约**2.5%~3.0%**。

**利润增长的剧烈波动性（格老特别警示）** ：

格雷厄姆提醒读者，“平均”二字掩盖了巨大的波动：
- 在经济繁荣期，利润可能**同比暴涨30%~50%**
- 在经济萧条期（如1932年），利润可能**几乎归零，暴跌90%以上**
- 即使是温和的衰退，利润也可能**腰斩**

> “利润的年度数据并不可靠。投资者不能因为某一年利润暴涨而认为‘永远会更好’，也不能因为某一年利润暴跌而认为‘世界末日’。”

📌 **A股映射**：2007年A股利润暴涨时，PE仍然高达50倍以上（因为股价涨得更快）；2014年利润增速放缓时，PE反而跌到了10倍以下（因为股价跌得更多）。**利润的波动，加上股价的波动，就构成了A股巨大的估值钟摆。**

**股息的长期趋势**：
- 早期美国企业派息率极高，经常将利润的**70%以上**以现金形式分给股东
- 到1970年代，这一比例已下降至约**50%**
- 格雷厄姆对此持中性态度：股息不是唯一的回报来源（留存利润再投资同样创造价值），但股息是防御型投资者的“定心丸”

🧠 **格老原话**：

> “持续稳定的股息支付，使投资者更容易在市场低迷时保持持仓耐心。”

📌 **A股现状**：A股派息率长期仅30%~40%，但近年来“中特估”推动央企提高分红，沪深300股息率已从不足2%提升至约2.8%~3.3%，这是一个**历史性的结构变化**。

### 3.4 第三个视角：市盈率——本章最重要的核心发现

**什么是市盈率？为什么它如此重要？**

市盈率（PE）= 股价 / 每股利润。它回答的是：**投资者愿意为每一块钱的当期利润支付多少价格？**

| PE倍数 | 含义 | 投资属性 |
| :--- | :--- | :--- |
| PE = 10倍 | 以当前利润计算，10年收回成本 | 低估 |
| PE = 20倍 | 以当前利润计算，20年收回成本 | 偏贵 |
| PE = 50倍 | 以当前利润计算，50年收回成本 | 泡沫 |

格雷厄姆将市盈率视为衡量市场“贵贱”的**核心标尺**，因为它将价格与企业的基本面（盈利能力）直接挂钩，剔除了纯粹的情绪因素。

**百年市盈率的中枢与极端区间**：

| 区间分类 | 市盈率范围 | 出现的典型历史时刻 | 市场情绪 |
| :--- | :--- | :--- | :--- |
| ❄️ 极度低估 | 5~7倍 | 1920年、1932年（大萧条底部）、1942年（二战最困难）、1949年 | 绝望、无人问津 |
| 🌥️ 低估至合理 | 8~12倍 | 多数熊市底部区间 | 谨慎、怀疑 |
| ☀️ 长期中枢 | **14~15倍** | 历史平均水平 | 市场情绪平稳 |
| 🌤️ 偏高 | 18~20倍 | 1960年代中后期、1972年初 | 乐观蔓延 |
| 🔥 极度高估 | 25~30倍以上 | 1929年顶峰（部分超50倍）、1968年“漂亮50”泡沫 | 狂热、“新时代”叙事 |

🧠 **格雷厄姆划下的“警戒线”** ：

> “市盈率一旦超过20倍，就进入了危险区域。”

这并不是说20倍以上一定会立刻下跌，而是意味着**安全边际已经消失或极为稀薄**，未来长期回报率将显著下降。

**市盈率的两大核心规律**：

**规律一：均值回归的铁律**

市盈率不会永远停留在高位或低位。极高之后，往往伴随长期而痛苦的下跌；极低之后，往往开启长达数年的牛市。

> “股票市场的历史反复讲述着同一个故事：从低市盈率买入的投资者，最终获得了丰厚的回报；从高市盈率买入的投资者，往往承受了痛苦的损失。”

**规律二：估值是长期回报的最主要决定因素**

| 买入PE | 未来10年年化回报（假设利润年增5%） | 说明 |
| :--- | :--- | :--- |
| 7倍买入 | 约10%~12% | 低PE+利润增长=戴维斯双击 |
| 14倍买入 | 约5%~7% | 合理估值+利润增长=合理回报 |
| 25倍买入 | 约0%~2% | 高PE+估值收缩=戴维斯双杀 |

📌 **A股应用**：2014年中沪深300 PE低于9倍时买入，持有至2015年高点收益超150%。2021年初核心资产PE超60倍时买入，至今仍深度亏损。**同样的公司，不同的买入价格，天壤之别的结果。**


## 四、1972年初的市场诊断——格雷厄姆亲手示范如何用“温度计”（第三层·大师示范）

### 4.1 1971年底—1972年初的具体数据

在完成百年数据的统计分析后，格雷厄姆将目光聚焦于“当下”。1972年初的美国市场呈现出以下面貌：

| 指标 | 具体数据 | 与历史比较 |
| :--- | :--- | :--- |
| 道琼斯工业指数 | 约900点（首次短暂突破1000点） | 心理关口突破 |
| 标普500每股利润 | 约6美元 | 处于历史高位 |
| 市盈率（PE） | **约17~18倍** | 高于14~15倍历史中枢 |
| 股息率 | 约3% | 远低于历史早期5%+的水平 |
| 高等级债券利率 | **约7%~8%** | 历史高位 |

### 4.2 格雷厄姆的三重对比判断框架

**对比一：与历史中枢比较 → “偏高”**

17~18倍的PE，已经脱离了14~15倍的长期均值。市场已不再是“物美价廉”的状态，而是进入了**合理偏贵**的区间。

**对比二：与极端高点比较 → “尚未疯狂”**

虽然偏高，但尚未达到1929年（30倍以上）或1968年“漂亮50”局部泡沫（40~80倍）的疯狂程度。这意味着市场整体没有出现系统性泡沫，但**安全边际已经严重缩水**。

**对比三：与债券收益率比较 → “股票失去相对优势”（最致命的一击）**

格雷厄姆在1965年后的各版修订中，越来越重视这一对比。他的逻辑是：**股票本质上是一种“特殊债券”**——它的“票息”（利润/股息）不固定，但长期来看应该高于固定收益证券，以补偿其更高的波动风险。

| 对比项 | 1948年（黄金时期） | 1972年初（警示时期） |
| :--- | :--- | :--- |
| 股票盈利收益率（PE倒数） | 约20%+（PE约5倍） | 约5.5%（PE约18倍） |
| 高等级债券利率 | 约5% | 约7%~8% |
| **差值（股票优势）** | **+15个百分点**（大幅优势） | **-2个百分点**（债券反超） |

🧠 **格雷厄姆的结论掷地有声**：

> “股票的预期回报率已经低于债券的确定回报率。即使是优质股票，也不可能在任何条件下都优于债券。”

这意味着，从资产配置的角度看，**1972年初的理性选择应该是减少股票、增加债券**，而不是像牛市狂热者那样All-in股票。

📌 **这是2026年A股与1972年美股最本质的区别——我们将在第六部分详细展开。**

### 4.3 板块的结构性分化（“双轨制”）

格雷厄姆敏锐地注意到，整体估值掩盖了巨大的内部分化：

| 板块类型 | 估值特征 | 典型代表 | 安全边际 |
| :--- | :--- | :--- | :--- |
| 热门“漂亮50”成长股 | PE高达**40~80倍** | IBM、宝丽来、可口可乐 | 几乎为零 |
| 冷落的价值股 | PE仅为**10~15倍** | 银行、保险、传统制造业 | 存在但有限 |

📌 **A股映射**：这让人想起2021年初的A股——“茅指数”PE高达60~100倍，而银行、保险、建筑央企PE仅4~8倍。同样的“冰火两重天”，时隔50年，剧本如出一辙。


## 五、A股的历史镜像与规律（1990-2026）（第四层·本土化实证）

### 5.1 数据移植的方法论基础

将格雷厄姆的分析框架移植到A股，需要正视两个差异：

| 差异维度 | 美股（1871-1971） | A股（1990-2026） | 对分析的影响 |
| :--- | :--- | :--- | :--- |
| 数据周期 | 100年 | 约30年 | A股周期更短，规律需谨慎外推 |
| 对标指数 | 道琼斯/标普500 | 沪深300（2005年发布） | 沪深300代表蓝筹，对标标普500最合适 |

虽然A股数据周期只有30年，但这30年已覆盖**3~4个完整的牛熊周期**（2005-2007牛市、2008熊市、2009反弹、2010-2014熊市、2015牛市、2016-2018熊市、2019-2021牛市、2022-2024熊市），足以提炼出统计学上有意义的规律。

### 5.2 A股第一个视角：股价走势——波动幅度远超美股

**长期涨幅**：
- 上证指数从1990年的100点到2026年约3000~3500点，35年上涨约**30~35倍**
- 沪深300指数从2005年的1000点到2026年约3800~4200点，20年上涨约**3.5~4.5倍**（全收益指数回报更高）

**A股独有的“暴涨暴跌基因”** ：

A股的波动性在全球主要市场中名列前茅。以下是一份浓缩的A股“极端波动简史”：

| 时期 | 核心驱动力 | 指数表现 | 涨跌幅 | 持续时间 |

🧠 **A股的核心特征总结**：
- **牛短熊长**：顶部极度疯狂，底部极度绝望
- **波幅极大**：年化波动率约25%~30%，远超美股（约15%~18%）
- **周期压缩**：格雷厄姆所描述的“暴涨—崩溃—长期横盘”在中国以更极端、更压缩的时间周期呈现

### 5.3 A股第二个视角：利润与股息——高增长伴随高波动

**利润的长期增长**：
沪深300成分股的总利润从2005年的约3000亿元增长至2023年的约4万亿元，年化增长率约**14%~15%**（名义值）。

这一增长率**远高于**美股的长期增长率（2.5%~3%），主要反映了中国经济在过去20年的高速增长（名义GDP年化增速约10%~12%）。

**利润的强周期性（A股的关键特征）** ：

A股利润的波动比美股更加剧烈，原因在于：
1. **强周期行业权重高**：金融、地产、能源、材料等周期行业在沪深300中占比过高，导致整体利润随宏观周期剧烈摆动
2. **政策干预频繁**：从“4万亿”到“供给侧改革”，从“去杠杆”到“疫情纾困”，政策周期的切换直接映射为企业利润的剧烈波动

**具体案例**：
- 2008年金融危机：利润腰斩
- 2015~2016年：供给侧改革导致上游利润暴增、下游利润承压
- 2021年之后：地产链利润出现断崖式下跌

**股息率的长期变化**：
A股历史上的派息率（股息/利润）偏低，长期在**30%~40%**之间徘徊，远低于格雷厄姆时代美国企业70%+的水平。

但近年来出现了两个积极变化：
1. “中特估”推动央企国企提高分红比例
2. 市场风格转向追求确定性，高股息策略受到追捧

**沪深300股息率已从过去长期不足2%，提升至2024~2026年的约2.8%~3.3%**，这是一个历史性的结构变化。

📌 **重要结论**：高股息策略在中国正在从“小众防御”走向“主流配置”。

### 5.4 A股第三个视角：市盈率波动——均值回归的周期更短、幅度更大

**A股市盈率的中枢与极值**：

经过对沪深300约20年的数据统计，我们得出以下规律：

| 区间分类 | 沪深300 PE（基于多年平均利润） | 出现的典型时刻 | 市场情绪 |
| :--- | :--- | :--- | :--- |
| ❄️ 极度低估（黄金坑） | **8~10倍** | 2014年中、2018年底、2024年1月 | 绝望、无人问津 |
| 🌥️ 合理偏低 | 10~12倍 | 多数熊市中后期 | 谨慎、怀疑 |
| ☀️ 长期中枢 | **12~14倍** | 市场相对平稳时期 | 情绪中性 |
| 🌤️ 偏高 | 18~20倍 | 牛市中后期 | 乐观蔓延 |
| 🔥 极度高估（危险区） | **25倍以上** | 2007年顶峰（超50倍）、2015年创业板（超100倍）、2021年初核心资产（部分超80倍） | 狂热、“新时代” |

**A股与美股估值规律的异同**：

| 维度 | 美股（1871-1971） | A股（1990-2026） | 差异原因 |
| :--- | :--- | :--- | :--- |
| 估值中枢 | 14~15倍 | **12~14倍**（略低） | A股历史风险溢价更高 |
| 低估极端 | 5~7倍 | 8~10倍 | A股较少出现5倍以下（退市机制不完善导致“壳价值”托底） |
| 高估极端 | 25~30倍 | **经常超过50倍** | A股散户主导、投机氛围更浓 |
| 均值回归周期 | 15~20年 | **3~5年**（压缩版） | A股政策驱动、情绪波动更剧烈 |

**格雷厄姆法则在A股的适用性验证**：

✅ **低PE买入有效**：
- 2014年中（PE<9倍）买入沪深300，持有至2015年高点收益超**150%**
- 2018年底（PE~10倍）买入，持有至2021年高点收益超**100%**
- 2024年1月（PE~10倍）买入，持有至2024年9月“924行情”后收益超**30%**

❌ **高PE买入失效**：
- 2007年（PE超50倍）买入上证，直到2015年才解套（**等待8年**）
- 2021年初（核心资产PE超60倍）买入，至今仍深度亏损

✅ **均值回归铁律有效**：
A股的估值钟摆不仅会回归，而且摆动幅度更大、速度更快。

🧠 **对A股的特别警示**：

> **A股波动更大，PE超过15倍已需保持警惕，超过20倍进入系统性危险区域。不能用美股的估值刻度来丈量A股，必须给予更保守的折扣。**

## 七、从历史规律推导出的投资行动指南（第六层·实战落地）

### 7.1 核心原则一：永远不要试图预测市场的精确走向

格雷厄姆用历史数据雄辩地证明了短期预测的徒劳：

> “1964年市场首次达到900点时，估值已经显得偏高。但市场此后仍继续上涨，直至1968年才真正见顶——整整又涨了4年。”

📌 **A股应用**：
- A股短期走势受政策、外资流动、市场情绪的影响极大
- “924行情”已经证明：政策转向可以在数周内将指数拉升20%~30%
- 任何对指数顶底的精确预测都是不可靠的，甚至是有害的

✅ **正确的态度**：不是“预测”，而是“应对”。判断温度，调整仓位，但永远保留容错空间。

### 7.2 核心原则二：学会用“温度计”代替“水晶球”

虽然不能精确预测，但投资者完全可以判断当前市场处于“偏冷”“温和”还是“过热”的状态。

**A股专属“温度计”刻度表**：

| 温度状态 | 沪深300 PE（平滑利润） | 股息率 | 其他辅助信号 | 建议股票仓位（防御型） |
| :--- | :--- | :--- | :--- | :--- |
| ❄️ **极度寒冷（黄金坑）** | <10倍 | >3.5% | 破净股占比>10%，新基金发行冰点 | **75%~80%** |
| 🌥️ **偏冷（低估区间）** | 10~12倍 | 3.0%~3.5% | 成交量低迷，市场情绪悲观 | **60%~70%** |
| ☀️ **温和（合理区间）** | 12~15倍 | 2.5%~3.0% | 正常交易，情绪中性 | **50%~60%** ← **当前在此区间** |
| 🌤️ **偏热（偏高区间）** | 15~18倍 | 2.0%~2.5% | 新基金发行回暖，社交平台热议 | **40%~50%** |
| 🔥 **极度炎热（危险区）** | >18倍 | <2.0% | 基金爆款频出，换手率极高，杠杆资金活跃 | **25%~30%**（下限） |

🧠 **温度计的使用目的**：不是精确择时，而是**调整防御姿态**。温度越高，越要收紧风险敞口；温度越低，越要敢于加大敞口。

### 7.3 对防御型投资者的具体行动指南（2026年版）

基于“整体合理、结构分化”的当前判断，防御型投资者应采取以下策略：

**第一步：资产配置（核心决策）**

**第五步：行为纪律——两条铁律**

| 铁律 | 内容 |
| :--- | :--- |

| **铁律二** | **绝不因恐慌而底部割肉** |

### 7.4 长期视角的最终安慰

格雷厄姆在章节末尾给出了一个既理性又温暖的结论：

> “即使从偏高估值出发，长期分散化投资仍能获得正回报，只是预期收益率应下调。历史上，没有任何一个时期能够推翻‘长期持有分散化优质股票终将回报投资者’这一基本结论，但前提是投资者能够承受期间的大幅波动，且不在低迷期被迫卖出。”

📌 **A股应用版**：

| 核心结论 | 具体内容 |
| :--- | :--- |
| 即使从当前估值出发 | 长期持有沪深300 ETF等高度分散的优质组合，仍能获得与名义GDP增速大致相当的正回报（**预期年化6%~9%**） |
| 每一次极度低估之后 | 都迎来了可观的长期回报（2014、2018、2024年初已验证） |
| 每一次极度高估之后 | 都迎来了痛苦的均值回归（2007、2015、2021年已验证） |
| 成功的关键 | 投资者能够承受期间的大幅波动，且**不在低迷期被迫卖出**（这要求不使用短期资金、不加杠杆） |


## 八、本章金句与核心思想提炼

### 8.1 格雷厄姆原著三大核心思想

> **核心思想一**：“股票市场的历史反复讲述着同一个故事：从低市盈率买入的投资者，最终获得了丰厚的回报；从高市盈率买入的投资者，往往承受了痛苦的损失。”

> **核心思想二**：“1972年初的市场，已不再为防御型投资者提供足够的安全边际。” —— 而2026年的A股，整体上仍存在安全边际（尤其在高股息板块），但需警惕结构分化带来的陷阱。

> **核心思想三**：“不要期望从历史数据中找到精确预测未来的公式；但忽视历史的教训，无疑是通往灾难的最短路径。”

### 8.2 A股投资者的专属提醒

> **“在中国，估值均值回归的钟摆摆动幅度比美股更大、时间更短。极端低估与极端高估之间的切换往往只需要两三年。这既是巨大的风险（追高者损失惨重），也是冷静投资者最大的机会所在（逆向布局收益惊人）。”**

### 8.3 2026年最终结论速查卡

## 十、总结：全章最终闭环——历史的韵律与智慧的传承

让我们回到开篇的那两次对话：

**1972年的纽约投资顾问**，面对格雷厄姆“股票已跑输债券”的诊断和周围人狂热的看多情绪，陷入了两难。如果他听了格雷厄姆的建议——减少股票、增加债券——他会在接下来的1973-1974年熊市中（道指下跌约45%）保住大量本金，然后在1974年底估值极低时重新入场，享受随后数年的大牛市。

**2026年的上海投资者**，面对A股“整体合理但结构分化”的局面，同样需要做出选择。如果他能够：
1. 理解历史的韵律（估值均值回归的铁律）
2. 掌握温度计的用法（当前PE 13~15倍，处于温和区）
3. 坚守行为的纪律（不追高、不恐慌、不加杠杆、保留现金）

那么他将在未来数年的市场波动中，既不会在狂热中迷失，也不会在恐慌中割肉，最终享受中国经济增长和企业盈利提升带来的长期回报。

**历史不会简单重复，但历史的韵律会反复奏响。**

当格雷厄姆在1972年写下“股票的预期回报率已经低于债券的确定回报率”时，他没有预测到1973-1974年的熊市，也没有预测到1975年后的反弹。他只是**诚实地说出了当下的温度**，然后让投资者自己决定是穿外套还是穿短袖。

这就是本章教给我们的最宝贵的能力：**用温度计代替水晶球，用应对代替预测，用纪律代替情绪。**

📌 **最终寄语**：

> 聪明的投资者不会因为读了这一章就获得了预测下个月A股涨跌的水晶球。但他获得了远比水晶球更宝贵的东西——一套经过百年检验的估值坐标系，一种衡量市场温度的客观方法，以及一颗在市场狂热中保持冷静、在市场绝望中保持勇敢的心。

**听懂历史韵律的人，将获得复利最丰厚的奖赏。**
