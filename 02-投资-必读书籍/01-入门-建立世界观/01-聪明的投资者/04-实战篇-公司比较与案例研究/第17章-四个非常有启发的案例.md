# 《聪明的投资者》第17章：四个非常有启发的案例 —— 2026中国A股适配版


## 一、本章要回答的核心问题（A股强化版）

历史上有哪些真实的案例，能够最生动地说明投资与投机的区别？

为什么即使是最著名的大公司，也会让投资者遭受灾难性损失？

市场情绪的极端波动如何创造了巨大的风险和无与伦比的机会？

聪明投资者从这些案例中能提炼出哪些永恒的原则？在中国市场，这些原则是否被反复验证？


## 二、案例一：绿地集团债务违约——安全债券的幻灭（对标原书宾州中央铁路）

### 2.1 背景

绿地控股集团有限公司（绿地集团）是中国知名的超大型房地产企业集团，长期位列世界500强，由上海市国资委控股。其发行的公司债券长期以来被众多机构和个人投资者视为"准政府信用"的安全投资。

格雷厄姆在书中记录宾州中央铁路案例时写道，宾州中央铁路是美国历史最悠久、规模最大的铁路公司之一，其债券长期以来被机构和个人投资者视为"安全的投资"，享有很高的信用评级。**绿地集团在A股市场的角色，与当年的宾州中央铁路惊人地相似。** 因为背靠地方国资，市场长期默认其债券不存在实质性违约风险。

### 2.2 灾难发生

2026年5月，上海证监局发布《关于对绿地控股集团有限公司采取责令改正措施并对张玉良、张蕴、王晓东采取出具警示函措施的决定》。经查，绿地集团作为公司债券H21绿地1、H21绿地2的发行人，存在以下严重问题：

**债务逾期未披露**：2024年7至12月，绿地集团发生债务逾期，累计未偿余额101.02亿元；2025年全年，发生债务逾期，累计未偿余额97.95亿元；2026年以来至3月11日，发生债务逾期，累计未偿余额25.45亿元。针对上述事项，公司均未及时披露临时报告。

**被列为失信被执行人未披露**：2025年3月，绿地集团被列为失信被执行人，未及时披露临时报告。

**巨额亏损未披露**：绿地集团2024年度公司净利润为**-196.35亿元**，亏损金额达到合并报表上年末净资产的13.94%，未披露临时报告。

### 2.3 债券持有人的惨痛损失

违约前，绿地相关债券价格在面值附近交易。随着债务逾期金额累计超过200亿元且信息披露严重违规，债券价格大幅下跌，大量持有绿地债的银行理财、公募基金、券商资管产品净值遭受重创。

**更广泛的债市警示**：根据证券时报统计，2026年年初至6月25日，包含可转债发行主体在内，共计**27家独立债券发行人**发生主体信用评级下调。其中既有龙大美食、东方时尚等多次遭遇评级下调的上市公司，也有**青岛上合控股发展集团有限公司这类被两家评级机构同步下调评级的地方国企**。同期，已有**221家债券发行人终止了评级机构的评级服务**。陕西西咸新区发展集团有限公司主体评级由AAA下调为AA+，主要因为"公司面临很大的资本支出压力，资产流动性依然较弱，短期偿债压力加大，存在较大的或有负债风险，盈利能力大幅下降"。

评级下调直接原因集中在**企业短期偿债压力加大、资产流动性偏弱、盈利持续下滑、出现债务或商票逾期、涉及重大诉讼**等负面事项。

### 2.4 核心教训（与格雷厄姆原书完全一致）

**任何公司，无论历史多么悠久、评级多高、背景多强，只要过度负债，就可能违约。** 绿地事件再次打破了"国企刚兑"信仰——即便背靠上海国资、位列世界500强，依然可以违约。

**投资者绝不能仅凭"AAA评级"或"国资背景"就认为债券安全**，必须仔细审查**利息保障倍数、短期债务到期规模、账面现金真实性**。

**分散化**即使对债券投资者也至关重要——不要把所有鸡蛋放在一个篮子里。绿地违约后，部分激进加杠杆持有单一债券的机构遭受重创。

格雷厄姆写道："任何公司，无论历史多么悠久、名声多么显赫，只要过度负债，就可能违约。"宾州中央铁路于1970年突然破产，当时是美国历史上最大的公司破产案。**2026年的绿地集团，就是21世纪中国版的宾州中央铁路。**


## 三、案例二：中国建筑（601668）——极端低估与市场非理性（对标原书A&P）

### 3.1 公司背景

中国建筑是全球最大的建筑企业，位列世界500强前列，业务涵盖房建、基建、地产开发。公司是全国规模最大、板块市值最大的建筑企业，是副部级建筑央企，是上证50、沪深300、中证红利等主要指数成分股。公司盈利稳定，连续多年分红。

但因其处于传统的建筑行业，被市场贴上"低增长、高负债、应收账款高"的标签，长期被冷落。

### 3.2 2026年的极端低估

截至2026年6月26日，中国建筑的估值数据如下：

| 指标 | 数据 |
|------|------|
| 股价 | 4.40元 |
| 每股净资产 | 12.01元 |
| **市净率（PB）** | **0.37倍** |
| 市盈率（TTM） | 4.79倍 |
| 市盈率（动态） | 3.27倍 |
| 每股收益 | 0.92元 |
| 每股股息（TTM） | 0.27元 |
| **股息率（TTM）** | **6.18%** |
| 总市值 | 1818亿元 |

这意味着**投资者可以以不到净资产四折的价格买入全球最大的建筑企业**。同时，公司每年盈利约0.92元/股，股息率高达6.18%，远高于大多数银行理财和债券收益率。市场在极度悲观中，几乎免费赠送其庞大的在手订单和全球领先的市场地位。

有投资者在股吧中写道："市净率0.37倍，市盈率3.32倍，估值比大多数银行都低；股息率6.15%，比大多好银行都高……"2026年5月，中国建筑在互动平台回答投资者提问时表示："公司经营情况总体稳定。上市公司市值表现受行业形势、市场风格等多种因素影响，**公司股价处于低估水平**。"

### 3.3 被忽视的基本面

中国建筑旗下中海地产2025年销售额排名全国第2，中建东孚、中建壹品、中建智地分列全国第16、17、27位，中国建筑合计地产销售额达**3981亿元**，遥遥领先保利发展的2530亿元。公司2025年全年新签合同总额45458亿元，同比提升1.0%。

公司为国资委市值管理考核试点单位，分红率常年领先建筑央企。近年保持了稳中有增的每股分红，其中2024年归属净利润下降，但公司将分红率从21%提升至24%进行应对，保持了每股分红不变。

更重要的是政策层面的变化：2026年，五部门发布国企改革方案，明确**连续12个月股价破净的央企，半年内必须出台完整估值修复方案**，可使用股份回购、大股东增持、提高现金分红、注入优质资产等方式提振股价，**杜绝企业长期躺平低估**。截至2026年一季度末，A股上市公司2025年年报现金分红计划中的拟派现总金额达**7343.61亿元**，而央企控股上市公司依然是分红的绝对主力，占比超过50%。

### 3.4 核心教训

**当一家大型、知名、财务尚可的公司股价跌至市净率极低（<0.5倍）、股息率极高（>6%）、经营现金流持续为正时，往往是市场给予了最极端的错误定价。**

投资者需要极大勇气，在"坏消息最多、情绪最悲观"时买入。

格雷厄姆当年对A&P的判断在A股完全适用：**市场情绪会在悲观与乐观之间剧烈摇摆，为冷静的投资者提供反复出现的买卖机会。** A&P在1938年股价跌至其净流动资产价值以下，随后几年利润恢复，股价大幅回升。**中国建筑在2026年的估值水平，甚至比当年的A&P更加极端。**


## 四、案例三："茅指数"成长股泡沫——投机泡沫的兴衰（对标原书"漂亮50"）

### 4.1 背景

2019年至2021年初，A股市场掀起狂热的"核心资产"崇拜，一批被称为"茅指数"的行业龙头受到机构和个人投资者疯狂追捧。典型代表包括：贵州茅台、海天味业、爱尔眼科、通策医疗、中国中免、宁德时代等。

这与1970年代美国的"漂亮50"泡沫如出一辙。当时IBM、施乐、雅芳、宝丽来、麦当劳等公司被视为"永远成长"的股票。

### 4.2 投机的特征

这些公司被视为"永远成长"的股票，投资者相信无论以什么价格买入，长期来看都会赚钱。"好公司可以无视估值""怕高都是苦命人"成为市场流行语。

其市盈率被推高到难以置信的水平：

- **茅指数瓦解前估值高达近80倍，中位数估值也有69倍**，而非茅指数估值仅30倍，中位数也25倍
- 海天味业市盈率一度超过100倍
- 爱尔眼科、通策医疗超过150倍
- **宁德时代最高接近200倍估值**
- 中国中免超过60倍

安全边际的概念被完全抛到脑后，市场口号是"这些股票没有天花板"。有分析指出，抱团出现的本质有三点：市场K型分化、某个方向高景气凸显成为少数甚至唯一上行方向、熊市后期的大规模放水导致流动性充裕。

### 4.3 泡沫破裂

2021年2月所谓坚不可摧的"茅指数"抱团瓦解，指数一个月跌幅高达30%，4月之后基本面开始被证伪，**2022年业绩+估值"双杀"** 。

到2023-2024年，大量明星股股价下跌了50%至80%：

- 海天味业从最高约7000亿市值跌至约2000亿
- 中国中免从最高约400元跌至约100元
- 通策医疗从最高约420元跌至约50元
- 宁德时代在2022年PE接近200倍估值透支到未来7年，随后碳酸锂价格大跌、电池供应过剩，基本面被证伪

即使其中许多公司利润仍在增长，仅仅是市盈率从极高向正常水平回归，就足以让追高的投资者血本无归。**格雷厄姆的"双杀"理论被完美验证。**

### 4.4 核心教训

**为优秀公司的股票支付过高的价格，同样是一种严重的投机，而且结果可能同样灾难性。** A股的"茅指数"泡沫与1970年代美国的"漂亮50"泡沫如出一辙。

公司质量再好，也无法替代"以合理价格买入"这一根本原则。

市场先生总是会从极度乐观走向极度悲观，没有任何一个"必须永远持有"的故事能够长久。2021年茅指数瓦解前估值高达近80倍，**"估值"没有长到天上的大树，这是估值的内涵**。


## 五、案例四：长江电力（600900）——被冷落的价值蓝筹（对标原书AT&T）

### 5.1 背景

长江电力是中国最大的水电上市公司，目前运营管理了**乌东德、白鹤滩、溪洛渡、向家坝、三峡、葛洲坝六座梯级电站**，形成了世界最大的"清洁能源走廊"。这种水能资源优势具备**稀缺性与天然垄断性**，无法被同行业公司所复制。公司盈利稳定，连续多年分红，几乎是"永续经营"的资产。

这与原书中的AT&T高度相似——AT&T是当时美国最大的通信公司，几乎垄断了电话业务，是典型的蓝筹股，由于其规模庞大、业务稳定、持续分红，被许多保守投资者视为"孤儿寡母股"。

### 5.2 市场的冷落

在2019-2021年"茅指数"狂飙时期，市场注意力全部集中于成长股，像长江电力这样增长缓慢但极其稳定的公用事业蓝筹遭到抛弃。

其市盈率长期在15-18倍区间（高于银行、建筑，但远低于消费医药），股息率约3.5%-4%。虽然绝对估值不算极度低估，但在资金疯狂追逐高成长股的环境中，它显得"乏味"且不被重视。

### 5.3 理性分析本该看到的

长江电力的利润虽然增长缓慢，但**极其稳定**，连续20年以上支付股息，从未出现亏损。水电行业已经步入成熟阶段，但公司仍有多元成长性：扩机增容进一步提升总装机容量和发电能力；折旧年限到期释放利润增长空间；对外投资收益贡献比重较高。

其财务状况极其健康，现金流充裕。水利发电的成本极低，一旦建成，边际成本接近于零。

**2026年最新数据**：

- 2025年度利润分配预案为每10股派发现金股利10.00元，共分派现金股利**244.68亿元**，创历史新高，股利分配率70.92%
- 对应2026年5月14日收盘价的股息率为**3.71%**
- 预计2026-2028年公司总营业收入分别为864.70、896.61、890.68亿元，归母净利润分别为355.11、371.32、371.34亿元
- 2026年一季度业绩增速亮眼，公允价值变动收益同比增加7.36亿元，利息费用同比下降3.92亿元

从任何保守估值角度看，这家公司的股票都提供了**确定性的、可持续的回报**。它的内在价值由未来数十年的稳定现金流决定，而非市场情绪。

### 5.4 随后的表现

当2021年后"茅指数"泡沫破裂，市场恐慌时，大量资金寻求安全资产。长江电力因其确定的现金流和高股息，成为资金的"避风港"。

股价从2021年的约18元稳步上涨至2026年的约27元区间，在成长股暴跌期间保持稳定，同时持续派发可观股息。机构给予的目标价在30.6-32.5元区间，国泰海通给予2026年22倍PE估值，对应目标价31.68元。

那些在它最不受欢迎时买入的防御型投资者，既获得了稳定的股息收入，又享受了股价稳健上涨带来的资本增值，并且完全避免了"茅指数"暴跌的伤害。

### 5.5 核心教训

**安全边际往往就藏在那些"乏味"、"不性感"但极其稳定的大公司里。** 长江电力在A股就是AT&T的完美映射。

当市场将某些股票遗忘、给予冷落时，恰恰是防御型投资者建立安全头寸的最佳时机。

**稳定的股息率加上可预测的盈利，往往预示着长期稳健的回报。** 虽然它不会让你一夜暴富，但能确保你在市场寒冬中安然入睡。


## 六、四个案例的综合总结：格雷厄姆的最终告诫（A股验证）

| 案例 | 类型 | 关键错误 | 核心教训 |
|------|------|----------|----------|

## 七、本章金句与核心警示（保留原书精华，补充A股启示）

> "这四个案例之所以极具启发性，不是因为它们罕见，恰恰是因为它们将一再重演。"（完全适用A股）

> "历史不会简单重复，但投资者的愚蠢却以相同的方式反复出现。"（A股的"茅指数"泡沫就是"漂亮50"的完美再现）

> "聪明投资者的真正优势，不在于预知未来，而在于能从历史中吸取教训，并拥有在极端市场中保持冷静的品格。"

**A股补充**：

> "在中国市场，债券刚兑的打破（绿地）、核心资产的疯狂（茅指数）、低估值蓝筹的逆袭（中国建筑、长江电力），都已反复验证了格雷厄姆的原则。每一次极端行情，都是对投资者纪律和心性的考验。"
