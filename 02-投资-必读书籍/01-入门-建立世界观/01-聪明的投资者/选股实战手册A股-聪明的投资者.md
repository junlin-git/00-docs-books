## 一、投资者类型自测：你是防御型还是积极型？

在选股之前，必须先认清自己的类型。**格雷厄姆将投资者分为两类**，选股标准完全不同：

| 维度 | 防御型投资者 | 积极型投资者 |
|------|------------|------------|
| 时间投入 | 极少（被动管理） | 大量（主动研究） |
| 专业能力 | 一般 | 较强的财务分析能力 |
| 风险偏好 | 低，追求稳定 | 中，追求超额收益 |
| 主要目标 | 保值 + 跑赢通胀 | 合理超额收益 |
| 核心工具 | 指数基金 + 少量个股 | 深度个股精选 |
| 组合调整频率 | 每年一次再平衡 | 持续跟踪 |

> ⚠️ **格雷厄姆警告**：大多数人认为自己是积极型，实际上缺乏时间和能力，结果两边都做不好。**诚实评估自己**是第一步。

## 二、防御型投资者选股七大硬性标准

这是格雷厄姆在第14章明确提出的标准，**七条必须同时满足**，缺一不可：

### 标准 1：企业规模足够大
- **原文标准**：年销售额不低于 1 亿美元（工业企业）；总资产不低于 5000 万美元（公用事业企业）
- **A股适配**：优先选择 **沪深300成分股** 或市值 100 亿以上的行业龙头
- **港股适配**：优先选择恒生指数或恒生国企指数成分股

> 理由：规模大的企业抗风险能力强，不易因单一事件陷入困境，财务信息也更透明可靠。

---

### 标准 2：财务状况足够强健（流动比率）
- **硬性指标**：流动比率（流动资产 ÷ 流动负债）≥ **2**
- **补充指标**：长期负债 ≤ 净流动资产（流动资产 - 流动负债）
- **公用事业/金融企业**：债务不超过股东权益的 2 倍

```
流动比率 = 流动资产 ÷ 流动负债 ≥ 2.0
净流动资产 = 流动资产 - 流动负债 > 长期负债
```

> 理由：确保企业有足够的短期偿债能力，不会因资金链断裂而陷入危机。

---

### 标准 3：持续盈利（10年无亏损）
- **硬性指标**：过去 **10年** 每年均有盈利，无亏损年份
- **A股适配**：由于A股上市历史较短，可适当放宽至 **5年连续盈利**，但需注意是否有补贴收入支撑

> 理由：持续盈利证明企业具备真实的商业模式，而非依赖一次性收益或政策红利。

---

### 标准 4：持续分红（20年不间断）
- **硬性指标**：过去 **20年** 每年均有分红记录
- **A股适配**：可放宽至 **5~10年** 连续分红，分红率 ≥ 30%，且近年分红金额稳定或增长

> 理由：分红是企业真实盈利能力和管理层股东友好态度的最直接体现。

---

### 标准 5：盈利增长（10年增长1/3以上）
- **硬性指标**：以三年平均EPS计算，最近三年均值 ÷ 10年前三年均值 ≥ **1.33**（增长33%以上）
- **计算方式**：
  ```
  增长率 = (近3年平均EPS) ÷ (10年前3年平均EPS) - 1 ≥ 33%
  ```
- **A股适配**：可参考近5年复合增长率 ≥ **5%**（跑赢通胀即可，不苛求高增长）

> 理由：盈利增长说明企业具备持续创造价值的能力，而非停滞不前。

---

### 标准 6：市盈率合理（PE ≤ 15倍）
- **硬性指标**：当前股价 ÷ 过去三年平均EPS ≤ **15 倍**
- **注意**：用三年平均EPS而非单年EPS，平滑周期性波动

```
PE（格雷厄姆版）= 当前股价 ÷ 近三年平均EPS ≤ 15
```

> ⚠️ **陷阱提示**：单年EPS可能因一次性收益虚高，必须用多年均值。

---

### 标准 7：市净率合理（PB ≤ 1.5倍）
- **硬性指标**：股价 ÷ 每股账面净资产 ≤ **1.5 倍**
- **组合使用**：格雷厄姆提出 PE × PB ≤ **22.5** 的综合估值上限

```
PB = 股价 ÷ 每股净资产 ≤ 1.5
综合上限：PE × PB ≤ 22.5
（例：PE=15, PB=1.5 → 15×1.5=22.5，刚好在上限）
```

> 理由：PB限制确保即使公司未来盈利下滑，资产也能提供一定保护。

---

### ✅ 防御型选股七条检查表（速查）

```
□ 1. 市值/规模足够大（沪深300成分股 or 行业龙头）
□ 2. 流动比率 ≥ 2，长期负债 ≤ 净流动资产
□ 3. 近5~10年每年盈利，无亏损年
□ 4. 近5~10年持续分红，分红率 ≥ 30%
□ 5. 近5年EPS复合增长率 ≥ 5%
□ 6. PE（三年均值）≤ 15倍
□ 7. PB ≤ 1.5倍，且 PE × PB ≤ 22.5
```

## 三、积极型投资者选股进阶标准

格雷厄姆在第15章提出积极型投资者的选股方向，核心是**在防御型标准的基础上寻找被低估的股票**：

### 3.1 低估类股票的四个来源

| 来源 | 说明 | A股参考 |
|------|------|---------|
| **相对不受市场青睐** | 业绩稳定但市场忽视，估值被压低 | 传统制造业、公用事业、银行 |
| **重大不利事件后超跌** | 因短期坏消息导致股价大幅下跌但基本面未变 | 周期股低谷期、业绩短暂下滑后 |
| **隐藏资产类** | 账面资产被低估（如土地、品牌、持有股权未重估） | 地产持有型、资源类企业 |
| **净流动资产价值低估** | 股价低于每股净流动资产（NCAV），俗称"烟蒂股" | 极端熊市中的小盘股 |

### 3.2 格雷厄姆净流动资产价值（NCAV）公式

```
NCAV = 流动资产 - 全部负债（包括优先股）
NCAV每股 = NCAV ÷ 总股数

选股标准：股价 ≤ NCAV每股 × 2/3（即以净流动资产的6折买入）
```

> 这是最经典的"烟蒂股"策略，适合极度熊市。A股熊市底部曾出现大量满足此条件的个股。

### 3.3 积极型投资者的额外条件

- **PE ≤ 10倍**（比防御型更严格，要求更低的价格）
- **PB ≤ 1.2倍**
- **资产负债率 ≤ 50%**（比防御型更保守）
- **近3年ROE ≥ 10%**（有一定的盈利能力要求）
- **排除：高速成长股**（格雷厄姆明确指出高增长股往往估值过高，不在其体系内）

### 3.4 积极型投资者应回避的策略

根据第6章"被动的方法"，以下是**格雷厄姆明确反对**的操作：
- ❌ 高价购买成长股（未来增长已定价，不划算）
- ❌ 跟风追热门股（市场追捧本身就是高价的信号）
- ❌ 做空操作（短期方向难以判断，风险过高）
- ❌ 频繁交易、短线操作（交易成本侵蚀收益）

## 四、核心估值方法：内在价值 & 安全边际

### 4.1 什么是内在价值

内在价值是**企业未来现金流的折现总和**，与市场价格无关。格雷厄姆认为，市场价格围绕内在价值波动，长期终将回归。

### 4.2 格雷厄姆估值公式（第11章）

格雷厄姆给出了一个简化估值公式：

```
内在价值 = EPS × (8.5 + 2g)

其中：
- EPS = 过去12个月每股收益（或三年平均）
- 8.5 = 零增长企业的合理PE基准
- g = 未来7~10年预期年增长率（%）
- 计算结果再与当前无风险利率调整：
  调整后内在价值 = [EPS × (8.5 + 2g) × 4.4] ÷ 当前AAA债券收益率
```

**实际使用示例**：
```
假设某股票：
- EPS（三年均值）= 2.00 元
- 预期增长率 g = 5%
- 当前十年期国债收益率 = 2.8%（A股参考值）

内在价值 = 2.00 × (8.5 + 2×5) × 4.4 ÷ 2.8
         = 2.00 × 18.5 × 4.4 ÷ 2.8
         = 162.8 ÷ 2.8
         ≈ 58.1 元

若当前股价 ≤ 58.1 × 0.67 ≈ 38.9 元，则具备安全边际，可考虑买入。
```

### 4.3 安全边际：最核心的原则（第20章）

> **"安全边际是投资的中心思想。"** —— 格雷厄姆

安全边际的本质是：**以远低于内在价值的价格买入，为错误预留容错空间。**

```
买入价格 = 内在价值 × (1 - 安全边际折扣)

格雷厄姆建议：
- 防御型投资者：安全边际 ≥ 25%~33%（即以内在价值的 67%~75% 买入）
- 积极型投资者：安全边际 ≥ 33%~50%（即以内在价值的 50%~67% 买入）
```

**安全边际的作用**：
1. **抵消分析误差**：即使估值出错，低价买入仍有保护
2. **抵消未来不确定性**：经济环境变化、行业衰退都有缓冲
3. **提供超额收益**：价格最终向价值回归时，折扣即为超额收益来源

## 五、财务报表分析要点

### 5.1 利润表关键指标

| 指标 | 健康标准 | 警戒信号 |
|------|---------|---------|
| 毛利率 | 稳定或提升，行业龙头通常 > 30% | 逐年下滑，竞争力弱化 |
| 净利润率 | 持续为正，与同行相当 | 依赖非经常性损益维持盈利 |
| EPS趋势 | 10年内稳定增长（允许周期性波动） | 大幅波动或长期不增长 |
| 营收增长 | 与利润增长匹配 | 营收增长但利润下降（成本失控） |

### 5.2 资产负债表关键指标

| 指标 | 健康标准 | 警戒信号 |
|------|---------|---------|
| 流动比率 | ≥ 2.0 | < 1.5，短期偿债有压力 |
| 资产负债率 | 工业类 ≤ 50%；公用事业 ≤ 67% | > 70%，财务风险高 |
| 商誉/总资产 | < 10% | 占比过高，减值风险大 |
| 货币资金 | 覆盖短期负债 | 货币资金持续减少 |

### 5.3 现金流量表关键指标

| 指标 | 健康标准 | 警戒信号 |
|------|---------|---------|
| 经营性现金流 | 持续为正，接近或大于净利润 | 长期小于净利润（应收账款质量差） |
| 自由现金流 | FCF = 经营现金流 - 资本开支 > 0 | 大规模扩张导致FCF长期为负 |
| 分红能力 | 股息 / 经营现金流 < 50% | 借债分红，不可持续 |

### 5.4 格雷厄姆特别警示：小心会计操纵

格雷厄姆在第12章详细分析了EPS操纵的手段，选股时需注意：

- **警惕非经常性收益虚增利润**：出售资产、政府补贴、投资收益一次性贡献的利润不可持续
- **警惕折旧政策变化**：延长折旧年限可人为提高当期利润
- **警惕股权摊销被忽视**：部分公司将大额摊销放入"调整后EPS"掩盖
- **警惕收入提前确认**：关注应收账款增速是否远超营收增速

> **实操建议**：将"扣非净利润"作为主要参考，而非总净利润。

## 六、每股收益的正确使用方式

基于第12章的分析，格雷厄姆对EPS的使用有严格要求：

### 6.1 不要用单年EPS

单年EPS容易受到周期、一次性事件影响，应使用：
- **三年平均EPS**（基本）
- **五年或七年平均EPS**（更保守，适合周期股）

### 6.2 EPS的陷阱识别

```
真实EPS = 归母净利润（扣非）÷ 总股本

需要从EPS中扣除：
- 出售资产的一次性收益
- 政府补贴
- 股权投资的公允价值变动
- 债务重组收益

还原后：若真实EPS显著低于报告EPS，警惕！
```

### 6.3 稀释EPS的重要性

若公司存在可转债、期权、股权激励等，必须使用**完全稀释后EPS**：
```
稀释EPS = 归母净利润 ÷ (总股本 + 潜在股份数)
```

## 七、必须规避的选股陷阱

### 7.1 新股与次新股（IPO）

格雷厄姆在第6章明确指出：
- **新股在牛市顶部大量发行**，定价通常对投资者不利
- IPO的承销商服务的是发行方，而非投资者
- **历史数据表明**：大多数IPO在上市后数年内的表现不如同期大盘

> **建议**：等待新股上市后 1~3 年，股价经过市场检验、估值回归合理后再考虑

### 7.2 "成长股"的陷阱

- 高增长预期已经反映在高估值中，任何不及预期都会导致股价大幅下跌
- 预测未来增长极其困难，"确定的高增长"往往并不确定
- **格雷厄姆体系不适合买成长股**，这是其核心局限，需与其他方法结合

### 7.3 可转换证券与认股权证（第16章）

- **可转债**：表面上兼具债券保护和股票上涨潜力，实际上往往两者都做不好
- **认股权证**：本质上对公司原有股东不利（稀释），投资者不应被其吸引
- **优先股**：格雷厄姆认为大多数优先股对投资者不公平——好的时候不如普通股，差的时候不如债券

### 7.4 市值泡沫期的选股

参考第3章（市场历史）和第8章（市场波动）：
- 当整体市场PE显著高于历史均值（如A股PE > 25~30，港股PE > 20）时，符合标准的个股极少
- 此时应提高现金比例，而非降低标准去买"相对便宜"的股票

### 7.5 管理层信号的识别（第17、19章）

**好的信号**：
- 持续稳定分红，甚至逐年提高分红
- 管理层持股比例高，且无大规模减持
- 资本配置合理，不盲目扩张或低效并购

**坏的信号**：
- 频繁发行新股融资（稀释股东权益）
- 利润不分红，大量留存但ROE低下
- 高管薪酬过高，与业绩不匹配
- 财务数据频繁"更正"或重述

## 八、市场先生与操作纪律

这是第8章的核心思想，也是整个格雷厄姆体系的心理基础：

### 8.1 市场先生的比喻

> 想象你和一个叫"市场先生"的人共同持有一家小企业的股份。每天，市场先生都会出现，给出一个买入或卖出的报价。有时他情绪乐观，报价很高；有时他悲观恐慌，报价很低。**你可以选择接受报价，也可以完全无视他。**

**关键启示**：
- 市场价格是你可以**利用**的，而不是你应该**跟随**的
- 当市场先生悲观时（低价），是买入的机会
- 当市场先生狂热时（高价），是卖出或持币的时机

### 8.2 选股后的操作纪律

| 情景 | 正确操作 | 错误操作 |
|------|---------|---------|
| 股价下跌20%但基本面未变 | 检视基本面，考虑加仓 | 因恐惧割肉 |
| 股价上涨50%达到合理价值 | 评估是否卖出或减仓 | 贪婪继续持有 |
| 市场大跌，恐慌蔓延 | 冷静检视持仓，寻找机会 | 跟风抛售 |
| 市场大涨，人人乐观 | 提高选股标准，增加现金 | 追高买入 |

### 8.3 买卖的基本原则

**买入触发条件**：
1. 价格低于内在价值，且安全边际 ≥ 25%
2. 符合防御型或积极型选股标准
3. 不是因为"感觉会涨"，而是因为"价格确实便宜"

**卖出触发条件**：
1. 股价上涨至内在价值以上（安全边际消失）
2. 基本面发生根本性恶化（盈利能力长期下滑）
3. 发现更好的投资机会（机会成本驱动）
4. **不应因**：价格短期下跌、市场整体下跌、听到坏消息就卖出

## 九、通货膨胀对选股的影响

基于第2章，通货膨胀是选股中不可忽视的背景变量：

### 9.1 通胀对资产的影响

| 资产类型 | 通胀保护能力 | 说明 |
|---------|------------|------|
| 现金/存款 | ❌ 极差 | 实际购买力持续下降 |
| 债券（固定利率） | ❌ 差 | 通胀侵蚀实际收益 |
| 普通股（优质企业） | ✅ 较好 | 企业可将成本转嫁给消费者 |
| 资源类股票 | ✅ 好 | 商品价格随通胀上涨 |
| REITs/地产 | ✅ 较好 | 实物资产，具有通胀对冲效果 |

### 9.2 格雷厄姆对股票抗通胀的保留意见

格雷厄姆并不认为股票是完美的通胀对冲工具，研究显示：
- 历史上，**部分高通胀时期股市实际回报率为负**
- 高通胀 → 高利率 → 估值收缩 → 股价下跌

**实操建议**：
- 通胀上升时期，选择具有**定价权**的企业（能提价而不失客户）
- 关注**ROE持续 > 通胀率**的企业（真正创造价值）
- 在低估值基础上，优先选消费品、医疗、公用事业等抗通胀行业

## 十、组合配置与再平衡规则

### 10.1 股债配置基准（第4章）

格雷厄姆推荐的基本配置框架：

```
基准配置：股票 50% : 债券（现金）50%

动态调整规则：
- 市场被高估时（整体PE高）：股票降至 25%，债券升至 75%
- 市场被低估时（整体PE低）：股票升至 75%，债券降至 25%
- 永远不要将股票比例降至 25% 以下，也不要超过 75%
```

### 10.2 个股集中度控制

| 投资者类型 | 建议持股数量 | 单只上限 |
|-----------|------------|---------|
| 防御型 | 10~30 只（或直接指数基金） | 不超过组合的 10% |
| 积极型 | 10~20 只（高度聚焦） | 不超过组合的 15% |

### 10.3 再平衡操作规则

- **触发条件**：股票比例偏离目标超过 ±5%
- **操作频率**：每年至少执行一次再平衡
- **再平衡方式**：卖出超配资产，买入低配资产（税费考虑后执行）

### 10.4 防御型投资者的指数基金方案

## 十一、选股检查清单（一页纸版）

使用方法：**逐项打勾，全部通过才考虑买入**

### 📋 基本面检查

```
【规模与稳定性】
□ 市值 ≥ 100亿（A股）/ 大型蓝筹（港股）
□ 上市时间 ≥ 5年（有足够财务历史）
□ 主营业务清晰，非概念炒作

【盈利能力】
□ 近5年每年盈利，无亏损年份
□ 扣非净利润 > 净利润的 80%（排除非经常性收益依赖）
□ 近5年EPS整体趋势向上或稳定
□ ROE ≥ 10%（近3年均值）

【财务健康度】
□ 流动比率 ≥ 2.0
□ 资产负债率 ≤ 50%（金融行业除外）
□ 经营性现金流持续为正
□ 自由现金流（FCF）为正

【分红记录】
□ 近5年持续分红，无中断
□ 分红率（分红/净利润）≥ 30%
□ 不存在借债分红的情况
```

### 📋 估值检查

```
【PE估值】
□ 当前PE ≤ 15（以三年平均EPS计算）
□ PE处于该股票历史估值的较低水平（历史分位 < 40%）

【PB估值】
□ 当前PB ≤ 1.5
□ PE × PB ≤ 22.5

【安全边际】
□ 内在价值估算（格雷厄姆公式）> 当前股价 × 1.3（即股价 < 内在价值的 77%）
□ 相比同行业可比公司，估值更低或相当
```

### 📋 风险检查

```
【排除项（有任何一项则否决）】
□ 不是新上市股票（上市 < 1年）
□ 不是当前市场热门主题概念股
□ 无重大未决诉讼或监管调查
□ 控股股东无大规模质押（质押率 < 50%）
□ 管理层无近期大额减持（6个月内）
□ 无财务数据异常（应收账款/营收比持续升高）
```

### 📋 操作纪律

```
【买入前确认】
□ 该股票符合我的投资类型（防御型/积极型）
□ 买入资金是不需要在3年内动用的闲置资金
□ 买入后即使股价继续下跌30%，我不会恐慌卖出
□ 已设定止盈目标：达到内在价值时评估是否卖出

【仓位控制】
□ 单只股票占总仓位 ≤ 10%（防御型）/ 15%（积极型）
□ 买入后股票总仓位 ≤ 组合上限（75%）
```

## 十二、A股 / 港股适配说明

### 12.1 A股特殊性

| 因素 | 影响 | 应对策略 |
|------|------|---------|
| **政策驱动** | 行业景气受政策影响大，盈利预测难度高 | 优选政策敏感性低的行业（消费、医疗） |
| **退市制度不完善** | 垃圾股长期存在，ST股不代表便宜 | 严格排除亏损股、ST股 |
| **散户主导** | 市场波动更剧烈，情绪周期更明显 | 波动即机会，坚守价值标准 |
| **会计准则差异** | 部分非经常性损益入表方式特殊 | 重点看扣非净利润 |
| **国企特殊性** | 部分国企有政策性任务，ROE偏低但分红稳定 | 国企用股息率作为补充估值指标 |

**A股国企补充估值标准**：
```
股息率（年度股息 ÷ 股价）≥ 4%（参考十年期国债收益率 + 2%）
即使PE/PB偏高，股息率达标也有一定安全垫
```

### 12.2 港股特殊性

| 因素 | 影响 | 应对策略 |
|------|------|---------|
| **流动性风险** | 中小港股流动性极差 | 只投流动性充足的个股（日均成交 > 500万港元） |
| **港元汇率** | 与美元挂钩，汇率稳定 | 汇率风险可控 |
| **估值折让** | 港股长期比A股便宜（AH溢价） | AH股优先买港股 |
| **做空机制** | 存在机构做空风险 | 财务透明度高的大市值股优先 |
| **分红税** | 内地投资者持有港股需缴纳分红税（20%） | 将税后股息率纳入估值 |

### 12.3 两地市场的行业偏好

**A股推荐参考行业**（适合价值投资）：
- 银行（高股息，低PB）
- 白酒/消费品龙头（强定价权，持续分红）
- 公用事业（稳定现金流）
- 医药（需甄别仿制药与创新药）

**港股推荐参考行业**（适合价值投资）：
- 内资银行H股（估值低于A股，股息率高）
- 香港本地公用事业（电力、燃气）
- 大型互联网公司（经历估值大幅回落后）
- REITs类（稳定分红，通胀对冲）
