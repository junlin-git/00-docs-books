# 巴菲特致股东的信——1992年（第01章：1992 Annual Letter，签署 1993-03-01）｜详细结构化总结

> **这封信的地位**：1992年是巴菲特思想"成熟期定音"的一年——它首次把**价值与成长的对立**正式拆毁、给出**DCF本体论**的最清晰表述、引入**伯克希尔 vs S&P 500对比表**（此后年年延续），并用会计商誉/经济商誉/透视盈余把"账面价值为何低估内在价值"讲透。

---

## 0. 仪表盘：20.3% 的背后在说什么

| 指标 | 数值 | 读法 |
|------|------|------|
| **每股账面价值增长** | **+20.3%**（S&P 500含股息 +7.6%） | 好年，但强调不平稳 |
| **28年（1965→1992）BV CAGR** | **23.6%**（$19 → $7,745/股） | 长期机器验证 |
| **年内净资产增加** | **$1.52B** | >98%来自经营收益+证券增值，极小部分来自新股 |
| **年末流通股** | **1,152,547股** | 1964/10/1为1,137,778股——**28年几乎不稀释** |
| **目标** | 每股内在价值年化 **+15%**（BV是保守但有用的proxy） | 明确"不可能平滑实现" |

> 关键开场白：**"我们发行新股的铁律——只有收到≥付出的价值才发。"**  
> 并用一个自嘲的"银行并购丑闻式笑话"来说明违背这条原则的代价——管理层" visibly in heat"时，对方老板开出"估值收购方净值两倍"的条件，还附加一句：**"合并完成后你答应我——永远别再做这么蠢的交易。"**

## 1. 首次亮出的"伯克希尔 vs S&P 500"对比表——与读表的三个警告

1992年起，信的"对面页"固定放置年度**每股净值变动 vs S&P 500总回报**对照，并形成持续至今的传统。他给三条阅读纪律：

| # | 警告 | 含义 |
|---|------|------|
| ① | 伯克希尔旗下**大量运营业务的盈利不受股市估值影响**（纺织曾拖累、现被保险+糖果+报纸+银行替代） | 表只反映"净值标记"侧，不全貌 |
| ② | 因税负结构差异，**税前S&P与伯克希尔税后不可直接等同比较** | 不要拿苹果的税后比橙子的税前 |
| ③ | 伯克希尔的**资本基数持续膨胀**→未来相对S&P的优势必然被数学压缩 | 别把历史α当永久保证 |

**隐含结论**：这张表是透明度工具，不是吹牛工具——它同时预告了"未来超额会收窄"。

## 2. 全信哲学核心：【价值与成长的统一】——拆掉投资界最有害的一堵墙

### 2.1 他先承认自己也曾糊涂
> "必须承认，几年前我也持这种糊涂看法"——即把"价值投资"与"成长投资"当作对立阵营选边站。

### 2.2 三个递进命题（把价值投资从"低PE教派"解放出来）

#### 命题A：「成长是价值计算的变量之一，不是独立阵营」
- 成长对价值的影响 **可正、可负、可零**
- 例（负）：一家资本回报率 **5%** 的纺织厂，再成长、再扩产＝**把更多的钱锁进低回报窖藏→毁灭价值**
- 例（正）：一家资本回报率 **25%** 的轻资产品牌企业，成长＝**每一美元再投入产生 >1 美元长期市值→创造价值**

> **一句话**：不是"买成长"或"买价值"二选一，而是——**这桩生意的增量资本能不能以高回报再投入？**能＝成长是加分项；不能＝成长是减值项。

#### 命题B：「"价值投资"一词本身是冗余的」
> 真投资＝支付≤你算出的价值；付超了还买，叫**投机**（"不违法、不缺德，但不会让荷包鼓起来"）。

所以他根本不认同"我是价值派所以我不买优质高PE公司"这种标签逻辑。

#### 命题C：估值本体论——DCF（引用约翰·伯尔·威廉姆斯）
> **任何资产的价值＝其存续期内未来现金流入/流出的期望值，以适当利率折现。**

- 债券：票息/到期日相对明确定义
- 股票：你要**自己判断未来的"票息"**——而管理层品质对股票"票息"的影响远大于对债券

**由此推出他对"好生意"的定义**（此后三十年不变）：

| 层级 | 特征 |
|------|------|
| **最理想的生意** | 能持续把**大量增量资本**以**很高回报率**投进去（高ROC→复利机器） |
| **次理想的生意** | 高回报但**不需要**大量资本（See's：赚很多、再投资需求极小＝现金喷泉） |
| **最差的生意** | 回报低、且**必须**不断砸资本维持地位（ commodity式重资产） |

## 3. 三个概念铁三角：内在价值 / 账面价值 / 市价（他最系统地拆过的一次）

| 概念 | 是什么 | 与另外俩的关系 |
|------|--------|----------------|
| **账面价值（Book Value）** | 会计净资产＝历史成本口径的"投入记录" | 对伯克希尔而言是**保守下限proxy**，但≠内在价值；优质子公司经济商誉不出现/被摊销压低 |
| **内在价值（Intrinsic Value）** | 存续期内所有现金提取的**现值** | 是目标函数；算不精确（巴菲特只算范围），但必须朝它配置 |
| **市场价格（Market Price）** | 供需/情绪决定的每日报价 | 长期回归内在价值；短期可远高于或远低于 |

> 那句经典林肯笑话的落点就在这里：  
> **"狗叫尾巴为腿——有几条腿？四条，因为叫尾巴为腿不改事实。"**  
> 同理：**会计把商誉摊销、把留存收益藏起来、把期权不记为费用——这些"改名"不改经济实质。**

## 4. 透视盈余（Look-Through Earnings）——让"隐藏的一半"现形

### 4.1 问题
按GAAP：持股 <20% 时，只有**收到股利**进利润表；被投公司的**留存收益**（哪怕高效再投资）对伯克希尔报表"毫无踪迹"。

### 4.2 解法：透视盈余
> **透视盈余 ＝ 伯克希尔报告营业利润 ＋ 应占被投资公司留存经营收益 － 相应税款**

- 1992年透视盈余 ≈ **$604 million**
- 15%年化内在价值增长目标 ⇒ 透视盈余到2000年需 >$1.8B（量化锚）

**巴菲特的潜规则**：判断"分红 vs 留存"的唯一标准是——  
**留存的一美元，能不能产生 > 一美元长期市值？**如果能＝不分红更好；如果不能＝该分/该换管理层。

## 5. 保险：浮存金成本表（1967–1992）＋安德鲁飓风——把"赌场"与"承保纪律"分开

### 5.1 26年总账
- 从1967涉足保险业到1992，**21 out of 26年**浮存金成本低于美国长期国债收益率 → 保险不是"主营赔钱靠投资补"，而是**低成本/负成本融资引擎**
- 1992展示的年度表（千$）把：浮存金平均额 / 累计承保利润或亏损 / 隐含"成本%" 摊开给你看

### 5.2 安德鲁飓风（1992）＝压力测试，不是失败
- 安德鲁造成行业巨损；伯克希尔承担约 **$125M** 损失（主要来自超级巨灾账簿）
- 巴菲特的解读：这基本抵消当年超巨灾的"已赚 premium"，但未伤筋骨——**验证了财务实力 + 风险定价纪律，而非"赌运"**
- 重申超巨灾业务的**极端波动性**：利润年度间会大幅摆动；会计上不提前认"未实现好年景利润"——保守到近乎"只认已发生"

### 5.3 对保险的信条（这年再次钉死）
> 保险的价值不在"承保+投资双位数魔术"，而在：  
> **浮存金是否以合理纪律获得 + 是否不被杠杆/贪婪炸掉**。

## 6. 会计战场：商誉/期权/退休福利——"叫尾巴为腿不行"

### 6.1 会计商誉（GAAP Goodwill）vs 经济商誉（Economic Goodwill）
| | 会计商誉 | 经济商誉 |
|---|---------|---------|
| 来源 | 收购价－可辨认有形资产公允值 | 持久竞争优势带来的超额回报能力（品牌/网络/转换成本/许可…） |
| 报表轨迹 | **逐年摊销↓**（机械减少） | **可能随时间↑**（See's的品牌壁垒越用越强） |
| 与BV关系 | 压低BV | BV不反映它 ⇒ BV更低于IV |

- 这也是为什么伯克希尔BV越来越**低估**真IV：赚大钱的轻资产业务，经济商誉巨大，但会计上要么没出现、要么在摊销里被"默默抹掉"。

### 6.2 股票期权必须记作费用（最锋利的会计道德段落）
> **"如果期权不是薪酬，那它是什么？如果薪酬不是费用，那它是什么？如果费用不应进利润表——它该去哪？"**

他逐一拆反对意见（难估值/初创企业伤不起/价外=无成本/非现金）：
- 给出"以期权付保险费→我看你敢不敢把保险成本不计入"的反讽
- 结论：**会计职业在期权问题上妥协＝该感到羞耻**，管理层 credibility 在此暴露底色

### 6.3 退休后福利负债
- 赞许新准则要求确认退休后医疗福利负债（不再"眼不见心不烦"把债务藏表外）
- 点名旧做法让liability被严重低估→最终股东埋单

## 7. 企业运营与文化：为什么"没有战略规划部"是一种战略

| 事实 | 数字/描述 |
|------|-----------|
| 公司支出 | **$4.2M**（<1%营业利润；<0.5%综合收益） |
| 无 | 无法律/人事/PR/IR/战略规划部门；无警卫/司机/信使；除Verne外不聘顾问 |
| 推崇的榜样 | Walmart / Nucor / Dover / GEICO / KSI / Price |
| B太太（99岁） | 出售建筑给NFM + 签竞业禁止，继续联手——商业双赢+人情深度 |
| 老将 | Ralph Schey (Scott Fetzer)、B太太等"超龄在岗"——经验能力优先 |
| 退休致敬 | Gladys Kaiser & Verne McKenzie |

> 潜台词：**低成本运营不是抠门，是"把资本配置的带宽留给懂生意的人而不是官僚层级"。**

## 8. 资本动作与持仓动向（1992当年）
- 适度增持 **Guinness / Wells Fargo**；Freddie Mac 持仓翻倍；新建 **General Dynamics ≈14%**
- 继续强调：持仓**集中**于少数理解的高质量企业；波动来自（1）股市震荡 （2）持仓集中 （3）超巨灾决策——**接受并欢迎这种波动**，因其是长期超额的前提
- 可转换债赎回（1993/1/4）：大部分转股的转换价 **$11,719/股**，全年仅增发 **6,106股**→几乎零稀释

## 9. 把全信压成一张"可复用思维框架"
```
┌─ I. 估值本体 ─────────────────────────────────────────────┐
│ Value = Σ [CF(t) / (1+r)^t] ← DCF，不是公式崇拜 │
│ 成长=变量之一：符号取决于 Δ资本 → ROC vs 要求回报 │
│ "价值投资"不是低PE标签；是"价≤算出的价值" │
├─ II. 三值校准 ─────────────────────────────────────────────┤
│ Market Price（情绪） │
│ ↓ 长期回归 │
│ Intrinsic Value（DCF现值·范围·要靠商业判断） │
│ ↑ 保守近似 │
│ Book Value（历史成本·会计·低估优质企业的IV） │
├─ III. 真实盈利 = 透视盈余 ──────────────────────────────────┤
│ 报告利润 + 应占被投留存(税后) │
│ 分红与否看：留存$1 → 能否产 >$1长期市值 │
├─ IV. 保险判据 ─────────────────────────────────────────────┤
│ 浮存金成本 vs 无风险收益；承保纪律>规模；波动率公开说清 │
├─ V. 会计诚实测试 ──────────────────────────────────────────┤
│ 期权=薪酬=费用；经济商誉≠会计商誉；退休负债不藏表外 │
│ Lincoln法则：叫尾巴为腿不改事实 │
├─ VI. 资本动作铁律 ─────────────────────────────────────────┤
│ 不发新股除非收到≥价值；集中持仓；接受波动；无官僚加法 │
└─────────────────────────────────────────────────────────────┘
```

## 10. 一句话收束

> **1992年这封信的终局贡献，不是告诉你"今年又涨20%"——而是把投资从标签战争（价值vs成长/低PEvs高PE）拉回唯一底盘：未来现金流的确定性×折现×增量资本回报；同时用透视盈余、经济商誉、LV vs BV vs Price三层校准和一个林肯笑话，把"会计数字只是起点不是终点"刻进你的操作系统。**  
> 它之所以被后世反复引用，是因为它不教你选股技巧，而是给你一套**防自欺的估值语言**。
