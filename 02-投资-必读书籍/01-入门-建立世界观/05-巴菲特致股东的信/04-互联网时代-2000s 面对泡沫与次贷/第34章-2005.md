## 1. 开篇成绩单：6.4% 背后的真实分量

| 指标 | 数值 |
|------|------|
| 净资产增加 | **$5.6 billion** |
| 每股账面价值增幅（A/B股） | **+6.4%** |
| 41年跨度（1965→2005） | $19.46 → **$59,377** |
| 年复合增长率 | **21.5%** |

### 先把话说透

> "2005年伯克希尔的表现**相当不错（a decent year）**。"

注意措辞的分寸——6.4%在41年的序列里是**偏低**的（多数年份15%~30%+），但巴菲特不拿它当失利：

- **$5.6B绝对增量本身约等于半个大型S&P公司的总市值**——规模越大，"百分比"越不好看但"绝对复利机器"越恐怖
- 真正拉低数字的不是经营差，而是**卡特里娜等飓风直接吞掉约$3.4B税前利润**
- 没有巨灾的正常运营层面：大多数子公司表现强劲，并购推进积极

他紧接着做了一件典型的事——**不等你问"会不会更差"，先把最坏的来源指出来**：

> 飓风损失 = **$2.5B（卡特里娜）+ $0.9B（丽塔+威尔玛）= ~$3.4B**  
> 整个保险行业创纪录的血洗年。但伯克希尔**整体保险板块仍为正**，靠的是承保纪律+GEICO的运营奇迹+多元分散。

## 2. 飓风三连击：34亿美元的自然灾害压力测试

### 2.1 数字之外：这也是一次"商业模式测验"

卡特里娜（8月29日）是新奥尔良灾难级事件，保险业赔付超千亿美元。巴菲特的态度值得细读：

- **不怨天**——气候/灾害频率是否属于"新常态"（global warming相关）他说自己不知道，但**必须按最坏情况定价**
- **不松纪律**——巨灾年之后最危险的情绪是"为了抢回保费份额放宽核保标准"，他明确说伯克希尔不会
- **再保险/巨灾超额层的结构**是浮存金安全的真正防线：伯克希尔的资本厚度允许它承担别人不能承担的层，但每一层都有定价底线

### 2.2 保险板块的内部分化

| 板块 | 2005处境 |
|------|---------|
| **GEICO**（直保车险） | ⭐ **亮点**：保单量↑、成本↓、承保盈利、份额抢 |
| **NICO / 国民赔偿**（特殊险/再保） | 承保纪律坚守，浮存金继续增长 |
| **通用再保险（Gen Re）** | ⚠️ 仍在消化前期衍生品/巨灾组合的整改阵痛 |
| **其他产险** | 受飓风冲击显著；MedPro（医疗事故险）新收购入列 |

核心信息：**浮存金≈$49B**，全年承保成本仍接近**零（甚至略负）**——意思是拿着别人$490亿的钱投资，资金成本基本为零。

## 3. 基石命题：内在价值 ≠ 账面价值——为什么68家公司让估值变难也变强

这一段是2005信的**哲学锚点**，和1996/1997一脉相承但更进一层：

> **"我写这份报告的目的，是为各位提供估算伯克希尔内在价值所需的信息。之所以说'估算'，是因为内在价值的计算虽至关重要，却不可避免地不够精确，且常常大错特错。"**[3,9](@ref)

### 三个层次拆开

| 层次 | 他说什么 | 为什么重要 |
|------|---------|-----------|
| **① 账面价值只是记账数** | 历史成本法/GAAP规则产物，不反映未来现金流折现 | 防止你把"$59,377/股"当"公司值$59,377/股" |
| **② 伯克希尔比大多数公司"可估"一点** | 多种相对稳定收益来源 + 巨大流动性 + 极低负债 → 现金流的可预测性较高 | 不是盲目自信，是说"我们的不确定性主要在经营层面而非财务爆破层面" |
| **③ 但68种业务让合并报表失效** | 纺织厂时代一张纸能估；今天68家特性完全不同的企业+庞大投资组合 → 你不可能只看合并报表得出明智估值 | 所以他**把业务归为四类分别讨论**（这是方法论升级） |

### 母公司价值的追问（极其锋利）

> "伯克希尔作为母公司究竟给各子公司带来了什么？你们股东如果**直接**持有这68家企业的股票，会不会更好？——这些问题**你们得自己回答**。"

这不是客气。这是把"控股公司折价 vs. 加成"的终极考题扔给股东：伯克希尔的存在理由是**配置资本优于分散个人持有**，如果这个理由不成立，结构就该变。

## 4. 双栏仪表盘：每股投资 vs 每股运营收益

他更新那张贯穿90年代信件的**两张核心表**（单位：美元/股）：

### 表A：每股投资额（Per-Share Investments）
| 年度 | 每股投资额 |
|------|-----------|
| 1965 | $4 |
| 1975 | $159 |
| 1985 | $2,407 |
| 1995 | $21,817 |
| **2005** | **$74,129** |
| 1965-2005 CAGR | **28.0%** |
| 1995-2005 CAGR | **13.0%** |

### 表B：每股税前运营利润（Per-Share Pre-Tax Earnings，非保险投资部位）
| 年度 | 每股利润 |
|------|---------|
| 1965 | $4 |
| 1975 | $4（负数实际） |
| 1985 | $52 |
| 1995 | $175 |
| **2005** | **$2,441** |
| 1965-2005 CAGR | **17.2%** |
| 1995-2005 CAGR | **30.2%** |

### 这组对比讲了两件事

1. **每股运营利润近十年增速（30.2%）>> 每股投资增速（13%）** → 伯克希尔正在从"投资控股公司"转型为"**运营企业帝国 + 投资仓位**"双引擎。收购驱动的运营收益越来越成为主发动机。
2. 他提醒：**基期选择会扭曲一切**——1965年盈利异常地好（高于此前10年中的9年），所以用1965当分母不会夸大，但原则是"永远怀疑增长率的起止选择"。

然后是那段著名的**老夫妇结婚50周年笑话**：

> 妻子在烛光音乐红酒刺激下提议上楼亲热，丈夫纠结半天答："**二选一我还行，两个都要可不行。**"  
> ——比喻：希望每股投资↑ **和** 每股运营收益↑ 双增，但别指望它们是轻松兼容的（尤其当运营并购消耗投资现金时）。

## 5. 四大业务集群：把68家公司装进4个抽屉

2005信里**首次系统化**把伯克希尔拆成四类（此后多年沿用此框架）：

| # | 集群名称 | 包含代表 | 本质 |
|---|---------|---------|------|
| **Ⅰ** | **保险及相关金融（Insurance Operations）** | GEICO / NICO / Gen Re / MedPro等 | 承保+浮存金引擎 |
| **Ⅱ** | **公用事业与能源（Utilities and Energy）** | MidAmerican Energy / PacifiCorp（拟收购） | 受监管稳定现金流 |
| **Ⅲ** | **制造/零售/服务（Manufacturing, Retailing, and Service）** | See's / Nebraska Furniture / Shaw / Clayton Homes / Forest River / Fechheimer… | 运营现金流牛 |
| **Ⅳ** | **金融类业务（Finance-Type）** | XTRA（租赁）/ CORT（家具租赁）/… | 特定融资/租赁 |

为什么要这么分？
- 每个集群的**风险属性、资本需求、回报规律**完全不同
- 合并在一起只会糊成一团"总利润"
- 分开看，你能判断：哪块在靠特许权赚钱、哪块在靠资本密集度赚钱、哪块的浮存金是"甜水"哪块是"盐水"

## 6. GEICO：飓风年里的生产效率奇迹

这是2005信里情感浓度最高的运营段落：

### 数字
- **两年内生产效率↑ 32%**
- 保单数量 **↑ 26%**
- 员工数量 **↓ 4%**
- 市场份额继续扩张，品牌强化

> "当你以如此戏剧性的方式降低单位成本，你就能给客户让出更多价值。如果你2006年喜得龙子/龙孙，**给他取名叫Tony**。"（指CEO Tony Nicely）

### 背后逻辑链条

直保模式的护城河 = 低成本运营结构 → 能给最低价 → 获客成本低 → 更多好风险 → 数据池更大 → 定价更准 → 成本更低（正循环）

巴菲特用GEICO证明：最厉害的保险竞争力不是"敢赔"，而是**运营效率本身即壁垒**——而且效率提升不靠压榨（员工士气/服务质量反而升），靠系统、IT、流程、品牌直销的复合杠杆。

## 7. 并购年：5起交易、0股新股——"熟人链"与两页传真的艺术

### 总原则先钉死

> "这些交易中**没有一个涉及发行伯克希尔股票**。这一点至关重要却常被忽略：当管理层骄傲地宣布'以股收购'另一家公司时，收购方股东同时也在出售自己拥有的一切的**一部分**。"[1,11](@ref)

他坦承自己也做过这类稀释交易——"总的来说，我的行为让你付出了代价。" 所以今天铁律：**现金收购或等价物交换，不拿股东股权做收购货币**。

### 逐个看五大收购

| # | 标的 | 完成时间 | 一句话 |
|---|------|---------|--------|
| ① | **Medical Protective Corp.（MedPro）** | 2005/6/30 | 106年历史的医疗事故险；巴菲特称之为"许多保险公司的坟墓"，但MedPro靠承保纪律+伯克希尔财务实力（医生不怕你破产了）可行 |
| ② | **Forest River（森林之河）** | 2005/8/31 | 年销售~$16亿房车/船舶制造商；巴菲特收到一份**2页传真**→要数据→**一周内握手成交**；创始人Pete Liegl曾被PE买走后被指手画脚搞垮、回购自救→巴菲特承诺"我绝不告诉你怎么经营" |
| ③ | **Business Wire（美通社/美国商业资讯）** | 2005年底协议 | Cathy Baron Tamraz读了WSJ写伯克希尔收购风格的文章后主动来信；严格管理、砍不必要开支、砸钱搞技术——典型的"伯克希尔式文化DNA" |
| ④ | **Applied Underwriters（81%）** | 2005/12协议 | 小企业薪资服务+工伤险；Sid Ferenc/Steve Menzies从12人做起→经奥马哈基地扩张；保留19%给自己 |
| ⑤ | **PacifiCorp（via MidAmerican Energy）** | 签协议待监管批 | 西部6州电力公司→把公用事业集群做大 |

### 收购哲学的浓缩

- **不靠投行超市扫货**，靠"已验证的人品/运营记录→引荐链→电话→握手"
- **两页传真就够了**的前提是：几十年积累的"什么算好生意"模板已在脑子里——你缺的不是更多尽调文件，而是**判断力**
- 创始人/CEO留任+留股权+总部零干预=文化不打碎

## 8. 衍生品的清理：通用再保险教训的延续

信中/同期年报部分继续交代了Gen Re（通用再保险）衍生品组合的出清进程：

- 1998年收购Gen Re时，其底下有一堆**General Re Securities**的衍生品合约（超20,000份），复杂、不透明、超出能力圈
- 巴菲特花了数年+投入超$4亿成本逐步平仓/缩减，到2005年已降到**不足1,000份优质/可控标的**
- 核心教训：**永远不赚你看不懂的钱；复杂≠聪明，简单≠简陋**

## 9. 宏观警报：Gotrocks家族寓言 + 贸易赤字 + 外汇对冲

这是2005信里**最"非典型"但最被后世引用**的长段落之一。

### 9.1 Gotrocks家族寓言（The Gotrocks Family）

巴菲特用一个虚构的"超级富有的Gotrocks家族"来比喻美国：

- 最初家族成员直接持有企业股权→股息/增值流向他们→所有人富裕
- 后来他们雇了**"帮手"（helpers）**：基金经理、顾问、投行家、私募老板、活跃交易者…
- 帮手们互相交易、收费、抽佣→**家族总资产没变（甚至因费用缩水）**，但财富被重新分配——家族成员变穷，帮手变富
- 家族成员的反应？**"我们需要更多帮手！请更贵的顾问来打败原来的顾问！"**

翻译：美国资本市场里，**投资费用（手续费/管理费/换手成本）是"看不见的税"**，长期复利下吃掉的是普通人的实际财富份额。巴菲特借此为**指数基金**再背书——减少帮手层级，让你的钱直接挂钩企业产出。

### 9.2 贸易赤字警告

- 美国经常账户赤字持续扩大→必须靠**外资净流入**融资→实质是"美国人把资产卖给外国人换消费品"
- 长期趋势不改→美国可能从"所有者社会"滑向某种形式的**"佃农经济"**——未来一代要向外国债主/资产持有者付"年贡"
- 所以伯克希尔**首次大规模持有外汇头寸**（约$214亿外汇远期/存款），不是看空美国，而是**对冲美元购买力结构性下滑的财务风险**

> 这段的精妙处在于：他既爱美国企业（持股根植于此），又诚实地告诉你"国家层面的收支失衡不是可以忽略的外部性"。

## 10. 公司治理底线：独立董事 & 期权费用化

### 独立董事重定义

> 真正"独立"的董事 = **自身财富与股东高度绑定**（大量持股、自掏腰包买入、不靠董事津贴过日子）  
> 靠$10万/年津贴生活的"独立董事"往往缺乏真正挑战管理层的激励——因为挑战可能让自己丢席位。

### 期权费用化

强烈主张：**股票期权是薪酬，必须作为费用从利润中扣除**。反对费用化的人多半是想**粉饰报表、隐藏真实薪酬成本**。伯克希尔早已把期权成本计入。
