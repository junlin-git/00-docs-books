# 巴菲特致股东的信 — 1970（第01章·起始篇）
> **文件**：1970年4月3日 致伯克希尔·哈撒韦全体股东（April 3, 1970）  
> **对应会计年度**：FY1969（1969.1.1–1969.12.31），信写于1970年春寄出  
> **身份标志**：这是**巴菲特以伯克希尔董事长身份写的第一封致股东信**，宣告基金经理念终结、工业企业转型正式成为"多元运营控股公司"元年  
> **同源补充**：1971年3月15日信（March 15, 1971）覆盖**日历1970**运营细节，两封合读才是完整"1970视角"

---

## 0. 这一封为什么是整部《致股东信》的"第01章"——历史定位

| 维度 | 含义 |
|------|------|
| **身份转折** | 1969年底巴菲特刚完成**巴菲特合伙有限公司（BPL）** 的清算分配，把纺织残壳+保险/银行控制权转换成一家**运营控股公司**的治理语境；从此"信"不再写给基金LP，而是写给**公司全体股东** |
| **叙事原点** | 全文第一句定调战略："四年前（≈1965接手后）就承诺把资本从纯纺织转出→多元运营"——等于向股东正式宣告纺织的死刑缓期执行 |
| **EPS结构（1969财年）** | EPS **$8.07**（其中运营$4.41 + 已实现证券收益等$3.66）；1970年（FY结尾）运营EPS **$4.38**——股东第一次看到"纯经营收益"和"变卖证券筹资"分列 |
| **里程碑** | 纺织占用大量资本 ROE <5%；整体 ROE **>10%**——多元化从理念变成数字证明 |

> **一句话读全信**：这不是业绩炫耀，而是**转型审计报告**——告诉股东：旧引擎（纺织）在耗电、新引擎（保险+银行）已点火、有价证券已全部清仓变现、未来只买整家企业不炒股票。

## 1. 开篇战略声明——全文的脊梁

> **"四年前你们的管理层承诺：如果资本继续只投在纺织业，就不可能发展出更强大、更稳定的盈利能力。此计划的资金暂时放在有价证券里，等待符合我们投资和管理标准的营运企业收购。这一政策已被证明相当成功——尤其对比那些面对完全不够的回报仍继续往纺织扩产的公司。"**

### 这句话拆开三层

① 承认纺织 = 回报黑洞（<5% on capital employed）
② 解释"为什么持有有价证券"= 不是炒股，是收购前的过渡仓
③ 亮结果：已完成两大运营企业收购 → 整体ROE >10%
→ 顺便埋下一句：已两年内有价证券全部清仓，税后利润>$5 million
"我们预期不再购买有价证券，但寻找理想收购持续进行"

> **这就是芒格后来总结的"坐等投资法"的公司版**：不瞎投、不等"市场时机"、等**可识别的好企业**闸门打开。

## 2. 三大业务体检——逐个拆解（1970信 = FY1969数据；1971:3/15信补日历1970细节）

---

### 2.1 纺织业务：承认失败但不甩锅——对"努力"的诚实背书

#### 数字与事实（两封信合读）
| 指标 | 状况 |
|------|------|
| 销售额 | 1969 vs 1968 **↓≈12%**（男装衬里 + 家居织物双降） |
| 利润 | 小幅↑ 但含关闭Box Loom部门的一次性损失；基本**收支平衡附近** |
| 资本回报率 | **<5%**（纺织占用那块资本）——而整体ROE >10% |
| 1970行业面（写入1971:3/15信） | 衰退更烈：需求缺失→被迫减产→两周停工→库存仍偏高→前景"更低利润" |

#### 巴菲特的原话态度（关键段落）

> "由Ken Chace领导的这部门管理层和劳工表现出的**努力、态度、进取心，与我们赚钱多得多的业务同仁毫无二致**。但他们过去一年是**逆强潮游泳**，写这封信时潮仍在。**（swimming against a strong tide）**"

#### 框架含义（这是整部信最痛的一段）
- 他不把纺织差归因于"管理层不行"——恰恰相反，**他明确保护管理者的尊严**
- 他的结论不是"换人能救"，而是：**坏行业 + 好管理 = 仍差**（后来1985年关停的前置伏笔）
- 但当下策略是：**收缩战线、砍亏损部门、压库存、集中到历史/预测"尚可"的细分，榨出稳定就业+现金流**

> 可迁移原则：**别用烂生意考验好人——要么改生意（定价权/产品升级），要么有序退出。**

---

### 2.2 保险业务：整封信真正的"主角"——浮存金引擎上线

#### 1969财年（1970:4/3信核心）
| 项目 | 记录 |
|------|------|
| 负责人 | **Jack Ringwalt**（国民赔偿公司/National Indemnity灵魂人物） |
| 行业背景 | 火灾意外险行业普遍**承保亏损**的年份 |
| 伯克夏保险子公司 | **承保利润**（Adj. underwriting profit）——Ringwalt的铁律："为利润承保，不是为规模" |
| 新部门 | 保证保险 Surety dept（小但进度OK）；再保险 division 启动（George Young）；加州工偿进入LA；"home-state"雏形（内布拉斯加 Cornhusker Casualty 1970初成立） |

#### 1970日历（1971:3/15信补记）
| 补充 |
|------|
| 传统业务量激增（常规车险市场收缩→非传统承保人接波）→ 承保综合比率升至≈100%（临界） |
| 保证保险/承包商保证金 → **重大承保亏损** → 砍到杂项保证金领域（volume↓但盼利润） |
| Home-state 模式开局强劲："大公司能力+小公司灵活+顶级代理" |

#### 巴菲特的定性（极关键）
> Ringwalt **坚持承保利润原则**——业内常说，极少做到。  
> "我们的历史是：当标准市场容量/承保出问题时，我们以波动方式接收量增。"

这半句道出保险商业模式的天机：
- 别人亏→退出→你接客→量涨
- 但你**必须坚持underwriting discipline**，否则量=炸弹
- 浮存金成本=综合比率 **<100%** → 等于**负成本/零成本杠杆**

---

### 2.3 银行业务：伊利诺伊国民银行——"沉默的印钞机"

#### 事实（1969–1970）
- **1969年收购 97.7%**（罗克福德 Illinois National Bank & Trust）
- 创始人 **Eugene Abegg**（1931年25万净资产起步→1969年1700万权益+1亿存款）
- 1970：Abegg在**存款不增**前提下，仍超越1969辉煌——净经营收益（不计证券升值）>**2%×平均存款**，流动性高于行业均

#### 但——致命外部变量
> **1970年末《银行控股公司法修正案》通过**：不允许实业公司控股银行 → 伯克希尔约**10年**窗口处理银行持股（最终1980年分拆/分配）

巴菲特的评价：
> "我们的银行业务在**安全性和盈利能力**上都是卓越的……但政府规则迫使结构性变化。"

> 潜台词：最好的资产不一定能留最久——**监管风险是商业模式之外的硬约束**。

## 3. 数字总账——ROE框架与"清仓证券"信号

### 3.1 核心比率（1969财年 / FYE）
| 指标 | 数值 |
|------|------|
| 整体平均股东权益回报率 | **>10%** |
| 纺织占用资本的回报 | **<5%** |
| EPS 1969（含资本利得） | **$8.07** |
| EPS 1970（纯运营，$4.38 / 全运营） | 运营利润 ≈$4.6M；银行≈$2.6M+保险≈$2.0M；纺织进一步压出~$1.5M+资产出售还购债 |
| 有价证券清仓损益 | **>$5M 税后利润**（两年全清、筹措1969大收购） |

### 3.2 这句话的资本含义
> **"我们预期不再购买有价证券（marketable securities），但我们的收购搜寻继续。任何收购当然取决于能否获得适当融资。"**

翻译成白话：
- 伯克希尔的现金/浮存金 → 今后**只买整家企业**（控制权）
- 不复归为"证券组合 manager"角色
- 融资原则≈不依赖高杠杆/不追高利率时期借款（1970年代初正是滞胀+高利率环境）

## 5. 1971年3月15日信（补日历1970操作细节）——逐块骨架

> 这封是"续篇"，把1970日历年的分部运营写细：

### 纺织（1970日历）
- 男装衬里+家织销售**显著↓**→继续砍产→成本高+扰员工生活→库存仍高→**预计更低利润**
- 再强调 Ken Chace 团队"努力态度进取心=最赚部门同级"但**逆强潮**

### 保险（1970日历）
- 传统业务量**出色增长**（标准市场收缩→非标接波）→综合比率≈**100%**（临界）
- Ringwalt+Liesche"有能力决心恢复承保利润"
- 再保险（George Young）→进展大但要几年判
- 保证保险 → **重大亏损** → 缩到miscellaneous bond area（volume↓盼利润）
- Home-state（Cornhusker Casualty / 内布拉斯加）→开局强；计划扩"另一州"

### 银行（1970日历）
- Abegg在**存款未增**仍顶过1969标杆→净经营收益/存款 **>2%**；流动性>均
- 1970末 **Bank Holding Company Act修正案**→约10年处理窗口
- Bob Kline ↑ President (1971.1)；Abegg留 Chairman/CEO

### 总ROE（日历1970）
≈ **10%** 股东权益平均回报（纺织拖但保险+银行顶住）

## 6. 五条可迁移的硬教训（从这一章直接带走）

1. **"逆潮游泳"的诚实命名**：不要把行业结构性衰退伪装成"周期底部我们就扛过去"。巴菲特1965–1970的做法是——**收缩止血 + 转移资本 + 公开承认格局**，而非每季喊"马上反弹"。（最终1985年关停纺织是逻辑终点）

2. **清仓有价证券不是"投降"，是资本再部署纪律**：>$5M税后变现证明——**卖是为了买更好的**，不是因为看空市场。这是后来"坐等好球"的身体记忆。

3. **保险业务的全部魅力在一句话**：综合比率<100% → 浮存金=负/零成本杠杆 → 但守纪律比守规模难一百倍（1970已逼近100%→他知道红线在哪）。

4. **最好的资产也可能被规则杀死**：伊利诺伊国民银行是巴菲特生涯罕见的"被迫卖好孩子"——提醒：**商业模式分析必须叠 regulatory regime**。

5. **对"努力但亏钱的团队"的公开保护**：他在全公开文件中写 Ken Chace 团队"毫不逊色于赚钱部门同仁"——这是**声誉资本管理**：让市场/员工/供应商知道CEO分得清真伪，不拿管理者祭旗。

## 7. 一句话封底

> **1970这封"第01章"的本质：巴菲特第一次以控股公司董事长身份对账——不谈指数、不谈选股，只谈"三个生意分别是什么质量、资本回报多少、接下来钱往哪走"；整封信只有一件事在证明：伯克希尔从此是一个靠运营ROE活着的企业，不是靠股价活着的投资组合。**
