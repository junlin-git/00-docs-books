# 巴菲特致股东的信（1973财年）——详细结构化总结
**Berkshire Hathaway Inc. | 发布：1974-03-29（1973财政年度报告）**  
**收件人：To the Stockholders of Berkshire Hathaway Inc.**

---

## 0. 这封信在全书/全系列里的位置

这是巴菲特以 **Berkshire Hathaway 董事长**身份写给股东的正式年度汇报（不再是早期"合伙人信"格式）。  
1973年是伯克希尔从"新英格兰纺织烂摊子"转型为**多元控股平台（保险+银行+少量纺织+并购拼图）**的关键过渡年之一：保险浮存金引擎在跑、See's/Wesco/Blue Chip 拼图在整合、股价（及持仓市值）在1973–1974熊市里承压，但巴菲特用这封信把**业绩、会计选择、业务质地、以及面对浮亏的心态**一次钉牢。

---

## 1）总览：满意度 + 一个"好消息/提醒"结构

### 1.1 核心数字（经营/营业口径，不含证券损益）

| 指标 | 1973 | 对比/备注 |
|---|---|---|
| **营业利润 Operating earnings** | **$11,930,592** |  |
| **按期初股东权益回报率 ROE（beginning equity）** | **17.4%** |  |
| **每股营业利润 EPS（operating）** | **$12.18** | 1972: $11.43 ↑ |
| **上年 ROE** | 1972: **19.8%** | 1973 看似"满意"，但较巅峰回落 |

### 1.2 回落的原因（不是借口，是资本结构算术）

> **"盈利的增长，跟不上股东权益/资本基数的扩张。"**

- 伯克希尔在持续把留存利润与并购性资本堆进平台 → 分母变大 → 同样的增量利润会让ROE自然下行（除非找到更高回报的新增去向）。
- 巴菲特提前一年就警告过这种可能性——这次只是证实。
- 所以他的"满意度"不是拍胸脯吹牛，而是说：**这组数字反映的，恰恰是我们在把资本转到更好去处的路上。**

### 1.3 目标锚（别用峰值当基准）

> 管理层目标：长期资本回报率 **略高于美国工业/企业平均水平**，同时坚持**保守会计 + 保守债务政策**。  
> 1974展望预警：资本基数更大 → ROE **还可能再降一点**（把预期管理做在前）。

## 2）纺织业务：强周期里的"繁荣但受限"——以及一次重要的会计选择（LIFO）

### 2.1 经营现实：需求很强，但两头夹击

| 正面 | 负面（瓶颈/管制） |
|---|---|
| 1973全年纺织需求异常强劲 | **纤维短缺** → 织机产能无法充分拉满、运营更复杂 |
|  | 部分纤维价格飙升（成本端通胀） |
|  | **生活成本委员会（Cost of Living Council）价格管制**→ 成品提价空间被压住，无法跟某些不受同款限制/不同处境的对手同幅度提价 |

- 结果：利润相对于"投入资本"仍算合理，但低于"若按市场定价本可到位的利润"。
- 芒格式/巴氏式判断：**纺织天生强周期**；价格管制可能是"削峰"，但**填不了必然来的谷底**。

### 2.2 关键会计动作：改用 **LIFO（后进先出）** 存货计价

- 理由很硬：1973原材料价格异常上涨，且1974还可能延续 →  
  **FIFO会把"旧低价成本"配到当期收入，制造出存货'纸面利润'（inventory profit）**，把报表利润吹虚、夸大真实回报。
- LIFO的作用：让**最近（更高）成本**与当期收入匹配 → 更诚实的利润、更少"存货通胀假象"。
- 细节放到财报附注——但信里把**为什么这么做（经济含义）**讲透：保守、可比对、不被成本滞后误导。

> 这一段的潜台词：纺织未必是未来，但它仍在产生现金流；而且哪怕在"非核心"业务上，会计也要讲真话——别让cost flow粉饰基本面。

## 3）保险业务：伯克希尔的"资本配置主引擎"——交接棒、竞争压力、局部伤口

保险是这封信里篇幅最重、信息密度最高的板块，因为对伯克希尔而言它就是**浮存金+承保纪律**的生命线。

### 3.1 National Indemnity 的权力交接：Jack Ringwalt → Phil Liesche

- **Jack Ringwalt**：1940年创立National Indemnity，留下"绝对辉煌的管理纪录"。1973年退休。
- **Phil Liesche**接任：幸运的是，他与Jack共享同一套**承保/经营哲学**（纪律优先、不追规模、把承保当核心）。
- 巴菲特的表达分量很重：这不只是人情更替，而是**文化基因的延续证明**——伯克希尔的保险优势不是某人的天才，是哲学+筛选+纪律的制度化。

### 3.2 行业气候：好年景吸引了坏竞争（费率下行）

- 1972那种"异常 favorable factors堆叠"的黄金承保年，引发了新竞争涌入，并以**不可持续/不足费率**抢量。
- 伯克希尔的姿态明确：**宁减量，不买烂风险**；眼光放长期。
- 再保险同样面临竞争环境，但George Young那块仍是主要利润来源之一。

### 3.3 Home-State（本州/区域）保险进展

- **Nebraska（Cornhusker）**：重要进展，保费增长不错，承保损失在可接受范围（新公司费用高、爬坡期）。
- **Minnesota**：起步阶段可控。
- **Texas**：问题大到需要换管理层、几乎重启。
- **Iowa**：1973末才起步。

巴菲特给的度量很清醒：home-state业务衡量的唯一标尺是**最终盈利能力**，不是扩张速度。

### 3.4 芝加哥的痛点：Home and Automobile Insurance

- 1973在芝加哥地区承保业绩**很糟**。
- 机理分析（典型巴氏推理）：  
  油价高 → 驾驶里程降 → 事故频率降 → **但之前按旧频率/旧风险假设定的费率偏低** → 滞后暴露。
- 这意味着：某些"城市/高 risk profile"子市场，数据与定价更新慢半拍就会咬人——教训是**承保要更动态、别以为昨天的loss ratio永远适用**。

## 4）银行业务：Rockford 的 Illinois National Bank——一台"小而离谱"的印钞机

- 位于Rockford的**伊利诺伊国民银行/Illinois National Bank & Trust**继续表现极佳。
- 关键支撑：  
  - 存款结构好（大量定期/更高息存款组合）  
  - 资产质量极强（坏账率远低于行业）  
  - 流动性/资本充足远优于标准
- 巴菲特反复强调：这种"社区银行精品资产"的价值不在于规模，而在于**稳、省、高质量**（且它后来成为伯克希尔现金调度的重要支点之一）。

---

## 5）资本操作：与 Diversified Retailing Company 合并（以及"尽量少发股"的铁律）

### 5.1 交易形态（关键：换股，不摊薄逻辑）

- 董事会批准伯克希尔与**Diversified Retailing（多元零售）**合并。
- 方案：伯克希尔**发行195,000股**交换DRC在外流通1,000,000股（因DRC本身还持有约109,551股BRK，冲抵后**净增发约≤85,449股**）。
- 目的/意义：  
  - DRC体系里装着**Blue Chip Stamps（蓝筹印花）**相关权益线索（以及喜诗/韦斯科的"入口路径"之一）
  - 用**极小比例股权交换**整合关键资产，而非高价现金扫货或乱发股——这是伯克希尔一贯的**anti-dilution discipline**体现。

### 5.2 Blue Chip Stamps / See's / Wesco：把"非保险优质现金流"拼进来

- 年末BRK持有Blue Chip Stamps约**19%**→已增持到**~22.5%**。
- BCS自身"印花业务"在结构性下滑（时代变了，积分/现金折扣替代印花），但它有两颗明珠：
  1. **See's Candies（喜诗糖果）**：高ROIC、定价权、现金牛  
  2. **Wesco Financial（54%持股）**：偏向储蓄&贷款/金融类资产（后来成为伯克希尔另一条资本枢纽）
- 这段话在信里的位置很妙：它告诉股东——看伯克希尔别只看保险，另几块**高品质消费特许经营权/金融特许经营权**正在通过多层持股被"锚"进来。

## 6）股票投资组合：1973熊市里的 $12M+ 未实现亏损 + 价值锚宣言（全信最被引用的段落）

### 6.1 事实陈述（不遮掩）

> **保险部门的普通股投资在1973年做了大量追加。**  
> 年末持仓出现**显著未实现贬值（unrealized depreciation）—over $12 million**。

### 6.2 立场（完全巴氏）

> 但我们相信：**按成本计的普通股组合代表着，在企业内在价值意义上，good value。**  
> 尽管年底有大额未实现亏损，**长期仍预期满意结果**。

翻译成他的决策语言就是三句：
1. **我们不按市值日波动管理。**  
2. **买的时候锚的是内在价值/生意质地，不是K线。**  
3. **$12M paper loss 不改变"以成本计的买入价是否有足够价值支撑"这一判断。**

> 这也就是后来常被总结成他一句口头禅的那个姿态：**别人恐惧时你更要分清"价格波动"与"价值变化"。**（此时华盛顿邮报等核心持仓也正在建仓/持有过程中。）

## 7）隐含的"总框架"：把1973信读成一张运营/资本配置地图

伯克希尔的回报引擎（1973视图）
```
┌──────────────────────────────────────────────┐
│ 1) 保险承保纪律 + 浮存金 → 投资本金（主引擎） │
│ · 交接棒（Ringwalt→Liesche）保文化 │
│ · 竞争压费率 → 宁缩量不松标准 │
│ · 局部伤口（芝加哥 auto）当教学案例 │
├──────────────────────────────────────────────┤
│ 2) 银行（Rockford）→ 高质量、稳现金流的辅引擎 │
├──────────────────────────────────────────────┤
│ 3) 纺织 → 仍贡献现金流，但周期+管制=天花板 │
│ · LIFO会计选择=反虚胖、保报表诚实 │
├──────────────────────────────────────────────┤
│ 4) 并购/持股拼图：DRC合并、BCS/See's/Wesco │
│ · 用极少股份净增发换"更好的资产网络" │
│ · 目标是未来现金流权，不是"做大"本身 │
├──────────────────────────────────────────────┤
│ 5) 证券组合：熊市浮亏 $12M+ │
│ · 公开承认、不粉饰 │
│ · 判断依据：intrinsic worth @ cost → 长期OK │
└──────────────────────────────────────────────┘

```
核心KPI观：
ROE（17.4%）> 工业均值 …但… ROE会从峰值自然滑（基数↑）
解法不是"喊口号提ROE"，而是把每块钱增量配到更高回报去处，且别为了配而买烂资产。

## 8）读完这封信你能带走的"可操作清单"

- [ ] **看控股公司ROE时，先把"分母变大"效应分离出来**：利润还在涨(EPS↑)，但ROE回落≠坏事，关键看增量资本去向。  
- [ ] **LIFO/FIFO不是"会计玄学"**：通胀期存货计价会造出fake earnings——巴菲特宁可压报利润也要匹配真实成本。你自己的生意/分析也该照这个标准审。  
- [ ] **保险/金融的命门是承保纪律**：丰年引来的烂竞争要用"减量"来挡，不能用"希望"来扛。  
- [ ] **并购时把"净增发股数"摊开算一遍**：哪怕听起来是大deal，净增≤几个百分点才算"股东友好型整合"。  
- [ ] **面对大账面浮亏：先问"成本是锚在内在价值上，还是锚在情绪/追高上"**——巴菲特这里能硬扛，因为买入价本身就设在安全边际里，不是因为"死扛就是美德"。
