# 巴菲特致股东的信 — 2016年
## 致伯克希尔·哈撒韦全体股东（2017年2月25日发出）
### 第52封年度信｜巴菲特86岁 / 芒格93岁

> **时间锚定**：这封信覆盖**2016财年**（伯克希尔日历年度），于2017年2月底发出。  
> 2016年的世界：英国脱欧公投震荡6月、特朗普意外当选11月——两次"不可能事件"接连冲击市场。但伯克希尔全年运营静水流深：运营利润稳、大象级收购落地（Precision Castparts）、苹果建仓引爆话题、十年对冲基金赌局临近终点线。**这封信的主旋律不是市场噪音，而是用52年数据回答一个问题：伯克希尔的发动机到底是什么，以及它为什么不靠你的宏观经济预测转。**

## 一、核心框架：「账面价值 → 内在价值」的缺口——为什么账越不准越说明赚到了

这是全信最"会计课"但也最重要的段落。巴菲特用近两页解释GAAP如何系统性扭曲伯克希尔的真实画面：

### 1.1 GAAP的非对称惩罚

| GAAP规则 | 对伯克希尔做了什么 |
|----------|-------------------|
| **"赢家从不向上重估"** | 旗下全资子公司的经济价值涨了10倍，账面上仍按**历史成本−折旧**记，一分钱不往上走 |
| **"输家必须减记"** | 收购溢价形成的商誉/资产一旦不达预期，立刻减值→账面价值被砍 |
| 结果 | 账面价值被**系统性压低** → 内在价值与账面价值的缺口越来越大 |

> 他的结论：**今天伯克希尔的内在价值已"远超过"账面价值**——这不是谦虚的"我们可能更值钱"，而是可解释的会计结构性偏差。

### 1.2 为什么他还在用账面价值当进度尺

- 因为账面价值是**可审计的客观锚**，虽偏低但方向对；
- 因为52年的一致性让它成为"相对进度条"，哪怕绝对值不准；
- 回购触发线（≤120%账面价值）之所以保守，正是因为**他知道内在价值 > 账面价值**——所以在120%以下买回股票，等于用打折价回购"更值钱的东西"，对持续股东是纯利。

## 二、最沉重的课：从Dexter鞋到Gen Re——"永远不要用伯克希尔股票买东西"

### 2.1 Dexter Shoe（1993）：价值归零，但付出去的股票还在涨

花了 $434 million 收购 → 生意价值归零
但付的是伯克希尔股票（25,203股A）
那些股票到2016年底价值 > $6 billion

> ### *"我用了伯克希尔的股票——这些股票代表了我当年无法创造的价值——去买了一个价值归零的生意。这是我做过最蠢的事之一。"*

### 2.2 Gen Re（1998）：又一次发股票的错误

- 为收购通用再保险发行了**272,200股A股** → 流通股增**21.8%** → 原有股东被稀释，而他买来的不是等值内在价值
- 后来Gen Re本身成了好业务（尤其是Ajit Jain接手再保后）——**但交易结构本身是错的**

### 2.3 此后铁律：只付现金，不付股票

> *"自那以后，伯克希尔收购的唯一货币就是**现金**。当我们买下GEICO另一半（1996）时用了现金——结果完全不同。"*

这条纪律是理解伯克希尔后来所有收购的钥匙：**BNSF（现金+少量债）/ Precision Castparts（现金）/ 苹果（二级市场现金买）/ 任何补强收购**——从不稀释。

## 三、十年赌局终局在望：主动管理 vs 低成本指数基金

### 3.1 赌局设定回顾

- 2007年，对冲基金FOF选手套Protege Partners选**五只母基金** vs 巴菲特选**标普500指数基金（Vanguard 500 Index Fund）**
- 10年，$1 million总奖金（通过Long Bets结构捐给慈善）
- 到2016年底（第9年完），结果已基本锁定：

| 一方 | 累计年化回报（约） | 备注 |
|------|-------------------|------|
| Protege的五只FOF（扣费后） | **~2.2%** | 管理费+业绩提成+交易成本把回报碾碎 |
| Vanguard标普500指数基金 | **~7.1%** | 什么都没做，就买并持有全美最大500家公司 |

> ### *"对冲基金收取的费用不是基于绩效——它们是**不管赚不赚都收的租金**。"*

### 3.2 他给普通投资者的结论

- 绝大多数人**不应该**挑股、不应付2-and-20、不应相信"天才一定能跑赢"
- 买并持有**极低成本广泛分散指数基金** = 拿到你应该拿到的"美国经济产出份额"
- 他甚至在遗嘱中对受托人指示：**死后信托的10%放短期政府债、90%放标普500指数基金**

> 📌 注意：他不是在说"主动投资不可能跑赢"——他自己就是活例证。**他在说的是：对你（普通投资者/机构受托人）而言，付费给声称能跑赢的人，期望值为负。**

## 四、股票回购：为它正名——但不是"任何价格都回购"

### 4.1 他对回购争议的回应

当时（2016前后）回购被很多批评者骂成"公司用本该涨工资/搞研发的钱讨好股东"。巴菲特的反驳极为清晰：

| 批评者的逻辑 | 巴菲特的拆解 |
|-------------|-------------|
| "回购=偷走发展资金" | 美国企业手里的待配置现金**泛滥**，缺的不是资本，缺的是值得投的项目 |
| "回购=操纵股价" | 只有在**价格低于内在价值**时回购才创造价值；高价回购只是另一种浪费 |
| "永远不该回购" | 如果股价<内在价值，回购=给持续股东**立即的每股价值提升**，比发股息更节税更有效 |

### 4.2 伯克希尔的具体政策

> **只有当BRK股价 ≤ 120% of 账面价值时才回购**——因为内在价值 > 账面价值，所以120%账面价值仍≈打折买内在价值。这个线多年未触发（市价通常在1.3x+），所以伯克希尔**几乎从不实际回购**——不是反对回购，是**市价不便宜**。

## 五、2016年的"大象"：Precision Castparts收购（$372亿）

| 要素 | 内容 |
|------|------|
| 收购价 | **~$372亿**（含承接债务），伯克希尔史上最大现金收购 |
| 标的 | **PCC（Precision Castparts）**——航空航天/动力系统精密铸锻件全球龙头 |
| 客户 | GE航空、普惠、劳斯莱斯、波音——极高准入壁垒、严苛认证、长周期合同 |
| 为什么买 | 极宽的护城河（技术+认证+关系）、高资本强度但稳定、可预测现金流 |
| 买的方式 | **全现金**，不增发BRK股票 |
| 整合方式 | 作为独立运营子公司（像BNSF/中美能源级别），Greg Colyer留任CEO |

> 这桩交易是"只付现金 + 买有真实护城河的实业企业 + 放手让优秀经理人管"的标准样本。

## 九、美国经济颂 + 移民辩护——"今天出生的美国孩子是历史上最幸运的人"

### 9.1 他对美国经济的基本立场

> *"如果要用一个词总结我们国家成就——**奇迹（Miracle）**。从零起点到今天7500万套自有住房、2.6亿辆车、超高产工厂、健全医疗中心、世界级大学……"*

- 驱动力：**市场体系 + 创新 + 企业家精神 + 法治 + 资本充沛**
- 对悲观论者的刺：**"怀疑论者靠宣传悲观谋生——但按他们宣传去行动，上帝也帮不了他们"**

### 9.2 移民段落（微妙但清晰）

> *"使美国伟大的关键因素之一，是**移民**——大量有才华、有野心的人来到这里。"*

写于特朗普就任后数周，他不明说但指向性清楚：美国优势的根基之一是开放吸纳全球人力资本。

### 9.3 对短期波动的态度

> *"财富的积累会**时不时被短暂打断**——但不会停止。"*  
> 没人（包括他和芒格）能预测何时大跌/恐慌 → 所以伯克希尔的策略是**立于不败（充足流动性+分散现金流）**而非押注时间表。

## 十二、读这封信最该带走的六句话

1. **"赢家的价值从不向上重估，输家必须减记——所以账面价值系统性压低了伯克希尔。"** 推而广之：任何用"账面/有形账面"一刀切估值的模型，遇到"轻资产+经济商誉"型企业都会系统性偏低。
2. **"我用了伯克希尔的股票去买了一个归零的生意。"** 这是全信最痛的一句——也是"永不发股票收购"铁律的血誓来源。
3. **"当股价 < 内在价值时回购增加持续股东每股价值；高价回购只是另一种浪费。"** 把回购从政治话题拉回**估值纪律**。
4. **十年赌局的教训不是"主动投资不可能赢"，而是"你付的费大概率买不到你说的alpha"。** 对99%投资者=买低成本广泛指数。
5. **"今天我们持有的现金比任何美国企业都多——不是因为怕什么，是因为当大象走过你得拿着网。"** 流动性不是怯懦，是弹药。
6. **"今天在美国出生的孩子是历史上最幸运的人。"** 不是盲目乐观——是52年复利+亲眼见过美国从$19到$172,108的那个人在说：别让选举年噪音骗你卖掉了这个国家的未来。
