# 巴菲特致股东的信 —— 第01章·2013年
## 伯克希尔·哈撒韦致股东信（2012经营年度，发布于2013.03.01 / 2013.02末）
### 详细总结 · 结构化精读版

> **⏳ 时代坐标（理解气压的钥匙）**
> - 这封信写的是**2012年**的数据，发布于**2013年3月1日**（部分版本标2014年2月28日对应的是2013财年——别混淆：用户说的"2013年信"在全书惯例里= **2013年发布的那封 = 2012财年**）
> - 2012年：标普500含股息 **+16%**，伯克希尔每股账面价值 **+14.4%** → 第9次跑输，且过去4年S&P连胜 → 巴菲特开篇就直面
> - 宏观背景：美国从金融危机复苏进入**QE驱动的强势牛市**，房价回暖、利率谷底、企业利润创新高——但巴菲特关注的是"这堆钱最终从哪来的现金流"
> - 本信的**两大教育 mission**：① 用农场/房产案例把"投资 vs 投机"钉死；② 用亨兹+3G展示"大型并购新模板"；并首次附上**1975年养老金备忘录**预警公共养老金危机

## 〇、开篇数字：+14.4% 很漂亮，但第一句是"表现欠佳"

| 指标 | 2012年数据 | 巴菲特定性 |
|------|-----------|-----------|
| **净值增加** | **$24.1B** 总收益（回购后净值+**$22.8B**） | "我从未想过一年赚$24B还'表现欠佳'"——但 |
| **每股账面价值增长** | **+14.4%** | 跑输 S&P 500含息 **+16%** |
| **48年累计** | $19 → **$114,214** | CAGR **19.7%** |
| 跑输S&P次数 | **9/48年**，其中**8次**S&P涨幅>15% | "强牛市年里我们通常落后；下跌/平年我们相对更强" |
| 5年滚动记录 | 43个完整5年窗口**全胜**——但本次若2013续涨，可能出现首个5年败绩 | 不改标准："增每股内在价值 > S&P" |

### 0.1 "账面 vs. 内在"的重申（每次必念的咒语）

> **账面价值是内在价值的保守替代物，不是精确等价。** 2012年二者差距继续扩大（大量控股业务IV≫BV：BNSF/能源/NFM等），但BV仍是股东最能核验的标尺。

### 0.2 为什么牛市年天然跑输——一句话力学

伯克希尔 = 大量**持有现金/现金等价物 + 承保纪律不追高风险资产 + 整企业价值靠现金流而非P/E扩张** → 当市场由**估值拉伸**驱动暴涨时，BRK的"赚真钱"引擎跑不过"别人愿意付更高倍数"。  
他的回应不是"我们会更激进"，而是：**"查理和我不会改变衡量标准。"**

## 一、【并购：亨氏 + 3G资本】"财务伙伴 × 运营伙伴"的新模板

### 1.1 交易骨架

| 项目 | 内容 |
|------|------|
| 标的 | **H. J. Heinz（亨氏）**——全球酱料/番茄/婴幼儿食品霸主，品牌护城河+定价权 |
| 结构 | 伯克希尔 + **3G Capital**（豪尔赫·保罗·雷曼 Jorge Paulo Lemann）联合收购 |
| 伯克希尔出资 | **$8B 9%股息优先股** + **$4.25B 普通股**（合计约**$12B**） |
| 3G出资 | ~$4.25B 普通股 |
| 控股 | 各≈50%（实际结构稍复杂：BRK优先股带warrant/回购溢价条款） |
| 巴菲特评价 | **"我们买不到比这更好的公司。保罗（雷曼）是杰出经理人。永不卖出。"** |
| 更大意义 | 开启**"BRK = 财务/资本平台，3G = 运营手术刀"**的合作范式——未来大型deal的可能模板 |

### 1.2 为什么这比"自己全资买"聪明

| 若全资买 | 与3G合伙版 |
|----------|-----------|
| 付100%控制权溢价 | 只出一半钱拿一半upside + 拿9%优先息流+回购溢价期权 |
| BRK得管运营（不是巴菲特最爱） | 3G做他们擅长的极致成本/品牌增长改造 |
| 单一文化风险 | 双文化：BRK的资本纪律 × 3G的执行狠劲 |

> 金句旁白：**"我追了几头象，空手而归……不过今年运气好转。"** → 2012无大型并购是遗憾，亨氏是破冰。

### 1.3 第二笔能源型收购：NV Energy（内华达能源）

- **中美能源（后改名Berkshire Hathaway Energy）** 斥资 **~$5.6B** 收购NV Energy
- 服务内华达**88%人口**，大幅扩张再生能源投资空间（风电/太阳能组合）
- 巴菲特的逻辑：受管制公用事业 = 长期需求确定 + 监管回报框架 + 能承载大资本

## 二、【五驾马车（Powerhouse Five）】非保险利润引擎突破 $101B 税前

> 这节是"整企业 > 股票"论点的最硬证据——它们都是**全资/控股的实体**，利润不走股价波动，走真实的运营现金流。

| 企业 | 业务 | 巴菲特强调的点 |
|------|------|----------------|
| **BNSF铁路** | 全美15%城际货运（吨英里） | 燃油效率=卡车4倍；2012资本支出$**3.9B**（单年铁路业纪录）；日运石油50万桶≈美产量10% |
| **MidAmerican / BH Energy** | 电力/天然气/可再生 | 11州、风电占全美7%、客户满意度顶尖 |
| **Iscar（伊斯卡）** | 超硬切削刀具（以色列） | 全球化制造护城河、高附加值、Eitan Wertheimer体系 |
| **Lubrizol（路博润）** | 特种化学品/添加剂 | 从2008年收购后持续增厚、深客户嵌入 |
| **Marmon（马蒙集团）** | 多元化工业（冷藏车/基建零件/运输设备等） | 通过逐步增持→**2013年增持至100%**（多步结构最终完成） |

- 2012五驾马车**税前利润 $101亿**（较2011 +约$6亿），8年前大多还不在此列表里
- 对应权益稀释极小（BNSF用6.1%股票+BNSF债，其余全现金）→ **每股利润仍增长**

## 四、【投资哲学大普及】农场 + 纽约大学房产——把"买股票=买企业"从口号变可触摸

这是2013年信**最广传的核心教学段**，巴菲特用两个自己真实持有的**非股票资产**来讲投资。

### 4.1 农场（1986，内布拉斯加 400英亩）

| 要素 | 内容 |
|------|------|
| 买价 | **$28万** |
| 对卖家 | 农艺师/专家算过：对玉米/大豆的合理预期 → 扣运营成本/按揭 → **≈10% 当期yield**，且有**长期产出增长潜力** |
| 关键动作 | **从不重估**；不看每日报价；只问：今年庄稼/租金现金流多少？ |
| 后续 | 如今农场价值≈**$500万**；但"如果有人报价明天跌30%，我才不在乎" |

### 4.2 纽约大学旁商业地产（1993）

- 金融危机最恐慌时**价格腰斩**，但租客（NYU）仍在、租金仍在 → 长期看现金流确定
- 他买的目的不是"等反弹卖"，而是**收租的产出能力**

### 4.3 由此导出的"六项投资 fundamentals"（巴菲特原话精神整理）

| # | 原则 | 原话精神 |
|---|------|---------|
| ① | **投资 = 放弃今天的购买力，以期未来拿到更多** | 看的是**资产能吐多少现金/购买力**，不是报价 |
| ② | **你不需要是专家**——只需在自己能力圈内、能对"未来产出"做**粗糙但合理的估算** | "如果不能估，忘了它，找下一个" |
| ③ | **投机 = 关注价格变化而非产出** | "比赛赢在球场，不是看计分板" |
| ④ | **宏观预测/听别人宏观预言 = 浪费时间** | 1987崩盘/1994加息/2008危机——都没改农场/房产的长期产出 |
| ⑤ | **对普通投资者的最终建议：低成本指数基金** | 他自己遗嘱安排：**90% Vanguard S&P500指数 + 10%短债**（对信托受益人） |
| ⑥ | **波动≠风险；本金损失=风险** | 20年以上持有期内，分散股票组合比现金/国债更安全（西格尔式论据随手引） |

> 这段话的杀伤力：它由**全世界最成功的选股者**说出"大部分人应买指数"——不是谦虚，是对"手续费+频繁交易+能力圈越界"的精确清算。

## 五、【坦诚清单】错误 + 怪自己 + 养老金警告

### 5.1 EFH（Energy Future Holdings）巨亏：$8.73亿的"未咨询查理"错误

- 2007年买了**TXU/EFH 高收益债券**（杠杆 buyout 后的煤电公司债务），赌天然气价反弹/维持
- 天然气**崩跌**→ 公司破产→ Bond价值蒸发
- 巴菲特：**"我错了……这决定我没咨询查理。下次一定先打电话。"**
- 强调：这不是别人骗他——**他自己的评估错了**（对行业经济动力误判），且"好在大多数错是小收购；大buy一般还行"

### 5.2 养老金"财务绦虫"（Financial Tapeworm）——1975备忘录附信

- 他罕见地附上一份**1975年写给Katharine Graham的备忘录全文**，主题是：
  - 公共养老金承诺**> 愿意/能够 funding 的**
  - 数学恒等式：承诺−缴费=负债增长→ 最终吃掉预算/加税/违约
- 预言：**未来十年（2010s）会读到大量公共养老金坏新闻** → 果然应验（底特律/伊利诺伊/加州公债压力等）
- 给 Corporate America 的对照：企业养老金已大部分mark-to-market/FASB化 → 州&市仍躲

## 六、【不分红论述】3页的 dividend policy 拆解——为什么伯克希尔不派息

本信用**整整一大段（常被单独摘出）**系统回答"你们收别人股息却不给自己股东发，什么逻辑？"

### 6.1 四步递进

| 步骤 | 逻辑 |
|------|------|
| ① 首要用途 | 再投到**现有业务提效/扩护城河/补强收购**——只要留存$1能创造 >$1市值 |
| ② 次选 | **回购**——但只在股价**明显低于IV**（他给阈值约**120% BV**以下触发，实际更严） |
| ③ 再次 | 偶尔**大型收购**（需用现金） |
| ④ 才轮到 | 分红——且只当上述全部机会都跑输"把钱退给你让你自己再配置"时 |

### 6.2 对"你想要股息我们就发股息"的反驳

- 股东要现金流？**自己卖微量股份**就行（税务时机自控）
- 公司发股息=强制所有人同时纳税→ 对不需要现金的人反而是**被迫税损**
- "如果你的医生根据你吃花生过敏，就给所有人开无花生食谱"= 类比错误

## 七、【"母矿脉在美国"】资本支出 $98亿记录 + 报纸 + 接班人

### 7.1 逆势扩产的炫耀（但不是虚荣）

- 2012 CapEx **$9.8B**（$98亿），≈**2×折旧**，其中**89%投在美国**
- 2013预计再破纪录 → "风暴过后又是雨"歌词引文（Gary Allan country song）
- 表态：**做空美国是237年里没人靠之获益的蠢事**

### 7.2 报纸（28份日报，$344M）

- 过去15个月以 **$3.44亿** 买28家**地区性日报**
- 他的筛选极窄：**紧密社区+本地垄断性分类广告+可守住的niche**；不买全国性/纯广告驱动的
- 承认营收仍承压，但"明智的互联网策略+社区信任"能让它比市场想的更耐用

### 7.3 托德·康布斯 & 泰德·韦施勒

- 各管 **~$7B+**，2012双双**跑赢S&P——巴菲特自嘲："他们把我落很远。查理说我得加'by a lot'。"**
- 管理规模继续上调（到$5B/人级→后来更高）
- 巴菲特再次强调：找他俩=中大奖

## 九、2013年信的"可带走清单"（Actionable Takeaways）

| # | 巴菲特示范/讲透的道理 | 落到你身上 |
|---|---------------------|-----------|
| 1 | **牛市年跑输≠失败**——衡量标准是IV增速>S&P长期，不是每年赢 | 你评价自己/基金经理：牛市狂奔年跑输，要先看"赢的是eps/现金流还是P/E拉伸" |
| 2 | **亨兹+3G模板**：不是"全控"才叫收购成功——找对运营合伙人能放大资本效率 | 你买企业/入股：问自己"我买的是资本配置平台，还是我自以为能管运营？"别越能力圈 |
| 3 | **农场法则**：股票只是企业碎片——如果你不会因农场每日报价慌，就别因股票报价慌 | 持有一只股前先答：我能不能说清它未来5-10年大概吐多少自由现金流？不能说清→指数基金区 |
| 4 | **EFH忏悔**：错不在"买债券"，在**对行业经济动力误判+没问查理** | 你的大仓位：有没有一个"查理角色"能踢你一脚？你上一次改主意是因为新数据还是因为价格动？ |
| 5 | **不分红论述**精炼：留存只有当>$1→>$1市值才道德；否则让股东自选卖股 | 任何不分红的高价股，你要自己算：公司留的每块钱，历史上有没有证明它值>1块？ |
| 6 | **遗嘱90/10**：连巴菲特都给家人配指数——这是对所有"必须选股才能赢"执念的终极否定 | 你的手续费/换手/情绪损耗，可能比"选错股"更吃收益 |
| 7 | **养老金绦虫**：承诺≠能fund→数学恒等式会把代价递延但绝不取消 | 你买的市政债/相关金融敞口：要问对方养老金负债覆盖率，不是只看信用评级 |
