# 巴菲特致股东的信 —— 2015（发布：2016-02-27，总结 2015 财年 / 第 51 封信）
## Berkshire Hathaway Inc. | To the Shareholders
### 主题：第 51 年复盘 + 从“账面价值叙事”过渡到“内在价值叙事” + 实业帝国运营体检

> **一句话定位**：这封信写在第 51 年节点（接管以来半世纪），核心任务不是炫耀回报，而是做三件“成年期统治者该做的事”：  
> ① 用 **BV +6.4%** 与 **市值 −12.5%** 的分裂，把“账面追踪器”和“市场投票机”的差别钉死；  
> ② 向股东证明伯克希尔已经从“证券组合为主的控股公司”演变为**以运营企业现金流为中心的工业/能源/交通/金融复合体**（BNSF、$5.8B capex、Precision Castparts $32B 全现金）；  
> ③ 把回购阈值、收购标准、以及对“唱衰美国”的宏观立场，写成可长期复用的制度参数。

## 1）第 51 年数字（他把“成绩单”先拍桌上，但不让它变成 whole story）

| 指标 | 2015 结果 |
|---|---|
| **净资产增加** | **$15.4 billion** |
| **每股账面价值增长（A/B 股）** | **+6.4%** |
| **每股账面价值（年末）** | **$155,501 / A 等价**（≈ 51 年从 $19 → $155,501） |
| **51 年 BV CAGR** | **19.2%** |
| **伯克希尔每股市值变动** | **−12.5%**（2008 以来最差单年市值表现） |
| **标普 500（含股息）** | **+1.4%** |

### 1.1 为什么 BV 涨、股价却跌？——他把“分叉”解释清楚

- 2015 对伯克希尔的**运营现金流侧**是扎实年（BNSF/能源/制造等更强）；  
- 但**二级市场持仓（富国/IBM/AXP 等）估值收缩**拖累市值，于是出现：
  - 企业层面：BV 仍增（留存+运营利润+少量并购会计）
  - 市场价层面：标价下行（＝“投票机”短期判词，不是“称重机”最终判词）

> 这正是他借机重申的：随着伯克希尔越来越像一个**运营控股平台**，BV 对内在价值的“低估偏差”会长期存在——因为会计准则对“控制型企业”**只准往下重估（减值），不准往上重估（升值）**，所以 BV 会越来越像“保守下限追踪器”，而不是“市值锚”。

## 2）账面价值 vs 内在价值——这封信的“会计哲学”段落（很关键，很多人误读）

### 2.1 他给的三句定位（白话转译）

1. **早期（1960s-80s）**：伯克希尔资产大量是“有价证券”，按市价记账 → BV ≈ 更接近内在价值的影子。  
2. **今天（运营控股为主）**：重要资产是整家企业（BNSF、能源、制造…），会计把它们**近成本持有**，减值能记、升值不能记 →  
   → **内在价值 长期 > BV**，且差距会扩大。  
3. 所以：**BV 仍是可用尺（尤其相对自身历史、相对标普对照），但别把它当“价值=账面的精确读数”。**

### 2.2 回购阈值那句经典表述

> 如果伯克希尔股价真被打到 **≤120% of BV** 附近，他会很乐意回购——因为只有到那个区间才足够明确“买回自家股权在创造价差价值”。  
> 现实：2015 末 A 股约 $198K，约是 BV 的 **~127%**，所以“没到触发线”，也不勉强回购去讨好市场。

## 3）运营帝国体检：哪里真赚钱、哪里被宏观磨、哪里在下注未来

### 3.1 BNSF = 2015 的“头号运营成就”（Powerhouse Five 核心）

- **2014 服务事故**后，2015 把服务拉回来是最高优先级  
- **资本支出约 $5.8 billion**（≈ 近 **3× 年度折旧**）——铁路史上单年最高 capex 记录之一[3,7,16](@ref)
- 结果：BNSF 运量基本稳住，而行业走弱 → BNSF **税前利润约 $6.8B**（比 2014 的 $6.2B 再上台阶）[3,16](@ref)
- 占比：承担美国约 **17% 城际货运（收入吨英里）**，运量比最接近对手高约 **45%**[7,16](@ref)

> 巴菲特的评价不是“ROI 漂亮”，而是“对客户的保障 + 对美国经济的正外部性 + 把 BNSF 的信誉资本修复回来”——这属于“护城河维护费”，不是短期利润优化。

### 3.2 “Powerhouse Five”利润数字（非保险最大五块）

| 成员 | 角色 |
|---|---|
| BNSF | 铁路/干线物流 |
| Berkshire Hathaway Energy（BHE） | 能源/电网/可再生 |
| Marmon | 多业务工业集团 |
| Lubrizol | 特种化学品 |
| IMC（原 Iscar） | 金属切削/工业材料 |
| **合计（2015口径）** | **税前利润约 $13.1B**（较 2014 +$650M）[16](@ref) |

### 3.3 PCC（Precision Castparts）——史上最大收购之一：约 **$32.7B，几乎全现金**

- 2015 年签约、2016 年初交割 → 此后改称 **Powerhouse Six**[3,16](@ref)
- 品类：航空/航天/动力系统复杂金属部件（同时也带油服敞口，所以 2015 油价崩时估值打折，对 BRK 反而是窗口）
- 逻辑：  
  - **不拆、不榨、不换血**，Mark Donegan 留任  
  - 用现金而非 BRK 股票付（保护现有股东不被隐性摊薄）  
  - 把“高CAPEX/高工艺门槛/长周期航空供应链”接进帝国，增强对宏观经济波动的截面多样性

### 3.4 制造/服务/零售（含 McLane 等）整体税前约 $7.1B 区间

- 这组是“美国消费与工业中后台”的体温计：不一定炸裂，但体量大、现金流稳（McLane 分销这种属于低毛利高周转现金牛）。

### 3.5 保险：GEICO 相对“弱年”，但承保仍在 streak 内

- 保险整体 **连续承保盈利 streak 已到 13 年**量级（仍为正，但不如某些顺风年）
- 浮存金约 **~$88B** 量级（持续往上走，靠的是规模+纪律，不是财技）
- GEICO 的“弱”主要来自行业竞争/索赔成本/周期，而不是品牌塌——巴菲特的写法更像“把期望值管好”，不是警报。

## 4）投资组合：Kraft Heinz、四大增持、以及“账面 vs 市值”的情绪隔离

### 4.1 Kraft Heinz（3G 合并产物）

- 伯克希尔成本约 **$4.25B 持 Heinz 53% → 合并后持 KHC 约 27%（约 3.25 亿股）**，年末账面约 **$15.7B**、市场价值约 **$25.5B** 量级[1,7,16](@ref)
- 措辞是合作但保持距离：对 3G 的效率/成本文化“愿意更多合作”，但强调自己不是并购操盘手、只是资本与信誉提供者。

### 4.2 “四大”（Wells Fargo / Coca-Cola / IBM / American Express）

- 2015 市场整体平淡甚至对某些名字残酷（AXP、IBM 压力很大），但巴菲特强调：  
  **他看的是“生意质地+管理层+分红/回购把留存收益滚回去”，不是季度股价打分。**
- 这里不追涨、不砍仓、不把浮亏当羞耻——只要“earning power + 资本配置纪律”没坏。

## 5）回购与分红逻辑：把“为什么我们不分红/回购也可以正当”写成宪法

- **不分红**：只要每留存 $1 的长期期望市值增量 ≥ $1（历史已验证），钱留在机器里更好。  
- **回购**：只在 **明确打折（≤~120% BV 那样的区间）** 才做；不为了 EPS 化妆而回购、更不为安抚短线叙事。  
- 现金堡垒：他在 BRK 体量下仍强调**随时保持极强流动性**，必要时甚至主动安排信贷额度，避免在别人失血时被逼卖资产。

## 6）宏观/政治语气：一句“别赌美国衰落”，但后面跟的是运营事实

> 他对竞选话语中“只讲问题、暗示国家走投无路”的叙事不耐烦：  
> **“It’s a terrible mistake to bet against America.”**（这代人是“史上最幸运”之类表述的变体）

但注意：他不是盲目乐观主义，他是用 **BNSF 运量、能源投资、制造业现金流、50 年 BV 记录** 当证据，而不是口号。  
真正的“押注美国”对他来说 = 把真金白银焊进**长期资产 + 不杠杆 + 能扛周期**。

## 7）收购标准（这封信把“购物清单”再挂一次，等于制度公告）

| 偏好 | 具体要求（重述口径） |
|---|---|
| 规模 | 税前利润至少 **~$75M**，更爱 **$5B–$20B** 级 |
| 盈利 | **已证实的持续性盈利**（不要预测/转机故事） |
| 资本结构 | 好 ROIC + **很少/无不良债务** |
| 管理层 | 在位且靠谱（我们不派 CEO） |
| 业务 | 简单（技术/黑箱我们不碰） |
| 价格 | **必须有明确报价**，不谈“价格未知”的暧昧 |
| 方式 | **现金优先**；若用股票，必须“给的内在价值 ≈ 拿到的内在价值” |
| 态度 | **无恶意收购**；能绝对保密；回得快 |

这实际解释了：PCC 这种交易能成，是因为它满足“现金、简单工业壁垒、留原管理层、不拆卖、明确价”。

## 8）未来 50 年：把“永久性损失”的概率压到接近零（而不是承诺你每年 +19%）

- 他对股东的诚恳降级：  
  - **伯克希尔的永久性损失概率极低**（流动性+多样化+不赌单点崩溃）  
  - 但如果你自己 **在 BV 两倍附近追高买 BRK 股票**，那你把“好企业”买成了“投机标的”——未来很多年可能才解套（这等于把锅放回买家手里：别用错价格把系统骂垮）

### 读完这封信你该带走的 3 条硬工具

1. **BV +6.4% / 市值 −12.5% 不是矛盾，是“控股运营公司”的会计指纹**：别拿市值回撤当企业退步；也别拿 BV 当精确估值，它只是保守下限尺。  
2. **PCC $32B 几乎全现金**的买法，才是伯克希尔真正的“回购替代”：把现金变成**能自己生现金流的工业资产**，比买回自家股票更容易在规模下创造增量（前提：不拆、留人、价格别疯）。  
3. **回购/分红的锚是“120% BV 附近=明确折扣”**，不是“股价涨了就该回购、跌了更该回购”的模糊口号——缺明确折扣时，现金留在机器/并购选项里更守纪律。
