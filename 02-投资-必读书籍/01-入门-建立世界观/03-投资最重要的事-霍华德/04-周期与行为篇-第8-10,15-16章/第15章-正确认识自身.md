## 第一部分 · 总起：核心理念——认识现状优于预测未来

### 1.1 为什么“认识自身”比“预测未来”更重要

霍华德·马克斯在书中写道：

> **“我们或许永远不会知道要去往何处，但最好明白我们身在何处。”**

这是本章最核心的箴言。在投资领域里，周期最可靠——基本面、心理因素、价格与收益的涨跌，提供了犯错或从别人错误中获利的机会。**但周期的幅度和转折时机无法预知。** 因此，与其徒劳地预测未来，不如努力弄清自己处在周期的哪个阶段，以及这一阶段将对我们的行动产生怎样的影响。

2026年的A股，正是一个 **“知道身在何处”远比“预测将去何处”更重要的市场**。全市场中位数跌**-15.4%**的同时科创50涨**64%**——如果你不能正确认识自己在周期中的位置，你的每一次决策都可能是错的。

### 1.2 面对市场周期的三种态度

| 态度类型 | 具体表现 | 2026年A股中的体现 |
|:---|:---|:---|
| **否认不可预测性** | 加倍努力预测未来，根据预测结果投资 | 投资者试图精准预测AI板块何时见顶、美联储何时降息 |
| **忽视周期** | 完全忽略周期，采用“买入并持有”策略 | 在科创50 PE 241倍时依然满仓持有，忽视极端高估风险 |
| **认识自身处境（马克斯主张）** | 努力弄清自己处于周期的哪个阶段，据此调整行动 | 在情绪指标降至0%分位数时逆向布局，在TMT成交占比48%时保持警惕 |


## 第二部分 · 分述一：如何认识自身处境——霍华德·马克斯的方法论

### 2.1 了解当下相对容易

马克斯指出： **“了解未来很困难，但了解现在没有那么难。”** 通过努力，了解当下市场的温度、参与者的心理和投资气候是可能的。

保持警觉和敏锐，我们就可以判断出其他人的行为，并据此判断我们应采取的行动。

### 2.2 市场评估练习（霍华德·马克斯经典工具）

从以下任意一对词语中选出一个你认为最能贴切地描述当前状况的。**如果你发现你的标记大部分在左侧栏里，那就要看紧自己的钱包。**

| 左侧栏（乐观/狂热特征） | 右侧栏（悲观/恐慌特征） |
|:---|:---|
| 经济活跃 | 经济呆滞 |
| 前景积极 | 前景消极 |
| 贷款人急切 | 贷款人谨慎 |
| 资本市场宽松 | 资本市场紧缩 |
| 资本充足 | 资本短缺 |
| 条款宽松 | 条款严格 |
| 利率低 | 利率高 |
| 利差窄 | 利差宽 |
| 乐观 | 悲观 |
| 投资者自作聪明 | 投资者担忧 |
| 渴望买入 | 丧失购买兴趣 |
| 资产持有人乐于持有 | 急于出手 |
| 卖家少 | 卖家多 |
| 市场拥挤、急需关注 | 市场冷清 |
| 申购门槛高 | 对所有人开放 |
| 每天都有新基金 | 只有最好的才能募集到资金 |
| 强 | 弱 |
| 近期表现高 | 近期表现低 |
| 预期回报低 | 预期回报高 |
| 风险积极进取 | 谨慎守纪 |

> 💡 **2026年A股的评估结果：科技板块的标记大部分落在左侧栏（乐观狂热），而非科技板块的标记大部分落在右侧栏（悲观恐慌）。同一个市场，两种完全不同的温度。** 这正是2026年A股最独特的特征——你必须分板块评估，而非用单一温度衡量整个市场。

## 第五部分 · 分述四：逆向行动——基于周期位置的投资策略

### 5.1 核心理念：在极端时逆向行动

马克斯给出了最清晰的行动指南：

> **“当其他人盲目自信、积极买入时，我们应加倍小心。当其他人不知所措或恐慌性抛售时，我们应该更加积极。”**

**关键：要在极端情况下，采取与群体相反的行动。**

### 5.2 2026年A股的逆向行动框架

| 市场区域 | 当前温度 | 群体行为 | 逆向行动 |
|:---|:---|:---|:---|
| **科技板块** | 🔥 极度过热（PE 241倍、成交占比48%） | 盲目自信、积极买入 | **保持警惕，控制仓位，不追高** |
| **消费/医药板块** | ❄️ 极度寒冷（PE历史6%-15%分位） | 恐慌性抛售、无人问津 | **更加积极，逆向布局** |
| **券商板块** | ❄️ 极度寒冷（PE历史4.78%分位） | 被系统性忽略 | **关注价值修复机会** |
| **全市场情绪** | 情绪指标降至1.1%（接近0%） | 恐慌、不知所措 | **短期企稳反弹可能性抬升** |

### 5.3 拒绝从众的勇气

马克斯警告： **“拒绝向导致无数投资者在市场顶部或底部犯下致命错误的群体行为看齐。”**

2026年A股，从众的代价是巨大的：

- 在科技板块成交占比**48%**时追入——你在跟随群体，买入的是**最拥挤的交易**
- 在消费板块PE历史**6%分位**时割肉——你在跟随群体，卖出的是**最被低估的资产**
- 在情绪指标接近**0%**时恐慌——你在跟随群体，而历史规律显示此时买入胜率更高

> 💡 **专业投资者的价值在于，不受市场情绪摇摆影响，始终锚定价值的准绳。**


## 第六部分 · 分述五：投资者常见误区与心理陷阱（2026年A股版）

### 6.1 预测迷恋

**错误**：过度相信能够预测市场拐点，不断试图择时。

**2026年表现**：投资者试图精准预测“AI板块何时见顶”“美联储何时降息”“科创板何时回调”。但正如马克斯所言，**关于周期唯一可预测的只是它的必然性。**

**正确认知**：不是每一个预测都需要准确，而是要知道预测在什么条件下有用。**与其预测拐点，不如识别极端。**

### 6.2 从众陷阱

**错误**：在狂热时跟风买入，在恐慌时跟风卖出。

**2026年表现**：5月情绪80%时追入科技股，6月情绪1.1%时割肉离场——**完美演绎了“高买低卖”。**

**正确认知**：在市场极端时追随群体行为会引发致命错误。**逆向不是为叛逆而叛逆，而是基于价值的独立判断。**

### 6.3 单一温度误判

**错误**：用一个温度衡量整个市场。

**2026年表现**：因为科创50涨64%就认为“A股是牛市”，或因为全市场中位数跌15%就认为“A股是熊市”。事实上，2026年A股是 **“半牛半熊”** ——科技板块是牛市，其他板块是熊市。

**正确认知**：**分板块测量温度**，在不同区域采取不同策略。

### 6.4 “叙事切换”困扰

**错误**：被市场叙事牵着鼻子走。

**2026年表现**：年初相信“AI将永远涨”，年中科技回调后开始怀疑“AI是不是泡沫”。叙事切换导致策略漂移。

**正确认知**：不要被短期叙事左右。科技的长期趋势可能没有改变，但短期估值已经透支。**你需要区分“趋势”和“价格”这两个不同的维度。**


## 第七部分 · 总 结：在2026年A股认识自身

霍华德·马克斯在书中写道：

> **“我们或许永远不会知道要去往何处，但最好明白我们身在何处。”**

2026年的A股，是对这一命题最残酷的考验：

- **身在何处？** ——你在科技板块的狂热中，还是在消费板块的寒冬中？你的持仓在TMT成交占比48%的热区，还是在全市场中位数-15.4%的冷区？
- **温度几何？** ——科创50 PE 241倍、历史逼近100%分位——那是**滚烫的**；券商PE 4.78%分位、消费PE 6%分位——那是**冰冷的**。
- **该做什么？** ——在狂热区**保持警惕、控制仓位**；在寒冷区**逆向布局、耐心等待**。

马克斯的核心忠告：

> **“当形势良好、价格高企时，投资者迫不及待买进，把所有谨慎都抛诸脑后。随后，当周围环境一片混乱、资产廉价待沽时，他们又完全丧失了承担风险的意愿，迫不及待地卖出。永远如此。”**

> 💡 **2026年，不要成为“永远如此”中的一员。** 要成为那个在科技板块狂热时保持清醒，在消费板块寒冷时保持贪婪的少数人。

**卓越的投资不需要“预知未来”，而是需要对“当下现实”有深刻、清醒且独立的认知，并具备逆群体而行之的勇气。**
