# 🚀 A股房地产开发行业股票筛选综合评分体系
## v1.0-A 激进型投资者版 · 周期反转博弈 · 核心城市土地储备 · 融资成本差异化与估值重估

**适用范围**：A股房地产开发核心企业，主营业务为住宅/商业地产开发（收入或毛利占比≥50%）。 **不适用**：纯物业管理、房地产中介/经纪、房地产REITs、产业地产运营商（除非开发收入占主体）、建筑装饰/工程总包。 **适用投资者画像**：激进型投资者——在深度调整的地产行业中追求超额收益，敢于在行业底部左侧布局，博弈“周期反转+融资成本改善+核心城市土地重估+行业格局出清”的四重弹性，容忍高波动、高负债、表观亏损，核心能力是判断销售拐点、土储价值和融资环境变化。

**核心哲学**（周期博弈 + 安全边际 + 地产独有规律）：

- **估值锚定RNAV/PB，放弃PE**（周期底部PE奇高或为负恰是机会，净利润被减值压低，核心看净资产真实性和折价率）
- **经营杠杆是利润爆发的核心**（融资成本下行+销售均价回暖=净利率弹性最大化）
- **核心城市土储是胜负手**（高能级城市货值占比直接决定复苏弹性，低能级土储是包袱）
- **坏房子/好房子分化是估值撕裂根源**（产品力溢价从“概念”变为“定价能力”）
- **轻当期利润，重RNAV折价、PB历史分位、PS（销售导向）、股息率（现金奶牛）**
- **融资成本差异化将固化行业格局**（央国企2.X% vs 民企4%-6%，直接决定拿地和展期能力）
- **政策驱动是超级催化剂**（白名单融资、存量收储、城市更新、取消限购、降首付）
- **销售权益比决定利润归属**（操盘权/并表权直接影响归母净利兑现）

**【房地产新增】土储质量深度穿透**：重估价值=核心城市货值×（1+折价修复系数），远郊/三四线货值按清算价值打折。
**【房地产新增】真实净资产/RNAV折价是弹性核心**：市值/RNAV < 0.5的房企在周期反转时弹性最大。
**【房地产新增】存货减值充分度**：过去三年是否已充分计提存货跌价准备，未充分减值的房企是“账面地雷”。

### 七、核心口径修正（房地产开发特有）

#### 7.1 RNAV（重估净资产）折价率
**RNAV = 归母净资产账面价值 + 开发物业重估增值 + 投资物业重估增值（以公允价值计）**
- **开发物业**：已售未结货值×预期净利率 + 未售货值×（当前市价-成本率）。这是激进型评估底部低估程度的核心工具。**低RNAV折价率 + PB历史极低分位 + 销售拐点 = 最佳买点**。
- **激进型运用**：RNAV折价率>50%时赋予估值弹性溢价，折价<10%时强制减仓。

#### 7.2 销售权益比与回款率
房地产开发大量采用合作开发。须穿透权益销售额和全口径销售的区别。**激进型重点关注：权益销售额同比增速 + 销售回款率（连续3年>90%是加分项）。**

#### 7.3 存货减值充分度——激进型最关键的会计分析
激进型重仓时机：过去3-5年已**超额计提**存货减值的房企，未来减值转回/不再计提将释放利润弹性。核心指标：**累计计提减值/存货原值** 对比 **房价累计跌幅**。计提过少的房企是“账面地雷”，计提充分的房企才是“隐形王者”。

#### 7.4 融资成本差异化溢价
区分：央国企（2.5%-3.5%）> 优质民营（3.5%-5%）> 困难民企（>6%或无法融资）。融资成本低=拿地能力和展期能力的根本来源。

#### 7.5 土储质量穿透评分
单独评估土储的潜在价值：核心城市货值占比×1.0 + 高能级二线×0.7 + 三四线×0.3。在模块七额外加分。

#### 7.6 商业/经营性收入占比
商业+物业+长租+产办等持续性收入占比。占比>20%且持续提升者，给予“穿越周期”溢价，在周期高位下调E系数时更抗跌。

#### 7.7 三道红线指标穿透
- 剔除预收款后资产负债率 ≤ 70%（绿档）
- 净负债率 ≤ 100%（绿档）
- 现金短债比 ≥ 1.0（绿档）
激进型允许黄档，但红档房企需扣分或估值折价。


### 八、模块评分体系（总分100，激进型·房地产开发版权重重构）

**激进型权重哲学**：
- **估值与安全边际（M1）= 16分**（PB/RNAV折价/PS是核心，底部可天然高分）
- **土储质量与货值（M7）= 14分**（核心城市土储占比决定复苏弹性，权重提至最高）
- **周期弹性与边际改善（M3）= 14分**（销售拐点、回款率、新开工、拿地强度）
- **盈利能力与成本优势（M4）= 10分**（毛利率韧性、融资成本差异化、减值充分度）
- **财务健康与杠杆（M5）= 10分**（激进型重视净负债率、现金短债比、少数股东权益藏债）
- **全球化与第二曲线（M2）= 8分**（海外投资/物业经营/代建等新赛道放量）
- **周期位置与市场情绪（M9）= 8分**（择时核心，逆向指标）
- **核心竞争力与市占率（M8）= 7分**（产品力溢价、规模效应、品牌）
- **政策与催化剂（M10）= 7分**（白名单/收储/城市更新/降息预期）
- **治理与股东回报（M6）= 6分**（管理层诚信、分红、股权激励、低稀释）

### 九、交叉封顶与共振规则

- **周期底部双击**：当周期阶段为“冰点/底部”且模块一总分≥12（估值极低折价），模块九（周期位置）直接按满分8分计算，且额外+2分。

- **核心城市+土储质量共振**：若模块七（土储质量）≥11分，则模块三（周期弹性）可额外+1.5分（总模块分≤14）。

- **融资成本+白名单共振**：若模块四4.2（融资成本）≥2.0且模块十10.1（白名单）≥1.5，则最终得分×1.05。

- **景气高位压制**：当周期阶段为“繁荣期”时，模块三得分上限锁定为8分，模块九得分上限为2分。

- **表外风险惩罚**：若模块五5.4（少数股东权益陷阱）得分<0.5，原始总分额外×0.85。

### 十三、执行SOP

1. 拉取A股房地产开发股票池，按企业类型分类（央企龙头、地方国企、优质民企、中小房企等），剔除纯概念。
2. 判定当前行业景气周期阶段（基于百强房企销售额同比、30大中城市成交面积趋势、核心城市去化周期）。
3. 逐只核查近5年财务与运营数据，重点：RNAV折价率、土储质量（按货值口径）、销售回款率、融资成本、净负债率与现金短债比。
4. 拉取最新月度/季度数据：权益销售额环比/同比、新开工/竣工数据、合同负债变化、拿地强度、已售未结转金额。
5. 按硬红灯12项排雷，命中即归零。
6. 记录黄灯事项及扣分。
7. 计算模块一至模块十得分，执行交叉封顶与共振加成。
8. 扣除黄灯分，并执行表外风险/少数股东权益惩罚（若适用）。
9. 乘以周期修正系数E。
10. 计算估值熔断K（基于PB、PS、RNAV折价率子行业指标），若冰点期PB处于近10年最低10%分位可额外上浮K+0.07。
11. 数据置信度E级扣分。
12. 按激进型评级池分类，输出结果表，并给出景气阶段相应的仓位操作建议。
13. 结果中必须注明数据日期、周期判定依据（百强销售增速、30大中城市成交、去化周期）、关键假设及风险提示。
