# 中证酒·白酒行业综合财报与成长性评分体系（W1–W8 v1.0）

**版本**：v1.0 白酒专属定制版（基于化学制药H1–H9 v2.2框架移植改造）

**核心原则**：每次运行时，强制拉取并使用最新可得的公开数据（最新年报、最新季报、最近交易日行情），并严格按照标准作业程序（SOP）逐项执行。针对白酒行业特有的品牌价值、渠道库存、产品结构等核心要素，增设专项评估模块，确保评分的行业适配性、公平性与可复现性。

**适用范围**：A股白酒制造企业（中证白酒指数成分股及申万白酒行业分类标的），含高端、次高端、区域地产酒企。

**不适用**：啤酒、葡萄酒、黄酒及其他酒精饮料；白酒流通渠道商。


## 一、数据动态更新机制（强制）

| 数据类型 | 数据来源（优先级） | 更新频率要求 |
|---|---|---|
| 股价/市值 | 交易所实时行情（最近一个交易日收盘价） | 每次运行当日 |
| 财务数据（历史10年/上市以来） | Wind/CSMAR/同花顺（年报） | 至少包含截至最新年报披露日的完整可获取年限数据（若上市不足10年，以IPO招股书披露的完整3年+上市后所有年报替代，评分按年限折算） |
| 最新财报 | 最新年报 + 最新季报/中报（合并报表） | 若季报已披露，则采用季报；否则采用中报或年报 |
| 估值指标（PE/PB/PS/股息率） | 基于最新股价 + 最新财报TTM数据计算 | 每次运行重新计算 |
| **白酒行业特有数据** | 公司公告、渠道调研、酒业协会数据、主流电商平台动销数据 | 抓取至运行日之前的最新状态 |
| 前瞻预测数据 | 内部研究员调研模型 + Wind一致预期（取最新一期） | 每次运行更新预测基数（基于最新季报调整） |
| 机构持仓 | 公募基金季报、北向资金每日数据 | 取最新披露的季度末持仓及近3月流向 |

**数据有效性检查与兜底条款**：

- **时效性检查**：若最新财报发布日期超过6个月，须标记为"数据滞后"，并强制等待最新季报或使用已披露的最新数据。
- **渠道数据兜底**：若某标的的渠道库存、批价等非强制披露数据无法获取公开来源，则该子项自动赋满分的60%作为基准分，并在报告中标注"数据缺失，按基准分处理"。
- **产品结构数据**：若公司未披露细分价格带产品收入占比，可通过Wind一致预期或券商调研数据补充，并标注置信度。

## 四、白酒行业周期位置修正系数（E）

依据当前最新行业数据（PE分位、持仓、批价趋势、库存周期、宏观经济指标）判定：

| 周期阶段 | 判定标准（基于最新数据） | 修正系数E |
|---|---|---|
| **冰点/底部区** | 板块PE处于近10年最低15%分位，公募持仓历史低位，批价全面承压，渠道去库接近尾声，市场预期极度悲观 | **1.30** |
| **弱复苏/黎明期** | 批价企稳，库存回归健康水位，头部酒企动销改善，持仓开始回升，宏观消费数据边际改善 | **1.15** |
| **景气上行/兑现期** | 高端酒放量加速，次高端恢复增长，吨价提升，业绩增速提升，估值合理 | **1.00** |
| **过热/泡沫区** | 估值泡沫化（PE>80%分位），市场过度乐观，渠道盲目囤货，非理性追捧 | **0.80** |
| **政策冲击区** | 消费税改革超预期、限制三公消费政策加码、宏观经济大幅下行 | **0.65** |

**当前（2026年7月1日）判定**：根据公开数据，白酒板块PE(TTM)约20x，处于10年18%分位、5年34%分位；1Q26板块营收同比-0.7%、归母净利同比-1.8%，降幅显著收窄；行业持续去库，产量降幅收窄至个位数；高盛判断"最困难阶段已经过去"。综合判断为 **🟡 弱复苏/黎明期（E=1.15）** 。

基于最新股价和近10年历史PE/PS分位计算。

| 估值条件（取PE与PS分位中较高者） | 熔断系数K | 名优酒企豁免条件 |
|---|---|---|
| **高端名酒：PE<15x 或 10年PE分位<10%** | 1.00 | — |
| **高端名酒：PE 15~22x 或 PE分位10%~30%** | 0.92 | — |
| **高端名酒：PE 22~30x 或 PE分位30%~70%** | 0.85 | — |
| **高端名酒：PE>30x 或 PE分位>70%** | 0.72 | 若公司为全国性名酒且股息率>4%，K下限锁定为0.85 |
| **高端名酒：PE>40x 或 PE分位>90%** | 0.50（强制清仓） | 同上，锁定0.85 |
| **次高端/地产酒：前瞻PE<12x且股息率>4%** | 1.00 | — |
| **次高端/地产酒：PE 12~20x** | 0.92 | — |
| **次高端/地产酒：PE>20x** | 0.80 | 若公司为省级龙头且市占率>30%，K系数参照高端名酒阈值执行 |
| **周期底部上浮**：若当前判定为"冰点/底部区"（E=1.30），且PE分位<15%，K可上浮+0.07（上限1.00） | | |

## 八、最终计分公式与主观调节器

原始总分 = W1 + W2 + W3 + W4 + W5 + W6 + W7 + W8（满分100）
扣除黄灯扣分（累加）
执行交叉加分（若加分后模块得分超过满分，则封顶）
周期修正 = 原始总分 × E
估值熔断 = 周期修正分 × K
置信度惩罚：若W6（前瞻预测）数据置信度为D级（纯第三方预测），最终得分×0.85
主观调节器：在最终得分（熔断后）给予研究员 ±3% 的浮动权限（需在输出报告中备注详细理由）
最终得分 = min(100, 熔断后得分 ± 主观调节)

## 十、标准作业程序（SOP）

**步骤0**：数据可得性预检查——遍历所有待评分标的，标记出"非强制披露项"（如分价格带收入明细、渠道库存天数等），预设基准分（满分的60%）。

**步骤1**：数据准备——获取最新交易日行情、最新财报、近10年历史数据、行业特有数据、Wind一致预期、卖方覆盖报告数量。

**步骤2**：硬红灯排查——逐项检查12条，命中即淘汰。

**步骤3**：行业周期判定（计算E）。

**步骤4**：黄灯扣分项检查。

**步骤5**：模块评分（W1–W8）。

**步骤6**：交叉加分。

**步骤7**：计算原始总分并扣除黄灯。

**步骤8**：计算估值熔断系数K。

**步骤9**：最终得分计算。

**步骤10**：评级与仓位决策。

**步骤11**：输出报告（必须包含"数据可得性兜底明细"章节）。

**步骤12**：存档与跟踪。
