# 📌 核心哲学（品牌护城河 + 周期博弈 + 安全边际 + 消费趋势）

- **估值锚定前瞻PE/DCF/PS**：放弃周期底部的静态PE，核心看前瞻PE。白酒行业高ROE、高自由现金流特性适合DCF模型，底部区域前瞻PE处于历史10%分位以下是理想买点。
- **品牌力是穿越周期的唯一护城河**：高端白酒（茅台/五粮液/老窖）具备不可复制的历史地位和社交属性，在大周期下行时抗跌性显著强于次高端和地产酒。
- **高端化与全国化是增量核心**：产品结构升级（吨价提升）+全国化扩张（省外收入占比）是打破区域和价格天花板的胜负手，但须警惕无效扩张带来的费用黑洞。
- **渠道健康度决定复苏弹性**：渠道库存、批价价差、经销商数量变化是白酒行业特有的先行指标，报表质量（合同负债、经营性现金流、销售收现比）反映真实动销。
- **轻当期利润，重吨价趋势、合同负债、销售收现比**：白酒行业可通过渠道压货调节报表，真实需求看终端动销、批价价差和现金回款质量。
- **存量集中是不可逆趋势**：总产量从2016年峰值1358万千升降至2025年的354.9万千升，收入利润向头部集中，市占率提升是进攻方向。
- **股东回报进入新时代**：龙头分红率普遍在65%以上，合计派息超千亿，股息率成为重要安全边际。
- **政策催化是方向性信号**：消费税改革、消费刺激政策等可加速板块估值修复。
- **报表真实出清是进场信号**：激进型主动博弈率先计提减值、主动去库存的“牺牲利润换健康”型酒企。
- **新渠道与新人群是增长引擎**：电商直营（如i茅台）、年轻化营销、低度化产品，是新周期中抢占增量市场的关键。
- **基酒库龄是隐性风险**：酱酒企业大量储存的基酒存在过期减值风险，成品酒周转率决定真实动销效率。
- **消费趋势代际切换**：年轻人不爱喝高度白酒已成结构性趋势，低度化、利口化、场景轻量化、内容电商触达是未来十年的胜负手。

## 二、数据置信度标记

| 等级 | 含义 |
|------|------|
| A | 年报、季报、交易所公告、行业协会报告 |
| B | 公司路演、投资者关系、机构调研纪要 |
| C | 政府规划文件、税务总局政策文件 |
| D | 券商模型、第三方渠道调研、草根调研 |
| E | 数据缺失或无法验证 |

**激进型规则**：核心运营指标（分价格带收入、省外收入、经销商数量）须为A/B级；若核心动销指标（渠道库存、批价价差）为D/E，最终得分×0.85。基酒库龄数据若为E级，直接扣减5分。消费趋势指标中低度酒收入占比须为A/B级，其余可为D级但需交叉验证。

## 七、核心口径修正（白酒行业特有）

### 7.1 前瞻PE（Forward PE）
静态PE在行业下行期会因利润下滑而飙升。激进型必需使用前瞻PE（基于未来1-2年的一致预期EPS）。运用：前瞻PE处于历史20%分位以下 + 前瞻PE/历史均值<0.6 = 最佳买点。

### 7.2 合同负债（预收账款）
反映经销商打款意愿，领先营收变化1-2个季度。激进型加分：合同负债连续2季度环比增长>10%，且同比增长转正。

### 7.3 渠道库存与批价价差（修正版）
- **健康区间**：渠道库存1.5-3个月，批价与内部结算价的价差率 > 15%（经销商利润充足）
- **警戒区间**：渠道库存3-4个月，价差率 5%-15%
- **危险区间**：渠道库存>4个月，价差率 <5% 或跌破出厂价

价差率计算公式：(核心单品批价 - 内部结算价/综合打款价) / 内部结算价 × 100%

### 7.4 吨价与产品结构
吨价 = 白酒收入 / 销量（万吨）。激进型加分项：吨价同比增速>10%，且高端产品收入占比提升>5个百分点/年。惩罚项：连续2年吨价下滑，模块七中本项得分清零。

### 7.5 省外收入占比与增速
激进型重点关注：省外收入占比>50% + 省外增速>省内增速 + 核心省外市场市占率提升。警示：对于省外收入占比<30%且销售费用率同比提升超过5个百分点的酒企，扣减模块八得分。

### 7.6 经销商数量与质量
经销商数量净增 > 0 表示渠道扩张；单商产出提升 = 营收/经销商数量。激进型偏好：经销商数量稳定或优化 + 单商产出提升。

### 7.7 经营性现金流 vs 销售收现比
白酒行业现金流普遍充裕，但近年部分酒企出现“账面盈利、现金流为负”的现象。强化指标：销售收现比（销售商品收到的现金/营业收入） > 1.0 为健康，<0.85 为警戒。经营性现金流/净利润 > 0.8 为底线。

### 7.8 主动报表出清——激进型最佳买点
酒企主动计提减值、费用前置导致利润大幅下滑，但渠道库存和批价价差已恢复健康，是典型的“牺牲利润换健康”。例如：泸州老窖2025年业绩调整后股息率高达5.8%，报表主动释压。

### 7.9 消费税改革影响
2026年6月1日起，白酒消费税引入“出厂价与关联方对外售价60%孰高”原则。对拥有自营销售公司的酒企（如茅台）影响有限；对大量依赖关联交易避税的中小酒企影响较大。激进型偏好受新规影响小、合规成本低的龙头。

### 7.10 股东回报（分红+回购）
激进型核心关注：股息率>4%且分红稳定 + 分红率>60% + 若有回购注销更佳。

### 7.11 基酒库龄与减值风险
基酒（尤其酱酒）储存超过3年，风味下降风险增加，且可能面临计提减值。考核指标：基酒库龄结构（A/B级数据强制要求）、成品酒周转率。周转率连续下滑或库龄老化严重者，触发黄灯扣分及基酒调整系数L。

### 7.12 【新增】消费趋势核心指标
- **低度化收入占比**：≤40%vol产品收入占总白酒收入比例
- **Z世代用户占比**：线上渠道18-30岁消费者比例
- **即时零售增速**：美团/京东到家/抖音小时达等渠道销售额同比
- **年轻化营销ROI**：联名款/潮饮活动投入产出比（参考社交声量转化）
- **小瓶化率**：≤200ml产品收入占比

## 十一、交叉封顶与共振规则

1. **估值底部+周期冰点双击**：当周期阶段为“冰点/底部区”且模块一（估值）总分≥14，模块三（周期弹性）直接按满分计算，且额外+2分。
2. **高端化+全国化共振**：若模块七（品牌力）≥12分且模块八8.1（省外占比）得分≥3，则模块三（周期弹性）额外+1.5分（模块总分≤14）。
3. **高股息+低估值共振**：若股息率>4.5%且前瞻PE<15倍，模块一额外+1.5分（总分≤18）。
4. **报表主动出清加分**：若酒企主动计提减值、费用前置导致利润大幅下滑但渠道库存<3个月、批价价差>10%，则模块三额外+2分。
5. **白名单/消费税受益共振**：若模块六6.1（消费税改革）得分≥1.5且6.2（消费刺激）得分≥1.0，则最终得分×1.03。
6. **景气高位压制**：当周期阶段为“成熟期”时，模块三得分上限锁定为8分；为“下行初期”时，模块三得分上限锁定为5分。
7. **经营现金流惩罚**：若经营性现金流/净利润<0.6且连续2年，原始总分额外×0.85。
8. **无效扩张惩罚**：若省外收入占比<30%且销售费用率同比提升超过5个百分点，模块八最终得分×0.80。
9. **【新增】消费趋势共振**：若 M12 总分 ≥ 6.5 且 模块七品牌力 ≥ 12，则 T 额外 +0.02（T 上限 1.15）。

## 十三、最终计分公式

模块合计分 = M1 + M2 + M3 + M4 + M5 + M6 + M7 + M8 + M9 + M10 - M11（扣分绝对值）
执行交叉封顶与共振加成 → 调整后模块总分（≤100）
原始总分 = max(0, 调整后总分 - 黄灯扣分)
若经营性现金流/净利润<0.6且连续2年，原始总分 × 0.85
周期修正后得分 = 原始总分 × E
熔断后得分 = 周期修正后得分 × K
基酒修正后得分 = 熔断后得分 × L
消费趋势修正后得分 = 基酒修正后得分 × T
最终得分 = min(100, 消费趋势修正后得分)
若数据置信度有E级关键指标，最终得分 × 0.85

## 十五、执行SOP（激进型美化版）

1. 拉取A股白酒股票池，按企业类型分类（高端龙头、次高端、地产酒等）。
2. 判定当前行业景气周期阶段（基于产量/收入增速、批价价差、餐饮数据）。
3. 逐只核查近5年财务与运营数据（吨价、库存、批价价差、合同负债、省外占比、分红、基酒库龄、低度酒占比、Z世代数据）。
4. 拉取最新季度数据（营收增速、合同负债环比、批价价差走势、渠道库存、销售收现比、即时零售增速、社交声量）。
5. 硬红灯12项排雷，命中即淘汰。
6. 记录黄灯事项及扣分（含新增的黄灯：无低度化布局、Z世代渗透率低）。
7. 计算模块一至模块十一得分，执行交叉封顶与共振加成。
8. 计算模块十二消费趋势得分，转换为T系数。
9. 扣除黄灯分，执行经营现金流惩罚及无效扩张惩罚。
10. 乘以周期修正系数E（冰点1.25，弱复苏1.15，成熟期0.95，下行0.75）。
11. 计算估值熔断K，冰点期PB处于近10年最低10%分位可上浮+0.07。
12. 计算基酒库龄调整系数L。
13. 乘以消费趋势系数T。
14. 数据置信度E级扣分。
15. 按评级池分类输出卡片及汇总表，给出仓位建议。

## 十六、⚠️ 关键风险提示（激进型必读）

- 白酒总产量较峰值下降超70%，存量竞争惨烈，次高端和地产酒分化极度剧烈。
- 五粮液2025年会计差错更正，须持续跟踪财务真实性，警惕其他酒企类似风险。
- 2025年“新禁酒令”对政务消费占比高的酒企构成结构性压制。
- 年轻人不爱喝高度白酒是长期结构性风险，低度化布局滞后的酒企可能面临长达十年的需求萎缩。
- 激进型博弈的是“存量集中+消费升级+消费趋势切换”的三重逻辑，须以3-5年维度持有。
- 每季度重新评估，若连续两季度批价价差走弱或库存超6个月，应下调评级。
- 酱酒企业须重点关注基酒库龄，3年以上基酒占比过高可能引发大规模减值。
- 销售收现比低于0.85是渠道压货或回款恶化的危险信号，即使利润表好看也须回避。
- 消费趋势T系数可能因年轻化营销效果不及预期而快速回落，需动态跟踪社交声量和Z世代复购率。
