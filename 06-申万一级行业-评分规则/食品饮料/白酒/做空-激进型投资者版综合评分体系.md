# 🍶 白酒行业做空评分框架（激进型·空头版）

> **核心理念**：做空是“价值毁灭”的发现游戏。本框架将原多头评分体系全盘逆转为空头逻辑——**高估值透支、渠道堰塞湖、消费代际断层、治理瑕疵**是核心做空驱动力。空头应在“周期过热/下行初期”建立头寸，在“冰点期”兑现离场。


## 📌 核心哲学（做空驱动逻辑）

- **估值泡沫是最好燃料**：静态PE膨胀、PS非理性溢价、股息率丧失防御价值——当市场把“确定性”定价为“永续增长”，便是做空的完美时点。
- **渠道堰塞湖必然决堤**：白酒行业具备天然压货属性。当渠道库存>6个月、批价价差<5%（或倒挂）、经销商大面积亏损，报表利润越好看，未来崩塌越剧烈。
- **消费代际切换不可逆**：年轻人不喝高度白酒是结构性趋势，不布局低度化、不触达Z世代的酒企，长期需求底做空-激进型投资者版综合评分体系座正在被蚕食。
- **存量竞争是零和博弈**：行业产量较峰值下降超70%，次高端及地产酒在份额争夺战中失败者将面临利润骤降甚至出清。
- **治理瑕疵是催化剂**：财务差错、关联交易、大股东质押、管理层频繁更迭——在行业下行期，治理问题会被放大为估值折价。
- **高端化/全国化失败的后遗症**：无效扩张导致费用黑洞，一旦省外扩张受阻且省内份额被侵蚀，利润将遭遇“戴维斯双杀”。


## 一、强制数据口径

> 与多头版一致，做空版同样依赖完整数据交叉验证。数据置信度不足时，评分权重打折处理（详见置信度标记）。

| 数据类型 | 必须使用 |
|---|---|
| 股价/市值 | 最近一个交易日A股收盘价 |
| 财务数据 | 最新年报 + 最新季报/中报（合并报表） |
| 历史数据 | 至少5个完整会计年度（2021年峰值→2026年调整周期） |
| 估值数据 | PE(TTM)、前瞻PE、PB(LF)、PS(TTM)、PCF、股息率TTM、EV/EBITDA |
| 行业数据 | 全国白酒产量/销售收入/利润总额增速、规模以上酒企数量 |
| 渠道数据 | 渠道库存水平（月数）、核心单品批价价差率、经销商数量变动 |
| 区域数据 | 省内/省外收入占比、省外增速 |
| 治理数据 | 管理层持股/股权激励、大股东背景、历史信披违规、会计差错 |
| 市场数据 | 机构持仓比例（公募+北向）、北向资金流向、日均成交额、52周高低点 |
| 基酒数据 | 基酒库龄结构、成品酒周转率、基酒减值计提 |
| 消费趋势 | 低度酒收入占比、Z世代线上渗透率、社交媒体声量、即时零售增速 |


## 二、数据置信度标记

| 等级 | 含义 |
|---|---|
| A | 年报、季报、交易所公告、行业协会报告 |
| B | 公司路演、投资者关系、机构调研纪要 |
| C | 政府规划文件、税务总局政策文件 |
| D | 券商模型、第三方渠道调研、草根调研 |
| E | 数据缺失或无法验证 |

**空头版置信度规则**：若核心做空信号（渠道库存、批价价差）为D/E级，评分权重×0.80（低于多头的0.85，因为做空对数据真实性要求更高）。基酒库龄数据E级，直接扣减（加分）空头得分。


## 三、前置硬性做空触发条件（🚨 强制做空信号）

> 触发任一条件，该标**直接纳入做空候选池**，评分权重上调。

| # | 类别 | 强制做空信号 |
|---|---|---|
| 1 | **估值极度泡沫化** | 前瞻PE > 历史均值×1.8倍，且股息率 < 1.0%（无安全边际） |
| 2 | **渠道库存危机** | 渠道库存 > 8个月；或核心大单品批价跌破出厂价（倒挂）持续超3个月 |
| 3 | **需求断崖** | 连续3个季度营收同比下滑 > 25%；且合同负债同比下滑 > 50% |
| 4 | **盈利崩塌** | 单季度亏损且亏损幅度同比扩大 > 200%；或ROE跌破8% |
| 5 | **核心大单品崩盘** | 高端/次高端核心单品营收同比下滑 > 40%，且无替代增长极 |
| 6 | **治理黑天鹅** | 公司或实控人近3年被认定财务造假/信披违规；近5年重大会计差错更正涉及金额 > 营收的3% |
| 7 | **消费代际脱节** | 低度化收入占比 = 0，且线上Z世代渗透率 < 3%（严重脱离年轻消费趋势） |
| 8 | **基酒堰塞湖** | 基酒库龄 > 5年占比 > 40%（酱酒适用），且成品酒周转率连续3年下滑（减值炸弹） |
| 9 | **流动性陷阱** | 日均成交额 < 5000万元且总市值 < 50亿元（做空流动性不足，排除） |
| 10 | **政策逆风** | 消费税改革对关联交易占比高的酒企负面影响显著；或三公消费限制再度收紧 |

> **空头版一票否决**（排除标的）：ST/*ST、连续2年审计意见非标、实控人资金占用>净资产5%、重大食品安全事故——这些标的做空流动性不足或存在停牌风险，直接剔除。


## 四、做空加分项（空头版“黄灯”）

> 做空框架下，原多头版“黄灯扣分”转化为“做空加分项”。累计加分越高，做空逻辑越强。

| 做空加分事项 | 加分幅度 |
|---|---|
| 省内市场依赖 > 75%（区域集中，缺乏增长想象空间） | +3 ~ +6 |
| 次高端及以下价格带收入占比 > 60%（高端化动力不足，利润天花板低） | +3 ~ +6 |
| 合同负债同比下滑 > 30%（经销商打款意愿崩塌，未来收入无锚） | +4 ~ +8 |
| 核心大单品批价价差率连续3个月走弱（收窄超5pct） | +3 ~ +6 |
| 经营性现金流净额连续2年为负（账面利润造假嫌疑） | +4 ~ +8 |
| 销售收现比 < 0.85 且连续2年（回款质量差，渠道压货） | +4 ~ +6 |
| 渠道库存 > 4个月（健康上限，未来去库压力巨大） | +3 ~ +5 |
| 经销商数量连续2年净减少 > 15%（渠道萎缩，市场信心溃散） | +3 ~ +6 |
| 销售费用率 > 30% 且毛销差连续2年下滑（砸钱换增长模式失效） | +2 ~ +5 |
| 毛利率同比下滑 > 5个百分点（产品结构降级，成本失控） | +3 ~ +5 |
| 大股东近2年减持超过持股的8%（内部人看空信号） | +3 ~ +5 |
| 核心管理层近1年减持超过持股的1.5%（高管不信任自家股票） | +2 ~ +4 |
| 近3年定增/配股稀释股本 > 10%（摊薄股东价值） | +2 ~ +4 |
| 股息率 < 1.5%（无防御价值，完全靠博弈支撑股价） | +1 ~ +3 |
| 机构持仓占比 < 3%（主流资金已撤离，只剩散户博弈） | +2 ~ +3 |
| 基酒库龄 > 3年占比 > 30%（酱酒减值风险，其他香型折半） | +3 ~ +5 |
| 成品酒周转率连续2年下滑（动销在恶化，产品滞销） | +2 ~ +3 |
| **无低度化产品布局**（与Z世代消费习惯脱节，失去未来） | +2 ~ +4 |
| **Z世代线上渗透率 < 5%**（线上渠道代际切换失败） | +2 ~ +3 |


## 五、周期位置做空修正系数（空头版）

| 周期阶段 | 特征 | 空头态度 | 修正系数 E_short |
|---|---|---|---|
| 🔥 过热/狂热期 | 估值泡沫化，批价虚高，渠道大规模压货，市场一致看多 | **重仓做空** | **1.35** |
| 📉 下行初期 | 增速放缓，库存开始累积，批价松动，经销商窜货乱价 | **核心加仓做空** | **1.20** |
| ⚖️ 稳健增长/成熟期 | 中个位数增长，竞争格局稳定，但估值合理偏低 | **轻仓试探** | **0.85** |
| 🌱 弱复苏/黎明期 | 收入降幅收窄，库存去化，批价企稳回升 | **空头回补/平仓** | **0.70** |
| 🔴 冰点/底部区 | 产量/收入双位数下滑，市场极度悲观，大面积亏损 | **全部平仓离场** | **0.50** |

> **关键逻辑**：做空的最佳窗口是“过热期”和“下行初期”。弱复苏及冰点期做空的风险收益比极差，应果断平仓。


## 六、做空估值熔断系数（空头版）

> 做空版核心逻辑：**估值越高，做空空间越大**。K_short与多头版K完全相反。

### 6.1 做空估值阈值（激进型空头版）

| 企业类型 | 核心估值指标 | 🟢 极度高估（最佳做空） | 🟡 偏高（可做空） | 🟠 合理（观望） | 🔴 低估（不做空） |
|---|---|---|---|---|---|
| 高端龙头 | 前瞻PE | > 30x | 25-30x | 18-25x | < 18x |
|  | PB(LF) | > 12x | 9-12x | 6-9x | < 6x |
|  | 股息率TTM | < 1.0% | 1.0%-2.0% | 2.0%-3.5% | > 3.5% |
| 次高端龙头 | 前瞻PE | > 35x | 25-35x | 15-25x | < 15x |
|  | PS(TTM) | > 10x | 7-10x | 4-7x | < 4x |
| 地产酒龙头 | 前瞻PE | > 30x | 20-30x | 12-20x | < 12x |
|  | PB(LF) | > 5x | 3.5-5x | 2-3.5x | < 2x |

### 6.2 做空熔断系数 K_short

| 条件 | K_short |
|---|---|
| 前瞻PE进入极度高估区 + PB高估 + 股息率<1.5% | **1.25** |
| 前瞻PE偏高区 + PB偏高 | **1.10** |
| 前瞻PE合理区（中高位） | **1.00** |
| 前瞻PE合理区（中低位） | **0.85** |
| 任一指标进入低估区 | **0.60（不做空或仅轻仓）** |

> 当周期处于“过热/下行初期”且前瞻PE处于近5年最高10%分位，K_short额外上浮 +0.10。


## 七、核心做空指标口径（空头版修正）

| 指标 | 多头逻辑 | **空头逻辑（做空信号强化）** |
|---|---|---|
| **前瞻PE** | 低估时买入 | **高估时做空**。前瞻PE > 历史均值×1.5倍是危险信号；PS(TTM) > 8x（次高端）或 > 15x（高端）暗示市场给予过度溢价 |
| **合同负债** | 增长=景气 | **骤降=危机**。合同负债同比下滑 > 30% 意味着经销商打款意愿断崖式下跌，未来2个季度收入无保障——这是做空的“先行指标” |
| **渠道库存+批价价差** | 健康=持有 | **恶化=做空**。库存>6个月+价差<5%是“死亡组合”；若批价跌破出厂价（倒挂），直接触发强制做空信号 |
| **吨价与产品结构** | 吨价提升=升级 | **吨价增速骤降或转负=结构降级**。连续2年吨价下滑，意味着高端化彻底失败，是次高端/地产酒的核心做空逻辑 |
| **省外收入** | 扩张=增长 | **扩张失败=双击杀**。省外收入占比<30%且销售费用率飙升 > 5pct——无效扩张带来的费用黑洞将严重侵蚀利润 |
| **经销商数量** | 扩张=渠道信心 | **净减少+单商产出下滑=渠道溃败**。连续2年净减>15%是渠道信心崩溃的信号 |
| **销售收现比** | >1.0=健康 | **<0.85=做空信号**。收现比持续低于0.85说明利润表“虚胖”——大量应收账款或票据贴现，真实回款能力恶化 |
| **主动报表出清** | 买入机会 | **阶段性反弹做空窗口**：报表出清后可能迎来短期反弹，但若行业景气未反转，反弹是做空的二次加仓点 |
| **基酒库龄** | — | **减值炸弹**：酱酒基酒库龄>3年占比>30%意味着未来可能大规模计提减值，直接冲击利润表 |
| **股东回报** | 高股息=安全边际 | **低股息=无防御**：股息率<1.5%说明无论公司还是市场都不认为该股有配置价值，股价全靠博弈支撑 |
| **消费税改革** | 龙头受益出清 | **中小酒企利润压缩**：对关联交易依赖度高、自营销售体系不完善的酒企，新规将直接侵蚀净利润 |

## 十五、执行SOP（激进型空头版）

1. **拉取A股白酒股票池**，按企业类型分类（高端/次高端/地产酒），剔除ST/*ST及流动性不足标的
2. **判定当前行业景气周期阶段**——过热/下行初期是最佳做空窗口，弱复苏/冰点期应回避
3. **逐只核查估值泡沫化程度**：前瞻PE历史分位、PS(TTM)、股息率——估值越高，做空确定性越强
4. **深度扫描渠道数据**：渠道库存月数、批价价差率、经销商数量变动——这是白酒做空最核心的“先行指标”
5. **评估消费趋势脱节程度**：低度化布局、Z世代渗透率、社交声量——脱离年轻消费趋势=长期价值毁灭
6. **逐项过“强制做空触发条件”**（10项），命中越多做空确定性越高
7. **核算S-M1至S-M12各模块得分**，执行交叉共振加成
8. **扣除/加总做空加分项**，乘以周期修正系数E_short
9. **计算估值熔断K_short**，过热期高估值标的K值可达1.25
10. **乘以基酒调整系数L_short**（基酒老化严重者放大做空弹性）
11. **乘以消费趋势系数T_short**（脱离年轻人者T值最高达1.20）
12. **数据置信度E级扣减**（×0.80）
13. **按评级池分类输出卡片及汇总表**，给出做空仓位建议和平仓条件


## 十六、⚠️ 做空关键风险提示（空头必读）

1. **白酒板块具备极强政策博弈属性**：消费刺激政策、国企改革等可能引发脉冲式反弹，做空须严格设置止损线（建议-20%）
2. **高端龙头（茅五泸）做空须极谨慎**：其品牌护城河和金融属性可能导致估值长时间维持高位，做空窗口极短
3. **茅台批价是行业风向标**：若茅台批价企稳回升，即使其他酒企基本面恶化，板块整体也可能反弹，需动态管理净空头敞口
4. **做空工具限制**：A股做空主要依赖融资融券，须提前确认标的券源充足、融券费率可控
5. **不要在冰点期做空**：市场极度悲观时，任何边际改善都可能引发报复性反弹——空头应在“人声鼎沸时卖出，在无人问津时买入平仓”
6. **每季度重新评估**：若连续两季度合同负债回暖+批价价差修复+库存去化至<4个月，应果断平仓
