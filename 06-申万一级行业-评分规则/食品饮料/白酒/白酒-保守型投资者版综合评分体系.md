# 🛡️ A股白酒行业股票筛选综合评分体系
## v1.0-C 保守型投资者版 · 稳健经营 · 高确定性 · 现金流为王 · 股息护城河

**适用范围**：A股白酒制造核心企业，主营业务为白酒酿造与销售（收入或毛利占比≥70%）。  
**不适用**：啤酒、葡萄酒、黄酒等非白酒品类；酒类流通渠道商（如华致酒行等）；业务中不含独立酿造环节的贴牌商。  
**适用投资者画像**：保守型投资者——追求长期稳健回报，规避本金永久性损失风险，将白酒作为低波动、高分红、类债券的核心底仓配置。不接受周期底部的不确定性，不博弈左侧反转，只在行业右侧确认、动销改善、报表健康后以合理估值介入。核心能力是识别持续经营能力、现金流质量、品牌护城河的深度和股东回报的可持续性。

**核心哲学（稳健·安全·可持续）**：
- **估值锚定股息率与自由现金流**：股息率是保守型投资者的“利息收入”，要求股息率 ≥ 4% 且分红稳定；自由现金流必须持续为正且覆盖资本开支。前瞻PE仅作参考，不博弈估值修复。
- **品牌力是唯一的永续护城河**：只有全国性高端品牌（茅、五、泸）具备穿越周期、永不消亡的特质。次高端和地产酒在经济下行期存在品牌折价和渠道崩塌风险，保守型原则上只投资于高端龙头。
- **拒绝杠杆，拒绝激进扩张**：净负债率必须为负（净现金），货币资金/有息负债 > 10倍。省外扩张必须已形成稳定产出，不接受烧钱式全国化。
- **渠道健康是底线**：渠道库存 < 3个月，核心单品批价与出厂价的价差率 > 15%，经销商数量连续3年稳定或优化，无压货行为。
- **利润质量重于利润规模**：经营现金流/净利润 > 1.0，销售收现比 > 1.10，合同负债持续增长或稳定，应收账款/营收 < 1%。
- **股东回报是唯一可靠的收益来源**：股息率不低于同期10年期国债收益率+2个百分点，连续5年分红且分红率 > 70%，有回购注销记录者优先。
- **只右侧，不左侧**：行业必须处于“弱复苏”或“稳健增长”阶段才可建仓。“冰点/底部区”只观望，不买入。“过热/下行初期”立即清仓。
- **低波动是保护**：股价52周最大回撤 < 30%，日均换手率 < 2%，机构持仓占比高（公募+北向 > 15%），避免游资主导的标的。
- **规避一切潜在的“雷”**：无会计差错历史、无实控人减持记录、无食品安全事件、无审计非标意见、无监管问询函。

## 三、前置一票否决：硬红灯项（保守型·底线思维更严）

触发任一硬红灯，最终得分 = 0，直接淘汰。

| # | 类别 | 硬红灯标准（相比激进型更严） |
|---|------|------------------------------|
| 1 | 交易状态 | ST、*ST、风险警示板、暂停上市风险；或股价低于净资产 |
| 2 | 审计诚信 | 近5年任一年审计意见为保留意见、否定或无法表示意见；年报披露前6个月内换所 |
| 3 | 治理黑历史 | 公司或实控人近5年被认定财务造假、内幕交易、操纵市场；大股东资金占用>1%且未清偿；实控人被调查、留置 |
| 4 | 食品安全 | 发生任何食品安全事故（含被省级以上监管部门通报批评）；核心产品抽检不合格 |
| 5 | 实控人/管理层 | 实控人质押>30%；或有息负债/EBITDA>5；核心管理层2年内全部更换 |
| 6 | 流动性/规模 | 日均成交额 < 1亿元；或总市值 < 300亿元（保守型只考虑中大型酒企） |
| 7 | 【债务炸弹】资不抵债 | 有息负债/EBITDA > 4；归母净资产低于50亿；连续2年经营现金流为负 |
| 8 | 【渠道炸弹】库存危机 | 渠道库存 > 3个月；核心大单品批价与出厂价价差率 < 10%（经销商利润薄） |
| 9 | 【需求恶化】销售断崖 | 连续2个季度营收同比下滑 > 15%；且合同负债同比下滑 > 30% |
| 10 | 【盈利断崖】严重亏损 | 最近一年归母净利润为负；或连续2年净利润下滑 > 30% |
| 11 | 【产品力崩塌】核心大单品失速 | 高端/次高端核心单品营收同比下滑 > 20%，且无增长引擎 |
| 12 | **【会计诚信】重大差错或问询** | 近5年发生过会计差错更正（无论金额）；或近2年收到交易所年报问询函 |
| 13 | **【估值泡沫】股息率过低** | 股息率TTM < 同期10年期国债收益率（当前约2.7%） |
| 14 | **【波动率过大】回撤超限** | 近52周最大回撤 > 35%（白酒行业整体允许放宽至40%，但个股不得超过） |
| 15 | **【治理瑕疵】管理层减持** | 核心管理层/实控人近2年有任何减持记录（含集合竞价、大宗交易） |

**保守型底线**：宁可错过，不可买错。所有标的要求至少连续5年盈利、连续5年分红、连续5年经营现金流为正。

## 五、白酒周期位置修正条款（保守型：严禁左侧，右侧确认）

### 5.1 周期阶段判定表

| 周期阶段 | 特征 | 关键信号 | 保守型态度 | 修正系数E |
|---------|------|---------|-----------|----------|
| 冰点/底部区 | 产量/收入双位数下滑，批价持续走弱，市场极度悲观 | 产量降幅开始收窄，茅台批价企稳 | **不入场，观望** | **0.80**（惩罚左侧） |
| 弱复苏/黎明期 | 收入降幅收窄至个位数，高端酒批价回升，库存去化至健康 | 连续2季度收入环比改善，合同负债回暖 | **分批建仓右侧** | **1.00** |
| 稳健增长/成熟期 | 收入中高个位数增长，结构升级稳步推进 | 行业集中度持续提升，头部市占率扩大 | **核心持有期** | **1.10** |

## 六、估值天花板熔断机制（保守型·严格估值约束）

**最终得分 = (模块合计分 - 黄灯扣分) × E × K × V**

其中 **V 为波动率调整系数**（见后）。

| 企业类型 | 核心估值指标 | 极度低估（可加仓） | 合理区间（持有） | 高估预警（减仓） | 泡沫区（清仓） |
|---------|-------------|------------------|----------------|---------------|---------------|
| 高端龙头（茅/五/泸） | 前瞻PE | ≤12x | 12-18x | 18-22x | >22x |
| | PB(LF) | ≤4x | 4-6x | 6-8x | >8x |
| | 股息率TTM | ≥5.0% | 4.0%-5.0% | 3.0%-4.0% | <3.0% |
| 次高端龙头（汾酒/舍得/酒鬼） | 前瞻PE | ≤10x | 10-15x | 15-18x | >18x |
| | PS(TTM) | ≤3x | 3-4.5x | 4.5-6x | >6x |
| 地产酒龙头（洋河/古井/今世缘） | 前瞻PE | ≤8x | 8-12x | 12-15x | >15x |
| | PB(LF) | ≤1.5x | 1.5-2.5x | 2.5-3.5x | >3.5x |

**保守型特别说明**：只允许在“极度低估”或“合理区间下沿”建仓。股息率必须高于10年期国债收益率（约2.7%）至少1.5个百分点，即 ≥ 4.2%。

### 6.2 熔断系数K

| 条件 | K |
|------|---|
| 前瞻PE极度低估 + PB极度低估 + 股息率≥5% | 1.00 |
| 前瞻PE极度低估 + PB合理 | 0.92 |
| 前瞻PE合理区间 + 股息率≥4.5% | 0.88 |
| 前瞻PE合理区间 + 股息率<4.5% | 0.80 |
| 任一进入高估预警区 | 0.65 |
| 任一进入泡沫区 | **0.40（强制清仓）** |

### 6.3 波动率调整系数 V

| 条件 | V |
|------|---|
| 年化波动率 < 25% 且 最大回撤 < 25% | 1.00 |
| 年化波动率 25%-30% 或 最大回撤 25%-30% | 0.92 |
| 年化波动率 30%-35% 或 最大回撤 30%-35% | 0.85 |
| 年化波动率 > 35% 或 最大回撤 > 35% | 0.70（触发一票否决？此处仅为系数，硬红灯已覆盖>35%回撤） |

**保守型最低准入线**：K ≥ 0.80 且 V ≥ 0.85。

## 七、核心口径修正（保守型专用）

### 7.1 前瞻PE（仅作参考）
保守型不依赖前瞻PE博弈反转，但用于判断安全边际。前瞻PE > 20x的标的直接淘汰。

### 7.2 合同负债（关键先行指标）
合同负债必须连续2个季度环比增长且同比增长 > 5%，否则模块三得分减半。

### 7.3 渠道库存与批价价差（底线指标）
- 健康区间：渠道库存 < 2.5个月，价差率 > 15%
- 黄灯区：渠道库存 2.5-3个月，价差率 10%-15%
- 红灯区：渠道库存 > 3个月 或 价差率 < 10% → 一票否决（硬红灯）

### 7.4 吨价与产品结构（不追求弹性，只要求稳定）
吨价同比增速 > 0 即可，负增长直接扣分。不要求>10%的高增长。

### 7.5 省外收入占比（要求成熟市场）
省外收入占比 > 50% 且省外市场已经实现稳定盈利（市占率 > 10%），不接受仍在烧钱扩张阶段的酒企。

### 7.6 经销商数量（要求稳定）
近3年经销商数量波动在 ±5% 以内，且单商产出持续提升。

### 7.7 销售收现比（强制要求）
销售收现比（销售商品收到的现金/营业收入） > 1.10 是底线，低于1.05直接黄灯。

### 7.8 主动报表出清（保守型不接受）
保守型不接受“牺牲利润换健康”的标的。任何因费用前置、计提减值导致利润大幅下滑的酒企，直接淘汰。

### 7.9 消费税改革（要求可预测）
只选受影响小、经营模式透明的龙头（如茅台），规避存在税务不确定性的中小酒企。

### 7.10 股东回报（核心收益来源）
股息率必须连续3年 ≥ 4%，分红率 ≥ 70%，有回购注销记录者加分。股息稳定性（每股股息波动 < 10%）单独加分。

### 7.11 波动率与回撤控制（新增）
要求52周最大回撤 < 30%，年化波动率 < 30%，贝塔系数 < 1.0。超标者模块十直接扣分或淘汰。

## 八、模块评分体系（总分100，保守型·权重重构）

保守型权重哲学：
- **盈利质量与现金流（M4）** = 18分（最核心，现金流为王）
- **估值与安全边际（M1）** = 15分（股息率优先，PE次之）
- **财务健康与杠杆（M5）** = 13分（低负债、净现金）
- **治理与股东回报（M2）** = 12分（分红连续性、无减持、国资背景）
- **品牌力与产品结构（M7）** = 10分（只认高端品牌）
- **周期弹性与边际改善（M3）** = 8分（仅作右侧确认，不博弈弹性）
- **渠道质量与全国化（M8）** = 8分（要求成熟稳定，不奖励扩张）
- **机构与资金面（M10）** = 6分（机构认同度高，波动低）
- **存量集中与市占率（M9）** = 5分（龙头溢价）
- **政策与催化剂（M6）** = 3分（不赌政策，只防风险）
- **波动率与回撤控制（M11）** = 2分（新增，负向扣分或正向加分）
