# ⚡ A股电力运营商股票筛选综合评分体系
## v4.2 A股本土化修正版 · 成长型/价值型双轨 · 子行业差异化估值熔断 · 含136号文电价压力测试

> 适用范围：A股电力**运营商**，包括水电、火电、核电、风电/光伏电站运营、综合能源运营平台、地方能源平台。
> 不适用：光伏组件、逆变器、储能设备、风机、电网设备、电缆、变压器、智能电表等**电力设备制造商**。
> 核心逻辑：资源/牌照垄断 → 权益装机增长 → 电价/消纳兑现 → 经营现金流回收 → 资本回报纪律。
> 评分目标：在A股语境下，识别"增长确定性强 + 现金流真实 + 估值未透支 + 政策顺风"的电力运营商。
> **v4.2核心改动**：估值阈值按A股市场实际中枢上移；PE/股息率分子行业；新增136号文（新能源全面入市）电价压力测试；风光补贴OCF豁免；火电容量电价权重提升；增长门槛梯度化。

# 一、强制数据口径

| 数据类型 | 必须使用 |
|---|---|

| 安全/环保/合规 | 交易所公告、生态环境部处罚、应急管理部处罚、失信被执行人名单 |
| 股权质押/减持 | 中登公司、交易所披露 |
| 天气/来水/风光资源 | 国家气候中心、电网/公司披露、行业公开数据 |
| 电价/电改 | 国家发改委、各省能源局月度交易公告、136号文配套细则 |

# 二、数据置信度标记

每只股票输出时必须标记：

| 等级 | 含义 |
|---|---|
| A | 年报、季报、交易所公告明确披露 |
| B | 公司路演、投资者关系、机构调研纪要披露 |
| C | 政府文件、环评公示、发改委/能源局文件可验证 |

> - 核心指标若为D/E，必须在备注中说明。

# 三、前置一票否决：硬红灯项

触发任一硬红灯，最终得分直接 = 0，进入淘汰区。

| # | 类别 | 硬红灯标准 |
|---|---|---|
| 1 | 交易状态 | 被实施ST、*ST、进入风险警示板、暂停上市风险明确 |
| 2 | 审计诚信 | 最近一年年报审计意见非标准无保留；或近3年更换审计机构≥2次且无合理解释；或年报披露前3个月突击换所 |
| 3 | 治理黑历史 | 公司或实控人近3年被认定财务造假且处罚生效；大股东资金占用未清偿；公司/实控人被立案调查或市场禁入未结案；实控人被留置 |
| 4 | 重大合规/安全 | 核心机组被列入强制淘汰目录；重大安全事故死亡≥3人；公司被列入失信被执行人；重大环保违法导致核心资产停产、排污许可受限或整改未完成 |
| 5 | 流动性/控盘风险 | 实控人近半年质押比例>70%；或股价<2元且PB<0.5；或同时满足：机构持股不含大股东<3% + 股东人数<5000 + 日均成交额<500万 |
| 6 | 财务排雷（A股本土修正） | （a）非补贴依赖型公司，连续3年OCF/净利润<0.5；**（b）补贴依赖型风光公司（应收国补/总资产>15%），连续3年OCF/（净利润+当期新增补贴应收）<0.5**；非建设期有息负债/EBITDA>7.0；**应收补贴款/总资产>35%且账龄>2年部分>60%**；在建工程/总资产>45%且>30%项目连续2年进度<20% |
| 7 | 业务崩塌 | 营业收入连续2年同比下滑且非资产剥离导致；度电毛利连续2年为负；单一电站/电源点贡献净利润>60%且无对冲预案 |
| 8 | 资产搁浅/合规灰区 | 煤电机组明确列入省级"十四五"关停清单但未足额计提减值；光伏项目涉及耕地/林地/湿地且无合法手续；核电退役基金计提比例<监管要求80%；固定资产成新率>85%但对应产能利用率<55%且连续2年无技改投入 |

> **修正说明**：A股存量国补风光（如太阳能、节能风电、三峡能源）因补贴拖欠，OCF/NP常年在0.5–0.8区间但并非财务造假，故对补贴依赖型公司采用调整后口径，避免误杀。

# 五、建设期豁免条款（A股利率本土化）

适用于核电、大型水电基地、国家级风光大基地。

若公司处于正式开工后的建设窗口，且同时满足：

1. EBITDA为正且增长；
2. **长期政策性贷款（国开行/进出口行）综合利率≤LPR+50bp**（v4.1为≤LPR，过严）；
3. 项目贷款期限≥10年；
4. 项目IRR≥WACC+150bp；
5. 项目已获核准/环评/接入/开工等实质性批复；

则红灯项中"有息负债/EBITDA>7.0"不直接归零，改为：

- 原始总分扣15分；
- 模块五5.2得0分；
- 不享受估值熔断K=1.00的安全区加成；
- 输出备注标记：`⚠️建设期豁免`。

# 七、核心口径修正

## 7.1 装机口径
权益装机 > 控股装机 > 总装机。评分时必须说明使用的口径。
若总装机增长快、权益装机增长明显较慢，下调模块三3.1和3.2得分。

## 7.2 归母口径
关注：归母净利润增长、归母EPS增长、少数股东损益占比、股本摊薄速度。
若装机/收入增长快但归母EPS不增长，模块八扣分。

## 7.3 【新增】136号文电价压力测试口径
2025年2月《关于深化新能源上网电价市场化改革的通知》后，新增风光项目电价不再保障，需按机制电价+差价合约/绿证收益评估。
- **136号文前并网项目**：享受存量保障，IRR按当地标杆电价测算。
- **136号文后并网项目**：必须按"机制电价+绿证均价+辅助服务"综合测算IRR，若无任何对冲手段，模块三3.5得分≤1.5，并触发黄灯扣-3至-6。

# 十、火电专项修正（容量电价权重上调）

火电收入或装机占比>50%时必须额外检查：

|---|---|

| 度电燃料成本 | 低于同业前30%加2分，高于同业后30%扣2分 |

# 十四、执行SOP

1. 拉取A股电力运营商股票池（申万二级"电力"剔除电力设备），明确子行业归类。
2. 按硬红灯项逐只排雷，命中即归零。
3. 对未触发硬红灯的公司，记录黄灯事项及扣分。
4. 拉取最新A股收盘价、PB、PE、EV/EBITDA、市值、成交额、股息率。
5. 拉取最新年报、季报，提取收入、归母净利润、OCF、EBITDA、有息负债、资产负债率、ROE、ROIC、CAPEX、折旧、分红、股本变化。
6. 拉取最新公告、核准、备案、环评、接入批复、开工公告，核实Pipeline。
7. 区分136号文前/后并网项目，分别测算IRR。
8. 所有装机优先使用权益装机；若只能获得总装机，必须备注。
9. 逐项计算模块一至模块十得分。
10. 执行交叉封顶：模块二 + 模块三3.2 + 模块十10.1 ≤ 20。
11. 扣除黄灯分，得到原始总分。
12. 根据子行业A股本土PB和EV/EBITDA计算估值熔断系数K。
13. 计算最终得分。
14. 按双轨评级池分类（成长/价值）。
15. 输出结果表，并注明数据日期、数据置信度和关键假设。
