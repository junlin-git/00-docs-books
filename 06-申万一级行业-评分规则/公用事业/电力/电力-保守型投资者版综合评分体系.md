# 🛡️ A股电力运营商股票筛选综合评分体系
## v4.2-D 防御型投资者版 · 格雷厄姆框架本土化 · 现金流与股息优先 · 子行业差异化估值熔断

> 适用范围：A股电力**运营商**，包括水电、火电、核电、风电/光伏电站运营、综合能源运营平台、地方能源平台。
> 不适用：电力设备制造商、储能EPC、虚拟电厂软件商。
> 适用投资者画像：**防御型投资者**——追求本金安全、稳定股息、低波动、低换手；不追求超额成长，宁可错过、不可买错。
> 核心哲学（格雷厄姆七准则A股本土化）：
> 1. **足够的规模**（避开小盘股流动性陷阱）
> 2. **足够强的财务状况**（低负债、高流动性）
> 3. **盈利稳定**（近10年无亏损年份）
> 4. **股息记录**（连续分红≥10年）
> 5. **每股收益增长**（10年EPS增长≥33%，即约3%年化）
> 6. **适度市盈率**（PE TTM ≤ 15，特殊行业上调）
> 7. **适度市净率**（PB ≤ 1.5，或PB×PE ≤ 22.5）
> 8. **【A股新增】实控人为央企/省级国企**（治理底线）
> 9. **【A股新增】安全边际 ≥ 30%**（DDM/DCF与市价对比）

# 一、强制数据口径

每次执行必须拉取并注明：

| 数据类型 | 必须使用 |
|---|---|
| 股价/市值 | 最近一个交易日A股收盘价（不参考H股） |
| 财务数据 | 最新年报 + 最新季报/中报（合并报表） |
| 历史数据 | **过去10个完整会计年度**（防御型核心要求） |
| 估值数据 | PB(LF)、PE(TTM扣非)、EV/EBITDA(TTM)、股息率TTM、Shiller PE（10年盈利均值） |
| 分红数据 | **过去10年完整分红记录**（金额、比例、是否中断） |
| 项目数据 | 仅采用已核准/已开工/已投运项目，**不计PPT Pipeline** |
| 安全/环保/合规 | 交易所公告、生态环境部处罚、应急管理部处罚、失信被执行人 |
| 股权质押/减持 | 中登公司、交易所披露 |
| 利率基准 | 10年期国债收益率（用于股息率安全边际比较） |

# 五、建设期豁免条款（防御型大幅收紧）

防御型投资者**原则上不投建设期负债激增的公司**。

仅当同时满足以下条件，给予有限豁免：

1. EBITDA为正且连续3年增长；
2. 长期政策性贷款（国开行/进出口行）综合利率 ≤ LPR+30bp；
3. 项目贷款期限 ≥ 15年（防御型加严）；
4. 项目IRR ≥ WACC+200bp（防御型加严）；
5. 项目已获核准/环评/接入/开工等实质性批复；
6. **建设期不影响连续10年分红记录**；
7. **建设期不导致股息率跌破国债收益率**；

豁免效果：
- 原始总分扣 **20分**（v4.2为15分）；
- 模块五5.2得0分；
- K上限锁定0.90；
- 输出备注 `⚠️建设期豁免-防御型限投`。

# 七、核心口径修正

## 7.1 装机口径
权益装机 > 控股装机 > 总装机。**防御型只采用权益装机评估**。

## 7.2 归母口径
关注：归母净利润10年波动、归母EPS 10年CAGR、少数股东损益占比、股本摊薄速度。

## 7.3 136号文电价压力测试
- 防御型对136号文后新增风光项目**采取保守态度**：除非有差价合约保护，否则模块三相关得分为0。

## 7.4 【新增】防御型估值锚（DDM）
对水电、核电、火电（容量电价后），按**戈登增长模型**估算内在价值：
- 内在价值 = D₁ / (k - g)
  - D₁ = 下一年度每股股息预期
  - k = 折现率 = 10年国债收益率 + 3%风险溢价
  - g = 永续增长率（水电2%、核电2.5%、火电1%、风光3%）
- **安全边际 = (内在价值 - 当前股价) / 内在价值**
- 防御型要求安全边际 ≥ 25%（A股公用事业本土化，低于格雷厄姆经典33%）

# 十、火电专项修正（防御型重点核查）

火电收入或装机占比>50%时必须额外检查：

| 火电变量 | 影响 |
|---|---|
| 长协煤覆盖率 | >85%加2分，<60%扣3分 |
| 长协煤履约率 | >95%加2分，<75%扣3分 |
| 度电燃料成本 | 低于同业前30%加2分 |
| **容量电价覆盖固定成本比例** | >60%加3分；40%-60%加1.5分；<40%扣3分 |
| 辅助服务/调峰收益占毛利 | >10%加1.5分 |
| 灵活性改造完成度 | 全部完成加1分 |
| 区域供需 | 紧张省份加2分，宽松扣1分 |
| 新能源冲击 | 利用小时较2019年下降>15%扣2分 |

> 防御型对火电的核心诉求是"容量电价覆盖固定成本+长协煤稳价"，缺一不可。

# 十一、最终计分公式

模块合计分 = M1 + M2 + M3 + M4 + M5 + M6 + M7 + M8 + M9 + M10
原始总分 = max(0, 模块合计分 - 黄灯扣分)
最终得分 = 原始总分 × K
若数据置信度有E级关键指标，最终得分 × 0.9

# 十四、执行SOP

1. 拉取A股电力运营商股票池，剔除电力设备、市值<200亿、日均成交<5000万。
2. **逐只核查近10年财报**：是否有亏损年份、是否连续分红、审计意见、实控人变更。
3. 按硬红灯12项排雷，命中即归零。
4. 对未触发硬红灯的公司，记录黄灯事项及扣分。
5. 拉取最新A股收盘价、PB、PE、EV/EBITDA、市值、成交额、股息率、10年期国债收益率。
6. 计算Shiller PE（10年扣非EPS均值）。
7. 用DDM测算内在价值与安全边际。
8. 拉取最新年报/季报，提取收入、归母净利润、OCF、EBITDA、有息负债、资产负债率、ROE、ROIC、CAPEX、折旧、分红、股本变化、流动比率、速动比率。
