# A股电子元件企业 · 综合财报分析与投资评分体系 V1.0

**适用对象**：A股申万三级"电子元件"（被动元件、PCB、连接器、电感等）及"半导体分立器件"中偏元件属性上市公司。核心判断标准：电子元器件（电容、电阻、电感、PCB、连接器等）收入或毛利占比 ≥ 70%。
**不适用**：纯集成电路设计（Fabless）、晶圆代工、封测、设备材料、整机组装。

**数据来源（优先级与更新频率）**：参考附录 C。
- **最新年报**：最近一个完整会计年度经审计的合并财务报表及年报全文。
- **最新季报**：最新一期未经审计的季度/半年度报告。
- **历史数据**：近 10 年（或自上市以来）可获取的全部财务数据。若上市不足 10 年，以IPO招股书披露的完整3年历史数据 + 上市后所有定期报告数据替代。
- **行业数据**：申万三级"电子元件"分类下所有可比公司同期财务及经营数据。
- **行情数据**：最新交易日收盘价、总市值、日均成交额（近20个交易日）、PE/PB/PS历史分位（近10年滚动窗口）。
- **行业特有数据**：下游行业（消费电子、汽车电子、服务器/数据中心）出货量/景气度报告、上游大宗商品（铜、锡、石油）价格走势、海关进出口数据、公司公告的产能扩张及客户认证进展。
- **前瞻数据**：Wind一致预期（净利润/营收/覆盖家数）、内部研究员调研模型、公司公开业绩指引。

**核心原则**：
- 财报是用来排除企业的，不是用来选择企业的。先排雷，再评分，最后决策——宁可错过，不要踩雷。
- 利润是"颜值"，现金流是"余额"——颜值可以化妆，余额骗不了人。
- 对于电子元件企业，**存货是照妖镜，稼动率是晴雨表**——周期高点扩产是毁灭价值的开始。
- 每次运行强制拉取最新数据，SOP 十二步不可跳过、不可调换顺序。

## 第一阶段：排雷淘汰

**核心思想**："宁可错过，不要踩雷。" A 股有 5000+ 家公司，不缺你错过的那一家。

本阶段采用 **"硬红灯 + 黄灯扣分"双层机制**。硬红灯命中即淘汰（最终得分 = 0，不再进入后续评分流程）；黄灯扣分从总分中扣除（累计上限 20 分，超过 20 分按 20 分计）。

⚠️ **执行顺序**：必须先完成全部硬红灯排查，确认无任何一项命中后，方可进入黄灯扣分及后续评分阶段。严禁跳过硬红灯排查直接评分。

### 1.1 硬红灯项（命中即淘汰，14条）

⚠️ **执行要点**：每次运行首先执行硬红灯排查，任何一项命中则直接淘汰，不再进行后续评分，最终得分记录为 0分（淘汰），并在报告中明确标注触发的红灯编号及原因。

## 第二阶段：九维量化评分（总分100分）

**设计原则**：沿用 V4.1 的 H1–H9 九维命名与权重框架（H1-H7 86 + H8 10 + H9 4），但将化学制药专属指标替换为电子元件专属指标。每个指标设 "量化评分 + 深度检查" 双层结构。

💡 **V1.0 相对化学制药 V4.1 的维度调整说明**：

### 维度 H1：历史稳定性与周期位置（12分）

**对应报表分析**：资产负债表——评估企业长期资产结构、资本效率的稳定性，判断当前所处的估值与杠杆周期位置。

**量化评分**

| 指标 | 满分 | 评分标准 |
| :--- | :--- | :--- |
| **1.1 近10年（或上市以来）营收正增长年份比例** | 4 | > 80% 得 4；60%~80% 得 2.5；40%~60% 得 1；< 40% 得 0 |
| **1.2 近10年（或上市以来）ROE标准差** | 3 | < 3% 得 3；3%~8% 得 2；8%~15% 得 1；> 15% 得 0。<br>🛡️ **补充**：若上市不足5年，改用 "营收复合增速标准差" 替代：< 20% 得 3；20%~50% 得 2；> 50% 得 1 |
| **1.3 当前PE(TTM)处于近10年历史分位** | 3 | < 10% 分位 得 3；10%~30% 得 2；30%~50% 得 1；> 50% 得 0。<br>🛡️ **替代**：若净利润为负导致PE无效，改用 **PB(TTM)** 分位，标准同上 |
| **1.4 当前资产负债率处于近10年历史分位** | 2 | < 30% 分位 得 2；30%~50% 得 1；> 50% 得 0 |

📋 **深度检查——资产负债表"三步法"**
⏱️ 预计耗时：3分钟（看右边30秒 → 看左边30秒 → 找矛盾2分钟）

| 步骤 | 检查要点 | 具体操作 | 标准/警报 |
| :--- | :--- | :--- | :--- |
| **第一步：看右边（负债与权益）** | ① 资产负债率高低<br>② 有息负债多不多<br>③ 当前负债率在历史上处于什么水平 | 总负债/总资产；短期借款+长期借款+应付债券占总资产比例 | ✅ 合理区间 30%~50%<br>⚠️ > 60% 为偏高<br>❌ > 100% 已触发🔴5 |
| **第二步：看左边（资产）** | ① 货币资金够不够<br>② 应收账款多不多<br>③ 存货高不高<br>④ 固定资产/在建工程是否合理 | 货币资金/总资产；应收账款/总资产；存货/总资产；固定资产+在建工程/总资产 | ✅ 货币资金 > 有息负债；应收/总资产 < 15%；存货/总资产 < 20%；固定资产占比合理（元件企业通常20%~40%）<br>⚠️ 货币资金 < 有息负债；存货/总资产 > 30% 为库存积压信号 |
| **第三步：找矛盾** | ① 现金多但负债也多（存贷双高）<br>② 在建工程长期不转固<br>③ 应收账款增速 > 营收增速 | 交叉比对货币资金与有息负债；在建工程明细账龄；应收账款增速与营收增速对比 | ❌ 存贷双高 → 硬红灯🔴6<br>❌ 在建工程长期不转固 → 硬红灯🔴12<br>⚠️ 应收增速 > 营收增速 → 收入质量下降 |

### 维度 H2：当前盈利能力与质量（15分）

**对应报表分析**：利润表——考察营收质量、利润质量、费用控制。

**量化评分**

| 指标 | 满分 | 评分标准 |
| :--- | :--- | :--- |
| **2.1 毛利率水平与近10年均值对比（定量）** | 5 | 当前毛利率较近10年均值降幅 < 5% 得 5；降幅 5%~15% 得 3；降幅 15%~30% 得 1；降幅 > 30% 得 0 |
| **2.2 扣非ROE（最新年报）** | 4 | > 15% 得 4；10%~15% 得 3；5%~10% 得 2；< 5% 得 0；负值得 0 |
| **2.3 高端/新品收入占比（最新年报/季报）** | 3 | 采用"产品迭代率"或"高端产品线占比"：高端产品/新品（如汽车电子、AI服务器、高频高速PCB、车规MLCC）收入占比 > 40% 得 3；20%~40% 得 2；5%~20% 得 1；< 5% 得 0 |
| **2.4 盈利现金比（CFO/净利润，最新年报）** | 3 | > 100% 得 3；70%~100% 得 2；50%~70% 得 1；< 50% 得 0。<br>🛡️ **替代**：若净利润为负，考察CFO是否为正 → 为正得 2，为负但亏损收窄得 1，为负且扩大得 0 |

📋 **深度检查——利润表"三个质量"**
⏱️ 预计耗时：3分钟

1.  **营收质量检查**：主营业务收入占比（✅ ≥ 95% 为正常）；分下游行业收入结构（消费电子 vs 汽车 vs 工业 vs 服务器）；产品集中度（⚠️ 单一产品/系列 > 60% 风险高）；区域收入分布（⚠️ 海外收入 > 40% 需关注地缘政治/关税风险）。
2.  **利润质量检查**：扣非净利润/归母净利润（✅ ≥ 85% 为健康；❌ < 50% 依赖非经常性损益）；利润来源是主业还是投资收益/政府补贴。
3.  **费用质量检查**：销售费用率（✅ 电子元件通常 2%~8%）；管理费用率（✅ 合理区间 5%~12%）；研发费用率（✅ 元件企业通常 4%~8%，高端/汽车级产品 > 8%）。
💡 **核心技巧**：先读管理层讨论（年报"管理层讨论与分析"章节），再看利润表数字——如果说的和数字对不上，信数字，不信嘴。

### 维度 H3：财务健康度——负债与偿债（12分）

**对应报表分析**：资产负债表——重点考察负债结构、偿债能力与流动性安全。（与 H1 共享数据源）

**量化评分**

| 指标 | 满分 | 评分标准 |
| :--- | :--- | :--- |
| **3.1 资产负债率（最新财报）** | 3 | < 30% 得 3；30%~50% 得 2；50%~60% 得 1；> 60% 得 0 |
| **3.2 有息负债/EBITDA（近3年均值）** | 3 | < 2x 得 3；2~4x 得 2；4~6x 得 1；> 6x 得 0。<br>🛡️ **替代**：若无盈利（EBITDA为负），考察有息负债/总资产：< 15% 得 3；15%~30% 得 2；> 30% 得 1 |
| **3.3 利息保障倍数（近3年均值）** | 3 | > 10x 得 3；5~10x 得 2；2~5x 得 1；< 2x 得 0 |
| **3.4 流动比率（最新财报）** | 3 | > 2.5 得 3；1.5~2.5 得 2；1.0~1.5 得 1；< 1.0 得 0 |

⚠️ 电子元件行业合理负债率通常 30%~50%。流动比率过高（> 5.0）说明资金使用效率低。

📋 **深度检查——负债细节**：短期偿债压力（短期借款+一年内到期非流动负债 / 货币资金 ⚠️ > 100%）；负债结构（有息 vs 无息）；隐性负债（对外担保、未决诉讼）。

### 维度 H4：营运效率与资产质量（10分）

**对应报表分析**：资产负债表 + 现金流量表——**电子元件行业最关键的维度之一**，考察库存、产能与资产质量。

**量化评分**

| 指标 | 满分 | 评分标准 |
| :--- | :--- | :--- |
| **4.1 应收账款周转率（近3年均值 vs 行业）** | 3 | 行业前30% 得 3；中游（30%~70%）得 2；后30% 得 1 |
| **4.2 存货周转率（近3年均值 vs 行业）** | 3 | 行业前30% 得 3；中游（30%~70%）得 2；后30% 得 1。<br>⚠️ **周期判断**：存货周转率连续下降+营收上升 → 警惕库存积压；存货周转率提升+营收提升 → 景气上行 |
| **4.3 商誉/总资产（最新年报）** | 1 | < 5% 得 1；5%~15% 得 0.5；> 15% 得 0 |
| **4.4 产能利用率与在建工程匹配度** | 3 | **产能利用率 > 85% 且在建工程/固定资产 < 30%** 得 3（健康扩产）；<br>**产能利用率 70%~85% 或在建工程/固定资产 30%~50%** 得 2（需要关注）；<br>**产能利用率 < 70% 或在建工程/固定资产 > 50%** 得 0（产能过剩风险）<br>🛡️ **兜底**：若公司未披露产能利用率，自动给予1.5分基准分（满分的50%），并在报告中标注 |

📋 **深度检查——资产质量"三个凡是"**
1.  **在建工程**：账龄 > 1年的在建工程占比 > 50% → 警惕（硬红灯🔴12线索）；预算超支 > 30% → 高度警惕。
2.  **商誉**：商誉/净资产 > 30% 已触发🟡5，进一步检查减值测试关键假设。
3.  **存货**：存货/总资产 > 30% → 黄灯🟡7线索，重点查看存货明细（原材料、在产品、库存商品），库存商品占比过高且库龄 > 1年 → 跌价风险极大。

### 维度 H5：现金流与资本开支纪律（12分）

**对应报表分析**：现金流量表——对于重资产的电子元件企业，**资本开支纪律决定股东回报**。

**量化评分**

| 指标 | 满分 | 评分标准 |
| :--- | :--- | :--- |
| **5.1 自由现金流/净利润（近3年均值）** | 4 | > 80% 得 4；50%~80% 得 2.5；20%~50% 得 1；< 20% 得 0。<br>🛡️ **替代**：若净利润为负，考察 FCF/营收：> 10% 得 3；0%~10% 得 2；为负但收窄得 1；为负且扩大得 0 |
| **5.2 资本开支/折旧摊销（近3年均值）** | 4 | **< 1.2x** 得 4（资本开支纪律严格，自由现金流充沛）；<br>**1.2x~1.8x** 得 2.5（合理扩张）；<br>**1.8x~2.5x** 得 1（扩张偏激进）；<br>**> 2.5x** 得 0（资本开支失控，FCF持续为负风险）<br>🛡️ **周期考量**：若公司处于景气底部逆势扩产且在手订单覆盖率 > 1.2，可上调一档（但上限不超过3分） |
| **5.3 经营性现金流净额连续为正年数（近10年/上市以来）** | 4 | > 8年 得 4；5~8年 得 2；3~4年 得 1；< 3年 得 0 |

📋 **深度检查——现金流量表"一正两匹配"**
⏱️ 预计耗时：5分钟

1.  **经营现金流为正（造血能力）**：连续3年为负 → 硬红灯🔴4。
2.  **经营现金流与净利润匹配（利润含金量）**：净现比（CFO/净利润）近3年均值 ✅ ≥ 1.0；⚠️ 0.4~1.0；❌ < 0.4。
3.  **经营现金流与营收匹配（收入含金量）**：收现比（销售商品收到现金/营收）近3年均值 ✅ ≥ 1.0；⚠️ 0.85~1.0；❌ < 0.7。

### 维度 H6：前瞻季度预测与成长性（15分）

**对应报表分析**：利润表成长性分析——考察增长动力与持续性。

🛡️ **分析师覆盖豁免**：若该标的近3个月Wind/卖方覆盖报告的家数 < 3家，则H6模块总分按 **50%权重** 折算（即满分由15分降为7.5分），释放出的7.5分权重自动转移至H5，并在报告中标注 "低覆盖度，下调前瞻权重"。

**量化评分**

| 指标 | 满分 | 评分标准 |
| :--- | :--- | :--- |
| **6.1 Q2-Q4营收环比Q1趋势判断** | 4 | 逐季加速（Q4>Q3>Q2>Q1）得 4；稳定增长（Q2-Q4均值环比Q1 > +10%）得 3；持平（-5%~+10%）得 1；下滑但降幅收窄得 1；下滑且扩大得 0 |
| **6.2 Q2-Q4毛利率趋势判断** | 3 | 逐季改善（产品结构升级、稼动率提升）得 3；稳定（±2个百分点以内）得 2；下滑得 0 |
| **6.3 全年业绩一致预期变化** | 3 | 较3个月前上调 > 5% 得 3；-5%~+5%（基本持平）得 2；下调 > 5% 得 0。<br>🛡️ 若Wind无覆盖，改用内部模型预测变化 |
| **6.4 新客户/新料号导入预期（未来6个月）** | 3 | 已确认进入核心客户（如苹果/华为/特斯拉等）新供应链名录或汽车电子/AI服务器新料号批量出货得 3；处于客户验证末期（预计 < 3个月通过）得 2；处于早期验证阶段得 1；无明确催化得 0 |
| **6.5 次年收入增速预测（内部模型）** | 2 | > 20% 得 2；10%~20% 得 1.5；5%~10% 得 1；< 5% 得 0 |

📋 **深度检查——营收/利润双维度增长矩阵**：
- 近3年营收CAGR ≥ 20%（锚3分*）、10%~20%（锚2分*）...
- 近3年扣非净利润CAGR ≥ 25%（锚3分*）...
- 利润增速 > 营收增速 → 规模效应/产品升级良性；利润增速 < 营收增速 → 成本/费用在吞噬增长。

### 维度 H8：下游景气度与周期风险（10分，V1.0专属）

**对应报表分析**：行业特有数据——考察下游景气度、库存周期、国产替代、竞争格局等电子元件专属风险因素。

**量化评分**

| 指标 | 满分 | 评分标准 |
| :--- | :--- | :--- |

| **8.5 行业景气度趋势（近6个月）** | 2 | 上行周期（下游订单可见度提升、产能利用率改善）→ 2；平稳得 1；下行（下游砍单、库存积压）得 0 |

📋 **深度检查——周期风险矩阵**

| 风险维度 | 检查要点 | 数据来源 | 标准/警报 |
| :--- | :--- | :--- | :--- |
| **下游周期风险** | 消费电子/汽车/服务器最新出货量同比；PCB/被动元件行业月度营收增速 | IDC/Counterpoint/工信部/公司公告 | ⚠️ 行业月度营收连续3个月负增长 → 高周期风险敞口 |

| **竞争格局** | 细分赛道集中度趋势；是否有新进入者（如台系、日系扩产） | 行业研究报告（Prismark/Murata等） | ⚠️ 陆资/台资新进入者增多 → 竞争加剧、价格压力 |
| **上游成本风险** | 铜/锡/石油/稀土价格趋势；公司是否有套保/价格联动机制 | LME/SHFE价格 + 年报成本结构 | ⚠️ 原材料占比 > 60%且无对冲 → 毛利率波动大 |

### 维度 H9：行业竞争力——护城河与市场地位（4分，V1.0专属）

**对应报表分析**：行业横向对比——补齐 V4.0 唯一结构性短板。财务好但行业地位弱的公司（如二线PCB厂）与财务同样好但细分Top2的公司，在打分相同但投资含义差异巨大。

**量化评分**

| 指标 | 满分 | 评分标准 |
| :--- | :--- | :--- |
| **9.1 细分领域市场排名** | 1.5 | 细分 Top3 得 1.5；Top5 得 1；Top10 得 0.5；其他 得 0。<br>🛡️ **细分口径**：按公司主赛道定（如"MLCC"、"多层PCB"、"汽车连接器"），取自公司年报"经营情况讨论" + Prismark/CPCA/中国电子元件行业协会行业报告 |
| **9.2 护城河评估** | 1.5 | 逐项累计，上限1.5：<br>• **规模优势**：产能规模全国/全球前列（覆盖被动/PCB/连接器各细分）→ +0.5<br>• **客户壁垒**：核心客户（苹果/华为/特斯拉/英伟达等）认证通过，且合作 ≥ 3年 → +0.5<br>• **技术平台**：高端产品线（车规MLCC、IC载板、112G高速背板连接器等）量产能力 → +0.3<br>• **垂直整合**：上游原材料（如铜箔、陶瓷粉）自供或战略合作 → +0.2 |
| **9.3 行业横向对比（vs 申万三级电子元件可比公司）** | 1 | 选取同细分 5~8 家可比公司，计算三项中位：<br>• 毛利率高于行业中位数 +0.4<br>• ROE高于行业中位数 +0.3<br>• 营收增速高于行业中位数 +0.3<br>三项合计 ≥ 0.8 得 1；0.4~0.7 得 0.5；< 0.4 得 0 |

📋 **深度检查——竞争力"三层验证"**
1.  **第一层：赛道卡位**：公司是"赛道龙头/细分冠军"还是"跟随者"？主业是否处在集中度提升的细分（如高端PCB、车规被动元件）？
2.  **第二层：护城河可维持性**：客户切换成本高不高？技术迭代风险大不大（如传统PCB vs IC载板）？规模效应是否显著？
3.  **第三层：横向对标**：拉申万三级"电子元件"下同细分 5~8 家可比的毛利率/ROE/存货周转率/负债率，公司是否全面优于中位？还是仅靠某一单项支撑？

💡 **H9 与黄灯/硬红灯的边界**：
- H9 是"竞争力定级"（加分逻辑），黄灯 🟡13（产能扩张激进）、🟡18（下游景气高点）、🟡20（稼动率下滑）是"风险扣分"，二者同向但不同维度，不重复。
- H9 得分高 ≠ 可豁免黄灯（如某公司在PCB行业Top3，但扩产过于激进且下游面临砍单，🟡13和🟡20仍需扣分），执行时先黄灯扣分、再H9加分。

💡 **雷达图解读**：九维评分 > 该维度满分×60% 的维度越多，企业综合质地越均衡。H9 < 2分提示"财务虽好但行业地位弱"，需结合细分赛道判断是否可接受。

### 附录A：标准作业程序（SOP）十二步法（含实时数据抓手）

⚠️ **强制性要求**：以下步骤为强制性流程，不得跳过或调换顺序。每次评分必须严格按照SOP执行，并在最终报告中标注每步的执行状态。

**步骤0：数据可得性预检查**：标记A股非强制披露项（如产能利用率、分下游收入明细、在手订单），预设基准分。

**步骤1：实时数据拉取（每次运行当日强制执行）**
1.1 获取最新交易日收盘价、总市值、近20日日均成交额。
1.2 拉取最新年报 + 最新季报/中报。
1.3 获取近10年（或上市以来）历史财务数据。
1.4 获取行业特有数据：下游景气度报告、上游大宗商品价格、行业月度营收数据。
1.5 获取Wind一致预期、机构覆盖家数、3个月前预期值。
1.6 统计近3个月卖方覆盖报告数量，判定H6是否触发权重豁免。
1.7 获取内部调研预测。

**步骤2：硬红灯排查（一票否决）** ⏱️ 5分钟。逐项检查硬红灯14条。任何一项命中即淘汰，最终得分 = 0分。

**步骤3：黄灯扣分项检查** ⏱️ 3分钟。逐项检查黄灯22条，累计扣分上限20分。

**步骤4：行业周期判定（计算E）** ⏱️ 2分钟。依据最新板块PE/PB分位、公募持仓、下游景气度，判定所处周期阶段，确定E系数。

| 周期阶段 | E系数 |
| :--- | :--- |
| 极度冰点（PE/PB分位 < 10%，公募持仓历史低点，下游极度悲观） | 1.30 |
| 复苏期（分位 10%~30%，基本面改善） | 1.15 |
| 平稳期（分位 30%~70%） | 1.00 |
| 高估期（分位 70%~90%） | 0.80 |
| 泡沫期（分位 > 90%） | 0.65 |

**步骤5：模块评分（H1–H9）** ⏱️ 15分钟。逐项完成量化评分 + 深度检查。

**步骤6：交叉加分** ⏱️ 1分钟。

| # | 交叉加分条件 | 加分值 |
| :--- | :--- | :--- |
| 1 | 净现比 ≥ 1.0 且 收现比 ≥ 1.0（利润+收入双重含金量） | +2 |
| 2 | PE/PB/PS 三项中至少两项处于历史 < 10% 分位（极低估值） | +2 |
| 3 | FCF持续正且资本开支/折旧 < 1.2x 且 股息率 > 3%（现金奶牛） | +2 |
| 4 | H9.1（细分排名Top3）+ H9.2（护城河≥1.0）双高（细分龙头溢价） | +1 |
| 5 | H9.1 + H2.3（高端产品占比>40%）双高（高端龙头溢价） | +1 |
| 6 | 最新季报同时满足：营收增速>20% + 毛利率环比提升>1pp + 存货周转加快 | +1 |

**步骤7：计算扣黄灯后总分** = H1~H9原始合计 − 黄灯扣分绝对值（≤20）

**步骤8：计算估值熔断系数K** ⏱️ 2分钟。
- 基础K = 1.00。
- PE/PB分位 > 70%（高估值）→ K × 0.85
- PE/PB分位 > 90%（极高估值）→ K × 0.70
- 若 H2.3（高端占比>40%）且 H8.3（国产替代逻辑强），K 下限锁0.85
- 冰点区(E=1.30) + 分位<10% → K上浮+0.07（上限1.00）

**步骤9：最终得分计算**
- 周期修正分 = 扣黄灯后总分 × E
- 熔断后得分 = 周期修正分 × K
- 若H6置信度为D级（全靠内部预测），熔断后得分 × 0.85
- 最终得分 = min(100, 熔断后得分)

**步骤10：评级与仓位决策**

| 评级 | 得分区间 | 仓位上限 | 操作建议 |
| :--- | :--- | :--- | :--- |
| **A+** | ≥ 90 | 10% | 强烈关注，可超配 |
| **A** | 80~89 | 7% | 重点关注，可配置 |
| **B+** | 70~79 | 4% | 适度关注，可小仓位 |
| **B** | 60~69 | 2% | 谨慎关注，需进一步验证 |
| **C** | 40~59 | 0% | 暂不配置，持续观察 |
| **D** | < 40 | 0% | 不配置，等待基本面改善 |

**步骤11：输出报告**（包含六大章节：基本结论、排雷结果、九维评分明细、周期与估值、数据可得性兜底、风险提示）

**步骤12：存档与跟踪**：存入投研数据库，下次运行更新时对比变化。

#### D.3 关键比率速查

| 比率 | 公式 | 健康标准 | 计算频率 |
| :--- | :--- | :--- | :--- |
| 收现比 | 销售商品收到现金 ÷ 营业收入 | ≥ 1.0 | 年度/季度 |
| 净现比 | 经营现金流净额 ÷ 净利润 | ≥ 1.0 | 年度 |
| 自由现金流 | 经营现金流 - 资本性支出 | 持续为正 | 年度 |
| 有息负债率 | 有息负债 ÷ 总负债 | ≤ 30% | 年度/季度 |
| 研发资本化率 | 资本化研发支出 ÷ 总研发支出 | ≤ 30% | 年度 |
| 利息保障倍数 | EBIT ÷ 利息费用 | > 5x | 年度 |
| ROE（扣非） | 扣非净利润 ÷ 平均净资产 | > 15% | 年度 |
| 毛利率 | （营收 - 营业成本）÷ 营收 | 视细分领域而定 | 年度/季度 |
| **存货周转率** | 营业成本 ÷ 平均存货 | ≥ 3x（行业基准） | 年度/季度 |
| **资本开支/折旧摊销** | 资本开支 ÷ 折旧摊销 | < 1.5x（健康） | 年度 |
| **产能利用率** | 实际产出 ÷ 产能 | > 85%（健康） | 年度/季度（非强制披露） |

#### D.4 三大报表一句话总结

| 报表 | 核心问题 | 一句话原则 |
| :--- | :--- | :--- |
