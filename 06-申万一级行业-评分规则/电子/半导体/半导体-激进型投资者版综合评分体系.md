# 半导体行业股票筛选综合评分体系（激进型投资者版）

**版本：v1.0-B 激进型投资者版**
**核心主题：AI算力爆发 · 国产替代加速 · 周期弹性放大 · 先进制程突破**
**适用范围：A股半导体核心企业（芯片设计、晶圆制造、封装测试、设备、材料、IDM），收入或毛利占比≥70%**
**不适用：被动元件、PCB、面板、LED、消费电子终端组装**
**适用投资者：激进型，追求AI算力产业链爆发、半导体设备材料国产替代、存储超级周期、先进封装技术突破四大弹性**


## 一、强制数据口径（总览）

| 数据类型 | 必须使用 |
|---------|---------|
| 股价/市值 | 最近一个交易日A股收盘价 |
| 财务数据 | 最新年报 + 最新季报/中报（合并报表） |
| 历史数据 | 至少3个完整会计年度 |
| 估值数据 | PE(TTM)、前瞻PE、PS(TTM)、PB(LF)、PCF、股息率TTM、EV/EBITDA |
| 产品/技术管线 | 主要产品线及制程节点、各业务板块收入结构、新产品研发进展 |
| 产能/资本开支 | 晶圆厂产能及利用率、资本开支计划及执行、设备采购订单 |
| 订单/客户数据 | 在手订单、新签订单、前五大客户集中度、海外客户占比 |
| 国产替代进展 | 核心设备/材料国产化率、验证进度、大基金持股及增减持 |
| 行业/政策/市场/利率 | 全球半导体销售额及增速、存储价格趋势、出口管制政策、大基金进展、公募持仓、国债收益率等 |

**特别口径：**

- **芯片设计公司**：主要产品线收入结构（AI芯片/CPU/GPU/存储芯片/模拟芯片/MCU等）、新产品流片及量产进度、客户导入验证情况。
- **晶圆制造/IDM**：产能利用率、晶圆价格趋势、资本开支计划、制程节点分布（成熟制程/先进制程）。
- **封测公司**：先进封装收入占比（CoWoS/HBM/3D封装等）、产能利用率、资本开支。
- **设备公司**：在手订单及新签订单、客户验证进展、大基金持股、国产化率提升空间。
- **材料公司**：核心产品国产化率、客户验证及批量供货进度、大基金持股。


## 二、数据置信度标记

| 等级 | 含义 |
|------|------|
| A | 年报、季报、交易所公告、行业协会官方数据 |
| B | 公司路演、投资者关系、机构调研纪要 |
| C | 政府文件、大基金公告、商务部/工信部政策 |
| D | 券商预测模型、第三方市场调研、行业专家访谈 |
| E | 数据缺失或无法验证 |

**激进型规则**：核心指标（分产品收入结构、在手订单、产能利用率）须为A/B级；设备/材料国产化率数据须有可验证来源；若核心数据仅为D/E级，最终得分×0.80。


## 三、前置一票否决：硬红灯项（命中即淘汰，最终得分=0）

| # | 类别 | 硬红灯标准 |
|---|------|-----------|
| 1 | 交易状态 | ST、*ST、风险警示板、暂停上市风险 |
| 2 | 审计诚信 | 近3年任一年审计意见为否定或无法表示意见 |
| 3 | 治理黑历史 | 公司或实控人近3年被认定财务造假；大股东资金占用>净资产5%且未清偿 |
| 4 | 产品质量/安全 | 核心产品发生重大质量/安全性事件致大规模召回 |
| 5 | 实控人/管理层 | 实控人质押>80%且有息负债/EBITDA>8；核心技术团队（CTO/研发负责人）近2年全部离职 |
| 6 | 流动性/规模 | 日均成交额 < 2000万元；或总市值 < 30亿元（设备/材料/设计公司） |
| 7 | 【债务炸弹】 | 有息负债/EBITDA > 15（制造/封测重资产企业可放宽至20）；连续3年经营现金流为负且账面现金不足以覆盖1年资本开支 |
| 8 | 【技术炸弹】 | 核心产品线遭遇重大技术路线颠覆（如AI芯片被新架构替代），且无下一代产品接替 |
| 9 | 【现金流枯竭】 | 账面现金 < 2年资本开支计划且无新增融资（制造/IDM类） |
| 10 | 【客户炸弹】 | 前三大客户贡献营收>70%且单一大客户流失（设计/封测类）；或主要客户大幅削减资本开支计划 |
| 11 | 【出口管制炸弹】 | 被美国商务部实体清单新增列入，且核心设备/材料/EDA供应被切断无替代方案 |
| 12 | 【产品力崩塌】 | 核心大单品因技术落后/竞品碾压/价格战，未来2年收入预期下滑>50% |
| 13 | 【地缘政治炸弹】 | 核心业务依赖特定海外技术授权/设备供应，且被明确列入出口管制禁止范围 |

**激进型底线**：允许半导体周期波动中亏损（如存储周期低谷），允许高研发投入导致短期盈利承压，但排斥流动性枯竭、核心技术断档、地缘封锁直接落地。

## 五、半导体周期位置修正条款

### 5.1 周期阶段判定表

| 周期阶段 | 特征与关键信号 | 激进型态度 | 修正系数E |

**当前判定（截至2026年7月）** ：**🟡 过热/泡沫区与景气上行交界**

- SW半导体指数PE(TTM)达161.68x，处于近2019年以来99.72%分位
- 半导体材料PE 281x、分立器件241x，均处历史极值
- 2026年6月半导体板块涨幅36.75%，估值5年分位PE/PB均达100%

- 存储价格自2025年以来涨幅2-17倍
- **综合判断：板块处于过热/泡沫区与景气上行交界，E暂取0.85-0.90（保守取0.85）**

## 七、核心口径修正（半导体行业特有）

- **AI算力相关收入**：GPU/AI芯片/算力相关收入占比，突破20%/40%为两大拐点
- **国产替代率**：设备/材料国产化率及提升速度，决定估值天花板
- **在手订单**：设备/封测类企业业绩前瞻指标，跟踪同比增速、新签订单、客户结构
- **产能利用率**：晶圆厂/封测厂景气度核心指标，>90%为满载信号
- **资本开支**：晶圆厂/设备企业扩产意愿，决定设备材料订单持续性
- **存储价格趋势**：DRAM/NAND价格周期，存储公司利润弹性核心变量
- **大基金持股**：国家产业资本背书，增减持信号需区分正常退出与战略调整
- **出口管制**：实体清单、设备出口管制升级是核心风险
- **先进封装**：CoWoS/HBM/3D封装等先进封装收入占比，弥补制程短板的关键路径

## 十一、最终计分公式（M1–M9）

模块合计分 = M1 + M2 + … + M8（制造/封测/设备企业按调整后权重计算，M9作为加分项）
执行交叉封顶与共振加成 → 调整后模块总分（≤100）

若经营现金流为负且连续2年且现金紧张，原始总分 × 0.85
周期修正后得分 = 原始总分 × E（E为周期系数）
熔断后得分 = 周期修正后得分 × K（K为估值熔断系数）
M1–M9最终得分 = min(100, 熔断后得分)
若核心数据置信度为E级，最终得分 × 0.80
制造/封测/设备企业计分公式：
模块合计分 = M1' + M2' + … + M8'（调整后权重，满分95）
原始总分 = (max(0, 调整后总分 - 黄灯扣分) + M9加分) × (100/95) × E × K

## 十三、执行SOP（激进型·半导体版）

1. **拉取A股半导体股票池**，按企业类型分类（芯片设计、晶圆制造、封装测试、设备、材料、IDM）。
2. **判定当前行业景气周期阶段**（E系数）——当前为过热/泡沫区与景气上行交界，E取0.85。
3. **对每只标的**：梳理产品线结构、AI/先进制程收入占比、国产替代进度、在手订单/产能利用率。
4. **硬红灯13项排雷**，命中即淘汰。
5. **记录黄灯事项及扣分**。
6. **计算M1–M9各模块得分**，执行交叉封顶与共振加成。
7. **扣除黄灯分**，执行经营现金流/出口管制惩罚。
8. **乘以周期系数E**，计算估值熔断K。
9. **数据置信度E级扣分**。
10. **综合M1–M9得分**，按评级池分类输出卡片及汇总表，给出仓位建议。

## 关键风险提示（激进型必读）

1. **估值泡沫风险**：当前半导体板块PE处于历史99%+分位，估值扩张已极致，需警惕中报兑现后的回调风险。高估值本身不是下跌的理由，但对业绩兑现能力提出了极高要求。
2. **出口管制升级风险**：美国商务部拟将设备出口许可从"个案审查"改为"推定拒绝"，对依赖进口设备/材料的国内晶圆厂构成实质性威胁。
3. **周期反转风险**：存储价格已从低点上涨2-17倍，若AI资本开支不及预期或供给超预期增长，价格可能高位回落。
4. **技术路线风险**：AI芯片架构快速迭代，技术路线选择错误可导致核心产品被颠覆。
5. **大基金减持风险**：一期、二期陆续退出是正常投资回收，但短期可能对股价形成压力。
6. **每季度重新评估**，核心看AI算力需求趋势、存储价格走势、国产替代进度、大基金投向变化。
