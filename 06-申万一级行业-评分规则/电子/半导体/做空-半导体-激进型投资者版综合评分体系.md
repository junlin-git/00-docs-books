# 半导体行业做空标的筛选综合评分体系（激进型做空者版）

**版本：v1.0-B 激进型做空者版**
**核心主题：估值泡沫破灭 · 周期见顶回落 · 技术路线淘汰 · 地缘政治风险**
**适用范围：A股半导体核心企业（芯片设计、晶圆制造、封装测试、设备、材料、IDM），收入或毛利占比≥70%**
**适用投资者：激进型做空者，追求估值回归、周期反转、技术颠覆、地缘制裁等下行催化剂带来的收益**

## 一、强制数据口径（与做多版相同，但侧重负面信号）

| 数据类型 | 必须使用 |
|---------|---------|
| 股价/市值 | 最近一个交易日A股收盘价 |
| 财务数据 | 最新年报 + 最新季报/中报（合并报表） |
| 历史数据 | 至少3个完整会计年度 |
| 估值数据 | PE(TTM)、前瞻PE、PS(TTM)、PB(LF)、PCF、股息率TTM、EV/EBITDA |
| 产品/技术管线 | 主要产品线及制程节点、各业务板块收入结构、新产品研发进展 |
| 产能/资本开支 | 晶圆厂产能及利用率、资本开支计划及执行、设备采购订单 |
| 订单/客户数据 | 在手订单、新签订单、前五大客户集中度、海外客户占比 |
| 国产替代进展 | 核心设备/材料国产化率、验证进度、大基金持股及增减持 |
| 行业/政策/市场/利率 | 全球半导体销售额及增速、存储价格趋势、出口管制政策、大基金进展、公募持仓、国债收益率等 |

**做空特别口径**：
- 估值历史分位（极高为做空信号）
- 库存水平及周转天数（累积为风险）
- 资本开支过度扩张（产能过剩风险）
- 客户砍单/资本开支削减
- 技术路线被替代风险
- 地缘政治制裁敞口
- 大股东减持/管理层套现

| 等级 | 含义 |
|------|------|
| A | 年报、季报、交易所公告、行业协会官方数据 |
| B | 公司路演、投资者关系、机构调研纪要 |

## 六、估值熔断机制（做空触发阈值）

做空不设“熔断”而是“做空置信度阈值”，评分越高越适合做空。

**设计类做空阈值**：
- PS>30x 或 PE>120x → 做空信号强烈（+10分）
- PS 20-30x 或 PE 80-120x → 做空信号中等（+6分）
- PS<10x 或 PE<50x → 做空信号弱（-5分，可能禁止做空）

**设备/材料类**：
- PE>150x → 强烈做空（+10分）
- PE 100-150x → 中等（+6分）
- PE<60x → 弱（-5分）

**制造/封测类**：
- PE>60x 或 PB>4x → 强烈（+10分）
- PE 35-60x 或 PB 2.5-4x → 中等（+6分）
- PE<20x 或 PB<1.5x → 弱（-5分）

做空K系数（即做空置信度乘数）：极高估K=1.3，高估K=1.15，合理K=0.8，低估K=0.5。

## 七、核心做空信号口径（半导体特有）

- **估值泡沫**：PS/PE历史分位>95%，且无业绩高增长匹配
- **库存积压**：存货周转天数连续上升，且行业需求放缓
- **产能过剩**：资本开支增速远超需求，利用率下滑
- **客户砍单**：主要客户下调资本开支或采购计划
- **技术替代**：新架构/新制程/新封装颠覆现有产品
- **地缘政治**：被列入实体清单或设备断供风险
- **大基金退出**：大基金减持信号，国家背书减弱
- **管理层减持**：大规模套现，显示内部信心不足

## 九、做空交叉共振规则（额外加分）

- **估值泡沫+基本面恶化**：PE分位>90%且营收转负，S1+S2额外+3分
- **周期见顶+库存积压**：行业处于过热区且存货周转天数>150天，S4额外+2分
- **技术替代+客户流失**：核心产品被竞品替代且大客户砍单，S5+S2额外+2分
- **政策利空+地缘风险**：被列入实体清单且海外收入高，S6额外+1.5分
- **资金出逃+内部减持**：公募大幅减仓且大股东减持>10%，S7+S8额外+2分
- **产能过剩+资本开支仍高**：利用率<70%且资本开支增速>20%，S9额外+1分

## 十、做空评级池

| 评级 | S1–S9条件 | 做空操作含义 |
|------|-----------|-------------|
| 🔴 强烈做空 | 最终得分≥80，S1≥18，S4≥8，无禁止项 | 核心做空标的，仓位可占做空组合的15% |
| 🟠 中等做空 | 得分65-79，S1≥12，S4≥5 | 战术做空标的，仓位≤10% |
| 🟡 观察储备 | 得分50-64 | 等待催化剂（如财报不及预期、制裁落地） |
| ⚪ 回避 | 得分<50，或触发禁止做空项 | 不适合做空 |
| 🚫 强制平仓 | 标的出现重大利好/基本面反转 | 立即平仓 |

**做空组合纪律**：
- 总做空仓位（融券/期权/衍生品）不超过净资产的20%
- 单一做空标的≤5%净资产（强烈做空标的≤8%）
- 设备/材料与设计类做空仓位分配：设计类50%，设备材料30%，制造封测20%
- 对冲策略：可同时持有多头行业龙头（如设备）对冲系统性风险

## 十一、最终计分公式（做空版）

模块合计分 = S1 + S2 + … + S8（制造/设备/封测按调整权重，S9加分）
执行交叉共振加成 → 调整后总分（≤100）
原始做空得分 = 调整后总分 + 黄灯加分（即做空信号加分）
若核心数据置信度为E级，原始得分 × 0.80
周期修正后得分 = 原始得分 × E（做空系数，过热区1.30）
最终做空置信度 = min(100, 周期修正后得分)
