# 文件：A股种植业（种业/粮食种植）股票筛选综合评分体系（M1–M9 量化评分框架）

**版本：v1.0-B 激进型投资者版**

**核心主题：转基因商业化红利 · 粮价周期反转弹性 · 种业集中度提升 · 土地资源稀缺性溢价**

**适用范围：A股种植业核心企业（种业/粮食种植/经济作物种植收入或毛利占比≥60%）**

**不适用：林业、渔业、饲料加工、农产品流通**

**适用投资者：激进型，追求转基因商业化爆发、粮价底部反转弹性、种业整合加速、土地资源价值重估四大弹性**


## 一、强制数据口径（总览）

| 数据类型 | 必须使用 |
|---------|---------|
| 股价/市值 | 最近一个交易日A股收盘价 |
| 财务数据 | 最新年报 + 最新季报/中报（合并报表） |
| 历史数据 | 至少3个完整会计年度 |
| 估值数据 | PE(TTM)、前瞻PE、PS(TTM)、PB(LF)、PCF、股息率TTM、亩均市值（种植企业）、EV/EBITDA |
| 经营数据 | 种子销量及同比、制种面积、品种审定数量、转基因品种获批数量及推广面积 |
| 种植数据 | 种植面积、粮食产量、单位亩产、土地租金、种植成本 |
| 行业数据 | 全国粮食总产量（2025年71488万吨/+1.2%）、玉米/小麦/大豆价格、转基因推广面积（2025年约3100万亩） |
| 政策数据 | 种业振兴行动、转基因品种审定进展（160+品种）、农垦改革、耕地保护制度 |
| 机构持仓 | 公募、北向、产业资本持仓变化 |

**种业/种植企业特别口径**：转基因品种储备及商业化进度、品种权数量及质量、研发投入强度、土地资源储备及确权情况。


## 二、数据置信度标记

| 等级 | 含义 |
|------|------|
| A | 年报、季报、交易所公告、农业农村部官方数据、品种审定公告 |
| B | 公司路演、投资者关系、机构调研纪要、种子双交会信息 |
| C | 政府文件、农业农村部政策公告、发改委数据 |
| D | 券商预测模型、第三方市场调研、行业专家访谈 |
| E | 数据缺失或无法验证 |

**激进型规则**：核心指标（种子销量、转基因品种获批数量、制种面积）须为A/B级；种植企业土地面积须有公开披露；若核心数据仅为D/E级，最终得分×0.80。无A/B级核心数据支撑者，直接淘汰。


## 三、前置一票否决：硬红灯项（命中即淘汰，最终得分=0）

| # | 类别 | 硬红灯标准 |
|---|------|-----------|
| 1 | 交易状态 | ST、*ST、风险警示板、暂停上市风险 |
| 2 | 审计诚信 | 近3年任一年审计意见为否定或无法表示意见；年报披露前3个月内换所且无合理解释 |
| 3 | 治理黑历史 | 公司或实控人近3年被认定财务造假；大股东资金占用>净资产5%且未清偿 |
| 4 | 品种安全 | 核心品种因质量问题被农业农村部强制退出市场；种子生产经营许可证被吊销 |
| 5 | 实控人/管理层 | 实控人质押>80%且有息负债/EBITDA>8；核心育种研发团队近2年全部离职 |
| 6 | 流动性/规模 | 日均成交额 < 1000万元；或总市值 < 15亿元（种业企业规模普遍偏小） |
| 7 | **债务炸弹** | 有息负债/EBITDA > 12；连续2年经营现金流为负且账面现金不足以覆盖1年研发+制种支出 |
| 8 | **品种炸弹** | 核心大品种（营收占比>40%）因抗性丧失/竞品碾压面临淘汰，且无后续梯队品种接替 |
| 9 | **库存炸弹** | 种子库存/销量比>150%（种子过期即减值），且无有效去库计划 |
| 10 | **土地炸弹**（种植企业） | 核心种植用地承包经营权到期无法续期；或耕地被强制收回/转用 |
| 11 | **合规炸弹** | 因种子质量/转基因违规种植被处以重大行政处罚 |
| 12 | **地缘政治炸弹** | 主要进口种质资源被实施出口管制且无替代渠道 |
| 13 | **转基因落后** | 在已放开转基因的作物领域（玉米、大豆）无任何获批转基因品种 |

**激进型底线**：允许种业周期底部亏损，允许研发投入高企，但排斥品种断层、库存失控、转基因赛道掉队风险。

## 五、种植业周期位置修正条款

### 5.1 周期阶段判定表

| 周期阶段 | 特征与关键信号 | 激进型态度 | 修正系数E |
|---------|---------------|-----------|----------|
| **粮价底部/种植亏损区** | 玉米/大豆价格处于历史低位（国内玉米约2355元/吨），种植效益偏弱，农户种植意愿下降 | 逆向左侧布局 | **1.35** |
| **弱复苏/拐点期** | 粮价企稳回升，全球供需由宽松转向紧平衡，种植效益改善 | 核心加仓期 | **1.20** |
| **景气上行/兑现期** | 粮价持续上涨，种植收益丰厚，转基因品种溢价兑现 | 持有等待 | **1.00** |
| **过热/泡沫区** | 粮价暴涨，种植面积过度扩张，种子价格泡沫化 | 降仓回避 | **0.80** |
| **政策冲击区** | 大规模进口放开、粮食安全政策重大调整 | 紧急避险 | **0.65** |
| **极端天气冲击区** | 重大干旱/洪涝导致核心产区大幅减产 | 紧急避险 | **0.60** |

**当前判定（截至2026年7月）** ：🟢 **弱复苏/拐点期（E=1.20）**

2025年全国粮食总产量71488万吨（+1.2%），连续2年超过1.4万亿斤。2025年国内玉米、大豆、小麦等大宗农产品价格低位运行，种植效益偏弱。中金公司研报认为，历经2023-2025年全球农产品持续累库、价格深度下行的调整周期后，2026年农产品板块或正式迎来周期拐点，全品类价格底部充分夯实。供给端收缩、成本端刚性抬升、极端天气扰动、能源转型需求四重逻辑共振。当前板块整体PB为2.51倍，处于2010年以来后10.92%分位。

## 七、核心口径修正（种植业特有）

- **转基因商业化进度**：种植业最大催化剂。2025年农业农村部批准96个转基因玉米品种和2个转基因大豆品种。预计2025年转基因种植面积约3100万亩，2026年常规化种植规模有望突破8000万亩。头部种企优先取得转基因品种推向市场，有望在推广前两年内市占率快速提升。

- **种子销量**：种业企业规模与成长性的核心指标。隆平高科2025年玉米种子营收50.4亿元（+0.4%），营收占比59.5%。

- **品种审定数量**：衡量种企研发转化能力的关键指标。已有160个转基因玉米品种和19个转基因大豆品种获批。

- **制种面积**：前瞻指标，决定下一年度可供种子量。

- **库存/销量比**：种业特有风险指标。种子过期即减值，库销比>120%须高度警惕。

- **研发投入强度**：种业核心壁垒。种业研发周期长、投入大，研发投入/营收>5%是优秀种企标配。

- **土地资源**：种植企业的核心资产。北大荒2025年营收53亿元，利润总额10.95亿元。跟踪种植面积、土地承包经营权年限、租金成本。

- **粮食价格**：种植业盈利的直接驱动。2025年玉米产量30124万吨（+2.1%），大豆2091万吨（+1.3%）。玉米价格已处于历史周期底部位置。

## 九、交叉封顶与共振规则

- **转基因+品种双击**：转基因品种获批数量>5个且种子销量增速>15%，M1+M2额外+3分。
- **粮价反转+种植弹性共振**：玉米/大豆价格同比上涨>10%且种植面积扩张>5%，M4额外+2分。
- **政策催化+转基因放量共振**：种业振兴政策加码且转基因推广面积增速>50%，M6额外+1.5分。
- **估值底部+周期拐点**：PS处于近5年10%分位以下且粮价确认拐点向上，M5额外+1.5分。
- **库存风险惩罚**：若库存/销量比>150%，M3.5得分归零，M3总分×0.80。
- **经营现金流惩罚**：若经营现金流为负且连续2年且账面现金<1年研发+制种支出，原始总分×0.85。

## 十一、最终计分公式

1. 模块合计分 = M1 + M2 + … + M8（M9为加分项）
2. 执行交叉封顶与共振加成 → 调整后模块总分（≤100）
3. 原始总分 = max(0, 调整后总分 - 黄灯扣分)
4. 若经营现金流惩罚，原始总分 × 0.85
5. 若库存风险惩罚，按规则执行
6. 周期修正后得分 = 原始总分 × E
7. 熔断后得分 = 周期修正后得分 × K
8. M1–M9最终得分 = min(100, 熔断后得分 + M9加分)
9. 若核心数据置信度为E级，最终得分 × 0.80

## 十三、执行SOP（激进型·种植业版）

1. 拉取A股种植业股票池，按种业/粮食种植分类。
2. 判定当前行业景气周期阶段（E系数）。
3. 对每只标的：梳理种子销量、品种审定、转基因储备、种植面积、估值。
4. 硬红灯13项排雷，命中即淘汰（特别注意转基因掉队风险、库存风险）。
5. 记录黄灯事项及扣分。
6. 计算M1–M9各模块得分（种业M9默认3分），执行交叉封顶与共振加成。
7. 扣除黄灯分，执行经营现金流/库存风险惩罚。
8. 乘以周期系数E，计算估值熔断K。
9. 数据置信度E级扣分。
10. 综合得分按评级池分类输出卡片及汇总表，给出仓位建议。
11. 实时跟踪关键事件（转基因品种审定公告、粮价走势、种业振兴政策、季报年报、厄尔尼诺天气）。

**关键风险提示（激进型必读）** ：

- 转基因商业化进度存在政策不确定性，推广速度和范围可能不及预期。
- 种子行业库存周期风险：种子过期即减值，库销比高企时须警惕减值风险。
- 粮食价格受全球供需、贸易政策、天气等多重因素影响，底部反转时点存在不确定性。
- 种业研发周期长、投入大，品种研发失败是常态，须分散配置。
- 种植企业受极端天气（干旱、洪涝、厄尔尼诺）影响大，2026年三季度至2027年一季度强厄尔尼诺发生概率近90%。
- 种业行业集中度低、竞争激烈，品种同质化严重，须优选具备转基因先发优势的头部企业。
- 每季度重新评估，核心看转基因推广面积、品种审定进展、种子销量、粮价趋势。
