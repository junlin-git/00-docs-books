# 文件：A股养殖业（生猪/禽养殖）股票筛选综合评分体系（M1–M9 量化评分框架）  
**版本：v1.0-B 激进型投资者版**  
**核心主题：周期反转弹性 · 成本优势兑现 · 出栏量高增长 · 疫病风险出清**  
**适用范围：A股生猪养殖、肉禽养殖（收入或毛利占比≥60%）**  
**不适用：饲料加工（纯饲料）、动保疫苗（纯生物制品）、水产养殖、种业**  
**适用投资者：激进型，追求猪周期底部反转、出栏量爆发、成本领先、估值重估四大弹性**

## 二、数据置信度标记
| 等级 | 含义 |
|------|------|
| A | 年报、季报、交易所公告、政府官方出栏数据 |
| B | 公司路演、投资者关系、机构调研纪要、行业会议 |
| C | 政府文件、农业部/发改委政策公告 |
| D | 券商预测模型、第三方调研、草根数据 |
| E | 数据缺失或无法验证 |

**激进型规则**：核心指标（完全成本、出栏量、能繁母猪存栏）须为A/B级；若为D/E级，最终得分×0.80。无公开经营数据支撑者，直接淘汰。

## 三、前置一票否决：硬红灯项（命中即淘汰，最终得分=0）
| # | 类别 | 硬红灯标准 |
|---|------|-----------|
| 1 | 交易状态 | ST、*ST、风险警示板、暂停上市风险 |
| 2 | 审计诚信 | 近3年任一年审计意见为否定或无法表示意见；年报披露前3个月内换所且无合理解释 |
| 3 | 治理黑历史 | 公司或实控人近3年被认定财务造假；大股东资金占用>净资产5%且未清偿 |
| 4 | 疫病安全 | 爆发非洲猪瘟等重大疫病导致存栏损失>30%且无有效防控措施 |
| 5 | 实控人/管理层 | 实控人质押>80%且有息负债/EBITDA>8；核心养殖团队近2年全部离职 |
| 6 | 流动性/规模 | 日均成交额<2000万元；或总市值<30亿元（养殖企业重资产属性） |
| 7 | **债务炸弹** | 有息负债/EBITDA>15；连续2年经营现金流为负且账面现金不足以覆盖1年饲料采购支出 |
| 8 | **产能炸弹** | 能繁母猪存栏连续3个季度下滑且无复产计划；或因环保/土地问题导致在建工程停滞 |
| 9 | **现金流枯竭** | 账面现金<6个月饲料采购及人工成本且无新增融资或大股东注资 |
| 10 | **成本炸弹** | 完全成本高于行业平均15%以上且无明确降本路线 |
| 11 | **政策炸弹** | 因环保违规被吊销排污许可证或遭农业部强制关停 |
| 12 | **产品力崩塌** | 商品猪出栏均重持续低于行业标准，或肉品质量安全事件致品牌受损 |
| 13 | **地缘政治炸弹** | 进口饲料原料（如大豆）被实施禁运，且公司无替代采购渠道（极端情形） |

**激进型底线**：允许周期亏损，允许高负债，但排斥流动性枯竭、产能崩溃、疫病失控。

## 五、养殖业周期位置修正条款
### 5.1 周期阶段判定表（以猪周期为例）
| 周期阶段 | 特征与关键信号 | 激进型态度 | 修正系数E |
|---------|---------------|-----------|----------|
| 深度亏损/底部区 | 猪粮比<5:1，能繁去化加速，行业普遍亏损，股价低迷 | 逆向左侧布局 | 1.35 |
| 弱复苏/黎明期 | 猪价反弹至成本线附近，能繁存栏企稳，市场预期改善 | 核心加仓期 | 1.15 |
| 景气上行/兑现期 | 猪价持续上涨，盈利丰厚，出栏量扩张 | 持有等待 | 1.00 |
| 过热/泡沫区 | 猪价创历史新高，养殖利润极高，产能过度扩张 | 降仓回避 | 0.80 |
| 政策冲击区 | 大规模进口放开、环保严令关停、重大疫病爆发 | 紧急避险 | 0.65 |

**当前判定（截至2026年6月）**：弱复苏/黎明期（E=1.15），猪粮比约6.5:1，能繁母猪存栏连续3个月微降，行业亏损面收窄。

## 六、估值天花板熔断机制（K系数）
### 6.1 估值阈值（激进型·差异化）
**生猪养殖企业**：
- 头均市值（市值/年出栏量）：
  - 极度低估：<3000元/头
  - 低估：3000-5000元/头
  - 合理：5000-8000元/头
  - 高估：>8000元/头

**禽养殖企业**：参考PB历史分位，PB<1.5倍为极度低估，1.5-2.5倍合理，>3倍高估。

### 6.2 熔断系数K
| 条件 | K |
|------|---|
| 生猪：头均市值<3000 且 PB<1.5 | 1.00 |
| 生猪：头均市值3000-5000 或 PB 1.5-2.5 | 0.92 |
| 生猪：头均市值5000-8000 或 PB 2.5-4.0 | 0.85 |
| 生猪：头均市值>8000 或 PB>4.0 | 0.72 |
| 生猪：头均市值>12000 | 0.50（强制清仓） |
| 禽：PB<1.5 | 1.00 |
| 禽：PB 1.5-2.5 | 0.92 |
| 禽：PB>2.5 | 0.80 |

**激进取暖期**：若周期为“底部区”且头均市值<2500，K可上浮+0.07。

## 七、核心口径修正（养殖业特有）
- **完全成本**：包含饲料、人工、折旧、防疫、财务费用等，是盈利核心。
- **出栏量**：年度生猪/禽出栏量，是成长性核心指标。
- **能繁母猪存栏**：领先指标，预示未来10个月出栏量。
- **头均市值**：估值核心，比PE更可靠（因周期亏损时PE无效）。
- **猪粮比**：衡量养殖利润，国家收储/放储依据。
- **饲料成本**：玉米、豆粕价格影响最大，自给率及锁价能力重要。
- **疫病**：非洲猪瘟、蓝耳病等，可造成毁灭性打击。

## 九、交叉封顶与共振规则
- **产能扩张+成本下降双击**：出栏量增速>20%且完全成本同比下降>5%，M1+M2额外+3分。
- **周期底部+估值极端**：头均市值<3000且PB<1.5，M5额外+2分。
- **政策收储+产能去化共振**：收储启动且能繁存栏环比降幅>1%，M6额外+1.5分。
- **经营现金流惩罚**：若经营现金流为负且连续2年且账面现金<6个月运营成本，原始总分×0.85。
- **疫病风险惩罚**：若公司所在区域发生重大疫情且未有效隔离，M4得分归零，总分×0.70。

## 十、评级池（激进型三梯队+淘汰）
| 评级池 | M1–M9条件 | 操作含义 |
|--------|-----------|----------|
| 🔥 核心弹性池 | 最终得分≥80，M1≥16，M2≥13，K≥0.85 | 核心仓位（单只≤15%） |
| 📈 趋势强化池 | 最终得分≥65，M2≥10，K≥0.78 | 战术仓位（单只≤10%） |
| 👀 观察储备池 | 得分50-64.9，K≥0.78 | 关注催化窗口 |

**仓位纪律**：
- 养殖业总仓位≤30%，单一标的≤15%，核心弹性池合计≤25%。
- 底部区总仓位可升至20%-25%；政策冲击区（如疫病）降至≤10%。
- 任一标的K<0.78或触发硬红灯，立即清仓。

## 十一、最终计分公式
1. 模块合计分 = M1 + M2 + … + M8（M9为加分）
2. 执行交叉封顶与共振加成 → 调整后模块总分（≤100）
3. 原始总分 = max(0, 调整后总分 - 黄灯扣分)
4. 若经营现金流惩罚，原始总分 × 0.85
5. 周期修正后得分 = 原始总分 × E
6. 熔断后得分 = 周期修正后得分 × K
7. M1–M9最终得分 = min(100, 熔断后得分)
