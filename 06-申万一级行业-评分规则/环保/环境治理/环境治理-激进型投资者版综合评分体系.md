# 环境治理行业股票筛选综合评分体系（激进型投资者版）

**版本：v1.0-B 激进型投资者版**

**核心主题：化债出清 · 运营资产重估 · 绿色产业跃迁 · 出海第二曲线**

**适用范围：A股环境治理核心企业**（固废处理/水务运营/大气治理/环境监测/生态修复/综合环境治理，收入或毛利占比≥70%）

**不适用：** 环保设备制造（纯设备类）、新能源发电（非环境治理主业）、化工/建材等泛环保概念

**适用投资者：** 激进型，追求化债受益现金流拐点、运营资产价值重估、绿色产业政策溢价、出海第二增长曲线四大弹性


## 一、强制数据口径（总览）

| 数据类型 | 必须使用 |
|---|---|
| 股价/市值 | 最近一个交易日A股收盘价 |
| 财务数据 | 最新年报 + 最新季报/中报（合并报表） |
| 历史数据 | 至少3个完整会计年度 |
| 估值数据 | PE(TTM)、前瞻PE、PB(LF)、PCF、股息率TTM、EV/EBITDA |
| 运营资产数据 | 污水处理能力/处理量、垃圾焚烧产能/处理量、在手特许经营项目数量及剩余年限、BOT/PPP项目结构 |
| 应收账款数据 | 应收账款总额及账龄结构、To G/To B收入占比、近2年回款率、坏账计提比例 |
| 化债受益数据 | 存量应收账款中政府类占比、化债政策落地后回款金额及进度、收现比变化趋势 |
| 政策/行业数据 | 环保行业增速、板块估值与持仓、碳达峰/循环经济/美丽中国政策进展、国债收益率等 |
| 出海数据 | 海外项目数量/投资额、海外收入占比及增速、项目所在国/地区分布 |

**数据置信度标记**（沿用原框架A-E五级）：

| 等级 | 含义 |
|---|---|
| A | 年报、季报、交易所公告、政府项目中标公告 |
| B | 公司路演、投资者关系、机构调研纪要、特许经营协议公告 |
| C | 政府文件、发改委/生态环境部政策、PPP项目库信息 |
| D | 券商预测模型、第三方市场调研、行业专家访谈 |
| E | 数据缺失或无法验证 |

**激进型规则：** 核心指标（分业务收入结构、运营资产规模、应收账款账龄及回款率）须为A/B级；化债回款金额须有公开公告或可验证数据；若核心运营数据仅为D/E级，最终得分×0.80。无A/B级运营数据支撑者，直接淘汰。

## 四、环境治理周期位置修正条款

### 4.1 周期阶段判定表

| 周期阶段 | 特征与关键信号 | 激进型态度 | 修正系数E |
|---|---|---|---|
| 冰点/底部区 | 估值极度压缩（PE<15x），公募持仓历史低位，化债政策初落地但效果未显 | 逆向左侧布局 | **1.30** |
| 弱复苏/黎明期 | 化债加速落地，收现比持续改善，政策密集出台（碳达峰/循环经济/美丽中国） | 核心加仓期 | **1.15** |
| 景气上行/兑现期 | 运营资产盈利释放，出海项目密集落地，分红持续提升 | 持有等待 | **1.00** |
| 过热/泡沫区 | 估值泡沫化（PE>35x），市场过度乐观，非理性追捧 | 降仓回避 | **0.80** |
| 政策冲击区 | 环保政策大幅收紧致项目大面积停滞、地方财政断崖、碳关税超预期冲击 | 紧急避险 | **0.65** |

**当前判定（截至2026年7月）：弱复苏/黎明期（E=1.15）。** 国务院印发《美丽中国建设“十五五”规划》，《“十五五”碳达峰行动方案》经国常会审议通过，《循环经济发展“十五五”规划》明确2030年产业产值迈向8万亿元。2026年置换隐债2万亿元额度已落地88%，环保板块收现比同比提升5个百分点，经营性现金流净额同比增长27.2%。板块PE约15-25x（垃圾焚烧7-13x），机构持仓、估值均处于历史底部。

| 温和预警 | 20x-25x | < 2.5% | 减仓 |
| 警戒/泡沫 | > 25x | — | 清仓观望 |

**综合环境治理平台（运营+工程混合）：** 前瞻PE<12x且股息率>3%为极度低估；12-18x为低估；>22x为高估。

## 六、核心口径修正（环境治理行业特有）

**运营资产质量：** 污水处理能力/处理量、垃圾焚烧产能/处理量是核心运营指标，关注产能利用率、处理费单价、特许经营剩余年限。BOT/TOT等特许经营项目收益稳定，类似“收租”模式。

**化债受益（核心边际改善）：** 2026年置换隐债2万亿元额度已落地88%。关注企业存量政府类应收账款规模、化债后实际回款金额、收现比改善趋势。化债“开源+节流”政策正从根本上改善环保企业现金流质量。

**应收账款/回款（行业最大风险）：** 2024年行业应收账款占营收比重31.3%，157家A股环境上市公司应收账款总额达2139亿元，占营收比例高达50.2%。收现比是核心跟踪指标，行业均值96.3%。

**出海第二曲线：** 垃圾焚烧出海空间广阔，东盟十国及印度垃圾焚烧投资空间约2500亿元。2026年以来中国环保企业出海明显提速。海外项目受益高电价&高处理费增收明显。

**绿色产业政策溢价：** 《美丽中国建设“十五五”规划》提出2030年碳达峰目标如期实现；《循环经济发展“十五五”规划》明确产业产值迈向8万亿元。制度协同驱动环保板块从估值修复向“业绩+绿色溢价”双重驱动转变。

**公募持仓低位：** 基金持有环保股总市值仅55.6亿元，占总持仓比重0.18%。机构持仓、估值均处于历史底部，弹性充足。

**高股息/股东回报：** 垃圾焚烧板块分红率持续提升至45.3%，运营类资产现金流改善后具备持续高分红能力。

**商业模式分化：** 投资运营业务（BOT/TOT）收益稳定、风险低；工程承包业务竞争激烈；设备产销业务技术溢价+规模化降本潜力大。

## 八、交叉封顶与共振规则

**化债+现金流双击：** 收现比>100%且政府类应收账款<30亿且化债回款率>50%，M2额外+2分（总分≤18）。

**政策+估值共振：** 直接受益于“十五五”三大规划且PE处于历史10%分位以下，M4+M5额外+2分。

**出海+运营共振：** 海外项目>3个且运营收入占比>60%，M6额外+1.5分。

**高股息+现金流改善双击：** 股息率>4.5%且经营现金流连续2年为正且覆盖CAPEX，M7+M2额外+2分。

**应收账款惩罚：** 若应收账款/营收>60%且账龄1年以上占比>40%（运营类企业），M2得分归零，M1-M9原始总分×0.80。

**资产负债率惩罚：** 若资产负债率>75%且有息负债/EBITDA>10，原始总分×0.85。

**工程收入依赖惩罚：** 若工程收入占比>60%且运营收入占比<30%，M1得分按50%计。

## 十、最终计分公式（M1–M9）

模块合计分 = M1 + M2 + … + M8

执行交叉封顶与共振加成 → 调整后模块总分（≤100）

原始总分 = max(0, 调整后总分 - 黄灯扣分)

若应收账款/营收>60%且账龄1年以上占比>40%，原始总分 × 0.80

若资产负债率>75%且有息负债/EBITDA>10，原始总分 × 0.85

周期修正后得分 = 原始总分 × E（E为周期系数）

熔断后得分 = 周期修正后得分 × K（K为估值熔断系数）

**M1–M9最终得分 = min(100, 熔断后得分)**

若核心运营数据置信度为E级，最终得分 × 0.80

## 十三、关键风险提示（激进型必读）

- **应收账款风险是行业最大痼疾**：2024年行业应收账款占营收31.3%，157家A股环境上市公司应收总额达2139亿元。市政污水、垃圾处理平均欠费周期大幅拉长。化债政策推进不及预期将构成系统性风险。
- **政策依赖风险**：环保行业受政策指引、驱动属性明显，政策推进或落实不及预期则存在企业发展条件不及预期的风险。
- **地方财政支付能力风险**：To G收入占比高的企业，地方财政压力直接影响回款和新增项目。
- **出海地缘政治风险**：海外项目所在国政策变化、征收风险、汇率波动。
- **BOT/PPP项目提前终止风险**：地方政府财政压力下存在提前终止存量PPP、特许经营项目的风险。
- **估值陷阱**：低PE可能反映的是应收账款坏账风险而非真实价值，需结合收现比和现金流综合判断。
- **商业模式分化风险**：工程类企业面临竞争加剧、毛利下滑；运营类企业虽稳定但扩张受限。


**每季度重新评估，核心看：化债回款进度、收现比变化、运营资产扩张、出海项目落地、分红率提升。**
