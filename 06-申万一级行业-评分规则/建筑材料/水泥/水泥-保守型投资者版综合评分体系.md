# 🛡️ A股水泥行业股票筛选综合评分体系
## v1.0-D 防御型投资者版 · 强周期价值陷阱规避 · 成本与现金流优先 · 水泥子行业差异化估值熔断

> **适用范围**：A股**水泥制造**企业，包括全国性水泥巨头、区域性水泥龙头、特种水泥制造商。核心业务（收入或毛利占比≥50%）必须为水泥、熟料、骨料或商品混凝土的生产与销售。
> **不适用**：水泥工程EPC、水泥装备制造、纯混凝土搅拌站（无矿山/熟料基地）、水泥助磨剂等产业链边缘企业。
> **适用投资者画像**：**防御型投资者**——在强周期行业中追求本金安全、穿越周期的成本优势、稳定股息、低负债率、高现金回收质量；认可“剩者为王”，不博弈短期价格波动。
> **核心哲学（格雷厄姆七准则强周期本土化）**：
> 1. **足够的规模**（小水泥在去产能中消亡）
> 2. **极其强大的财务结构**（高负债水泥股是价值陷阱）
> 3. **盈利稳定（周期调整后）**（近10年累计利润为正，亏损年份≤2年）
> 4. **股息记录**（行业底部仍能分红）
> 5. **每股收益增长**（不要求高增长，但要求“产量-成本”剪刀差不恶化）
> 6. **适度市盈率**（强周期必须用周期调整后PE，常规PE是陷阱）
> 7. **适度市净率**（PB ≤ 1.2，或PB×PE ≤ 18.0，水泥行业重资产更严）
> 8. **【A股新增】实控人为央企/省级国企**（行业集中度提升期，民企抗风险能力弱）
> 9. **【A股新增】吨指标安全边际**（吨市值、吨成本、吨净利——水泥行业独有估值锚）

触发任一硬红灯，最终得分 = 0，进入淘汰区。

| 9 | **【水泥防御核心】财务排雷** | 资产负债率 > 60%（水泥行业严于电力）；有息负债/EBITDA > 5.0（周期底部可放宽至6.0）；**货币资金/短期有息负债 < 0.5**（流动性危机前兆）；**应收账款/营业收入 > 40%**（下游地产/基建回款恶化） |
| 10 | 业务崩塌 | 营业收入连续2年同比下滑**且**毛利率同时下滑；**熟料产能利用率连续3年 < 60%**；**吨净利连续2年为负**；核心矿山资源枯竭（剩余可采年限<5年，且无替代矿山） |

# 七、核心口径修正（水泥行业特有）

## 7.1 吨指标是唯一的真实语言
水泥行业**一切财务指标必须归一化为吨指标**：
- **吨均价** = 水泥销售收入 / 水泥销量
- **吨成本** = 水泥营业成本 / 水泥销量（需拆分：吨燃料成本 + 吨电力成本 + 吨原料成本 + 吨折旧 + 吨人工）
- **吨净利** = 归母净利润 / 水泥（含熟料）总销量
- **吨市值** = 总市值 / 熟料产能（万吨）
- **吨自由现金流** = (OCF - CAPEX) / 水泥总销量
- **吨EBITDA** = EBITDA / 水泥总销量
- **吨有息负债** = 总有息负债 / 熟料产能

> **防御型口诀**：不看PE看吨市值，不看利润看吨净利，不看营收看吨成本。

## 7.2 权益产能 vs 并表产能
防御型优先关注**权益熟料产能**（含联营合营比例分配），避免高估控股权集中度低的公司产能。

## 7.3 错峰生产影响量化
对于错峰生产天数>120天的区域（如东北、华北冬季），实际产能利用率 = 设计产能 × (365 - 错峰天数) / 365。以实际可运行产能为基准。

## 7.4 碳成本内化
若公司未披露碳成本影响，按以下保守假设内化：
- 全国碳市场水泥纳入后，免费配额比例按80%估算；
- 碳价按当前CEA均价+20%溢价（安全边际）；
- 缺口部分按购买CCER或拍卖成本计入吨成本，影响模块四。

## 7.5 并购商誉穿透
水泥行业商誉主要来自并购整合（如中国建材系、华新海外）。对商誉/净资产>20%的公司，需穿透到被并购标的当前盈利，做减值测试。若标的区域价格下跌>15%，商誉减值风险需在模块五额外扣分。

## 7.6 【新增】防御型估值锚（吨重置成本法）
对水泥行业，DDM不适用（周期波动大），防御型采用**吨重置成本法**作为内在价值锚：
- **熟料重置成本** = 350元/吨（全国平均，视区位调整±50元）
- **骨料重置成本** = 30元/吨
- **商品混凝土重置成本** = 100元/立方米
- **内在价值 = (熟料产能 × 熟料重置成本 + 骨料产能 × 骨料重置成本 + 商混产能 × 商混重置成本 - 净有息负债) × 流动性折扣0.75**
- **吨市值安全边际 = (内在价值/总市值 - 1) × 100%**
- 防御型要求吨市值安全边际 ≥ 20%（低于格雷厄姆经典33%，A股水泥历史PB中位数较高，但远低于行业景气高位）

# 八、模块评分体系（总分100，防御型权重重构）

> **水泥防御型权重哲学**：
> - 成本护城河（M2）= 15分（水泥的核心是一切归为成本）
> - 估值与安全边际（M1）= 15分（低估值是强周期的唯一保护伞）
> - 财务健康（M5）= 14分（高负债水泥股是屠宰场）
> - 盈利能力（M4）= 12分（看吨净利稳定性，不看ROE绝对值）
> - 股东回报（M8）= 10分（行业底部仍分红是真正的信仰）
> - 增长与周期（M3）= 8分（不追求增长，追求成本不恶化）
> - 治理（M6）= 8分（国企+无质押+无减持）
> - 业务结构（M7）= 6分（矿山+骨料是加分，商混是减分）
> - 周期位置（M9）= 6分（防御型可逆势加仓底部，但需扣分高位）
> - 政策与碳（M10）= 6分（碳成本是未来十年的变量）

# 九、交叉封顶规则（水泥防御版）

**成本+财务交叉封顶**：
模块二（成本护城河）得分 + 模块五（财务健康）得分 ≥ 18分时，原始总分上限锁定100分；若＜18分，原始总分上限 = 实际得分 + (18 - 模块二得分 - 模块五得分) × 0.5（即，成本或财务任一短板，会拖累其他模块得分上限）。

**周期高位成长封顶**：
当周期阶段为“景气高位”时，模块三（增长与稳定性）总分 ≤ 4分。

# 十一、最终计分公式

模块合计分 = M1 + M2 + M3 + M4 + M5 + M6 + M7 + M8 + M9 + M10
交叉封顶调整后 = min(模块合计分, 封顶上限)
原始总分 = max(0, 交叉封顶调整后 - 黄灯扣分)
周期修正后得分 = 原始总分 × C
最终得分 = 周期修正后得分 × K
若数据置信度有E级关键指标，最终得分 × 0.88

# 十三、执行SOP

1. 拉取A股水泥制造股票池，剔除EPC、装备、纯混凝土搅拌站、助磨剂等非核心标的。
2. **逐只核查近10年财报**：亏损年份数、分红连续性、审计意见、实控人性质。
3. **拉取吨指标数据**：熟料产能、水泥销量、吨均价、吨成本（拆分燃料/电力/原料/折旧）、吨净利、吨市值、吨自由现金流。
4. **拉取矿山数据**：石灰石可采年限、骨料产能、采矿权详情。
5. **拉取成本数据**：长协煤覆盖率/履约率、余热发电覆盖率、替代燃料使用比例。
6. 判定行业当前周期阶段（基于水泥价格、行业吨毛利、产能利用率）。
7. 按硬红灯12项排雷，命中即归零。
8. 对未触发硬红灯的公司，记录黄灯事项及扣分。
9. 拉取最新A股收盘价、PB、PE（TTM+周期调整）、EV/EBITDA、市值、成交额、股息率、10年期国债收益率。
10. 计算吨市值安全边际（吨重置成本法）。
11. 拉取最新年报/季报，提取各财务指标（资产负债率、有息负债/EBITDA、货币资金/短债、利息保障倍数、应收账款/营收、商誉/净资产、ROE、ROIC、CAPEX/折旧、分红率、股本变化）。
12. 逐项计算模块一至模块十得分。
13. 执行交叉封顶规则（成本+财务短板惩罚）。
14. 扣除黄灯分，得到原始总分。
15. 乘以周期修正系数C。
16. 计算估值熔断K（含PB、EV/EBITDA、吨市值、PB×PE四重熔断）。

# 十四、防御型vs激进型 核心差异（水泥版）

| 维度 | 激进型 | 防御型（本体系） | 防御型逻辑 |
|---|---|---|---|
| **估值锚** | PE、PEG | **吨市值、吨重置成本、PB、周期调整后PE** | 吨指标消除周期利润波动噪音 |
| **估值权重** | 约10分 | **M1 = 15分** | 买得便宜是强周期的唯一保护 |
| **财务健康权重** | 约8分 | **M5 = 14分，且负债率>60%直接淘汰** | 高负债水泥股是价值陷阱 |
| **核心护城河** | 品牌、规模 | **矿山+水运+长协煤+吨成本** | 成本是穿越周期的唯一护城河 |
| **分红要求** | 可有可无 | **10年连续分红、行业底部仍分红** | 周期底部能否分红是生存能力证明 |
| **历史考察期** | 3-5年 | **10年完整周期** | 必须覆盖2015年行业大底+2021-2022年地产崩盘 |
| **实控人** | 无要求 | **必须央企/省级国企** | 民企在去产能中抗风险能力极弱 |
| **规模门槛** | 50亿 | **熟料产能≥500万吨** | 小产能是淘汰对象 |
| **PB上限** | 2.0 | **全国龙头≤1.4，区域龙头≤1.3** | 水泥PB 1.5以上就是风险区 |
| **吨市值上限** | 无 | **600元/吨为硬上限** | 吨市值反映市场为产能支付的对价 |
| **周期态度** | 博弈景气上行 | **底部逆向加仓，高位强制减仓** | 防御型不博弈周期，利用周期 |
| **建设/扩张** | 视为增长 | **逆周期扩张扣分** | 景气高位扩张是下一轮亏损的源头 |
| **碳成本** | 可忽略 | **必须内化并测试影响** | 碳成本是水泥行业未来十年最大变量 |
| **仓位纪律** | 无硬约束 | **水泥总仓位≤25%，现金≥30%** | 强周期行业必须限制敞口 |
