# 🚀 A股水泥行业股票筛选综合评分体系
## v1.0-A 激进型投资者版 · 周期弹性博弈 · 成长与反转优先 · 水泥子行业差异化估值重估

> **适用范围**：A股**水泥制造**企业，包括全国性水泥巨头、区域性水泥龙头、特种水泥制造商。核心业务（收入或毛利占比≥50%）必须为水泥、熟料、骨料或商品混凝土的生产与销售。
> **不适用**：水泥工程EPC、水泥装备制造、纯混凝土搅拌站（无矿山/熟料基地）、水泥助磨剂等产业链边缘企业。
> **适用投资者画像**：**激进型投资者**——在强周期行业中追求超额收益，敢于左侧布局周期反转，容忍高波动、高负债扩张、暂时亏损，核心博弈“成本优势+产能出清+价格弹性”三重击。
> **核心哲学（彼得·林奇周期博弈 + 费雪成长股本土化）**：
> 1. **周期底部布局**（买在亏损、卖在景气）
> 2. **重产能弹性**（高经营杠杆在复苏期带来利润爆发）
> 3. **轻短期亏损，重吨市值重置**（亏损年恰是买入点）
> 4. **高成长可溢价**（骨料/海外/并购驱动的二次增长曲线）
> 5. **适度负债可接受**（行业底部逆势扩张是优秀管理层试金石）
> 6. **重边际改善趋势**（吨毛利/吨净利/出货率环比改善速度比绝对值重要）
> 7. **PE不可信，看EV/吨和周期调整后盈利弹性**（景气高位PE低是陷阱，底部PE高/负是机会）
> 8. **【A股新增】博弈政策与供给收缩**（错峰加严、碳配额收紧、产能置换淘汰是超额催化剂）
> 9. **【A股新增】博弈格局改善**（区域集中度提升、并购整合、小产能退出）

# 一、强制数据口径

每次执行必须拉取并注明：

| 数据类型 | 必须使用 |
|---|---|
| 股价/市值 | 最近一个交易日A股收盘价（不参考H股） |
| 财务数据 | 最新年报 + 最新季报/中报（合并报表） |
| 历史数据 | **至少5个完整会计年度**（重点覆盖近一轮周期上行/下行） |
| 估值数据 | PB(LF)、PE(TTM扣非)、**周期调整后PE（近10年平均净利润，若上市不足10年取5年）**、EV/EBITDA(TTM)、**EV/吨（熟料产能）**、吨市值、股息率TTM |
| 分红数据 | **近5年分红记录**（激进型不要求连续，但关注行业底部是否仍有分红意愿） |
| **吨指标数据** | **熟料产能、水泥销量、吨均价、吨成本（燃料+电力+原料+折旧）、吨毛利、吨净利、吨EBITDA、吨市值、吨自由现金流** |
| **边际改善数据** | **季度吨毛利环比变化、出货率环比变化、库存天数、区域水泥价格月环比** |
| **成本结构数据** | **煤炭/电力成本占比、长协煤比例、余热发电覆盖率、替代燃料使用比例** |
| 矿山/资源数据 | 石灰石矿山可采年限、采矿权摊余成本、骨料矿山储备 |
| 产能数据 | 在产熟料产能、在建产能、产能置换指标、错峰生产执行情况、**关停/退出产能** |
| 环保/合规数据 | 生态环境部处罚、能耗双控达标情况、碳排放配额盈亏、应急管理部处罚 |
| 股权质押/减持 | 中登公司、交易所披露（激进型容忍适度质押） |
| 利率基准 | 10年期国债收益率 |
| **需求侧/格局数据** | 所在区域基建/地产投资增速、区域水泥产量增速、**区域CR3/CR5变化趋势、小产能退出量** |

# 二、数据置信度标记

| 等级 | 含义 |
|---|---|
| A | 年报、季报、交易所公告明确披露 |
| B | 公司路演、投资者关系、机构调研纪要、行业协会披露 |
| C | 政府文件、环评公示、工信部/发改委/生态环境部文件可验证 |

| E | 数据缺失或无法验证 |

> **激进型规则**：激进型对数据可靠度容忍度略高，核心吨指标为D仍可评分，但置信度为E的关键指标需在最终得分中注明风险，并酌情手动扣分（-2至-5）。

# 三、前置一票否决：硬红灯项（激进型，大幅缩减）

触发任一硬红灯，最终得分 = 0，进入淘汰区。激进型仅保留最核心的底线。

| # | 类别 | 硬红灯标准（水泥行业激进型） |
|---|---|---|
| 1 | 交易状态 | ST、*ST、风险警示板、暂停上市风险 |
| 2 | 审计诚信 | **近3年任一年审计意见为否定意见或无法表示意见**；年报披露前3个月内更换审计机构且无合理解释 |
| 3 | 治理黑历史 | **公司或实控人近3年被认定财务造假**；大股东资金占用>净资产10%且未清偿；实控人被留置且无过渡方案 |
| 4 | 重大合规/安全 | 矿山/产线被**永久性**关停且未计提；重大安全事故**被吊销生产许可证**；失信被执行人 |
| 5 | **【激进型放宽】实控人性质** | 无硬性要求，但若为民企且**质押率>80% + 有息负债/EBITDA>8.0**，则触发淘汰 |
| 6 | **【激进型底线】流动性** | **日均成交额 < 1000万元**（规避绝对僵尸股）；或总市值 < 20亿元（壳价值陷阱） |
| 7 | **【周期调整】累计亏损** | **近5年扣非净利润累计亏损 > 3年，且最新年报未出现边际改善（吨毛利同比无回升）** |
| 8 | **【激进型仅底线】分红记录** | 无硬性要求，但若**近5年从未分红且OCF/净利润持续<0.5**，触发淘汰（利润造假信号） |
| 9 | **【激进型放宽】财务排雷** | **资产负债率 > 75% 且 有息负债/EBITDA > 8.0**（极高杠杆赌徒）；或**货币资金/短期有息负债 < 0.2**（流动性枯竭） |
| 10 | 业务崩塌 | 营业收入连续3年同比下滑且毛利率连续下滑；**熟料产能利用率连续3年 < 50%**；**核心矿山资源枯竭（可采<5年且无替代）** |
| 11 | **【水泥特有】资产搁浅** | **主生产线列入国家强制淘汰目录未计提**；**碳排放配额缺口>10%且无任何应对** |
| 12 | **【激进型估值容忍】估值极端高估** | **吨市值 > 1000元/吨熟料产能**（收购价值完全丧失）；或**PB > 3.5**（市场过度炒作）；或**PB×PE > 50** |

> **激进型核心**：不排斥亏损、不排斥高负债扩张，但排斥不可逆的资产搁浅、估值完全脱离重置成本的炒作、以及财务造假。

# 五、行业周期位置修正条款（激进型：放大周期弹性）

激进型投资者**必须主动利用周期**，而不是被动防御。周期修正系数E（Elasticity）大幅放大收益波动。

## 5.1 周期阶段判定表

| 周期阶段 | 特征 | 水泥价格趋势 | 行业吨毛利 | 激进型态度 |
|---|---|---|---|---|
| **底部区间** | 价格低于或接近成本线、全行业亏损面>30%、产能利用率<60% | 磨底或微跌 | 20%企业亏损，行业吨毛利<30元 | **重仓布局阶段**，估值容忍度大幅上调，重视吨市值和经营杠杆 |
| **复苏初期** | 价格止跌回升、出货率>65%、库存下降、行业限产加码 | 环比上涨 | 吨毛利回升至成本线上40% | **核心加仓阶段**，追求边际改善速度最快的标的 |
| **景气高位** | 价格历史高位、产能利用率>85%、排队拉货 | 同比高位 | 吨毛利处于近5年85%分位 | **逐步减仓阶段**，仅保留最强成本优势+高股息标的，其余兑现收益 |
| **下行初期** | 价格见顶回落、出货率下滑、库存快速累积 | 环比下跌 | 吨毛利从高位回落>15% | **清仓回避阶段**，不博弈下跌中的反弹 |

## 5.2 周期修正系数E（激进型）

| 周期阶段 | E系数 | 估值容忍度修正 | 应用范围 |
|---|---|---|---|
| 底部区间 | 1.25 | PE容忍无上限（只看PB/吨市值）、吨市值满分线下调至150元 | M1、M2部分、M3 |
| 复苏初期 | 1.12 | PE满分线上调2倍、PB满分线上调0.25 | M1、M3、M9 |
| 景气高位 | 0.80 | PE满分线下调3倍、PB满分线下调0.3、增长项得分×0.5 | M1、M3.5、M9 |
| 下行初期 | 0.70 | PE满分线下调5倍、PB满分线下调0.5 | M1 |

> 最终得分乘以E系数。激进型在底部获得巨大加分，在高位/下行期被严厉惩罚，强制其执行逆向仓位。

# 七、核心口径修正（水泥行业特有·激进型版）

所有吨指标口径与防御型一致（参见防御型第七章7.1-7.5），但新增以下激进型关注指标：

## 7.6 吨经营杠杆
**经营杠杆系数 = (吨收入 - 吨变动成本) / (吨收入 - 吨变动成本 - 吨固定成本)**  
吨变动成本 = 吨燃料 + 吨电力 + 吨原料；吨固定成本 = 吨折旧 + 吨人工 + 吨矿山摊销。  
经营杠杆越高，在行业复苏期利润弹性越大。激进型偏爱**固定成本占比高、可变成本控制能力强的公司**（如高自有矿山、高比例长协煤、高余热发电）。

## 7.7 产能退出弹性（供给侧博弈）
**产能退出弹性 = 公司所在省/区域未来1年计划关停/置换的熟料产能 / 该区域总产能**  
若该比率>5%，且公司自身无退出/为产能置换接收方，则赋予额外加分。激进型博弈政策驱动的供给收缩。

## 7.8 价格弹性与协同
**区域集中度CR3变化**：若过去2年CR3提升≥5个百分点，且公司市占率提升，则预示未来协同提价能力增强。  
**错峰执行力度**：所在省份错峰天数同比增幅>20%，且公司非被加严错峰对象，则供给收缩逻辑强化。

# 八、模块评分体系（总分100，激进型权重重构）

> **水泥激进型权重哲学**：
> - 估值与周期弹性（M1）= 12分（估值是为弹性服务，底部可接受更高估值）
> - 成本护城河与经营杠杆（M2）= 12分（核心是周期反转时的利润爆发力）
> - 增长弹性与边际改善（M3）= 22分（激进型的核心——季度改善、销量/产能扩张）
> - 盈利能力与趋势（M4）= 14分（看趋势而非绝对水平）
> - 财务健康与杠杆（M5）= 10分（容忍适当杠杆，但需控制风险）
> - 治理与博弈结构（M6）= 6分（关注管理层进取心和股权激励）
> - 业务与格局弹性（M7）= 8分（骨料/海外等二次增长曲线）
> - 股东回报与资本配置（M8）= 6分（分红不重要，重点看并购与扩张是否明智）
> - 周期位置与市场情绪（M9）= 10分（这是激进型的择时核心）
> - 政策与碳博弈（M10）= 6分（碳成本和错峰是催化剂）

## 模块一：估值与周期弹性，12分（底部可得分更高）

| 指标 | 满分 | 评分标准（激进型倾斜） |
|---|---:|---|
| **1.1 吨市值（熟料产能）** | 4 | ≤200得4.0；200-300得3.5；300-450得2.5；450-600得1.2；600-800得0.5；>800得0 |
| **1.2 EV/吨（熟料产能）** | 3 | ≤250得3.0；250-400得2.5；400-600得1.8；600-800得0.8；>800得0 |
| **1.3 PB相对子行业阈值** | 1.5 | 安全区1.5；温和预警1.0；警戒区0.5；危险区0 |
| **1.4 周期调整后PE弹性（近10年均利润）** | 1.5 | ≤10得1.5；10-15得1.2；15-20得0.8；>20得0.3；亏损年份不计入（激进型容忍） |

# 九、交叉封顶规则（激进版）

**低成本+高弹性共振加分**：
当模块二（成本护城河）≥10分 且 模块三（增长弹性）≥18分 且 估值模块（M1）吨市值≤300时，总分可额外获得**+3分弹性加成**（不超100）。

**周期底部双击**：
当周期阶段为“底部区间”且吨市值≤250时，模块九（周期位置）可直接按满分10分计算。

**景气高位限弹**：
当周期阶段为“景气高位”时，模块三得分上限锁定为12分，模块九得分上限锁定为4分。

# 十一、最终计分公式

模块合计分 = M1 + M2 + M3 + M4 + M5 + M6 + M7 + M8 + M9 + M10
交叉封顶调整后 = min(模块合计分, 100) （激进型上限100，但允许弹性加成+3分，最终不超过100）
原始总分 = max(0, 交叉封顶调整后 - 黄灯扣分)
周期修正后得分 = 原始总分 × E
最终得分 = min(100, 周期修正后得分 × K)
若数据置信度有E级关键指标，最终得分酌情扣2-5分。

# 十三、执行SOP

1. 拉取A股水泥制造股票池，剔除EPC、装备、纯混凝土搅拌站、助磨剂等非核心标的。
2. 判定当前水泥行业周期阶段（基于水泥价格、行业吨毛利、产能利用率、行业亏损面）。
3. **逐只核查近5年财务数据**：亏损年数、分红记录、审计意见、质押风险。
4. **重点拉取边际改善数据**：季度吨毛利环比、出货率、区域水泥价格月环比。
5. 拉取吨指标：熟料产能、销量、吨均价、吨成本、吨毛利、吨净利、吨市值、EV/吨、吨自由现金流。
6. 拉取产能数据：在产产能、在建产能、区域产能退出计划、错峰执行情况、碳排放配额。
7. 按硬红灯12项排雷，命中即归零。
8. 记录黄灯事项及扣分。
9. 逐项计算模块一至模块十得分，执行交叉封顶与弹性加成。
10. 扣除黄灯分，乘以周期修正系数E。
11. 计算估值熔断K（含吨市值、EV/吨、PB、EV/EBITDA四维），若底部极度低估共振则K额外上浮。
12. 关键指标置信度为E的，酌情扣分（-2至-5）。
13. 按激进型评级池分类，特别注意周期阶段对应的仓位建议。
14. 输出结果表，注明数据日期、置信度、周期判定、关键假设。
