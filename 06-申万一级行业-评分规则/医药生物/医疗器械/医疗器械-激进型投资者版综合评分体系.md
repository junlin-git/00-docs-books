# 📌 核心哲学（医疗器械·激进型投资者版·A股修订版）

- **赢在破局，押注从0到1的颠覆**：医疗器械已告别集采免疫的普惠时代，激进型不看重成熟低值耗材的防守，而**押注高端影像、手术机器人、电生理、神经介入等国产渗透率<20%的蓝海赛道，博弈技术突破带来的非线性爆发**。
- **集采是双刃剑，拥抱“剩者为王”的份额抢夺**：高值耗材集采常态化，激进型不惧降价，而在降价靴子落地后重仓**产能完备、能以价换量、迅速挤占外资份额的龙头**，博弈收入断层的修复与市占率的飙升。
- **出海是唯一估值跃升通道**：内卷市场只能给20x PE，但凡能证明欧美主流市场拿证与商业化能力（非单纯低端代工），估值体系即可从周期制造切换至全球科技成长（40x+ PE）。激进型要求海外营收增速>30%且高毛利产品占比提升。
- **管线厚度与商业化转化决定爆发力**：不迷信“研发狂魔”，要求关键节点（NMPA绿通道/FDA CE获批）的兑现率，以及重磅新品入院放量的斜率。从获批到单季度过亿的时间越短，爆发力越强。
- **并购整合是做大必经之路**：医疗器械天生“多科室、碎片化”，激进型偏好具备“内生+外延”双轮驱动基因的平台型雏形，对通过并购补齐管线、拓展渠道的动作给予期权溢价。

## 七、核心口径修正（医疗器械·A股激进型特有）

### 7.1 集采量价博弈真实测算
不单纯看降价幅度（如砍掉70%），必须结合**约定采购量基数**和**医院报量增速**测算。若量增(300%) > 价降(70%)，且无需大规模新增产能即可满足，则集采为重大利好。

### 7.2 出海商业化质量分级
- **Level 1 (最强)**：FDA/CE Class III获批，且自建直营团队打入欧美日核心医院，毛利率>70%。
- **Level 2 (中等)**：通过OEM/贴牌打入国际市场，或仅获CE Class II认证主打新兴市场，毛利率50-70%。
- **Level 3 (最弱)**：低值耗材出口，纯代工，毛利率<40%，不给予任何出海估值溢价。

### 7.3 平台化 vs 单品型风险收益比
单品型公司（如心脉医疗、惠泰医疗早期）爆发力极强但容错率低，PEG要求更苛刻；平台型公司（如迈瑞医疗、微创医疗）容忍局部管线失败，给予估值溢价。

### 7.4 DRG/DIP控费下的经济学优势
产品能否帮医院“省钱”或“缩短住院天数”（如手术机器人降低手术时间、微创耗材替代开放手术），是决定能否在控费下逆势放量的关键。

## 十、交叉封顶与共振规则

1. **国产替代+集采反转双击**：若核心赛道渗透率<20%且集采靴子落地量增超预期，M1额外+5分。
2. **高端出海爆发共振**：若欧美自营收入增速>40%且海外毛利率>65%，M2额外+5分。
3. **平台化并购扩张**：若成功并购非主业标的且1年内整合见效，M5额外+3分。
4. **单品坠落惩罚**：若核心单品占营收>60%且面临新竞品大幅降价冲击，总分×0.75。

## 十二、最终计分公式

模块合计分 = M1 + M2 + M3 + M4 + M5
执行交叉共振加成 → 调整后总分（≤100）
扣除黄灯分 → 扣分后总分
若单品坠落，扣分后总分 × 0.75
政策周期修正 = 上述得分 × P (集采与替代周期系数)
估值熔断 = 周期修正得分 × V (估值系数)
最终得分 = min(100, 熔断后得分)
