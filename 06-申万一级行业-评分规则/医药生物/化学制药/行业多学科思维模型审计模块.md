# A股化学制药行业多学科思维模型审计模块（M10）

> **版本**：v2.1 — 修订校准版（基于2025年年报及2026年上半年最新进展全面校准）
> **定位**：作为M1–M9量化评分体系的**认知质量过滤器**，独立计分，不纳入M1–M9总分
> **作用**：评估投资决策的思维质量，辅助仓位上限调整与评级池判定

---

## 一、M10模块概述

M10将全部128个多学科思维模型按11大知识领域完整映射，归并整合为**十大投资决策维度**。每个维度由AI分析师依据公开信息打分为0–10分（精度0.5分），十项累加即为M10总分（满分100分）。

M10得分**独立于M1–M9所有运算**（不参与E、K、黄灯、置信度等任何乘除或加总），仅作为平行展示的思维审计结果，用于：

- 识别认知偏差与逻辑陷阱
- 辅助仓位上限调整
- 作为评级池的**准入/限制门槛**

**v2.1修订要点**：
- 消除原版中“大市值偏好”和“确定性溢价”带来的系统偏差
- 将地缘政治从单一维度升级为“系统性相变”贯穿多个维度
- 基于百利天恒核心产品获批上市等最新进展重新校准风险收益结构

---

## 二、M10十大维度 — 完整思维模型映射与评分逻辑

> 以下十个维度完整覆盖全部128个思维模型，每个模型均与A股化学制药行业投资决策场景建立直接关联。

---

### 维度一：逻辑与元认知（00-逻辑与元认知）

| 映射模型 | 在制药投资中的具体应用 |
|---------|---------------------|
| 01-第一性原理 | 回归制药本质：是否解决未满足的临床需求？疗效是否真正优于标准疗法？ |
| 02-奥卡姆剃刀 | 商业模式是否简洁？创新药企的核心逻辑能否用一句话说清？ |
| 03-汉隆剃刀 | 对BD交易对手方、监管机构的决策，是否优先归因于情境而非恶意？ |
| 04-证伪主义 | 管线临床数据是否具备可证伪性？若III期失败，当前叙事是否仍然成立？ |
| 05-二阶思考 | 市场共识之外，二阶效应是什么？如集采对创新药长期格局的间接影响 |

**评分逻辑（0–10分）**：
- 公司战略是否直击制药第一性原理（解决未满足需求）？
- 商业模式是否简洁可证伪？
- 二阶预期差是否被市场系统性地忽视？
- 0分=完全背离第一性原理，10分=战略与制药本质完美契合

### 维度二：数学与概率（01-数学与概率）

| 映射模型 | 在制药投资中的具体应用 |
|---------|---------------------|
| 01-复利 | 创新药企的长期价值是否具备复利增长特征（专利悬崖+新品接力）？ |
| 02-指数增长 | 重磅大单品的放量曲线是否符合指数增长早期特征？ |
| 03-幂律分布 | 管线组合是否呈现幂律特征（少数项目贡献绝大多数价值）？ |
| 04-概率论 | 临床成功的先验概率与条件概率如何影响管线估值？ |
| 05-贝叶斯更新 | 市场是否随着临床数据读出动态修正成功概率？ |
| 06-期望值 | 管线组合的整体期望值是否为正？是否覆盖了失败成本？ |
| 07-回归均值 | 公司超额增速是否终将回归行业均值？竞争优势是否可持续？ |
| 08-大数定律 | 临床入组样本量是否足以支撑统计学结论？ |
| 09-随机游走 | 短期股价是否近似随机游走？是否避免对短期波动过度反应？ |
| 10-蒙特卡洛思维 | 是否对管线组合进行概率加权情景分析？ |
| 11-非线性 | 临床成功/失败是否带来非线性价值变化？ |
| 12-帕累托分布 | BD交易和重磅管线是否呈现头部集中特征？ |
| 13-边际分析 | 增加一个适应症或一个联用方案的边际收益是否大于边际成本？ |
| 14-遍历性 | 地缘政治、政策变化是否破坏了投资的时间平均与集合平均一致性？ |
| 15-辛普森悖论 | 亚组分析中是否存在被总体数据掩盖的相反结论？ |

**评分逻辑（0–10分）**：
- 管线组合是否具备幂律分布特征（赢家通吃）？
- 市场是否在以贝叶斯方式动态修正管线成功概率？
- 整体期望值是否显著为正？
- 0分=负期望值，10分=正期望值且贝叶斯持续上修

- 管理层是否建立了对抗熵增的组织机制？

**评分逻辑（0–10分）**：
- 公司业务是否简单易懂（低复杂度）？
- 管线数据的信息熵是否足够低（高信噪比）？
- 组织结构和激励机制是否支持高效的决策和执行？
- 0分=信息混沌+组织僵化，10分=高信噪比+低复杂度+高效组织

## 三、M10评级门槛与仓位影响

| M10得分区间 | 定性含义 | 对投资操作的叠加影响（独立于M1–M9评级） |
|------------|---------|-------------------------------------|
| **≥85分** | 顶级认知质量，思维模型完美契合 | 可额外提升该标的仓位上限+2%（如M1–M9已达核心池） |
| **75–84分** | 优秀认知质量，逻辑自洽 | 正常按M1–M9评级池操作 |
| **60–74分** | 一般认知质量，存在明显逻辑瑕疵 | 该标的仓位上限降低30% |
| **<60分** | 认知质量堪忧，思维陷阱较多 | 直接禁止进入核心弹性池，仅可进入观察储备池或更低仓位 |

## 四、M10与评级池的协同规则

M10作为认知质量过滤器，不改变M1–M9的量化得分，但严格约束最终的操作层级：

| 评级池 | 准入条件 | 仓位规则 |
|--------|---------|---------|
| **核心弹性池（🔥）** | M1–M9≥80 且 M10≥75 | 单只≤15%；M10≥85时可额外+2% |
| **趋势强化池（📈）** | M1–M9≥65 且 M10≥60 | 单只≤10%；M10<75时降低30%（上限7%） |
| **观察储备池（👀）** | M1–M9≥50 但 M10<60 | 禁止核心或战术仓位配置 |
| **规避/减仓池（⏸️）** | M10<50（无论M1–M9得分） | 仅保留观察仓或清仓 |
