# 文件一：A股化学制药行业股票筛选综合评分体系（M1–M9 量化评分框架）

> **版本**：v1.0-B 激进型投资者版  
> **核心主题**：创新管线弹性 · 出海商业化兑现 · 集采出清反转  
> **适用范围**：A股化学制药核心企业（化学制剂/原料药，收入或毛利占比≥70%）  
> **不适用**：生物制品、中药、医疗器械、医药商业流通、医疗服务  
> **适用投资者**：激进型，追求创新药商业化放量、BD出海爆发、集采出清反转、管线价值重估四大弹性

## 一、强制数据口径（总览）

| 数据类型 | 必须使用 |
|---------|----------|
| 股价/市值 | 最近一个交易日A股收盘价 |
| 财务数据 | 最新年报 + 最新季报/中报（合并报表） |
| 历史数据 | 至少3个完整会计年度 |
| 估值数据 | PE(TTM)、前瞻PE、PS(TTM)、PB(LF)、PCF、股息率TTM、EV/EBITDA |
| **管线数据** | 在研管线数量及阶段、核心管线适应症/靶点/竞争格局/预计上市时间/峰值销售预期 |
| **临床数据** | 近期关键临床数据读出（II/III期结果）、PFS/OS、头对头数据 |
| **BD交易数据** | License-out/授权引进金额、首付款+里程碑结构、合作方资质、交易日期 |
| **商业化数据** | 分产品收入结构（创新药/仿制药/原料药）、新药上市后季度销售额、医保纳入情况及降价幅度 |
| 行业/政策/市场/利率 | 医药制造业增速、板块估值与持仓、集采/医保/商保/《生物安全法案》进展、机构持仓、国债收益率等 |

**CXO特别口径**：在手订单/新签订单金额及增速、客户结构（海外/国内）、产能利用率、多肽/ADC/小核酸新业务占比。

**仿制药/传统药企特别口径**：集采涉及品种收入占比及毛利率变化、仿制药收入下滑幅度及企稳信号、创新药/首仿药管线进度、BD收入贡献。

## 二、数据置信度标记

| 等级 | 含义 |
|------|------|
| A | 年报、季报、交易所公告、CDE/NMPA审批公告 |
| B | 公司路演、投资者关系、机构调研纪要、权威临床数据发布 |
| C | 政府文件、医保目录公告、发改委/药监局政策 |
| D | 券商管线预测模型、第三方市场调研、行业专家访谈 |
| E | 数据缺失或无法验证 |

**激进型规则**：核心指标（分产品收入结构、创新药收入占比、核心管线临床数据）须为A/B级；BD交易金额须有公开公告；若核心管线数据仅为D/E级，最终得分×0.80。**创新药企无A/B级临床数据支撑者，直接淘汰。**

## 三、前置一票否决：硬红灯项（命中即淘汰，最终得分=0）

| # | 类别 | 硬红灯标准 |
|---|------|------------|
| 1 | 交易状态 | ST、\*ST、风险警示板、暂停上市风险 |
| 2 | 审计诚信 | 近3年任一年审计意见为否定或无法表示意见；年报披露前3个月内换所且无合理解释 |
| 3 | 治理黑历史 | 公司或实控人近3年被认定财务造假；大股东资金占用>净资产5%且未清偿 |
| 4 | 药品安全 | 核心产品发生重大安全性事件致召回/致死；被FDA/NMPA出具警告信且未整改 |
| 5 | 实控人/管理层 | 实控人质押>80%且有息负债/EBITDA>8；核心研发团队（CSO/CMO）近2年全部离职 |
| 6 | 流动性/规模 | 日均成交额 < 2000万元；或总市值 < 20亿元（创新药企） |
| 7 | 【债务炸弹】 | 有息负债/EBITDA > 10；连续3年经营现金流为负且账面现金不足以覆盖1年研发支出 |
| 8 | 【管线炸弹】 | 核心管线III期临床失败且无后续重磅管线接替；或FDA/NMPA拒绝批准核心上市申请 |
| 9 | 【现金流枯竭】 | 账面现金 < 2年研发支出且无新增融资或BD首付款到账（Biotech类） |
| 10 | 【CXO炸弹】 | 大客户流失致营收单季下滑>30%；在手订单同比下滑>30% |
| 11 | 【违规出海】 | 收到FDA完整回应函(CRL)致上市受阻；或工厂收到FDA进口警示 |
| 12 | 【产品力崩塌】 | 核心大单品因竞品获批/医保未续约/新适应症失败，未来2年收入预期下滑>50% |
| 13 | **【地缘政治炸弹】** | 美国《生物安全法案》直接列明禁止与该企业合作（CXO适用） |

**激进型底线**：允许创新药企亏损，允许研发失败，但排斥流动性枯竭、核心管线全军覆没、地缘制裁直接落地。

**创新药企（创新药收入占比≥30%或亏损期纯创新药企）**：

| 估值区间 | PS(TTM) | 管线估值/市值比 | 激进型态度 |
|---------|---------|---------------|-----------|
| 极度低估 | < 5x | < 50% | 重仓买入 |
| 低估/安全区 | 5x-10x | 50%-70% | 加仓 |
| 合理区间 | 10x-15x | 70%-90% | 持有 |
| 温和预警 | 15x-20x | >90% | 减仓 |
| 警戒/泡沫 | > 20x | — | 清仓观望 |

**仿制药转型企业（创新药收入占比<30%）**：前瞻PE<12x且股息率>3.5%为极度低估；12-18x为低估；>18x为高估。

**CXO企业**：前瞻PE<15x且在手订单增速>20%为极度低估；15-25x为合理；>25x为高估。

## 七、核心口径修正（化学制药行业特有）

- **管线估值（rNPV/市值比）**：比值<50%代表市场定价不足，是左侧信号。
- **BD出海交易**：关注首付款（短期价值）、里程碑结构、合作方资质（MNC背书）。
- **创新药收入占比**：突破30%/50%为两大拐点，标志“有存在感”和“主导地位”。
- **CXO在手订单**：业绩前瞻指标，跟踪同比增速、新签订单、海外占比、新业务增速。
- **临床数据**：核心催化剂，尤其PFS/OS主要终点、头对头优势。
- **集采出清**：制剂板块收入增速企稳转正，关注集采品种占比及毛利率底部。
- **地缘政治风险**：CXO特定风险，法案列名即硬红灯。
- **公募持仓低位**：2025Q4低点7.9%，2026Q1回升至8.9%，弹性充足。
- **医保支付边际改善**：创新药平均降幅从55%降至42%，商保目录提供第二支柱。
- **股东回报**：分红+回购作为安全边际参考。

## 十一、最终计分公式（M1–M9）

1. **模块合计分** = M1 + M2 + … + M8（CXO企业按调整后权重计算，M9作为加分项）
2. 执行交叉封顶与共振加成 → **调整后模块总分**（≤100）
3. **原始总分** = max(0, 调整后总分 - 黄灯扣分)
4. 若经营现金流为负且连续2年且Biotech现金紧张，原始总分 × 0.85
5. **周期修正后得分** = 原始总分 × E（E为周期系数）
6. **熔断后得分** = 周期修正后得分 × K（K为估值熔断系数）
7. **M1–M9最终得分** = min(100, 熔断后得分)
8. 若核心管线数据置信度为E级，最终得分 × 0.80

**CXO企业M1–M9计分公式**：
模块合计分 = M1' + M2' + … + M8'（调整后权重，满分99）  
原始总分 = (max(0, 调整后总分 - 黄灯扣分) + M9加分) × (100/99) × E × K
