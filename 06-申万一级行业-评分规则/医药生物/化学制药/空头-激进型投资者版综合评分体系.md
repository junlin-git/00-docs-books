# A股化学制药行业股票筛选综合评分体系（空头版）

## —— M1–M9 看空/做空评分框架

**版本**：v1.0-B 激进型做空版

**核心理念**：识别化学制药企业基本面恶化、估值泡沫破裂、管线价值崩塌、财务质量恶化四大做空机会

**适用范围**：A股化学制药核心企业（化学制剂/原料药，收入或毛利占比≥70%）

**不适用**：生物制品、中药、医疗器械、医药商业流通、医疗服务

**适用投资者**：激进型，追求做空/回避创新药管线失败风险、仿制药集采冲击、出海受阻、估值泡沫破裂等下行机会


## 一、强制数据口径（做空依据）

| 数据类型 | 必须使用 |
|---------|---------|
| 股价/市值 | 最近一个交易日A股收盘价 |
| 财务数据 | 最新年报 + 最新季报/中报（合并报表） |
| 历史数据 | 至少3个完整会计年度 |
| 估值数据 | PE(TTM)、前瞻PE、PS(TTM)、PB(LF)、PCF、股息率TTM、EV/EBITDA、历史分位数 |
| 管线数据 | 在研管线数量及阶段、核心管线适应症/靶点/竞争格局/预计上市时间 |
| 临床数据 | 近期关键临床数据读出（II/III期结果）、失败/终止数据 |
| BD交易数据 | License-out/授权引进金额、首付款+里程碑结构、合作方资质、交易日期 |
| 商业化数据 | 分产品收入结构（创新药/仿制药/原料药）、集采品种收入占比及价格降幅、医保纳入情况 |
| 行业/政策/市场 | 医药制造业增速、板块估值与持仓、集采/医保进展、机构持仓变化 |
| CXO特别口径 | 在手订单/新签订单金额及增速、客户流失情况、产能利用率、多肽/ADC/小核酸新业务占比 |
| 仿制药特别口径 | 集采涉及品种收入占比及毛利率变化、仿制药收入下滑幅度、创新药管线失败/延期信号 |


## 二、做空数据置信度标记

| 等级 | 含义 | 做空效力 |
|------|------|---------|
| A | 年报、季报、交易所公告、CDE/NMPA审批公告 | 最强做空依据，直接扣分/加分 |
| B | 公司路演、投资者关系、机构调研纪要、权威临床数据发布 | 强力做空依据 |
| C | 政府文件、医保目录公告、发改委/药监局政策 | 政策面做空依据 |
| D | 券商管线预测模型、第三方市场调研、行业专家访谈 | 参考但不作为核心依据 |
| E | 数据缺失或无法验证 | 不构成做空依据，该项视为中性 |

**做空底线**：核心做空信号（管线失败、收入崩塌、现金流断裂）须为A/B级；若核心做空信号仅为D/E级，该项做空得分×0；财务造假/审计问题证据达A级，加分权重提高50%。


## 三、做空触发：硬红灯做空信号（触发即强烈做空信号）

| # | 类别 | 做空触发标准 |
|---|------|-------------|
| 1 | **审计黑名单** | 近3年任一年审计意见为否定或无法表示意见；年报披露前3个月内换所且无合理解释 |
| 2 | **财务造假嫌疑** | 公司或实控人近3年被认定财务造假/立案调查；大股东资金占用>净资产5%；应收账款/营收>40%且持续恶化 |
| 3 | **管线全军覆没** | 核心管线III期临床失败/终止且无后续重磅管线接替；或FDA/NMPA拒绝批准核心上市申请（CRL） |
| 4 | **现金流枯竭** | 账面现金 < 1年研发支出且无新增融资或BD首付款到账（Biotech类）；连续3年经营现金流为负 |
| 5 | **债务炸弹** | 有息负债/EBITDA > 10且经营现金流持续为负；短期有息负债/账面现金 > 1.5 |
| 6 | **产品力崩塌** | 核心大单品因竞品获批/医保未续约/新适应症失败/集采未中标，未来2年收入预期下滑>50% |
| 7 | **药品安全事故** | 核心产品发生重大安全性事件致召回/致死；被FDA/NMPA出具警告信且未整改 |
| 8 | **违规出海打击** | 收到FDA完整回应函(CRL)致上市受阻；工厂收到FDA进口警示/警告信 |
| 9 | **地缘政治炸弹** | 美国《生物安全法案》直接列明禁止与该企业合作（CXO适用） |
| 10 | **CXO订单崩塌** | 大客户流失致营收单季下滑>30%；在手订单同比下滑>30%；美国客户收入占比>60%且无全球化布局 |
| 11 | **治理崩坏** | 实控人质押>80%且有息负债/EBITDA>5；核心研发团队（CSO/CMO）近2年全部离职 |
| 12 | **交易状态** | ST、*ST、风险警示板、暂停上市风险 |
| 13 | **业绩变脸** | 近4季度营收连续下滑且无改善迹象；最新季报净利润同比下滑>50%且无一次性因素解释 |

**做空信号释义**：任一触发 → 做空意愿强烈，直接进入🔥**核心做空池**，M1–M9总分可低至≤30分。

## 五、化学制药周期位置修正条款（做空版）

### 5.1 周期阶段判定表（做空方向）

| 周期阶段 | 特征与关键信号 | 做空态度 | 做空系数D |
|---------|---------------|---------|----------|
| 冰点/底部区 | 估值极度压缩，公募持仓历史低位，悲观情绪充分释放 | 避免做空，等待反弹 | 0.70 |
| 弱复苏/黎明期 | BD回暖，重磅数据读出，持仓开始回升 | 谨慎做空，轻仓试探 | 0.85 |
| 景气上行/兑现期 | 创新药放量加速，出海持续落地，订单饱满 | 不宜做空 | 1.00 |
| 过热/泡沫区 | 估值泡沫化，市场过度乐观，非理性追捧 | **核心做空窗口** | **1.30** |
| 政策冲击区 | 《生物安全法案》通过、集采降幅远超预期等 | 紧急做空（但注意政策落地即利空出尽） | 1.15 |
| 业绩/管线暴雷区 | 密集临床数据读出/季报披露，市场预期过高 | **最佳做空窗口** | 1.25 |

**当前判定（截至2026年6月）** ：弱复苏/黎明期（D=0.85），化学制药板块PE约38x，PS约8-10x，估值分化明显。

**CXO特别周期判定（做空）** ：订单拐点期 D=0.75；景气上行期 D=0.90；政策压制期 D=1.15；制裁落地期 D=1.35（强烈做空）。


## 六、估值熔断做空修正（V系数）

### 6.1 估值阈值（做空·差异化）

**创新药企（创新药收入占比≥30%或亏损期纯创新药企）** ：

| 估值区间 | PS(TTM) | 管线估值/市值比 | 做空态度 |
|---------|---------|---------------|---------|
| 极度低估 | < 5x | < 50% | 不做空 |
| 低估/安全区 | 5x-10x | 50%-70% | 观望 |
| 合理区间 | 10x-15x | 70%-90% | 试空 |
| 温和预警 | 15x-20x | >90% | **加仓做空** |
| 警戒/泡沫 | > 20x | — | **重仓做空** |

**仿制药转型企业（创新药收入占比<30%）** ：前瞻PE>18x且股息率<2%为做空触发；>25x为强烈做空。

**CXO企业** ：前瞻PE>25x且在手订单增速<15%为做空触发；>35x为强烈做空。

**原料药/普药企业** ：前瞻PE>20x且股息率<2%为做空触发；>25x为强烈做空。

## 七、核心口径修正（做空版·化学制药行业特有）

| 指标 | 看空/做空解读 |
|------|-------------|
| 管线估值（rNPV/市值比） | 比值>90%代表市场过度乐观/泡沫，是强烈做空信号 |
| BD出海交易 | 关注首付款是否到位、里程碑能否达成；交易稀少或金额小=增长乏力 |
| 创新药收入占比 | 突破30%/50%后若增速放缓/停滞=成长逻辑证伪 |
| CXO在手订单 | 同比增速下滑/负增长=业绩前瞻指标恶化 |
| 临床数据 | 失败/延期=核心做空催化剂，尤其III期失败 |
| 集采冲击 | 尚未集采的大品种面临降价风险；已集采品种毛利率持续下滑 |
| 地缘政治风险 | 《生物安全法案》列名即强烈做空信号 |
| 公募持仓高位 | 2020Q2高点15.8%，当前若快速回升至高位=超买风险 |
| 估值泡沫 | 板块PS>10x为危险信号，个股PS>15x须警惕 |

## 十一、最终计分公式（M1–M9做空版）

模块合计分 = M1 + M2 + … + M8（CXO企业按调整后权重计算，M9作为加分项）
执行交叉叠加与共振加成 → 调整后模块总分（≤100）
做空总分 = max(0, 调整后总分 + 黄灯加分)

周期修正后得分 = 做空总分 × D（D为做空周期系数）
熔断后得分 = 周期修正后得分 × V（V为估值做空修正系数）
M1–M9最终得分 = min(100, 熔断后得分)

CXO企业计分公式：
模块合计分 = M1' + M2' + … + M8'（调整后权重，满分95）
做空总分 = (max(0, 调整后总分 + 黄灯加分) + M9加分) × (100/95) × D × V

## 十三、执行SOP（激进型做空版）

1. **池筛选**：拉取A股化学制药股票池，按企业类型分类（创新药、仿制药转型、CXO、原料药等）

2. **周期判定**：判定当前行业景气周期阶段（D系数）——判断做空时机是否成熟

3. **负面排查**：对每只标的梳理管线失败风险、BD交易停滞、创新药收入增速放缓

4. **做空触发**：硬红灯13项做空信号排查，触发即强烈做空信号

5. **加分汇总**：记录黄灯加分项及幅度

6. **模块评分**：计算M1–M9各模块得分，执行交叉叠加与共振加成

7. **扣分调整**：执行盈利保护扣分机制

8. **系数修正**：乘以周期系数D，计算估值做空修正V

9. **评级分类**：综合M1–M9得分，按做空评级池分类输出卡片及汇总表，给出做空仓位建议

10. **动态跟踪**：实时跟踪关键事件（临床数据失败公告、BD交易终止、医保谈判结果、法案进展、季报暴雷）
