# 化学制药——综合财报分析与投资评分体系 V3

> **设计理念**：以《手把手教你读财报》三大报表分析框架 + 排雷反诈体系为骨架，融合原 V2 评分体系的量化机制，构建 **"先排雷、再评分、后决策"** 的三阶段投资分析模型。  
> **适用对象**：A 股申万三级行业"化学制药"上市公司（化学制剂、原料药，收入或毛利占比 ≥ 70%）。  
> **数据来源**：最新年报 + 最新季报 + 近 5～10 年纵向对比 + 同行业横向对比。  
> **核心原则**：**财报是用来排除企业的，不是用来选择企业的。** 先排雷淘汰，再量化评分，最后综合决策。

## 第一阶段：排雷淘汰（一票否决）

> **核心思想**：**"宁可错过，不要踩雷。"** A 股有 5000+ 家公司，不缺你错过的那一家。  
> 本阶段采用 **"硬红灯 + 黄灯扣分"** 双层机制。硬红灯命中即淘汰（最终得分 = 0）；黄灯扣分从总分中扣除。

### 1.1 硬红灯项（命中任一即淘汰）

| # | 硬红灯标准 | 识别方法 |
|---|-----------|---------|
| 🔴1 | **非标审计意见**：年报被出具保留意见、否定意见或无法表示意见 | 翻开年报第一页"重要提示"，3 秒钟确认 |
| 🔴2 | **交易状态异常**：ST、\*ST、风险警示板、暂停上市 | 股票软件直接可见 |
| 🔴3 | **财务造假实锤**：近 3 年公司或实控人被认定财务造假 | 查证监会行政处罚决定书 |
| 🔴4 | **经营现金流连续 3 年为负**且营收连续 2 年下滑 | 现金流量表直接可读 |
| 🔴5 | **资不抵债**：资产负债率 > 100%（净资产为负） | 资产负债表一眼可见 |
| 🔴6 | **存贷双高且无合理解释**：货币资金 > 总资产 30% 且有息负债 > 总资产 20% 同时存在 | 对比资产负债表左右两边 |
| 🔴7 | **实控人失联/涉刑**：实控人失联、被刑事拘留或被终身禁入 | 公司公告 |
| 🔴8 | **大股东资金占用**：关联方非经营性资金占用 > 净资产 5% 且未清偿 | 查"其他应收款"及公告 |
| 🔴9 | **核心产品重大安全事件**：药品被召回 / 被 NMPA 或 FDA 出具警告信且未整改 | NMPA/FDA 官网 |
| 🔴10 | **年报前突然换审计机构**：年报披露前 3 个月内换所且无合理解释，或审计机构"弃标" | 公司公告 |
| 🔴11 | **流动性不足**：日均成交额 < 2000 万元或总市值 < 20 亿元 | 行情数据 |
| 🔴12 | **业绩预告重大变脸**：从预盈变预亏，且差异金额 > 净资产 10% | 对比业绩预告与年报 |

### 1.2 黄灯扣分项（化学制药专属）

> 黄灯项不直接淘汰，但从总分中扣除。累计扣分上限 20 分。

| 黄灯事项 | 扣分 | 备注 |
|---------|------|------|
| 审计意见为"带强调事项段的无保留意见" | -3 至 -5 | 需看强调事项具体内容 |
| 频繁会计差错更正（近 3 年 ≥ 2 次重大更正） | -3 至 -6 | 参考至纯科技案例 |
| 业绩预告频繁修改（近 2 年 ≥ 2 次修正） | -2 至 -4 | 参考东华能源案例 |
| 研发支出资本化率 > 50%（可能虚增资产和利润） | -2 至 -4 | |
| 商誉 / 净资产 > 30% | -3 至 -5 | 商誉减值风险 |
| 销售费用率 > 50%（创新药商业化早期可豁免） | -2 至 -4 | |
| 大股东近 2 年竞价减持 > 持股 5% | -3 至 -6 | 协议转让引入产业战投且锁定期 ≥ 3 年可豁免 |
| 实控人股权质押比例 > 50% | -2 至 -4 | |
| 核心产品集采丢标且无替代品种 | -3 至 -5 | |
| 关联交易 / 营收 > 20% | -2 至 -4 | |
| 近 3 年内变更 2 次以上重要会计政策或估计 | -2 至 -4 | 参考折旧政策变更案例 |
| 核心管线同靶点竞争格局拥挤（> 10 个同类在研） | -2 至 -4 | 创新药企适用 |

## 第二阶段：六维量化评分（总分 100 分）

> **设计原则**：三大报表各独立 20 分（合计 60 分），成长性 15 分，行业竞争力 15 分，风险溢价与股东回报 10 分。  
> 每个指标设"量化评分"+"深度检查项"双层结构：量化评分快速定位，深度检查质性把关。

### 评分总览

| 维度 | 权重 | 核心考察 |
|------|------|---------|
| 资产负债表 | 20 分 | 资产含金量、负债安全性、资本效率 |
| 利润表 | 20 分 | 营收质量、盈利能力、费用控制、利润真实性 |
| 现金流量表 | 20 分 | 造血能力、投资质量、筹资健康、自由现金流 |
| 成长性 | 15 分 | 营收增速、利润弹性、研发驱动力 |
| 行业竞争力 | 15 分 | 市场地位、护城河、行业对比 |
| 风险溢价与股东回报 | 10 分 | 估值合理性、分红回购、政策风险 |
| **合计** | **100 分** | |

### 维度一：资产负债表——资产质量与财务安全（20 分）

> **核心思想**：资产负债表是企业的"家底照片"。看**左边**判断资产质量（钱变成了什么），看**右边**判断负债风险（钱从哪来）。
>
> **快速阅读三步法**：①看右边→判断风险 ②看左边→判断质量 ③看矛盾信号→综合判断

#### A1. 资产质量（8 分）

##### A1.1 货币资金充裕度（2 分）

| 指标 | 计算方式 | 评分标准 |
|------|---------|---------|
| 货币资金 / 总资产 | 货币资金 ÷ 总资产 × 100% | ≥ 20%：2 分 / 10%–20%：1 分 / < 10%：0 分 |

**深度检查**：
- 货币资金过高（> 50%）且长期不分红、不投资 → 警惕资金真实性（参考存贷双高排雷项）
- 检查是否有大额受限货币资金（质押、冻结），应从可用资金中扣除
- 理财产品（交易性金融资产 / 其他流动资产中的理财）可视为"类货币资金"纳入计算
- **矛盾信号**：账上现金很多但同时大量借款 → 典型"存贷双高"（参考安孚科技案例）

##### A1.2 应收账款健康度（2 分）

| 指标 | 计算方式 | 评分标准 |
|------|---------|---------|
| 应收账款 / 营业收入 | 应收账款 ÷ 营业收入 × 100% | ≤ 15%：2 分 / 15%–30%：1 分 / > 30%：0 分 |

**深度检查**：
- **账龄结构**：1 年以内应收占比应 > 80%，否则扣 1 分
- **增速对比**：应收账款增速远超营收增速 → 可能在赊销冲业绩或虚增收入（参考 ST 荃银案例）
- **坏账准备**：计提比例是否合理？过低可能虚增利润（参考"少计减值"造假手法）
- **应收票据**：银行承兑汇票 = 优质应收；商业承兑汇票 = 风险较高
- **化药行业特殊关注**：医院终端回款周期通常 3–6 个月，应收占比高于其他行业是正常现象

##### A1.3 存货合理性（2 分）

| 指标 | 计算方式 | 评分标准 |
|------|---------|---------|
| 存货 / 营业收入 | 存货 ÷ 营业收入 × 100% | ≤ 20%：2 分 / 20%–40%：1 分 / > 40%：0 分 |

**深度检查**：
- **存货构成**：原材料 vs 在产品 vs 产成品比例变化
- **增速匹配**：存货增速持续高于营收增速 → 产品可能滞销，扣 1 分
- **跌价准备**：药品有效期有限，过期药品应充分减值
- **化药行业差异**：原料药企业存货较高是正常现象（大宗原料备货周期长）

##### A1.4 固定资产与商誉合理性（2 分）

| 指标 | 计算方式 | 评分标准 |
|------|---------|---------|
| （固定资产 + 在建工程）/ 总资产 | 合计 ÷ 总资产 × 100% | 20%–50%：1 分 / 其他区间：0.5 分 / > 70%：0 分 |
| 商誉 / 净资产 | 商誉 ÷ 净资产 × 100% | < 10%：1 分 / 10%–30%：0.5 分 / > 30%：0 分 |

**深度检查（"三个凡是"原则）**：
- **在建工程**：长期不转固 → 可能少提折旧虚增利润、或通过虚构工程项目把钱"洗"出去
- **商誉**：商誉是"定时炸弹"，减值一来利润塌（参考劲嘉股份案例）
- **研发资本化**：开发支出资本化比例 > 50% → 可能虚增资产和利润（参考比亚迪案例）
- **折旧政策变更**：突然拉长折旧年限 → 每年折旧变少 → 利润虚高

#### A2. 负债安全性（6 分）

##### A2.1 资产负债率（2 分）

| 指标 | 评分标准 |
|------|---------|
| 资产负债率 | ≤ 40%：2 分 / 40%–60%：1 分 / > 60%：0 分 |

**化药行业基准**：合理负债率通常 30%–50%。

##### A2.2 有息负债占比（2 分）

| 指标 | 计算方式 | 评分标准 |
|------|---------|---------|
| 有息负债 / 总负债 | （短期借款 + 长期借款 + 应付债券 + 一年内到期非流动负债）÷ 总负债 | ≤ 30%：2 分 / 30%–50%：1 分 / > 50%：0 分 |

**要点**：
- 有息负债 = "硬负债"，需刚性偿还本息
- 应付账款、预收账款 = "无息负债"，反而体现对上下游的议价能力
- **矛盾信号**：有息负债高但货币资金也高 → "存贷双高"，已在排雷项覆盖

##### A2.3 流动性安全（2 分）

| 指标 | 计算方式 | 评分标准 |
|------|---------|---------|
| 流动比率 | 流动资产 ÷ 流动负债 | 1.5–3.0：2 分 / 1.0–1.5：1 分 / < 1.0 或 > 5.0：0 分 |

**注意**：流动比率过高（> 5.0）说明资金使用效率低，并非越高越好。

#### A3. 资本效率（6 分）

##### A3.1 净资产收益率 ROE（3 分）

| 指标 | 评分标准 |
|------|---------|
| ROE（加权平均，近 3 年平均） | ≥ 15%：3 分 / 10%–15%：2 分 / 5%–10%：1 分 / < 5%：0 分 |

**杜邦分解深度分析**：
```
ROE = 净利润率 × 总资产周转率 × 权益乘数
```
- **高净利润率驱动**（创新药企）→ 优质模式 ✅
- **高周转率驱动**（普药/原料药）→ 效率模式 ⚠️
- **高杠杆驱动**（权益乘数高）→ 风险模式 ❌

##### A3.2 总资产周转率（1.5 分）

| 指标 | 评分标准 |
|------|---------|
| 总资产周转率 | ≥ 0.6 次：1.5 分 / 0.3–0.6 次：1 分 / < 0.3 次：0 分 |

##### A3.3 投入资本回报率 ROIC（1.5 分）

| 指标 | 计算方式 | 评分标准 |
|------|---------|---------|
| ROIC | NOPAT ÷ 投入资本 | ≥ 12%：1.5 分 / 8%–12%：1 分 / < 8%：0.5 分 / < 4%：0 分 |

> ROIC > WACC → 创造价值；ROIC < WACC → 毁灭价值。

### 维度二：利润表——盈利能力与利润质量（20 分）

> **核心思想**：利润表是企业的"成绩单"。但**利润可以"算"出来（权责发生制），现金很难"造"出来（收付实现制）**——所以利润表必须和现金流量表交叉验证。
>
> 重点看三个质量：**营收质量、利润质量、费用质量**。

#### B1. 营收质量（5 分）

##### B1.1 营收结构（2 分）

| 指标 | 评分标准 |
|------|---------|
| 主营业务收入 / 营业收入 | ≥ 90%：2 分 / 80%–90%：1 分 / < 80%：0.5 分 |

**深度检查**：
- 非经常性收入（政府补贴、资产处置、投资收益）占比是否过高
- 化药企业关注：制剂 vs 原料药 vs CMO/CDMO 收入结构
- 单一产品收入 > 50% → 产品集中度风险
- **排雷关联**：收入确认方法是否变更？"总额法"变"净额法"可能虚增营收规模（参考上海雅仕案例）

##### B1.2 营收现金含量——收现比（3 分）

| 指标 | 计算方式 | 评分标准 |
|------|---------|---------|
| 收现比 | 销售商品、提供劳务收到的现金 ÷ 营业收入 | ≥ 1.0：3 分 / 0.85–1.0：2 分 / 0.7–0.85：1 分 / < 0.7：0 分 |

**核心原则**：
> 收现比 ≥ 1.0 → 不仅当期收入变成了现金，还收回了以前的应收款 ✅  
> 收现比长期 < 0.7 → 大量赊销，收入质量堪忧 ❌  
> **排雷关联**：收入高增长但收现比持续下降 → 可能在虚增收入（参考创维数字案例：利润暴增 14 倍但经营现金流 -14.69 亿）

#### B2. 毛利率与费用率（8 分）

##### B2.1 毛利率水平与稳定性（3 分）

| 指标 | 评分标准（化学制药行业） |
|------|---------|
| 毛利率 | ≥ 60%：2 分 / 40%–60%：1.5 分 / 20%–40%：0.5 分 / < 20%：0 分 |
| 毛利率近 5 年波动 | 标准差 < 5%：1 分 / 5%–10%：0.5 分 / > 10%：0 分 |

**行业基准**：
- 创新药/特色制剂：60%–90%
- 品牌仿制药：40%–70%
- 原料药：20%–50%
- 大宗原料药：10%–30%

**排雷关联**：毛利率显著高于同行（差 20 个百分点以上）且无合理解释 → 可能有猫腻

##### B2.2 期间费用率（3 分）

| 指标 | 计算方式 | 评分标准 |
|------|---------|---------|
| 三费率 | （销售 + 管理 + 财务费用）÷ 营业收入 | ≤ 25%：3 分 / 25%–40%：2 分 / 40%–55%：1 分 / > 55%：0 分 |

**逐项拆解**：

| 费用项 | 化药行业关注点 |
|--------|-------------|
| 销售费用率 | 行业普遍 30%–50%，集采后应有所下降；"学术推广费"占比过高 → 商业贿赂风险 |
| 管理费用率 | 合理区间 5%–15%；股权激励摊销属一次性影响，可还原 |
| 财务费用率 | 负值 = 资金充裕（利息收入 > 支出）；正值且 > 5% → 关注有息负债 |

##### B2.3 研发费用率（2 分）

| 指标 | 评分标准 |
|------|---------|
| 研发费用 / 营业收入 | ≥ 10%：2 分 / 5%–10%：1.5 分 / 3%–5%：1 分 / < 3%：0 分 |

**深度检查**：
- 资本化比例 > 50% → 警惕利润调节（参考"研发资本化"造假手法）
- 研发人员数量占比 → 体现研发实力真实性
- 研发投入绝对值 → 小企业比率高但绝对值低，需结合规模判断

#### B3. 利润质量——"真钱"还是"纸面富贵"（7 分）

##### B3.1 净利率水平（2 分）

| 指标 | 评分标准 |
|------|---------|
| 净利率 | ≥ 15%：2 分 / 8%–15%：1.5 分 / 3%–8%：0.5 分 / < 3%：0 分 |

##### B3.2 扣非净利润占比（2 分）

| 指标 | 计算方式 | 评分标准 |
|------|---------|---------|
| 扣非净利润 / 归母净利润 | 扣非后 ÷ 归母 × 100% | ≥ 85%：2 分 / 70%–85%：1 分 / < 70%：0 分 |

**核心原则**：
> 长期依赖政府补贴、资产处置、投资收益的企业，利润质量较低。  
> 化药企业中，政府补贴（增值税返还、研发补贴）较常见，但不应成为利润主要来源。  
> **排雷关联**：扣非净利润与归母净利润差距极大 → 可能靠非经常性损益"撑门面"（参考升达林业案例：利润暴增 998% 但非经常性损益占比近 80%）

##### B3.3 净利润现金含量——净现比（3 分）

| 指标 | 计算方式 | 评分标准 |
|------|---------|---------|
| 净现比 | 经营活动现金流净额 ÷ 净利润 | ≥ 1.0：3 分 / 0.7–1.0：2 分 / 0.4–0.7：1 分 / < 0.4：0 分 |

**核心原则**：
> **"利润是'颜值'，现金流是'余额'——颜值可以化妆，余额骗不了人。"**  
> 净现比 ≥ 1.0 → 每 1 元利润对应至少 1 元经营现金流 ✅  
> 净现比长期 < 0.4 → 高度警惕利润造假或严重赊销 ❌（参考排雷第一招）

### 维度三：现金流量表——造血能力与资金健康（20 分）

> **核心思想**：现金流量表是企业的"血液循环报告"，是**"事关存亡的表"**。  
> **利润可以调节，现金很难造假。** 当利润表和现金流量表"打架"时——信现金流。

#### C1. 经营活动现金流——造血能力（8 分）

##### C1.1 经营现金流净额趋势（3 分）

| 指标 | 评分标准 |
|------|---------|
| 经营活动产生的现金流量净额 | 连续 5 年为正且逐年增长：3 分 / 连续 3 年为正：2 分 / 偶有为负但最近 2 年为正：1 分 / 最近年度为负：0 分 |

**核心原则**：
> **"经营现金流为正是底线。主业不赚钱的公司，不值得投资。"**

##### C1.2 收现比与付现比（2.5 分）

| 检查项 | 评分 |
|--------|------|
| 销售商品收到的现金 / 营业收入 ≥ 1.0 | 1 分 |
| 购买商品支付的现金 / 营业成本 ≤ 1.2 | 0.5 分 |
| 支付给职工的现金 / 营业收入在合理区间（化药 8%–20%） | 0.5 分 |
| 支付的各项税费与利润规模匹配 | 0.5 分 |

##### C1.3 自由现金流 FCF（2.5 分）

| 指标 | 计算方式 | 评分标准 |
|------|---------|---------|
| 自由现金流 | 经营现金流净额 - 资本性支出 | 连续 3 年为正：2.5 分 / 偶有为负：1.5 分 / 连续为负：0.5 分 |

**核心原则**：
> **"自由现金流是股东真正可以拿走的钱。没有自由现金流的企业，就像一个永远需要往里填钱的无底洞。"**

#### C2. 投资活动现金流——投资质量（6 分）

##### C2.1 资本支出方向（3 分）

| 检查项 | 评分 |
|--------|------|
| 购建固定资产支出 / 折旧摊销在 1.0–2.5 之间（合理扩张） | 1.5 分 / 过高(>3.0)或过低(<0.5)：0.5 分 |
| 投资方向聚焦主业（非大量投资非主业领域） | 1.5 分 / 大量非主业投资：0 分 |

**化药行业关注**：
- 产能扩建是否与在手订单/市场需求匹配
- 大额并购支出 → 关注并购标的质量和商誉风险
- 研发管线投入（临床试验等）属于合理投资方向

##### C2.2 投资回报评估（3 分）

| 指标 | 评分标准 |
|------|---------|
| 近 3 年新增投资的 ROI | 已投产项目回报率 > 10%：3 分 / 5%–10%：2 分 / < 5%：1 分 / 大量项目未达预期：0 分 |

#### C3. 筹资活动现金流——融资健康度（6 分）

##### C3.1 现金流肖像分类（3 分）

> 把三类现金流的正负组合起来，给企业画一张"肖像"。

| 经营 | 投资 | 筹资 | 肖像 | 评分 |
|------|------|------|------|------|
| + | - | - | 🐄 **奶牛型**：自己赚钱自己花，还分给股东 | 3 分 |
| + | + | - | 🐔 **老母鸡型**：主业赚钱 + 吃利息/回收投资 | 2.5 分 |
| + | - | + | 🐂 **蛮牛型**：借钱扩张（高速成长但风险较高） | 2 分 |
| + | + | + | 🦄 **妖精型**：什么都往里进钱（警惕融资动机） | 1 分 |
| - | + | + | 🦇 **蝙蝠型**：卖资产 + 借钱活着 | 0.5 分 |
| - | - | + | 🐛 **毛毛虫型**：借钱烧钱 | 0.5 分 |
| - | + | - | 🦉 **猫头鹰型**：卖资产还债 | 0 分 |
| - | - | - | 💀 **僵尸型**：什么都往外流钱 | 0 分 |

**最优模式**：奶牛型 🐄 → 成熟稳健企业的理想状态（参考贵州茅台、格力电器）  
**高成长可接受**：蛮牛型 🐂 → 但要看现金储备够不够（参考宁德时代有 4100 亿现金 vs 比亚迪经营现金流只有 28 亿）

##### C3.2 分红与融资平衡（3 分）

| 指标 | 计算方式 | 评分标准 |
|------|---------|---------|
| 分红率（近 3 年平均） | 现金分红 ÷ 归母净利润 | 30%–70%：2 分 / 10%–30%：1 分 / < 10% 或 > 90%：0.5 分 |
| 融资依赖度 | 近 3 年经营现金流 vs 股权 + 债权融资 | 经营现金流 > 融资总额：1 分 / 否则：0 分 |

**核心原则**：
> 持续稳定分红 → 现金流真实且充裕 ✅  
> 从不分红 + 频繁融资 → 高度警惕 ❌

## 附录 A：实操流程——七步法

> 融合《手把手教你读财报》"财报阅读七步法"与量化评分体系，形成完整的实操流程。

### 第一步：排雷筛选（5 分钟）

**打开年报，第一件事不是看利润，而是翻到"重要提示"部分。**

```
✅ 审计意见是不是"标准无保留意见"？ → 不是就直接排除
✅ 有没有 ST/*ST 标记？ → 有就直接排除
✅ 有没有重大诉讼、资金占用、实控人违规？ → 有就直接排除
✅ 业绩预告有没有"变脸"？ → 有就高度警惕
✅ 最近有没有换审计机构？ → 有就查清原因
```

**排雷口诀**：
> 审计非标直接跑，业绩变脸要警惕  
> 存贷双高藏猫腻，大股东借钱不还排  
> 宁可错过不踩雷，五千家公司不缺你

### 第二步：看"主要财务指标"速览（5 分钟）

只盯四个数：
1. **营业收入** → 在变大还是变小？
2. **归母净利润** → 在赚钱还是亏钱？
3. **扣非净利润** → 利润是"真赚"还是靠补贴？
4. **经营现金流净额** → 赚的是真金白银吗？

**快速判断矩阵**：

| 情况 | 结论 |
|------|------|
| 营收↑、利润↑、现金流↑ | ✅ 好公司信号 |
| 营收↑、利润↑、现金流↓ | ⚠️ 赚的可能是"纸面利润" |
| 营收↑、利润↓、现金流↓ | ⚠️ 成本失控或竞争加剧 |
| 营收↓、利润↓、现金流↓ | ❌ 出问题了 |

### 第三步：读资产负债表（10 分钟）

**"三步法"快速阅读**：

1. **看右边（30 秒）** → 资产负债率高不高？有息负债多不多？
2. **看左边（30 秒）** → 货币资金够不够？应收账款多不多？商誉大不大？
3. **找矛盾（2 分钟）** → 现金多但负债也多？在建工程长期不转固？

**重点关注"四大金刚"**：
- 货币资金：够不够、真不真
- 应收账款：多不多、老不老
- 存货：涨没涨、卖没卖
- 固定资产 + 在建工程：值不值、转没转

### 第四步：读利润表（10 分钟）

**重点看"三个质量"**：

1. **营收质量**：主营占比多高？收现比多少？
2. **利润质量**：扣非占比多高？净现比多少？
3. **费用质量**：三费率趋势是上还是下？研发投入够不够？

**核心技巧**：先读管理层讨论（文字），再看利润表（数字）——**如果说的和数字对不上，信数字，不信嘴。**

### 第五步：读现金流量表（10 分钟）——最重要！

**关注"一正两匹配"**：

1. **经营现金流为正**（造血能力）
2. **经营现金流与净利润匹配**（利润含金量 = 净现比）
3. **经营现金流与营收匹配**（收入含金量 = 收现比）

**画出现金流肖像**：把三类现金流正负组合，判断是奶牛型🐄、蛮牛型🐂还是僵尸型💀。

**看趋势变化**：
- 经营现金流**由负转正** → 重大利好 ✅✅
- 经营现金流**由正转负** → 重大利空 ❌❌

### 第六步：纵向 + 横向对比（15 分钟）

**纵向**：拉出近 5 年关键指标趋势表

| 指标 | Y-4 | Y-3 | Y-2 | Y-1 | 最新年 | 趋势 |
|------|-----|-----|-----|-----|--------|------|
| 营业收入 | | | | | | ↑/↓/→ |
| 扣非净利润 | | | | | | |
| 毛利率 | | | | | | |
| ROE | | | | | | |
| 经营现金流 | | | | | | |
| 资产负债率 | | | | | | |
| 研发费用率 | | | | | | |

## 附录 C：数据动态更新机制

> 每次运行评分时，必须确保数据为最新可得。

| 数据类型 | 数据来源 | 更新要求 |
|---------|---------|---------|
| 股价/市值 | 交易所实时行情 | 运行当日收盘价 |
| 财务数据 | 最新年报 + 最新季报 | 至少包含最新年报披露的完整数据 |
| 历史数据 | 近 5–10 年年报（上市不足 10 年按实际年限） | 纵向对比必备 |
| 估值指标 | 基于最新股价 + TTM 数据计算 | 每次运行重新计算 |
| 行业数据 | 公司公告、CDE/NMPA 官网、医保局目录 | 抓取至运行日最新状态 |
| 审计意见/公告 | 巨潮资讯网 | 以官方公告为准 |

**数据有效性检查**：
- 若最新财报发布日期超过 6 个月，标记为"数据滞后"
- 若某指标在 A 股非强制披露（如在手订单），该子项按满分的 60% 给予基准分，并标注"数据缺失"
- 若上市不足 5 年，历史稳定性指标按实际年限折算
