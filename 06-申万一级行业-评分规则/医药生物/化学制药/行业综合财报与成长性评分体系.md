# A股化学制药行业综合财报与成长性评分体系（H1–H9 v2.2）

**版本**：v2.2 动态数据版（基于实战反馈与数据可得性修正）  
**核心原则**：每次运行时，强制拉取并使用最新可得的公开数据（最新年报、最新季报、最近交易日行情），并严格按照标准作业程序（SOP）逐项执行。**针对A股数据披露口径差异，增设数据兜底与分析师覆盖豁免机制**，确保评分的公平性、时效性与可复现性。  
**适用范围**：A股化学制药企业（化学制剂、原料药，收入或毛利占比≥70%），含创新药、仿制药转型、原料药及CXO企业。  
**不适用**：生物制品、中药、医疗器械、医药商业。

## 一、数据动态更新机制（强制）

每次运行评分时，必须执行以下数据抓取与清洗步骤，确保所有输入均为最新。

| 数据类型 | 数据来源（优先级） | 更新频率要求 |
| :--- | :--- | :--- |
| 股价/市值 | 交易所实时行情（最近一个交易日收盘价） | 每次运行当日 |
| 财务数据（历史10年/上市以来） | Wind/CSMAR/同花顺（年报） | 至少包含截至最新年报披露日的完整可获取年限数据（若上市不足10年，以IPO招股书披露的完整3年+上市后所有年报替代，评分按年限折算） |
| 最新财报 | 最新年报 + 最新季报/中报（合并报表） | 若季报已披露，则采用季报；否则采用中报或年报 |
| 估值指标（PE/PB/PS/PCF/股息率） | 基于最新股价 + 最新财报TTM数据计算 | 每次运行重新计算 |
| 行业特有数据 | 公司公告、CDE/NMPA官网、FDA官网、医保局目录 | 抓取至运行日之前的最新状态 |
| 前瞻预测数据 | 内部研究员调研模型 + Wind一致预期（取最新一期） | 每次运行更新预测基数（基于最新季报调整） |
| 机构持仓 | 公募基金季报、北向资金每日数据 | 取最新披露的季度末持仓及近3月流向 |

**数据有效性检查与兜底条款（v2.2新增）**：
- **时效性检查**：若最新财报发布日期超过6个月（即已过下一季报披露时限），须标记为“数据滞后”，并强制等待最新季报或使用已披露的最新数据。
- **核心管线数据**：若仅有券商预测（D/E级），须在评分中明确标注并执行置信度惩罚。
- **数据可得性兜底（v2.2核心修正）**：若某指标（如“在手订单”）在A股现行财报披露准则中**非强制披露项**，导致该公司从未披露过该数据，则**该子项自动赋满分的60%作为基准分**，并在报告中标注“数据缺失，按基准分处理”，严禁直接给0分造成不公。

## 二、前置一票否决：硬红灯项（命中即淘汰，最终得分=0）

每次运行首先执行硬红灯排查，任何一项命中则直接淘汰，不再进行后续评分。

| # | 硬红灯标准 |
| :--- | :--- |
| 1 | 交易状态为ST、*ST、风险警示板、暂停上市风险 |
| 2 | 近3年任一年审计意见为否定或无法表示意见；年报披露前3个月内换所且无合理解释 |
| 3 | 公司或实控人近3年被认定财务造假；大股东资金占用>净资产5%且未清偿 |
| 4 | 核心产品发生重大安全性事件致召回/致死；被FDA/NMPA出具警告信且未整改 |
| 5 | 有息负债/EBITDA > 10（且无明确偿债计划）；或（货币资金+交易性金融资产）/最近4个季度研发费用 < 1.0，且无近期再融资计划（Biotech类） |
| 6 | 近10年（或上市以来）中超过3个会计年度营业收入同比下滑>30%（若下滑主要由集采导致，且最新财报营收已恢复至下滑前峰值80%以上，可豁免此条） |
| 7 | 连续3年经营现金流为负且连续2年营收下滑（若为创新药企且有大额在手现金可豁免） |
| 8 | 日均成交额 < 2000万元；或总市值 < 20亿元（创新药企可放宽至15亿元） |
| 9 | 核心管线III期临床失败且无后续重磅管线；或FDA/NMPA拒绝批准核心上市申请 |
| 10 | 收到FDA完整回应函(CRL)致上市受阻；或工厂收到FDA进口警示 |
| 11 | 美国《生物安全法案》直接列明禁止与该企业合作（CXO适用） |
| 12（v2.2修正）| 基于最新季报及调研，当年Q2-Q4营收合计将同比下滑>40% **且** 经营性现金流同步恶化>30%（若因集采出清末期一次性财务出清，但有新产品接替且现金流稳定，可酌情豁免，不触发红灯） |

## 五、估值熔断机制（K系数）

基于最新股价和近10年历史PE/PS分位计算。

| 估值条件（取PE与PS分位中较高者） | 熔断系数K | 创新药企豁免条件 / **v2.2仿创豁免** |
| :--- | :--- | :--- |
| **创新药企**：PS<5x 或 10年PE分位<10% | 1.00 | — |
| **创新药企**：PS 5~10x 或 PE分位10%~30% | 0.92 | — |
| **创新药企**：PS 10~15x 或 PE分位30%~70% | 0.85 | — |
| **创新药企**：PS>15x 或 PE分位>70% | 0.72 | 若公司核心管线处于NDA/III期且（货币资金+交易性金融资产）/最近4季度研发费用 ≥ 3年，则K下限锁定为0.85，不执行0.72及以下熔断 |
| **创新药企**：PS>20x 或 PE分位>90% | 0.50（强制清仓） | 同上，锁定0.85 |
| **仿制药/原料药企**：前瞻PE<12x且股息率>3.5% | 1.00 | — |
| **仿制药企**：PE 12~18x | 0.92 | — |
| **仿制药企**：PE>18x | 0.80 | **v2.2新增豁免**：若仿制药收入占比降至50%~70%且研发投入/营收>8%（仿创转型期），K系数可参照创新药企的PS阈值执行，不强制按PE>18x打八折 |
| **CXO**：前瞻PE<15x且在手订单增速>20% | 1.00 | — |
| **CXO**：PE 15~25x | 0.92 | — |
| **CXO**：PE>25x | 0.80 | — |
| **周期底部上浮**：若当前判定为“冰点/底部区”（E=1.30），且PS或PE分位<10%，K可上浮+0.07（上限1.00）。 |
