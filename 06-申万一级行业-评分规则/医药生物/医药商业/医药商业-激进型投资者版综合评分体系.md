# 📌 核心哲学（医药商业·激进型投资者版·A股修订版）

> **适用范围界定**：本体系专攻A股医药商业板块，核心为**医药零售（连锁药店）**与**医药流通（分销/批零一体）**。激进型投资者在此板块的核心逻辑不是防守收息，而是**押注行业剧变下的份额抢夺与模式颠覆**。

- **处方外流是最大红利，卡位者赢天下**：医院零差率与DRG/DIP控费倒逼处方外流，激进型不看重院边店的稳态租金，而**重仓抢占“双通道”与DTP特药药房资格、且与互联网医疗深度绑定的抢流先锋**，博弈千亿级处方外流的非线性增量。
- **集采重塑流通，剩者为王加极速集中**：两票制与国采常态化抹平多级分销利润，激进型不惧流通毛利下降，而**押注具备全国性/跨区域性物流网络、能承接原院外市场份额的流通巨头**，博弈小B出清后的市占率飙升。
- **加盟与下沉是降维打击，规模即正义**：直营模式在下沉市场面临人效与租金瓶颈，激进型偏好**“直营+加盟”双轮驱动、供应链极速赋能加盟商**的模式，用轻资产杠杆撬动下沉市场，开店加速度决定估值上限。
- **批零一体与CSO模式是估值跃升通道**：纯流通只配10x PE，纯零售面临线上冲击只配15x PE。但凡能证明**批零一体化协同（分销反哺零售）**或向药企提供**CSO（合同销售组织）服务**，即可从搬砖逻辑跃升为服务逻辑，享受估值重塑。
- **现金流是扩张的子弹，应收账款是生死线**：医药商业本质是垫资与资金周转的游戏。激进型容忍扩张期的高杠杆，但绝不容忍应收账款周转恶化，**能以极低资金成本撬动规模、且用占用上游资金扩张的企业才是真霸主**。

## 七、核心口径修正（医药商业·A股激进型特有）

### 7.1 处方外流质量的真伪鉴别
并非所有院边店都能承接外流。激进型只认两类：①**DTP/双通道特药药房**（高毛利、绝对刚需、护城河深）；②**接入门诊统筹的慢病药房**（高频复购）。普通医保药店仅视为流量入口，不给高溢价。

### 7.2 加盟模式的财务毒药与解药
激进型偏好加盟，但必须穿透财务：优质加盟是“强管控+供应链利润”（赚商品差价），劣质加盟是“卖招牌+收加盟费”（一锤子买卖且毁品牌）。若加盟店毛利率显著低于直营，视为向下游压货，属毒药。

### 7.3 批零一体化的协同测算
流通(B端)与零售(C端)结合的真正威力在于：流通拿院外配送权，零售做终端承接；零售敏感需求反哺流通向上游议价。若批零毛利率差 < 5pct且无供应链数据打通，视为伪协同。

### 7.4 O2O与B2C的降维打击防御
线上买药正在重演电商对实体的冲击。激进型要求企业必须有防御甚至反杀能力：O2O做到同城30分钟达且不亏损，或B2C依托私域慢病管理实现高复购。纯线下等客模式估值直接打7折。

## 十、交叉封顶与共振规则

1. **外流红利+DTP卡位双击**：若处方药增速>25%且DTP店数增速>30%，M2额外+5分。
2. **资金霸权+规模收割共振**：若CCC为负且集采配送市占率飙升，M3额外+4分。
3. **轻资产下沉+数字化反杀**：若加盟店增速>直营且O2O业务盈利，M4额外+4分。
4. **现金流恶化惩罚**：若连续2季度经营性现金流/净利润 < 0.5，总分×0.80。

## 十二、最终计分公式

模块合计分 = M1 + M2 + M3 + M4 + M5
执行交叉共振加成 → 调整后总分（≤100）
扣除黄灯分 → 扣分后总分
若现金流恶化，扣分后总分 × 0.80
政策周期修正 = 上述得分 × P (商业周期系数)
估值熔断 = 周期修正得分 × V (估值系数)
最终得分 = min(100, 熔断后得分)
