# 📌 核心哲学（医疗服务·激进型投资者版·A股修订版）

> **适用范围界定**：本体系专攻**C端消费医疗与民营专科医院**（如眼科、齿科、植发、中医、康复、辅助生殖、医美等），**剔除B端CXO/ICL**（其逻辑偏周期制造与海外订单，不适用本C端连锁估值框架）。

- **连锁复制的非线性爆发**：医疗服务本质是“手工作坊”，激进型不看重单家医院的稳态利润，而**押注标准化单店模型跑通后的异地复制加速度**。从1到10是线性增长，从10到100是指数级爆发，开店加速度即估值提升的斜率。
- **爬坡期是黄金击球区**：新院/新店从开业到盈亏平衡通常需1-3年。激进型不在稳态PE上买单，而**重仓处于亏损收窄、盈亏平衡点前夜的爬坡期门店**，博弈产能利用率提升带来的经营杠杆非线性释放。
- **脱钩医保，拥抱纯消费**：医保控费是长期达摩克利斯之剑。激进型只给“纯自费、强消费属性”赛道高估值（如屈光、种植牙高端线、植发、医美），医保收入占比>30%且受DRG/DIP严重挤压的标的直接视作周期股。
- **获客成本决定生死，流量闭环降维打击**：线下地推与买量成本飙升，激进型偏好具备“医生IP化+私域池+低频转高频”流量闭环的机构，销售费用率>30%的买量模式视为护城河缺失。
- **并购基金表外孵化，是扩张的核武器**：A股医疗服务受再融资与商誉限制，激进型极度偏好具备“产业并购基金体外孵化→盈利后并入上市公司”能力的平台，表外蓄水池是估值期权。

## 七、核心口径修正（医疗服务·A股激进型特有）

### 7.1 同店增长(SSSG)的量价拆解
医疗服务真正的健康增长是“量增”（就诊人次提升），而非单纯的“价增”（过度推销高价项目）。若SSSG>15%但客单价提升>10%，需警惕过度医疗与客户流失风险；若SSSG由初诊人次暴增驱动，给予双倍估值溢价。

### 7.2 门店生命周期与经营杠杆
- 培育期（1-2年）：折旧与摊销固定，销售费用前置，净利润为负。
- 爬坡期（2-3年）：产能利用率突破盈亏平衡点，收入增速远超成本增速，净利润率非线性跃升（从5%跃升至15%+）。**激进型最爱的击球区**。
- 成熟期（3年+）：增速放缓，贡献稳定现金流，支撑PE估值。

### 7.3 医生IP与平台赋能
过度依赖超级医生的机构无法连锁（医生出走即带走客户）。激进型偏好具备强大“中台赋能”能力（标准化术式、供应链集采、数字化营销体系）的公司，医生仅作为执行终端，离开平台即失效。

### 7.4 体外并购基金（表外蓄水池）
爱尔眼科模式的精髓。通过并购基金在体外开设/收购数百余家医院，待盈利后并入上市公司。激进型需计算**体外未注入院区数相当于当前体内院区数的比例**，比例越大，未来注入预期带来的期权价值越高。

## 十、交叉封顶与共振规则

1. **复制+爬坡双击**：若年度净增院区>20%且爬坡期院区占比50%左右，M2额外+5分。
2. **纯消费+低获客共振**：自费占比>80%且销售费用率<15%，M3额外+4分。
3. **表外期权注入催化**：若未来6个月有明确的体外成熟医院注入预期，M5额外+5分。
4. **同店萎缩惩罚**：若SSSG连续2季度<0（同店负增长），总分×0.80。

## 十二、最终计分公式

模块合计分 = M1 + M2 + M3 + M4 + M5
执行交叉共振加成 → 调整后总分（≤100）
扣除黄灯分 → 扣分后总分
若同店萎缩，扣分后总分 × 0.80
政策周期修正 = 上述得分 × P (行业生命周期系数)
估值熔断 = 周期修正得分 × V (估值系数)
最终得分 = min(100, 熔断后得分)

📌 **Top 3 激进爆点**：
1️⃣ **“体外并购基金+体内利润释放”永动机模式**：体外数百只基金储备超300家医院，构筑庞大估值期权
