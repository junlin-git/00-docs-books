# 📌 核心哲学（中药·保守型投资者版）

- **现金流是生命线，分红是安全绳**：中药行业普遍具有较好的经营性现金流，保守型要求经营性现金流/净利润 > 0.9，且连续5年以上稳定分红，股息率 > 3.5%。

- **独家品种 + 国家保密配方构成最强壁垒**：片仔癀、云南白药等拥有国家绝密/保密配方的企业，受集采冲击极小，具备长期提价能力和消费粘性。保守型优先选择核心品种为国家保密配方、竞争格局稳定的企业。

- **品牌OTC优于处方药**：品牌OTC（如华润三九、同仁堂）主要依靠院外市场，不受医保控费和集采降价的直接冲击，收入及利润稳定性远高于处方药占比高的企业。

- **集采是分水岭，独家品种抗风险**：第四批全国中成药联盟采购覆盖89种药品，但独家品种降幅一般小于竞争品种。保守型要求非独家品种收入占比 < 30%，避开集采高风险敞口。

- **老龄化是确定性慢变量**：人口老龄化对心脑血管、糖尿病、骨质疏松等慢病用药需求持续增长，保守型偏好核心品种治疗领域与老龄化高度相关的企业，享受长期稳定增长。

- **资产负债率必须低于行业安全线**：中药行业普遍负债率较低（龙头一般 < 40%）。保守型要求资产负债率 < 45%，有息负债/EBITDA < 2x，货币资金/有息负债 > 2x。

- **中药材成本控制能力决定利润稳定性**：集采后医院采购价格已锁定，若企业具备中药材战略储备或长期锁价协议，可在原材料价格波动时保持毛利率稳定。保守型要求中药材采购成本占比 < 35%且具备储备机制。

- **轻创新药管线，重现有品种确定性**：中药创新药研发周期长、失败率高，保守型不应为“在研管线”支付过高溢价。重点考核已上市品种的成长性、医保/基药覆盖稳定性，对研发费用率过高的企业给予折价。

- **渠道健康度是先行指标**：合同负债（预收账款）反映经销商打款意愿，应收账款周转天数反映回款效率。保守型要求合同负债稳定或增长，应收账款周转天数 < 90天。

- **基药目录调整是确定性放量催化剂**：新版基药目录预期2026年出台，独家品种新增入目录后将迎来结构性放量。保守型关注已在目录中或预期新增的稳定品种，避免博弈不确定性过大的品种。

- **股东回报进入新时代**：中药龙头分红率普遍在40%-60%，云南白药、白云山等股息率达4%-5%，构成重要的安全边际。保守型要求连续分红 ≥ 10年，分红率 ≥ 40%。

- **存量集中是不可逆趋势**：白云山、云南白药、华润三九前三家企业营收占30家样本企业总营收的63%。龙头强者恒强，保守型优先选择市占率持续提升的头部企业。

- **政策催化是方向性信号**：中药工业高质量发展实施方案（2026-2030）明确支持守正创新、数智化升级，但保守型不依赖政策博弈，只将其作为辅验证。

- **保守型偏好的是确定性长逻辑，不是高风险博弈**：以3-5年为持有周期，精选品牌护城河深厚、现金流强劲、高股息、低负债的龙头，以时间换空间。

**最终得分 = (模块合计分 - 黄灯扣分) × E × K**

- **E**：周期修正系数
- **K**：估值熔断系数

## 七、核心口径修正（中药行业特有·保守型强化版）

### 7.1 独家品种收入占比与护城河
**独家品种收入占比**：保守型要求 > 50%为健康，30%-50%为可接受，< 30%为高风险（集采冲击大）。国家绝密/保密配方等级额外加分。

### 7.2 合同负债与应收账款（真实动销信号）
**合同负债**反映经销商打款意愿，**应收账款周转天数**反映回款效率。保守型要求：合同负债同比不下降 > 10%，应收账款周转天数 < 90天。若合同负债连续2季度下滑且应收账款恶化，需警惕渠道压货风险。

### 7.3 经营性现金流/净利润（盈现比）
中药行业普遍现金流良好。保守型要求：近3年均值 > 0.9为健康，0.7-0.9为警戒，<0.7为危险。连续2年 < 0.7触发硬红灯。

### 7.4 集采风险敞口
**非独家品种收入占比**是集采风险的核心指标。保守型要求：非独家品种收入占比 < 30%。集采降价压力下，竞争品种毛利率可能压缩30-50个百分点，独家品种降幅一般<20%。

### 7.5 分红率与连续性
保守型核心关注：连续分红 ≥ 10年 + 分红率 ≥ 40% + 股息率 ≥ 3.5%。云南白药、白云山、华润三九等符合要求。

### 7.6 资产负债率与利息覆盖
保守型要求：资产负债率 < 45%，有息负债/EBITDA < 2x，货币资金/有息负债 > 2x。中药行业普遍满足此条件。

### 7.7 OTC渠道稳定性
OTC渠道（药店+电商）受医保控费影响小，收入稳定性强。保守型偏好：OTC收入占比 > 60%，且近年占比稳定或提升。

### 7.8 中药材成本控制
中药材价格波动影响毛利率。保守型要求：有中药材战略储备（覆盖6个月以上使用量）或长期锁价协议，且采购成本占比 < 35%。

### 7.9 研发投入保守处理
保守型认为高研发投入（>8%）存在较大不确定性，视为风险项。要求研发费用率 < 5%，且不以此给予估值溢价。

### 7.10 基药目录稳定性
已在基药目录中的独家品种，销售确定性更强。保守型关注：核心品种是否已在最新版基药目录中，或预期新增的确定性极高。

## 十、交叉封顶与共振规则

1. **高股息+低估值双击**：若股息率>4.5%且PE处于安全区，模块一额外+1.5分。

2. **独家护城河+低负债共振**：若独家品种收入占比>70%且资产负债率<30%，模块四额外+1分。

3. **稳定分红+经营性现金流充沛共振**：若连续分红≥10年且经营性现金流/净利润>1.0，模块二额外+1分。

4. **集采风险极低+渠道健康共振**：若非独家品种收入占比<20%且合同负债同比>10%，模块五额外+1分。

5. **OTC稳定性+基药覆盖共振**：若OTC收入占比>70%且核心品种在基药目录，模块七额外+1分。

6. **原材料成本控制优秀加分**：若具备完善的中药材战略储备且毛利率波动<2pct，模块八额外+1分。

7. **无效扩张惩罚**：若商誉/净资产>15%且并购标的业绩未达预期，模块六最终得分×0.85。

8. **盈利质量惩罚**：若连续2年经营性现金流/净利润<0.7，原始总分×0.85。

## 十五、⚠️ 关键风险提示（保守型必读）

- **中药行业并非完全无风险**：集采持续扩围、中药材价格波动、医保控费常态化，均可能影响企业利润。保守型必须通过严格筛选（独家品种、低负债、高股息）来对冲。

- **独家品种也可能被集采**：虽目前独家品种降幅较小，但未来政策存在不确定性。需持续跟踪集采目录变化，一旦核心品种被纳入且降幅超预期，需立即重新评估。

- **品牌OTC也面临消费降级风险**：经济下行周期中，消费者可能转向低价替代品或减少消费，需关注终端动销数据。

- **中药材价格长期中枢上移**：随着资源稀缺性和种植成本上升，中药材价格可能持续高位，对毛利率形成长期压制。

- **高股息不等于低风险**：部分企业股息率高但分红比例不可持续（如一次性特别分红），需考察分红来源是否为稳定经营现金流。

- **商誉减值风险**：部分中药企业通过并购扩张积累大量商誉，若被并购标的业绩不达预期，可能集中计提减值。

- **保守型应以3-5年为持有周期**，每半年重新评估核心指标（合同负债、应收账款、毛利率、分红稳定性），只要基本面未恶化，应坚持持有。

- **当以下信号出现时应重新评估**：核心独家品种被纳入集采且降幅超30%、合同负债连续4季度下滑、资产负债率突破50%、分红率降至30%以下。

- **切勿为“创新药管线”支付溢价**：保守型不参与研发不确定性博弈，应坚持估值安全边际（PE≤20x，股息率≥4%）。

- **分散配置是保守型的重要原则**：即使最优质的中药龙头也应控制在15%以内，行业总仓位不超过20%，避免单一黑天鹅事件冲击。
