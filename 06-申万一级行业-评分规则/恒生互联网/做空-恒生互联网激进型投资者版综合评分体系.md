# 📌 核心哲学（恒生互联网·激进型做空版）

**高估值泡沫+盈利预期下修是做空的弹性基础**：恒生互联网指数自2025年10月以来最大回调近35%，但估值仍不便宜。智谱上市不到半年股价累计涨幅超20倍、市值达1万亿港元，约相当于阿里巴巴的将近一半，接近美团的两倍。大型互联网企业AI基础建设尚处于投入阶段，同时受到传统广告和电商业务的拖累，而资本市场在大模型赛道进入“Token通胀”与商业化加速阶段后，对纯AI标的给予“业务纯粹性溢价”。这种极致分化酝酿着估值收敛风险。

**AI商业化不及预期是估值下修的核心驱动力**：恒生互联网科技业指数AI含量达95%，但AI从算力投入到实质性收入产出之间仍存在巨大鸿沟。2026年一季度，阿里Non-GAAP净利润下降43%，经营现金流同比下降超50%。大型互联网企业的AI基础建设尚处于投入阶段，同时受到传统广告和电商业务的拖累。

**南向资金并非无限子弹，趋势逆转风险巨大**：南向资金5月一度净流出，为2023年6月以来首次。南向资金近期虽持续净买入但出现“快进快出”特征，一旦趋势逆转转为持续净流出，对板块冲击同样巨大。

**平台经济监管政策仍在持续收紧**：国家市场监督管理总局发布《互联网平台反垄断合规指引》，要求平台经营者遵循针对性、全面性、穿透性和持续性四大原则，不得利用数据和算法、技术优势从事垄断行为。

**龙头回购无法对冲基本面下行**：腾讯2026年累计回购金额超百亿港元，但在盈利预期持续下修和南向资金流出面前，回购提供的支撑有限。

**降本增效的红利正在消退，盈利拐点迟迟未至**：互联网板块2025年整体收入增长稳健，但利润因AI投入加大而短期承压。机构预期2026年指数整体EPS同比增速约5.9%，较此前大幅下修。

**高集中度是双刃剑——做空同样享受高弹性**：前两大成分股权重上限15%，前十大权重占比近90%。集中度高意味着下跌时弹性同样巨大——一旦触发系统性下跌，指数跌幅将远超宽基指数。

**激进型做空博弈的是“高估值泡沫破裂+AI商业化不及预期+南向资金逆转+政策持续收紧”的四重共振**，以1-6个月为持有周期，在财报季盈利miss和估值回归中获利。

# 七、核心口径修正（恒生互联网行业特有·激进型做空放大版）

### 7.1 前瞻PE（Forward PE）——做空核心指标
互联网板块周期性波动剧烈。**做空判断标准**：前瞻PE > 25倍 + 前瞻PE/历史均值 > 1.5 + 盈利预期拐点确认下修 = 最佳做空点。

### 7.2 AI泡沫化评估（激进型做空核心弹性指标）
恒生互联网指数AI含量达95%，但**AI贡献收入 = 云业务收入 + AI应用服务收入 + 其他AI相关收入**。核心判断：**云业务增速 < 20% + AI相关收入占比 < 5% = AI泡沫即将破裂**。智谱上市不到半年股价累计涨幅超20倍，市值达1万亿港元，而同样布局大模型的阿里、腾讯年内股价分别跌27%、27%——这种极致分化酝酿着估值收敛风险。

### 7.3 南向资金流向逆转（做空核心催化剂）
南向资金成交额已占港股主板46%，是港股边际定价的核心力量。**做空核心监控**：南向资金5月净流出为2023年6月以来首次；单周内净买入转向净卖出的切换幅度可达570亿港元。**南向资金持续净流出 + 指数下跌，形成做空的右侧确认信号**。

### 7.4 回购规模与进度——做空需警惕的护盘力量
龙头持续回购是管理层对股价低估的判断。**做空核心追踪**：腾讯2026年累计回购超百亿港元。回购规模扩大是做空的重要风险点，需在回购力度减弱时加大做空仓位。

### 7.5 盈利拐点迟迟未至
2025年Q4国内主要互联网公司Non-GAAP净利润同比-35.6%，主因AI投入加大。**做空判断**：当AI投入持续加大而收入端未见改善——云业务、广告、电商三大引擎同步疲软时，盈利拐点确认失败，是做空的强力催化剂。机构预期2026年指数整体EPS同比增速仅5.9%，一旦实际数据低于预期，将触发估值进一步下修。

### 7.6 资本开支与自由现金流恶化
AI投入高峰期，自由现金流持续承压。**做空核心追踪**：资本开支/经营性现金流趋势是否连续两季度上升。当巨头宣布资本开支计划扩大时，是自由现金流恶化的前瞻信号。

### 7.7 做空比例与极端情绪指标——做空的核心战场
港股做空机制成熟。**做空核心监控**：
- 大市沽空比例：7月17日半日抛空306亿元，占成交17.43%
- 港股卖空成交比例超20%，做空势头盛极而衰
- 个股沽空比率：美团22.12%、快手20.42%
- 腾讯沽空比率15.5%，沽空金额13.9亿
- 阿里巴巴沽空比率17%-24%，沽空金额13-44亿
- 小米集团沽空比率38.3%，沽空金额23.3亿

**做空比例 > 15% 且持续上升 + 南向资金流出 + 指数破位下跌 = 做空的最佳右侧确认信号**。

### 7.8 平台经济监管政策收紧
国家市场监管总局发布《互联网平台反垄断合规指引》。**做空核心关注**：监管政策从“支持规范并重”转向更严格的执行层面，平台企业金融业务进入常态化监管。

### 7.9 海外业务与汇率风险
互联网龙头海外业务收入占比较高，人民币兑美元汇率波动将影响财报折算利润。**做空核心关注**：美元指数回落可能改善港股流动性，是做空的风险点。

### 7.10 新纳入指数成分股的泡沫化风险
智谱、MiniMax于2026年6月纳入恒生科技指数。智谱上市不到半年股价累计涨幅超20倍，市值达1万亿港元。**做空应重点关注这些高估值、低流动性、基本面尚未验证的标的**。
