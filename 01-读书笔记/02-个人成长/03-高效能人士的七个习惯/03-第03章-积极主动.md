# 📚 《高效能人士的七个习惯》第03章 · 积极主动
> 个人愿景的原则 · 你是创造者，你是选择者

---

## 📌 章节基本信息

- **章节定位**：七个习惯之首，属于"**个人领域成功**"（从依赖到独立）的第一个习惯
- **英文原名**：Be Proactive
- **核心命题**：在刺激与回应之间，人类拥有选择的自由。积极主动，就是正视这一自由，并为自己的选择负责
- **作者**：史蒂芬·柯维（Stephen R. Covey）
- **思想源头**：维克多·弗兰克尔（Victor Frankl）《活出生命的意义》——"人所拥有的任何东西，都可以被剥夺，唯独人性最后的自由，也就是在任何境遇中选择一己态度和生活方式的自由，不能被剥夺。"

> 💡 **本章在全书中的位置**：习惯一是"个人愿景的原则"，它与习惯二"以终为始"、习惯三"要事第一"共同构成**独立性**的基石。没有积极主动，后面的所有习惯都无从谈起。

## 🧠 一、开篇定调：人类终极的自由

柯维引用弗兰克尔在纳粹集中营中的亲历：即使在那种极端恶劣、完全剥夺人身自由的环境下，人依然拥有"**人类终极的自由**"——**选择自己态度的自由**。

弗兰克尔观察到，集中营里大多数人经历了"愤怒→恐惧→崩溃→被动接受"的心路历程，但也有一部分人"倔强地活着，甚至会每天用玻璃片刮干净胡子，优雅高贵地面对着无情的岁月"。他深受感染，决定选择积极主动的态度对待生活，做力所能及的事，甚至组织狱友唱歌，共同面对生死考验。

> 🔥 **本章核心观点**：**积极主动不仅指行事的态度，还意味着人一定要对自己的人生负责。** 人类应该有营造有利的外在环境的积极性和责任感。我们的行为取决于**自身的抉择，而不是外在的环境**。

## ⚖️ 二、何为积极主动？——思维、语言、行为的统一

柯维指出，积极主动是一个完整的体系，包含三个相互贯通的层面：**思维、语言、行为**。

### 消极被动 vs 积极主动

| 维度 | 消极被动（Reactive） | 积极主动（Proactive） |
|------|---------------------|----------------------|
| **核心信念** | 刺激直接决定回应（S→R） | 刺激与回应之间有选择的自由（S→自由空间→R） |
| **驱动力** | 受环境、情绪、外界条件支配 | 依据自身的价值观与原则做出回应 |
| **语言模式** | "我没办法""只能这样""都是他害的" | "我选择""我负责""让我们想想办法" |
| **责任观** | 把责任推给外界（环境、他人、命运） | 对自己的选择和行为负责 |
| **关注焦点** | 聚焦于"关注圈"（无法控制的事） | 聚焦于"影响圈"（可以控制的事） |
| **能量状态** | 被动应付，消耗能量，怨天尤人 | 主动创造，产出能量，影响圈扩大 |
| **行为特征** | 允许外部刺激决定回应 | 巧妙运用刺激与回应之间的空间，依价值观自由选择 |

### 人类的四种天赋——选择的"武器库"

是什么让我们能在刺激与回应之间拥有"选择"的余地？柯维指出，人类拥有其他生物不具备的四种天赋，它们构成了我们在刺激与回应之间的"**过滤器**"：

| 天赋 | 英文 | 含义 | 在生活中的体现 |
|------|------|------|--------------|
| 🧠 **自我意识** | Self-Awareness | 跳出自己观察自己的能力 | "我正在生气" vs 只是生气——能从愤怒中抽离出一个冷静的自己 |
| 🌟 **想象力** | Imagination | 超越现实，在头脑中创造的能力 | 设想未来的自己、愿景和目标；弗兰克尔设想获释后站在讲台讲述教训 |
| 🧭 **良知** | Conscience | 明辨是非，判断对错的道德能力 | 内心深处的"对"与"错"，作为行事的指南针 |
| 💪 **独立意志** | Independent Will | 基于自我意识，不受外力影响自行决定的能力 | 即使害怕也选择去做正确的事 |

> 💡 **核心逻辑**：**消极被动的人，放弃了这四种天赋的使用，让外界（刺激）直接指挥自己（回应）。积极主动的人，则在每一次刺激来临时，调用这四种天赋，做出有意识的选择。**
>
> 哪怕你在接受刺激的那一刻，停下零点几秒，去运用这四种天赋中的哪怕一种，你的回应就会与基于本能的答复有着云泥之别。

### 积极主动的经典模型

```text
                  刺激（Stimulus）
                       ↓
┌──────────────────────────────────────────┐
│       选择的自由空间（Space to Choose）  │
│ ┌────────────────────────────┐           │
│ │ 自我意识 / 想象力 / 良知    │          │
│ │ 独立意志 → 依价值观做选择   │         │
│ └────────────────────────────┘           │
└──────────────────────────────────────────┘
                       ↓
                  回应（Response）
```

> 柯维本人曾因交通堵塞面临误机，他运用了这一模型：承认"我仍然有选择的余地"→选择主动干预而非被动等待→通过行动为赶上飞机创造机会。最终他赶上了飞机。

## 🗺️ 三、关注圈与影响圈：你的精力花在了哪里？

这是本章最著名的模型，也是判断一个人是否积极主动的"试金石"。

### 概念定义

- **关注圈（Circle of Concern）**：你关心的所有事物。包括健康、工作、子女、薪资、世界局势、他人的评价、天气等。
- **影响圈（Circle of Influence）**：在关注圈内，那些**你可以直接控制或影响**的事物。比如：自己的态度、行为、说的话、时间安排。

### 两种人的思维焦点与能量变化

| 类型 | 焦点 | 结果 | 能量变化 |
|------|------|------|---------|
| **积极主动的人** | 专注于 **影响圈** | 专心做自己力所能及的事，影响圈**不断扩大** | 能量增加，创造现实，"积极能量扩大了影响圈" |
| **消极被动的人** | 紧盯 **关注圈** | 紧盯他人弱点、环境问题及超出个人能力范围的事，影响圈**不断缩小** | 能量消耗，怨天尤人，"积极能量缩水了影响圈" |

### 模型图解

```text
┌──────────────────────────────────────────┐
│  关注圈（Circle of Concern）             │
│ ┌────────────────────────────┐           │
│ │ 影响圈（Circle of Influence）│         │
│ │                              │         │
│ │  自己的态度、行为、选择       │        │
│ │                              │         │
│ └────────────────────────────┘           │
│  天气 / 他人评价 / 市场环境              │
└──────────────────────────────────────────┘
```

> ⚠️ **柯维的警告**：**积极主动的人专注于"影响圈"，他们专心做自己力所能及的事，他们的能量是积极的，能够使影响圈不断扩大。消极被动的人则全神贯注于"关注圈"，紧盯他人弱点、环境问题以及超出个人能力范围的事情不放，结果越来越怨天尤人，并不断为自己的消极行为寻找借口。错误的焦点产生了消极能量，再加上对力所能及之事的忽略，就造成了影响圈日益缩小。**

### 一个被忽视的细节：影响圈 ≠ 永远小于关注圈

柯维特别指出：**在某些情况下，影响圈可能大于关注圈**。这反映出此人自私浅薄，也是另一种形式的受制于人。积极主动的人虽然更看重自己的影响力，但也有一个关注圈，只不过他们的关注圈往往不小于影响圈，这样才能有效发挥影响力。

### 实践案例

- **房价高企**：我们不能改变房价，但我们可以在提升本职工作素养的同时学习其它技能，利用副业增加收入。
- **人际关系**：我们不能改变家人/老板/客户的性格，但我们可以学习沟通技巧，提高有效沟通。
- **核心方法**：当我们想改变别人，或对别人有期待时，**先从自己开始**，改变缺失不良的行为、习惯，成为理想的自己，然后再去影响周围的人。逐渐扩大自己的影响圈。

## 🔍 四、三类问题：你能做的只有一件事

根据影响圈，柯维将生活中的问题分为**三类**：

| 问题类型 | 定义 | 正确应对方式 | 错误应对方式 |
|---------|------|------------|------------|
| 🔴 **可直接控制的问题** | 与自身行为有关 | 通过**改变习惯**来解决（习惯一、二、三） | 抱怨、拖延、推卸责任 |
| 🟡 **可间接控制的问题** | 与他人行为有关 | 通过**改进施加影响的方法**来解决（习惯四、五、六：双赢思维、知彼解己、统合综效） | 命令、指责、试图直接控制他人 |
| ⚫ **无法控制的问题** | 已成过去或客观环境使然 | **以平和的态度接纳**，或转换视角 | 焦虑、愤怒、内耗 |

> **"我们应该把注意力集中在我们能控制的事情上，而不是为那些我们无法控制的事情烦恼。"**

埃莉诺·罗斯福曾说：**"除非你愿意，否则没人能伤害你。"** 所有积极主动的人都深谙其道。

## 🗣️ 五、语言的转变：听其言，观其人

一个人的语言，直接反映了他属于"积极主动"还是"消极被动"。**语言是思维的外化，改变语言，就是在重塑思维。**

### 消极被动的语言（语言在推卸责任）

| 消极语言 | 背后的潜台词 |
|---------|-------------|
| "我已无能为力" / "我没办法" | 放弃选择，把处境当作借口 |
| "我就是这样/我天性如此" | 放弃选择，把性格当作借口 |
| "他把我气疯了" | 把自己的情绪归咎于他人 |
| "他们不会答应的" | 预设失败，放弃尝试 |
| "我只能这样做" / "我不得不……" | 放弃主动性，被迫接受 |
| "如果……就好了" / "要是……就好了" | 把希望寄托在外部条件上 |

### 积极主动的语言（语言在承担责任）

| 积极语言 | 背后的潜台词 |
|---------|-------------|
| "试试看有没有其他可能性" | 承认自己有选择的自由 |
| "我可以选择不同的作风" | 承认自己有选择的自由 |
| "我可以控制自己的情绪" | 对情绪负责 |
| "我可以想出有效的表达方式" | 聚焦于解决 |
| "我能选择恰当的回应" | 主动发起行动 |
| "我要……" | 主动发起行动 |

> 💡 **柯维的忠告**：**如果你真的想改变，先改变你的语言。** 通过语言监督自己的思维模式，让自己不断朝积极主动的人生成长。如果你察觉到自己的回应是消极被动的，要反思自己是不是处于消极被动的状态而不自知。

## 🤝 六、"做出承诺，信守承诺"——影响圈的核心行动

柯维指出，**积极主动最具体的表现，就是"做出承诺，并信守承诺"**。

### 为什么承诺如此重要？

- **承诺**：是你为自己设定的目标（习惯二），是你对影响圈的主动声明。
- **信守承诺**：是你对自我的"交付"。**每一次兑现承诺，都是在向自己证明"我是一个可靠、有能力的人"**。
- **信任的根基**：对他人的承诺，是建立互赖关系（习惯四、五、六）的基础。
- **扩大影响圈**：通过信守承诺，你逐渐成为"转型人"（Transition Person）——即能够改变周围环境氛围的人。

### 如何践行？

> **"先从一件小事做起。承诺一件你力所能及的事，然后去完成它。哪怕只是早起10分钟、每天读5页书。通过信守这些微小的承诺，你会慢慢地重建对自己能力的信心，你的影响圈会随之扩大。"**

### 主动积极者的三种特质

1. **依据价值观作出回应**（而非依据情绪或环境）
2. **对自己的行为负责**
3. **把焦点放在"影响圈"**

## 🌱 七、失败、痛苦与积极主动

### 伤害我们的并非痛苦本身

柯维区分了两种伤害：

| 伤害类型 | 描述 | 影响 |
|---------|------|------|
| ⚡ **物理伤害** | 外界发生的客观事件（如投资失败、被辞退） | 产生初期痛苦 |
| 😤 **情感伤害** | 我们对事件的回应和态度（如一直耿耿于怀、怨天尤人） | **二次伤害，往往比第一次伤害更持久、更致命** |

> "**伤害我们的并非悲惨遭遇本身，而是我们对于悲惨遭遇的回应。**" 尽管这些事的确会让人身心受创或者经济受损，但是品德和本质完全可以不受影响。事实上，越痛苦的经历越能磨练意志、开发潜能，提升自主应对困境的能力，甚至还可能感召他人争取同样的自由。

### 错误与改正

> **"对待错误的积极态度应是马上承认，改正并从中吸取教训，这样才能真正反败为胜。"**

- 犯了错误，不要狡辩，不要推脱。
- 承认它，改正它，从中学习——**错误是学习的机会**。
- **"因为一个被错误影响的'关注圈'（后悔、内疚），如果持续消耗你的精力，会让你失去'影响圈'内的主动性。"**

### 爱与积极主动

柯维特别提到：**积极主动的人以实际行动来表现爱**。就像母亲忍受痛苦把新生命带至人世，爱是牺牲奉献，不求回报。又好像父母爱护子女，无微不至——**爱必须通过行动来实现，爱的感觉由此而生**。这再次印证：积极主动不仅是态度，更是**负责任的行动**。

## 🏁 八、总结：你是司机，不是乘客

### 本章核心框架回顾

| 核心概念 | 定义/比喻 | 关键启示 |
|---------|----------|---------|
| ⚖️ **刺激与回应之间** | 人类拥有选择的自由（S→自由空间→R） | 我们是自己人生的"创造者"，而非"产物" |
| 🧠 **四种天赋** | 自我意识、想象力、良知、独立意志 | 这是"选择自由"的武器库，构成人类的"过滤器" |
| 🗣️ **语言的转变** | 从"我没办法"到"我可以选择" | 思维、语言、行为三者统一；语言是改变思维的起点 |
| 🗺️ **关注圈 vs 影响圈** | 关注圈是你关心的；影响圈是你能控制的 | **聚焦影响圈**，能量增加，影响圈扩大；紧盯关注圈，能量消耗，影响圈缩小 |
| 🔍 **三类问题** | 可直接控制、可间接控制、无法控制 | 前两类用行动解决（习惯一至六），最后一类用平和接纳 |
| 🤝 **承诺与信守承诺** | 影响圈的扩张方式；成为"转型人" | 先在小事上对自己守信；每一次兑现都在扩大影响圈 |
| 💔 **痛苦与回应** | 伤害我们的不是遭遇，而是对遭遇的回应 | 把错误当作学习的机会；爱通过行动实现 |

### 本章的金句

> **"在最恶劣的环境中，弗兰克尔运用人类独有的自我意识，发掘了人性最根本的原则，即在刺激与回应之间，人有选择的自由。"**

> **"积极主动不仅指行事的态度，还意味着人一定要对自己的人生负责。"**

> **"我们无法控制身上发生的每一件事，但是我们可以控制自己的反应。"**

> **"看一个人的时间和精力集中于哪些事物，也能大致判断他是否积极主动。"**

> **"积极主动的人专注于'影响圈'，他们专心做自己力所能及的事，他们的能量是积极的，能够使影响圈不断扩大。"**

> **"做出承诺，信守承诺，是培养高效能习惯的根本力量。"**

> **"伤害我们的并非悲惨遭遇本身，而是我们对于悲惨遭遇的回应。"**

> **"除非你愿意，否则没人能伤害你。"** ——埃莉诺·罗斯福

> **"我已无能为力" 其实是 "我，不想改变" 的借口。**

### 本章的终极心法

**从"受害者"到"创造者"，只有一念之隔。**

- **消极被动（受害者心态）**：我是环境的产物。我的情绪是别人造成的。我没办法。我把每个外界反馈都当真，别人以礼相待我就笑脸相迎，反之则摆出自卫姿态，心情好坏取决于他人言行。
- **积极主动（创造者心态）**：我是我自己选择的结果。我的情绪是我选的。让我想想办法。我不把自己的行为归咎于环境、外界条件或他人的影响。

**"积极主动"不是一句口号，而是一个决定——从今天起，把所有的精力，从你无法控制的"关注圈"，转移到你可以掌控的"影响圈"。**

> 📖 **延伸思考**：读完这一章，不妨问自己三个问题——
> 1. **今天遇到的一个挑战，我是在"关注圈"里焦虑，还是在"影响圈"里行动？** ——我能不能做一个行动者，而不是一个评论家？
> 2. **仔细听自己说话，我今天的语言偏向于"积极主动"还是"消极被动"？** ——我能不能试着把"我没办法"改成"让我想想"？
> 3. **我最近一次"信守承诺"是什么时候？** ——我能给自己设定一个怎样的微小承诺，并坚决在24小时内完成它？

**这三个问题的答案，就是你在第三章收获的成长起点。** 🚀🧠✨
