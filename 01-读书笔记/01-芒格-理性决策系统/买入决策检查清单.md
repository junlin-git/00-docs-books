# 买入决策检查清单（2026年A股适配版·完整版）

## 一、检查维度清单（10维度）

| 序号 | 检查维度 | 核心问题（请自问） | 您的事实依据/数据 | 您的结论（✔/✘/？） | 备注 |
| :---: | :--- | :--- | :--- | :---: | :--- |
| **1** | **能力圈** | **我能用3句话讲清楚这家公司/指数怎么赚钱的吗？** <br>① 它卖什么产品/服务？② 客户是谁？为什么客户选它不选别人？③ 为什么它能持续赚钱（护城河是什么）？<br>**如果讲不清楚，坚决不买。** | | | 这是最基础也是最重要的防线。讲不清楚=不懂=不买。 |
| **2** | **概率与赔率（不对称风险）** | **我看对的概率大概是多少？** （请基于事实估算，勿凭感觉）<br>对了能赚多少？**错了会亏多少？**（2026年退市风险加大，下行亏损可能不是-20%，而是-100%）<br>考虑极端下行风险后，期望值是否仍然为正？<br>公式参考：期望值 = 胜率 × 盈利幅度 - 败率 × 亏损幅度（亏损幅度按最坏情况估算） | | | 如果下行亏损是-100%（退市），即使胜率很高，期望值也可能为负。务必算清这笔账。 |
| **3** | **机会成本** | **如果我现在空仓，我还会买它吗？** <br>全市场横向对比，有没有性价比更高的替代标的？<br>（当前A股整体估值极高，空仓或持有国债逆回购/货基也是可选策略） | | | 买入任何标的，都在放弃其他机会。不要因为“手里有闲钱”而降低选股标准。 |
| **4** | **二阶思维（博弈对手）** | **现在我买入，后面谁会以更高的价格接盘？** <br>（注意：当前量化交易占比30%-40%，对手盘可能是程序化交易，它们的买卖逻辑与散户完全不同）<br>如果市场上大家都看好并蜂拥买入，会发生什么连锁反应？（过度拥挤→估值泡沫→量化反噬→踩踏下跌） | | | 一阶思维想“这公司好所以我要买”；二阶思维想“如果大家都认为它好并买入了，然后会怎样”。 |
| **5** | **估值安全垫（行业比较视角）** | **当前PE/PB在同行业中处于什么水平？** （勿只看历史分位，当前万得全A历史分位已极高，参考意义减弱）<br>盈利增速能否支撑当前估值？（参考PEG指标，PEG>2需高度警惕）<br>如果估值继续下跌30%，我能否扛得住且**敢加仓**？ | | | **若跌30%源于业绩变脸（而非情绪杀跌），此条不构成加仓理由，反而可能是卖出信号。** 加仓的核心条件是“逻辑未变、估值变便宜”，而非“跌多了就补”。 |
| **6** | **财务合规与退市红线（2026重点）** | **审计意见**是否为标准无保留？（非标即危险，可能直接*ST）<br>**是否触及组合类财务退市指标？** <br>· 主板：**净利润（含扣非孰低）为负** 且 营收<3亿元<br>· 创业板/科创板：**净利润（含扣非孰低）为负** 且 营收<1亿元<br>· 北交所：**净利润（含扣非孰低）为负** 且 营收<5000万元<br>净资产是否为正？是否被证监会立案调查？<br>是否存在其他规范类退市风险（如资金占用、重大信息披露违规）？ | | | **此维度若“不通过”（✘），一票否决，立即放弃。** <br>2026年退市力度大幅加强，踩中退市红线可能导致本金永久性损失。 |
| **7** | **资金结构与筹码博弈** | **近期有无大股东/高管减持？** （尤其是大规模、清仓式减持）<br>**北向资金**近期流向如何？（持续流入/流出/震荡）<br>**ETF份额**是净流入还是流出？（反映被动资金的配置方向）<br>量化基金持仓是否过度拥挤？（可参考融资余额是否处于历史高位、龙虎榜量化席位是否频繁净卖出） | | | 资金面信息可从东方财富、同花顺、Wind等数据终端获取。需注意：资金流向是滞后指标，应结合基本面一起看，不可单一依赖。 |
| **8** | **情绪检查（行为金融）** | **我买它是因为“怕错过”（FOMO）吗？** <br>是因为“大家都买”才跟风吗？<br>是因为最近涨得好、后悔没早买、现在想追吗？<br>**如果是，先退出，冷静24小时再决定。** | | | 这是最后一道心理防线。大多数亏损都源于情绪化交易。24小时冷静期能过滤掉大部分冲动买入。 |
| **9** | **政策敏感性（新增）** | **该标的/行业是否契合2026年国家战略方向？** <br>（如：新质生产力、人工智能、半导体国产替代、新能源高质量发展、生物制造、低空经济等）<br>**是否存在政策打压风险？** <br>（如：反垄断、医药集采扩大、教培类监管、地方政府债务管控等） | | | 2026年A股政策市特征显著。站在政策顺风的一边，胜率更高；逆风的一边，即使基本面好也可能持续被杀估值。 |
| **10** | **流动性风险（新增）** | **该标的日均成交额是否足够大？** <br>**分级参考标准**：<br>· 微盘股（市值<50亿）：建议日均成交额 **>3000万元**<br>· 中大盘股（市值≥50亿）：建议日均成交额 **>5000万元**<br>· 若日均成交额 **<1000万元**：流动性极度枯竭，直接一票否决<br>**量化主导下，流动性差的个股是否容易被“瞬间拉涨或砸盘”导致无法按合理价格止损？** | | | **若流动性严重不足（日均<1000万），一票否决。** <br>若逻辑极强且日均>3000万（微盘股）或>5000万（中大盘股），可接受，但需设置更宽的止损容忍度（如-20%而非-10%），以防范闪崩时无法及时卖出的风险。<br>**指数ETF投资可豁免本维度检查。** |
