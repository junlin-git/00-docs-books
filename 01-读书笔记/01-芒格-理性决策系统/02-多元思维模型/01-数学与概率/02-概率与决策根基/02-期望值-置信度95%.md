# 🧠 多元思维模型 · 期望值

> **“不是问‘我赢了吗？’，而是问‘在10万次选择中，我平均赢多少？’”**

**期望值是你对“长期结果”的量化预判——它不告诉你这一次会发生什么，但它告诉你：只要坚持做正期望值的事，时间一定会站在你这边。**

🎯 **记住这句咒语**：“单次看运气，长期看概率。期望值为正，坚持就能赢。”


## 一、一句话讲清楚

**期望值**（Expected Value，简称EV），是概率论中最重要的决策工具之一。它指的是：**在某个随机事件中，每个可能结果乘以该结果发生的概率，然后全部相加，得到的“长期平均值”。**

**公式**：**EV = Σ（结果 × 概率）**

**大白话翻译**：
> 你在一个赌局中，60%概率赢100元，40%概率输100元。
>
> 期望值 = 100 × 60% + (-100) × 40% = 60 - 40 = **20元**
>
> 意思是：**长期来看，你每玩一次，平均赚20元。** 虽然你有可能亏100元，但只要玩得足够多，你一定会逼近“每局赚20元”这个结果。

**⚠️ 重要澄清**：
- 期望值**不是**说“我一定能赚到那个数”——单次结果可能远高于或远低于期望值。
- 期望值**不是**说“每次都是平均值”——它只在大量重复时才会显现。
- 期望值**是**说：“**只要长期坚持做期望值为正的事，收益会像大数定律一样，最终兑现。** ”

**🔑 核心逻辑**：期望值让你把“世界从确定性的赌局”变成“概率性的计算”。赌场之所以永远赚钱，不是因为它在每一局都赢了，而是因为**每一局的期望值都是负的**（对赌客而言）。玩得越久，负期望值越确定。


## 二、🧠 期望值的三大底层逻辑

### 1️⃣ 逻辑一：单次 vs 长期——短期靠运气，长期靠数学 📈

| 视角 | 单次结果 | 长期平均 |
|:---|:---|:---|
| 60%概率赢100，40%概率输100 | 要么赚100，要么亏100 | **平均每局赚20元** |
| 赌场轮盘赌（玩家赔率5.26%） | 可能赢钱 | **每局必亏5.26%** |
| 彩票（中奖率千万分之一） | 可能一夜暴富 | **每注期望值远低于2元** |

**🔑 关键认知**：**单次结果是运气，长期平均是数学。** 赌场不在乎你今天赢了多少——因为只要你一直玩，大数定律会确保你最终亏掉那5.26%。

### 2️⃣ 逻辑二：正期望值 vs 负期望值——长期赢家和长期输家的分水岭 ⚖️

| 期望值类型 | 特征 | 长期结果 | 例子 |
|:---|:---|:---|:---|
| **正期望值（+EV）** | 概率优势在你这边 | **稳定盈利** | 保险公司的保费收入、索普的21点策略 |
| **负期望值（-EV）** | 概率优势在别人那边 | **稳定亏损** | 买彩票、去赌场、追涨杀跌 |
| **零期望值（0 EV）** | 概率优势均等 | **不赚不亏** | 公平的抛硬币游戏 |

**🔑 关键认知**：**你的长期财富水平，基本上等于你所有决策期望值的总和。** 每天都做正期望值的事，时间越长，你的下限越高；每天都做负期望值的事，时间越长，你亏得越多。

### 3️⃣ 逻辑三：期望值与方差——正期望不等于零风险 🔄

即使期望值为正，也不代表你可以无脑下注。**方差**（Variance）是风险——如果方差太大，你可能会在长期兑现之前就破产。

| 场景 | 期望值 | 方差 | 风险 |
|:---|:---|:---|:---|
| 每天存100元到4%收益的账户 | +4%年化 | 极低 | 安全 |
| 90%概率赢100万，10%概率亏1000万 | +80万（正期望） | 极高 | 你可能还没等到赢，就已经亏光了 |
| 用凯利公式下注 | 正期望 | 可控 | 最优下注比例，避免破产 |

**🔑 关键认知**：**正期望值 + 过高方差 = 潜在的毁灭。** 这就是为什么索普需要用**凯利公式**（Kelly Criterion）来计算下注比例——他不仅要确保EV为正，还要确保不会因为一次小概率的失败而爆仓。

 
> 🧠 **核心悖论**：即使期望值为正，如果方差（波动）过大，你极可能在“长期兑现”之前就因资金枯竭而被迫出局。  
> 🏆 这就是为什么索普（Edward Thorp）在拉斯维加斯和华尔街都必须使用凯利公式（Kelly Criterion）的核心原因。

## 1️⃣ 方差（Variance）计算公式 🧮

方差衡量的是**每个可能结果偏离平均期望值的“平方距离”**，并按概率加权求和。  
标准差（√方差）则是我们常说的 **“波动率”** 🌊。

**公式**：  
σ² = Σ [ Pᵢ × (Xᵢ - EV)² ]

| 符号 | 含义 |
| :--- | :--- |
| **Pᵢ** | 🎲 第 i 种结果发生的概率 |
| **Xᵢ** | 💰 第 i 种结果的具体盈亏金额 |
| **EV**  | 🎯 该策略的期望值（数学期望） |

---

## 2️⃣ 场景代入计算（对照你的原始案例）📋

为了严谨，我将你的原始案例拆分为 **“文字本意（EV为负）”** 与 **“修正后（EV为正）”** 两种情况，方便你对比方差对风险的直观冲击。

---

### 🔴 场景 A：原文案字面数据（实则 EV 为负）❌

> 条件：90% 概率赢 **100万**，10% 概率亏 **1000万**

| 步骤 | ✏️ 计算过程 | 📊 结果 |
| :--- | :--- | :--- |
| **期望值 (EV)** | EV = 0.9 × (+100) + 0.1 × (-1000) <br>    = 90 - 100 <br>    = -10 万元 | **-10 万元**（💀 负期望，纯粹送死局） |
| **方差 (σ²)** | σ² = 0.9 × [100 - (-10)]² + 0.1 × [-1000 - (-10)]² <br>    = 0.9 × 110² + 0.1 × (-990)² <br>    = 0.9 × 12100 + 0.1 × 980100 <br>    = 10890 + 98010 <br>    = 108900 (万元²) | **108,900** (万²) |
| **标准差 (σ)** | σ = √108900 ≈ 330 万元 | ≈ **330 万元** |

📌 **残酷结论**：标准差 330万 远大于你的盈利目标（100万），且期望值为负。这就像 **“开着漏油的跑车冲向悬崖”** 🏎️💥——又危险又亏钱，碰都别碰。

---

### 🟢 场景 B：修正为正期望（符合你的逻辑假设）✅

> 条件：90% 概率赢 **200万**，10% 概率亏 **1000万**（此时 EV = +80万）

| 步骤 | ✏️ 计算过程 | 📊 结果 |
| :--- | :--- | :--- |
| **期望值 (EV)** | EV = 0.9 × (+200) + 0.1 × (-1000) <br>    = 180 - 100 <br>    = +80 万元 | **+80 万元**（🎉 正期望，有搞头！） |
| **方差 (σ²)** | σ² = 0.9 × [200 - 80]² + 0.1 × [-1000 - 80]² <br>    = 0.9 × 120² + 0.1 × (-1080)² <br>    = 0.9 × 14400 + 0.1 × 1166400 <br>    = 12960 + 116640 <br>    = 129600 (万元²) | **129,600** (万²) |
| **标准差 (σ)** | σ = √129600 ≈ 360 万元 | ≈ **360 万元** |

🚨 **致命警告**：虽然 EV 为正（+80万），但标准差（360万）是 EV 的 **4.5 倍**！  
这意味着在极少数情况下（10%概率），一次亏损就会像 **“海啸”** 🌊 一样吞掉你数次的盈利积累——**方差过高直接导致了“路径依赖性破产风险”**，你很可能在“大数定律”生效之前就倒在黎明前。

## 3️⃣ 风险量化指标：变异系数（CV）📈

用来衡量 **“每单位期望收益所承担的风险”**：

**CV = 标准差 / 期望值 = 360 / 80 = 4.5**

| CV 范围 | 🌈 风险等级 | 代表场景 |
| :--- | :--- | :--- |
| **CV < 1** | 🛟 安全可控 | 每天存100元到4%收益的账户 |
| **1 < CV < 3** | ⚠️ 需要警惕 | 普通股票或指数基金定投 |
| **CV ≥ 4.5** | 🔥 极度高危 | 杠杆赌局、期权末日轮、你的这个案例 |

## 4️⃣ 解决方案：凯利公式（Kelly Criterion）如何“驯服”方差？🛡️

凯利公式的作用**不是降低波动率本身**，而是通过控制 **“下注比例（仓位）”** ，将破产概率降为 **0** 🧘。

针对 **场景 B**（赢 200万 对应赔率 b = 0.2 倍，胜率 p = 0.9）：

**已知条件**  
- 胜率 p = 0.9  
- 败率 q = 1 - 0.9 = 0.1  
- 赔率 b = 盈利金额 / 亏损金额 = 200 / 1000 = 0.2（净赔率）

**代入凯利公式**  

f* = (b × p - q) / b
= (0.2 × 0.9 - 0.1) / 0.2
= (0.18 - 0.1) / 0.2
= 0.08 / 0.2
= 0.4 （即 40%）

在做任何高风险决策前（投资、创业、博彩），先问自己这 3 个灵魂拷问：

- [ ] 🧮 **Step 1**：我算出这个策略的 **期望值（EV）** 确实为正了吗？（别凭感觉，拿笔算！）

## 三、🌰 真实案例 · 期望值如何改变决策？

### 🎲 案例 1：赌金分配问题——期望值的“出生证明”（1654年）

- **背景**：1654年，法国贵族**德·梅累骑士**（Chevalier de Méré）在一次名流聚会中向数学家**布莱兹·帕斯卡**（Blaise Pascal）提出了一个问题：

> “两个赌徒各下赌金32枚金币，约定谁先赢满5局谁获得全部赌金。现在A赢了4局，B赢了3局，游戏因故中断——赌金该如何公平分配？”

- **直觉的陷阱**：B认为按已赢局数比例分配（4:3）是公平的。A认为“我再赢一局就全拿，你要连赢两局”——这个直觉更接近正确答案，但无法量化。

- **期望值的解法**：帕斯卡写信给**费马**（Pierre de Fermat），两人通过通信给出了正确答案——用**期望值**来分配：
  - 最多再玩两局就能分出胜负
  - 两局的所有可能结果：**AA、AB、BA、BB**（每种概率相等）
  - 其中**前三种**都是A赢，**只有BB**是B赢
  - 因此A获胜概率 = **3/4**，B获胜概率 = **1/4**
  - 期望值分配：A应得 **32 × 3/4 = 24** 枚，B应得 **32 × 1/4 = 8** 枚

- **结果**：按3:1比例分配。这组通信被公认为**概率论和期望值的诞生标志**。

- **🎯 一句话**：**期望值的第一次出场，是在两个赌徒分钱的争吵中。帕斯卡和费马发现：公平不是“你赢了几局”，而是“你有多大概率赢下全部”。** 这才是期望值的雏形。


### 🎰 案例 2：爱德华·索普——用正期望值“合法击败”拉斯维加斯（1960年代）

- **背景**：1958年，数学教授**爱德华·索普**（Edward Thorp）第一次走进拉斯维加斯赌场。他买了**10美元**筹码——他不是赌徒，他是**数学家**。他想测试自己的概率模型：21点是否可以被击败？

- **期望值的计算**：索普发现，21点的秘密在于**5**——如果一盒牌中的四张5全部被移除，庄家的优势会从**0.21%** 变为玩家的优势**3.29%** 。关键在正期望值：
  - 大多数情况下，玩家的期望值为**负**（-0.21%）
  - 但当剩余牌堆中高牌（10、A）密集时，玩家的期望值转为**正**（+3%以上）
  - 索普的策略：**正期望时下重注，负期望时下小注或不注**

- **结果**：索普的21点算牌策略**横扫拉斯维加斯**，赌资迅速翻倍。1962年他出版《**击败庄家**》（*Beat the Dealer*），内华达赌场被迫修改游戏规则——**因为他证明了：在正期望值面前，庄家是可以被击败的**。

- **🎯 一句话**：**索普不是靠运气赢的，他是靠数学赢的。他算出了什么时候期望值为正，然后只在那个时候下注。赌场靠大数定律赚钱，他用同样的数学反过来打败了赌场。**


### 🎟️ 案例 3：彩票的数学——负期望值的“大众陷阱”

- **背景**：美国的强力球彩票（Powerball）头奖高达数亿美元时，数百万人疯狂购买。**期望值是多少？**

- **期望值的计算（简化）** ：
  - 每张彩票2美元
  - 头奖概率：1/2.92亿 ≈ 0.0000000034%
  - 其他小额奖金的期望值加起来大约0.3美元
  - 头奖期望值 ≈ 5亿 × 1/2.92亿 ≈ 1.71美元
  - **总期望值 ≈ 0.3 + 1.71 = 约2.01美元**（购买价为2美元）

- **误区**：当奖金超过5.84亿美元时（理论上），彩票的期望值会超过2美元。媒体欢呼：“彩票变成正期望值了！”

- **期望值的真相**：即使期望值略大于2美元，也依然不是好投资：
  - **方差巨大**：你中奖的概率是1/2.92亿，你几乎一定会亏
  - **税收和年金**：如果一次性领取，实际到手只有**一半**（约2.5亿），期望值再次变成负
  - **共享头奖的风险**：如果多人中奖，奖金被分割，期望值断崖式下跌
  - 绝大多数情况下，彩票的期望值约为**0.5美元**（每2美元净亏1.5美元）

- **🎯 一句话**：**彩票的本质是“负期望值税”——穷人以为在买希望，其实是在交智商税。正期望值不是数学算出来的，是买彩票的人没把‘税’和‘方差’算进去。**


### 🎂 案例 4：巴菲特的生日悖论——正期望值的“认知战”（1990年代）

- **背景**：在一次**本杰明·格雷厄姆**（Benjamin Graham）信徒的聚会上，有**25名**会友参加。**沃伦·巴菲特**（Warren Buffett）与《财富》杂志编辑**凯洛·卢米斯**（Carol Loomis）打赌：**这25人中至少有两个人同月同日生**。

- **直觉的陷阱**：卢米斯认为这个概率很低——一年有365天，25个人撞生日的概率怎么可能高？她接下了这个赌。

- **期望值的计算**：
  - 第一个人可以是任意一天：概率 = 1
  - 第二个人不与第一个人相同：364/365
  - 第三个人不与前两人相同：363/365
  - ……
  - 第25个人不与前面24人相同：341/365
  - 没有两个人相同的概率 ≈ **43%**
  - **至少两个人相同的概率 = 1 - 43% = 57%**

- **结果**：巴菲特**赢了**。57%的概率意味着：如果重复做这个赌局，巴菲特每10局赢5.7局，输4.3局——**这是一个正期望值的赌局**。对巴菲特这样的赔率计算者来说，这就是“把钱白捡”。

- **🎯 一句话**：**巴菲特不需要每次都赢。他只需要在概率超过50%的时候下注——长期下来，他就赢了。这不叫赌博，这叫套利。**


### 🚗 案例 5：汽车保险——正期望值如何让保险公司“稳赚不赔”

- **背景**：假设你买了汽车保险，年保费**1000美元**。一年内你出事故的概率是**5%**，一旦出事保险公司平均赔付**1.5万美元**。

- **期望值的计算**：
  - 对保险公司：EV = 1000（你交的保费） - 15000 × 5%（期望赔付） = 1000 - 750 = **+250美元**
  - 对车主：EV = -1000 + 15000 × 5% = -1000 + 750 = **-250美元**

- **结果**：保险公司每年从每个客户身上净赚**250美元**（期望值）。全美有**超过2亿**辆投保车辆——这就是为什么**保险公司永远是盈利的**。这不是因为保险公司“会算命”，而是因为他们**设计了正期望值的商业模式**。

- **🎯 一句话**：**保险的本质是：你付1000美元买一个‘概率保护’，保险公司收1000美元承担一个‘概率风险’。因为他们的精算师算得很清楚——聚合大量的风险，期望值必然是正的。**


## 四、⚠️ 期望值的三大致命陷阱

| 陷阱 | 表现 | 杀伤力 |
|:---|:---|:---|
| **把“正期望值”当成“必胜”** | “这个策略的期望值为正，所以我这次一定赢！” | 正期望值不等于“必胜”——你还可能遇到那10%的失败。**长期才兑现，短期靠运气** |
| **忽视方差（破产风险）** | “期望值为正，我要ALL IN！” | 90%概率赚100万，10%概率亏1000万——正期望值（+80万）但方差极高，一旦那10%发生，你直接破产。**凯利公式告诉你：下注比例才是关键** |
| **赌徒谬误** | “连续亏了10次了，下一次一定是正期望值！” | 赌场轮盘赌每一局的期望值都是负的——**连续亏损不会改变下一局的概率** |

## 六、🛠️ 防身三式 · 期望值实战指南

| 工具 | 操作 | 核心逻辑 |
|:---|:---|:---|
| **① “EV计算器”法** | 做任何决策前，问自己：“**这件事发生的概率是多少？如果发生，收益/损失是多少？** ”然后相乘，得到期望值 | 概率 × 收益 = 决策依据——**不赌“会不会”，只算“值不值”** |
| **② “凯利比例”法** | 如果期望值为正，不要ALL IN，用**凯利公式**计算最优下注比例：**f = (bp - q) / b** | 即使EV为正，下注比例也要控制在“不至于一次破产”的范围内 |
| **③ “大数定律提醒”法** | 短期结果随机时，告诉自己：“**这只是小样本的噪音。长期来看，概率会兑现。** ” | 不被短期随机性迷惑——**赌场靠这个赚钱，你也靠这个赚钱** |


## 七、🧠 超级记忆包 · 3样东西记住“期望值”

### 1️⃣ 记一个故事：**“帕斯卡与费马分赌金”** 🎲

A赢了4局，B赢了3局，最多再玩两局定胜负。两局所有可能：AA、AB、BA、BB——A赢3种，B赢1种。**赌金按3:1分。** 这就是期望值的出生证明——**公平不是按过去分，而是按未来概率分。**

### 2️⃣ 记一个公式：**“EV = 概率 × 收益”** 📊

做任何决策前，先算这个。如果期望值为正，做；如果为负，不做。**投资、职业、婚姻——都适用。**

### 3️⃣ 记一句查理·芒格的话：**“你必须把现实当作一个概率系统来理解，而不是一个确定性的系统。”**

🎯 **终极口诀**：
> **“别问会不会，问多大概率。单次靠运气，长期靠数学。正期望就做，负期望就躲。”** 🔥


## 八、🏁 回到开篇那句话

> **“不是问‘我赢了吗？’，而是问‘在10万次选择中，我平均赢多少？’”**

🔍 **彩蛋练习**：
**今天，只做一件事——**

找一个你最近做的“不确定决策”（比如：要不要买那个课程？要不要跳槽？要不要买这只股票？）：

**用期望值做一次决策分析**：
1. 这件事成功的概率是多少？（估算一个数字）
2. 如果成功，收益有多大？
3. 如果失败，损失有多大？
4. **期望值 = 成功概率 × 收益 - 失败概率 × 损失**
5. 如果期望值为正——**做**。如果为负——**不做**。

**期望值不会让你100%正确，但会让你长期赢。** 🧠
