## 三、两份实战检查清单

这是整个系统的**落地终端**，将151个思维模型浓缩为可执行的10维度检查表：

### 📋 买入决策检查清单（10维度）

| 维度 | 对应模型 |
|:---|:---|
| ① 能力圈 | 🎯 能力圈 |
| ② 概率与赔率 | 📊 概率与赔率 + 期望值 |
| ③ 机会成本 | ⚖️ 机会成本 |
| ④ 二阶思维 | ♟️ 二阶思维 |
| ⑤ 估值安全垫 | 📉 对比错误反应 + 锚定效应 |
| ⑥ 财务合规与退市红线 | 📋 检查清单（一票否决） |
| ⑦ 资金结构与筹码博弈 | 🔍 信息不对称 + 激励驱动偏差 |
| ⑧ 情绪检查 | 🧠 双轨理论 + FOMO/从众 |
| ⑨ 政策敏感性 | 🌍 路径依赖 + 外部性 |
| ⑩ 流动性风险 | 📊 遍历性（一票否决） |

### 📋 卖出决策检查清单（10维度）

覆盖：逻辑是否还在、基本面恶化、估值泡沫、政策逆转、筹码恶化、流动性枯竭、机会成本、仓位风控、情绪检查、市场环境。

**两份清单共同特点**：
- 有**一票否决机制**（退市红线 + 流动性枯竭）
- 有**综合决策区**和**最终决策与行动计划**
- 有**执行纪律承诺**（自我约束签名区）
- 有**复盘记录区**（供未来回顾）
- 适配 **2026年A股** 实际规则（退市新规、量化交易占比等）

## 五、系统级亮点

### 🔄 模型间交叉引用极为丰富
- 每个模型文件都有"案例隐藏模型索引"，标注该故事背后还涉及哪些其他模型
- 系统论13个模型形成完整叙事链，每个模型的结尾引出下一个模型的开头
- 误判心理学25个倾向与元认知7件武器形成"攻击-防御"对偶关系

### 📊 置信度标注
每个文件都标注了 **AI生成置信度**（55%-98%），让你知道哪些内容更可靠：
- 🟢 **90%+**：复利、大数定律、概率论、囚徒困境等（硬核学科，验证充分）
- 🟡 **75-89%**：复杂系统、决策理论等（有一定主观性）
- 🟠 **<75%**：Lollapalooza(55%)、社会与组织(65-70%)、部分心理学(72-75%)（较难量化验证）

### 🎯 实战导向
几乎所有模型都映射到 **2026年A股** 的具体案例，不是纸上谈兵。
