# 卖出决策检查清单（2026年A股适配版·完整版）

## 一、检查维度清单（10维度）

| 序号 | 检查维度 | 核心问题（请自问） | 您的事实依据/数据 | 您的结论（✔/✘/？） | 备注 |
| :---: | :--- | :--- | :--- | :---: | :--- |
| **1** | **买入逻辑是否还在？** | **当初买入的核心逻辑是否依然成立？** <br>① 如果是“业绩高增长”逻辑——最新财报是否证实了增长？<br>② 如果是“政策受益”逻辑——政策是否仍在落地或加码？<br>③ 如果是“估值修复”逻辑——估值是否已经修复到位？<br>**如果核心逻辑被证伪或已充分兑现，是否应坚决卖出？** | | | **逻辑破坏是最重要的卖出信号。** 不要因为“还没回本”而持有逻辑已坏的公司。 |
| **2** | **基本面是否恶化？** | **最近一期财报是否出现业绩变脸？** （营收/净利润大幅低于预期、毛利率下滑、现金流恶化）<br>**是否触及退市新规红线？** <br>· 主板：**净利润（含扣非孰低）为负** 且 营收<3亿元[reference:5]<br>· 创业板/科创板：**净利润（含扣非孰低）为负** 且 营收<1亿元[reference:6]<br>· 北交所：**净利润（含扣非孰低）为负** 且 营收<5000万元[reference:7]<br>**净资产是否转为负值？审计意见是否变为非标准无保留？** <br>**是否被证监会立案调查？** （财务造假1年达2亿元以上且比例30%以上即触发强制退市）[reference:8] | | | **若触及退市红线，一票否决，立即卖出。** 2026年退市新规刚性执行，*ST后若次年再触红线即终止上市[reference:9]。 |
| **3** | **估值是否严重泡沫化？** | **当前PE/PB是否处于历史极高位置？** （远超历史均值及行业均值）<br>**PEG是否远大于2？** （成长严重透支，股价已充分甚至过度反映未来预期）<br>**相比无风险收益率**（如10年期国债利率），股权风险溢价是否已为负？<br>**DCF/股息率模型**是否显示当前价格已无安全边际？ | | | 在2026年整体估值极高的背景下，需警惕“好公司但不便宜”的陷阱。**卖在泡沫中，比卖在合理估值更难，但更重要。** |
| **4** | **政策环境是否逆转？** | **行业是否遭遇监管打压？** （如反垄断、医药集采扩大、教培类监管、行业整顿新规）<br>**国家战略方向是否已转移？** （该行业是否不再列为“新质生产力”或“科技自立自强”重点方向）<br>**政策补贴/税收优惠是否面临退坡或取消？** | | | 2026年政策市特征显著。**政策从“顺风”转为“逆风”时，即使基本面暂时未变，也应果断离场。** |
| **5** | **资金结构与筹码是否恶化？** | **是否有大股东/高管大规模减持？** （尤其是公告减持比例>1%或清仓式减持）<br>**北向资金是否持续净流出？** （连续多日/多周流出）<br>**ETF份额是否持续净赎回？** （反映被动资金正在撤离该板块）<br>**融资余额是否快速下降？** （杠杆资金撤退，情绪转冷）<br>**龙虎榜量化席位是否出现密集净卖出？** | | | 2026年违规减持监管已升级，大额减持（超总股本5%且金额超5亿元）将面临重罚[reference:10]。但合规减持仍是重要信号。 |
| **6** | **流动性是否枯竭？** | **个股日均成交额是否已大幅萎缩？** <br>**分级参考标准**：<br>· 微盘股（市值<50亿）：日均成交额 **<2000万元** 为危险信号<br>· 中大盘股（市值≥50亿）：日均成交额 **<3000万元** 为危险信号<br>· 若日均成交额 **<1000万元**：流动性极度枯竭，一票否决<br>**是否出现连续跌停或流动性折价？** <br>**量化主导下，是否因盘口过薄而无法按合理价格卖出？** | | | **若流动性严重不足（日均<1000万），一票否决，不计成本卖出。** <br>量化交易占35%-42%的市场环境中，流动性差的个股容易被“瞬间砸盘”导致无法止损[reference:11][reference:12]。<br>**指数ETF投资可豁免本维度检查。** |
| **7** | **机会成本比较** | **是否有性价比更高的替代标的？** <br>**持有现金的机会成本**（如国债逆回购年化2%+、货基收益）是否已高于该标的的预期回报？<br>**如果现在空仓，我还会在这个价位买入这只股票吗？** <br>（若答案是否定的，则应该卖出） | | | 这是最经典的卖出测试之一。**“如果现在没持有，我还会买吗？”——如果不会，就卖出。** |
| **8** | **仓位与风险控制** | **该仓位是否已超出单一标的的风险上限？** （如超过总资产的5%-10%）<br>**当前浮亏是否已触及预设止损线？** （如-15%）<br>**当前浮盈是否已触及预设止盈线？** （如+50%）<br>**该标的的波动率是否已超出个人风险承受能力？** | | | **触发止损/止盈线应机械执行，不犹豫。** 这是保护本金和锁定利润的最后防线。 |
| **9** | **情绪检查（行为金融）** | **是否因为“再等等、会反弹”的侥幸心理而延迟卖出？** <br>**是否因为“曾经赚过XX钱”而难以接受利润回吐？** （处置效应）<br>**是否因为“已经亏了这么多，现在卖就真亏了”而拒绝止损？** （沉没成本谬误）<br>**是否因为“大家都还在持有”而不敢率先卖出？** （从众心理）<br>**如果现在空仓，我还会在这个价位买入吗？** （反向验证） | | | 这是最后一道心理防线。**大多数亏损扩大的根源，不是看错了，而是不愿意认错。** 诚实面对自己的情绪，才能做出理性决策。 |
| **10** | **市场整体环境** | **大盘指数是否处于明显高估且开始下跌的阶段？** <br>**市场情绪是否极度狂热？** （新基金发行天量、融资余额历史新高、散户开户数暴增）<br>**宏观政策是否开始收紧？** （货币政策转向、监管层密集提示风险）<br>**系统性风险来临时，是否应优先减仓而非纠结个股基本面？** | | | 2026年量化交易占比高，同质化策略易引发“助涨助跌”[reference:13]。**系统性风险来临时，覆巢之下无完卵，先降仓位再谈选股。** |
