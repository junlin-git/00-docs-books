# 《孙子兵法·兵势篇》超详细深度解读 —— 以正合，以奇胜

> 本篇导读：前四篇，孙子教我们“算”（始计）、“耗”（作战）、“谋”（谋攻）和“等”（军形）。如果你已经算过了、耗得起、找到了最优策略、也等到了最佳时机——现在终于可以出手了。但出手怎么出？**第四篇“军形”讲的是“积蓄力量”，第五篇“兵势”讲的是“释放力量”。** 全篇核心就三个字：**奇、正、势**。本文将以2026年A股主力的新型操盘手法、京东方A的惊天反转、宁德时代与比亚迪的双雄对决、传统制造老板的转型困局等真实案例，彻底拆解这套“用兵如神”的实战框架。


## 第一章：开篇定调——什么是“势”？什么是“节”？

### 原文第一段
> **“孙子曰：凡治众如治寡，分数是也；斗众如斗寡，形名是也；三军之众，可使必受敌而无败者，奇正是也；兵之所加，如以碫投卵者，虚实是也。”**

### 🔍 逐字精讲
- **治众如治寡，分数是也**：管理很多人就像管理很少人一样，靠的是**组织编制**（把大部队分成小单位）。
- **斗众如斗寡，形名是也**：指挥很多人作战就像指挥很少人一样，靠的是**信号系统**（旗鼓、号令）。
- **可使必受敌而无败者，奇正是也**：能让全军在面对敌人时立于不败之地，靠的是**“奇正”的运用**。
- **兵之所加，如以碫投卵者，虚实是也**：进攻时像用石头砸鸡蛋一样势不可挡，靠的是**“虚实”的把握**（以实击虚）。

### 🧠 什么是“奇”和“正”？（最重要的概念澄清）

很多人把“奇”理解成“奇招”“怪招”——这是天大的误解！

> **华杉在《讲透孙子兵法》中正本清源：这里的“奇”，读“jī”，是数学里“奇数偶数”的“奇”。它指的是“预备队”“杠杆”“底牌”。**

- **正兵**：正面战场的常规部队——你的**基本盘、常规打法、主营业务**。
- **奇兵**：预备队、后备力量——你的**备用方案、第二增长曲线、秘密武器**。

**“以正合，以奇胜”的意思是：用正兵（常规力量）与敌人正面交锋（合），然后用奇兵（预备队）在最关键的时刻、最关键的位置投下去，取得胜利（胜）。**

### 📊 2026年A股翻译

| 概念 | 古代军事 | 现代投资 | 2026年实操 |
| :--- | :--- | :--- | :--- |
| **正** | 正面主力部队 | 你的**底仓配置** | 高股息防御板块、指数ETF、核心龙头 |
| **奇** | 预备队/奇袭部队 | 你的**机动仓位** | 题材股、短线博弈、事件驱动交易 |
| **以正合** | 用正兵与敌人对峙 | 用底仓**跟随市场** | 长期持有银行、电力等高股息资产 |
| **以奇胜** | 用奇兵决胜 | 用机动仓位**超额收益** | 在市场恐慌时抄底、在题材爆发时出击 |


## 第二章：“势”的本质——激水漂石，鸷鸟毁折

孙子在这一篇用了两个极其精妙的比喻，把“势”和“节”讲透了。

> **原文：“激水之疾，至于漂石者，势也；鸷鸟之击，至于毁折者，节也。是故善战者，其势险，其节短。势如彍弩，节如发机。”**

### 🔍 逐字精讲
- **激水之疾，至于漂石者，势也**：湍急的水流能把石头冲走，靠的是**势能**的积累。水流不急，石头纹丝不动；水流足够急，巨石也能被冲走。
- **鸷鸟之击，至于毁折者，节也**：猛禽捕猎时一击即中、直接击碎猎物，靠的是**节奏**的把控——时机、速度、精准度。
- **势如彍弩**：势能要像拉满的弓弩一样——**蓄得越满，射得越远**。
- **节如发机**：节奏要像扣动扳机一样——**短促、精准、不可逆转**。

### 🧠 现代翻译（投资版）

| 孙子概念 | 现代投资翻译 | 2026年实操 |
| :--- | :--- | :--- |
| **势（激水漂石）** | **趋势的力量** | 2026年上半年，科创50涨64%，上证50跌1.38%——这就是“势”：资金如激水，往科技方向涌，传统板块根本挡不住 |
| **节（鸷鸟毁折）** | **出手的节奏** | 2026年7月2日，京东方A早盘一度跌停，机构在跌停板附近大举抄底，日内振幅18%，最终收涨3.76%——这就是“节”：在最恐慌的瞬间出手 |
| **势险（彍弩）** | **蓄势要足** | 半导体设备板块在2026年上半年暴涨前，经历了2023-2025年连续三年的订单积累——蓄势三年，爆发一季 |
| **节短（发机）** | **出手要快** | 顶级游资的操作：三天打鱼两天晒网，机会来了重仓猛干，机会走了空仓休息——扣动扳机，不拖泥带水 |


## 第三章：核心方法论——“以正合，以奇胜”的实操框架

> **原文：“凡战者，以正合，以奇胜。故善出奇者，无穷如天地，不竭如江河。”**

### 🔍 深度解读

“以正合”是**基本功**——你必须有稳定的基本盘，才能在市场上活下来。
“以奇胜”是**胜负手**——光有基本功不够，你必须在关键时刻拿出别人没有的“牌”。

**“正”是活下来的底线，“奇”是赢下来的上限。**

### 💼 2026年商业案例一：传统制造老板的“死局”与“破局”

有一个做了20年实业的老板：厂房很大，设备很先进，产品质量吊打同行。但最近三年，订单越来越少，利润越来越薄。他觉得是“世道不好”。

**用《兵势篇》诊断：这位老板犯了典型的“有正无奇”的错误。**

- **他的“正”** ：把所有的力气都花在了生产上。质量好、产能大——这是他的“正兵”。但在2026年的市场环境下，“产品好”只是入场券，不再是决胜点。
- **他缺的“奇”** ：缺了品牌认知、缺了直连消费者的能力、缺了私域流量。他把“势能”都压在了库存里，而不是建立在用户的心智里。

**怎么破局？“奇正相生”的系统——**

**第一步：用“正”养“奇”。** 利用现有的现金流（正），去组建一个小团队，专门做品牌、做内容、做私域。哪怕刚开始不赚钱，也要把这个“预备队”养起来。

**第二步：用“奇”带“正”。** 当品牌做起来了、有了自己的私域流量，同样的产品，贴上自己的品牌，价格能翻倍。这时候，“奇”就转化成了新的“正”。

### 💼 2026年商业案例二：奇瑞“守正”与比亚迪“出奇”

2026年，中国汽车出口格局发生了一个有趣的对比：

- **奇瑞（守正）** ：2025年前11个月出口119.9万辆，继续保持出口销量冠军。奇瑞的打法是**守住燃油车的基本盘**，稳扎稳打，步步为营——这是“正”。
- **比亚迪（出奇）** ：同期出口92.1万辆，同比增长1.5倍。比亚迪的打法是**用新能源车作为“奇兵”** ，在别人还没反应过来时闪电切入海外市场——这是“奇”。

**“以正合，以奇胜”的结构在这里完美体现：奇瑞用“正”守住阵地，比亚迪用“奇”打开局面。两者都不是只靠“正”或只靠“奇”，而是正奇结合。**

### 📊 2026年A股案例：茶饮行业的“金字塔产品结构”

茶饮行业的血战是“以正合，以奇胜”的典型案例：

当整个行业陷入“5元定价”的恶性循环时，某区域品牌玩起了**金字塔产品结构**：

| 层级 | 产品类型 | 作用 | 兵法对应 |
| :--- | :--- | :--- | :--- |
| **塔基** | 5元基础款 | 维持客群基数，守住基本盘 | **正兵** |
| **塔中** | 15元鲜果茶系列 | 提升毛利，赚取利润 | **正中有奇** |
| **塔尖** | 联名非遗茶器周边 | 打造品牌溢价，制造话题 | **奇兵** |

这种打法，既守住了基本盘（正），又通过高附加值产品实现盈利突破（奇）。


## 第四章：“奇正相生”——循环往复，无穷无尽

> **原文：“战势不过奇正，奇正之变，不可胜穷也。奇正相生，如循环之无端，孰能穷之？”**

### 🔍 深度解读

“奇”和“正”不是固定的——**今天的“奇”，明天可能变成“正”；今天的“正”，明天可能变成“奇”。**

- 2023年的AI，是“奇”（少数人看懂）。
- 2024年的AI，变成了“正”（大家都进场）。
- 2026年的AI算力，变成了新的“正”（主流赛道）。
- 而“AI+具身智能”“AI+医药”，正在成为新的“奇”。

**“奇”和“正”像阴阳一样互相转化、循环往复，无穷无尽。**

### 📊 2026年A股现实映射：板块轮动的“奇正相生”

2026年上半年，A股呈现极致的K型分化：**科创50暴涨64.25%，而超六成行业录得下跌**。

这个过程中，“奇正相生”在不停上演：

| 阶段 | 正兵（主流） | 奇兵（预备队） | 转化 |
| :--- | :--- | :--- | :--- |
| **2025年** | 红利资产、高股息 | AI概念、半导体 | AI是“奇” |
| **2026年Q1** | AI算力、半导体设备 | 消费电子、新能源 | AI变成“正” |
| **2026年Q2** | 科技硬制造（正） | 消费板块反弹（奇） | 消费开始变成“奇” |
| **2026年下半年（预期）** | 科技+均衡配置 | 金属原材料、游戏 | 新的“奇”在酝酿 |

> **关键洞察：在A股赚钱的核心能力，不是判断“正”是什么，而是判断“奇”什么时候会变成“正”——在它还是“奇”的时候布局，在它变成“正”的时候收获。**


## 第五章：A股主力的“奇正之术”——2026年新型收割套路全解析

2026年，A股主力发现传统收割套路（拉涨停、砸盘、出货）已经割不动“精明散户”了。于是，一套全新的“奇正”战术悄然登场。

### 🎯 新型套路一：不拉涨停，编一个“宏大叙事”（用“奇”伪装成“正”）

过去主力收割靠涨停板——连续拉板，散户闻着味就来了。但2026年监管趋严，异常波动票被重点监控，游资连续拉板的空间被极限压缩。

**新玩法：不急着拉涨停，先把故事讲圆。逻辑越宏大越好——AI、Token工厂、算力革命，哪个词热贴哪个。**

**典型案例：润建股份的“Token工厂”故事**
- 公司宣布转型“Token工厂”，将智算中心升级，推出“星算云池”产品。
- 券商研报给出“Token业务目标营收10亿元、毛利率50%+”的预期。
- 但翻开业绩一看：2025年归母净利润同比大幅下降84.62%，2026年Q1同比下降81.82%。
- 股价却在8个交易日里录得5个涨停。

**散户为什么上当？** “AI确实是大趋势”“Token确实是智能时代的价值锚点”——这些都没错。但**趋势不直接等于利润，概念也不等于现金流**。主力用“宏大叙事”（奇）包装了一个没有业绩支撑的股票（无正），散户以为自己在追“正”，其实在追“伪奇”。

> **孙子的警告：没有“正”做根基的“奇”，不是“奇兵”，是“赌命”。**

### 🎯 新型套路二：龙虎榜造“神”——利用散户对游资的盲目信任

这是2026年最典型的“流量+资金联动”套路。交易软件和券商APP上，龙虎榜席位被直接打上“陈小群”“作手新一”等游资标签，散户一看到这些名字上榜，第二天闭眼跟风冲进去。

**利益链揭秘**：游资先建仓，然后主动让席位上龙虎榜，利用标签机制吸引散户跟风，等散户蜂拥而至时悄悄出货。

**2026年1号罚单**：牛散余韩控制67个账户，在5年多时间里通过集中资金优势连续买卖，操纵“博士眼镜”，违法所得5.11亿元，被罚没超10亿元。

**2026年5月**：知名牛散屠文斌一家三口举牌可川科技。该公司2025年净利润同比下滑76.27%，2026年一季度直接亏损1158.87万元，公司自己发公告说“光模块处于送样阶段，暂未形成营收”。而屠文斌本人，2025年6月刚因操纵市场被证监会罚没约7700万元。

> **孙子的视角：散户的“知彼知己”严重失衡——知道自己想赚钱（己），但完全不知道对手是谁、对手在干什么（彼）。**

### 🎯 新型套路三：机构“导演”惊天反转——正奇配合的天花板

2026年7月2日，玻璃基板龙头**京东方A**上演了教科书级别的“正奇配合”：

- **早盘**：一度跌停，散户恐慌割肉（主力用“奇”制造恐慌）。
- **盘中**：快速拉升，日内振幅达18.36%（主力“正兵”进场）。
- **收盘**：涨3.76%，成交额接近**500亿元**，创历史新高。
- **龙虎榜**：4家机构席位合计买入39.22亿元，但同时卖出24.64亿元——**滚动操盘（做T）或量化交易的迹象明显**。

**孙子的解读**：
- 机构在跌停板抄底（用“奇”——在别人恐惧时贪婪）。
- 机构在涨停附近减仓（用“正”——在别人贪婪时恐惧）。
- **“奇正相生”在一只股票的一天之内完成了三次转换。**


## 第六章：终极心法——“求之于势，不责于人”

全篇最核心、最深刻的句子来了：

> **原文：“故善战者，求之于势，不责于人，故能择人而任势。”**

### 🔍 逐字精讲
- **求之于势**：胜利的关键在于**创造和利用“势”** （趋势、形势、大势）。
- **不责于人**：不要苛责你的士兵/员工不够努力。
- **择人而任势**：选择合适的人，去驾驭和利用这个“势”。

### 🧠 现代翻译（老板必读）

孙子在2500年前就洞察了一个管理学的终极真理：

> **不要怪员工不够努力，要怪你自己没有造好“势”。**

| 错误的管理方式 | 正确的管理方式 |
| :--- | :--- |
| “你们怎么这么不努力？” | “我有没有给大家创造一个‘努力就能成功’的环境？” |
| “市场不好，没办法。” | “市场不好，但‘势’在哪里？我怎么利用它？” |
| “员工执行力太差。” | “我的制度、激励、文化，有没有让员工愿意执行？” |

### 📊 2026年A股翻译（投资必读）

| 错误思维 | 正确思维 |
| :--- | :--- |
| “这只股票怎么还不涨？” | “这个行业的‘势’到位了吗？” |
| “庄家太坏了，又割我！” | “我的仓位管理、止损纪律做好了吗？” |
| “市场太差了，没法赚钱。” | “市场的‘势’在哪里？我有没有站在‘势’的一边？” |

### 💼 2026年商业案例：宁德时代 vs 比亚迪——谁在“任势”？

2026年，宁德时代与比亚迪的竞争从电池技术路线杀到补能基础设施，不断升级。两者合计市占率维持64%。

| 维度 | 宁德时代 | 比亚迪 |
| :--- | :--- | :--- |
| **“势”是什么** | 全球动力电池龙头，掌握行业定价权 | 全球新能源车龙头，掌握终端市场 |
| **怎么“任势”** | 靠“外部定价权”锁定供应链优势 | 凭“内部消化力”硬扛价格压力 |
| **2026年Q1业绩** | 营收1291亿，净利润207亿，同比+48.52% | 营收1502亿，净利润41亿，同比-55% |
| **“势”的差异** | 宁德时代的“势”在**产业链上游**（电池技术+定价权） | 比亚迪的“势”在**终端市场**（整车+闪充站） |

两家都是顶级企业，但“任势”的方式不同——一个抓上游，一个抓下游。谁能更好地“求之于势”，谁就能在竞争中占据主动。

> **金句提炼：不要跟趋势作对。趋势向上，猪都能飞；趋势向下，神仙也救不了。高手不是创造趋势，而是识别趋势、顺应趋势、利用趋势。**


## 第七章：“兵势篇”完整决策框架（傻瓜式操作手册）

### 第二步：判断“势”的方向

| 问题 | 检查项 |

| **宏观“势”** | 政策方向是什么？（“十五五”规划重点在哪？） |

| **情绪“势”** | 市场是恐慌还是贪婪？（别人恐惧我贪婪，别人贪婪我恐惧） |

### 第三步：选择“节”的时机

| 时机 | 操作 |
| :--- | :--- |

| **势在、节已到** | 全力出击——用“奇兵”决胜 |
| **势不在、节已到** | 放弃——再好的时机，趋势不对也是白搭 |
| **势不在、节未到** | 空仓——什么都不做，就是最好的策略 |

### 第四步：实现“奇正相生”

- **当“正”涨多了** → 减仓“正”，加仓“奇”（高低切换）。
- **当“奇”变“正”了** → 把“奇”纳入“正”的范畴（让赚钱的变成基本盘）。
- **永远保持“正”和“奇”的动态平衡**——不要全是“正”（太慢），也不要全是“奇”（太险）。

## 第九章：兵势篇与前五篇的逻辑串联

至此，前五篇构成了一个完整的“战前五部曲”：

| 篇章 | 核心问题 | 决策输出 | 比喻 |
| :--- | :--- | :--- | :--- |
| **始计篇** | 这仗值不值得打？（定性） | “打”或“不打” | **战略会** |
| **作战篇** | 我打得起吗？（定量/成本） | “速打”或“缓打” | **财务会** |
| **谋攻篇** | 我该怎么用最小的代价打？（方法） | “伐谋/伐交/伐兵/攻城” | **方案会** |
| **军形篇** | 我现在具备“必胜条件”了吗？（时机） | “现在打”或“再等等” | **时机会** |
| **兵势篇** | 我该怎么出手？（战术） | “正兵稳、奇兵狠” | **执行会** |

**串联案例（2026年完整推演）** ：

1. **始计**：AI算力是2026最大风口 → 决定打。
2. **作战**：半年内能承受的最大亏损是20% → 速战速决。
3. **谋攻**：不直接买算力租赁股，买上游光模块龙头 → 伐谋。
4. **军形**：光模块龙头在手订单饱满、技术壁垒高 → 先胜条件具备。
5. **兵势**：
   - **“正”** ：拿出一半仓位配置光模块龙头的底仓（正兵）。
   - **“奇”** ：另一半仓位等待市场恐慌时抄底（奇兵）。
   - **“势”** ：AI产业趋势确定（激水漂石之势）。
   - **“节”** ：在板块回调15%时出手（鸷鸟毁折之节）。
