# 《孙子兵法·军形篇》超详细深度解读 —— 先为不可胜，以待敌之可胜

> 本篇导读：前三篇，孙子教我们“算”（始计）、“耗”（作战）和“谋”（谋攻）。如果你算过了、耗得起、也找到了最优策略，是不是就该冲上去打了？**大错特错！** 第四篇“军形”是全书的**忍耐哲学**。它告诉你：**在出手之前，先把自己练成“打不死的小强”，然后像猎人一样耐心等待猎物自己送上门。** 全篇核心就八个字：**先胜后战，不动如山。** 本文将用2026年的A股防御策略、巴菲特的现金等待、宁德时代的技术壁垒，彻底拆解这套“不败→待敌→求胜”的思维框架。

## 第一章：开篇定调——真正的牛人，是先让自己“不可战胜”

### 原文第一段
> **“孙子曰：昔之善战者，先为不可胜，以待敌之可胜。不可胜在己，可胜在敌。故善战者，能为不可胜，不能使敌之可胜。故曰：胜可知，而不可为。”**

### 🔍 逐字精讲
- **先为不可胜**：先把自己打造成一个“不可被战胜”的状态——防守滴水不漏、粮草充足、士气高昂、地形有利。
- **以待敌之可胜**：然后耐心等待敌人露出破绽、犯错误、内部崩溃的那一刻。
- **不可胜在己**：你能不能不被敌人打败，这事儿**完全取决于你自己**——你做好防守了吗？你风控到位了吗？你现金流充足吗？
- **可胜在敌**：你能不能打赢敌人，这事儿**不完全取决于你**——还得看敌人给不给你机会。如果敌人不犯错，你就赢不了。
- **胜可知，而不可为**：胜利是可以预见的（你能判断出“如果敌人犯错，我就能赢”），但**不能强求**（你不能逼着敌人犯错）。

### 🧠 现代翻译（投资版）
- **先为不可胜**：先确保自己不会亏大钱——仓位控制、止损纪律、不借钱炒股、不押单一标的。
- **以待敌之可胜**：然后耐心等市场出现“错误定价”——等恐慌性抛售、等黑天鹅、等优质资产被错杀。
- **不可胜在己**：你的最大亏损有多大，完全由你自己控制——设置止损线、控制仓位。
- **可胜在敌**：你能赚多少钱，很大程度上取决于市场给不给你机会——如果市场一直不跌，你就一直买不到便宜货。
- **胜可知，而不可为**：你能判断出“如果PE跌到历史10%分位以下，买入胜率极高”，但你不能强迫市场现在就跌到那个位置。

### 📊 2026年A股现实映射——“先为不可胜”的防御配置

2026年上半年，A股呈现出极致的K型分化：科创50暴涨60%以上，但**超六成个股录得负收益**。31个申万一级行业中，涨跌幅头尾差值高达115%。

在这样的极端分化中，聪明的资金怎么“先为不可胜”？

**答案是：配置高股息防御板块。**

2026年，银行板块凭借连续多年稳定分红、低估值（PB普遍不足0.7倍）以及高股息率（普遍在5%以上），成为红利策略的“压舱石”。在十年期国债收益率仅约1.8%的低利率环境下，银行股5%以上的股息率形成了显著的利差优势。

电力与公用事业板块同样被视为“永续现金流资产”——水电龙头如长江电力，分红率长期超70%，股息率约4%~5%，防御属性极强。公用事业板块需求刚性、现金流稳定，是红利策略的“底仓选择”。

**这就是“先为不可胜”在投资中的体现：**
- 不管科技股涨得多猛，你先拿一部分仓位配置高股息、低波动的防御资产。
- 如果市场继续涨，你有进攻仓位吃肉；如果市场暴跌，你的防御仓位帮你“扛住不崩”。
- **你无法控制市场涨跌（可胜在敌），但你可以控制自己的回撤幅度（不可胜在己）。**

> **金句提炼：先让自己变成“打不死的小强”，再去想怎么打死别人。投资先想“亏多少”，再想“赚多少”。**

## 第二章：防守与进攻的辩证法——“守则不足，攻则有余”

### 原文第二段
> **“不可胜者，守也；可胜者，攻也。守则不足，攻则有余。善守者，藏于九地之下；善攻者，动于九天之上。故能自保而全胜也。”**

### 🔍 逐字精讲
- **不可胜者，守也**：当你不具备必胜条件时，就老老实实防守。
- **可胜者，攻也**：当你发现敌人露出破绽、你具备必胜条件时，才发动进攻。
- **守则不足，攻则有余**：防守是因为“实力不足”或“时机不到”；进攻是因为“实力有余”或“时机成熟”。
- **善守者，藏于九地之下**：真正擅长防守的人，隐藏得像埋在地下九层那么深——敌人根本找不到你的弱点。
- **善攻者，动于九天之上**：真正擅长进攻的人，发动时像从九重天俯冲下来——迅雷不及掩耳，敌人根本来不及反应。
- **故能自保而全胜**：先确保自己安全，再追求全面胜利。

### 🧠 现代翻译（创业版）
- 当你**资金不足、团队不熟、产品不完善**时 → 不要急着扩张、打广告、烧钱抢市场 → **守**。
- 当你**现金流充裕、团队磨合到位、产品验证成功**，且**竞争对手恰好出了重大负面**时 → 果断出击，抢占市场份额 → **攻**。
- **“藏于九地之下”** ：在时机成熟前，低调做事，不让对手注意到你。
- **“动于九天之上”** ：时机一到，全力出击，让对手措手不及。

### 💼 2026年商业案例——宁德时代的“守”与“攻”

2026年，固态电池成为新能源领域最热的话题。宁德时代董事长曾毓群在夏季达沃斯论坛上公开表示：**全固态电池技术成熟度仅达到4/9（满分9分），大规模量产将推迟至2030年之后**。

竞争对手们（如比亚迪、中创新航）则纷纷承诺在未来两年内实现固态电池商业化。

**表面上看，宁德时代在“示弱”——“我们的技术还不够成熟，量产还早。”**

**但孙子的视角完全不同：**

宁德时代在做什么？**“善守者，藏于九地之下。”**

- 宁德时代在固态电池领域已有**10余年的研发积累**，组建了业内领先的研发团队，技术始终处于行业领先地位。
- 其硫化物全固态电池能量密度已突破500Wh/kg，支持15分钟快充至80%，技术水平处于行业第一梯队。
- 宁德时代持有的**固态电池专利数量全球领先**。

曾毓群公开说“量产还早”，实际上是在**降低市场预期、给竞争对手制造“虚假安全感”** ——让对手觉得“宁王也不过如此，我们可以超车”。

而当真正的技术突破和市场时机到来时，宁德时代会怎样？**“善攻者，动于九天之上。”** ——凭借全球领先的专利布局、全产业链优势和庞大的客户网络，瞬间收割市场。

**这就是“守则不足，攻则有余”的完美演绎：**
- 时机不成熟时（技术未到量产阶段）→ **守**，低调积累，不跟对手打嘴仗。
- 时机成熟时（技术突破+市场需求爆发）→ **攻**，凭借积累的优势碾压对手。

> **金句提炼：防守不是懦弱，是在等待最好的进攻时机。真正的高手，90%的时间在“藏”，10%的时间在“打”。**

## 第三章：投资界的“九地之下”——巴菲特的3800亿现金等待

2026年，一个震撼全球资本市场的数字出现了：**伯克希尔·哈撒韦的现金储备飙升至3973.8亿美元，创下61年历史峰值，现金占比高达58.2%，首次彻底超过股票持仓市值**。

95岁的巴菲特在卸任前，给接班人留下了这笔天文数字般的现金。

### 🤔 巴菲特在等什么？

巴菲特的逻辑，正是**“先为不可胜，以待敌之可胜”**的完美实践：

**第一步：先为不可胜**
- 手握近4000亿现金，无论市场怎么跌，伯克希尔都不会“死”。
- 美股巴菲特指标已超过220%，市场风险极高。
- 巴菲特公开表示：**“当前股市未到‘抄底’时刻”** ，公司将继续持有大量现金储备，等待真正有利的买入机会。

**第二步：以待敌之可胜**
- 巴菲特不是在等10%或20%的普通回调，而是在等待一场“崩盘式”的超底机会。
- 他的哲学是：**“宁可错过，也不冒险。”** 

**第三步：胜可知，而不可为**
- 巴菲特知道：只要他手握现金，等市场暴跌时他就能以极低价格买入优质资产——**胜可知**（他能预见自己的优势）。
- 但他不能强迫市场现在就暴跌——**不可为**（他不能控制市场）。

## 第四章：“胜兵先胜”的量化框架——怎么判断自己“已胜”？

孙子给出了全篇最著名、最实操的金句：

> **原文：“故善战者，立于不败之地，而不失敌之败也。是故胜兵先胜而后求战，败兵先战而后求胜。”**

### 🔍 逐字精讲
- **立于不败之地**：把自己放在一个“就算输了也输不了多少”的位置。
- **不失敌之败**：同时不放过敌人犯错的机会。
- **胜兵先胜而后求战**：**常胜将军**——先在庙算中确保自己已经“具备必胜条件”了，然后才出去找敌人打。
- **败兵先战而后求胜**：**常败将军**——先冲出去跟人干一架，打的过程中才想“我怎么才能赢啊？”

### 📋 “先胜”的五个量化指标（2026投资版）

在2026年买入任何一只股票前，请对照以下五个“先胜”指标：

| 指标 | 问题 | 合格标准 | 2026年实操案例 |
| :--- | :--- | :--- | :--- |
| **1. 现金储备** | 你手里有多少“弹药”？ | 至少保留30%现金，不轻易满仓 | 巴菲特58%现金 |
| **2. 止损纪律** | 跌多少你无条件离场？ | 单笔亏损不超过总资金的5% | 顶级游资的“-3%无条件止损” |
| **3. 信息优势** | 你比市场多知道什么？ | 至少能回答“为什么别人不知道这个机会” | 调研半导体设备公司的在手订单 |
| **4. 时间窗口** | 你愿意等多久？ | 至少能持有6个月以上 | 险资的“耐心资本”定位 |
| **5. 安全边际** | 买入价足够便宜吗？ | PE/PB处于历史30%分位以下 | 银行股PB不足0.7倍 |

**如果你5个指标全部达标 → “先胜”已定，可以“求战”。**
**如果有3个以上不达标 → 你现在就是“先战而后求胜”的败兵。**

### 📊 2026年半导体设备的“先胜”案例

2026年，半导体设备板块成为A股最亮的明星之一。

以**盛美上海**为例：公司在2026年第一季度**新签订单同比增长65%** ，维持全年82亿元至88亿元的营收指引。**华海清科**同样“在手订单饱满”，机构上调其2026-2028年业绩预测。

**这些公司为什么涨？因为他们“先胜”了——**
- **先胜条件1**：订单已经签了（胜的条件已具备）→ 业绩确定性高。
- **先胜条件2**：国产替代的大趋势不可逆转（天时已定）→ 行业天花板高。
- **先胜条件3**：技术壁垒极高，竞争对手难以进入（地利已占）→ 护城河深。

**“先胜而后求战”的意思就是：**
> 不是“买了等它涨”（先战而后求胜），而是“它已经具备上涨的所有条件了，我才去买”（先胜而后求战）。

## 第五章：战争与投资的“度量衡”——从土地面积到资金规模

孙子在这一章突然转入一个极其务实的“量化”话题——怎么测量敌我双方的“形”。

> **原文：“地生度，度生量，量生数，数生称，称生胜。”**

### 🔍 逐字精讲
- **地生度**：先测量土地的面积（有多大地方）。
- **度生量**：根据面积估算能产出多少粮食（有多少资源）。
- **量生数**：根据粮食估算能养活多少士兵（有多少兵力）。
- **数生称**：根据兵力对比，称量出谁重谁轻（谁占优势）。
- **称生胜**：根据优劣势对比，得出胜负的结论。

### 🧠 现代翻译（投资版）
这是一条完整的**“从底层数据到最终决策”的量化链条**：

| 孙子概念 | 现代投资翻译 | 2026年实操 |
| :--- | :--- | :--- |
| **地** | 你研究的行业/赛道有多大？ | AI算力、半导体设备、新能源 |
| **度** | 这个行业的市场规模是多少？ | 全球半导体设备市场超1000亿美元 |
| **量** | 这个市场能产生多少营收/利润？ | 国内晶圆厂资本开支保持高位 |
| **数** | 这个行业里有多少家公司在竞争？ | 半导体设备龙头就那几家 |
| **称** | 你选的这家公司在这个行业里排第几？ | 盛美上海清洗设备国际领先 |
| **胜** | 综合以上，你判断能赢吗？ | 订单+技术+趋势 → 结论：能赢 |

### 💼 2026年创业版“度量衡”

假设你想在2026年开一家**AI应用开发公司**：

| 步骤 | 问题 | 你的答案 |
| :--- | :--- | :--- |
| **地** | AI应用的市场有多大？ | 千亿级 |
| **度** | 你能切到多少份额？ | 哪怕是0.1%也是1个亿 |
| **量** | 做这个需要多少资金和人力？ | 需要200万启动资金、10人团队 |
| **数** | 现在有多少竞争对手？ | 有5家做得不错的，但都在不同细分 |
| **称** | 你比竞争对手强在哪？ | 你有独家行业数据，他们没有 |
| **胜** | 综合判断，能打吗？ | 能打，但需要先融资（先胜后战） |

> **金句提炼：拍脑袋决策是赌博，用“度量衡”链条算出来的决策才是科学。先算清楚“地有多大、量有多少、称有多重”，再决定“打不打”。**

## 第六章：“形”的本质——实力是“水”，不可战胜是因为“深”

孙子用了一个极其生动的比喻来总结“形”的本质：

> **原文：“胜者之战民也，若决积水于千仞之溪者，形也。”**

### 🔍 逐字精讲
- **胜者之战民也**：胜利者指挥士兵作战。
- **若决积水于千仞之溪者**：就像在千仞高的山涧上，掘开积蓄已久的积水（水从万丈高崖上倾泻而下）。
- **形也**：这就是“形”的力量——**实力（水）积累到极致 + 地形（高度）占据优势 = 不可阻挡的冲击力。**

### 🧠 现代翻译
- **“积水”** = 你积累的实力（资金、技术、团队、品牌、专利、客户）。
- **“千仞之溪”** = 你占据的有利位置（行业赛道、市场地位、成本优势、技术壁垒）。
- **“决”** = 在最佳时机释放你的实力。

**“形”的本质就是：**
> **你的实力像水一样深，你的位置像山一样高。当你在最佳时机“掘开堤坝”，这股力量根本无人能挡。**

### 📊 2026年宁德时代的“千仞积水”

回到宁德时代的例子：

- **积水**：10余年固态电池研发积累 + 全球领先的专利数量 + 全产业链优势 + 庞大的客户网络。
- **千仞之溪**：全球新能源车渗透率持续提升 + 固态电池是下一代技术制高点 + 政策全力支持。
- **决**：当固态电池技术成熟、市场需求爆发的那一刻，宁德时代“掘开堤坝”——凭借积累的所有优势，瞬间收割市场。

**这就是“形”——你看到的是它“决”的那一瞬间的摧枯拉朽，看不到的是它在此之前的漫长积累。**

### 📊 2026年A股的“形”——半导体设备的“积水”与“决”

2026年上半年，半导体设备板块涨幅惊人。但这不是一夜暴富——这是“形”的积累与释放：

**积水阶段（2023-2025）** ：
- 国内晶圆厂持续扩产，设备订单不断积累。
- 国产替代从“政策口号”变成“实际订单”。
- 各设备龙头持续研发，技术壁垒不断加高。

**决的阶段（2026）** ：

## 第九章：军形篇与前四篇的逻辑串联

至此，前四篇构成了一个完整的“战前四部曲”：

| 篇章 | 核心问题 | 决策输出 | 比喻 |
| :--- | :--- | :--- | :--- |
| **始计篇** | 这仗值不值得打？（定性） | “打”或“不打” | **战略会** |
| **作战篇** | 我打得起吗？（定量/成本） | “速打”或“缓打” | **财务会** |
| **谋攻篇** | 我该怎么用最小的代价打？（方法） | “伐谋/伐交/伐兵/攻城” | **方案会** |
| **军形篇** | 我现在具备“必胜条件”了吗？（时机） | “现在打”或“再等等” | **时机会** |

**串联案例（2026年完整推演）** ：

1. **始计**：你算出AI算力是2026最大风口（五事皆备）→ 决定打。
2. **作战**：你算好自己半年内能承受的最大亏损是20%（日费千金）→ 决定速战速决。
3. **谋攻**：你不直接买高位的算力租赁股，而是“伐谋”——买入算力上游的光模块龙头。
4. **军形**：你观察光模块龙头的“形”——
   - 它在手订单饱满吗？ ✅ 是（先胜条件1）
   - 它的技术壁垒高吗？ ✅ 是（先胜条件2）
   - 行业趋势确定吗？ ✅ 是（先胜条件3）
   - 现在的估值合理吗？ ⚠️ 略高（再等等）
   - **结论**：先胜条件大部分具备，但估值略高 → **“再等等，等一个回调”** （以待敌之可胜）。
