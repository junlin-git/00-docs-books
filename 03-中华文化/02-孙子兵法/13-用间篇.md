> **“用间”不是“搞阴谋”，而是“信息不对称”的终极应用。** 孙子认为，战争胜负的最高决定因素不是兵力、不是地形、不是士气——而是**情报**。花千金去打仗，却舍不得花钱搞情报，是最愚蠢的行为。
>
> 全篇核心就八个字：**五间俱起，上智为间**。

> 本文将用2026年A股的商业秘密窃取案（赛托生物3.2亿索赔、天赐材料8000万赔偿）、内幕交易案（长安汽车罚没1669万、甬金股份实控人获刑）、境外商业间谍案（芯片采购数据泄露）、上市公司举报与虚假信息案（巨力索具蹭热点被罚950万）等真实案例，彻底拆解这套“信息战”的实战框架。


## 第一章：开篇定调——花千金打仗，却舍不得花钱搞情报？

### 原文第一段
> **“孙子曰：凡兴师十万，出征千里，百姓之费，公家之奉，日费千金；内外骚动，怠于道路，不得操事者，七十万家。相守数年，以争一日之胜，而爱爵禄百金，不知敌之情者，不仁之至也，非人之将也，非主之佐也，非胜之主也。”**

### 🔍 逐字精讲

| 原文 | 含义 | 数据 |
| :--- | :--- | :--- |
| **兴师十万，出征千里** | 出动十万大军，远征千里 | 大规模军事行动 |
| **百姓之费，公家之奉，日费千金** | 百姓的耗费、国家的开支，每天花费千金 | 战争是“碎钞机” |
| **内外骚动，怠于道路** | 国内国外都骚动不安，百姓疲于奔命 | 社会成本巨大 |
| **不得操事者，七十万家** | 无法正常从事生产的人，有七十万家 | 间接损失惊人 |
| **相守数年，以争一日之胜** | 对峙好几年，就为了争夺一天的胜利 | 长期消耗 |
| **而爱爵禄百金，不知敌之情者** | 却舍不得花百金去搞情报，不知道敌人的情况 | **因小失大** |
| **不仁之至也，非人之将也** | 这是最不仁义的，不配做将领 | **严厉谴责** |

### 🧠 2026年翻译（A股版）

| 孙子原文 | 2026年A股翻译 |
| :--- | :--- |
| **兴师十万** | 投入100万资金炒股 |
| **日费千金** | 每天的交易成本、时间成本、机会成本 |
| **相守数年，以争一日之胜** | 持有一只股票好几个月，就为了等一波主升浪 |
| **而爱爵禄百金，不知敌之情者** | 却舍不得花时间研究财报、跟踪行业数据、分析资金流向 |
| **不仁之至也** | 这是对自己资金最不负责任的行为 |

> **金句提炼：你愿意花100万去投资，却不愿意花100块买一份深度研报？你愿意每天盯盘4小时，却不愿意每周花2小时研究基本面？这就是“爱爵禄百金，不知敌之情”——因小失大，愚蠢至极。**

### 📊 2026年数据验证

2026年上半年，A股市场5528只股票中**仅1715只上涨，占比31%** ，个股涨跌幅中位数为 **-15.35%** 。79%的散户账户亏损。

**为什么亏？**

不是因为“市场不好”——同样的市场，362只个股翻倍。

**核心原因之一：信息不对称。**

| 群体 | 信息优势 | 结果 |
| :--- | :--- | :--- |
| **机构** | 实地调研、专家访谈、卫星图像、供应链数据 | 赚64%+ |
| **散户** | 看K线、听消息、追热点 | 亏15%+ |

**孙子在2500年前就骂过了：**
> **“不知敌之情者，不仁之至也。”**
>
> **你不知道对手在干什么，就冲进去送死——这是对自己最大的不负责任。**


## 第二章：“五间”详解——五种情报来源，五种打法

### 原文核心
> **“故用间有五：有因间，有内间，有反间，有死间，有生间。五间俱起，莫知其道，是谓神纪，人君之宝也。”**

### 🔍 五种间谍详解（附2026年A股翻译）

| 五间 | 原文 | 含义 | 2026年A股翻译 | 2026年真实案例 |
| :--- | :--- | :--- | :--- | :--- |
| **因间** | 因其乡人而用之 | 利用敌方的当地人做间谍 | **利用行业内部人士的信息** | 券商研究员通过行业专家网络获取产业链信息 |
| **内间** | 因其官人而用之 | 利用敌方的官员/内部人做间谍 | **内幕交易——利用内部信息炒股** | 长安汽车5名员工内幕交易；慈星股份3人内幕交易 |
| **反间** | 因其敌间而用之 | 收买或利用敌方的间谍 | **利用对手的“线人”反向获取信息** | 上市公司反向调查举报者的信息来源 |
| **死间** | 为诳事于外，令吾间知之，而传于敌间 | 故意制造假情报，让我方间谍传给敌方 | **释放虚假信息误导市场** | 巨力索具虚假“商业航天”概念误导投资者 |
| **生间** | 反报也 | 完成任务后能活着回来报告的人 | **实地调研、深度研究后带回真实信息** | 机构研究员实地调研上市公司后出具深度报告 |


## 第三章：“内间”——内部人泄密，杀伤力最大

### 原文
> **“内间者，因其官人而用之。”**

### 🔍 深度解读

“内间”是利用敌方内部人员（官员、将领、亲信）获取情报。**这是五种间谍中杀伤力最大的——因为内部人掌握核心机密。**

### 📊 2026年A股案例一：长安汽车内幕交易案——5人罚没1669万

2026年5月，中证中小投资者服务中心公开通报了一起A股车企重大内幕交易案件。

**案件核心：**

2023年11月25日，长安汽车与华为正式签署《投资合作备忘录》。但在官宣之前的敏感窗口期，**合作双方5名内部员工**利用职务便利，提前获取未公开信息，斥资**6100万元**提前布局套利，非法获利超400万元。

**“内间”的典型特征：**

| 特征 | 本案表现 |
| :--- | :--- |
| **内部人** | 5人全部为合作双方内部在岗员工 |
| **信息优势** | 早于公告发布一个多月便启动建仓 |
| **精准操作** | 交易节奏高度贴合内幕信息形成、发酵全过程 |
| **隐蔽性强** | 单人大额获利、夫妻协同操作 |

**处罚结果：**

| 处罚 | 金额 |
| :--- | :--- |
| 没收违法所得 | 400余万元 |
| 三倍罚款 | 约1200万元 |
| **合计罚没** | **1669万元** |
| 刑事追责 | 案件线索移送公安机关 |

**孙子的警告：**
> **“内间”的杀伤力在于——信息差。内部人知道的事情，外面的人不知道。利用这个信息差获利，本质上就是“内间”。**

## 第四章：“因间”与“反间”——利用行业内部人与反向利用对手

### 原文
> **“因间者，因其乡人而用之。反间者，因其敌间而用之。”**

### 🔍 深度解读

- **因间**：利用对方的本土人/内部人获取信息——这是最基础的情报手段。
- **反间**：发现并利用对方的间谍，反过来为自己服务——这是最高级的情报手段。

### 📊 2026年商业案例一：赛托生物前员工窃密案——“因间”的典型

| 角色 | 身份 | 行为 |
| :--- | :--- | :--- |
| **常尊学** | 赛托生物联合实验室负责人、沈阳研发中心负责人 | 指使团队成员窃取技术秘密，离职后成立沈阳博泰 |
| **刘亮、刘艳玲** | 赛托生物前核心员工 | 以不正当手段获取技术秘密，构成侵犯商业秘密罪 |

**“因间”的逻辑：**
> **利用对方的核心人员（“乡人”）获取核心信息（技术秘密），然后“另立山头”直接竞争。**

赛托生物的核心技术研发团队带头人，深度参与了公司多项核心涉密技术的研发与落地，全面掌握公司高端甾体药物中间体的生产工艺、技术配方、量产参数等核心商业秘密。然后带着这些技术离职，成立竞品公司。

**这比外部间谍更可怕——因为他是“自己人”。**

## 第五章：“死间”——虚假信息，诱敌深入

### 原文
> **“死间者，为诳事于外，令吾间知之，而传于敌间。”**

### 🔍 深度解读

“死间”是故意制造虚假情报，让我方间谍（假装）泄露给敌方——**用假信息引导对手做出错误决策。**

### 📊 2026年A股案例：巨力索具的“商业航天”谎言

2026年，巨力索具（002342）上演了一场教科书级的“死间”——**用虚假信息误导市场，吸引投资者高位接盘。**

**时间线：**

| 时间 | 事件 |
| :--- | :--- |
| 2025年12月15日 | 投资者在互动易询问是否为长征十二号甲提供产品 |
| 12月16日 | 公司回复称“在商业航天领域为国内可回收火箭提供了产品支持” |
| 2026年1月4日 | 公司回复称产品“在箭体发射前的安装调试、转运以及地面回收等环节已有代表性应用” |
| 2026年2月11日 | 股价从7.25元涨至19.06元，涨幅162.9% |
| 2026年2月12日 | 经监管督促，公司披露：商业航天订单仅996.51万元，收入占比低于0.50% |
| 2026年5月13日 | 证监会立案调查 |
| 2026年6月26日 | 河北证监局拟罚款合计950万元 |

**“死间”的逻辑：**

| 步骤 | 操作 | 结果 |
| :--- | :--- | :--- |
| **制造假情报** | 公司发布关于“商业航天”的误导性回复 | 市场以为它是“商业航天概念股” |
| **让“间谍”传播** | 互动易平台公开回复，信息迅速扩散 | 散户、游资蜂拥而入 |
| **诱导对手犯错** | 23.51万户投资者在高位接盘 | 超10万股民在概念炒作高位入场 |
| **泡沫破裂** | 真相曝光，股价连续跌停 | 市值蒸发近70亿 |

> **金句提炼：巨力索具的“商业航天”谎言，就是现代版的“死间”——用虚假信息诱导市场，让无数投资者在高位接盘。但监管的“反间”越来越快：从立案到处罚仅44天。**


## 第六章：“生间”——活着回来，带回真相

### 原文
> **“生间者，反报也。”**

### 🔍 深度解读

“生间”是完成任务后能活着回来、带回真实情报的人。**这是最珍贵的情报来源——因为信息是真实的、一手的、可验证的。**

### 📊 2026年投资版：实地调研与深度研究

在A股市场，“生间”就是**那些愿意花时间做实地调研、深度研究的投资者和研究员。**

| “生间”行为 | 价值 |
| :--- | :--- |
| **实地调研上市公司** | 看到工厂开工率、库存水平、员工士气 |
| **访谈行业专家** | 了解产业链真实情况、竞争格局 |
| **分析财务报表细节** | 发现隐藏的风险和机会 |
| **跟踪上下游数据** | 提前预判行业拐点 |

### 📊 2026年案例：外资机构的“生间”优势

2026年上半年，北向资金一季度净买入**3274亿元**，创同期历史新高。截至2026年5月底，境外投资者持有A股流通市值已**超过4万亿元**，较2025年底实现万亿级增量。

**外资为什么敢买？**

因为他们做了“生间”的工作：
- 实地调研中国科技企业
- 跟踪半导体设备国产化率从16%升至21%
- 分析一季报科技行业盈利同比增速54%-123%

**散户为什么不敢买？**

因为他们没有做“生间”的工作：
- 看K线、听消息、追热点
- 不知道真实的产业趋势
- 不知道业绩在兑现

> **金句提炼：生间的价值在于“真实”——花时间去研究、去验证、去跟踪。没有“生间”的投资，就是盲人摸象。**


## 第七章：“上智为间”——最高级的情报，来自最高级的智慧

### 原文核心
> **“故惟明君贤将，能以上智为间者，必成大功。此兵之要，三军之所恃而动也。”**

### 🔍 深度解读

孙子说：**只有英明的君主、贤能的将领，能够用最高智慧的人去做间谍，才能成就大功。**

**“上智为间”不是“派间谍”，而是“用智慧获取信息”。**

- 低级的间谍：偷文件、偷拍、收买
- 高级的间谍：分析、推理、判断

**最高级的情报，不是“偷”来的，而是“算”出来的。**

### 🧠 2026年翻译

| 低级“间谍” | 高级“上智为间” |
| :--- | :--- |
| 听消息、跟风、抄作业 | 自己研究、自己分析、自己判断 |
| 看K线、数浪、追热点 | 看基本面、看产业趋势、看资金流向 |
| 信“大V”、信“内幕”、信“这次不一样” | 信数据、信逻辑、信常识 |

### 📊 2026年案例：半导体国产化率的“上智为间”

2026年上半年，半导体板块A股市值从6.6万亿元飙升至14.14万亿元，**半年实现翻倍式增长**。

**哪些人赚到了这笔钱？**

不是那些“偷”到内幕消息的人——内幕交易的人都被罚了。

是那些**用“上智”算出趋势的人**：

| “上智”分析 | 结论 |
| :--- | :--- |
| 半导体设备国产化率从16%升至21% | 国产替代在加速 |
| 国内晶圆厂资本开支保持高位 | 设备需求确定 |
| 中芯国际N+2产线持续扩产 | 产能释放确定 |
| 美国制裁持续加码 | 国产替代不可逆转 |

**这些信息不是“偷”来的，是“算”出来的。** 任何一个愿意花时间研究的人都能得到这些信息。

> **金句提炼：最高级的“间谍”，不是偷情报的人，而是能从公开信息中“算”出真相的人。**
