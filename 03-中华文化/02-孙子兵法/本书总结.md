# 《孙子兵法》全书总结 —— 十三篇逻辑链与终极决策框架

> 全书13篇不是13个孤立的话题，而是一条**严密的因果传导链**：从"要不要打"到"怎么打"，从"打哪里"到"怎么赢"，从"常规战"到"信息战"，层层递进，环环相扣。孙子用2500年前的军事语言，构建了人类历史上最早的**全维度战略决策系统**。

## 二、13篇逻辑链——从"算"到"间"的完整传导

### 第一阶段：战前三部曲（要不要打？打得起吗？怎么打？）

```
始计篇（算胜率）→ 作战篇（算成本）→ 谋攻篇（选方法）
     "打不打"         "打得起吗"        "怎么打"
```

**逻辑传导：**
1. **始计篇**用"五事七计"算出胜率，决定"打"还是"不打"。
2. 如果决定打，**作战篇**立刻算账：每天花多少钱、能撑多久、粮草从哪来。**算不过去就不打——即便战略正确，没钱也会输。**
3. 钱够、时间够，进入**谋攻篇**：选择"伐谋/伐交/伐兵/攻城"哪条路径。**优先伐谋，绝不轻易攻城。**

> **核心逻辑**：先定性（值不值得）→ 再定量（打不打得起）→ 最后定方案（用什么方法）。三层递进，任何一层算不过去就停。

---

### 第二阶段：战机四部曲（什么时候打？怎么出手？打哪里？怎么抢？）

```
军形篇（等时机）→ 兵势篇（蓄势出击）→ 虚实篇（选目标）→ 军争篇（抢速度）
     "等"            "出"            "击"          "抢"
```

**逻辑传导：**
4. 方法定好了，**军形篇**告诉你：不要急着出手，先"立于不败之地"，等对手露出破绽。**时机不到，忍如磐石。**
5. 时机到了，**兵势篇**教你如何"蓄势"和"释放"：用"正兵"稳住正面，用"奇兵"打出致命一击。**势如彍弩，节如发机。**
6. 出手时，**虚实篇**指明打击方向：不要跟对手的强项硬碰硬，专打他的软肋。**避实击虚，因敌制胜。**
7. 目标选定后，**军争篇**解决速度问题：以迂为直（走别人不走的路反而最快），用"风林火山"四种节奏灵活切换。**后人发，先人至。**

> **核心逻辑**：等得到（时机）→ 蓄得满（势能）→ 看得准（目标）→ 抢得先（速度）。四步合一，一气呵成。

---

### 第三阶段：应变三部曲（情况变了怎么办？怎么看清环境？不同地形怎么打？）

```
九变篇（随机应变）→ 行军篇（侦察部署）→ 地形篇（六形六败）
     "变"             "察"            "地"
```

**逻辑传导：**
8. 战场上一切都在变，**九变篇**教你不死守任何教条："途有所不由，军有所不击"——学会放弃；"智者之虑，必杂于利害"——两面都看到。**前七篇是剑谱，第九篇是忘掉剑谱。**
9. 面对变化，你首先要**看清环境**。**行军篇**教你"处军相敌"：四种地形（山地/水地/沼泽/平陆）四种部署，32种"相敌"法从细节看透对手。**高手靠"看"不靠"猜"。**
10. 看清了敌情，还要看清**地形**。**地形篇**把战场分为六种（通/挂/支/隘/险/远），每种地形打法完全不同。同时警告"六败"——六种将领的致命错误。**"地形者，兵之助也"——地形只是辅助，胜负在人。**

> **核心逻辑**：会变（不死板）→ 会看（侦察清）→ 会用地（地形对）。三步联动，灵活制胜。

---

### 第四阶段：环境与非常规（不同战场心理怎么打？非常规手段怎么用？）

```
九地篇（九种战场心理）→ 火攻篇（非常规打击+情绪管理）
     "境"                "火"
```

**逻辑传导：**
11. **九地篇**把视角从"物理地形"拉升到"战场心理"：散地、轻地、争地、交地、衢地、重地、圮地、围地、死地——九种环境，九种心理，九种打法。**"九地之变，屈伸之利，人情之理"——环境变了，人的心理就变了；心理变了，打法就要变。**
12. 当常规手段不够用，**火攻篇**教你用"非常规打击"（五种火攻），但紧接着给出全书最严厉的警告：**"主不可以怒而兴师，将不可以愠而致战。"——任何决策的唯一标准是"利"，不是"情绪"。**

> **核心逻辑**：懂心理（九地）→ 慎非常规（火攻）+ 慎情绪（戒怒）。前者教你读懂环境心理，后者教你管理自己的情绪。

---

### 第五阶段：信息战（最高级的情报是"算"出来的）

```
用间篇（五间俱起，上智为间）
     "间"
```

**逻辑传导：**
13. 全书收官，**用间篇**揭示最终决定因素：**情报**。花千金打仗却舍不得花钱搞情报，是"不仁之至"。五种间谍（因间/内间/反间/死间/生间），最高级的是"上智为间"——不是偷情报，而是从公开信息中**算**出真相。**"此兵之要，三军之所恃而动也"——全军行动都依赖情报。**

> **核心逻辑**：一切决策的基础是信息。没有情报支撑的"庙算"是空谈，没有情报支撑的"出击"是送死。

## 三、13篇完整决策时间线（一个完整推演）

用2026年A股投资为案例，串联全篇：

| 步骤 | 篇章 | 核心问题 | 决策输出 | 2026年实操 |
| :--- | :--- | :--- | :--- | :--- |
| **1** | 始计 | 值不值得打？ | "打"或"不打" | AI算力是2026最大风口 → 决定打 |
| **2** | 作战 | 打得起吗？ | "速打"或"缓打" | 半年内能承受最大亏损20% → 速战速决 |
| **3** | 谋攻 | 怎么用最小代价打？ | 伐谋/伐交/伐兵/攻城 | 不买算力租赁股，买上游光模块龙头 → 伐谋 |
| **4** | 军形 | 具备必胜条件了吗？ | "现在打"或"再等等" | 光模块龙头在手订单饱满 → 先胜条件具备 |
| **5** | 兵势 | 怎么出手？ | 正兵稳、奇兵狠 | 一半底仓（正）+一半机动（奇）→ 正奇结合 |
| **6** | 虚实 | 打对手哪里？ | 避实击虚 | 板块回调时买入 → 击虚 |
| **7** | 军争 | 怎么抢在前面？ | 以迂为直、风林火山 | 找同一赛道未发掘的细分标的 → 以迂为直 |
| **8** | 九变 | 情况变了怎么办？ | 随机应变、杂于利害 | 中报不及预期立即止损 → 随机应变 |
| **9** | 行军 | 怎么观察敌情？ | 处军相敌 | 看北向资金流向、龙虎榜 → 相敌 |
| **10** | 地形 | 不同地形怎么打？ | 六形六败 | 半导体是"通形"顺势，ST是"挂形"不碰 → 用对地形 |

| **12** | 火攻 | 非常规手段怎么用？ | 慎战戒怒 | 不因情绪追高，不因恐慌割肉 → 合于利而动 |
| **13** | 用间 | 情报怎么获取？ | 五间俱起、上智为间 | 从公开信息中"算"出国产替代趋势 → 上智为间 |

## 六、一句话总结全书

> **孙子兵法13篇，讲到底就是一件事：用理性的计算代替血与火的试错，让你永远只打必胜的仗。**

- 前3篇解决"要不要打、打不打得起、怎么打"——**决策前的理性**。
- 第4-7篇解决"什么时候打、怎么出手、打哪里、怎么抢"——**执行中的精准**。
- 第8-11篇解决"情况变了怎么办、怎么看清环境、不同地形怎么打"——**应变中的灵活**。
- 第12篇解决"非常规手段怎么用+情绪怎么管"——**极端时的克制**。
- 第13篇解决"信息怎么获取"——**一切决策的底层基石**。

**始计是起点，用间是终点，知己知彼贯穿始终。**
