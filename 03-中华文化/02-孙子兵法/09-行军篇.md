# 《孙子兵法·行军篇》超详细深度解读 —— 处军相敌，择人而任

> 本篇导读：前七篇，孙子教我们“算”（始计）、“耗”（作战）、“谋”（谋攻）、“等”（军形）、“势”（兵势）、“虚实”（避实击虚）和“争”（军争）。第八篇“九变”教我们“随机应变”。到了第九篇“行军”，孙子把视角从“怎么打”拉回到“怎么走”和“怎么看”。
>
> **“行军”不是“行军打仗”的那个“行军”，而是“军队在行进和驻扎中如何观察敌情、如何选择地形”。** 全篇分两大块：**上卷讲“处军”——军队在不同地形下该怎么部署；下卷讲“相敌”——通过32种细节观察判断敌情**。
>
> 全篇核心就八个字：**处军相敌，择人而任**。
>
> 本文将用2026年A股的极致K型分化、外资的“杠铃策略”、43家上市公司被立案调查、13家公司退市、新能源车价格战退潮等真实案例，彻底拆解这套“行军侦察”的实战框架。


## 第一章：开篇定调——行军不是走路，是侦察与部署

### 原文第一段
> **“孙子曰：凡处军相敌，绝山依谷，视生处高，战隆无登，此处山之军也。绝水必远水，客绝水而来，勿迎之于水内，令半济而击之，利。欲战者，无附于水而迎客，视生处高，无迎水流，此处水上之军也。绝斥泽，惟亟去无留，若交军于斥泽之中，必依水草而背众树，此处斥泽之军也。平陆处易，而右背高，前死后生，此处平陆之军也。凡此四军之利，黄帝之所以胜四帝也。”**

### 🔍 逐字精讲

孙子把地形分为四种：山地、水地、沼泽地、平陆地。每种地形的部署原则完全不同：

| 地形 | 部署原则 | 现代翻译 |
| :--- | :--- | :--- |
| **山地** | 绝山依谷，视生处高，战隆无登 | 在山谷中行军，在高处驻扎，不要仰攻高地 |
| **水地** | 绝水必远水，半济而击之 | 渡河后远离水域，等敌人渡到一半时攻击 |
| **沼泽** | 惟亟去无留，依水草而背众树 | 快速通过不要停留，靠近水草、背靠树林 |
| **平陆** | 处易而右背高，前死后生 | 在平坦处驻扎，右侧背靠高地 |

### 🧠 核心逻辑：**不同的“地形”，需要不同的“姿势”**

孙子不是教你背口诀，而是教你一个思维：**环境变了，你的部署必须跟着变。**

**在A股，不同的“地形”就是不同的市场环境：**

| A股“地形” | 特征 | 正确的“部署” |
| :--- | :--- | :--- |
| **山地（牛市/主升浪）** | 趋势向上，情绪亢奋 | “视生处高”——顺势而为，不要轻易做空，但“战隆无登”——不要追到山顶 |
| **水地（震荡/分歧）** | 多空拉锯，方向不明 | “绝水必远水”——不要在水边（震荡区）恋战，“半济而击”——等方向明确再出手 |
| **沼泽（熊市/流动性危机）** | 全面下跌，泥沙俱下 | “惟亟去无留”——快速离场，不要抄底 |
| **平陆（横盘/磨底）** | 不上不下，消磨耐心 | “前死后生”——前面是死地后面是生地，等突破方向确认再行动 |

### 📊 2026年A股案例一：四种“地形”同时存在

2026年上半年，A股市场出现了罕见的“四地形并存”：

- **科创50（山地）** ：暴涨64.25%，趋势向上——“视生处高”，顺势而为的人大赚。
- **上证50（平陆）** ：微跌1.38%，横盘震荡——“前死后生”，方向不明，等突破再动。
- **消费板块（沼泽）** ：商贸零售跌29.42%，农林牧渔跌25.26%——“惟亟去无留”，快速离场的人少亏，死扛的人深套。
- **ST板块（死地）** ：224只ST股，13家公司退市——“死地则战”，但大部分是“战死”而非“战胜”。

> **金句提炼：同一个市场，不同的板块就是不同的“地形”。在山地要用山地的打法，在沼泽要用沼泽的打法——用错地形，必败无疑。**


## 第二章：“相敌三十二法”——从32个细节看透对手

这是《行军篇》最精彩的部分。孙子一口气给了32条“相敌”之法——通过观察敌人的各种细微迹象，判断其真实状态。

### 原文核心段落（精选部分）
> **“敌近而静者，恃其险也；远而挑战者，欲人之进也；其所居易者，利也。众树动者，来也；众草多障者，疑也；鸟起者，伏也；兽骇者，覆也。尘高而锐者，车来也；卑而广者，徒来也；散而条达者，樵采也；少而往来者，营军也。辞卑而益备者，进也；辞强而进驱者，退也；轻车先出居其侧者，陈也；无约而请和者，谋也；奔走而陈兵车者，期也；半进半退者，诱也。”**

### 🔍 32条“相敌法”分类详解（附2026年翻译）

孙子把观察敌情分成了几大类。我们挑选最核心的15条，直接翻译成2026年的投资语言：

#### 第一类：通过“动静”判断意图

| 观察现象 | 孙子的判断 | 2026年A股翻译 |
| :--- | :--- | :--- |
| **敌近而静者，恃其险也** | 敌人靠近却很安静，是依仗地形险要 | 股价在高位横盘缩量——主力在“恃险”，筹码集中，不急于拉升 |
| **远而挑战者，欲人之进也** | 敌人远来挑战，是想引诱你进攻 | 游资在低位拉一个涨停——是想引诱散户跟风接盘 |
| **其所居易者，利也** | 敌人驻扎在平坦处，是觉得有利可图 | 机构大量买入某板块——是看到了业绩确定性 |

#### 第二类：通过“环境变化”判断敌情

| 观察现象 | 孙子的判断 | 2026年A股翻译 |
| :--- | :--- | :--- |
| **众树动者，来也** | 树林摇动，敌人来了 | 板块突然放量——主力资金进场了 |
| **鸟起者，伏也** | 鸟惊飞，有伏兵 | 某只股票突然拉长阳——可能是有“伏兵”（潜伏资金）在发动 |
| **兽骇者，覆也** | 野兽惊逃，有大部队 | 市场突然放量暴跌——可能是“大部队”（机构/量化）在撤退 |

#### 第三类：通过“尘土”判断兵种和规模

| 观察现象 | 孙子的判断 | 2026年A股翻译 |
| :--- | :--- | :--- |
| **尘高而锐者，车来也** | 尘土高而尖，战车来了 | 成交额突然暴增——大资金（“战车”）进场了 |
| **卑而广者，徒来也** | 尘土低而广，步兵来了 | 成交额温和放大——散户（“步兵”）在进场 |

#### 第四类：通过“言辞”判断虚实

| 观察现象 | 孙子的判断 | 2026年A股翻译 |
| :--- | :--- | :--- |
| **辞卑而益备者，进也** | 言辞谦卑但备战更充分——是要进攻了 | 上市公司发公告说“经营正常”——但高管在偷偷增持——要涨了 |
| **辞强而进驱者，退也** | 言辞强硬且假装进攻——是要撤退了 | 上市公司发公告说“业绩大好”——但大股东在偷偷减持——要跌了 |
| **无约而请和者，谋也** | 没有约定却主动求和——有阴谋 | 竞争对手突然示好——可能是在麻痹你，背后有动作 |

#### 第五类：通过“士兵状态”判断士气

| 观察现象 | 孙子的判断 | 2026年A股翻译 |
| :--- | :--- | :--- |
| **杖而立者，饥也** | 士兵拄着兵器站立——是饿了 | 股价缩量滞涨——多头“饿了”（没资金了） |
| **汲而先饮者，渴也** | 打水的人自己先喝——是渴了 | 主力自己先买入——是“渴了”（急着建仓） |
| **见利而不进者，劳也** | 见到好处却不进攻——是累了 | 出了利好股价却不涨——多头“累了”（已透支） |
| **鸟集者，虚也** | 鸟在营地聚集——是空营 | 股价低位但无人问津——是“虚”的（没人关注，可能是机会） |
| **夜呼者，恐也** | 夜里有人惊呼——是恐惧 | 盘后突然出现利空传闻——是有人在制造恐慌 |
| **军扰者，将不重也** | 军队骚乱——是将领没有威信 | 公司内部动荡——是管理层出了问题 |
| **旌旗动者，乱也** | 旗帜乱动——是队伍混乱 | 龙虎榜上机构席位乱战——是多空分歧巨大 |
| **吏怒者，倦也** | 军官发怒——是疲惫了 | 基金经理频繁发声、情绪激动——是压力太大了 |
| **杀马肉食者，军无粮也** | 杀马吃肉——是没有粮食了 | 公司开始卖资产、质押股权——是现金流枯竭了 |
| **军无悬缶者，不返其舍者，穷寇也** | 不敲锅、不回营——是走投无路了 | 股价连续跌停、无人接盘——是“穷寇”（流动性枯竭） |

## 第三章：“令之以文，齐之以武”——用文化凝聚，用制度约束

### 原文核心
> **“故令之以文，齐之以武，是谓必取。令素行以教其民，则民服；令不素行以教其民，则民不服。令素行者，与众相得也。”**

### 🔍 逐字精讲
- **令之以文**：用文化、道理、情感来教育感化士兵（“文”=软性的东西）。
- **齐之以武**：用制度、纪律、刑罚来统一约束士兵（“武”=硬性的东西）。
- **令素行以教其民**：平时就严格执行法令来训练士兵。
- **令不素行以教其民**：平时不执行法令，临时抱佛脚。
- **与众相得也**：将领和士兵之间相互信任、相互配合。

### 🧠 现代翻译（企业管理+投资）

| 维度 | “文”（软实力） | “武”（硬制度） |
| :--- | :--- | :--- |
| **企业管理** | 企业文化、愿景、价值观 | KPI、考核、奖惩制度 |
| **投资纪律** | 投资理念、信仰、心态 | 止损线、仓位上限、买卖规则 |
| **团队管理** | 关心员工、建立信任 | 明确的汇报线、责任分工 |

**孙子的核心观点：**

> **“文”和“武”缺一不可。只有“文”没有“武”，团队会松散；只有“武”没有“文”，团队会冷漠。必须两手都硬。**

### 📊 2026年A股案例：证监会的“文”与“武”

2026年，证监会在资本市场治理上同时用了“文”和“武”：

**“武”（硬制度）：**
- 2026年上半年，**43家A股公司被立案调查**。
- 集中开展三轮专项行动，累计查办财务造假案件**247起**，作出行政处罚**156起**，罚没**90.51亿余元**，**21家**严重造假公司被强制退市。
- 上半年**13家公司摘牌**，ST股扩容至**224只**。

**“文”（软治理）：**
- 证监会部署“打击和防范上市公司财务造假专项行动”。
- 推动先行赔付机制，支持各类民事诉讼84件，泽达易盛、广道数字等案先行赔付投资者近5亿元。
- 加快建设财务舞弊非现场监测和发现中心。

**“令素行”的效果：**
- 退市数量虽与去年同期持平，但“排雷”进程在加速。
- 市场“有进有出、优胜劣汰”的生态闭环正在加速形成。

> **金句提炼：好的制度（武）+好的文化（文）= 好的结果。缺了任何一个，都是“令不素行”——平时不严，临时再严也没用。**


## 第四章：“卒未亲附而罚之，则不服”——先爱后罚，先亲后严

### 原文核心
> **“卒未亲附而罚之，则不服，不服则难用也；卒已亲附而罚不行，则不可用也。故令之以文，齐之以武，是谓必取。”**

### 🔍 逐字精讲
- **卒未亲附而罚之，则不服**：士兵还没亲近你、信任你，你就处罚他——他会不服气，不服气就不会为你卖命。
- **卒已亲附而罚不行，则不可用**：士兵已经亲近你了，但你该罚的时候不罚——队伍就废了，没法用了。

### 🧠 管理的“先后顺序”

孙子的逻辑非常清晰：

> **第一步：先“亲附”（建立信任和情感连接）。**
> **第二步：再“罚之”（执行制度和纪律）。**
>
> **顺序不能反。先罚后亲 → 怨恨；先亲后罚 → 敬畏。**

### 📊 2026年商业案例：新能源车企的“先亲后罚”

2026年，新能源车市的价格战全面退潮。车企从“拼价格”转向“拼保障”。

| 阶段 | 做法 | 兵法对应 |
| :--- | :--- | :--- |
| **第一阶段（先亲）** | 用技术、服务、品质赢得用户信任 | “卒已亲附”——用户信任品牌了 |
| **第二阶段（后罚）** | 上调售价、收紧优惠 | “罚之”——该赚钱的时候要赚钱 |

2026年一季度，四大头部自主品牌成交均价全部上涨。比亚迪成交均价稳定在16万元。行业从“价格战”转向“价值战”。

**为什么用户接受涨价？**
- 因为车企先用技术和品质“亲附”了用户（“文”）。
- 然后才上调价格（“武”）。
- **“先亲后罚”——用户服气。**

> **金句提炼：先让员工/客户/用户认可你、信任你，然后再提要求、定规矩。顺序对了，一切顺；顺序错了，一切乱。**


## 第五章：“托之以利”——用利益来检验人心

### 原文核心
> **“令素行者，与众相得也。”**

这句话的意思是：平时就能严格执行法令的将领，和士兵之间是相互信任、相互配合的。

### 🧠 深层逻辑：**信任不是靠嘴巴说的，是靠行动证明的。**

- 平时对士兵好（“文”），战时严格要求（“武”）——士兵服你。
- 平时对士兵不好，战时突然严格要求——士兵不服你。
- “与众相得”——将领和士兵之间建立了一种“默契”，不需要多说，大家心照不宣。

### 📊 2026年商业案例：外资的“与众相得”

2026年，外资机构对A股的态度发生了显著转变——从“观望”转向“实质布局”。

**为什么外资信任A股了？**

| 信任的来源 | 具体表现 |
| :--- | :--- |
| **制度完善（“武”）** | 退市常态化、财务造假严惩、信息披露强化 |
| **业绩兑现（“文”）** | 科技行业一季度盈利同比增速54%-123% |
| **政策明确（“信”）** | “十五五”规划科技自立自强方向清晰 |

**结果：**
