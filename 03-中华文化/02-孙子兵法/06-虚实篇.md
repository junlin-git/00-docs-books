# 《孙子兵法·虚实篇》超详细深度解读 —— 避实击虚，因敌制胜

> 本篇导读：前五篇，孙子教我们“算”（始计）、“耗”（作战）、“谋”（谋攻）、“等”（军形）和“势”（兵势）。如果你已经算过了、耗得起、找到了最优策略、等到了最佳时机、也准备好了“正奇结合”的打法——现在进入最核心的实战环节。**第六篇“虚实”是孙子兵法的“战术天花板”。** 它告诉你：**不要跟对手的强项硬碰硬，要打他的软肋；不要用固定的套路，要随机应变。** 全篇核心就八个字：**避实击虚，因敌制胜。** 本文将用2026年A股的极致分化行情、北向资金的“杠铃策略”、游资“陈小群”的收割套路、宁德时代与比亚迪的双雄对决等真实案例，彻底拆解这套“致人而不致于人”的顶级智慧。


## 第一章：开篇定调——“致人而不致于人”

### 原文第一段
> **“孙子曰：凡先处战地而待敌者佚，后处战地而趋战者劳。故善战者，致人而不致于人。”**

### 🔍 逐字精讲
- **先处战地而待敌者佚**：先到达战场、以逸待劳的一方，从容不迫（佚 = 安逸）。
- **后处战地而趋战者劳**：后到达战场、匆忙应战的一方，疲惫不堪（劳 = 劳累）。
- **致人而不致于人**：**调动敌人而不被敌人调动**——这是全篇最核心的一句话。

### 🧠 现代翻译（投资版）

| 古代概念 | 现代投资翻译 | 2026年实操 |
| :--- | :--- | :--- |
| **先处战地** | 提前布局、埋伏等待 | 在板块启动前就建仓，而不是涨起来后追高 |
| **待敌者佚** | 以逸待劳，心态从容 | 持仓成本低，不怕震荡，拿得住 |
| **后处战地** | 追高进场、匆忙买入 | 看到别人赚钱了才冲进去 |
| **趋战者劳** | 被动挨打，焦虑不安 | 高位接盘，一跌就慌，一涨就追 |
| **致人** | **主动布局，让市场按你的节奏走** | 设置好买入区间和止损线，等待价格进入你的“伏击圈” |
| **致于人** | **被市场牵着鼻子走** | 天天看盘、追涨杀跌、被情绪支配 |

### 📊 2026年A股现实映射

2026年上半年，A股呈现极致的“K型分化”：**科创50暴涨64.25%，创业板指大涨35.58%，但全市场5528只个股中仅1715只上涨，占比仅31%，接近七成个股录得下跌**。

**谁是“致人”的？**
- 那些在2025年底就布局半导体、AI算力的机构——他们**先处战地**，以逸待劳，上半年赚得盆满钵满。

**谁是“致于人”的？**
- 那些在2026年3-4月看到科技股暴涨后才追进去的散户——他们**后处战地**，匆忙应战，结果很多人在5-6月的回调中被套。

> **金句提炼：高手在无人问津时布局，在万人追捧时离场。被市场情绪牵着走的人，永远是被收割的一方。**


## 第二章：“避实击虚”的精髓——出其不意，攻其无备

### 原文第二段
> **“能使敌人自至者，利之也；能使敌人不得至者，害之也。故敌佚能劳之，饱能饥之，安能动之。出其所不趋，趋其所不意。行千里而不劳者，行于无人之地也；攻而必取者，攻其所不守也；守而必固者，守其所不攻也。”**

### 🔍 逐字精讲
- **能使敌人自至者，利之也**：能让敌人自己送上门来，是用**利益**引诱了他。
- **能使敌人不得至者，害之也**：能让敌人不敢来，是用**威胁**吓退了他。
- **故敌佚能劳之，饱能饥之，安能动之**：敌人安逸就让他疲劳，敌人吃饱就让他饥饿，敌人安稳就让他骚动。
- **出其所不趋，趋其所不意**：出击敌人不去的地方，奔袭敌人意想不到的方向。
- **行千里而不劳者，行于无人之地也**：行军千里还不累，是因为走的是没有敌人的路。
- **攻而必取者，攻其所不守也**：进攻一定能拿下，是因为攻击的是敌人没防守的地方。
- **守而必固者，守其所不攻也**：防守一定稳固，是因为防守的是敌人不会攻击的地方。

### 🧠 现代翻译

**核心逻辑只有一句话：**
> **打对手没防备的地方，守对手不会打的地方。**

### 📊 2026年A股案例一：北向资金的“杠铃策略”

2026年6月以来，北向资金连续多个交易日净流入，累计净买入规模超过150亿元。截至2026年5月底，境外投资者持有A股总市值已超过4万亿元，较2025年底实现**万亿级增量**。

外资机构采用的是**“杠铃策略”** ：

| “杠铃”的一端 | “杠铃”的另一端 |
| :--- | :--- |
| **科技成长 + 新质生产力**（进攻） | **高股息 + 优质资产**（防守） |
| 电子、计算机、半导体 | 银行、电力、公用事业 |
| 一季度盈利同比增速54%-123% | 股息率5%+，十年期国债仅1.8% |

**这就是孙子的“避实击虚”：**
- 不在所有人都拥挤的板块里硬拼（回避“实”）。
- 而是在“科技成长”和“高股息防御”两端同时布局（抓住“虚”和“实”的平衡）。
- 当科技股涨多了，有高股息资产兜底；当市场恐慌时，有科技仓位进攻。

> **金句提炼：不要把鸡蛋放在一个篮子里——这是散户的常识。在多个篮子里放不同种类的鸡蛋——这才是高手的“虚实结合”。**

### 📊 2026年A股案例二：游资“陈小群”的“虚实”收割术

2026年1月，商业航天板块剧烈震荡，一个叫“陈小群”的名字被推上风口浪尖。

**游资的“虚实”操作流程：**

| 步骤 | 操作 | 兵法对应 |
| :--- | :--- | :--- |
| **第一步** | 游资先低位建仓 | **“先处战地”** ——提前埋伏 |
| **第二步** | 拉出涨停，主动上龙虎榜 | **“利之也”** ——用赚钱效应引诱散户 |
| **第三步** | 同花顺、东方财富等平台给席位打上“陈小群”标签 | **“造势”** ——制造“虚”的权威感 |
| **第四步** | 散户看到“陈小群”上榜，第二天无脑跟风 | **“致人”** ——调动散户跟风 |
| **第五步** | 游资在高位出货，散户接盘 | **“攻其所不守”** ——攻击散户的风控盲区 |

据调查，中国银河证券大连黄河路营业部上榜后次日，相关个股**平均涨幅超4%**，部分标的甚至直接“一字”涨停开盘。但1月15日，前期强势的雷科防务遭遇**“3连”跌停**，该席位净卖出3.58亿元。

**散户以为自己在追“实”（跟着顶级游资赚钱），其实追的是“虚”（被精心包装的收割陷阱）。**

> **孙子的警告：“能使敌人自至者，利之也。”——游资用“利”（涨停、赚钱效应）引诱散户“自至”（主动跟风），然后在高位完成收割。**


## 第三章：“形人而我无形”——让对手看不清你，你把对手看透

### 原文核心段落
> **“故形人而我无形，则我专而敌分。我专为一，敌分为十，是以十攻其一也，则我众而敌寡。能以众击寡者，则吾之所与战者约矣。吾所与战之地不可知，不可知则敌所备者多，敌所备者多，则吾所与战者寡矣。”**

### 🔍 逐字精讲
- **形人而我无形**：让敌人的“形”暴露出来，而我的“形”隐藏起来。
- **我专而敌分**：我集中兵力，敌人分散兵力。
- **我专为一，敌分为十，是以十攻其一也**：我10个人打他1个人——以多胜少。
- **吾所与战之地不可知**：我到底要在哪里打，敌人不知道。
- **不可知则敌所备者多**：敌人不知道，就要处处设防——兵力被分散。
- **敌所备者多，则吾所与战者寡矣**：敌人防备的地方越多，每个地方的兵力就越少——我集中打他一个点，他就扛不住。

### 🧠 现代翻译（投资版）

| 孙子概念 | 现代投资翻译 | 2026年实操 |
| :--- | :--- | :--- |
| **形人** | 让对手暴露持仓、暴露意图 | 通过龙虎榜、大宗交易、股东增减持等公开信息判断主力动向 |
| **我无形** | 隐藏自己的真实意图 | 不在社交媒体晒单、不跟别人讨论持仓、不让对手知道你的成本 |
| **我专而敌分** | 集中资金打一个方向 | 2026年上半年，聪明的钱**集中**在AI、半导体（“专”），而不是分散在30个板块（“分”） |
| **以十攻一** | 在局部形成绝对优势 | 在半导体设备这个细分赛道集中火力，而不是在整个科技板块撒胡椒面 |

### 📊 2026年A股数据验证

2026年上半年，31个申万一级行业中**仅10个上涨，超六成行业下跌**，板块间首尾差超过**115个百分点**。

**谁赢了？**

| 类型 | 做法 | 结果 |
| :--- | :--- | :--- |
| **“专”的赢家** | 集中资金在电子（+86.29%）、通信（+73.59%） | 大赚 |
| **“分”的输家** | 分散在消费（-29.42%）、农林牧渔（-25.26%） | 大亏 |

**“我专为一，敌分为十”在2026年的意思是：**
> **市场上有5000多只股票，你不可能全都研究透。集中精力研究3-5个行业、10-20只股票，把“兵力”（资金和研究精力）集中在一个点上——这才是散户战胜机构的唯一路径。**

### 💼 2026年商业案例：宁德时代 vs 比亚迪——“形人而我无形”的攻防战

2026年，宁德时代与比亚迪在动力电池领域形成了**双强格局**，两家企业合计市场份额维持在**64%**。

| 维度 | 宁德时代 | 比亚迪 |
| :--- | :--- | :--- |
| **2026年5月市占率** | 46.14% | 约17% |
| **全球1-4月市占率** | 40.1% | 14.2% |
| **核心竞争力** | 技术+产能+定价权（“实”） | 整车+电池一体化（“奇”） |
| **战略** | 守住“实”——强化技术壁垒 | 打“虚”——依托整车销量带动电池 |

**宁德时代的“形人而我无形”：**
- 宁德时代从不公开自己的固态电池量产时间表（“我无形”）。
- 但对手（比亚迪、中创新航）急于公布自己的量产计划，暴露了自己的技术进度和产能规划（“形人”）。
- 宁德时代通过观察对手的“形”，精准判断对手的虚实，然后调整自己的节奏。

**比亚迪的“避实击虚”：**
- 不在电池技术上跟宁德时代硬拼“实”（技术壁垒），而是利用自己的整车优势（“虚”——别人没有的整车销量），带动电池出货。

> **金句提炼：让别人把底牌亮出来，把自己的底牌藏起来。你看透了对手，对手看不透你——你就赢了八成。**


## 第四章：“因敌制胜”——没有固定套路，只有随机应变

### 原文核心段落
> **“夫兵形象水，水之形，避高而趋下；兵之形，避实而击虚。水因地而制流，兵因敌而制胜。故兵无常势，水无常形，能因敌变化而取胜者，谓之神。”**

### 🔍 逐字精讲
- **兵形象水**：用兵的规律像水一样。
- **水之形，避高而趋下**：水的规律是避开高处、流向低处。
- **兵之形，避实而击虚**：用兵的规律是避开敌人坚实的地方、攻击敌人虚弱的地方。
- **水因地而制流**：水根据地形决定流向。
- **兵因敌而制胜**：用兵根据敌人的情况决定取胜的方法。
- **兵无常势，水无常形**：用兵没有固定的态势，水没有固定的形状。
- **能因敌变化而取胜者，谓之神**：**能根据对手的变化而变化、最终取胜的人，叫做“神”。**

### 🧠 现代翻译

孙子在2500年前就说了一句极其超前的话：

> **这个世界上没有“万能公式”。每一种成功的方法，都是针对特定对手、特定环境、特定时机的“定制方案”。**

**“因敌制胜”的三种层次：**

| 层次 | 做法 | 2026年对应 |
| :--- | :--- | :--- |
| **最低（死板）** | 用一个方法打所有对手 | “我就死守消费股，不管市场怎么变” → 2026上半年亏25%+ |
| **中等（应变）** | 根据市场变化调整策略 | “科技涨多了我就减，跌多了我就加” → 赚一些 |
| **最高（因敌）** | 根据对手的动向来制定策略 | “我看到北向资金在买半导体，我跟；我看到游资在出货，我跑” → 大赚 |

### 📊 2026年A股案例：北向资金的“因敌变化”

2026年上半年，北向资金的流向呈现出清晰的“因敌变化”特征：

- **一季度**：北向资金净买入**3274亿元**，创同期历史新高。主要买入方向：宁德时代、贵州茅台、中际旭创等核心资产。
- **5月中旬以来**：机构资金和北向资金从前期涨幅巨大的AI、半导体高位科技股中**连续净流出**。
- **6月**：北向资金连续多个交易日净流入，累计净买入超150亿元。
- **7月2日**：北向资金大幅净卖出，机构集中抛售前期高位算力、存储、半导体筹码。

**北向资金在干什么？**

> **“因敌变化”——根据市场情绪、估值位置、政策信号，不断调整自己的持仓结构。涨多了就卖（避“实”），跌多了就买（击“虚”）。**

### 💼 2026年商业案例：多家车企的“战略瘦身”——因敌制胜的防守反击

2026年，面对存量竞争加剧、电动智能化研发成本高企的挑战，**长城、吉利、长安、赛力斯**等多家国内车企开启战略收缩。

| 过去的做法（死板） | 现在的做法（因敌） |
| :--- | :--- |
| 多品牌、多车型全面铺量 | 整合、精简、剥离 |
| 粗放扩张 | 集中资源筑牢核心盈利基本盘 |
| “什么都要做” | “只做最能赚钱的” |

**这就是“因敌制胜”在企业管理中的体现：**
> **市场变了（“敌”变了），打法就要变（“因敌而变化”）。死守过去的成功经验，等于刻舟求剑。**


## 第五章：“虚实”的终极应用——2026年A股实战推演

### 📋 第一步：识别“实”和“虚”

| 维度 | “实”（拥挤/高估/风险） | “虚”（冷清/低估/机会） |
| :--- | :--- | :--- |
| **2026年上半年的“实”** | AI算力、半导体设备（涨太多，拥挤度高） | 消费、地产链（跌太多，无人问津） |
| **2026年下半年的“虚”** | 科技板块回调后的优质标的 | 低估值顺周期板块的反弹机会 |

### 📋 第二步：选择“避实击虚”的策略

| 策略 | 操作 | 兵法对应 |
| :--- | :--- | :--- |
| **避实** | 不追高已经涨了5倍的AI概念股 | “避实而击虚” |
| **击虚** | 在科技板块回调15%-20%时分批建仓 | “攻其所不守” |
| **形人** | 每天看龙虎榜、北向资金流向、大宗交易 | “形人而我无形” |
| **我无形** | 不公开讨论自己的持仓，不跟风热门股吧 | “我专而敌分” |

### 📋 第三步：实现“以十攻一”

> **散户最大的优势是“灵活”，最大的劣势是“分散”。**

2026年上半年，全市场5528只个股中只有**362只翻倍**——概率只有**6.5%**。

如果你分散在30只股票里，你抓到翻倍股的概率很低。
但如果你集中研究3个行业、10只股票，你抓到翻倍股的概率大幅提升。

**“我专为一，敌分为十”在投资中的意思是：**
> **把有限的研究精力集中在一个细分赛道，而不是在整个市场里撒网。**

## 第七章：虚实篇与前六篇的逻辑串联

至此，前六篇构成了一个完整的“战前六部曲”：

| 篇章 | 核心问题 | 决策输出 | 比喻 |
| :--- | :--- | :--- | :--- |
| **始计篇** | 这仗值不值得打？（定性） | “打”或“不打” | **战略会** |
| **作战篇** | 我打得起吗？（定量/成本） | “速打”或“缓打” | **财务会** |
| **谋攻篇** | 我该怎么用最小的代价打？（方法） | “伐谋/伐交/伐兵/攻城” | **方案会** |
| **军形篇** | 我现在具备“必胜条件”了吗？（时机） | “现在打”或“再等等” | **时机会** |
| **兵势篇** | 我该怎么出手？（战术） | “正兵稳、奇兵狠” | **执行会** |
| **虚实篇** | 我打对手哪里？（目标） | “避实击虚、因敌制胜” | **目标会** |

**串联案例（2026年完整推演）** ：

1. **始计**：AI算力是2026最大风口 → 决定打。
2. **作战**：半年内能承受的最大亏损是20% → 速战速决。
3. **谋攻**：不直接买算力租赁股，买上游光模块龙头 → 伐谋。
4. **军形**：光模块龙头在手订单饱满、技术壁垒高 → 先胜条件具备。
5. **兵势**：一半仓位做“正”（底仓），一半仓位做“奇”（机动）→ 正奇结合。
6. **虚实**：
   - **避实**：不追高已经涨了3倍的光模块龙头（那是“实”）。
   - **击虚**：在板块回调15%-20%时买入（那是“虚”——别人恐慌时）。
   - **形人**：观察北向资金是否在持续买入该板块。
   - **我无形**：不在社交媒体讨论自己的操作。
   - **因敌变化**：如果中报不及预期，立即止损；如果超预期，加仓。


## 第八章：写在最后——2026年，谁在“避实击虚”，谁在“以实击实”？

2026年上半年，A股市场出现了**362只翻倍股**和**1134只跌幅超30%的股票**。同样的市场，截然不同的结果。

**赢的人做对了什么？**
- 他们**避开了“实”** ——不追高、不盲从、不拥挤的地方不去。
- 他们**击中了“虚”** ——在无人问津时布局、在别人恐慌时贪婪。
- 他们**“形人而我无形”** ——研究对手（北向、机构、游资）的动向，但隐藏自己的意图。
- 他们**“因敌变化”** ——市场变了，打法就变，不固执、不刻舟求剑。

**输的人做错了什么？**
- 他们**“以实击实”** ——在AI最火热的时候追进去，跟机构和游资在同一个价位抢筹码。
- 他们**“形我而人无形”** ——自己的持仓全暴露在社交平台上，但对手的意图完全看不清。
- 他们**“刻舟求剑”** ——用2020年买消费股的方法来买2026年的科技股。
