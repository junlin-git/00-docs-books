# 《孙子兵法·军争篇》超详细深度解读 —— 以迂为直，风林火山

> 本篇导读：前六篇，孙子教我们“算”（始计）、“耗”（作战）、“谋”（谋攻）、“等”（军形）、“势”（兵势）和“虚实”（避实击虚）。如果你已经算过了、耗得起、找到了最优策略、等到了最佳时机、准备好了正奇结合、也选好了打击目标——现在面临最后一个问题：**怎么抢在对手前面到达战场？** 第六篇“虚实”告诉你打哪里，第七篇“军争”告诉你**怎么去**。
>
> 全篇核心就六个字：**以迂为直，风林火山**。
>
> 按孙武的意思，所谓“军争”就是“两军争利”，而“利”的具体定义就是“先”——**先机、先手、抢先、占先**。“军争”的正确意义，就是在战斗发生之前，为了先于对方占据有利作战条件而做出的调遣和行动。一旦失去“先机”，则几乎必然失去主动权。
>
> 如果说前六篇是“纸上谈兵”的理论框架，那么从“军争”开始，就进入了实战考核阶段。本文将用2026年A股的潜伏牛股、名创优品的反向营销、华为的半导体制程突围、新能源车企的集体转型等真实案例，彻底拆解这套“抢占先机”的实战框架。


## 第一章：开篇定调——军争之难，以迂为直

### 原文第一段
> **“孙子曰：凡用兵之法，将受命于君，合军聚众，交和而舍，莫难于军争。军争之难者，以迂为直，以患为利。故迂其途，而诱之以利，后人发，先人至，此知迂直之计者也。”**

### 🔍 逐字精讲
- **军争**：两军争夺有利条件和制胜先机。
- **以迂为直**：**把迂回曲折的道路，变成直达目的地的捷径**。
- **以患为利**：**把不利的因素，转化成有利的条件**。
- **迂其途，而诱之以利**：自己走弯路（看起来绕远了），同时用利益引诱敌人走更弯的路。
- **后人发，先人至**：**比敌人晚出发，却比敌人先到达**——这就是“迂直之计”的终极目标。

### 🧠 为什么“直线”反而是最慢的路？

很多人觉得两点之间直线最短。但孙子告诉你：**在充满竞争的现实中，直线往往堵满了人，走得最慢**。

| 场景 | “直线”（看似最快） | “迂回”（实际最快） |
| :--- | :--- | :--- |
| **考公务员** | 毕业直接挤独木桥 | 先去企业积累经验，再考特定岗位 |
| **职业晋升** | 在拥挤的通道里死磕 | 先去核心部门“镀金”再曲线回归 |
| **炒股** | 追涨停、追热点 | 在无人问津时潜伏 |
| **商业竞争** | 跟巨头正面打价格战 | 从边缘切入，逐步渗透 |

### 📊 2026年A股案例一：志特新材的“迂直之计”

2025年，志特新材的“AI 4S + 量子科技”核心逻辑**未被市场关注**——这条“无人问津的迂途”，成了聪明资金的潜伏阵地。

那些追AI热点、追Sora概念的散户，走的是“直线”——看似最快，结果呢？Sora概念爆发当天，散户蜂拥追高无业绩支撑的杂毛股，3只跟风股尾盘资金出逃，**超2万户散户单日浮亏超5%** 。

而那些走“迂回路线”的聪明资金呢？他们在2025年就潜伏进了志特新材，2026年1月5日启动后，**短短5个交易日斩获148%涨幅**。

> **这就是“后人发，先人至”——你比我晚关注，我比你早赚钱。热门赛道人声鼎沸时，多一份冷静；冷门逻辑无人问津时，多一份研究**。

### 📊 2026年A股案例二：军工板块的“潜伏逻辑”

军工板块同样印证了这一逻辑。兵装集团重组背景下，建设工业（002265）作为95式步枪核心供应商，2025年Q1净利润同比增长49.39%，军品收入占比超70%，前期未被过度炒作。2026年1月9日，主力资金净买入833.63万元，悄然走出稳健上涨趋势。北方导航（600435）作为导弹制导龙头，军贸订单占比从18%提升至35%，提前布局者已锁定丰厚收益。

### 📊 2026年商业案例三：名创优品的“迂直”世界杯营销

2026年美加墨世界杯，各大品牌疯狂砸钱签球星、赞助球队。

名创优品却走了**完全相反的“迂回路线”** ——不请球星、不买天价赞助。它在广告和海报上抠出“人型马赛克”，直接摊牌称“不请球星”。品牌还在杭州西湖边价值68万元的大屏上投放广告，系品牌首次在门店外线下场域开展大型营销活动。

**结果呢？**

其他品牌花了天价赞助费（走“直线”），在世界杯营销的汪洋大海里被淹没。名创优品没花几个钱（走“迂回”），却因为“反向操作”引发全网热议，实现了**“低成本、高曝光、强转化”** 的效果。

**“迂其途，而诱之以利”的现代翻译：**
> **大家都去挤的“直路”，你别去。走一条别人没发现的“弯路”，反而更快到达。你用“不走寻常路”的方式，把竞争对手引向更拥挤的方向，自己轻松抵达目的地。**

### 📊 2026年科技案例四：华为“韬定律”——半导体的“以迂为直”

外部制裁持续强化，先进制程设备买不到了——这是“患”。

但华为怎么“以患为利”？**彻底放弃“追先进制程、缩晶体管尺寸”的主流内卷路线**。华为提出“韬定律”，核心思路在于**不再执着于摩尔定律“把晶体管做得更小”的单一路径**，而是通过“逻辑折叠”等技术，在三维空间中堆叠和重构电路。以“时间缩微”替代传统“几何缩微”，重点不是继续单纯缩小晶体管的几何尺寸，而是压缩信号传播、数据搬运和系统协同所消耗的时间。

**“以迂为直”的翻译：**
> **大家都去挤“先进制程”这条直路（但被封锁了），华为走了一条“三维堆叠+先进封装”的迂回路——看似绕远，实则是在被封锁的绝境中开辟了一条新路。**


## 第二章：“风林火山”——行动的四种节奏

这是《军争篇》最著名的段落，也是被日本战国名将武田信玄绣在军旗上的四字箴言。原文其实不止四个字，完整版是六个——但“风林火山”四个字最为经典。

### 原文核心
> **“故其疾如风，其徐如林，侵掠如火，不动如山，难知如阴，动如雷震。”**

### 🏔️ 六字详解（附2026年实战案例）

| 四字 | 原文 | 含义 | 2026年对应场景 |
| :--- | :--- | :--- | :--- |
| **风** | 其疾如风 | **行动要快**——决策果断、执行迅猛，抓住时机绝不犹豫 | 游资“跌停翘板”：情绪冰点快速吸筹 |
| **林** | 其徐如林 | **缓慢时有序**——不急不躁、不暴露意图，像森林一样沉稳 | 机构底部吸筹：每天慢慢接，耗时数月 |
| **火** | 侵掠如火 | **进攻要猛**——一旦发起攻击，像烈火一样不可阻挡 | 主力拉主升浪：连续大阳线逼空 |
| **山** | 不动如山 | **防守要稳**——没有机会时，像山一样沉稳，不为所动 | 顶级游资空仓观望：没有机会绝不出手 |
| **阴** | 难知如阴 | **隐蔽要深**——像阴天一样让人看不清虚实 | 主力建仓期：隐藏真实意图 |
| **雷** | 动如雷震 | **冲锋要猛**——像雷霆一样让人无法抗拒 | 主升浪爆发：连续涨停逼空 |

### 📊 “风林火山”的现代翻译——仓位管理的艺术

有投资者把“风林火山”直接转化为仓位管理体系：

| 仓位类型 | 兵法对应 | 功能 |
| :--- | :--- | :--- |
| **风部** | 其疾如风 | 轮动配置，快速捕捉机会 |
| **林部** | 其徐如林 | 定期投入，慢慢积累 |
| **火部** | 侵掠如火 | 短线博弈，猛烈出击 |
| **山部** | 不动如山 | 长线持有，雷打不动 |

> **金句提炼：该快的时候比风还快（追趋势），该慢的时候比森林还稳（等机会），该狠的时候比火还猛（重仓出击），该忍的时候比山还稳（空仓等待）。**

### 📊 2026年A股数据：仓位失控的惨痛代价

2026年前四个月，A股散户亏损账户高达**79%** ，人均亏2.1万。大盘跌不到2%，散户亏了12倍。根源就一个——**仓位失控**。

**“风林火山”的仓位纪律正是在解决这个问题：**
- **风**：机会来了快速出击，但不恋战。
- **林**：建仓时慢慢来，不急不躁。
- **火**：主升浪时敢于重仓。
- **山**：没有机会时空仓如山。

2026年A股大概率还是震荡上行、轮动为主，对散户来说，**不贪、不急、不赌、不情绪化，严格控制仓位，比学任何技术都管用**。


## 第三章：“避其锐气，击其惰归”——情绪周期的实战运用

### 原文核心
> **“朝气锐，昼气惰，暮气归。故善用兵者，避其锐气，击其惰归，此治气者也。”**

### 🔍 逐字精讲
- **朝气锐**：军队刚出发时，士气最旺盛（“锐气”）。
- **昼气惰**：到了白天，士气开始懈怠（“惰”）。
- **暮气归**：到了傍晚，士气衰竭、只想回家（“归”）。
- **避其锐气**：**避开敌人锐气最盛的时候**——不要在对方最强的时候硬碰硬。
- **击其惰归**：**等敌人懈怠、疲惫、想回家的时候再攻击**。

### 🧠 现代翻译（情绪周期版）

孙子的“治气”之道，对应A股的**情绪周期**。同花顺情绪指数是衡量市场情绪的常用工具。

| 情绪阶段 | 对应兵法 | 判断指标（同花顺情绪指数） | 操作策略 | 2026年实战案例 |
| :--- | :--- | :--- | :--- | :--- |
| **朝气锐（亢奋）** | 避其锐气 | ＞1050（情绪亢奋） | **减仓/观望**——不追高 | 1月9日Sora概念，指数1068时追高，尾盘回调套人 |
| **昼气惰（中性）** | 击其惰归 | 850-1050（情绪中性） | **分批布局**——慢慢建仓 | 2025年12月AI应用端，指数980时介入，后续涨幅超60% |
| **暮气归（低迷）** | 击其惰归 | ＜850（情绪低迷） | **重仓潜伏**——别人恐惧我贪婪 | 2025年11月航天装备板块，指数830时布局 |

### 📊 2026年6月量化数据验证

2026年6月，全A短线情绪指标**降至1.1%水位**。全A最近几次情绪接近0%后指数短期往往反弹，情绪接近100%时指数短期往往调整。该指标自5月13日的80%再度降至接近0%的状态，短期担忧情绪已经释放较为充分，对应短期企稳反弹的可能性抬升。

**“避其锐气，击其惰归”在2026年6月的翻译是：**
> **市场情绪已经低迷到极致（暮气归），别人都在恐慌割肉。这时候不是跟着恐慌，而是“击其惰归”——重仓布局。**

### 📊 2026年7月最新数据

进入2026年7月，市场情绪处于牛市中偏低水平，反映市场强弱势水平的分项指标同样处于低位，意味着**市场短期反弹动能较强**，特别是前期超跌板块有望轮动反弹。

### 💼 生活案例——别和正在气头上的人吵架

“避其锐气，击其惰归”在日常生活中同样适用。

刚发怒的人，是“锐气”正盛的时候——你去硬碰硬，吃亏的是自己。等他冷静下来、疲惫了，再去沟通，效果会好很多。

**吵架的“军争”智慧：**
> **不要在对方情绪最高涨的时候争论。等他气消了、累了，再讲道理——事半功倍。**


## 第四章：“以患为利”——把坏事变成好事

### 原文回顾
> **“军争之难者，以迂为直，以患为利。”**

“以患为利”的意思是：**把不利的因素，转化成有利的条件**。

### 💼 2026年商业案例一：新能源车企的“以患为利”

2025年，新能源汽车行业陷入惨烈的价格战——“低价竞争”、“迭代竞速”、“爆款之争”成为主旋律。

**这是“患”——全行业利润被压到极致。**

但进入2026年，市场风向变了。

| 变化 | 数据 | 兵法对应 |
| :--- | :--- | :--- |
| 从“价格混战”转向“技术战” | 近20家车企宣布上调售价 | **以患为利**——价格战打不下去了，倒逼行业转向技术竞争 |
| 从“卖车亏钱”转向“价值竞争” | 头部车企加大研发投入 | **以患为利**——盈利承压，倒逼放弃以价换量 |
| 渗透率突破60% | 4月新能源车零售渗透率达61.4% | **以患为利**——价格战倒逼行业洗牌，优胜劣汰加速 |
| 技术价值凸显 | 技术迭代带来的净积极消费影响达20.7% | **以患为利**——消费者从“比价格”转向“比技术” |

**“以患为利”的翻译：**
> **价格战打不下去了（患）→ 倒逼行业转向技术竞争（利）。全行业盈利承压（患）→ 倒逼各大车企收紧优惠、上调售价（利）。**

### 📊 2026年科技案例二：半导体行业的“以患为利”

外部制裁持续强化——这是“患”。但中国企业怎么“以患为利”？

| 路径 | 做法 | 兵法对应 |
| :--- | :--- | :--- |
| **技术迂回** | 华为采用开源指令集架构RISC-V，绕开美国主导的x86与ARM架构管制 | **以迂为直** |
| **逻辑折叠** | 华为推出“韬定律”——通过三维空间堆叠和重构电路 | **以患为利**——买不到先进设备，倒逼换道超车 |
| **单点突破** | 艾佛光通用全球独创的单晶氮化铝技术路线打破BAW滤波芯片的国外垄断 | **以患为利**——封锁越狠，国产替代越快 |

**“以患为利”的翻译：**
> **买不到先进设备（患）→ 倒逼国产替代加速（利）。外部封锁越狠（患）→ 国产化的决心和投入越大（利）。**


## 第五章：“用兵八戒”——八种不能打的情况

### 原文核心
> **“高陵勿向，背丘勿逆，佯北勿从，饵兵勿食，归师勿遏，围师必阙，穷寇勿迫，此用兵之法也。”**

### 🔍 八条禁令详解（附2026年翻译）

| 禁令 | 原文 | 古代含义 | 2026年投资翻译 |
| :--- | :--- | :--- | :--- |
| **1. 高陵勿向** | 不要仰攻占据高地的敌人 | 不要逆势而为 | 不要在市场极度亢奋时追高 |
| **2. 背丘勿逆** | 不要迎击背靠山丘的敌人 | 不要跟有优势的对手硬拼 | 不要在机构重仓股上跟机构对着干 |
| **3. 佯北勿从** | 不要追击假装败退的敌人 | 不要追“假摔” | 不要追“放量下跌”的假破位——可能是主力诱空 |
| **4. 饵兵勿食** | 不要吃诱饵部队的“饵” | 不要被小利诱惑 | 不要被“利好”消息引诱接盘 |
| **5. 归师勿遏** | 不要阻截正在撤退回国的军队 | 不要拦“出货” | 主力出货时不要逆势接盘 |
| **6. 围师必阙** | 包围敌人要留缺口 | 给人留条活路 | 谈判中不要把对方逼到绝路 |
| **7. 穷寇勿迫** | 不要逼迫走投无路的敌人 | 不要逼死对手 | 不要逼死一只已经跌到底的股票 |

### 🧠 核心逻辑：“围师必阙”的智慧

“围师必阙”是八条中最深刻的一条。

把敌人团团围住、不留活路，他就会**拼死抵抗**——反正都是死，不如拉几个垫背的。留个缺口，他反而会想着逃跑，士气涣散，更容易被消灭。

**2026年翻译：**
> **在商业谈判中，不要把对方逼到绝路。留点面子、给个台阶下，对方反而更容易接受你的条件。逼急了鱼死网破，对谁都没好处。**


## 第六章：军争篇完整决策框架（傻瓜式操作手册）

### 第一步：判断“迂直”——走哪条路？

| 问题 | 检查项 |
| :--- | :--- |
| **大家都在走的路是什么？** | 热门赛道、拥挤板块、追高热点 |
| **有没有“迂回”的路？** | 冷门逻辑、无人问津的优质标的、被忽视的细分赛道 |
| **我能“后人发，先人至”吗？** | 我能不能在别人还没发现的时候提前布局？ |

### 第二步：选择“节奏”——风林火山用哪个？

| 场景 | 该用什么节奏 |
| :--- | :--- |
| **机会突然出现** | **风**——快速决策，果断出手 |
| **建仓/布局阶段** | **林**——慢慢来，不急不躁 |
| **主升浪/爆发期** | **火**——全力出击，猛烈进攻 |
| **没有机会/市场不明** | **山**——空仓等待，不为所动 |

### 第三步：判断“情绪”——避还是击？

| 情绪状态 | 操作 |
| :--- | :--- |
| **情绪亢奋（＞1050）** | **避其锐气**——减仓/观望 |
| **情绪中性（850-1050）** | **击其惰归**——分批布局 |
| **情绪低迷（＜850）** | **击其惰归**——重仓潜伏 |

### 第四步：遵守“八戒”——什么不能做？

- ❌ 不追高（高陵勿向）
- ❌ 不跟机构硬拼（背丘勿逆）
- ❌ 不追假摔（佯北勿从）
- ❌ 不被利好诱多（饵兵勿食）
- ❌ 不接出货盘（归师勿遏）
- ❌ 不把对手逼死（围师必阙、穷寇勿迫）

## 第八章：军争篇与前七篇的逻辑串联

至此，前七篇构成了一个完整的“战前七部曲”：

| 篇章 | 核心问题 | 决策输出 | 比喻 |
| :--- | :--- | :--- | :--- |
| **始计篇** | 这仗值不值得打？ | “打”或“不打” | **战略会** |
| **作战篇** | 我打得起吗？ | “速打”或“缓打” | **财务会** |
| **谋攻篇** | 怎么用最小的代价打？ | “伐谋/伐交/伐兵/攻城” | **方案会** |
| **军形篇** | 我现在具备必胜条件了吗？ | “现在打”或“再等等” | **时机会** |
| **兵势篇** | 我该怎么出手？ | “正兵稳、奇兵狠” | **执行会** |
| **虚实篇** | 我打对手哪里？ | “避实击虚” | **目标会** |
| **军争篇** | 我怎么抢在对手前面到达？ | “以迂为直、风林火山” | **速度会** |

**串联案例（2026年完整推演）** ：

1. **始计**：AI算力是2026最大风口 → 决定打。
2. **作战**：半年内能承受的最大亏损是20% → 速战速决。
3. **谋攻**：不直接买算力租赁股，买上游光模块龙头 → 伐谋。
4. **军形**：光模块龙头在手订单饱满 → 先胜条件具备。
5. **兵势**：一半底仓（正）+一半机动（奇）→ 正奇结合。
6. **虚实**：在板块回调时买入（击虚）→ 避实击虚。
7. **军争**：
   - **以迂为直**：不追已经涨了3倍的龙头，找同一赛道还没被发掘的细分标的。
   - **风林火山**：机会来了快速出手（风），建仓时慢慢来（林），主升浪时重仓（火），没机会时空仓（山）。
   - **避锐击惰**：市场亢奋时不追（避锐），市场恐慌时布局（击惰）。


## 写在最后：最快的路，往往不是直线

2026年的A股，31个申万一级行业中仅10个上涨，超六成行业下跌。**走对路的人赚64%，走错路的人亏25%**。

**“避其锐气，击其惰归”告诉我们：**
> **不要在别人最兴奋的时候跟风，要在别人最恐慌的时候出手。**

**“以患为利”告诉我们：**
> **每一个“坏消息”背后，都可能藏着一个“好机会”。关键是你能不能把它转化出来。**

**孙子在2500年前就告诉我们：**

> **“先知迂直之计者胜。”**
>
> **谁能把弯路走成直路，谁就能赢。**

2026年下半年，市场依然充满变数。有人会告诉你“再不买就来不及了”，有人会告诉你“这次不一样”。

**但孙子会说：**

>
> **别被情绪裹挟，别被利益诱惑，别把对手逼到绝路。**
>
> **走自己的“迂回之路”，用“风林火山”的节奏，在别人恐慌时出手，在别人疯狂时收手。**
