# 《孙子兵法·九变篇》超详细深度解读 —— 随机应变，杂于利害

> 本篇导读：前七篇，孙子教我们“算”（始计）、“耗”（作战）、“谋”（谋攻）、“等”（军形）、“势”（兵势）、“虚实”（避实击虚）和“争”（军争）。如果你已经算过了、耗得起、找到了最优策略、等到了最佳时机、准备好了正奇结合、选好了打击目标、也抢占了先机——现在进入最高阶的挑战：**变化**。
>
> **“九变”的“九”不是数字九，而是“极多”的意思——无穷无尽的变化。“变”是唯一的不变。** 前七篇教的是“原则”，第九篇教的是“打破原则”——根据实际情况灵活变通。全篇核心就八个字：**随机应变，杂于利害**。
>
> 如果说前七篇是“剑谱”，那第九篇就是“忘掉剑谱”——在实战中根据对手的出招随时调整。本文将用2026年A股的极致K型分化、京东方A的惊天反转、科技股的风格切换、逆变器板块的黑天鹅等真实案例，彻底拆解这套“应变”的顶级智慧。


## 第一章：开篇定调——“九变”是打破所有规则的最高规则

### 原文第一段
> **“孙子曰：凡用兵之法，将受命于君，合军聚众。圮地无舍，衢地交合，绝地无留，围地则谋，死地则战。途有所不由，军有所不击，城有所不攻，地有所不争，君命有所不受。”**

### 🔍 逐字精讲

| 原文 | 含义 | 现代翻译 |
| :--- | :--- | :--- |
| **圮地无舍** | 在难以通行的地方不要扎营 | 在流动性差、信息不明的市场不要重仓 |
| **衢地交合** | 在四通八达的要地要结交盟友 | 在热点板块要借势、跟随主力 |
| **绝地无留** | 在绝境中不要逗留 | 趋势走坏的市场不要恋战，果断离场 |
| **围地则谋** | 在被包围时要谋划突围 | 被套牢时要思考解套策略，而非死扛 |
| **死地则战** | 在死地则必须殊死一战 | 到了最极端的情况，反而要放手一搏 |

**最关键的五句（“五不”）：**

| 原文 | 含义 | 2026年翻译 |
| :--- | :--- | :--- |
| **途有所不由** | 有的道路不走 | 有些看似“机会”的赛道，不碰 |
| **军有所不击** | 有的敌军不打 | 有些看似“热门”的板块，不追 |
| **城有所不攻** | 有的城池不攻 | 有些看似“低估”的股票，不买 |
| **地有所不争** | 有的土地不争 | 有些看似“便宜”的筹码，不要 |
| **君命有所不受** | 君主的命令也可以不执行 | 不要盲从任何“专家”“大V”“政策传言” |

### 🧠 最高级的智慧：学会“放弃”

孙子在“九变篇”开篇就给了五条“禁令”——**不是告诉你要做什么，而是告诉你可以不做什么。**

> **知道“做什么”是本事，知道“不做什么”是智慧。**

**在2026年A股，这五条“不”意味着：**

| “不”的原则 | 2026年实操 |
| :--- | :--- |
| **途有所不由** | 不碰那些“看似在涨、但你看不懂”的票 |
| **军有所不击** | 不追那些“已经涨了5倍、但你没有成本优势”的板块 |
| **城有所不攻** | 不买那些“估值极低、但基本面持续恶化”的价值陷阱 |
| **地有所不争** | 不在那些“机构早已布局完毕、散户进去就是接盘”的赛道硬挤 |
| **君命有所不受** | 不盲从任何“这次不一样”的牛市口号 |


## 第二章：“通于九变”——不懂变通的人，熟悉地形也赢不了

### 原文核心
> **“故将通于九变之利者，知用兵矣；将不通于九变之利者，虽知地形，不能得地之利矣。治兵不知九变之术，虽知五利，不能得人之用矣。”**

### 🔍 逐字精讲
- **通于九变之利者，知用兵矣**：真正懂得灵活变通的人，才算真正懂得用兵。
- **不通于九变之利者，虽知地形，不能得地之利**：不懂变通的人，就算熟悉地形，也利用不了地形优势。
- **虽知五利，不能得人之用**：就算知道各种有利条件，也发挥不出团队的作用。

### 🧠 “通于九变”的反面：刻舟求剑

2026年A股最大的悲剧是什么？**不是选错了板块，而是用2020年的方法炒2026年的股。**

| 刻舟求剑的行为 | 2026年的现实 |
| :--- | :--- |
| “白酒永远涨，茅台回调就是买入机会” | 2026年上半年食品饮料跌近20%，茅台被“新股王”联讯仪器（+2700%）全面碾压 |
| “消费是永远的防御品种” | 商贸零售跌29.42%，农林牧渔跌25.26% |
| “银行股股息率高，稳稳的幸福” | 上半年银行跌超10% |
| “科技股泡沫，迟早崩盘” | 科创50涨64.25%，电子行业涨86.29% |

> **“虽知地形，不能得地之利”——你熟悉股市的所有技术指标，但不知道今年市场在炒什么，照样亏钱。**

### 📊 2026年数据：谁在“通于九变”，谁在“刻舟求剑”？

2026年上半年，A股5528只股票中，**仅31%的个股录得正收益，近七成个股下跌**，个股涨跌幅中位数为 **-15.35%**。

**“通于九变”的人做了什么？**
- 年初从消费切换到科技 → 赚64%
- 3月地缘冲突时减仓避险 → 躲过一波回调
- 5月反弹时加仓半导体 → 吃到主升浪
- 6月底科技拥挤时部分止盈 → 锁定利润

**“不通九变”的人做了什么？**
- 死守消费、白酒 → 亏20%+
- 3月恐慌时割肉科技 → 卖在最低点
- 5月追高科技 → 买在阶段性高点
- 6月科技回调时恐慌卖出 → 又割在低点

**同一个人、同一个市场，结果天差地别——区别就在于“变”与“不变”。**


## 第三章：“杂于利害”——好事里藏着坏事，坏事里藏着好事

### 原文核心
> **“是故智者之虑，必杂于利害。杂于利而务可信也，杂于害而患可解也。”**

### 🔍 逐字精讲
- **智者之虑，必杂于利害**：聪明人思考问题，**一定同时考虑利和害两个方面**。
- **杂于利而务可信也**：在不利的情况下，要看到有利的一面，才能坚定信心。
- **杂于害而患可解也**：在有利的情况下，要看到有害的一面，才能防范风险。

### 🧠 翻译成大白话
- **顺境看危**：涨的时候要想“万一跌了怎么办？”
- **逆境看机**：跌的时候要想“这里面有没有机会？”

### 📊 2026年案例一：京东方A的“利害交织”

2026年7月2日，玻璃基板龙头**京东方A**上演了极致反转行情：

| 时间 | 事件 | “利” | “害” |
| :--- | :--- | :--- | :--- |
| **早盘** | 一度跌停 | — | 散户恐慌，担心科技行情终结 |
| **盘中** | 快速拉升，振幅18.36% | 机构大举抄底 | 追高者可能被套 |
| **收盘** | 涨3.76%，成交近500亿创历史新高 | 坚定持有者大赚 | 日内追涨杀跌者亏损惨重 |
| **龙虎榜** | 4家机构买入39亿，同时卖出24亿 | 机构在做T/量化交易 | 散户看不懂机构意图 |

**“杂于利害”的智慧：**
- 早盘跌停时，看到“害”的人恐慌割肉。
- 早盘跌停时，看到“利”的人（机构）大举抄底。
- **同一个价格，有人看到风险，有人看到机会。**

自5月21日京东方与康宁签署合作备忘录以来，该股已累计上涨**115.54%**。那些“杂于利害”的投资者，在每一波回调中都看到了机会；那些只看到“害”的投资者，在上涨115%的过程中不断踏空。

### 📊 2026年案例二：科技股7月1日的风格切换——“利”中有“害”

2026年7月1日，A股超**4300只个股上涨**，市场风格出现明显切换：

| 维度 | 科技板块 | 非科技板块 |
| :--- | :--- | :--- |
| **当日表现** | 通信、电子等科技板块大幅调整 | 券商、医药、消费、养殖大涨 |
| **“利”** | 上半年涨太多，但产业趋势没变 | 超跌修复，估值便宜 |
| **“害”** | 拥挤度过高，获利盘集中兑现 | 基本面拐点尚不明确 |

**机构怎么看？——“勿做极端切换”**
> 科技股的调整属于**交易层面的良性换手**，低位板块的上涨更多是**超跌修复，而非趋势反转**。全面风格切换的条件尚不成熟。

**“杂于利害”的操作：**
- **看到“害”** ：科技股涨太多了，拥挤度高，要防范回调。
- **看到“利”** ：科技仍是主线，调整是上车机会。
- **决策**：不减仓科技（不因“害”而全跑），也不All in非科技（不因“利”而全换）——**“杂于利害”，两面都看到，两面都应对**。

### 📊 2026年案例三：逆变器板块的黑天鹅——“害”中有“利”

2026年7月1日，美国拟禁止中国产逆变器进口：

| 影响 | 数据 |
| :--- | :--- |
| **阳光电源** | 盘中一度暴跌近20%，市值单日蒸发超400亿元 |
| **其他逆变器股** | 固德威跌超7%，锦浪科技跌超8%，德业股份等大幅下跌 |

**“杂于利害”的智慧：**
- **看到“害”** ：利空消息，短期暴跌。
- **看到“利”** ：美国禁令难改全球产业格局，暴跌可能是错杀。
- **“杂于害而患可解”** ：如果你提前分散了仓位（不只是逆变器一个板块），这个“害”就不会致命。

> **金句提炼：涨的时候想“跌了怎么办”，跌的时候想“涨了怎么办”——永远在两个方向上都做好准备。**


## 第四章：“将有五危”——五种性格缺陷，五种死法

这是全篇最深刻的一段——孙子不是在讲兵法，而是在讲**人性**。

### 原文核心
> **“故将有五危：必死，可杀也；必生，可虏也；忿速，可侮也；廉洁，可辱也；爱民，可烦也。凡此五者，将之过也，用兵之灾也。覆军杀将，必以五危，不可不察也。”**

### 🔍 五种性格缺陷详解（附2026年散户对照）

| 五危 | 原文 | 含义 | 2026年散户对应 | 典型死法 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 必死** | 可杀也 | 不怕死、一味死拼 | **不止损，越跌越补** | 2026年上半年，318只个股跌幅超40%——死扛的人，亏40%以上 |
| **2. 必生** | 可虏也 | 贪生怕死、畏首畏尾 | **不敢出手，错过行情** | 2026年上半年，科创50涨64%——不敢追的人，完美踏空 |
| **3. 忿速** | 可侮也 | 急躁易怒、容易被激怒 | **情绪化交易、追涨杀跌** | 2026年7月1日，科技股回调时恐慌卖出——卖在最低点 |
| **4. 廉洁** | 可辱也 | 过于爱惜名声、好面子 | **死守“价值投资”标签** | 2026年上半年，死守消费、白酒的人亏20%+——为了“面子”亏了“里子” |
| **5. 爱民** | 可烦也 | 过于仁慈、顾虑太多 | **舍不得割肉、不忍心止损** | 2026年上半年，3700只个股下跌——舍不得卖，越套越深 |

### 🧠 你是哪一种？

| 你的行为 | 对应的“五危” | 2026年后果 |
| :--- | :--- | :--- |
| “我就不信它不涨，越跌越补！” | **必死** | 2026年上半年，92只个股跌幅超50% |
| “再等等，等确认了再买” | **必生** | 科创50上半年涨64%，等确认了已经涨完了 |
| “今天必须操作一把！” | **忿速** | 7月1日科技回调时恐慌卖出，第二天可能就反弹 |
| “我是价值投资者，不碰科技股” | **廉洁** | 上半年亏20%，看着别人赚64% |
| “再拿拿吧，万一反弹了呢” | **爱民** | 从亏10%变成亏40% |

## 第五章：九变篇完整决策框架（傻瓜式操作手册）

### 第一步：识别“变”——市场发生了什么变化？

| 问题 | 检查项 |
| :--- | :--- |
| **大盘变了没？** | 是“衢地”（量价健康）还是“绝地”（量价背离）？ |
| **主线变了没？** | 科技还在涨，还是切换到消费/券商了？ |
| **个股变了没？** | 你持有的股票，基本面、技术面、资金面变了没？ |

### 第二步：判断“利与害”——好事坏事都看到

| 场景 | 看“利” | 看“害” |
| :--- | :--- | :--- |
| **科技股大涨** | 产业趋势确定，业绩在兑现 | 拥挤度过高，随时可能回调 |
| **消费股大跌** | 超跌修复，估值便宜 | 基本面拐点尚不明确 |
| **黑天鹅事件** | 可能是错杀机会 | 可能是趋势反转 |

### 第三步：运用“五不”——学会放弃

- **途有所不由**：有些看似“机会”的赛道，不碰。
- **军有所不击**：有些看似“热门”的板块，不追。
- **城有所不攻**：有些看似“低估”的股票，不买。
- **地有所不争**：有些看似“便宜”的筹码，不要。
- **君命有所不受**：不盲从任何“专家”“大V”。

### 第四步：检查“五危”——你的性格缺陷是什么？

| 检查 | 问题 |
| :--- | :--- |
| **必死** | 我有没有在死扛一只不断下跌的股票？ |
| **必生** | 我有没有因为恐惧而错过明显的机会？ |
| **忿速** | 我有没有因为情绪而做出冲动的交易？ |
| **廉洁** | 我有没有因为“面子”而死守一个错误的判断？ |
| **爱民** | 我有没有因为“舍不得”而迟迟不止损？ |
