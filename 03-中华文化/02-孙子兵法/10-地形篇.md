# 《孙子兵法·地形篇》超详细深度解读 —— 知天知地，胜乃可全

> 本篇导读：前八篇，孙子教我们“算”（始计）、“耗”（作战）、“谋”（谋攻）、“等”（军形）、“势”（兵势）、“虚实”（避实击虚）、“争”（军争）和“变”（九变）。第九篇“行军”教我们“怎么观察地形和敌情”。到了第十篇“地形”，孙子把视角从“行军中的观察”拉到了“战场上的生死法则”。
>
> **“地形”不是简单的地理概念，而是“你与对手之间的力量关系在空间上的分布”** 。孙子在本篇给出了六种地形的战术原则、六种必败的将领错误，以及最核心的结论：**“地形者，兵之助也”** ——地形是打仗的辅助，真正的胜负取决于将领的智慧与决策。
>
> 全篇核心就八个字：**知天知地，胜乃可全**。
>
> 本文将用2026年A股的极致K型分化、半导体板块市值登顶、光伏行业30余家企业破产、新能源车价格战退潮、43家公司被立案调查等真实案例，彻底拆解这套“地形决胜”的实战框架。


## 第一章：开篇定调——地形的六种形态与对应战术

### 原文第一段
> **“孙子曰：地形有通者，有挂者，有支者，有隘者，有险者，有远者。我可以往，彼可以来，曰通；通形者，先居高阳，利粮道，以战则利。可以往，难以返，曰挂；挂形者，敌无备，出而胜之；敌若有备，出而不胜，难以返，不利。我出而不利，彼出而不利，曰支；支形者，敌虽利我，我无出也；引而去之，令敌半出而击之，利。隘形者，我先居之，必盈之以待敌；若敌先居之，盈而勿从，不盈而从之。险形者，我先居之，必居高阳以待敌；若敌先居之，引而去之，勿从也。远形者，势均，难以挑战，战而不利。凡此六者，地之道也，将之至任，不可不察也。”**

### 🔍 六种地形详解（附2026年A股翻译）

孙子把地形分为六种，每种都有完全不同的打法。这六种地形，放在2026年的A股市场中，恰好对应六种完全不同的市场状态：

| 地形 | 原文定义 | 战术原则 | 2026年A股翻译 |
| :--- | :--- | :--- | :--- |
| **通形** | 我可以往，彼可以来——四通八达 | 先占据高处向阳处，保证粮道通畅 | **流动性充足的主线行情**——资金自由进出，趋势明确。此时要“先居高阳”（选龙头、占先机），顺势而为 |
| **挂形** | 可以往，难以返——进去容易出来难 | 敌人无防备就出击；有防备就不要打 | **高波动但流动性差的小盘股**——进去容易，想出来时没人接盘。只在“敌无备”（无人关注、估值极低）时出手 |
| **支形** | 我出不利，彼出也不利——谁先动谁吃亏 | 敌人引诱我也不出去；引他出来一半再打 | **多空僵持的震荡市**——谁先出手谁被收割。不追涨不杀跌，等方向明确再说 |
| **隘形** | 狭窄通道——一夫当关万夫莫开 | 我先占就守住；敌人先占且兵满就不打 | **关键技术位的争夺**——年线、颈线、前高前低。谁先占住谁有主动权 |
| **险形** | 险要之地——易守难攻 | 我先占就居高临下等；敌人先占就不打 | **机构重仓控盘的核心资产**——主力已经“居高”控盘，不要去硬碰硬 |
| **远形** | 距离远——势均力敌时不宜挑战 | 势均力敌时不要主动挑战，打了也不利 | **缺乏信息优势的陌生领域**——你看不懂的行业、不了解的公司，不要碰 |

### 📊 2026年A股案例：六种地形同时并存

2026年上半年，A股市场恰好呈现出“六种地形并存”的奇观：

**通形——半导体板块：**

2026年上半年，申万半导体板块A股市值历史性超越国有大型银行，登上申万二级行业第一——从6.6万亿元飙升至14.14万亿元，**半年实现翻倍式增长**。电子行业以86.29%的涨幅高居行业榜首，通信行业上涨73.59%。

这就是“通形”——资金可以自由进出、趋势明确、流动性充沛。此时正确的打法是 **“先居高阳，利粮道”** ——选龙头、占先机、顺势而为。

**挂形——ST板块与退市股：**

2026年上半年，A股退市公司13家，风险警示股票达224只，同比增长23.8%。ST板块累计跌幅巨大，224只ST股中有多只跌幅超过50%。

这就是“挂形”——进去容易出来难。很多散户贪便宜买ST股，以为能“抄底”，结果退市后血本无归。孙子说 **“敌若有备，出而不胜，难以返，不利”** ——当退市风险已经明确（“敌有备”），就不要进去。

**支形——新能源车板块：**

2026年上半年，申万汽车行业跌幅达17.82%。车企陷入“降价→观望→再降价”的负循环，一季度汽车制造业利润率骤降至3.2%的历史低位。

这就是“支形”——谁先动谁吃亏。车企打价格战，越打越亏；投资者抄底，越抄越跌。孙子说 **“敌虽利我，我无出也”** ——看似便宜（“利我”），但不要出手。

**隘形——关键点位的多空争夺：**

2026年7月1日，A股超4300只个股上涨，科技股出现明显调整，券商、医药、消费等低位板块大涨。机构判断这是 **“交易层面的良性换手”** ，并非趋势反转。

这就是“隘形”——多空在关键点位激烈争夺。谁先占住关键位置（如年线、前高），谁就掌握主动权。

**险形——宁德时代与比亚迪的双头格局：**

2026年5月，宁德时代动力电池市占率46.14%，比亚迪市占率约17%，两家合计拿下超六成市场。宁德时代一季度营收1291亿元，同比增长52.45%，归母净利润207亿元，同比增长48.52%。

这就是“险形”——头部企业已经“居高”控盘，拥有绝对定价权。孙子说 **“若敌先居之，引而去之，勿从也”** ——对手已经占据险要位置，不要去硬碰硬。小企业在动力电池领域跟宁德时代正面竞争，就是“勿从”的反面教材。

**远形——你不了解的陌生行业：**

2026年上半年，全市场5528只个股中仅1715只上涨，占比31%，其中362只翻倍。但与此同时，318只个股跌幅超40%，92只跌幅超50%。

这就是“远形”——如果你对一个行业没有深入研究（“势均”），就不要轻易出手。孙子说 **“远形者，势均，难以挑战，战而不利”** ——信息不对等的时候，出手就是送死。

> **金句提炼：同一个市场，不同的板块就是不同的“地形”。六种地形的打法完全不同——用错了地形，就是送死。**


## 第二章：“六败”——将领的六种致命错误

孙子在讲完六种地形后，笔锋一转，讲了六种必败的将领错误。**这六条是“地形篇”最深刻的部分——不是在讲地形，而是在讲人性。**

### 原文核心
> **“故兵有走者，有弛者，有陷者，有崩者，有乱者，有北者。凡此六者，非天之灾，将之过也。夫势均，以一击十，曰走；卒强吏弱，曰弛；吏强卒弱，曰陷；大吏怒而不服，遇敌怼而自战，将不知其能，曰崩；将弱不严，教道不明，吏卒无常，陈兵纵横，曰乱；将不能料敌，以少合众，以弱击强，兵无选锋，曰北。凡此六者，败之道也，将之至任，不可不察也。””

### 🔍 六种败兵详解（附2026年散户对照）

| 六败 | 原文 | 含义 | 2026年散户对应 | 典型死法 |
| :--- | :--- | :--- | :--- | :--- |
| **走** | 势均，以一击十 | 实力相当却以一打十 | **盲目重仓单一个股** | 2026年上半年，92只个股跌幅超50%——全仓押中一只，直接腰斩 |
| **弛** | 卒强吏弱 | 士兵强、将领弱 | **选对了赛道，但操作稀烂** | 买了半导体龙头，但频繁追涨杀跌——赚了指数没赚钱 |
| **陷** | 吏强卒弱 | 将领强、士兵弱 | **研究能力一流，但执行力为零** | 看对了科技主线，但不敢重仓、不敢持有——完美踏空64% |
| **崩** | 大吏怒而不服 | 中层不服、各自为战 | **听多个“大V”互相矛盾的建议** | 这个说科技见顶、那个说消费反弹——左右挨打 |
| **乱** | 将弱不严，教道不明 | 将领软弱、纪律不明 | **没有交易系统、没有止损纪律** | 2026年上半年，79%散户亏损——无纪律的人，必败 |
| **北** | 不能料敌，以少合众 | 判断失误、以弱击强 | **逆势操作、跟市场对着干** | 在消费板块跌了30%后抄底——越抄越跌 |

### 📊 2026年数据验证：六败的代价

| 指标 | 数据 | 对应的“败” |
| :--- | :--- | :--- |
| 全市场5528只个股中仅1715只上涨，占比31% | **走**——押错个股的人，必败 |
| 79%的散户账户亏损，人均亏损2.1万 | **乱**——没有纪律的人，必败 |
| 318只个股跌幅超40%，92只跌幅超50% | **北**——逆势死扛的人，必败 |
| 362只个股翻倍，但大部分散户踏空 | **陷**——看对不敢做的人，必败 |
| 43家公司被立案调查，13家退市 | **崩**——信错“大V”踩雷的人，必败 |

**孙子的警告：**
> **“凡此六者，非天之灾，将之过也。”**
>
> **这六种失败，不是“市场不好”（天之灾），而是“你自己的错误”（将之过）。**

### 🧠 “六败”的生活案例

- **走**：你一个月赚1万，却想靠炒股一个月赚10万——以一击十，必败。
- **弛**：你买了一本“价值投资”的书，但看了三页就扔一边——士兵强（书好）、将领弱（你不学），必败。
- **陷**：你研究透了某只股票的所有财务数据，但跌5%就吓得割肉——将领强（研究能力）、士兵弱（执行力），必败。
- **崩**：你同时听三个炒股群的不同建议——中层不服、各自为战，必败。
- **乱**：你今天追AI、明天割AI、后天追消费——没有系统、没有纪律，必败。
- **北**：市场明明在跌，你非要“逆向投资”死扛——不能料敌、以弱击强，必败。


## 第三章：“地形者，兵之助也”——地形只是辅助，真正的胜负在人

### 原文核心
> **“夫地形者，兵之助也。料敌制胜，计险厄远近，上将之道也。知此而用战者必胜，不知此而用战者必败。”**

### 🔍 逐字精讲
- **地形者，兵之助也**：地形是打仗的**辅助条件**，不是决定因素。
- **料敌制胜**：判断敌人的虚实、制定取胜的策略——这才是关键。
- **计险厄远近**：计算地形的险要、远近——这是基本功。
- **上将之道也**：这才是优秀将领的真正本事。
- **知此而用战者必胜，不知此而用战者必败**：懂得这些并且会运用的人必胜，不懂的人必败。

### 🧠 核心逻辑：**地形只是“助”，不是“主”**

孙子在说一个极其深刻的道理：

> **不要把所有失败都归咎于“环境不好”。**
>
> **地形（市场环境）只是辅助条件。真正的胜负，取决于你能不能“料敌”、能不能“计险”、能不能做出正确的决策。**

### 📊 2026年A股案例：同样的“地形”，不同的命运

2026年上半年，A股市场5528只个股中——**362只翻倍**，也**3700多只下跌**。

**同样的“地形”（同一个市场），为什么有人赚2700%，有人亏90%？**

| 维度 | 赢的人 | 输的人 |
| :--- | :--- | :--- |
| **地形判断** | 识别出半导体是“通形”（趋势明确），重仓 | 误判消费是“洼地”（以为会反弹），死守 |
| **料敌制胜** | 看到北向资金持续流入科技板块，跟随 | 看到股价跌了就觉得“便宜”，抄底 |
| **计险厄远近** | 算清了半导体设备的国产化率从16%升至21%，业绩确定性高 | 只看K线、不看基本面 |
| **结果** | 赚64%+ | 亏20%+ |

> **金句提炼：市场还是那个市场，板块还是那些板块——区别不在于“地形”，在于你怎么“用”这个地形。**

### 📊 2026年半导体案例：地形的“助”与“不助”

**地形在“助”谁？**

2025年，中国半导体设备整体国产化率从2024年的16%跃升至21%，预计2026年达到26%。刻蚀国产化率达31%，薄膜沉积达27%。SEMI将2026年全球前端半导体设备市场规模预期上调至1522亿美元。

**这些是“地形”——行业趋势向上、政策支持、业绩兑现。**

**谁在用这个“地形”？**

- 2026年上半年，半导体指数大涨超106%，70只个股翻倍。
- 半导体板块市值从6.6万亿飙至14.14万亿。
- 存储龙头业绩暴增近14倍。

**谁没用好这个“地形”？**

- 2026年上半年，仍有79%的散户亏损。
- 很多人在半导体涨了50%后才追进去，然后被回调震出来。
- 更多人压根没买半导体，死守消费、地产。

**地形就在那里，你用好了就是“助”，用不好就是“不助”。**


## 第四章：“进不求名，退不避罪”——将领的最高境界

这是“地形篇”最震撼的一段。孙子不是在讲战术，而是在讲**人格**。

### 原文核心
> **“故进不求名，退不避罪，唯人是保，而利合于主，国之宝也。”**

### 🔍 逐字精讲
- **进不求名**：进攻不是为了追求个人的名声。
- **退不避罪**：撤退不是为了逃避罪责——该退就退，不怕别人骂。
- **唯人是保**：一切以保护士兵、保护人民为最高准则。
- **利合于主**：一切以符合君主的根本利益为标准。
- **国之宝也**：这样的人，是国家的宝贝。

### 🧠 现代翻译（投资版）

| 古代概念 | 2026年投资翻译 |
| :--- | :--- |
| **进不求名** | 买入不是为了“证明自己看对了”——不要为了面子死扛 |
| **退不避罪** | 止损不是为了“认输”——该割就割，不要怕别人笑 |
| **唯人是保** | 一切以保护本金为最高准则 |
| **利合于主** | 一切以符合自己（家庭）的根本利益为标准 |

### 📊 2026年A股案例：进不求名、退不避罪的人

**“进不求名”的人：**
- 在2025年底布局半导体——不是为了“证明自己”，只是因为看到了国产替代的趋势。
- 2026年上半年赚了64%，不炫耀、不晒单。

**“退不避罪”的人：**
- 2026年4月微盘股流动性危机时，果断割肉离场——不怕别人说“你卖在最低点”。
- 保住本金，在6月科技股回调时重新入场。

**“唯人是保”的人：**
- 单只股票仓位不超过总资金的20%。
- 止损线设在-5%到-8%，雷打不动。

**“利合于主”的人：**
- 不跟风、不盲从、不赌“这次不一样”。
- 每一次操作都问自己：“这符合我家庭的长期利益吗？”

> **金句提炼：赚钱不是为了证明自己有多牛，亏钱了也不要因为面子而死扛。保护本金、保护家庭——这才是投资的终极目标。**


## 第五章：“视卒如婴儿”——爱兵如子，生死与共

### 原文核心
> **“视卒如婴儿，故可与之赴深溪；视卒如爱子，故可与之俱死。厚而不能使，爱而不能令，乱而不能治，譬若骄子，不可用也。”**

### 🔍 逐字精讲
- **视卒如婴儿，故可与之赴深溪**：把士兵当婴儿一样爱护，他们就会跟你一起赴汤蹈火。
- **视卒如爱子，故可与之俱死**：把士兵当亲生儿子一样疼爱，他们就会跟你同生共死。
- **厚而不能使，爱而不能令，乱而不能治**：但光厚待却指挥不动、光疼爱却命令不了、队伍乱了却管不住——**那就是溺爱，不是真爱**。
- **譬若骄子，不可用也**：就像被宠坏的孩子，根本没法用。

### 🧠 现代翻译（管理+投资）

| 古代概念 | 企业管理翻译 | 投资翻译 |
| :--- | :--- | :--- |
| **视卒如婴儿** | 关心员工、建立信任 | 对自己的资金负责、珍惜每一分钱 |
| **可与之赴深溪** | 员工愿意跟你一起拼 | 你的资金愿意“陪你”等待价值兑现 |
| **视卒如爱子** | 把员工当家人 | 把投资当事业，而不是赌博 |
| **厚而不能使** | 光发钱不管用，还得有领导力 | 光有“信仰”不行，还得有纪律 |
| **爱而不能令** | 光对员工好不行，还得有规矩 | 光“看好”不行，还得有止损 |
| **乱而不能治** | 队伍乱了要能管 | 心态崩了要能调整 |

### 📊 2026年A股案例：被“骄子”毁掉的散户
