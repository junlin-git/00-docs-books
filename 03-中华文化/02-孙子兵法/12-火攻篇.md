# 《孙子兵法·火攻篇》超详细深度解读 —— 火发于内，早应之于外

> 本篇导读：前十一篇，孙子教我们“算”（始计）、“耗”（作战）、“谋”（谋攻）、“等”（军形）、“势”（兵势）、“虚实”（避实击虚）、“争”（军争）、“变”（九变）、“察”（行军）、“形”（地形）和“境”（九地）。到了第十二篇“火攻”，孙子突然把视角从“常规战争”转向了“特种作战”。
>
> **“火攻”不是真的教你放火，而是“非常规打击手段”的代名词——突发、剧烈、具有破坏性，利用外部条件（天时、地利、内应）在瞬间改变战局。** 但孙子在讲完火攻的五种方式后，话锋一转，给出了全篇最深刻的警告：**“主不可以怒而兴师，将不可以愠而致战。”** ——不要因为愤怒而发动战争，不要因为情绪而做出决策。
>
> 全篇核心就八个字：**火发于内，早应于外**。
>
> 本文将用2026年A股的批量风险提示潮、ST股连板与退市危机、央行的“火线救市”、管理层的“精准降温”、东鹏饮料的AI谣言黑天鹅、气派科技的“过山车”行情、新能源汽车的“最严电池令”、思必驰的经销商举报门等真实案例，彻底拆解这套“非常规打击 + 情绪管理”的实战框架。


## 第一章：开篇定调——五种火攻，五种打法

### 原文第一段
> **“孙子曰：凡火攻有五：一曰火人，二曰火积，三曰火辎，四曰火库，五曰火队。行火必有因，烟火必素具。发火有时，起火有日。时者，天之燥也；日者，月在箕、壁、翼、轸也。凡此四宿者，风起之日也。”**

### 🔍 五种火攻详解（附2026年A股翻译）

| 火攻类型 | 原文 | 攻击目标 | 2026年A股翻译 |
| :--- | :--- | :--- | :--- |
| **火人** | 火人 | 烧杀敌军士兵 | **攻击市场情绪**——制造恐慌、引发踩踏 |
| **火积** | 火积 | 烧毁敌军粮草物资 | **攻击筹码结构**——砸盘、出货、击穿关键价位 |
| **火辎** | 火辎 | 烧毁敌军辎重装备 | **攻击行业基本面**——做空报告、财务质疑 |
| **火库** | 火库 | 烧毁敌军仓库 | **攻击核心资产**——暴雷、黑天鹅、退市 |
| **火队** | 火队 | 烧毁敌军运输线 | **攻击流动性**——断融资、断资金链 |

## 第二章：“发火有时”——时机是火攻的第一要素

### 原文核心
> **“发火有时，起火有日。时者，天之燥也；日者，月在箕、壁、翼、轸也。凡此四宿者，风起之日也。”**

### 🔍 深度解读

孙子说，火攻不是想放就放的——**要看“天时”** 。
- **“时”** ：天气干燥的时候（“天之燥”）——没有干燥的条件，火点不着。
- **“日”** ：特定的日子（月亮在箕、壁、翼、轸四宿时）——这些日子容易起风。

### 🧠 2026年翻译：火攻的“天时”

2026年A股的每一次“火攻”，都有其特定的“天时”：

| “火攻”事件 | “天时”（触发条件） |
| :--- | :--- |
| **批量风险提示公告潮** | 科技股半年暴涨，估值泡沫巨大；6月陆家嘴论坛监管定调；半年报业绩窗口期 |
| **ST股涨停潮** | 7月6日交易新规落地（涨跌幅5%→10%）——制度变化就是“天时” |
| **东鹏饮料AI谣言** | 三家投行同步下调目标价；市场本就对增长预期偏谨慎——情绪脆弱就是“天时” |
| **气派科技“过山车”** | 行业消息催化情绪高涨——消息刺激就是“天时” |

### 📊 2026年案例：科创50的“火攻日”

2026年7月2日，科创50指数单日暴跌**7.7%** ，创自2025年4月7日以来最大跌幅。

**这把“火”的“天时”是什么？**

| 因素 | 细节 |
| :--- | :--- |
| **“天之燥”** | 科技股上半年涨太多，估值泡沫巨大，情绪极度亢奋——越“燥”越容易着火 |
| **“风起之日”** | 7月1日科技板块集中调整；海外市场悲观情绪传导；国内科技板块调整与海外下跌“互相强化” |

> **金句提炼：火不是你想放就能放的——要看天时、看风向、看湿度。在市场情绪最“燥”的时候，一根火柴就能点燃整片森林。**


## 第三章：“火发于内，早应之于外”——内外配合，才能烧透

### 原文核心
> **“凡火攻，必因五火之变而应之。火发于内，早应之于外。”**

### 🔍 深度解读

火攻最核心的原则：**火从内部烧起来，外部要及早接应。**

如果火从内部烧起来了（比如敌军内部有人放火、粮草自燃），外部部队要**第一时间**接应进攻——不能等火灭了再动手。

### 🧠 2026年翻译：内外配合的收割逻辑

2026年A股的各种“火攻”事件，几乎都遵循了“火发于内，早应之于外”的逻辑：

| “火攻”事件 | “火发于内”（内部引爆） | “早应之于外”（外部反应） |
| :--- | :--- | :--- |
| **科技股批量风险提示** | 上市公司内部自曝：无HBM业务、无建厂计划、AI光学尚未贡献业绩 | 外部资金快速撤离，板块集体暴跌 |
| **ST股涨停潮** | ST股内部：退市风险、立案调查 | 外部游资借新规炒作，但基本面“火”已烧起 |
| **东鹏饮料谣言** | 内部：投行下调目标价 | 外部：AI谣言引爆恐慌，70亿市值蒸发 |
| **气派科技“过山车”** | 内部：异动公告揭示基本面硬伤 | 外部：资金快速离场，叠加获利盘兑现 |

### 📊 2026年案例：管理层的“精准降温”——火攻的顶层设计

2026年6月17日，A股科技炒作行情迎来分水岭：

**“火发于内”：**
- 白天，陆家嘴论坛重磅定调：证监会主席吴清公开表态，将严查严处假借AI、硬科技之名蹭热点、炒概念、操纵市场、内幕交易等全链条违法违规行为

**“早应之于外”：**
- 当晚，**72家**高位热门科技概念股连夜扎堆发布风险提示公告
- 属于**窗口指导下的集体风险自查**
- 高位炒作情绪直接承压

**监管层的逻辑：**
> 先“点火”（内部定调），然后让上市公司“自燃”（批量发公告），最后外部市场“灭火”（炒作降温）。
>
> **“火发于内，早应之于外”的完美演绎。**


## 第四章：“火攻”的致命风险——火可以烧敌，也可以自焚

### 原文核心
> **“火发而其兵静者，待而勿攻；极其火力，可从而从之，不可从而止。火可发于外，无待于内，以时发之。火发上风，无攻下风。昼风久，夜风止。凡军必知有五火之变，以数守之。”**

### 🔍 深度解读

孙子在这一段给出了火攻的**风险控制原则**：

| 原则 | 原文 | 含义 | 2026年翻译 |
| :--- | :--- | :--- | :--- |
| **观察反应** | 火发而其兵静者，待而勿攻 | 火起后敌人很镇定——等一等，不要急着进攻 | 利空消息出来后股价不跌——可能有更大的“火”在后面 |
| **见好就收** | 极其火力，可从而从之，不可从而止 | 火势最大时能攻就攻，不能攻就停 | 炒到最热的时候能跑就跑，跑不了就别硬来 |
| **注意风向** | 火发上风，无攻下风 | 火从上风烧来，不要在下风攻击 | 趋势向下时不要逆势操作 |
| **掌握变化** | 凡军必知有五火之变，以数守之 | 必须掌握五种火攻的变化规律 | 必须掌握五种“非常规打击”的规律和应对方法 |

### 📊 2026年案例一：气派科技的“火发上风，无攻下风”

2026年7月1日，气派科技以20%涨幅强势涨停，成交额高达10.24亿元。

**7月2日，气派科技大幅回调18%，几乎抹平昨日涨幅，市值失守50亿元**。

**这就是“火发上风，无攻下风”的反面教材：**
- 昨天的涨停是“火”（情绪高涨）
- 今天的跌停是“风”（风向变了）
- 在“上风”（高位）点火的人，被“下风”（回调）烧死了

**孙子的警告：**
> **“火发上风，无攻下风。”**
>
> **火从上风烧过来了，你站在下风——要么跑，要么被烧死。**
>
> **气派科技昨天的追高者，就是站在“下风”的人。**

### 📊 2026年案例二：风华高科的“极其火力，不可从则止”

2026年5月18日至6月29日，风华高科连续30个交易日内的收盘价格累计涨幅偏离值达到200%，触及股票交易严重异常波动情形。

**7月1日，风华高科跌停**。

**这就是“极其火力，可从而从之，不可从而止”的案例：**
- 股价涨了2.2倍——“火”已经烧到最大
- 公司主动“泼凉水”——“火”该灭了
- 追高者没有“止”（停止买入），而是继续冲——结果被套

> **金句提炼：火最旺的时候，往往是离场的时候，而不是进场的时候。“极其火力，可从而从之，不可从而止”——火势最大时，能跑就跑，跑不了就别硬来。**


## 第五章：全篇最深刻的警告——“主不可以怒而兴师”

### 原文核心
> **“夫战胜攻取，而不修其功者凶，命曰费留。故曰：明主虑之，良将修之。非利不动，非得不用，非危不战。主不可以怒而兴师，将不可以愠而致战。合于利而动，不合于利而止。怒可以复喜，愠可以复悦，亡国不可以复存，死者不可以复生。故明君慎之，良将警之，此安国全军之道也。”**

### 🔍 逐字精讲

这是《孙子兵法》全书**最深刻、最震撼的一段**——孙子在讲完火攻（非常规打击）的全部技巧后，突然话锋一转，给出了极其严厉的警告：

| 原文 | 翻译 | 核心含义 |
| :--- | :--- | :--- |
| **非利不动** | 没有利益就不要行动 | **不要为了“爽”而出手** |
| **非得不用** | 没有必胜把握就不要用兵 | **不要为了“赌”而出手** |
| **非危不战** | 不到危急关头就不要打仗 | **不要为了“证明自己”而出手** |
| **主不可以怒而兴师** | 君主不能因为愤怒而发动战争 | **不要在情绪激动时做重大决策** |
| **将不可以愠而致战** | 将领不能因为恼怒而出战 | **不要在生气时做交易** |
| **合于利而动，不合于利而止** | 符合利益就行动，不符合就停止 | **一切以“利”为判断标准** |
| **怒可以复喜，愠可以复悦** | 愤怒会过去，恼怒会消散 | **情绪是暂时的** |
| **亡国不可以复存，死者不可以复生** | 国家灭亡了不能复存，人死了不能复生 | **损失是不可逆的** |

### 🧠 2026年翻译（投资版）

| 孙子原文 | 2026年投资翻译 |
| :--- | :--- |
| **非利不动** | 没有确定性机会就不出手——不要为了“交易快感”而买卖 |
| **非得不用** | 没有研究透彻的股票就不买——不要听消息、跟风 |
| **非危不战** | 不到万不得已不重仓——不要“All in” |
| **主不可以怒而兴师** | 亏钱了不要急着“扳回来”——越急越亏 |
| **将不可以愠而致战** | 被套了不要因为生气而死扛——该割就割 |
| **合于利而动，不合于利而止** | 买入前问自己：这符合我的长期利益吗？ |
| **怒可以复喜，愠可以复悦** | 今天的亏损会过去的——不要因为一时得失而冲动 |
| **亡国不可以复存，死者不可以复生** | 本金亏没了就真的没了——**保住本金是第一原则** |

### 📊 2026年案例：79%散户亏损的根源——“怒而兴师”

2026年上半年，79%的散户账户亏损。人均亏损2.1万。

**为什么这么多人亏钱？**

| 散户行为 | 对应的“怒而兴师” |
| :--- | :--- |
| 看到科技股暴涨，FOMO（害怕错过）追高 | **“怒”——贪婪之怒** |
| 追高后被套，因为“不甘心”而死扛 | **“愠”——恼怒之愠** |
| 死扛到退市，本金归零 | **“亡国不可以复存”** |
| 亏钱后急着“扳回来”，换股再亏 | **“怒可以复喜，但本金回不来了”** |

> **金句提炼：情绪是投资最大的敌人。愤怒会过去，恼怒会消散——但本金亏没了，就真的没了。**


## 第六章：“合于利而动”——决策的唯一标准

### 原文核心
> **“合于利而动，不合于利而止。”**

### 🔍 深度解读

这句话只有12个字，但它是《孙子兵法》全书的**决策总纲**。

**所有的判断标准，只有一条：这件事符合我的利益吗？**

- 符合 → 行动
- 不符合 → 停止
- 不清晰 → 也停止（因为“不清晰”本身就不符合利益）

### 🧠 2026年翻译：买入前的“三问”

在你2026年买入任何一只股票前，问自己三个问题：

| 问题 | 检查项 |
| :--- | :--- |
| **“合于利而动”** | 这笔交易符合我的长期利益吗？（不是短期爽一把） |
| **“非得不用”** | 我真的研究透这只股票了吗？（不是听消息、跟风） |
| **“非危不战”** | 这笔钱我亏得起吗？（不是“All in”赌一把） |

**如果三个问题有任何一个是“否”——不要买。**

### 📊 2026年案例：央行“净放水”2000亿——“合于利而动”的宏观版

2026年7月3日，A股连续杀跌的关键时刻。科创50指数暴跌7.7%，创业板指暴跌5.71%。

**央行出手了：**
- 宣布7月6日开展**10000亿元**买断式逆回购操作
- 当日有8000亿元到期
- 实际“净放水”**2000亿元**

**央行为什么出手？**

> **“合于利而动”——符合国家利益（稳定市场、防止系统性风险）。**
>
> **“不合于利而止”——如果市场没有系统性风险，央行不会出手。**

## 第九章：火攻篇与前十二篇的逻辑串联

至此，前十二篇构成了一个完整的“实战十二部曲”：

| 篇章 | 核心问题 | 决策输出 |
| :--- | :--- | :--- |
| **始计篇** | 这仗值不值得打？ | “打”或“不打” |
| **作战篇** | 我打得起吗？ | “速打”或“缓打” |
| **谋攻篇** | 怎么用最小的代价打？ | “伐谋/伐交/伐兵/攻城” |
| **军形篇** | 我现在具备必胜条件了吗？ | “现在打”或“再等等” |
| **兵势篇** | 我该怎么出手？ | “正兵稳、奇兵狠” |
| **虚实篇** | 我打对手哪里？ | “避实击虚” |
| **军争篇** | 我怎么抢在对手前面到达？ | “以迂为直、风林火山” |
| **九变篇** | 如果情况变了怎么办？ | “随机应变” |
| **行军篇** | 我怎么观察敌情？ | “处军相敌” |
| **地形篇** | 不同地形怎么打？ | “六形六败” |
| **九地篇** | 不同战场环境怎么打？ | “九地九变” |
| **火攻篇** | 非常规打击怎么用？ | “五火五变、慎战戒怒” |

**火攻篇的特殊地位：**
> 前十一篇教的是“常规战争”——怎么算、怎么打、怎么等、怎么变。
>
> 第十二篇教的是“非常规战争”——用火（突发事件）瞬间改变战局。
>
> **但孙子在讲完火攻后，立刻给出了全书最严厉的警告：不要因为情绪而行动！**
>
> **这意味着：火攻（非常规手段）是最后的手段，不是首选。能用常规手段解决的问题，不要用火攻。**
