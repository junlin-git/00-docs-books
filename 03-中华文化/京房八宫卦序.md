# 京房八宫卦（纳甲世应系统）· 完善全览

> 此为西汉京房（公元前77–前37年）在原始八卦基础上创立的“占卜运算系统”。  
> **核心逻辑**：以八纯卦为“本宫”，通过**逐爻递变**（一世→二世→三世→四世→五世→游魂→归魂）生成一宫八卦，并配以**五行属性**与**天干地支（纳甲）**，再依五行生克推导出**六亲**（父母、兄弟、子孙、妻财、官鬼），专用于占卜断吉凶。  
> **与原始易经的本质区别**：不看卦辞爻辞，不看《易传》哲理，纯算五行生克与六亲旺衰。

---

## 一、核心递变逻辑（小白必读 · 逐爻怎么变）

京房将每一宫的 8 个卦按“变爻”顺序严格排列。**变爻规则**：从初爻（最底下）开始，逐级向上“翻转”（阳变阴，阴变阳）。

### 变化路径图（以乾宫为例，一步一步带你看）

| 阶段 | 卦名 | 卦符 | 哪些爻变了？ | 下卦（内卦） | 上卦（外卦） | 说明 |
| :---: | :--- | :---: | :---: | :---: | :---: | :--- |
| **本宫** | 乾为天 | <span style="font-size:3em;">䷀</span> | 一爻未变 | 乾（☰） | 乾（☰） | 纯卦，祖宗 |
| **一世** | 天风姤 | <span style="font-size:3em;">䷫</span> | **初爻**变 | 巽（☴） | 乾（☰） | 只动最底层 |
| **二世** | 天山遁 | <span style="font-size:3em;">䷠</span> | **初、二**爻变 | 艮（☶） | 乾（☰） | 往上再动一层 |
| **三世** | 天地否 | <span style="font-size:3em;">䷋</span> | **初、二、三**爻变 | 坤（☷） | 乾（☰） | 下卦全变（人位） |
| **四世** | 风地观 | <span style="font-size:3em;">䷓</span> | **初至四**爻变 | 坤（☷） | 巽（☴） | 开始动上卦 |
| **五世** | 山地剥 | <span style="font-size:3em;">䷖</span> | **初至五**爻变 | 坤（☷） | 艮（☶） | 上卦只剩最顶没动 |
| **游魂** | 火地晋 | <span style="font-size:3em;">䷢</span> | 外卦全变后，**返变第四爻** | 坤（☷） | 离（☲） | 不继续动上爻，回头动四爻 |
| **归魂** | 火天大有 | <span style="font-size:3em;">䷍</span> | **下卦恢复本宫内卦（乾）** | 乾（☰） | 离（☲） | 内卦回老家 |

> 🧠 **理解关键**：五爻变尽后，**不返变上爻**（上爻永远不动，代表“祖宗位”），而是回头变第四爻，称为“游魂”；最后下卦整个回归本宫下卦，称为“归魂”。此即京房所言 **“游魂归魂为鬼易”**。

## 二、八宫五行与纳甲（天干地支）总表

所有变卦的纳甲，**全部继承自本宫纯卦**，不因爻变而改变。下表是八宫的“基因编码”：

| 宫位 | 五行属性 | 上卦纳干 | 下卦纳干 | 六爻纳支（自下而上：初→二→三→四→五→上） |
| :---: | :---: | :---: | :---: | :--- |
| **乾宫** | 金 | 壬 | 甲 | 子（初）→ 寅 → 辰 → 午（四）→ 申 → 戌（上） |
| **坤宫** | 土 | 癸 | 乙 | 未（初）→ 巳 → 卯 → 丑（四）→ 亥 → 酉（上） |
| **震宫** | 木 | 庚 | 庚 | 子 → 寅 → 辰 → 午 → 申 → 戌（震纳庚，支同乾） |
| **巽宫** | 木 | 辛 | 辛 | 丑 → 亥 → 酉 → 未 → 巳 → 卯 |
| **坎宫** | 水 | 戊 | 戊 | 寅 → 辰 → 午 → 申 → 戌 → 子 |
| **离宫** | 火 | 己 | 己 | 卯 → 丑 → 亥 → 酉 → 未 → 巳 |
| **艮宫** | 土 | 丙 | 丙 | 辰 → 午 → 申 → 戌 → 子 → 寅 |
| **兑宫** | 金 | 丁 | 丁 | 巳 → 卯 → 丑 → 亥 → 酉 → 未 |

> 📌 **干支五行速查**：  
> - 子、亥 = 水  
> - 寅、卯 = 木  
> - 巳、午 = 火  
> - 申、酉 = 金  
> - 辰、戌、丑、未 = 土

## 三、六亲推导法则（断卦的核心工具）

“六亲”就是把五行生克关系，**转化成社会人际关系**，方便断卦时直观理解。规则如下：

以 **本宫五行** 为“我”（太极点），看每一爻的纳支五行与“我”的生克关系：

| 关系 | 命名 | 含义 | 推导规则 |
| :---: | :---: | :--- | :--- |
| **生我者** | 父母 | 庇护、长辈、文书 | 五行生“我”的爻 |
| **我生者** | 子孙 | 晚辈、下属、财源 | “我”所生的五行之爻 |
| **克我者** | 官鬼 | 官位、灾祸、丈夫 | 五行克“我”的爻 |
| **我克者** | 妻财 | 财富、妻子、资源 | “我”所克的五行之爻 |
| **同我者** | 兄弟 | 同辈、同伴、竞争 | 与“我”五行相同的爻 |

### 🧮 举例：乾宫（五行属金）

- **我 = 金**
- 初爻纳支 **子**（水）—— 金生水 → 我生者 → **子孙**
- 二爻纳支 **寅**（木）—— 金克木 → 我克者 → **妻财**
- 三爻纳支 **辰**（土）—— 土生金 → 生我者 → **父母**
- 四爻纳支 **午**（火）—— 火克金 → 克我者 → **官鬼**
- 五爻纳支 **申**（金）—— 同我 → **兄弟**
- 上爻纳支 **戌**（土）—— 土生金 → 生我者 → **父母**

> 💡 只要你记住本宫的五行，任何一个变卦的六亲，都可以照此逐爻推导出来，完全不用死记硬背。

## 四、世爻定位法则（附记忆口诀）

**世爻** = 卦主之位，代表占卜者自身。定世爻是起卦后第一步。

### 八宫世位总规律（与“几世卦”严格对应）

| 卦的分类 | 世爻位置 | 应爻位置（世隔两位） |
| :---: | :---: | :---: |
| 本宫（纯卦） | 上爻（第6爻） | 三爻 |
| 一世卦 | 初爻（第1爻） | 四爻 |
| 二世卦 | 二爻（第2爻） | 五爻 |
| 三世卦 | 三爻（第3爻） | 上爻（第6爻） |
| 四世卦 | 四爻（第4爻） | 初爻 |
| 五世卦 | 五爻（第5爻） | 二爻 |
| 游魂卦 | 四爻（第4爻） | 初爻 |
| 归魂卦 | 三爻（第3爻） | 上爻（第6爻） |

### 🧠 快速记忆口诀

> **“世应相隔两位间，本宫世上是祖先；  
> 一世初爻二世二，三四五爻依次连；  
> 游魂归魂特殊位，游四归三莫乱颠。”**

## 六、实战断卦三步骤（京房体系）

当你用铜钱摇出一卦后，按以下顺序操作：

1. **定宫位与世应**  
   - 根据卦的六爻组合，查出它属于哪一宫（乾、坤、震……），以及是几世卦。  
   - 世爻就是“你自己”，应爻就是“对方/环境”。

2. **配纳甲与六亲**  
   - 按本宫的纳甲表，给六个爻安上天干地支。  
   - 以本宫五行为“我”，逐爻推导出六亲（父母、兄弟、子孙、妻财、官鬼）。

3. **看生克旺衰断吉凶**  
   - 看世爻与应爻的五行生克关系（世克应吉，应克世凶）。  
   - 看用神（比如问财运看妻财爻）是否旺相、有无生扶。  
   - 看卦中是否有动爻（老阳老阴），动爻带来的变卦进一步影响结果。

> ⚠️ **京房断卦不看《周易》卦辞爻辞**，完全依靠五行生克、六亲关系和日月建（时间因素）来综合判断。这是它与原始易经最根本的分水岭。
