# 《道德经·安民第三》超详细深度解读 —— 不尚贤，使民不争

> 本篇导读：前两章，老子构建了“道”的本体论（体道第一）和“相对论”的方法论（养身第二）。第三章则从“宇宙哲学”正式转向“政治哲学”和“人生哲学”——老子开始谈一个极其现实的问题：**如何让社会安定、人心不浮躁？**
>
> 老子给出的答案极其颠覆：**不要推崇“贤能”，不要追求“奇珍异宝”，不要炫耀“欲望之物”。** 他认为，社会动乱、人心焦虑的根源，恰恰是“推崇”和“追求”本身。
>
> 全篇核心就十个字：**不尚贤，不贵货，不见可欲**。
>
> 本文将用2026年A股的极致内卷（公募基金经理批量离任、研究员年薪腰斩）、年轻人的“反内卷”浪潮、价值投资的“不尚贤”、国家队买入沪深300ETF的“不见可欲”等真实案例，彻底拆解这套“去魅”的思维框架。


## 第一章：原文与逐字精讲

### 原文

> **不尚贤，使民不争；**
> **不贵难得之货，使民不为盗；**
> **不见可欲，使民心不乱。**
>
> **是以圣人之治，虚其心，实其腹，弱其志，强其骨。**
> **常使民无知无欲，使夫智者不敢为也。**
> **为无为，则无不治。**

## 第二章：第三章的哲学内涵——四个核心命题

### 命题一：“不尚贤”——不要再卷“名”了

**【讲解】**

老子说：“不尚贤，使民不争。”

这句话在今天听起来极其“反直觉”——我们从小就被教育“要做一个对社会有贡献的人”“要争当先进”“要出人头地”。

但老子说：**恰恰是“推崇贤能”这个行为本身，导致了社会的争斗和不和谐。**

- 你推崇“聪明”，就会有人装聪明。
- 你推崇“成功”，就会有人不择手段去追求成功。
- 你推崇“第一名”，就会有人为了第一名而不顾一切。

**【现代延伸】**

2026年的中国，正在经历一场深刻的“反内卷”浪潮。

**2026年金融行业的“尚贤之痛”：**

2026年上半年，金融行业经历了一场前所未有的“去魅”：

| 现象 | 数据 | 含义 |
| :--- | :--- | :--- |
| 公募基金经理离任 | 2026年上半年离任人数创新高 | 曾经的“金饭碗”不再光鲜 |
| 研究员年薪腰斩 | 部分券商研究员年薪从百万降至50万 | “贤能”的溢价在消失 |
| 证券从业人员流失 | 多家券商裁员降薪 | 行业光环褪去 |
| 经纪业务收入下滑 | 佣金率持续走低 | “卷”到极致后的自然出清 |

2026年4月底，**年内已有超百位基金经理离任**，行业头部机构亦未能幸免。另一边，研究员群体也在经历现实阵痛——受降费、降佣冲击，**部分券商研究员年薪已从峰值时期的百万级别腰斩**。

**这些现象的背后，正是“尚贤”的终结——**
- 当所有人都想当“贤能”（基金经理、研究员、投行精英）时，“贤能”就不再值钱了。
- 当社会过度推崇一个行业时，这个行业就会过度拥挤、过度竞争、最终所有人一起受伤。

**“不尚贤”的2026年翻译：**
> **不要盲目追逐“热门赛道”“热门岗位”“热门标签”。所有人都去卷的地方，一定是最卷的、最不赚钱的。**

> **金句提炼：尚贤则争，争则乱。2026年，过度追捧的任何东西，最终都会“反噬”追捧它的人。**


### 命题二：“不贵难得之货”——不要被“稀缺”绑架

**【讲解】**

老子说：“不贵难得之货，使民不为盗。”

“难得之货”就是稀缺的东西——黄金、玉石、限量版、奢侈品。老子说：**你越把稀缺的东西当宝贝，就越有人为了得到它而不择手段。**

- 你炒作“茅台是奢侈品”→ 就会有人囤积茅台、假酒泛滥。
- 你炒作“学区房是稀缺资源”→ 就会有人天价抢房、焦虑内卷。
- 你炒作“AI芯片是战略物资”→ 就会有人囤货、炒货、哄抬价格。

**【现代延伸】**

2026年，A股市场正在经历一轮“不贵难得之货”的洗礼。

**2026年“难得之货”的泡沫破裂：**

| 曾经的“难得之货” | 2026年现状 |
| :--- | :--- |
| 白酒（茅台=稀缺） | 2026年上半年食品饮料跌19.52%，茅台被“新股王”联讯仪器（+2700%）全面碾压 |
| 核心资产（白马股=稀缺） | 2026年核心资产光环褪去，资金转向科技 |
| 学区房（教育资源=稀缺） | 房地产持续调整，学区房溢价大幅缩水 |
| AI概念股（算力=稀缺） | 2026年7月2日科创50暴跌7.7%，拥挤度过高的板块率先调整 |

**“不贵难得之货”的2026年翻译：**
> **不要被“稀缺”的故事绑架。今天被捧上神坛的“难得之货”，明天可能就变成无人问津的“寻常之物”。**

**价值投资的“不贵货”：**

真正的价值投资者，不会去追捧“热门股”“翻倍股”“概念股”。他们关注的是：**这个公司到底值多少钱？** 而不是 **“别人都在买，我也要买”**。

2026年，价值投资者的重仓股可能是“无人问津”的：

| 类型 | 2026年表现 | “难得”程度 |
| :--- | :--- | :--- |
| 银行股 | 高股息、低估值、PB 0.5倍 | 不“难得”，但确定性高 |
| 公用事业股 | 现金流稳定、分红率高 | 不“难得”，但收益稳定 |
| 消费龙头 | 跌了25%，但基本面没变 | 现在“不难得”了，反而是机会 |

> **金句提炼：别买“难得”的，买“值得”的。当所有人都觉得某个东西“难得”的时候，它往往已经太贵了。**


### 命题三：“不见可欲”——不要炫富，不要刺激欲望

**【讲解】**

老子说：“不见可欲，使民心不乱。”

“可欲”就是能勾起人欲望的东西——奢侈品、豪车、豪宅、晒收入、晒成功。老子说：**你不要炫耀这些东西，老百姓看到就不会心乱。**

- 你天天在朋友圈晒豪车→ 别人看了心乱、焦虑、也想买豪车。
- 你天天晒涨停板→ 别人看了心乱、追涨、最终被套。
- 你天天晒“我赚了多少”→ 别人看了心乱、觉得自己不行、焦虑失眠。

**【现代延伸】**

2026年，社交媒体上的“炫富”正在退潮，取而代之的是“低调”和“务实”。

**2026年的“不见可欲”现象：**

| 过去（“见可欲”） | 2026年（“不见可欲”） |
| :--- | :--- |
| 晒豪车、晒豪宅、晒奢侈品 | 晒健康、晒生活、晒平淡幸福 |
| 晒涨停板、晒收益截图 | 不晒单、不炫耀、闷声赚钱 |
| “我一个月赚了50%” | “今年收益还行，不说了” |
| 消费主义、买买买 | 理性消费、存钱、极简生活 |

2026年，越来越多的年轻人开始“反向消费”——不追求品牌、不追求奢侈品、不追求“别人眼中的成功”。他们追求的是“实在”——把钱花在真正能让自己快乐的地方。

**在投资中，“不见可欲”意味着：**

> **不要被社交媒体上的“收益截图”刺激。**
> **你看到的“别人赚了50%”，可能是P的、可能是运气的、可能是假的。**
> **你越是被“可欲”刺激，就越容易做出错误的决策。**

**2026年7月2日，科创50暴跌7.7%。那些在6月底被“赚钱效应”（可欲）刺激追高的人，一天之内亏了7.7%。**

> **金句提炼：别让别人的“可欲”乱你的心。你看到的是“别人赚了”，你看不到的是“别人亏了”和“别人赚了但没告诉你”。**


### 命题四：“虚其心，实其腹”——治理的“减法”哲学

**【讲解】**

老子说：“是以圣人之治，虚其心，实其腹，弱其志，强其骨。”

这四句话是老子的“治国药方”，也是“修身药方”：

| :--- | :--- | :--- |
| **虚其心** | 让内心虚静、减少杂念 | 焦虑、内卷、信息过载、停不下来 |

| **强其骨** | 强健体魄、身体健康 | 熬夜、久坐、亚健康、过劳 |

**【现代延伸】**

2026年的“内卷”本质上就是“志太强、心太满”——

| 维度 | 现代社会的“过” | 老子的“药” |
| :--- | :--- | :--- |
| **心** | 信息过载、焦虑、攀比 | 虚其心——关掉朋友圈、少看盘、多冥想 |
| **腹** | 垃圾食品、外卖、暴饮暴食 | 实其腹——吃得健康、吃得规律 |
| **志** | 人人想“逆天改命”“财务自由” | 弱其志——接受平凡、踏实做事 |
| **骨** | 熬夜、久坐、过劳 | 强其骨——锻炼身体、规律作息 |

**2026年，那些在A股里“收获”最多的人，往往不是天天盯盘的人——而是“虚其心”（心态平静、不焦虑）的人。**

> **金句提炼：虚其心才能看清趋势，实其腹才能稳住心态，弱其志才能不追涨杀跌，强其骨才能活得久、赚得久。**

| **我在争“名”吗？** | 我炒股是为了“证明自己很厉害”，还是为了“长期稳健增值”？ |
| **我的“贤”会变吗？** | 今天的“热门”基金经理、热门赛道，明天还会是“热门”吗？ |

### 第二步：检查“贵货”陷阱——我是不是被“稀缺”绑架了？

| 问题 | 检查项 |
| :--- | :--- |
| **这个“难得”是真实的吗？** | 这只股票“稀缺”是因为基本面好，还是因为“大家都说它好”？ |
| **这个“难得”还值得买吗？** | 大家都觉得“难得”的时候，往往已经太贵了 |
| **有没有“不难得”的机会？** | 那些“无人问津”的板块，有没有被低估的机会？ |

### 第三步：检查“见可欲”陷阱——我是不是被“刺激”了？

| 问题 | 检查项 |
| :--- | :--- |
| **我在被什么“刺激”？** | 社交媒体上的收益截图、朋友推荐的“暴富故事”、媒体的“牛市来了” |
| **这些“刺激”是真的吗？** | 别人晒的收益是真的吗？还是只晒了赚钱的、没晒亏钱的？ |
| **我能“不见可欲”吗？** | 能不能少刷股吧、少看盘、多研究基本面？ |

### 第四步：做到“虚其心，实其腹，弱其志，强其骨”

| 操作 | 2026年投资版 |
| :--- | :--- |
| **虚其心** | 减少杂念、减少焦虑、不追涨杀跌 |
| **实其腹** | 扎实研究基本面、吃透行业逻辑 |
| **弱其志** | 不强求“跑赢所有人”，接受合理收益 |
| **强其骨** | 保持身体健康、心态稳定，才能熬过市场周期 |

### 第五步：践行“为无为”

| 操作 | 含义 |
| :--- | :--- |
| **不乱动** | 没有确定性机会时，不强行交易 |
| **不折腾** | 看准了再出手，出手了就不乱动 |
| **不妄为** | 不在情绪激动时做决策 |
| **顺自然** | 顺应产业趋势，不逆势而为 |

## 第六章：安民第三与《道德经》《孙子兵法》的逻辑串联

### 《道德经》前三章的逻辑递进：

| 篇章 | 核心命题 | 层面 |
| :--- | :--- | :--- |
| **体道第一** | 道不可道，有无之辨 | **世界观**——世界是什么？ |
| **养身第二** | 有无相生，功成弗居 | **方法论**——怎么看待世界？ |
| **安民第三** | 不尚贤，不贵货，不见可欲 | **实践论**——怎么在这个世界做事？ |

**第一章告诉你“世界是什么”，第二章告诉你“怎么看待世界”，第三章告诉你“在这个世界里怎么行动”。**

### 与《孙子兵法》的串联：

| 《道德经》概念 | 《孙子兵法》对应 |
| :--- | :--- |
| **不尚贤** | 始计篇“五事七计”——不要被“热门股”的标签迷惑，要看本质 |
| **不贵货** | 虚实篇“避实击虚”——不追“稀缺”的热门股，寻找被低估的“虚”处 |
| **不见可欲** | 军争篇“避其锐气”——不被市场的“赚钱效应”刺激，在情绪亢奋时保持冷静 |
| **虚其心** | 军形篇“先为不可胜”——心静才能看清趋势，不焦虑才能做好风控 |
| **弱其志** | 谋攻篇“不战而屈人之兵”——不强求“打败市场”，而是“顺应市场” |
| **为无为** | 九变篇“君命有所不受”——不乱操作、不妄为 |

> **“为无为，则无不治。”**

2026年的投资世界，最稀缺的不是“信息”，不是“资金”，也不是“技术”——而是 **“不被刺激的心”** 。

- 不被“热门赛道”刺激（不尚贤）
- 不被“稀缺概念”刺激（不贵货）
- 不被“别人赚了多少”刺激（不见可欲）

**能“不见可欲”的人，才能“心不乱”；**
**心不乱的人，才能看清趋势；**
