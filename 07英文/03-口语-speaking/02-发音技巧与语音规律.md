# 发音技巧与语音规律

好口语的基础是准确的发音。本章系统介绍英语的音标体系、连读规律、重音规则和语调模式。

---

## 第一章：国际音标（IPA）快速入门

### 1.1 元音（Vowels）

英语有 20 个元音音素，分为单元音和双元音。

**单元音（12个）**：

| 音标 | 示例词 | 发音要领 |
|------|--------|---------|
| /iː/ | see, me, tree | 双唇向两侧伸展，发长音 |
| /ɪ/ | sit, big, fish | 比 /iː/ 短促，嘴不太用力 |
| /e/ | bed, head, ten | 嘴半开，舌位居中 |
| /æ/ | cat, hand, back | 嘴大开，舌前部抬起 |
| /ɑː/ | car, father, arm | 嘴大开，舌后，发长音 |
| /ɒ/ | hot, dog, stop | 嘴大开圆，发短音（英式） |
| /ɔː/ | law, call, door | 嘴圆，发长音 |
| /ʊ/ | foot, book, push | 嘴稍圆，发短促音 |
| /uː/ | food, school, moon | 双唇收圆，发长音 |
| /ʌ/ | cup, bus, love | 嘴半开，舌中部位置 |
| /ɜː/ | bird, word, nurse | 嘴半开圆，r音化（美式） |
| /ə/ | about, sofa, again | **最常见元音**，轻松发"额" |

**双元音（8个）**：

| 音标 | 示例词 | 滑动方向 |
|------|--------|---------|
| /eɪ/ | face, make, day | /e/ → /ɪ/ |
| /aɪ/ | price, my, time | /a/ → /ɪ/ |
| /ɔɪ/ | boy, join, choice | /ɔ/ → /ɪ/ |
| /əʊ/ | go, home, road | /ə/ → /ʊ/ (英式) |
| /oʊ/ | go, home, road | /o/ → /ʊ/ (美式) |
| /aʊ/ | mouth, now, how | /a/ → /ʊ/ |
| /ɪə/ | ear, here, near | /ɪ/ → /ə/ |
| /eə/ | air, there, care | /e/ → /ə/ |

### 1.2 辅音（Consonants）

**清辅音与浊辅音对比**（清辅音不振动声带，浊辅音振动声带）：

| 清辅音 | 浊辅音 | 位置 | 示例 |
|--------|--------|------|------|
| /p/ | /b/ | 双唇 | **p**en / **b**en |
| /t/ | /d/ | 齿龈 | **t**en / **d**en |
| /k/ | /g/ | 软腭 | **c**ap / **g**ap |
| /f/ | /v/ | 唇齿 | **f**an / **v**an |
| /θ/ | /ð/ | 齿间 | **th**ink / **th**is |
| /s/ | /z/ | 齿龈 | **s**eal / **z**eal |
| /ʃ/ | /ʒ/ | 腭 | **sh**oe / trea**s**ure |
| /tʃ/ | /dʒ/ | 腭 | **ch**air / **j**ump |

**难点辅音**：

| 音标 | 中国学习者常见错误 | 正确发音要领 |
|------|-----------------|-------------|
| /θ/ think, three | 发成 /s/ 或 /t/ | 舌尖轻放上齿背，气流通过 |
| /ð/ this, that | 发成 /z/ 或 /d/ | 舌尖轻放上齿背，声带振动 |
| /v/ very, live | 发成 /w/ | 上齿轻咬下唇，声带振动 |
| /r/ red, run | 舌尖抬起顶上腭 | 舌尖卷起，不碰任何地方 |
| /l/ love, ball | 词尾/l/不发音 | 词尾 /l/ (dark L)：舌尖抬起，喉音 |
| /w/ wine, wait | 发成 /v/ | 双唇收圆向外推，不用齿 |

## 第二章：连读规律（Linking）

连读是自然英语流利度的关键。以下是四大核心规律。

### 2.1 辅音+元音连读（Consonant-Vowel Linking）

前一个词以辅音结尾，后一个词以元音开头时，辅音滑入下一词：

| 书面形式 | 连读发音 | 例句 |
|---------|---------|------|
| turn it off | "tur-ni-toff" | **Turn it off** the light. |
| an apple | "a-napple" | I ate **an apple**. |
| pick it up | "pi-ki-tup" | Please **pick it up**. |
| not at all | "no-ta-tall" | **Not at all**, I'm happy to help. |
| take it easy | "ta-ki-tee-zy" | **Take it easy**! |

---

### 2.2 相同辅音省略（Consonant Elision）

两个相同（或相近）辅音相遇，只发一次：

| 书面形式 | 实际发音 |
|---------|---------|
| big game | "bi-game" |
| good day | "goo-day" |
| hot tea | "ho-tea" |
| black cat | "bla-cat" |
| some more | "so-more" |

---

### 2.3 /t/ 和 /d/ 的闪音（Flapping，美式英语）

美式英语中，/t/ 和 /d/ 在两个元音之间发成轻弱的"d"音（/ɾ/）：

| 书面形式 | 美式发音 |
|---------|---------|
| water | "wa-der" |
| better | "be-der" |
| butter | "bu-der" |
| city | "ci-dy" |
| little | "li-dl" |
| ladder / latter | 发音相同 |

---

### 2.4 /t/ 的弱化（T-glottalization，英式）

英式英语中，词中或词尾的 /t/ 常变成喉塞音（如"哼"一下）：

| 单词 | 发音现象 |
|------|---------|
| butter | "bu'er" |
| bottle | "bo'le" |
| important | "impor'ant" |
| that one | "tha' one" |

---

| for | /fɔː/ | /fə/ | wait **for** me |

## 第四章：词重音规律（Word Stress）

### 4.1 名词和动词重音区别（N/V 对）

部分词形相同，重音不同区分词性：

| 名词（重音在前） | 动词（重音在后） | 中文 |
|----------------|----------------|------|
| **RE**cord | re**CORD** | 记录 |
| **OB**ject | ob**JECT** | 反对/物体 |
| **PER**mit | per**MIT** | 允许/许可证 |
| **PRO**test | pro**TEST** | 抗议 |
| **IM**port | im**PORT** | 进口 |
| **EX**port | ex**PORT** | 出口 |
| **IN**crease | in**CREASE** | 增加 |
| **CON**duct | con**DUCT** | 行为/指挥 |
| **PRE**sent | pre**SENT** | 礼物/呈现 |
| **CON**tent | con**TENT** | 内容/满意的 |

---

### 4.2 后缀影响重音的规律

某些后缀会拉近重音：

| 后缀 | 规律 | 例子 |
|------|------|------|
| -tion/-sion | 重音在该音节前 | edu**CA**tion, deci**SION** |
| -ic/-ical | 重音在该音节前 | e**CO**nomic, his**TOR**ical |
| -ity | 重音在该音节前 | e**LEC**tricity, capa**CI**ty |
| -ify | 重音在该音节前 | i**DEN**tify, **JUS**tify |
| -ous | 不影响重音 | **FA**mous, **SER**ious |
| -ment | 不影响重音 | **MOVE**ment, **MAN**agement |

## 第五章：语调规律（Intonation）

### 5.1 两种基本语调

**下降调（Falling Intonation ↘）**：表示陈述、命令、完整信息
- 用于：陈述句、特殊疑问句（wh-questions）、感叹句
- She **lives in London**. ↘
- **Where** do you **come from**? ↘

**上升调（Rising Intonation ↗）**：表示询问、未完成信息、礼貌
- 用于：一般疑问句（yes/no questions）、列举中间项、请求确认
- **Are you** coming? ↗
- I'd like coffee, ↗ tea, ↗ or water. ↘

---

### 5.2 选择疑问句语调

列举选项：前项上升，最后一项下降：
> Do you want tea ↗ or coffee ↘?

---

### 5.3 降升调（Fall-Rise ↘↗）

表示**转折、保留、礼貌不同意**：
- **That's true ↘↗** (but there's something else...)
- **It's possible ↘↗** (but I'm not sure)

## 第六章：常见发音错误纠正

### 6.1 中国学习者常见错误

| 错误类型 | 错误示例 | 正确说法 | 原因 |
|---------|---------|---------|------|
| 词尾辅音不发音 | "tes" | test /test/ | 受汉语影响 |
| /r/ 和 /l/ 混淆 | "rice" → "lice" | 注意/r/舌尖卷起不碰腭 | — |
| /v/ 发成 /w/ | "very" → "wery" | /v/ 上齿咬下唇 | — |
| /θ/ 发成 /s/ | "think" → "sink" | 舌尖伸出轻咬 | — |
| 短元音发成长元音 | "ship" /ʃɪp/ → "sheep" /ʃiːp/ | 注意 /ɪ/ 短促 | — |
| 词尾-ed 发音 | "talked" 发"talkid" | /t/ 后-ed=/t/, /d/后-ed=/d/ | 不知规则 |

### 6.2 词尾 -ed 发音规则

| 规则 | 前面的音 | 发音 | 例词 |
|------|---------|------|------|
| 发 /ɪd/ | /t/ 或 /d/ | 额外加一个音节 | want**ed** /ˈwɒntɪd/, need**ed** |
| 发 /t/ | 其他清辅音 | 不加音节 | talk**ed** /tɔːkt/, stopp**ed** |
| 发 /d/ | 元音和浊辅音 | 不加音节 | play**ed** /pleɪd/, call**ed** |

### 6.3 词尾 -s 发音规则

| 规则 | 前面的音 | 发音 | 例词 |
|------|---------|------|------|
| 发 /ɪz/ | /s/,/z/,/ʃ/,/ʒ/,/tʃ/,/dʒ/ | 额外音节 | buses, roses, watches |
| 发 /s/ | 清辅音 | — | books /s/, cats /s/ |
| 发 /z/ | 元音和浊辅音 | — | dogs /z/, plays /z/ |
