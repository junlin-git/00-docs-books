### 每日学习计划（参考）

- **早晨 20 min**：复习昨日词汇 + 学习 20 个新词
- **午休 15 min**：读一篇文章，标注生词
- **晚上 30 min**：语法笔记 + 口语跟读练习

## 词汇学习建议

1. **间隔重复**：新词第 1/3/7/14/30 天各复习一次
2. **语境记忆**：把词放进例句里记，不要孤立背单词
3. **词族扩展**：学 `act`，同时记 `action / active / actively / activate`
4. **联想法**：`catastrophe`（灾难）= `cat`（猫）狂奔 `astrophe`（天体）→ 天体撞猫 → 大灾难

## 阅读技巧

- **略读（Skimming）**：快速获取主旨，看首尾段和每段首句
- **扫读（Scanning）**：寻找具体信息，如数据、名字、时间
- **精读（Close reading）**：理解逻辑、修辞和隐含意义
