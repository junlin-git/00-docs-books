## 二、数字/字母/日期专项听力训练

> 雅思听力Section 1必考内容。以下为高频考点类型及易错点。


### 1. 数字（Numbers）

| 类型 | 示例 | 易错点 |
| :--- | :--- | :--- |
| **电话号码** | 0791-234-5678 | double（两个相同数字），注意连读 |
| **手机号** | 07700 900 999 | 0读作"zero"或"oh" |
| **金额** | £15.75 | 小数点读作"point"，15.75 = fifteen point seventy-five |
| **日期** | 12th July, 2024 | 序数词（twelfth） |
| **年份** | 2023 | twenty twenty-three / two thousand and twenty-three |
| **时间** | 2:30 pm | half past two / two thirty |
| **百分数** | 37% | thirty-seven percent |
| **小数** | 0.5 | zero point five |
| **分数** | 2/3 | two thirds |

**数字听写训练表（易混淆数字对）**：
| 易混组合 | 区别提示 |
| :--- | :--- |
| 13 vs. 30 | thirTEEN（重音在后） vs. THIRty（重音在前） |
| 14 vs. 40 | fourTEEN vs. FORty |
| 15 vs. 50 | fifTEEN vs. FIFty |
| 16 vs. 60 | sixTEEN vs. SIXty |
| 17 vs. 70 | sevenTEEN vs. SEVen-ty |
| 18 vs. 80 | eighTEEN vs. EIGHty |
| 19 vs. 90 | nineTEEN vs. NINEty |


### 2. 字母拼写（Spelling）

| 易混淆字母 | 发音区别（国际音标） | 记忆技巧 |
| :--- | :--- | :--- |
| B / P | /biː/ vs. /piː/ | B有"ee"长音，P是轻音 |
| D / T | /diː/ vs. /tiː/ | 注意送气区别 |
| F / S | /ef/ vs. /es/ | 结尾音不同 |
| M / N | /em/ vs. /en/ | 口型大小不同 |
| G / J | /dʒiː/ vs. /dʒeɪ/ | 注意元音 |
| A / I | /eɪ/ vs. /aɪ/ | 双元音不同 |
| C / E | /siː/ vs. /iː/ | C有/s/开头 |

**常见字母拼写场景**：
- 姓名拼写：S-M-I-T-H / 有时会特殊说明，如"G as in George"
- 街道名称：King Street, Bridge Road
- 邮箱地址：john.smith@gmail.com
- 车牌号码：AB12 CDE

| 11:30 am | half past eleven | eleven thirty |

**月份与星期重点听辨**：
- Tuesday / Thursday（发音易混）
- January / February（拼写复杂）
- August / October（重音位置）

## 四、听力转折/信号词（抓住答案的关键）

> 听力中，**转折词后面往往是答案句**。以下为最常考的转折/提示信号。


### 1. 转折类（答案往往在后面）

| 信号词 | 功能 | 示例 |
| :--- | :--- | :--- |
| **but** | 转折（最核心） | I'd love to go, but I have to work. |
| **however** | 然而 | It was expensive. However, it's worth it. |
| **although / though** | 虽然 | Although I was tired, I stayed up. |
| **yet** | 然而 | It's simple, yet effective. |
| **while** | 虽然/而 | While I agree, I have some doubts. |
| **whereas** | 然而（对比） | He is outgoing, whereas his brother is shy. |
| **actually** | 事实上 | Actually, I think we should wait. |
| **in fact** | 事实上 | In fact, he never came. |
| **well** | 嗯（引出相反观点） | Well, that's not entirely true. |


### 2. 因果类（关注答案方向）

| 信号词 | 功能 | 示例 |
| :--- | :--- | :--- |
| **because / since / as** | 因为 | We left early because it was raining. |
| **so / therefore** | 所以 | I was hungry, so I ate. |
| **that's why** | 那就是为什么 | That's why I left early. |
| **as a result** | 因此 | As a result, we missed the train. |
| **consequently** | 因此 | He didn't study; consequently, he failed. |
| **due to / owing to** | 由于 | Due to bad weather, the flight was delayed. |
| **the reason is...** | 原因是 | The reason is quite simple. |


### 3. 递进/补充类（多选/信息叠加）

| 信号词 | 功能 | 示例 |
| :--- | :--- | :--- |
| **and** | 和 | 最基础 |
| **also / as well** | 也 | I also like swimming. |
| **too** | 也（句末） | I like it too. |
| **in addition** | 此外 | In addition, we need more time. |
| **furthermore / moreover** | 此外 | Furthermore, it's very cheap. |
| **not only... but also...** | 不仅...而且... | Not only is it cheap, but also good. |
| **another thing is...** | 还有... | Another thing is the location. |
| **plus** | 而且 | Plus, it's very convenient. |


### 4. 强调类（答案往往是重点）

| 信号词 | 功能 | 示例 |
| :--- | :--- | :--- |
| **especially** | 尤其 | I like fruit, especially apples. |
| **particularly** | 特别 | particularly important |
| **in particular** | 尤其是 | I love Italy, in particular Tuscany. |
| **the main point is...** | 重点是... | The main point is this. |
| **importantly** | 重要的是 | More importantly, we must act fast. |
| **remember that...** | 记住... | Remember that we have a meeting. |


### 5. 举例类（细节提示）

| 信号词 | 功能 | 示例 |
| :--- | :--- | :--- |
| **for example / for instance** | 例如 | For example, you can try this. |
| **such as** | 比如 | ...such as apples and pears. |
| **like** | 像 | ...like London or Paris. |


### 6. 转折/否定陷阱（听力最大的坑）

| 信号词 | 陷阱说明 | 示例 |
| :--- | :--- | :--- |
| **thought / would have** | "过去曾想/本会" → 实际没做 | I thought I would go, but... |
| **was going to** | "本打算" → 实际没去 | I was going to call, but I forgot. |
| **had planned to** | "本计划" → 改变了 | I had planned to study, but I went out. |
| **used to** | "过去曾经" → 现在不这样了 | I used to smoke, but I quit. |
| **not really** | "不太..." | Do you like it? Not really. |
| **I wish I could** | "希望我可以" → 但不行 | I wish I could come, but I'm busy. |
| **if only** | "要是...就好了" → 无法实现 | If only I had more time. |
| **I'd rather not** | "我宁愿不" → 委婉拒绝 | I'd rather not say. |
